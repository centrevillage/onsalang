# W7-17 の形の値の表（段 1、仕様の字と決定だけから）

- 89 形。期待の値は、模型を回す前に字から手で書いた。「模型: 一致」は `model.py` の出力と同じという意味で、不一致は 0 件。
- 作り直すとき: `python3 -B cases.py`（突き合わせ）、`python3 -B cases.py --md`（この表）、`python3 -B mutate.py`（読み違いの形に変えた模型で、どの事例が変わるか）。
- 事例の本体は `flow top(x: U32 at sample, y: U32 at sample, c: U32 at sample) -> U32 at sample { … }` の中身である。
  入力の列は位置 0 からの値で、書いていない入力は全て 0。イベントは中の作り手（`gen~` など）が sample の段で出す。
- 模型は式のクロックを推論しない。各式のクロックは、組むときに §11.3・§11.11 の規則で手で決めた。
  入れ子の呼び出し・`par~`・`if~`・`match~` は、式の評価の順（§11.3、§11.5）のとおりに項目へ開いて組んだ。
- 構文が確かでない所: `enum V { A(U32), B }` と `impl Default for V` の書き方、修飾子の条件の中の作り手の呼び出し（P1-6）、
  ガード付きの `match~`（A1-6）、本体が外のイベントのクロックの式の `par~`・`par`（P1-2、P2-2。§11.5 の E0815 は「`e` の中の呼び出しのイベントの出力のクロック」だけなので通ると読んだ）。
- 【字で決まらない】の事例の値は、模型が選んだ読みの値である。

## 共通の部品

```onsa

enum V { A(U32), B }
impl Default for V { rt fn default() -> V { V.B } }

flow gen(x: U32 at sample) -> U32 at event { some_if(x != 0, x) }       // sample の段で、0 でない x を出す
flow genz(x: U32 at sample) -> U32 at event { if x != 0 { Some(x - 1) } else { None } }  // x - 1 を出す（値 0 のイベントを作れる）
flow genv(x: U32 at sample) -> V at event {                             // 1〜5 は V.A(x)、6 以上は V.B を出す

flow tk() -> U32 at event { Some(sample_tick()) }                       // 本体の sample の刻みごとに、その時間を出す

  n }

  n }

flow inc(e: U32 at event) -> U32 at sample { e + 1 }                    // イベントの段の計算した式
flow inc2(e: U32 at event) -> U32 at sample { (e at sample) + 1 }       // sample で計算する式
flow stamp(e: U32 at event) -> U32 at sample { let t: U32 = e * 1000 + sample_tick()   // イベントの段の時間
  t }
flow pe(e: U32 at event) -> U32 at sample { let p = prev~(e)            // 一つ前のイベントの値
  p }
flow runs() -> U32 at sample { let k: U32 = prev~(^k) + 1               // 動いた刻みの数
  k }
flow pv(x: U32 at sample) -> U32 at sample { prev~(x, 9) }
flow idf(x: U32 at sample) -> U32 at sample { x }
flow mix(e: U32 at event, s: U32 at sample) -> U32 at sample { s * 100 + e }
flow hit(a: U32 at event, b: U32 at event) -> U32 at sample { cnt~(a).reset_if~(b != 0) }
flow wa(e: U32 at event, c: U32 at sample) -> U32 at sample { acc~(e).when~(c != 0) }
flow inner(x: U32 at sample) -> U32 at sample { let d = gen~(x)
  d at sample }
flow in2() -> U32 at sample { let d = tk~()
  stamp~(d) }
flow fw1(e: U32 at event) -> U32 at event { Some(e + 1) }
flow wn(m: U32 at event) -> U32 at event { let d = beat~(m).up~(2)
  Some(d) }
flow w2() -> U32 at event { let d = tk~().up~(2)                        // 一回の sample の段で二つ出す
  Some(d) }
flow w3() -> U32 at event { let d = w2~()
  Some(d) }
flow w4() -> U32 at event { let d = w2~().up~(2)                        // 一回の段で四つ
  Some(d) }
flow wb() -> U32 at event { let d = tk~().up~(2).down~(2)               // 塊の境界の位置で二つ
  Some(d) }
flow pp(e: U32 at event, x: U32 at sample) -> U32 at sample {
  let s = par i in 0 ..< 2 { x + (e + i + 1) }
  s[0] * 100 + s[1] }
flow lastof(x: U32 at (sample * 2)) -> U32 at sample { x[1] }           // 変換の flow: 二つの走りの後の方
flow both2(x: U32 at (sample * 2)) -> U32 at sample { x[0] * 1000 + x[1] }
// S-1251 (W7-17): the forms of the reading (1), whose events come from a flow that has the event within it
flow sbeat(v: U32 at sample) -> U32 at event { Some(v + 1) }
flow sfwd(m: U32 at event) -> U32 at event { Some(m) }
flow scnt(m: U32 at event) -> U32 at sample { let n: U32 = prev~(^n) + m
  n }
flow sbm() -> U32 at event { let k: U32 = prev~(^k) + 1
  Some(k at sample) }
flow ssum_out(m: U32 at event) -> U32 at event { let n: U32 = prev~(^n) + m
  Some((n at sample) + 1) }

  let s: U32 = prev~(^s) + (m at sample)
  Some(d) }

  Some(d) }
flow sbm2() -> U32 at event { Some(sbm~().up~(2)) }
// 事例の本体は flow top(x: U32 at sample, y: U32 at sample, c: U32 at sample) -> U32 at sample { … } の中身
```

### M1-1（M1）

```onsa

let a = acc~(d).when~(c != 0)
a
```

- 入力: x = 0 3 0 5 0 0 2 0、c = 1 1 0 0 1 0 0 1
- 手で出した期待: `100 203 203 203 308 308 308 410`
- 根拠: §11.10「イベントの刻みの処理は止めない」「止まっている間は最後の出力を保つ」。位置 3・6 のイベントは止まっている間に足され、次に動いた刻みの出力に出る。
- 模型: 一致

- 根拠: §11.10「イベントの値（W の刻みで、その位置までの最後の値として読む水準）」、§11.11「周期の…被演算子の無いイベントの値の式は、そのイベントのクロックの式」、§11.3 の刻みの欄の初めの値。`g == 0` は g の刻みで評価する Bool の欄で、最初のイベントの前は false（「0 だから真」ではない）。一度も動いていない間の出力は T.default()。
