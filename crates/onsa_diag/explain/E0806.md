# E0806: this form is not allowed in a flow body, nor a thing with state on the right of `&&` / `||`

A flow body is written with a closed list of forms (spec §11.2): `let`s,
names, literals, operators, calls of effect-free functions, flow calls,
`if` / `match` and their `~` forms, `par` / `par~`, and the few others the
list names. Another form, such as a `let` in a nested block, a mode on a
flow input, or a function used as a value, is E0806.

The right of `&&` / `||` is evaluated only when the left does not decide
the value, like a branch (spec §11.5). A thing with state (an instance, a
built-in delay, a `par~`) there is E0806 too, as it is E0811 in a branch.
The candidate moves it into a new `let` before the statement that holds
it, which evaluates it on every sample.

```onsa
let y = gate && lp~(x) > 0.5                 // E0806
let s = lp~(x)
let y = gate && s > 0.5                      // OK
```
