# E0010: binary operators of groups without a strength between them, mixed without parentheses

Binary operators belong to groups: multiplicative (`* / *% *|`),
remainder (`%`), additive (`+ - +% -% +| -|`), comparison
(`== != < <= > >=`), `&&`, `||`, and bitwise (`& | ^ << >>`). Some
groups are stronger than others, only where mathematics and the main
languages agree (spec §3.1):

- multiplicative > additive > comparison > `&&`, `||`
- remainder > comparison

An expression of a stronger group may be an operand of a weaker one
without parentheses. Groups without a strength between them (`&&` and
`||`; the remainder and the additive or multiplicative groups; the
bitwise group and every other group) are not mixed without parentheses.

```onsa
let a = x + y * z        // OK: x + (y * z)
let b = i % 2 == 0       // OK: (i % 2) == 0
let c = lo <= x && x < hi // OK
let d = w + 1 % n        // E0010: (w + 1) % n or w + (1 % n)
let e = p && q || r      // E0010: (p && q) || r or p && (q || r)
let f = m & 1 == 0       // E0010: (m & 1) == 0 or m & (1 == 0)
let g = a < b < c        // E0010: a < b && b < c
let h = m | 1 | 2        // OK: the same bitwise operator chains
let k = m & 1 | 2        // E0010: (m & 1) | 2 or m & (1 | 2)
```

Within one group, the multiplicative, remainder, additive, `&&` and
`||` groups chain left to right. Comparisons do not chain. In the
bitwise group, only the same operator chains (`a | b | c`). The
candidates are the readings of the expression, one per placement of a
strength on the groups that clash, with only the parentheses each one
needs; with more than three readings, there is no candidate.
