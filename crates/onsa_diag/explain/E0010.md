# E0010: binary operators from different groups mixed without parentheses

Onsa has no operator precedence. Binary operators belong to groups
(additive `+ - +% -% +| -|`, multiplicative `* / % *% *|`, comparison,
`&&`, `||`, bitwise), and operators from different groups cannot be
chained without parentheses (spec §3.1).

```onsa
let c = x + y * z        // E0010
let c = x + (y * z)      // OK
```

Within one group, additive, multiplicative, `&&` and `||` chain
left-to-right; comparison and bitwise operators do not chain at all.
