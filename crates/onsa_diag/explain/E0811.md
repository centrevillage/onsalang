# E0811: calling a flow creates a stateful instance and needs `~`

Inside a flow body, `name~(args)` creates a stateful instance of the
flow `name`, while `name(args)` applies a stateless function point by
point (spec §2.6, §11.5). Calling a flow without `~` is an error so that
the two kinds of call never look the same.

```onsa
let f1 = resonator(src, vowel_f1, 80.0)     // E0811
let f1 = resonator~(src, vowel_f1, 80.0)    // OK
```

A replication of a flow's structure is written `par~` for the same
reason (spec §2.6, §11.5): inside a flow body, `par` without `~` is
E0811, with the candidate that adds the `~`.

```onsa
let saws = par i in 0 ..< 4 { saw~(f0) }     // E0811
let saws = par~ i in 0 ..< 4 { saw~(f0) }    // OK
```
