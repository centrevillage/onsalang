# E0200: feature not supported in this version of the compiler

The program uses a feature, or a form of a feature, that this version of the
compiler cannot handle (spec §18.1). The message names the feature. It is one
of:

- a feature the spec says this version does not support,
- a feature the target does not provide (spec §15.2, §15.5),
- a feature the spec defines that the compiler cannot handle yet, including
  some forms of a feature it handles otherwise.

The compiler never turns such a program into a wrong result: it stops with
E0200 at the place it found the feature. When this version accepts another
form that does the same, a note shows it.

E0200 is not an internal error. A failure inside the compiler that it did not
expect has no code and exits with 101 (spec §18.2); it is a bug in the
compiler, not in the program.

Which features are in the list below changes with the version of the
compiler. The list holds the forms this version of the compiler reports as
E0200; it is not everything the spec leaves out of this version (some of
those, such as `main_frame` in the manifest, are not detected yet).
