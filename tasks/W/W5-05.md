# W5-05 数の trait と関連定数

- 内容: `AnyNum` / `Num` / `Float` / `Int` / `Unsigned`、`Not`、ラップ・飽和の trait、シフトの右辺は `U32`。符号なし整数は `Num` を満たさない。
  演算子ごとに自分の trait を引き（単項の `-` は `Neg`）、`Num` での代用と単項の `-` の特別扱いを消す。`Copy` は `AnyNum` が要し、`Num` は `AnyNum` を通じて含む。trait の関連定数と `T.ZERO` / `F32.ZERO`。総称の演算子の修正候補。整数型の `BITS` を型の幅にする（R-136）
- 実現する決定: R-94、S-84、R-56、S-46、R-128、S-73、R-131 の一覧、S-141、R-136、R-169
- 持ち越し:
  - **第 40 組から（2026-10-23、55 回目）:** `F32.MIN` が今は通る（S-46 の E0302 と候補 `-F32.MAX` が未実装。第 40 組の下書きの n10 で確かめた）。
