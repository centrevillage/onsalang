# W5-05 数の trait と関連定数

- 内容: `AnyNum` / `Num` / `Float` / `Int` / `Unsigned`、`Not`、ラップ・飽和の trait、シフトの右辺は `U32`。符号なし整数は `Num` を満たさない。
  演算子ごとに自分の trait を引き（単項の `-` は `Neg`）、`Num` での代用と単項の `-` の特別扱いを消す。`Copy` は `AnyNum` が要し、`Num` は `AnyNum` を通じて含む。trait の関連定数と `T.ZERO` / `F32.ZERO`。総称の演算子の修正候補
  暫定の `Bound`・`implies`・Rust の表を、1 行が 1 つの `impl` に対応する形に組み替える（R-127。std への移行は第 2 期。W5-02 から移した）。総称の範囲の端（`T: Int` の `T.ZERO ..< n`、S-257 の総称の部分）。整数型の `BITS` は W5-02（X-23）
- 決定の範囲: R-131 の一覧、S-257 の総称の範囲の端
- 単位: X-23 の見積もり（2026-11-02、104 回目、`issues/X/X-23/estimate.md`。素の行数で、テストを除く）: 約 630 行と R-127 の 60〜100 行、4 単位（組 B）。
  U1 数の trait と演算子の trait の表、R-127 の組み替え（`body/bounds.rs` は半分を超えうるので、この単位は設計メモで作り直すかを決める）→ U2 演算子ごとの trait ／ U3 関連定数（U2 と並べられる）→ U4 総称の演算子の修正候補（修正候補の約束の器）。
  S-231・S-238 の両方がこの作業に決まって約 1,000 行を超えるときは、U4 以降を別の作業に切り出す。
