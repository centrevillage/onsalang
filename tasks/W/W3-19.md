# W3-19 型引数の構文 `::[…]`

- 内容: 名前の経路の後の `::[` と型の並び（要素は型の位置の並びと同じ読み取りで、const 引数は定数式）を構文の木に読む（S-239）。型の位置の `Buf::[F32]` は E0020（候補は `::` を除く）、名前と `::`・`::` と `[` の間の空白は E0020（候補は空白を除く）。
  行頭の `::`、宣言の `fn f::[T]`、パターンの `None::[I32] =>`、名前の経路でない式の後（`(e)::[T](x)`、`g(x)::[T](y)`）、空の並び `f::[]` は E0002。`!` は並びの後（`buf.push::[F32]!(x)`）。入れ子の深さで `::[…]` は一段（段を作るトークンは `[`、§2.5）。
  経路の `::` の E0020 は `[` が続かない `::` にし、S-248 の一つの経路の形は `::[…]` の前後を問わない（`Buf::[F32]::zeroed(4)` は一つの誤りで、候補は `Buf::[F32].zeroed(4)`）。
  fmt の正規形（`::[` の前後に空白を置かない、並びの中は型の位置と同じ、期待型の注釈と型引数を互いに書き換えない。`spec/tools.md` §3.2）。
  構文の段の他言語の形（`f<T>(x)`、`f::<T>(x)`、添字として読めない `pair[U8, F32](…)`）は E0020 で、候補は `::[…]` への構文上の編集（S-277。`P<…>(…)` は比較の連鎖の候補も並べる、S-256）。呼び先が名前の経路でもメソッドでもない形（`(e)<I32>(x)`、`g(x)::<I32>(y)`）は型引数を除いて `e.(x)`。
  表の行は W3-15 の手順で足し、S-250 のデータのファイルの `f::<T>(x)` の行の候補を `::[…]` にする。W4-13 までの名前の段と型の段での `::[…]` の扱いは作業票で決める S-321 の `SPEC-GAP(S-321)` の印（`parser.rs` の `is_item_start`）を外す（決定は W3-15 の実装のまま）。
- 決定の範囲: S-239 の構文と fmt、S-256 の構文の段、S-277 の構文の段、S-248 の経路の境
