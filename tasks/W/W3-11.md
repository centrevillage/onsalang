# W3-11 fmt を CST の上に

- 内容: コメントを書かれた行に残す。正規形（項目の間の空行など）。1 行の `let` と `var` の `=` の整列（型注釈で列を切らない）。数値リテラルの綴りを揃える（接頭辞と指数は小文字、16 進の数字は大文字、`_` は数字の間に一つずつ、浮動小数の整数部の余分な 0 を外す、指数の `+` を外す）。コメントの位置の性質テストを実装待ちから外す。
  継続と並びの中の書き手の改行を保ち、fmt の性質テストに足す（R-143）。改行を LF に揃える（S-201）。範囲の記号の後の書き手の改行を保ち、次の行を 1 段深くする（S-335 の fmt）。
  範囲の記号の両側に空白を一つ置く（S-334。`fmt.rs` の `SPEC-GAP(S-334)` を外し、仕様の例・std・テストの写し・`docs/` の Onsa のコードの範囲を fmt の形に書き換える。`onsa graph` のラベルは縛らない）。
  属性の引数、列挙子の要素、効果行と `use` の並び、型引数と型パラメータ、タプル型と関数型の引数も三つの形の並びにし、1 行に畳む並びを無くす（S-510、S-328）
- 決定の範囲: S-89 の整列、S-62 の fmt、S-126 の fmt、S-201 の fmt、S-335 の fmt
