# W3-20 呼び出しと式の形

- 内容: 関数値の呼び出し `.(`（S-191）の構文・低下・今の sema の値の呼び出しへの写し・fmt・dump。呼び先が名前の経路でも名前の経路に `[…]` を付けた形でもない呼び出し（`(e)(x)`、`g(x)(y)`）は構文の段で E0020（候補は `e.(x)`。W3-19 の `is_value_callee`・`value_call` を使う）。
  名前の経路に `[…]` を付けた呼び先（`xs[i](x)`）は名前の段（W4-12、S-256）なので、`tests/spec/fixes/e0020_call_forms_syntax.onsa` の `ops[i](x)` の事例を名前の段の事例へ移し、冒頭の注記を直す（実装待ちの一覧の until は W4-12）。`f(x)` と `.(` の E0020 は W4-12 まで出ないので、その否定例は実装待ちの一覧に置く。
  既存のテストの関数値の呼び出しは、名前の解決で決まるのでスクリプトでは書き換えず、手で `.(` に直す（`tests/spec/semantics/fn_values.onsa`、`tests/spec/negative/` と `tests/review-phase1/` の関数値を呼ぶファイル）。`fn_values.onsa` の「仕様が言わない」の注記を外し、`s.f.(x)` の正例を足す。
  引数の `move` / `inout` の被演算子は後置式、括弧の中の `move` は 2 要素以上のタプルだけ（R-42）。1 要素のタプルの `,` は式と型で E0002、式・型・パターンの `(e)` はグループ化（R-43。`foreign_candidates.rs` の R-43 の `#[ignore]` を外す）。
  末尾の式と返り値の位置の `move` の構文（S-100。検査は W4-09。構文だけ入った間の modes の段の扱いを設計メモで決め、黙って誤らない、§18.1。`tests/fuzz/67f69e84.onsa` を外せなければ until を W4-09 に）。
  複合代入と増減の左辺にタプルの添字を含める（S-322。`is_place` と一覧の例、`SPEC-GAP(S-322)` を外す）。W3-19 の `,` を含む `[…]` の行の候補を型の位置の中では出さない（R-196）。`type_args_on_expression` と `e0020_type_args_callee.onsa` の項目（候補の `.(`）を外す。
  メンバの `.` の前後の空白の E0020（S-203 の `.` の分、行 `space_around_dot`。W3-06 から移した）
- 決定の範囲: S-191 の構文と構文の段の E0020、S-100 の構文、S-203 の `.`
