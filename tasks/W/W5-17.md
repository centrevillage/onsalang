# W5-17 第二級の型を受ける型パラメータ `?Escape`

- 内容: S-862 の K。型パラメータの暗黙の `Escape` の要求と、それを外す境界 `?Escape`（§4.5）。印の付いた型パラメータは第二級の型でも具体化でき、その値は本体の中で第二級（返す・保存する・捕捉する・`move` の引数は E0710、`T` を返り値・フィールドに書いた宣言も E0710、S-217 の借用の行の束縛は書ける）。
  第二級の型での具体化は種の制約を満たすとして扱い、trait の境界は判定する。`onsa interface` に境界を出す。W5-02 の `?Escape` の E0200 の分岐を消し、配列の `len` を組込みの表の行から std の `impl[T: ?Dup + ?Escape, const N: U32] [T; N]` へ移す。第二級の関数値（S-809）は範囲の外

    形: `GenericKind::Type` の `escape`、`GenericDef::lifts_escape`。`second_class`・`no_kind_argument` が `Ty::Param` の `?Escape` を `Span` の頭として答え、`places` が `?Escape` の型引数を `LIFTED`（`(Pos::Bind, ROOT)`）に置く。
    modes は `SecondClass::Lifted`（扱いは `View` と同じで文面だけが違う）。`?Escape` のある範囲では `misfit` の控えを使わない。`impl` の型パラメータは `onsa interface` の `impl` の見出しに出す（JSON の `generics` も。R-382）。
    親の読み: `T: ?Escape + Num` の値も §4.5 の文のとおり本体の中で第二級で、`let y = x + x` は E0710 である（境界を見て第一級に読む形は後で緩められる）。`rows[i].len()` が受け手を評価して範囲外で panic すること、`[F32; A6.len()]` の E0417（§4.5）、`len` が呼び出しの深さに数えられること（§12.5）は仕様に合う変化である。
