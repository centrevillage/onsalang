# W5-17 第二級の型を受ける型パラメータ `?Escape`

- 内容: S-862 の K。型パラメータの暗黙の `Escape` の要求と、それを外す境界 `?Escape`（§4.5）。印の付いた型パラメータは第二級の型でも具体化でき、その値は本体の中で第二級（返す・保存する・捕捉する・`move` の引数は E0710、`T` を返り値・フィールドに書いた宣言も E0710、S-217 の借用の行の束縛は書ける）。
  第二級の型での具体化は種の制約を満たすとして扱い、trait の境界は判定する。`onsa interface` に境界を出す。W5-02 の `?Escape` の E0200 の分岐を消し、配列の `len` を組込みの表の行から std の `impl[T: ?Dup + ?Escape, const N: U32] [T; N]` へ移す。第二級の関数値（S-809）は範囲の外
- 決定の範囲: S-862 の K の部分
- 単位: 見積もり（2026-11-03、106 回目、S-862 の段 2 の続き。素の行数で、テストを除く）: 100〜150 行、事例 10〜15 件、1 単位。`bounds.rs` に触れないので W5-05 と並べられる。
- 持ち越し:
