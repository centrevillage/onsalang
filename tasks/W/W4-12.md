# W4-12 名前で決まる呼び出しとパターンの形

- 内容: 名前の経路の呼び出しの形: 項目（関数、関連関数、名前空間の関数、効果の操作、列挙子の構築）は `f(x)`、ローカルの束縛と引数は `v.(x)` で、違えば E0020（W3-02 の表の行を引く）。関連関数と名前空間の関数は値になり、`Point.norm` と効果の操作を値の位置に書くと E0308（S-205）。
  パターンの名前（`snake_case` は束縛、それ以外は解決して定数か列挙子でなければ E0308、S-185）。`f(x)` と `inc.(1)` の否定例。
  名前の経路に `[…]` を付けた呼び出し（`P[…](…)`）: `P` が値なら `P[…].(…)`（S-191）。`P` が項目か型のとき（と型の経路の型引数 `Buf[F32].zeroed(4)`）の E0020 は、候補が `::` の挿入になったので W4-13（S-239 で S-256 の除く候補と注釈に移す候補を置き換えた、K-22）。
  flow の本体の `~` の有無（E0811 / E0812。枝の E0811 と `if~` / `match~` の E0812 を除く）と flow の外の flow だけの構文（E0821）を名前の解決で判定し、名前の段で出す（型の誤りがあっても出す。`let a: I32 = lp(x)` の候補の後の E0401 は後の段で、S-236 の約束の内。S-267）。
  登録簿の E0811 / E0812 / E0821 の段を名前に改める（E0811 / E0812 は枝の分の flow を残す）
- 実現する決定: S-191 の名前の段、S-205 の名前の段、S-185 の名前、S-267 の `~` の有無と E0821、S-368、S-379
- 持ち越し:
  - **W4-12（9 回目）:** W3-09 の関門のため、flow の外の `fn` の `prev~(x)` は E0812 から E0200 になった（`tests/review-phase1/parent/t5.onsa` の 25 行、コメントの期待は E0821）。`a.prev~(x)` と自作の `my~(x)` は E0812 のまま。E0821 を入れるときに揃える。
    - E0812 の候補「`~` を除く」は、`~` を除いた形が呼べるときだけ出す（R-225。`x.prev~(0.5)` で E0413 を作る）。直したら `tests/pending.toml` の `fuzz-input` の `8be605b6` を外す（28 回目、W3-12 の U1b の gate）。
  - **W4-12・W4-13（W3-20 の直し、2026-10-09）:** `~(`・`!(`・`::[` の関門は、まだ種類だけの `names_a_path` で判定する（`mk2().0!(x)`、`mk2().0~(x)`、`mk2().0::[I32](x)` は構文の段を通り、後の段の E0714・E0812・E0200 で止まる）。
    - 呼び先の述語 `callee_by_name` に揃えるかを決める。
    - W3-20/b の再確認（2026-10-09、報告 8 回目の scratchpad の `w320b2/`）の D: `callee_by_name` の `TypeArgsExpr` の枝は連鎖を見ず、`mk2().0::[I32](x)`・`ts[0].0::[I32](x)` が構文の段を通り E0200 で止まる。
