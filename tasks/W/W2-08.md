# W2-08 生成したコードの実行時の誤り

- 内容: poisoned / 未初期化のインスタンスの `process` が無音を出す。平面の入出力の全てのチャンネルの長さを比べる。export の入出力の重なりの検査を、各範囲の要素の大きさで測る（R-141）。長さは状態を進める前に全ての `Span` で比べる（S-196）。poison の呼び出しの出力は全て 0（S-199）。
  0 フレームの呼び出しは `block` の段だけを評価し、ポインタを読まず重なりを検査しない（S-204）。期待値は W1-11 の `[[test.host]]` で書く（K-14）。Core の降下を直すので、インタプリタと C の両方に当たる
