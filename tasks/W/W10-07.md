# W10-07 イベントの C の API

- 内容: 一番外の flow のイベントの入出力の境界。生成する API の `Event` と入力ごとの作る関数、`process`・`render` のイベントの列と出力の列（長さが容量、出した数を返す）、`Rendered` のイベント。
  C の `<p>_event`・`<P>_EV_<名前>`、`_process` の `events`・`events_len`、`<p>_out_event`・`<p>_events_out`、容量の上限と `<P>_OUT_EVENTS_PER_FRAME`、列の前提を破ったときの 2、`<p>_event_in_info`・`<P>_EVENT_IN_COUNT`・`<P>_EVENT_OUT_KIND`、`onsa.h` の `onsa_event_kind`・`onsa_event_in_info`。
  境界のイベントの型の C の表し方（`midi.Message`・`transport.Event` は `uint32_t`）
