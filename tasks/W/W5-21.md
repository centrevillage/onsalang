# W5-21 総称の修正候補（境界を絞る、note、`as` の型パラメータ、`MIN`）

- 内容: W5-05 の U5 を切り出した（2026-11-05、117 回目。U3 の終わりの累計が約 785 行で、W5-05 の `単位` の線の約 650 を超えたため）。総称の誤りの修正候補と note だけで、通るプログラムは変えない。
  (1) 境界を絞る（S-141、S-84、§6.3）: E0401 の演算子に、見出しの境界を足すか置き換える候補を出す。候補の trait は、否定が `Num`、ビット演算・`!`・ラップ・飽和が `Int`、`+ - * / %` が `Num`、`==` `!=` が `PartialEq`、`<` 系が `PartialOrd`。既にある境界のうち候補の trait に含まれるものは置き換える。絞れないとき（`T: Unsigned` の否定、`T: Float` のビット演算）と `?Dup` と矛盾するときは出さない（`IMPLS` から導く）。後回しの判定の失敗でも同じ候補を出す。
  (2) note（S-84）: 符号なしの否定に `0 -% u` と `T.ZERO -% x`。E0416 に満たす数の trait を `IMPLS` の行から出す。`T: Num` の `T.ONE` の E0302 に note を足す。
  (3) `as` の型パラメータ（S-231、§3.3）: `cast_instead` の変換先に型パラメータの枝を足す（`k as T`（`T: Float`）の `T.round_from(k)` など）。
  (4) `F32.MIN`・`T.MIN`（S-46）: E0302 の候補 `-F32.MAX`・`-T.MAX`。受け手の位置と前置の下は括弧を足す。
- 決定の範囲: S-141、S-84・S-231・S-46 の候補の部分
- 単位: 素の見積もりは 150〜190 行（W5-05 の設計メモの項目 8、`target/notes/116/w505/memo.md`）。器（`fix_contract`）の広げは要らない見込み。族ごとに事例を分ける（`fixes = N` の事例は候補が一つでも出ると実装待ちが外れる）。
