# W4-10 `match` の対象の変更

- 内容: ガードの中では対象を変更できない（E0715）。腕の束縛を借用の起点にし、腕の中の変更と重なる Copy でない束縛は、派生した束縛と一緒に以後使えない（E0704）。Copy の束縛は束縛した時点の値
- 決定の範囲: S-604 の派生元の並び
  86 回目に、腕の中の変更の E0704（S-42、R-118）を W4-07 へ移した（W4-07 の設計メモの審査の A1、利用者が了承）。残るのはガードの中の変更の E0715（R-110）で、W4-07 の `write.rs` の頭の口に足す。
- 持ち越し:
  - **S-799 の独立のレビューから（2026-10-30、90 回目）:** ガードは式なのでブロックを置ける。ガードの中のブロック・腕・入れ子の呼び出しの変更（`Some(b) if { o = None … true } => b.len()`。今は腕の `b.len()` の §7 の E0704）を、E0715 の事例に入れる（`target/notes/90/s799-advisor/probe/adv_forms.onsa` の a25）。
  - **W4-07 から（2026-10-30、87 回目）:** ガードの E0715 は新しい modes の `modes/write.rs::write_place` の頭に足す。S-796 の決定のとおり、対象は解決した場所（派生した借用束縛は派生元の場所）との重なりで判定し、E0702 を重ねない（`Some(b) if f(b, inout o) > 0` は E0715）。腕の中の変更の E0704（S-42・R-118）は W4-07 U3b で入った。
  - **X-8 から（2026-10-23、54 回目）:** `modes.rs` の作り直し（W4-07）の後のコードを直す。E0715 の仕組み（R-24 の反復元と R-110 のガード）とループの状態を W4-09 と共有するので、W4-09 の後に置く。腕の束縛の派生元は W4-16 の束縛の状態が記録する。
  - **第 42 組から（2026-10-23、57 回目）:** S-604: 借用の束縛の派生元は末尾の場所の全て（`let t = if c { s } else { u }` は `s` と `u`）で、E0715 と S-42 の無効化はその各々に当たる。派生元の並びは W4-16 の束縛の状態が持つ。
  - **58 回目の文書の点検から（2026-10-23）:** S-217 の補い: 部分ビューの反復元 `for v in xs.slice(a, b)` は `xs` の場所を反復元とする借用の `for` で、E0715 は本体での受け手 `xs` の全体の変更に当てる（範囲 `[a, b)` は実行時の値なので比べない）。
