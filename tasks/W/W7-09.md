# W7-09 部品のレートと変換の flow の検査と参照評価器

- 内容: 部品のレートと変換の flow の検査の段と参照評価器。導くクロックの構文（`at (sample / N)`・`at (sample * N)`、今は `at` の後ろが名前一つ）。修飾子の名前の表（`.名前~(` の頭がインスタンスの式のときだけ閉じた一覧を引く。`down`・`up`・`when`・`reset_if` を一度に入れ、意味のまだ無いものは flow の段の E0200。`~` の無い `.when(` は E0811、一覧に無い名前と値の受け手は E0812、受け手の規則（`let` で受けた名前・`par~`・`if~` / `match~` は E0812）と S-811 の修飾子の `!`。W7-10 から、X-26 の X26-5）。
  修飾子 `.down~(N)`・`.up~(N)`（N の検査、連鎖の比の合成、入れ子の比の積は 2^24 以内）と、変換の flow の入出力の `at (sample / N)`・`at (sample * N)` と本体での配列の見え方。遅い周期のクロックの値の読み（`at`、`block < sample / N`）、集める入力の E0816、位相のカウンタの `sample_tick()`（予約名、E0304。巻き上げない、§11.3）の型とクロック、総称の遅延の `sample / N` の刻み。計画の表にクロックごとの段を足す。W7-01 の参照評価器にマルチレートを足す（印はテスト・壊す側）。一番外の flow の `sample / N`・`sample * N` は、W10-01 の E0810 まで `process`・`render`・export で E0200 にする。Core と後端は W7-16（X-26 の X26-4・X26-23）
- 決定の範囲: S-565・S-566・S-567・S-578 の検査の側、S-969、S-555・S-556 の修飾子の名前の引き方と受け手の規則、S-811 の修飾子の `!`、R-288 の検査の側
