- 内容: W7-01 の参照評価器に flow の意味を足す（Q-02 (b)。§11 の文言をそのまま書く部分）。W7-01 から分けた（2026-11-16、158 回目、利用者）。`let` ごとのクロックと段（定数・`init`・`block`・`sample`）、呼び出し位置の状態の木、`prev~`・`delay~`・`vdelay~`（§11.4 の式をそのまま、二相の保存）、`^`、インスタンス、`sample_rate()`・`sample_tick()`、生成 API の flow の意味（`init`・`process`・`reset`・`render`）、`par~`、`if~`・`match~`、export の境界の poison（`Boundary`）。修飾子は W7-10、導くクロックは W7-09、イベントは W7-17 が足す
- 決定の範囲: Q-02 (b)
- 単位: W7-01 U1 の設計メモ（2026-11-16、158 回目、`target/notes/158/w701/memo/memo.md`（口の確かめは `target/notes/158/w701/api2/api2.md`））の見積もり: U1 `flow.rs`（クロックと段、状態の木、遅延、`^`、インスタンス、`init`・`process`・`reset`・`render`）300（20% を超える見込みなら U1a 状態の木・遅延・`^` と U1b インスタンス・段・`process`・`reset` に分ける）→ U2 `branch.rs`（`par~`、`if~`・`match~`、`Boundary`）170
