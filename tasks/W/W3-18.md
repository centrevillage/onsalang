# W3-18 範囲の書き方

- 内容: 字句解析器に `..<` と `..=` を置き、`..` と `...` は E0020 で候補は `a..<b` と `a..=b`（S-257。表の行は W3-15 の手順で足す）。範囲の記号は二項演算子より弱く、端は整数の型（E0401）。
  見出しの外の範囲は E0002 と note（`xs.slice(from, to)`）。`..=` の降下が入るまで（`for` は W8-03、`par` は W7-04）、見出しの `..=` は E0200（S-224）。
  今の `..=` の E0002 と note を消し、W3-15/t の `foreign_range_inclusive.onsa` と `foreign_candidates.rs` の `..=` の期待値（E0002）を改める。
  仕様の写し・std・`tests/`・`examples/`・`docs/` の範囲を一つ目の候補（`..<`）を当てるスクリプトで書き換え（`tests/cst/lex_*.onsa` の `..=` の扱いを確かめる）、実装待ちの一覧の spec-example の S-257 の項目を外す
- 決定の範囲: S-257 の構文と候補
