# W8-11 Core の型名の単射

- 内容: Core の型名を単射にする
- 決定の範囲: R-48 の Core の側
- 持ち越し:
  - **W8-01 の設計メモから（2026-11-27、191 回目）:** 部 2 の 5 章（`mangle` の符号、生成する区切りを `__` で始める、V-33、golden の更新）・9.1 を読む。W8-14 の `CTy` が先にあるので、名前を一度だけ作る。C の名前の重なり（S-1138）は W10-02 のまま。
  - **W7-03 U1c の壊す側から（2026-11-18、165 回目）:** `par~` の複製の Core の型名は W7-03 U1c で `{flow}.{path}.State`（`main.f.a.par_0.State`、`main.f._out.par_0.State`）にした。仕様 §11.6 は複製の型名を書かない。Core の型名の単射を決めるときに、この形を含めて決める（低）。
  - **第 110 組から（2026-11-18、165 回目、S-1138・S-1081・S-1136・S-1137）:** `_` で始まる生成する名前を `.` の後に持つ Core の型名（`main.f._out.par_0.State`）と、末尾の `_` の名前の型名（flow `f_` の `main.f_.out.par_0.State`）は、`.` を `__` にすると同じ C の名前になる。処理系が重ならない名前を選ぶ（仕様 §11.6 の C の文、S-1138。W10-02 の状態のフィールドの名前と同じ規則で）。
