# W10-08 ホストの情報と遅れ

- 内容: `block` の入力の `@host(<種類>)`（種類の閉じた一覧と E0005、型の違いと `@param` との重なりの E0809。export で `@param` が要らない）、`Params` の欄、`<p>_host_info`・`<P>_HOST_COUNT`、`onsa.h` の `onsa_host_kind`・`onsa_host_info`、C の `_params_default` の `@host` の既定の値、`onsa_param_info` と `onsa_host_info` の `offset`。
  一番外の flow の `@latency(samples: …, seconds: …)`（定数の項、値の誤りは E0809。C の `_init` が §11.6 の式で計算して状態の隠れた欄に書き、`reset` は保つ）と、C の `<p>_latency`
- 持ち越し:
  - **X-7 から（2026-10-23、53 回目、利用者が X-7 の全てを第 1 期に入れると決めた）:** W10-03 の後に行う。`ONSA_ABI_VERSION` 1 を出す前に足す（S-580）。ラッパーがホストの値を確かめて既定の値に置き換える形と、遅れの報告は M10。
  - **第 50 組から（2026-10-24、61 回目）:** S-588（(L3)）と S-632 の族の規則で内容を改めた（生成する API の `latency` は外した、S-625）。`@host`・`@latency` の検査は、export しない flow も含めて全て `onsa check` で出す。
    E0809 に `@host` の 2 形（`block` でない入力、同じ種類の二つ。二つ目の入力で note で一つ目を指す）と `@latency` の値の誤り（有限で 0 以上でない `seconds`、項の無い `@latency()`）。項の型の違いは E0401、評価の panic は E0419。E0815 は `@latency` に当たらない。
    報告する値は `samples +| (seconds * sample_rate).trunc_u32_sat()`（§11.6、`F32` の積）で、C の生成コードはこの式とビットで同じ値を出す。Onsa の `init`（インタプリタと `onsa test`）は隠れた欄に触れない。`onsa interface` に `@host` と `@latency`（書いたとおりの形）を出す（§18.2）。
  - **53 回目の点検の後半から（2026-10-23）:** `tools/builtin_names.toml` の属性の綴り（`param`・`mem`・`repr`・`fp`）に、属性の `host`・`latency` を実装のときに確かめる（`build.rs` の platform の `"host"` は同じ綴りとして載せた、`e5d2056`）。
