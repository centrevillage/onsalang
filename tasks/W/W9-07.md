- 持ち越し:

  - **W7-15 の設計メモから（2026-11-19、170 回目、親）:** interface に計画の構造上の位置（`spec/tools.md` §2 の照合の位置）を出すかと行の形を、S-65 の欄の印・型の表記と一緒に決める（S-86 の補い。読み手は照合 T7-5 だけで、出さないなら T7-5 へ）。あわせて `interface.rs::flow_layout` が Core の flow を名前の末尾の一致でも探す件（同じ名前の flow が二つのモジュールにあると大きさが消える。Core の flow が `DefId` を持てば一致で引ける。W7-15 の設計メモ 11 章）。
