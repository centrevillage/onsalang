# W5-03 Option / Result を std の enum に

- 内容: sema と Core の特別扱いを取り除く。メソッドは `unwrap` と `map_err` だけで、他は E0413。`Option` / `Result` の大小の比較が構造上 E0401 になることを確かめる（R-120 は作業から外す）
- 決定の範囲: S-607（型の名前空間から prelude の列挙子を引かない条件）、S-514 の一時の枝、S-659 の (c2) の `Option`・`Result` の仮の引きを消すこと
- 単位: X-23 の見積もり（2026-11-02、104 回目、`issues/X/X-23/estimate.md`。素の行数で、テストを除く）: +130〜230 行・約 340 行を消す・std の Onsa 20〜35 行、2 単位（組 A）。U1 std の enum と lang item（S-71・S-607・S-514・S-659 の (c2)、S-785・S-786 の確かめ）→ U2 `?`、Core と後端、R-96、`lazy_args` の撤去。
- 持ち越し:
  - **W5-14 U2a の壊す側から（2026-11-04、112 回目）:** `crates/onsa_sema/src/body/conversions.rs` の `const SOME: &str = "Some"` は登録簿の外の直書きで、`tools/builtin_names.toml` の許可で通している。`Option` を std の enum にするこの作業で、`names/prelude.rs` の登録簿か lang item から綴りを引く形にする。
  - **第 81 組から（2026-11-04、110 回目）:** （済み: W5-08 の U1 で確かめた。網に乗り E0406 になる。）`panic` を扱えるようにした後に、期待の型の無い位置の、本体が発散する無名関数（`let g = fn() { panic("x") }`）の返り値の型を試す。§4.7 の「リテラル以外の型変数が関数の終わりに残ればその式に E0406」の網に乗れば足りる。網の外なら S に登録する（第 81 組の独立のレビュー）。
  - **W5-18 U3 から（2026-11-04、110 回目）:** 基の複製（`Base::copy_for`）が、空の入力の検査（debug 約 0.36 ms）の約 43 % になり、C3（std の本体の表を `Arc` で分ける）の閾値「下限の半分」に近い。

  - **W4-04 U5 から（2026-10-27、77 回目）:** prelude の列挙子がどの型のものか（`Some` は `Option`）を、名前の段の `names/prelude.rs` の `VALUES` の列と `variant_of`（修飾した列挙子の E0302 の判定）と、型付けの `body/named.rs`・`body/patterns.rs`（型を作る所）の三か所が別に書く。
