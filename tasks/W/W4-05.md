# W4-05 署名の型と整形性

- 内容: 宣言どうしの閉路: 型定義の閉路 E0311、定数の初期化式の名前による閉路 E0312、自分をインスタンスにする flow E0817（K-10。関数を経由する定数の閉路は W9-03、S-173）。型の整形性を、位置と型構成子の組で判定する独立の段。`Copy` / `Dup` を種の制約にし、`impl Copy` と `: Copy` は E0020。重複実装とメンバの同名。
  総称の `impl` の規則。構造体のフィールドの第二級の型は E0710（R-135）。型別名の自己参照を E0310 でなく E0311 にする（R-182）。
  検査が作る型の深さ 256 と大きさ 4096 の上限（S-264）: 別名と書いた型の E0422（位置は別名の宣言か書いた型の形で、超えた別名を使う別名には出さない。note は途中の型を名前付きの struct にする形）と、共有した節ごとに深さと大きさを覚えて展開せずに判定する型の表現。
  推論した型の上限をどの W5 の作業で行うかは、この作業票で決める。`onsa_diag::stack` の文書を、この上限で有界と書き直す。E0006 の note を「型を名前付きの struct に」に改める（§2.5）
- 実現する決定: R-02、R-03 の E0817、R-37、S-140、S-134、S-137、R-135、R-152、R-182、S-264 の別名と書いた型
- 持ち越し:
