# W8-13 `onsa test` の `assert` の両辺の値（S-1261）

- 内容: S-1261。`onsa test` の `assert` の最上位が比べ（`==`・`!=`・`<`・`<=`・`>`・`>=`）で、失敗したとき、text の出力の失敗の行の後に両辺の値を出す。値を出すのは `Show` を実装する型（§6.3）。被演算子は一度だけ評価し、評価の順と panic の位置・種類は今と同じ。C の生成物は変えない。
  Core の `assert` の降下（`lower/body/mod.rs` の `AS::Assert`）に両辺の値を足し（C の後端は読まない）、比べの降下は二項演算と `assert` が一つの関数を使う。インタプリタが型に沿った `Show` で文字列にし、driver が出す。
  読むだけの見積もり（190 回目、`target/notes/190/assertvals/memo.md`）: `Show` を実装する型の全てで約 190 行（テストを除く）。W8 で書き直すのは約 25〜30 行（W8-03 の評価順、W8-04 の束縛、W8-08 の歩き）で、W8-09 の `check` の反例の表示がこの `Show` を使える。
  W8 の始め、W8-01 より前に置く（190 回目、親。X-27 の道具の単位と並べる）。着手の前に、S-1261 の残りの点（`Show` の無い型、大きな配列の出し方、浮動小数と `Char` の形、`spec/tools.md` の文面の約束と JSON の欄）を仕様の空白の流れで決める。W8-01 の設計メモに `Panic` の新しい欄を一行入れる。
