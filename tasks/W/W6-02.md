# W6-02 経路を見た破棄の点

- 内容: 破棄点を modes が経路を見て列挙し、rt と効果が共有する。一時値・上書き・総称の `T`。`Copy` の無い `T` の破棄は `Alloc` を要する
- 実現する決定: R-32、S-610 の破棄の行、R-255、S-613 の破棄の行
- 持ち越し:
  - **第 44 組から（2026-10-23、58 回目）:** S-610: 静的な値（W4-07 の印）の一時の値と束縛の破棄は数えない（§12.2）。Shared を含む値の型を組むことは `Alloc` を要さず、所有する Shared を含む値の破棄は要る。
    R-255: rt の関数で `move` の引数に受けた Shared 値をそのまま返すか、`move` の引数に（S-609 で `move` 無しで）渡すと E0901 になる（移動を記録しない見込み）。
  - **第 45 組から（2026-10-24、58 回目）:** S-613: 破棄の要らないリテラル（W4-07 が確定した束縛の状態と式の印）の一時の値と束縛の破棄は数えない（§12.2）。集成体のリテラルの破棄点の記録に、リテラルを所有の行にした最初の要素を持たせる（W6-03 の E0601 の note が読む）。
