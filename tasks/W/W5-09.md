# W5-09 `match` の網羅と到達しない腕

- 内容: 網羅は `Bool`、enum、それらのタプルと struct だけで数え、リテラル・定数・ガードの付いた腕は数えない。前の腕で覆われる腕は E0503（候補は腕を消す形と、`_` か束縛の腕を最後へ移す形）。`match~` も同じ。
  定数のパターン（書ける型はリテラルと同じ具体的な型で、他と `-LIMIT` は E0020。浮動小数の型の定数は型の段で出す、S-252。ガードの形の候補が新しく置く束縛の名前は見えている名前と重ならないもの、S-253。網羅と到達では値を見ない）。列挙子が一つの enum の `let` は E0502。
  実装待ちの一覧の E0503 を外す S-319: 書けない型の定数のガードの形の候補は一つの腕で一つの候補、選択の枝の規則は S-317 と同じ。`PartialEq` を満たさない型と枝の形が違うときは E0020 のまま候補なしで note（データのファイルの欄に候補 0 の約束の形が要る）。`-LIMIT` は W3-07 へ移した（K-23 で W3-21）。
- 実現する決定: S-187、S-185 の定数、S-177、S-252 の定数、S-253 の候補、S-319
