# W5-09 `match` の網羅と到達しない腕

- 内容: 網羅は `Bool`、enum、それらのタプルと struct だけで数え、リテラル・定数・ガードの付いた腕は数えない。前の腕で覆われる腕は E0503（候補は腕を消す形と、`_` か束縛の腕を最後へ移す形）。`match~` も同じ。
  定数のパターン（書ける型はリテラルと同じ具体的な型で、他と `-LIMIT` は E0020。浮動小数の型の定数は型の段で出す、S-252。ガードの形の候補が新しく置く束縛の名前は見えている名前と重ならないもの、S-253。網羅と到達では値を見ない）。列挙子が一つの enum の `let` は E0502。
  実装待ちの一覧の E0503 を外す S-319: 書けない型の定数のガードの形の候補は一つの腕で一つの候補、選択の枝の規則は S-317 と同じ。`PartialEq` を満たさない型と枝の形が違うときは E0020 のまま候補なしで note（データのファイルの欄に候補 0 の約束の形が要る）。`-LIMIT` は W3-07 へ移した（K-23 で W3-21）。
- 決定の範囲: S-185 の定数、S-252 の定数、S-253 の候補
- 単位: X-23 の見積もり（2026-11-02、104 回目、`issues/X/X-23/estimate.md`。素の行数で、テストを除く）: 約 340 行、2 単位（組 C）。U1 定数のパターン（〔メモ〕: crate をまたぐガードの候補の口。`onsa_syntax/src/foreign/guard.rs` の公開の入口を触るので、同じファイルを触る W5-11 の単位は親が前後に並べる）→ U2 網羅と到達しない腕（S-187・S-177）。
  設計メモ（2026-11-06、119 回目、`target/notes/119/w509_memo/memo.md`）と独立の審査で改めた単位: U1a 書ける定数（S-185・S-931・S-933）→ U1b 書けない定数とガードの候補（S-252、S-253、S-319。`foreign/guard.rs`）→ U2 判定と E0503 と S-177（S-187、S-932、`exhaust.rs` の再帰の作り直し。S-930 の上限の値をここで測って決める）→ U3 E0503 の候補（S-292、S-876、S-934。新しい `body/arms.rs`）。
  素の合計は 425〜455 行である。
  審査で改めた形: `cover` を作らず `P::Const` を足すだけ。`bad` は `P` に持たせず `bad_consts` に集める。移す候補の検査は移した後の並びの全ての腕に当て、試しは `end_is_clean` の形（`failed` を戻す）。挿す位置は腕の終わり。親が決めたこと: 定数の降下は案 A、移す候補は試し。
  親の読み: リテラルは値で比べる（`16` の後の `0x10` は E0503）。E0501 と E0503 が同じ `match` にあれば E0503 が先。
