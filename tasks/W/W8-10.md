# W8-10 配列・タプルの大小の比較

- 内容: 辞書式の比較を Core に下ろす。比べられない組では `<` などを全て偽
- 持ち越し:
  - **X-23 から（2026-11-02、104 回目、利用者が了承）:** derive した `PartialOrd`・`Ord`（struct のフィールドの辞書式、列挙子の宣言順、NaN の規則。S-135）の Core の比較の関数を W5-06 から移した。配列とタプルの辞書式（R-119）と同じ生成した関数として一度に書く（組 B の見積もりで、`lower/eq.rs` と同じ形の新しい `lower/ord.rs` 約 185 行）。型の段は W5-06。
  - **W8-10:** `tests/spec/negative/lower_unsupported.onsa` は配列とタプルの大小の比較を未対応の機能の例にしている。この比較を実装したら、別の未対応の機能に替える。R-119 の flow 側の E0401 も同じ回。
