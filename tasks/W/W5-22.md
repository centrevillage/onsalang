# W5-22 struct のフィールドの既定値とパターンの残りの印

- 内容: struct のフィールドの宣言の既定値（`y: F32 = 0.0`）、struct リテラルの最後の `...`（§4.4）、struct のパターンの最後の `_`（§7）。見えないフィールドの例外（§15.1）。derive の `Default` が宣言の既定値を使う枝（§6.4）。`onsa interface` の既定値の表示、fmt、flow の本体（§11.2）。
- 単位: 設計メモ（2026-11-06、118 回目、`target/notes/118/w522/memo/memo.md`）。素の行数で、テストを除く。括弧は W5-06 の伸び（1.4〜1.9 倍）を当てた見込みである。

  形: 既定値はフィールドごとに名前の無い `const` の `Def` で持つ（`FieldDef.default: Option<DefId>`、`Def.owner` は struct、新しい `ItemKind::FieldDefault`）。`...` と `default()` は Core の `Const` を読み、Core の新しい形は足さない。`consteval` は変えない（`const P0: P = P { x: 1, ... }` の `onsa interface` は値なしで、長さに読む形は今の E0200。W9-03 まで）。

  既定値の式の構文の誤りは struct の宣言の単位の誤りである（§18.1 の「宣言の単位で回復する」。フィールドの並びは回復の位置でない）。`Ring { data: xs }` の `...` の note は E0303 にも付ける（S-697 の下書きの「E0410 と E0303 の note」）。
