# W3-06 行と空白

- 内容: 継続の規則をトップレベルにも。継続の間のコメント行と空行、行頭の二項演算子の E0020、`with` の位置、属性の独立の行。`else` と `{` の位置（E0003）を括弧などの中でも。前置の `-` / `!` の後、名前と `~` / `!` の間、`^` と名前の間の空白。
  後置の `(` / `[` は「前に空白か改行がある」印で判定し、空白なら E0020（`f (x)`）、括弧の中の改行なら E0002（`,` の挿入と改行の除去）。呼び出し・添字・型引数・宣言の引数と型パラメータ・パターン・属性で同じ関数を使う。
  腕の `return` / `break` / `continue` は E0020（修正候補はブロックで囲む形）。`{` は継続した見出しの最後の行に置く（S-202）。`?` の前の空白は E0020（S-203。`.` の前後の空白は W3-20 が実装した）。
  E0003 の主の位置は置き場所を誤ったトークン（`else`、`with`、`{`）で、`found` と範囲の文字列を揃える（R-160）。修正候補は前の行の末尾のコメントの前に入れ、コメントは書かれた行に残す。一つの候補は一つの診断だけを直す。
  前の行へつなぐ他の候補（行頭の二項演算子の E0020、改行の後の `(` の E0002）も同じ（S-216）。`tests/spec/negative/syntax_else.onsa` の印を `else` の行に移す。直す候補は S-236 の約束（一つだけ当てて検査し直したとき、編集が触れた単位に同じ段以前の診断を残さない）を満たす。W3-17 の器の検査で確かめる。
  範囲の記号（S-335）: 行末の `..<`・`..=` で継続し、範囲の記号で始まる行は E0020（候補は前の行の末尾へ移す形。`..` と `...` は読みごとに二つ。見出しの外の範囲になる形は候補なし。検出は `for` / `par` の見出しが `{` を期待して改行を見た位置。データのファイルに `leading_operator` と別の行）
