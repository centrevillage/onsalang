# W5-06 `Default` と derive

- 内容: `default()` を降下し、`P.default()` と `T.default()` で呼ぶ。宣言の `: trait` の意味と前提の検査。derive した `PartialOrd` / `Ord`（フィールドの辞書式、列挙子の宣言順）。`Hash` の derive は境界の判定だけ。`Ordinal` の derive と整数との変換。
  enum の `Default` の derive と、中身のある enum の `Ordinal` の derive は E0416。`Show` の derive は E0200
- 実現する決定: R-60、S-49、S-34 の意味、R-35、S-135、S-138、S-145、S-13
- 持ち越し:
  - **W5-06（20 回目、W3-08、S-460）:** 誤りの属性の付いた struct・enum の `derives` が未知（`None`）のとき、derive が作るメソッドの引き（`P.default()`・`m.ordinal()`・`M.from_ordinal(n)`）と、手書きの `impl` との重なりの E0304 を黙らせる（事例は `tests/spec/negative/continue_derive_methods.onsa`）。
    `Hash` の derive は今も E0200（S-138 では境界の判定だけを実装する）。`repr` の `Unknown` を読む所はまだ無い（FFI の配置を検査する回）。
