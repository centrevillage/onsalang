# W10-05 浮動小数の環境

- 内容: `strict-ftz` の生成コード（`onsa__runtime.h` に制御レジスタの保存・設定・復元の補助、wrapper の入口と出口と `longjmp` の後）とインタプリタ。扱い方を知らないアーキテクチャと WASM / JS は E0200。マニフェストの `fp` を読む。export の入口で浮動小数の状態を保存して戻す。インタプリタの判定。単精度の FPU のソフトウェアの F64 の FTZ。x86 は Rosetta で確かめ、実機の確認は保留として残す
- 持ち越し:
  - **W5-07 の壊す側から（2026-11-06、119 回目）:** `sum` の `N = 1` は演算が起きないので、`strict-ftz` の `sum([sub])` は非正規化数のまま返る見込みである（`sum([sub, 0.0])` は 0）。`strict` の C では `sum([1.0e-40])` が非正規化数のまま。`fp` を実装するときに、§15.5 の DAZ・FTZ の文と合うかを確かめる（再現の形は `let` で読むだけの値と同じ）。
  - **X-8 から（2026-10-23、54 回目）:** `fp = "strict-ftz"` を実装したら、マニフェストの未対応の値の閉じた一覧（`tasks/diag-codes.md` の E0200 の行）から外す（W4-02 がそれまで E0200 にする）。
