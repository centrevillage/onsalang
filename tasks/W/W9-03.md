# W9-03 定数の評価の段

- 内容: 定数の評価を Core の一つの段にする。flow の定数のクロックの式（定数だけを引数にする、効果行が空の関数の呼び出しを含む。`rt` かどうかによらない）は `const` の初期化式と同じ評価器でコンパイル時に評価し、状態に置かず静的な領域に一つだけ置く。fn の本体の式は畳み込まない。評価の panic は E0419。型の位置の計算で決まる定数（K-05 の (a)）。
  設計メモに、項目の単位の依存の順と crate の依存の向きを含める。関数を経由する定数の閉路（S-173）をこの回に決めて検出する。`@param` の値の評価と制約。呼び出しの深さの上限 128 を超えた評価を E0419 にし、`onsa check` でも出す。
  全ての環境で 128 に届く評価器の形（自分のスタックを持つなど）を設計メモで決める（S-222）。`const` の初期化式の panic を E0200 でなく E0419 にし、`onsa check` でも出す（`const N: U32 = 0 - 1` が `check` を通る、R-155）。`const K: I32 = -(-2147483648)` は E0419（S-227）。
  止まらない初期化式でコマンドが終わらない（R-165）。着手の前に S-230（本体の中の必ず panic する定数だけの式）と S-237（評価の手数の上限）を決める
- 実現する決定: R-89 (2)、S-146、S-131、S-50 の計算で決まる定数、R-61、S-87 の評価、S-173、S-200 の評価、S-222、R-153、S-227 の E0419、S-230、S-237、R-155、R-165
