# W3-12 fmt の書き換えの一覧

- 内容: AST を変える書き換えを閉じた一覧にする。
  第 1 期で外すのは末尾の位置の値のある `return e` だけ（値の無い `return` は外さない、S-547。落とす範囲にコメントがあれば外さない、S-536 (1)・S-538 (s2)）。`-> ()`・空の `uses {}`・冗長な括弧の除去は第 2 期（S-540、S-546、S-339 ほか。2026-10-15 に範囲を縮めた）。
  既定値と等しい `init` と返り値の位置の `move` の除去は撤回（S-539、S-541）。S-56 の比較も同じ書き換えを施した AST で行い、数値リテラルは値で比べる。AST は doc を持たず、確かめは項目の順、doc の付く宣言、全てのコメントの並びも比べる（D-02 の改定）。`diff --ast` は同じ正規化を施した構造だけを比べる（S-534）。
  fmt は全てのファイルを処理し、書き込みは一時ファイルと rename（S-535）、比べて違えば最初に違った項目を示して 101。テストのコードの明示の 0 の `init` は省略の形に直す（S-539）
- 決定の範囲: S-68 の `return`、D-02 の改定
