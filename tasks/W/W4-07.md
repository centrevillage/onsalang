# W4-07 束縛の状態

- 内容: 状態を一つの列挙（所有・不変／所有・可変／借用／`inout`）にし、名前の段で一度だけ決める。§5.4 の表を写す一つの関数。借用の起点（借用引数、借用の `for`、派生した借用束縛、静的な値、元が起点の分解する `let`。`inout` 引数は起点にならず、`move` で取り出すと E0711）。
  捕捉した Shared 型の値は E0200（第 2 期）。`subst` を一本化し、種の分からない型は Affine。`const` への代入と、場所でないものの `inout` は E0415。
  タプルの左辺は E0415 と note（S-178、S-180）。`let` への代入の E0701 の「`let` を `var` に」を、位置付きの note でなく修正候補にする（R-161） `move` の引数（`move self` を含む）は所有・可変（R-191）。
