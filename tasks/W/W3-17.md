# W3-17 修正候補の約束の検査

- 内容: テストの器（W3-02 の `onsa_tests` の修正候補の期待値）に、全ての事例の全ての修正候補を一つずつ当てて検査し直す検査を足す。元の診断がその単位の同じ段以前の唯一の誤りなら、編集が触れた全ての単位に同じ段以前の診断が無いことを確かめる（後の段は許す）。複数の誤りを持つ事例は、当てた後に残る診断を期待値に書く形を足す。ファズには「同じ箇所」の近似。
  今の候補で約束を破るもの（`;;` の E0020、`let a = 1; let b = 2` の `;` の E0020、`- - x` の E0012、予約語になる E0320 など）は実装待ちの一覧に、直す作業（W3-15、W3-06、W3-07、W4-04）を until にして載せる。
  一つの構文の形（S-248）を一つの誤りと数え、`;;` と複数の `::` の経路を「唯一の誤り」の事例にする（別々の文の `;` は誤り二つ）。ブロックコメントの候補（S-247）は `same_code` の性質で確かめる
- 実現する決定: S-236、S-248、S-247 の候補
