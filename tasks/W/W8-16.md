# W8-16 降ろせない型を持つ単位を降下の入口で止める（新作業 B）

- 内容: 降ろせない型（この版の `Str`・Shared を含む型など）を、降下の項目の束縛の段で一つの E0200 にして項目を止め、仮の型 `()` を作らない。R-529（診断なしに `()` で Core に降り検証器が 101 で拒む形）、R-332・R-335（`Str` のフィールドを持つ struct の読みで「no field」の 101、14 件）を構造で閉じ、穴のやり直しの O(穴 × 大きさ) を消す。
  S-67 を狭める判断（2026-11-27、利用者「推奨案で良いです」、§18.1 に一文）: 単位の引数・返り値・ローカルの束縛・式の型がこの版で E0200 になれば、その単位は降下せず、降下の診断は降下できない型ごとに一つの E0200 だけ（総称の単位は具体化ごと）。降下しなかった flow のインスタンスを作る flow も診断を出さずに降下しない。
  止めた定数を読む単位は止めず、その式を報告なしの穴にして続ける。位置は束縛の宣言（引数とローカルの束縛は名前、返り値は返り値の型。sema の `FnDef` に `ret_span` を足す）に、型ごとに単位で一件。フィールド経由は宣言に書いた型を指す note。式だけに現れる型は単位の最初の一件。`panic("…")` の文字列は数えない。
  入れるもの: `FailKind::UnsupportedType`・`Stopped`、`FnCx::new` の束縛の段（集めて組ごとに一件）、`lower_item`、`const_id`・`ensure_flow` の `stopped`、`ret_span`、代わりの `()` と `stand_in_spans`・`around_stand_in` を消す、写しの E0200 を内部エラーに、`StrValues`・`StrPatterns` を一覧から外す、`Equality` が届くかの確かめ。
  設計は W8-01 の設計メモ部 3 の 3 章・6 章の行・9 章・10 章・13 章の B2・B3（`target/notes/191/w801/p3v2/memo.md`）。W8-14 の A3（`bad_types` と `core_ty` の一か所の失敗）の後、W8-02 の前に置く。W8-02 と並べない（どちらも `lower/body/pat.rs` を触る。部 3 の審査 L3）。
- 決定の範囲: S-67 の判断（B2・B3）、R-529、R-332、R-335
- 単位: 予定（親の判断）: 一単位（約 +100 −55）。受け入れに、S-224 の判断の (2)（穴のやり直しの時間。`quad` の形の n = 400 で 0.65 秒が消える）と、事例の位置と数の変わり（部 3 の 10.3: `a3` は 6 件が 2 件に、ターゲット付きの 10 件の印の行、R-335 の 14 件と R-529 の 7 件が `dump --core` で E0200）を一つずつ入れる。
