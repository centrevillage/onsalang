# W4-03 名前の段: 収集と `use`

- 内容: `sig.rs` を収集・`use`・署名の型・flow の生成項目の段に分ける。`use` は絶対経路で独立に解決する（各 `use` は他の `use` によらず決まる、§15.1。循環は E0310）。`use` を必須にする。可視性（`pub` / 無指定 / `priv`、フィールドは struct を継ぐ）とメソッドの可視性。公開の宣言に書ける型。
  演算子 trait・標準 trait・`Copy`・`Dup` を prelude へ（暫定の `Bound` も同じ名前で引く）。std の `effect` 宣言と prelude、効果の名前の解決。
  ルート直下のモジュールの名前か、モジュールを含むディレクトリの名前が依存のパッケージ名（`std` を含む）と重なれば E0304（`std.onsa` も `std/math.onsa` も。同じ場所の `a.onsa` と `a/` は重ならない。S-37、S-246）。別のモジュールから取り込んだ総称の型の型引数の数は、定義の型パラメータから数える（R-197）
- 実現する決定: R-84 (1)(2)(4)、S-78、R-50、S-37、R-39、S-36、R-106、S-35、R-38、S-144、S-107、C-15、S-74、R-129、S-246、R-197、S-312・S-313 のモジュール木（`sig/collect.rs`）、S-593・S-482 の記録、S-594 の取り込める一覧と循環の辺、S-491 のメンバの可視性、S-462、R-246、S-596（`pub use` の E0200）、R-250、S-611（名前の空間と E0304）、S-611 の prelude と同じ名前の `use` と項目（R-103）
