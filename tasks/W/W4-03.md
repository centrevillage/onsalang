# W4-03 名前の段: 収集と `use`

- 内容: `sig.rs` を収集・`use`・署名の型・flow の生成項目の段に分ける。`use` は絶対経路で独立に解決する（各 `use` は他の `use` によらず決まる、§15.1。循環は E0310）。`use` を必須にする。可視性（`pub` / 無指定 / `priv`、フィールドは struct を継ぐ）とメソッドの可視性。公開の宣言に書ける型。
  演算子 trait・標準 trait・`Copy`・`Dup` を prelude へ（暫定の `Bound` も同じ名前で引く）。std の `effect` 宣言と prelude、効果の名前の解決。
