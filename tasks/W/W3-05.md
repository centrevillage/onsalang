# W3-05 数値リテラルと文字列の区切り

- 内容: 指数があれば小数点は不要、既存言語の形の E0020、先頭の 0 の E0020、指数の `+`。浮動小数の字面から値への変換を一つの関数にし、`const` の F32 を二重に丸めない。型が決まった時点で有限でなければ E0408（K-10）。0 でない字面が 0 に丸まるときも E0408（非正規化数は通す、S-211）。
  整数の後の `.` は、名前か `(` が続けばメンバの `.`（S-350。W3-20 の三つの例外を外し、`syntax_no_candidate_forms.onsa` の 2 件を `fixes/` へ）。他の言語の文字列の区切りの字句の段の E0002 の行（`string_delimiter`、S-406）と、名前に接するリテラル（S-400）も中身を読まない形への改め。
  区切りと接するリテラルの中の書けない文字は E0001（S-454）、区切りに `@$"…"`（S-455）、`1.e-3` も `float_dot_exponent`（S-452）。直後に `(` が接する数の形の誤りにも数の候補を出し、呼び先の E0020 も報告する（S-457。`literal_call` の分かれを外す）。
  閉じた二つの文字列リテラルは、中に字句の誤りがあってもまとめる候補を出す（S-438）。`"{"a"}"` は `string_prefix`（S-465）
- 実現する決定: S-62、R-73、S-63、R-124、S-126、R-20、R-45、S-184、S-211 の 0 に丸まる字面、S-350、S-406、S-400 の改め、S-452、S-454、S-455、S-457、S-438、S-465、R-213、R-215
