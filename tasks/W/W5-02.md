# W5-02 組込みの表

- 内容: 組込み型のメソッド・関連関数・関連定数を std の `impl` に宣言し、プリミティブだけを `target` にする。`Prim` の表（シグネチャ、rt と効果、演算の分類）と lang item。sema は表の ID を Core へ渡し、降下は名前を読み直さない。
  各バックエンドは `Prim` を `_` 無しで網羅し、走らせる・生成する前に Core の全体を照らして E0200。std の `target` 宣言は `bind` で差し替えられない。宣言と `Prim` の 1 対 1 をテストで確かめる。M5 までの `std.test` の `check` / `gen` は表に未対応の印を付ける。
  暫定の `Bound`・`implies`・Rust の表は、1 行が 1 つの `impl` に対応する形で作る（R-127。std への移行は第 2 期）。組込みのメソッドの閉じた一覧。`abs` / `min` / `max` の std の本体、整数の `abs(MIN)`、`map_err` の宣言。
  gate の直書きの許可リストを減らす。`s.f(x)` でメソッドが無く関数型のフィールドがあれば E0020（S-191）。
  メソッドに書いた型引数（`v.m[I32](x)`）は E0020 で、候補は `v.m::[I32](x)`（S-239 で S-256 の除く候補を置き換えた）と note（式の中の型引数は `名前::[…]`。S-256 の型の段）。`p.norm`（メソッドを値として取る形）は E0413 で、note でメソッドは呼び出しだけと示す（S-205）。`s.f(x)` と `p.norm` の否定例。
  同じ型への変換メソッド（`F32` の `x.round_f32()`、`I32` の `n.narrow_i32()`）は E0413、型パラメータの `as` は `x as T` も E0411 で、文面を「型パラメータに `as` は無い」にし、`x: T` の `x as T` には `as T` を外す候補、`x: F32` の `x as T` には候補を出さない（S-210、R-158、R-159）。
  std の `abs` の doc コメントに「組込みの浮動小数は符号のビットを 0 にする」と書き、組込みの浮動小数の `abs` がプリミティブに行くことをテストで固定する（S-208）
- 実現する決定: R-79、S-69、R-126、S-98、S-108、S-130、S-143、R-127 の第 1 期の制約、S-191 の `s.f(x)`、S-256 の型の段（S-239 の候補）、S-205 の型の段、S-208、S-210 の E0413 と E0411、R-158、R-159
