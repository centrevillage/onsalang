# W7-04 flow の本体の検査

- 内容: 本体で使える式の閉じた一覧。flow だけの構文を外に書いたときの E0821。
  struct の入力は E0810。`@param` の入力の値型（E0809）と、数値と文字列のキーを `const` の初期化式と同じ道で型付けする（E0401）。`vdelay` の `MAX`（E0808）。`^名前` の範囲と E0801 の修正候補と見えている名前への `^` の E0020（名前の段で出す、S-267）。
  使われない束縛（flow の世界）。`par` の範囲（空は E0808）と状態の無い `par`、`par i in a..=b` は `N = b - a + 1` で空は `a > b`（W3-07 の `par` の `..=` の E0200 を外す、S-257）、入れ子のブロックの `let` は E0806（E0806 は代入の形を含めて名前の段で出す、S-267。登録簿の E0801 / E0806 の段を名前に改める）、`par` の look-back で落ちる入力。
  flow の外の `par` は E0821（R-139）
- 決定の範囲: S-87 の sema、R-100 の E0808、S-129 の flow、R-03 の `par`、S-257 の `par`、S-267 の名前の段の E0801・E0806・`^`
- 持ち越し:
  - **W7-04・W9-03（W3-10 の作業票にも入れた）:** 定数のクロックの式と `@param` の値をインタプリタで評価するときは、`Interp::enter`（評価の入口。深さを 0 にし、`Drop` で戻す）を通る入口を一つ足す（S-222、W2-04 の設計）。
  - **W3-18 の後（W3-18/b の報告、2026-10-09）:**
    - W7-04: `Node::Par` は `end` を持たない（`..=` の降下で `RangeHead` を Core まで運ぶ）。
  - **W7 の `@param` の作業:** `sig.rs` の `@param` の `num` が負のリテラルを `-` の直後のリテラルだけで判定し（`Ast::negated_literal` と別の定義、D-15）、`@param(min: -(60.0))` が E0809。§11.7 は `const` の初期化式と同じ規則なので、定数の評価に寄せる（W2-06/b の 9）。
