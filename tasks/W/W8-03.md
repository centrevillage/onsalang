# W8-03 正規化と評価順

- 内容: 正規形 R1〜R4。評価順（左から右、代入は右辺が先、添字は基の後、短絡、引数を全て評価してから呼ぶ、panic は順で最初のもの）。
  範囲の端は `a`、`b` の順に一度（S-188）。`for i in a..=b` は終わりを先に比べてから増やす降下にし、`b` が型の最大値でも溢れずに終わる（W3-18 の `for` の `..=` の E0200 `InclusiveRangeFor` を外し、`tests/spec/negative/range_inclusive_for_e0200.onsa` を意味の事例に置き換える、S-257）。
  始点が終点より大きい `..=` は最初の比較で 0 回（S-219。新しい比較は要らない。`tests/spec/control/` に `a > b` と `1..=n` の `n = 0` の事例を足す）
- 実現する決定: R-81 (1)、R-93、S-75、S-188、S-257 の `for` の降下、S-219 の `..=`
