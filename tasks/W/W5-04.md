# W5-04 孤児規則と E0307

- 内容: 固有の `impl Ty` は `Ty` を定義したモジュールにだけ、trait の `impl` は `Tr` か `Ty` を定義したモジュールにだけ書ける（見出しの誤りなので impl 全体が一つの単位）。組込み型は std で定義されたものとして扱う。E0307 の範囲。利用者の `impl Float`、手書きの `Ordinal` は E0307。手書きの `impl Hash` は E0200
- 決定の範囲: C-16、S-145 の E0307、S-138 の E0200
- 単位: X-23 の見積もり（2026-11-02、104 回目、`issues/X/X-23/estimate.md`。素の行数で、テストを除く）: 約 280 行、2 単位（組 B）。U1 孤児規則と trait の `impl` の見出し（S-70・R-104・S-139・S-145・S-138・S-748）→ U2 見出しで失敗した `impl` と届く範囲（R-180、M18。S-850 は決定済み）。
  - U1 済み（2026-11-05、115 回目）: S-70、S-138、S-139、S-145、S-748、S-895、S-896、R-104。見積もりは素の 83〜188 行で、実際は +174 −30。`compare.py speed` の `check` は 25.14 → 25.08 秒。`compare.py diags` の違いは 3027 件のうち 31 件で、全て孤児と見出しの形。
