# W5-04 孤児規則と E0307

- 内容: 固有の `impl Ty` は `Ty` を定義したモジュールにだけ、trait の `impl` は `Tr` か `Ty` を定義したモジュールにだけ書ける（見出しの誤りなので impl 全体が一つの単位）。組込み型は std で定義されたものとして扱う。E0307 の範囲。利用者の `impl Float`、手書きの `Ordinal` は E0307。手書きの `impl Hash` は E0200
- 決定の範囲: C-16、S-145 の E0307、S-138 の E0200
- 持ち越し:
  - **W4-05 U3a から（2026-10-29、80 回目）:** 孤児規則で利用者の `impl F32` が E0307 になると、`tests/spec/fixes/e0320_builtin_member_no_candidate.onsa` の E0320 は同じ単位に隠れる（§18.1、見出しの誤りの `impl` のメンバは検査しない）ので、その事例を見直す。
  - **第 72 組から（2026-10-28、80 回目、S-748）:** 見出しが E0307 の固有の `impl` のメンバも、対象の型の `.` の空間の名前に数える（孤児規則の形も含む、§18.1）。
    孤児規則を入れたら、利用者の `impl F32 { pub const PI: F32 = 3.0 }` が std の `F32.PI` と重なる形の帰結（E0304 が E0307 の単位に隠れ、S-675 の (d1) で使う所の `F32.PI` が黙る。値の位置なら単位の以後を検査しない）を事例で確かめる（今は孤児規則が無く、黙って通って `F32.PI` が引ける。第 72 組の独立のレビューの `a4`）。
  - **第 55 組から（2026-10-25、65 回目、S-669）:** std の trait を利用者の型に手で実装する形（`impl Num for Q15` など）を第 1 期に開くなら、同じ作業で std の `target fn` の `else` の本体を降下で呼ぶ経路を入れるか、届く形を E0200 にする（今は降下の内部エラー「math function type」、`lower/body/call.rs`）。
    プリミティブも本体も無い型での使用は、使った位置で E0200（§15.2）。
  - **X-8 から（2026-10-23、54 回目）:** std の trait を利用者の型に手で実装する `impl Trait for Type`（今は `Feature::TraitImpls` の E0200）を、どの作業で受け付けるかを作業票で確かめる（W5-06 の手書きの `impl` との重なりも）。利用者が宣言した trait は第 2 期（`tasks/phase2.md`）。54 回目の文書の点検の 2 の 8。
