# W8-09 Core の関数値

- 内容: 無名関数を本物の関数値として降下する（`std.test.check` の前提）。`from_fn` の展開をこの仕組みに寄せるかを決める。無名関数の中の `?` と `return`（W2-07 の E0200 を外す）。既定のモードの関数型の引数は関数と環境の組、保存する関数値は関数だけ（S-190）。`.(` の呼び出し（S-191）
- 決定の範囲: R-08 の補足、T5-4 の前提
- 持ち越し:
  - **W5-03 U1 の設計メモから（2026-11-05、114 回目）:** 注釈の無い無名関数の `?`（§9.1「`?` が返り値の型を…決める」）は、今は型の段の E0414（「it returns `_`」）で、関数値の降下だけでは `tests/spec/semantics/try_in_closure.onsa` は通らない（再現 `target/notes/114/w503memo/probe/h1.onsa`）。
    interp の `value::show` は enum を `#1(1)` の形で出し、§6.3 の形（`Some(1)`、`Shape.Circle(1.0)`）と違う。`std.test.check` の反例に enum が出るときに見る。
  - **W5-08 の設計メモから（2026-11-04、113 回目）:** `check` の反例はまだ走らないので、S-554 の `kind = "assert"` の事例は W5-08 で書けない。`check` を作るときは `panic_from(PanicOrigin::Assert, …)` を使い、事例を足す。
  - **W8-09:** 関数値の呼び出し `f.(x)` は、`Interp::call_with`（呼び出しを数える一か所）を通し、1 回の呼び出しとして数える（W2-04/t2 の `recursion_deep_fn_values.onsa` がこの読みで境界を書いた。S-229 で確かめる）。
