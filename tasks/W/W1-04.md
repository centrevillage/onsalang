# W1-04 内部エラーと短いファズ

- 内容: driver の `catch_unwind` で内部の panic を S-67 の内部エラー（終了コード 101）にする。降下とビルドの診断は全て報告し、位置・コード・文面が同じものだけを一つにする。降下の内部の失敗は E0200 ではなく内部エラー。降下は関数の中の最初の E0200 で止まらず、降下の診断は原因のソースの位置と文面で出し、生成した関数の名前を含めない。
  全体に関わる診断（E1011、E0820、ポリシー）は宣言の単位に入れない。終了コード 0 / 1 / 2 / 101 を全てのコマンドで揃える（S-56）。入力名の予約名の E0304 は W7-03。`check` と `fmt` に変異させた入力を与える短いファズ。見つかった落ちる入力は、該当する段の作業に渡し、それまで実装待ちの一覧に置く
- 実現する決定: R-77、S-67、S-56 の終了コード、Q-06
