# W5-20 型パラメータを含む型の種の制約（R-176）

- 内容: `body/bounds.rs` の `Bounds::meets` の「種が計算できなければ通す」を外し、型パラメータを含む型の種を `kind_in_body`（R-30）で本体の型パラメータの境界から求める。`Wrap[U]`（`U: ?Dup`）は Dup でないので E0416。タプル・配列・`Result` の中の形（R-176 の補い）も同じ。`Option[U]` も同じ道（W5-03 の後）。
  `None` のまま黙る形（誤りの型、未知の境界、第二級の型）は今の読みのままで、第二級は W5-17。自分を持つ型の扱いは票で確かめる。`[w; 2]` は E0416 が modes より先に出て、`move` の候補は付かない（R-176 の補い）。書いた型の `Buf[Owner]`（R-172）は `85400d9b` で直っているので、事例を足して閉じる。
- 決定の範囲: R-176、R-172
- 単位: 1 単位。素の見積もりは 15〜40 行（親の読み。読む所は `meets` と `deferred.rs`・`receivers.rs`・`wellformed.rs` の呼び手）。std の宣言と本体がこの穴に頼っていれば、その分の直しが足される。反転する正例を先に走査する。
- 時期: W5-04 の後、W5-05 の前（2026-11-05、115 回目、利用者「手戻りがないタイミングで対応しましょう」）。W5-16 から分けた。前に置く理由は、W5-04 の U2 が同じファイルの `traits_unknown` を触ること。後に置かない理由は、W5-05・W5-06・W5-07 が足す std の総称のコードがこの穴に頼ると、その直しが手戻りになること。`meets` が読む `kind_in_body` は W5-05 の表の組み替えに頼らない（型パラメータは `satisfies` で読む）。W5-05 が `bounds.rs` を作り直すときは、この単位の事例が直しを守る。
