# W8-04 移動・コピー・破棄

- 内容: Core に移動・コピー・破棄を入れ、破棄の種類を一度だけ決める。参照カウントは E0200
- 決定の範囲: R-81 (2)、S-85 の降下
- 持ち越し:
  - **W7-12 U2c1c の壊す側から（2026-11-17、162 回目、低）:** 別の腕の文で Dup の値を解放し、同じ引数で開いたリテラルの要素がその値の経路を借用する形は、U2c1c（R-486）から複製でなく移す（E0601 は変わらず、「another argument of the call borrows」の note が消える）。この note を持つ事例が無いので、Core が移すか複製かの記録を読むときに、その形（`target/notes/162/w712/u2c1c/` の `rel1`）と同じ腕の対照（「used after」で複製）を事例にする。
  - **W7-12 U2c2 から（2026-11-17、162 回目）:** 腕の中の一時（`Buf` を含む）を `FnDef::hoisted` で関数の高さに置く形（R-481）では、呼び出しを待つ一時（R-483）の破棄が腕の外で、どの腕を通ったかによる条件付きになる。破棄を入れるときに、その記憶域と破棄の位置を `hoisted` の記録と合わせて決める。
  - **W5-13 から（2026-11-13、143 回目、W5-13 の持ち越しから。W5 の終わりに利用者が送り先を了承）:** W4-18 から（W4-08）: 「平面の引数に置いた配列リテラル」の判定が型の段・modes・Core（`onsa_core/src/lower/body/call.rs`）の三か所にある。sema の側は W6-04 U4（`0b203231`）で一か所になった（型の段の `body/calls.rs` が `BodyInfo::planar` に記録し、modes はそれを読む）。Core の側が残る。
  - **W4-18 から（2026-11-02、103 回目、W4-18 の持ち越しから。W4 の終わりに利用者が送り先を了承）:** W4-09 U3 の壊す側（91 回目）: 消費する位置の一覧が `Pos::consumes()`（`modes/walk.rs`）、`marks.rs::unplaced`、`consume.rs::consume` の `(Pos::Own | Pos::Value, None)` と `how`、`out_of_place` の分岐にある。
    取り出しや `Drop` の規則を変えるときに、一つの表から引く形にする（`marks.rs::wants_move` が `consume` の表を写す件は W4-18 U5a の `Movable` で済んだ）。
    R-485（2026-11-17、162 回目に W7-12 から移した。利用者: 共通の構造で判定できる形に）: 返り値の位置に置いた、場所でない基の経路（`return ({ let h = mkh(1) … h }).n`）は `move` 無しで通り、同じ形の `let` の見出しは E0711。表の一行として、仕様の文と一緒に決める。
  - **W4-09 U2 の壊す側から（2026-10-31、91 回目）:** 取り出しの E0200（`Feature::TakenFields`）は `onsa_core/src/lower/body/mod.rs::lower_fn_body` の頭だけにある。`const` の初期化は `ConstBindings` の E0200 に、flow の本体は modes を通らないこと（`move` の E0806、Affine の信号の E0810）に頼って止まる。
    E0200 を外すとき、`ConstBindings` を外す作業が先に来るときは、取り出しの止め方を共通の入口に寄せる。実装待ちの `semantics/take_out_run.onsa`（`until = "W8-04"`）を外す。
  - **X-8 から（2026-10-23、54 回目）:** S-85: 取り出しで全体を消費する形の降下（取り出さなかった残りの破棄）。W4-09 から W8-04 までは、modes が受け付け、Core で E0200。
