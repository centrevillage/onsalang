# W8-04 移動・コピー・破棄

- 内容: Core に移動・コピー・破棄を入れ、破棄の種類を一度だけ決める。参照カウントは E0200
- 決定の範囲: R-81 (2)、S-85 の降下
- 持ち越し:
  - **W4-18 から（2026-11-02、103 回目、W4-18 の持ち越しから。W4 の終わりに利用者が送り先を了承）:** W4-09 U3 の壊す側（91 回目）: 消費する位置の一覧が `Pos::consumes()`（`modes/walk.rs`）、`marks.rs::unplaced`、`consume.rs::consume` の `(Pos::Own | Pos::Value, None)` と `how`、`out_of_place` の分岐にある。
    取り出しや `Drop` の規則を変えるときに、一つの表から引く形にする（`marks.rs::wants_move` が `consume` の表を写す件は W4-18 U5a の `Movable` で済んだ）。
  - **W4-09 U2 の壊す側から（2026-10-31、91 回目）:** 取り出しの E0200（`Feature::TakenFields`）は `onsa_core/src/lower/body/mod.rs::lower_fn_body` の頭だけにある。`const` の初期化は `ConstBindings` の E0200 に、flow の本体は modes を通らないこと（`move` の E0806、Affine の信号の E0810）に頼って止まる。
    E0200 を外すとき、`ConstBindings` を外す作業が先に来るときは、取り出しの止め方を共通の入口に寄せる。実装待ちの `semantics/take_out_run.onsa`（`until = "W8-04"`）を外す。
  - **X-8 から（2026-10-23、54 回目）:** S-85: 取り出しで全体を消費する形の降下（取り出さなかった残りの破棄）。W4-09 から W8-04 までは、modes が受け付け、Core で E0200。
