# W6-03 効果の使用の記録

- 内容: 型付けと modes の後の一つの段で、本体ごとの使用の記録を作る。効果行は効果の宣言の ID の集合。std が宣言する全ての効果の使用を検査し、効果行に無い効果の使用は `rt` かどうかによらず E0601（暗黙の確保と破棄を含む、E0611 をまとめる）。E0601 は最初の使用の位置で、修正候補は `rt` でない関数では署名への挿入、`rt` の関数では出さない。
  第 1 期の `Random` は修正候補を出さず note で示す。E0901 は `rt` でない関数と関数値の呼び出しだけ。テスト用の補助は効果行で呼べる場所が決まる。`Gen` のフィールドを `priv` にし、`std/test.onsa` の doc を改める。`main` の効果行も export と同じく `provides` と照合する（E0610、R-134）
- 実現する決定: R-83、S-77、R-87 (6)、S-82 の E0601、R-125、S-97、S-23、R-134、S-613 の E0601 の note、R-256
