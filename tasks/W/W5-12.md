# W5-12 固定長の文字列 `FixedStr`（`std.text`）

- 内容: S-614 の固定長の文字列を入れる。std の `std.text` に Copy の型 `FixedStr[const N: U32]`（`priv bytes: [U8; N]`・`priv len: U32`）を宣言し、lang item で知らせる（W5-02・W5-03 の仕組み）。
  コンパイラが知るのは三か所: 期待の型が `FixedStr[N]` の文字列リテラル（§2.4・§4.7。代入の右辺と比較の被演算子を含み、総称の `N` が決まっていなければリテラルの長さ。容量を超えるか ASCII の外は E0408、補間は E0401）、`Span[U8]` の引数に渡すと使った長さの部分を見ること（§5.3）、`match` の文字列リテラルのパターン（§7、使った長さとバイトの等値）。
  メソッドは Onsa の std に書く: 長さ、文字列の書き足し、整数の 10 進（総称の `put_int[T: Int]`）、桁を決めた浮動小数（`F64` に広げ `10^d` を掛けて最近接偶数で丸める式）、`write_to(self, inout out: Span[U8]) -> U32`。
  NaN・無限大・`10^d` 倍が整数に収まらない値・`d` の上限の書き方は S-1007（NaN・`inf`・`-inf`、収まらない値と `d > 22` は `*`、`d = 0` は小数点なし。「いったん」。S-614 の A3）。容量を超えた書き足しは黙って切り詰める（std の文書に注意を書く）。
  等値・順序・`Hash`・`Default` は derive（不変条件: `len <= N`、後ろは 0、ASCII）。
  書き足しは総称の三つ `put_str`・`put_int[T: Int]`・`put_float[T: Float](v, d)` で、型の名前は `FixedStr` のまま（S-614 の補い、139 回目）。`Log` の操作、`extern`、`Str` との変換、`Show` は第 2 期（`tasks/phase2.md`）。見積もりは Rust 約 80〜120 行（パターンを足すので設計メモで見直す）、Onsa 約 130〜170 行、事例約 25 件。
