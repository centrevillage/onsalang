# W4-20 `par` を `par~` に改名（S-745）

- 内容: flow の構造の複製を `par~ i in a ..< b { e }` と書く（S-745、`if~`・`match~` と同じ `~` の印）。`~` は `par` の直後に空白なしで書き、`par ~` は E0020 で空白を除く候補。
  flow の本体の `~` の無い `par` は E0811 で `~` を足す候補、flow の外は `~` の有無によらず E0821。`par` は予約語のまま。状態を持つものを含まない `par~` も誤りにしない（E0812 を当てない）。状態のノードの名前は `par_0` のまま。
  §19.1 の予定の形を `ser~` にする（`ser`・`ser~` とも E0200）。仕様の文（約 44 か所）は、この作業で実装と同じに改める。事例（`.onsa` 約 137 ファイル・337 行）と golden は台本で置き換える。
  字句のキーワードの表、構文、診断の文と候補、fmt。決定・作業の文のうち今の形を書いた所も改める（`history/` は変えない）
