# W4-08 場所の重なりの関数

- 内容: `slice` と平面の要素を元の場所の射影として扱い、排他性を検査する。`inout xs.slice(a, b)` と `inout [a, b]`。この関数を R-24（W4-09）、S-42（W4-10）、R-81 (3)（W8-05）が使う（C-118）。排他性の窓は引数の評価の始まりから呼び出しの終わりまでで、借用と `inout` の重なりも含む（S-193）。`xs[k]` の受け手と添字の左辺（S-181）、`[a, b]` の要素の種類と長さ（S-196）
- 実現する決定: R-31、S-193、S-181、S-196
- 持ち越し:
  - **W4-08:** 他の引数の中の `inout`（`f(inout x, g(inout x))`）が平らな変数でも E0702 にならない（S-193）。テストの票は平らな変数の形も足す。S-217（平面の要素の `let`）を着手の前に決める。
  - **X-8 から（2026-10-23、54 回目）:** `modes.rs` の作り直し（W4-07）の後のコードを直す。W4-08 は modes の検査だけにする。Core の検証器は `inout` の引数の slice を拒む（`onsa_core/src/verify.rs` の `is_place_expr`）ので、modes が通した `inout xs.slice(a, b)` などは Core で E0200 にし、実行は W8 で入れる（`rules/process.md` 8.6 の「後の段で作り直す部分」）。
