# W4-08 場所の重なりの関数

- 内容: `slice` と平面の要素を元の場所の射影として扱い、排他性を検査する。`inout xs.slice(a, b)` と `inout [a, b]`。この関数を R-24（W4-09）、S-42（W4-10）、R-81 (3)（W8-05）が使う（C-118）。排他性の窓は引数の評価の始まりから呼び出しの終わりまでで、借用と `inout` の重なりも含む（S-193）。`xs[k]` の受け手と添字の左辺（S-181）、`[a, b]` の要素の種類と長さ（S-196）
- 決定の範囲: S-217 の重なり
- 持ち越し:
