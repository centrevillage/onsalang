# W7-10 修飾子 `when~`・`reset_if~`

- 内容: インスタンスの呼び出しに付ける修飾子 `.when~(c)`・`.reset_if~(r)`。修飾子の名前の引き方（`.名前~(` の頭がインスタンスの式のときだけ閉じた一覧を引く。`~` の無い `.when(` は E0811、一覧に無い名前と値の受け手は E0812）と、受け手の規則（`let` で受けた名前・`par`・`if~` / `match~` は E0812）。
  `when~` の条件のクロック（E0815）と止まっている間の出力の保持（`T.default()`、E0816）、`reset_if~` の初期化の部分木（生成する `reset` と同じ。poisoned と位相のカウンタには触れない）、順と重ねがけの合成。§11.2 の本体で使える式の一覧に修飾子の連鎖を足す（W7-04 の一覧）。
  計画の表のインスタンスのノードに修飾子の並びと保持の欄を置き、Core に降ろしてインタプリタと C で動かす。W7-01 の参照評価器にも足す。イベントの条件は W7-11
