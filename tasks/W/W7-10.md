# W7-10 修飾子 `when~`・`reset_if~`

- 内容: インスタンスの呼び出しに付ける修飾子 `.when~(c)`・`.reset_if~(r)` の検査と意味（名前の引き方と受け手の規則は W7-09、X-26 の X26-5）。`when~` の条件のクロック（E0815）と止まっている間の出力の保持（`T.default()`、E0816）、`reset_if~` の初期化の部分木（生成する `reset` と同じ。poisoned と位相のカウンタには触れない）、順と重ねがけの合成。§11.2 の本体で使える式の一覧に修飾子の連鎖を足す（W7-04 の一覧）。
  計画の表のインスタンスのノードに修飾子の並びと保持の欄を置き、Core に降ろしてインタプリタと C で動かす（新しい IR を足さない）。W7-01 の参照評価器にも足す。イベントの条件は W7-11
- 単位: X-26 の見積もり（2026-11-16、157 回目、`issues/X/X-26/estimate.md`。素の行数で、テストを除く、倍率なし）: 300〜510 と参照評価器 60〜120、2 単位（U2 修飾子の検査と計画の表 → U3 降下と実行）（組 D の U2・U3。U1 の名前の段は W7-09 へ移した）
- 持ち越し:
  - **W7-16 U5b2 の設計の審査から（2026-11-22、176 回目、構造の中）:** `when~` で止まる子は、遅い段も含めて全ての段を、連鎖の段の読む所で子の `_tick` で駆動する（`.up~` のループの中身と同じ形）。呼び出し側の `stages` に子の遅い段を写さない（写すと止まっている子の遅い段が呼び出し側の格子で黙って走る）。計画の `node_runs` は `n.frame` だけを見るので、`.when~`・`.reset_if~` だけの連鎖のノードは修飾子なしと同じ `runs` になる。W7-16 U5b2 は `run_child`（`crates/onsa_core/src/lower/flow/phases.rs`）で連鎖のあるノードを内部エラーにした。孫（修飾子なし）は、子の段の関数が子の `_tick` で駆動されれば判定なしのまま合成する。`reset_if~` は r = 0 の子では崩れない（格子が呼び出し側のもの）。
  - **S-1207 から（2026-11-22、175 回目、利用者が塊の読みに決めた）:** 各修飾子は左の全体を一つの部品として包み、`.down~(N)` は `.up~` を含む中の部品の入出力を境界で集めて配る。`when~`・`reset_if~` を連鎖に交ぜた形（`x.up~(2).when~(c).down~(2)` など、今は E0200）も同じ合成で読む。§11.10 の字と塊の読みの突き合わせは、読みが割れるので S-1209 に登録した（W7-10 の設計メモの前に利用者が決める）。
  - **W7-16 の設計メモの審査から（2026-11-22、175 回目、構造の中）:** W7-16 は位相のカウンタをインスタンスごとの欄 `_tick` に持ちうる（§11.9「実装の選択」）。集める輪の添字は自分の `_tick`、段の呼び出しは駆動する側のカウンタで、二つは「同じ時に 0 から始まる」不変条件で揃う。`reset_if~` が子の `_tick` を戻すと黙ってずれるので、カウンタに触れない初期化（§11.10）は `reset` と別の関数の族が要る（`reset_nodes` に旗を渡して二つにする形で +20〜40 の見当）。`sample_tick()` は根の数から作る（S-1129 の決定 (1)、W7-16 U5b が時間を根から渡す形を作る）ので、`when~` の中の `sample_tick()` は渡された時間を通すだけ。
  - **W7-09 U2s から（2026-11-21、172 回目、S-1196、W7-09 を閉じるときに送った）:** `reset_if~` の条件の刻みは、条件の式のクロック（`at` で付けたクロックを含む）で決まる（§11.10。`.reset_if~(c at (sample / 4))` は `sample / 4` の刻み）。実装はこの作業で確かめる。
  - **W7-09 U3b から（2026-11-21、173 回目）:** 修飾子の連鎖は頭ごとの `FlowCx::chains`（`crates/onsa_sema/src/flow.rs` の `ModifierChain { ratio, mods, gate }`）に置く。`.when~`・`.reset_if~` の仮の門は `ModifierChain::gate`（連鎖に N の誤りがあれば出さない）で、歩きの `Walk::modifier`（`flow/clocks.rs`）は修飾子の引数を規則なしで切っている。枠は `when~`・`reset_if~` を比 0 として数える（§11.9「`when~`・`reset_if~` はレートを変えない」）。計画の `PlanModifier` の `ratio` は `when~`・`reset_if~` で `None`、graph のラベルは計画の連鎖を読むので `.when~(…)` の字もここで出る。
