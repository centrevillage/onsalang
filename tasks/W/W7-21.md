# W7-21 上りを下りが包む連鎖の塊の読み（S-1207）の検査と参照評価器

- 内容: S-1207 の塊の読みを、W7-09 が作った検査と参照評価器に入れる。修飾子の連鎖を比の和一つでなく境界の列として読み、`.down~(N)` が `.up~` を含む部品を包む所ごとに、中の部品の入出力を集めて配る（遅れは境界ごとに足される。M ≠ N も同じ規則）。
  検査: 上りを下りが包む連鎖で、集める型と配る型に `Default` が要る（E0816、§11.9）。境界から見た中の部品の入出力のクロック。計画（`PlanNode::frame`・`chain`）が境界の列を W7-16 の降下に渡す形。
  参照評価器（`crates/onsa_tests/src/flow_ref/`）: `rate.rs` の `chain_of`（`Chain { head, ratio }`）を境界の列にし、`gathers`・`deals`・`take`・`dealt` を境界ごとに当てる。U2c の表（`port_table_tests.rs`）と模型に連鎖の形の行を足す。
  事例: `tests/spec/flow_clock/e0816_conversion_flow_gather_deal.onsa` の比が 1 の連鎖（`up_down_chain_of_the_ratio_one`、注の「a chain of the ratio one」）、`crates/onsa_tests/src/flow_ref/multirate_tests.rs` の注（「of ratio 0 (the same as a call with none)」）を書き直し、入力のある部品の遅れ（`x.up~(4).down~(4)` は 4、`x.up~(4).down~(2).down~(2)` は 6）と E0816 の事例を足す。
