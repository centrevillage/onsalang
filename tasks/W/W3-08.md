# W3-08 宣言の見出しと属性

- 内容: 宣言の `: trait`（`@derive` は E0020）と、`@derive`・`#[derive]` の候補（名前はそのまま写し、種の制約 `Copy`・`Dup` だけ外す、S-463）。
  可視性の `priv` と、`pub(pkg)` の扱い。`pub struct` のフィールドの `pub(crate)`・`pub(pkg)` は候補の無い E0002 の行（S-420）。タプル形の struct は E0020。項目の文脈ごとに書ける項目。
  属性の位置と引数の表、未知の属性。`@mem(bulk)`、`@fp(relaxed)` の構文。`<…>` を `[…]` にする候補（W3-15 の `angle_brackets`）は、中身が型パラメータ・型引数の並びとして読めるときだけ作る（R-193。`tests/fuzz/b330941f.onsa` の `fuzz-input` の項目を外す）。
  単位 2: 名前より前の同じ行で閉じる可視性と属性の形と、見出しの前の表に無い語の後は、読み続けて名前解決に見せる（S-435、S-459。誤りの属性の付いた struct・enum は derive の一覧と `@repr` を未知に、S-460）。宣言のキーワードの並びの誤りは一般の規則で読み続け、`const_fn`・`extern_fn`・`export_c` の行を登録する。
  修飾の重なりと順は一つの E0002 と並べ直す候補（S-464）。FAUST の形と handler の本体は W3-23、doc の付く先は W3-24 に分けた（2026-10-13）
