# W7-06 分岐

- 内容: `if` / `match` と短絡の演算子は取る枝だけを評価し、枝に状態を持つものを書けない。枝とガードに書くと E0811、短絡の右辺は E0806。`if~` / `match~` は全ての枝を評価して状態を進め（`~` は連鎖の全体に掛かる）、状態を持つものが無ければ E0812。`match~` の取られない腕の束縛は `T.default()`、無ければ E0816
- 実現する決定: S-110、R-14
