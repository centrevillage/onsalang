# W2-09 GCC と浮動小数のフラグ

- 内容: `runtime/c/onsa.h` を、公開の `onsa.h` と内部の `onsa__runtime.h` に分ける（S-53 の分割の部分を前倒し。`#error` を内部に置くため）。
  内部に `#error` の検査（GCC で `__STRICT_ANSI__` も `ONSA_FP_CONTRACT_OFF` も無い、`__FAST_MATH__`、`__FINITE_MATH_ONLY__`、`_M_FP_FAST`、`FLT_EVAL_METHOD`）。`ONSA_ALLOW_INEXACT_FP` で全て外す。
  STDC のプラグマは GCC に出さない。`-Wtype-limits` に当たる検査を生成しない。緩和の属性（今の `@relaxed`、W3-08 で `@fp(relaxed)`）の関数は Clang のプラグマと GCC の関数属性で緩める。生成した `.c` の先頭に必要なフラグを書く。
  W1-06 の GCC の FMA と `-Wtype-limits` を実装待ちから外す。`if` の条件の比較に余分な括弧を付けない（R-142、clang の `-Wparentheses-equality`）。`@fp(relaxed)` は GCC では縮約だけを緩め、GCC の再結合を使わない（関数ごとの再結合は符号付きの 0 を無視する簡約も入れる、S-207）。
  poison の export の wrapper の `-Wclobbered` を wrapper の形で無くす（R-167）。緩和は `@fp(relaxed)` の関数と flow の呼び出しの中の全ての演算に許可として及ぶ（S-287。属性とプラグマの出し方は S-54 のまま。呼ばれた strict の関数が緩んでもよい）。
  ソースの縮退した形（整数と `Bool` の自己比較、符号なしの `x >= 0` と `x >= T.MIN`）を Core で畳み、自己代入を出さず、使われなくなる値と `var` には `(void)x` を残す。浮動小数の自己比較は畳まない。
  費用の高い形は無理に畳まず、形と費用の見積もりを報告し、事例は実装待ちの一覧に置く（S-288。`c_self_compare` の理由を S-288 に付け替える）。ALLOW のビルドの事例は `-Werror` なしでコンパイルできることを見る（`c_fp_flags.rs` の GCC の行も。S-289）。
  ALLOW のビルドで出る警告のうち、明らかに無くした方が良く費用の小さいものは報告する（S-289）
- 実現する決定: R-67、S-54、S-53 の分割、R-142、R-145、S-207 の GCC の緩和、R-167、S-287、S-288、S-289
