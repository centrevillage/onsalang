# S-759 `impl` の見出しの対象の型引数の数の誤り（`impl P[I32]`・`impl[T] P[T]`・`impl W`・`impl W[I32, I32]`）と、引数の中の数の誤り（`impl[T] W[T[I32]]`）を、並びの規則の E0307 と数の E0412 のどちらで報告するか

- 空白: §6.2 は `impl` の対象の型引数を `impl` の型パラメータを一度ずつ並べたものに限り、それ以外を E0307（名前の段）とする。§4.5 は型引数の数が宣言と合わなければ E0412（型の段、S-103）とする。§18.1 は依存する段の間では位置によらず先の段の誤りを報告する。
  対象そのものの型引数の数が合わない見出し（`impl P[I32]` の `P` は型引数を取らない、`impl[T] P[T]`、総称の `W` に引数の無い `impl W`、`impl W[I32, I32]`）と、引数の中に数の誤りがある見出し（`impl[T] W[T[I32]]`）で、E0307 と E0412 のどちらを報告するかは書いていない。
  今（`0eb4575`）: 五つとも E0302（`P` takes 0 type argument(s), 1 given、a type parameter takes no arguments）。W4-05 U4c で型の位置の数の誤りが E0412（型の段）になる。
  読み: (1) 書いた引数が並びの規則（`impl` のパラメータを一度ずつ）を破れば名前の段の E0307 で、E0412 より先に残る（`impl P[I32]`、`impl W[I32, I32]`、`impl[T] W[T[I32]]`）。並びの規則を満たし数だけが合わなければ E0412（`impl[T] P[T]`、`impl W`）。
  W4-05 U3b の「引数の型の段の誤り（計算した長さの E0200、E0417）では判定する」と同じ線。(2) 対象の数が合わなければ対象を誤りの型にし、E0412 だけを報告する（並びの規則を判定しない）。
  どちらも誤りのあるプログラムの報告だけが変わり、通るプログラムは変わらない。どちらも見出しの誤りなので `impl` の全体が一つの単位。再現は `target/notes/81/s759/gaps.onsa` の 9・13・17・21・25 行。
- 決定: 決定（2026-10-29、利用者。81 回目。第 73 組の独立のレビューの段 2 の答えと親の案が一致）: (2')。
  `impl` の見出しの並びの規則（§6.2、E0307）は書いた引数で判定し、対象自身の型引数の数が分かっていて宣言と合わないときは判定しない（数の E0412 だけ、§4.5）。数の比べは書いた引数の数と宣言の型パラメータの数で行う（組込みの総称は `arity()`）。
  `impl P[I32]`（`P` は型引数を取らない）・`impl W[I32, I32]`・`impl P[Nope]`・`impl[T] W[T, Nope]`・`impl[T] P[T]`・`impl W` は E0412。
  数の合う `impl[T] W[T[I32]]`・`impl[T] W[P[I32]]` と、値の循環の型を対象にした `impl[T] S`・`impl S[I32]`（数が合う形）は E0307。失敗した名前の頭（`impl[T] Gone[T]`）は判定しない。どちらも見出しの誤り。
  理由: 数の誤りまで並びの規則で判定すると、`impl P[I32]` の E0307 が直し方（引数を除く）から遠く二回の修復になり、数を超えて読まない引数（S-762）の見つからない名前を「パラメータでない」と判定して S-753 と食い違う。「対象が誤りの型なら判定しない」(2) は、数の誤り以外の誤りの型（値の循環）まで黙らせ、型を直しても残る E0307 を次の検査に回す。
  誤りのあるプログラムの報告だけが変わり、通るプログラムは変わらない。仕様は §6.2 の対象の型引数の文に一句。実装は W4-05 U4c（`a0f7d12`、`sig.rs::impl_heading` と `sig/types.rs::declared_params`）。事例は `tests/spec/types/impl_target_args_count.onsa`。
- 経緯: 81 回目（2026-10-29）、W4-05 U4c のテストの票（onsa-test）が仕様の空白の候補（NEW の二件）として挙げ、親が `P80/bin/onsa-w405u3b2` で今の出力を確かめた。親の読みは (1)（§6.2 の並びの規則と §18.1 の段の順）。利用者が外出中なので、(1) を暫定にして U4c の実装に渡し、第 73 組の助言のレビューに加える。期限は W4-05 U4c。関係: S-103、S-137、S-753、R-258。
- 補い（2026-10-29、親）: 81 回目（第 73 組の助言のレビュー）: 助言の担当は段 1 で (2)、段 2 で (2') を選んだ。(2') は、書いた引数で並びの規則を判定し、対象自身の型引数の数が分かっていて宣言と合わないときだけ並びの規則を判定しない（数の E0412 だけ）形。
  (2) の「対象が誤りの型なら判定しない」は、数の誤り以外の誤りの型（値の循環、構文で切れた見出し）まで黙らせる。親も (2') に賛成し、U4c の暫定を (1) から (2') に改めた（利用者の外出中。帰宅後に最終に決める）。
  (1) では、S-762 (1) で読まない引数の見つからない名前（`impl P[Nope]`）に E0307 が出て S-753 と食い違う（U4c の壊す側の指摘 1）。
