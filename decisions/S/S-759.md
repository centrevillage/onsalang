# S-759 `impl` の見出しの対象の型引数の数の誤り（`impl P[I32]`・`impl[T] P[T]`・`impl W`・`impl W[I32, I32]`）と、引数の中の数の誤り（`impl[T] W[T[I32]]`）を、並びの規則の E0307 と数の E0412 のどちらで報告するか

- 空白: §6.2 は `impl` の対象の型引数を `impl` の型パラメータを一度ずつ並べたものに限り、それ以外を E0307（名前の段）とする。§4.5 は型引数の数が宣言と合わなければ E0412（型の段、S-103）とする。§18.1 は依存する段の間では位置によらず先の段の誤りを報告する。
  対象そのものの型引数の数が合わない見出し（`impl P[I32]` の `P` は型引数を取らない、`impl[T] P[T]`、総称の `W` に引数の無い `impl W`、`impl W[I32, I32]`）と、引数の中に数の誤りがある見出し（`impl[T] W[T[I32]]`）で、E0307 と E0412 のどちらを報告するかは書いていない。
  今（`0eb4575`）: 五つとも E0302（`P` takes 0 type argument(s), 1 given、a type parameter takes no arguments）。W4-05 U4c で型の位置の数の誤りが E0412（型の段）になる。
  読み: (1) 書いた引数が並びの規則（`impl` のパラメータを一度ずつ）を破れば名前の段の E0307 で、E0412 より先に残る（`impl P[I32]`、`impl W[I32, I32]`、`impl[T] W[T[I32]]`）。並びの規則を満たし数だけが合わなければ E0412（`impl[T] P[T]`、`impl W`）。
  W4-05 U3b の「引数の型の段の誤り（計算した長さの E0200、E0417）では判定する」と同じ線。(2) 対象の数が合わなければ対象を誤りの型にし、E0412 だけを報告する（並びの規則を判定しない）。
  どちらも誤りのあるプログラムの報告だけが変わり、通るプログラムは変わらない。どちらも見出しの誤りなので `impl` の全体が一つの単位。再現は `target/notes/81/s759/gaps.onsa` の 9・13・17・21・25 行。
