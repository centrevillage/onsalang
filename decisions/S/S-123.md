# S-123

- 空白: 名前と `~` / `!` の間、`^` と名前の間の空白にコードが無く、`saw ~(f0)` の修正候補が行き止まり（点検 C-11）
- 提案: 名前に付く印と前置の記号（`-`、`!`、`^`）の後の空白は E0020（空白を除く候補。行頭の `- b` / `^ b` には前の行とつなぐ候補も）。仕様 §18.1 の `~x` の行は、直前が名前でない前置の `~` に限る（2026-10-06 決定。実装は構文の段）
- 時期: M1
