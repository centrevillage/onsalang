# S-1214 塊の読み（S-1207）の及ぶ範囲: 速いポートの部品に下りを重ねる形・下りの後の上り、集める入力に定数とパラメータを渡す形、S-566 の A10 の例文

- 空白: S-1207 は「上りを下りが包む連鎖」を名指して塊の読み（各修飾子は左の全体を一つの部品として包み、`.down~(N)` の境界で中の部品の入出力を集めて配る）に決めた。その規則（§11.10 の合成と §11.9 の一段の集めて配る形）を当てると、名指していない次の形も、今の実装（連鎖の比の和一つ）と値か診断が変わる。字の上では規則から一つに決まる見込みだが、下書きの例文（S-566 の A10）と字面が食い違う所と、利用者の確認を経ていない親の判断がある。
  (1) 速いポートを持つ部品に下りを二つ以上: `g4~(x).down~(2).down~(2)`（`g4(x: F32 at (sample * 4))`）は、境界ごとに集めて 6 サンプル遅れる（`.down~(4)` 一つなら 4）。S-1207 の例 `x.up~(4).down~(2).down~(2)` = 6 と同じ形（`x.up~(4)` は `sample * 4` のポートを持つ一つの部品）。値が変わるのは一つの入力を二つ以上の境界が集める形だけで、通るプログラムは変わらない。
  (2) 速いポートを持つ部品の下りの後の上り: `use4~(c).down~(4).up~(4)`（`use4(c: Char at (sample * 4))`）は、`.down~(4)` の境界が `Char` を集めるので E0816（今は比の和が 0 で通る）。単独の `use4~(c).down~(4)` は今も E0816。A10 の「`x.down~(2).up~(2)`（x と同じ）」を全ての x の値の規則と読むと今のまま通るが、その句は §11.9 に無く（§11.9 は比だけを挙げる）、値の規則と読むと `.down~(N)` の意味が後ろの `.up~(N)` で変わる。
  (3) 集める入力に定数とパラメータを渡す形（W7-09 U2b の親の判断 (d)「位置ごとに読んだ値を集める」、利用者の確認を経ていない）: `cnt~(1.0).up~(2).down~(2)`（`cnt(k: F32 at sample)`）は 0, 0, 1, 2, 3, 4（今の評価器のテスト `ud` は 1, 2, 3）、`id~('a').up~(2).down~(2)` はリテラルの引数に E0816（一段の `g2~('a').down~(2)` は今も E0816）。A10 の「音声の入力の無い `osc~(f).up~(2).down~(2)` は遅れず `osc~(f)` と同じ」は、`f` のポートが刻みでない（`block`）ときに当たり、ポートが `sample` ならパラメータを渡しても集める（最初の塊は `T.default()`）。`f` が `block` でも「`osc~(f)` と同じ」は塊の中でパラメータが変わらないときに限る（塊の走りは刻みの時の値で先に走る。§13.4 の分け方に依らないことは保たれる）。
  再現: `target/notes/176/w721/`（W7-21 の設計メモと審査の入力。`cases2` の `c05`・`c06`・`c12`、審査の `r06`〜`r08`）。今は (1) は値だけ、(2)・(3) の E0816 は今通るプログラムが誤りになる。
  仮の扱い（決定の前）: 合成の規則のまま（W7-21 の設計メモ 2.1 と審査、2026-11-22）。advisor は (1) を高い確信で、(2)・(3) を中〜高の確信で規則から一つに決まると読んだ。急ぎ: W7-21 U1 の票の前に利用者へ確認（今通るプログラムが誤りになるので確認だけでも先に出す）。
- 決定: 決定（2026-11-22、利用者。176 回目。「すべて合成の読みから決まるので、提案の内容で問題ないと思います」）: (1)〜(3) とも合成の読み（S-1207 の規則: 各修飾子は左の全体を一つの部品として包み、`.down~(N)` の境界で中の部品の入出力を集めて配る）のとおり。(1) 速いポートを持つ部品に下りを重ねると境界ごとに集めて遅れが足される（`g4~(x).down~(2).down~(2)` は 6）。(2) 速いポートを持つ部品の下りの後の上りも、下りの境界で集めて配る（`use4~(c).down~(4).up~(4)` は E0816）。S-566 の A10 の「`x.down~(2).up~(2)`（x と同じ）」は比の例で、値の規則ではない。(3) 集める入力に定数とパラメータを渡す形は、位置ごとに読んだ値を集める（W7-09 U2b の親の判断 (d) を決定にする。`cnt~(1.0).up~(2).down~(2)` は 0, 0, 1, 2, 3, 4、`id~('a').up~(2).down~(2)` は E0816）。A10 の「音声の入力の無い `osc~(f).up~(2).down~(2)` は遅れず `osc~(f)` と同じ」は `f` のポートが刻みでない（`block`）ときで、塊の中でパラメータが変わらないときに限る。仕様の字は今のまま。実装は W7-21（検査・計画・参照評価器、`target/notes/176/w721/decided.md`）と W7-16 U6a・U6b（降下）。
