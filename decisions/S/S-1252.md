# S-1252 細部: `.up~(N)` の部品の本体の走りが出したイベントの段の `sample_tick()` の歩（出した走りの時間か、0 歩目か）

- 空白: §11.4 は、`.up~(N)` の本体の、外から来たイベントの段の時間を 0 歩目とする（S-1217 の 2026-11-25 の補い）。本体の走り（j 歩目）が出したイベントの段の `sample_tick()` は字に無い。
  読み: (1) 出した走りの時間（外の数 × N + j）。(2) 0 歩目（外の数 × N）。
  仮の扱い: 読み (1)（W7-17 U4 の実装、字だけの値の表、参照評価器が一致。188 回目に親が `inner~().up~(2)` の走り 1 が出したイベントの段の `sample_tick()` で確かめた: フレーム 0 で 1、フレーム 2 で 5）。通るプログラムの値は変わる形だが、字に無い細部。W7 の区切りで確認だけ。
- 決定: 決定（2026-11-26、利用者。189 回目、W7 の区切りの確認だけ。「(A)と(B1)はS-1148以外OKです」）: 仮の扱いのとおり。0 歩目にするのは外から来たイベントだけで、本体の走りが出したイベントはその走りの時間。
  突き合わせ: 助言の担当が固定のバイナリ `onsa-d02ddee` で再現し、仮の扱いが今の挙動と合い、既決とぶつからないことを確かめた（`target/notes/189/reports/onsa-advisor-a4f41d23ad112f9fe-001.md`）。
- 経緯: 185 回目の S-1217 の補いが「字にしていない（細部）」と書き、188 回目（2026-11-25）に W7-17 の字だけの値の模型（onsa-advisor）が挙げたので、親が細部として登録した。
