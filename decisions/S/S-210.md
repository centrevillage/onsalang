# S-210 同じ型への変換

- 空白: 同じ型への変換（`F32 as F32`、`I32.narrow_i32()`）。§3.3 の E0413 の文は同じ型の組を `as` で書ける組として扱うが、`as` の表に同じ型の組が無い。型別名（`type Sample = F32`）で精度を切り替えるコードにも関わる。W2-01 の設計メモで見つけた（2026-10-08）
- 提案: (a)。組込みの数の型の同じ型の `as` を書ける（別名は解決した後の型で判定）。同じ型への変換メソッドは E0413、型パラメータの `as` は `x as T` も含めて E0411（仕様 §3.3。2026-10-08 決定。ベクトルの同じ型の `as` の 10 行は W2-12、E0413 と E0411 の文面と候補は W5-02（R-158、R-159））
- 時期: W2
- 元の下書き: `spec-gaps-w2-w3.md` の「### S-210 同じ型への変換」
- 補い（2026-11-04、親）: S-231 の決定（111 回目）で、「`x: F32` の `x as T` には候補を出さない」（書ける形が無いため）を改める: `T: Float` なら `T.round_from(x)` を候補にする（変換先が `T: Int` で変換元が整数なら縮小で候補なし、境界の無い `T` は候補なし）。作業は W5-14 U3
