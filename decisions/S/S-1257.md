# S-1257 細部: 範囲の端が二項式で、その被演算子の `as` と反対の端の `as`（`for i in a as U32 ..< b as U16 + 1`）が、§3.3 の一つの E0011 か（仮は別々で、候補は始点の `(a as U32)` だけ）

- 空白: §3.3 は「括弧の無い `as` / `at` の式が一つの式（括弧で切れる二項演算子の式の単位）の被演算子の位置に複数あれば、全てで一つの誤り…見出しの範囲の両端も同じ」とする。範囲の端が和（`b as U16 + 1`）のとき、その和の被演算子の `as` は、範囲の両端の単位か、和の単位かが割れる。
  読み: (1) 範囲の端の `as` と端の和の被演算子の `as` は一つの誤りで、候補は全部を囲む。(2) 和は別の式の単位なので、別々に報告する。
  再現: `for i in a as U32 ..< b as U16 + 1 {`（`x as U32 + 1 ..< k as U32 as U32` も同じ）は E0011 が一つ（主の範囲は始点の `a as U32`、候補は `(a as U32)` だけ）で、当てると和の中の E0011 が残る（前後のバイナリで同じ）。再現の入力は `target/notes/188/w717/l2/b/`。
  仮の扱い: 読み (2)（今の実装）。通るプログラムは変わらない（候補の範囲だけ）。W7 の区切りで確認だけ。
