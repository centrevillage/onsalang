# S-1186 `reset_if~` で初期化した部品の本体の、遅い刻み（`sample / N`）の値を速い段で読む欄の値（位相のカウンタは戻らないので、次の遅い刻みの前に読まれる）と、その欄の型の `Default` の要求

- 空白: §11.10 の `reset_if~` は部品の状態（巻き上げの欄を含む）を初期値に戻すが位相のカウンタには触らない。部品の本体の遅い刻みの値を速い段で読む欄は戻り、次の遅い刻みの前に `sample` の刻みが戻した値を読む。W7-09 の設計メモ 3.2 の「最初の読みの前に必ず書かれる」は `init`・`reset` だけに当たる。戻り先（`T.default()` か）と、`sample / N` の欄の型に `Default` を要るか（E0816）を書いていない。
  W7-09 が `Default` でない型の遅い値を通すと、W7-10 で E0816 を足したときに通っていた形が止まる。
  読み: (1) 戻り先は `T.default()` で、`sample / N` の欄の型にも `Default` を要る（E0816、S-1158 の (α) と同じ）、(2) 戻した後の最初の遅い刻みまで前の値を保つ（欄を戻さない）、(3) `reset_if~` の後に遅い刻みを一つ先に動かす。急ぎ: W7-09 U2r・U3b の前。
- 決定: 決定（2026-11-20、利用者。172 回目）: (1a)。`reset_if~` で、刻みで書いて速い段が読む欄（計算した部分式の欄、名前の値の欄、本体の中の `at` の欄、配る配列、イベントの値）は `T.default()` に戻り、位相のカウンタは進んだままなので次のその刻みまで `T.default()` が読まれる（S-566 の B3 (丙) で格子はずれない）。型に `Default` を常に要る（部品の本体の検査、速い段で読む式で E0816。§11.3 の S-1158 の欄とイベントの値に揃え、呼び出し側の `reset_if~` の有無に依らない）。(2) は S-567 の H2（「戻したいときは `at` を部品の本体の中に書く」）と、(3) は (丙) と食い違うので外した。細部（利用者が了承）: 変換の flow の `at (sample / N)` の入力を本体で `at sample` と読む欄は本体のものとして戻す（#8）、配る配列は変換の flow に付けた `reset_if~` は触れず（S-578）、呼び出しを持つ部品の `reset_if~` で戻り配る型に E0816（#9）、`p at (sample / 4)`（`p` は `block`）の `let` は刻みの欄を作らない（#12、`at` は段を変えない）、E0816 は速い段で読む式に出す（#14）。親が既決から導いた文（利用者が了承）: `reset_if~` はパラメータの種類の値（`block` の入力の写しと巻き上げの欄）に触れない、集める配列は呼び出しを持つ部品の `reset_if~` の後の最初の遅い刻みで初期化の前の所が `T.default()`。§11.3・§11.9・§11.10 と `tasks/diag-codes.md` の E0816 の行に入れた。W7-09 は E0816 の検査と欄の種類（R-92 の「`init` で `T.default()`」）、W7-10 は `reset` の経路の使い回し。段 1（onsa-advisor）と親の伏せた読みが (1a) で一致し、段 2 は省いた。段 1 は、条件が `sample` やパラメータの種類なら格子の上の位置でも初期化のたびに 1〜N サンプルの窓が開くと訂正した。
- 経緯: 170 回目（2026-11-20）、第 115 組の段 1（onsa-advisor、`target/notes/170/g115/stage1_summary.md` の L17）が挙げ、親が登録した。172 回目（2026-11-21）、W7-20 を閉じる前の文書の点検（onsa-docs）が、§11.9 の配る型の E0816 が `reset_if~` を付けたときだけと読める字を挙げた。親が (1a)（`reset_if~` が付くかに依らない）に合わせて、配る型の E0816 を集める入力の型と並べる字に直し、同じ節の「集めた値は…`reset_if~` は触れない」に「変換の flow に付けた」を補った（離席中の暫定、利用者の確認待ち）。
