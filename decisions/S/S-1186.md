# S-1186 `reset_if~` で初期化した部品の本体の、遅い刻み（`sample / N`）の値を速い段で読む欄の値（位相のカウンタは戻らないので、次の遅い刻みの前に読まれる）と、その欄の型の `Default` の要求

- 空白: §11.10 の `reset_if~` は部品の状態（巻き上げの欄を含む）を初期値に戻すが位相のカウンタには触らない。部品の本体の遅い刻みの値を速い段で読む欄は戻り、次の遅い刻みの前に `sample` の刻みが戻した値を読む。W7-09 の設計メモ 3.2 の「最初の読みの前に必ず書かれる」は `init`・`reset` だけに当たる。戻り先（`T.default()` か）と、`sample / N` の欄の型に `Default` を要るか（E0816）を書いていない。
  W7-09 が `Default` でない型の遅い値を通すと、W7-10 で E0816 を足したときに通っていた形が止まる。
  読み: (1) 戻り先は `T.default()` で、`sample / N` の欄の型にも `Default` を要る（E0816、S-1158 の (α) と同じ）、(2) 戻した後の最初の遅い刻みまで前の値を保つ（欄を戻さない）、(3) `reset_if~` の後に遅い刻みを一つ先に動かす。急ぎ: W7-09 U2r・U3b の前。
