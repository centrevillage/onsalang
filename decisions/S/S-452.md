# S-452

- 空白: `1.e-3`・`1.e+3`（小数点の後の指数に符号）。§2.4「`e`・`E` と数字が続けば…`1.e3`」に符号を挟む形を含むか。含めないと `1.e - 3`（メンバの `.e`）と読み、型の段の誤り。W3-05/i の設計メモで見つけた（2026-10-13）
- 提案: 決定（2026-10-13、利用者が ID を挙げて親の直しの案を了承、確認だけ）: 含める（S-126 が指数の符号を受ける）。`float_dot_exponent` の E0020 で候補 `1.0e-3`。仕様 §2.4 の文を「`e`・`E` と（符号を挟んでよい）数字」に改める。実装は W3-05
- 時期: W3
