# S-521

- 空白: ブロック形の構造体のパターンで、`..` が最後の要素と同じ行にある形（`let P {` 改行 `x: a, ..` 改行 `} = p`）。S-500 は「`..` を要素に数えず、後ろに `,` を置かずに独立の行に残す」とし、同じ行に書かれた `..` を独立の行へ移すかを書かない。今の fmt は 1 行に畳む（S-510 の前の扱い）。W3-11/t（U3b）が見つけた（2026-10-14）
- 提案: 決定（2026-10-14、利用者が ID を挙げて親の確認だけの読みを了承）: S-520 のとおり、`..` の前の改行も要素の間の改行と同じく書き手のままにする（`x: a, ..` は同じ行に残る。後ろに `,` は置かない）。S-500 の「独立の行に残す」は、独立の行に書かれた `..` を残す意味。`spec/tools.md` §3.2 の `..` の文。実装は W3-11 の U3b
