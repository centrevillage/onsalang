# S-606 族: タプルの添字で終わる名前の経路の呼び出し

- 空白: §2.4 はタプルの添字で終わる経路（`t.0`）を名前の経路とするが、§6.1 の呼び出しの段の分け（名前の経路は名前の段、`s.f(x)` は型の段）と §2.6 の `!`・`~`（名前の直後）が、その経路の呼び出しにどう当たるかを書かない。族の規則を一つ決め、S-342（`t.0(x)`）と S-591（`t.0!(x)`・`t.0~(x)`・`mk2().0~(x)`）をそこから決める。
- 決定: 決定（2026-10-23、利用者が ID を挙げて了承。57 回目、第 43 組）: (a)。タプルの添字は名前でない（§2.3）ので、それで終わる呼び先は前が何であっても項目・メソッド・flow を指せない値で、構文の段で決める。`(` は E0020（候補 `.(`）、`!(`・`~(` は印を書けない位置の E0002（候補なし、note で印は項目・メソッド・flow の名前の直後と示す）。
  S-191 と §6.1 の「名前の経路の呼び出しは名前の段」から、タプルの添字で終わるものを除く。`t.0::[T](x)` も §4.5 の名前の経路でない式の後の E0002。
  実装は `callee.rs` で添字を値の鎖の環にし、`(`・印・`::[`・§2.5 の空白の規則を一度に揃える（`t.0 (1)`・`t.0 ~(x)` は `mk2().0 (1)` と同じ E0002、`t.0<I32>(1)` は §4.5 の候補 `t.0.(1)`）。§2.5 の例から `t.0` を外した。
  `tests/spec/fixes/e0020_callee_tuple_index.onsa` の `fine`（`t.0(x)` が通る）を否定例に移し、`callee.rs` の説明を改める。W4-12 の「関門の結果を AST に持たせるか」は設計メモで決める。仕様 §2.5、§2.6、§4.5、§6.1
- 経緯: 57 回目（2026-10-23）、W4 の前の S の下書き（X-8）で、同じ族の未決の S が二つなので族の規則の S として登録した。族の分けは X-8 の族の分け（54 回目、onsa-gap）。
