# S-502 「ブロックと並びの先頭と末尾の空行」の読み

- 空白: §3.2（`spec/tools.md`）の「ブロックと並びの先頭と末尾の空行は取り除く」の「先頭」の読み。最初の中身（コードかコメント）より前の空行と読むと、先頭のコメントの後の空行（`{` 改行 `// c` 改行 空行 改行 `let x = 1`）は残る。R-70 の補い（W1-07 の性質テスト）は「ブロックの先頭のコメントの後の空行が消えない」を症状に挙げ、最初のコードより前と読める。W3-11/i の設計メモの G7（2026-10-13）
- 提案: 決定（2026-10-13、利用者が ID を挙げて推奨の (a) を了承。下書きと Fable が一致、第 28 組）: 最初の中身（コードかコメントの行）より前と最後の中身より後の空行を除く。開き括弧の行の行末のコメントは中身に数えない。ファイルの先頭と末尾も同じ。
  R-70 の補いの症状は、コメントが移った後に空行が先頭に残ったもので、(b) を求めていなかった（第 28 組の下書きで確かめた）。`tests/spec` の 794 ファイルのうち 757 が先頭のコメントの行の後に空行を置き、(a) の読みに依る。`spec/tools.md` §3.2。実装は W3-11 の U3
