# S-1102 細部: flow の本体の代入の E0806 に `let` を足す候補を出す範囲（右辺に別の誤りを持つ代入、タプルの代入先）

- 空白: §18.1 は「代入先がまだ定義されていなければ `let` を付ける修正候補を示す」とし、同じ節の約束は「元の誤りが唯一なら、当てた後に同じ段か前の段の診断を残さない」「この約束を満たす候補を作れなければ、候補を出さない」とする。
  約束から決まる形（親の読み）: 右辺が代入先を読む `y = y + x`（当てた後に `y` の前方参照の E0801 が残る）、本体の最後の文の代入（当てた後に出力の無い本体の誤りが残る）、フィールド・要素への代入 `s.a = x`（`let` にできない）、後の `let` が定義する名前への代入（当てると E0304）には出さない。
  決まらない形: 右辺に別の誤りを持つ `y = nope`（元から誤りが二つで約束の外。出して `leaves` で書くか、出さないか）、タプルの代入先 `(a, b) = (x, x)`（`let (a, b) = …` は書ける）。通るプログラムは変わらない。再現は `target/notes/158/w704/u1b/t/gaps.txt` の `g1`〜`g3`・`g6`。
  仮の扱い: W7-04 U1b の実装の出す候補（代入先が名前一つのときに限る見込み）。
  急ぎ: W7 の区切りで確認だけ（`rules/leader.md` 5.11）。
- 決定: 決定（2026-11-26、利用者。189 回目、W7 の区切りの確認だけ。「(A)と(B1)はS-1148以外OKです」）: 仮の扱いのとおり。`let` の候補は、代入先がまだ無い名前一つで、当てた後に名前の段の誤りも出力の無い本体も残らないときだけ。タプルとフィールドの代入先、右辺に別の誤りのある代入には出さない。
  突き合わせ: 助言の担当が固定のバイナリ `onsa-d02ddee` で再現し、仮の扱いが今の挙動と合い、既決とぶつからないことを確かめた（`target/notes/189/reports/onsa-advisor-a5d87f2cf05f2cfce-001.md`）。
