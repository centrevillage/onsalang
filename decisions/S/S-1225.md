# S-1225 細部: `.up~` の中の `reset_if~` の条件の刻みが P の枠で `sample / 2^32` 以上に遅い形（この版は E0200）

- 空白: `reset_if~` の条件の刻み R は、呼び出し側の枠では `sample / 2^31` まで（§11.10 の `at` を含む条件のクロック）だが、外に `.up~` があると、修飾子の位置 P の枠では `.up~` の比だけ遅くなり、`sample / 2^32` 以上になりうる（`x.reset_if~(c at (sample / 2147483648)).up~(2)`）。§11.9 の `U32` の上限は「連鎖のどの修飾子の外から見ても、中の部品の入出力のクロックと遅い刻み」の字で、条件の刻みはそれに入らず、誤りと読む字は無い。実装は P の枠の `U32` の数え（`Ratio::made_n`）で刻みを作るので、間に `when~` があると作れない。
  仮の扱い: この版では作らない E0200（`Feature::ResetTicksPastU32`、修飾子の名前に付ける）。判定は、条件の刻みが修飾子の位置の枠から呼び出し側の枠までの各枠（`run_at` を連鎖の頭から順に当てた段）のどれかで `made_n` の外になる形（間の `.down~` で外れる `g2~(cnt~().reset_if~(c at (sample / 2147483648)).down~(2).up~(2))` を含む）で、`when~` の有無で分けない一つの規則。通るプログラムは変わらない（W7-10 U2b の前は `reset_if~` が全て E0200）。段の区切りで確認だけ。
- 決定:
- 経緯: 181 回目（2026-11-23）、W7-10 U2b の実装の担当の段 1 の設計（設計メモの審査の低「`Reset` だけで作る段が P の枠で 2^32 以上になる形」、179 回目）が E0200 を案にし、親が細部として登録した。
