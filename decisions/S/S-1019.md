# S-1019 §18.1 の「見出しが誤りの trait の impl のメンバも、同じように数える」が、どの trait の impl のどの見出しの誤りに当たるか（開いた形の `impl Default for Ty` だけか、名前の段の見出しの誤りがある全ての trait の impl か、trait の部分が読めない impl だけか）

- 空白: §18.1 は、100 行で「名前の段の誤りがあればそれが単位の誤りで形の E0200 は出さず、誤りが無ければ形の E0200 で、メンバは読まない」、104 行で見出しが誤りの固有の `impl`（E0307 の別名・型引数・孤児規則、E0412、E0416）も「対象の型が決まればメンバを…数え」、105 行で「見出しが誤りの trait の `impl` のメンバも、同じように数える」とする。105 行を足した S-851 の決定の文は「見出しが E0307 の trait の `impl` も、対象の型が決まれば数える（S-748 と同じ）」で、開いた形（`impl Default for Ty`）の文脈だった。読みは (1) 開いた形の見出しの誤りだけ（開かない trait の `impl` は 103 行の「読めなかった部分」で黙らせる。W5-13 U1 の仮の形に近い） (2) 名前の段の見出しの誤りがある全ての trait の `impl` で、対象の型が決まるもの（trait の名前と型引数、対象の別名・型引数・孤児規則、`[ ]`） (3) trait の部分（名前とその型引数）が読めない `impl` だけ。型の段だけの見出しの誤りは、どの読みでも 100 行が先（形の E0200、メンバは読まない）。どの読みでも通るプログラムは変わらない（誤りの単位の後の連鎖が変わる）。今（W5-13 U1 の後）は、`impl Defualt for P` の後の使う所を広く黙らせ、`impl Hash for Al`・`impl Hash for F32` などの後の使う所は E0302 が出る。設計メモ（W5-13 U11）は (2) を推し、案 B'（署名の段の `lower_impl` の形の E0200 の分岐で数えるかを決め、後から表に入れる）なら読みを替えるのは述語の一行。材料 `target/notes/141/w513u11_memo/`（`memo.md` の 3 章と 8 章、再現 `c1.txt`〜`c4.txt`、`sc/scan.tsv`）。
- 決定: 決定（2026-11-12、利用者。142 回目、確認だけの A1〜A6 も ID で了承）: (1)。105 行の「数える」は、見出しが誤りの `impl Default for Ty`（開いた形）に当たる。この版でメンバを読まない trait の `impl` は、見出しに名前の段の誤りがあってもメンバを読まず、数えない（対象の側だけの誤りの `impl Hash for Al` の後の `Q.hash(q)` は今のとおり E0302）。
  細部（確認だけ）: A1 trait の名前が読めない `impl` の対象の型は、trait を満たすかの判定を全て黙らせ、種の制約は判定する（S-850 の B1）。A2 その型の値のメソッドの探索の失敗と、`.` の後の見つからない名前（書いたメンバと書いていない trait の項目を含む）も黙らせる。A3 黙らせるのは、その `impl` のモジュールで宣言した型（別名は右辺の頭）だけで、組込み型、std の型（`Option` など）、他のモジュールの型は黙らせない。A4 引き金は trait の名前が読めないこと（見つからない名前、trait でない名前、失敗した `use` の名前）だけで、trait の型引数の誤り（`impl Default[Gone] for P`）は当たらない（直しても形の E0200 なので直した後と同じ扱い。`P.default()` は E0302）。A5 仕様は §18.1 の見出しが誤りの trait の `impl` の段落の最後の文（「この版でメンバを読まない trait の `impl`」）を改め、S-850 の段落の後に一段落を足した。A6 S-851 に範囲の `補い` を書いた。
  理由: 利用者の基準は「今は手戻りの少ない方」。(2)・(3) はメンバを後から数える仕組みが要り、第 2 期に全ての trait の `impl` を読むと作り直しになる。(1) は S-850 の道具で済む（見当 +15 −6 行前後）。(2) は対象の側の誤りで、誤った見出しの方が正しい見出しより多くを与える（直すと E0302 が出る）。代償は、trait の名前の綴りの誤りの間、その型の本物の誤りが見出しを直した次の検査まで出ないこと（S-850 と同じ）。
  独立のレビュー（段 1・段 2）は (1) で、設計メモ（(2)）と割れた。材料は `target/notes/142/s1019/`。実装は W5-13 U11。既にある事例 `tests/spec/module/failed_impl_trait_name_other.onsa` の `Default[Gone]` の二つの期待が変わる（A4）。外の論点（形の E0200 の `impl` の後の使う所）は S-1022。
