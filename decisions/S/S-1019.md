# S-1019 §18.1 の「見出しが誤りの trait の impl のメンバも、同じように数える」が、どの trait の impl のどの見出しの誤りに当たるか（開いた形の `impl Default for Ty` だけか、名前の段の見出しの誤りがある全ての trait の impl か、trait の部分が読めない impl だけか）

- 空白: §18.1 は、100 行で「名前の段の誤りがあればそれが単位の誤りで形の E0200 は出さず、誤りが無ければ形の E0200 で、メンバは読まない」、104 行で見出しが誤りの固有の `impl`（E0307 の別名・型引数・孤児規則、E0412、E0416）も「対象の型が決まればメンバを…数え」、105 行で「見出しが誤りの trait の `impl` のメンバも、同じように数える」とする。105 行を足した S-851 の決定の文は「見出しが E0307 の trait の `impl` も、対象の型が決まれば数える（S-748 と同じ）」で、開いた形（`impl Default for Ty`）の文脈だった。読みは (1) 開いた形の見出しの誤りだけ（開かない trait の `impl` は 103 行の「読めなかった部分」で黙らせる。W5-13 U1 の仮の形に近い） (2) 名前の段の見出しの誤りがある全ての trait の `impl` で、対象の型が決まるもの（trait の名前と型引数、対象の別名・型引数・孤児規則、`[ ]`） (3) trait の部分（名前とその型引数）が読めない `impl` だけ。型の段だけの見出しの誤りは、どの読みでも 100 行が先（形の E0200、メンバは読まない）。どの読みでも通るプログラムは変わらない（誤りの単位の後の連鎖が変わる）。今（W5-13 U1 の後）は、`impl Defualt for P` の後の使う所を広く黙らせ、`impl Hash for Al`・`impl Hash for F32` などの後の使う所は E0302 が出る。設計メモ（W5-13 U11）は (2) を推し、案 B'（署名の段の `lower_impl` の形の E0200 の分岐で数えるかを決め、後から表に入れる）なら読みを替えるのは述語の一行。材料 `target/notes/141/w513u11_memo/`（`memo.md` の 3 章と 8 章、再現 `c1.txt`〜`c4.txt`、`sc/scan.tsv`）。
