# S-983 失敗した単位の直後の行頭の `static NAME: T = e` を項目の始まりに数えるか（今は前の単位に入り、使う所に E0302）

- 空白: §18.1 は項目の始まりを「見出しを始めるトークン、doc コメント、行頭で見出しの前に並ぶ語」とし、回復が止まる位置をこの定義で見る。§2.2 と §18.1 が項目の頭の形として読む `static NAME: T = e`（S-620）は、`static` の直後が見出しを始めるトークンでないので、この定義に入らない。
  失敗した単位（型の無い `static X = 4`、閉じない `const K: I32 = (1 +`）の次の行に `static Y: I32 = 1` を書くと、前の単位に入って行の診断が出ず、`Y` を使う所に E0302 が出る。
  決めること: 行頭の `static` に名前が続く形を項目の始まりに数えるか。今は数えない（W5-24 U2b の実装のまま。再現は 133 回目の scratchpad の `w524u2b/i/x/gap1.onsa`・`gap2.onsa`）。
- 決定:
- 経緯: 133 回目（2026-11-10）、W5-24 U2b の実装の担当（onsa-impl）が報告し、親が登録した。元から誤りが二つある入力で、一つ目を直せば消える。急ぎでない。
