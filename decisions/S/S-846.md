# S-846 族: §7 のパターンの一覧の形

- 空白: §7 のパターンの一覧に無い形や書き違えの形の、構文の段の扱い（E0002 の文と行、候補）を一つの規則で決める族。今の未決は S-512（構造体のパターンの `..,`）、S-516（unit のパターン `()`）、S-845（選択でない形の中のコメントで候補を作らない腕の行）。W5-11 の「§7 のパターンの一覧の形」の族として下書きする（`rules/process.md` 8.6 の空白の流れ）。
- 決定: 決定（2026-11-09、利用者。128 回目、共通の規則 S-965 と利用者の判断 B1〜B8、`target/notes/128/r58/decisions.md`）: （出所: R10、既決 S-366、X、Y）族「§7 のパターンの一覧の形」の規則: 一覧に無い形と書き違えは、字面で見分けられるものを構文の段で見つける（フィールドや型が要る `..` と浮動小数の型の定数は型の段）。既存言語の形はその行のコード（候補を作れる形は E0020 でガードか置き換えの候補、作れない形は E0002。`s @ Some(_)`、選択の形の行、Y）、一覧に無い形は E0002 で、意図が一つに決まるとき（最後の `_`・`...`・`..` の後ろの `,` を除く、最後でない `_` を最後に置く）だけ候補を付ける。候補を作らない腕の E0002 は、選択を持つ腕では選択の形、選択の無い腕では見つけた形の誤り。
  - 仕様の節: §7 のパターンの一覧の最後に項を一つ（二文）。
  - 今通るプログラムが変わるか: 変わらない（族の規則。個々は S-512・S-516・S-845）。
  - 実装の見当: 個々の S のとおり。
  - ぶつかる既存の事例: なし。R10 の頭の文は段 1 の文「構文の段で見つける」を「字面で見分けられるものを構文の段で」に狭めた（S-366 の `..` と浮動小数の型の定数は型の段、X）。
- 経緯: 101 回目（2026-11-02）、S-845 の登録で同じ族の未決の S が三つになったので登録した（`rules/process.md` 8.6 の空白の流れ 2）。
