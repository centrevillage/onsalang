# S-611 `use` の束縛と同じ名前の子モジュール（`main.onsa` の `use kp.inner` と `main/inner.onsa`）

- 決定済みで戻さないもの: 同じ名前の二度目の取り込みは E0304（S-17）。失敗した `use` の名前は束縛として数えず E0304 の相手にしない（S-462）。`pub use` は名前の段の E0200 で、その名前も失敗した名前（S-596）。
  モジュールの項目と同じ名前の子モジュール（R-177）、ルート直下のモジュールと依存のパッケージ名（S-37・S-246）は E0304。`use` の経路は絶対経路で、頭はルート直下のモジュールか依存のパッケージ名だけ（S-37）。
  経路の途中の要素は子モジュールと項目の定義だけから引く（R-250、S-596 の A7）。`use` の束縛はモジュールの中だけ（S-36）。ローカルは見えている束縛（項目、`use` の名前、prelude、組込み型）と同じ名前を使えない（§5.1、S-79・R-103）。
  暗黙に見えるのは自分のモジュールの項目、prelude、組込み型だけで、依存は `use` の一覧で分かる（§15.1）。
- 略記: 名前の空間を三つに分けて書く。「本体」はモジュールの本体から見える名前（項目、`use` の束縛、prelude、組込み型。§5.1・§15.1）。
  「モジュールの名前空間」は他のモジュールの経路の `main.X` が引く名前（項目とその flow の名前空間、子モジュール。§15.1 の取り込める一覧）。「経路の頭」はルート直下のモジュールと依存のパッケージ名（§15.1）。
  例の `kp` はルート直下のモジュール（`kp/inner.onsa` に `g`）、`main/inner.onsa` は `main` の子モジュール（`h`）、`other` は別のモジュール。
