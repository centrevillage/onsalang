# S-329 定数式の名前の `::[…]`

- 空白: 定数式（配列の長さ、const 引数）の名前に `::[…]` を含められるか（`[F32; Rg::[F32, 4].CAP]`）。§4.5 は具体的な型の関連定数を定数式に含める。W3-19/t で見つけた（2026-10-09）
- 提案: 後の段（W4-13 の前）
- 時期: W4
- 決定: 決定（2026-11-07、利用者が ID を挙げて了承。121 回目、第 91 組。下書きと独立のレビュー（段 1）が一致）: (c)。定数式の名前に `::[…]` を書ける（`[F32; Rg::[F32, 4].CAP]`）。§4.5 が `Rg.CAP` の E0406 の直し先として示す形である。
  型引数に型パラメータか const パラメータを含む形は E0417（S-898 と同じ理由）で、総称の `impl` の中の定数式の `Self.CAP` も同じ（`Self` は対象の型を右辺にした別名と同じ、§4.4）。今通る形を止めるが、`tests/`・`std/`・`examples/` に当たる形は無い。`[F32; Rg[F32, 4].CAP]` は値の位置と同じ E0020 で、候補は `::` を挿す形。`Pl::[F32].K` は E0412。
  W5-16 は構文の枝と E0200 の揃えと `Self.CAP` の E0417、読み手は W5-10 U1a が値の位置の `Rg::[F32, 4].CAP` に作る道を使う。
- 経緯（2026-10-23、親）: X-8: W4-13 を W5-10 へ移したので、期限を W5-10 にした。
- 補い（2026-11-02、親）: X-23（W5 の見積もり）で、期限を W5-16（定数式の文法と型を決める作業。W5-08 から分けた）にした。
