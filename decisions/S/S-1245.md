# S-1245 遅延の第 1 引数の中の、`^名前` を対象かガードに読む `match~` の束縛を、腕の中の利用者の flow の引数か修飾子の条件に書く形（`prev~(match~ ^v { V.A(b) => g~(b), … })`）

- 空白: §11.2 は「`^名前` を書けるのは、遅延の組込みの第 1 引数の式の中だけで、その中の利用者の flow の引数と修飾子の引数には書けない（E0801）」とし、理由を「遅延の位置を、閉路を切る場所に書き手が明示するため」「ほぼ同じ帰還を二通りに書けるようにしない（P2）」とする。
  `^名前` を対象かガードに読む `match~` の腕の束縛を、腕の中の呼び出しの引数か修飾子の条件に書く形（`prev~(match~ ^v { V.A(b) => g~(b), V.B => 0 })`）は、`^` を直に書いていないので今は通る（`d439fac9` で再現）。`prev~(match~ ^v { b => g~(b) })` は、E0801 になる `prev~(g~(^v))` と同じ意味である。
  第 119 組（S-1233）の字「組込みの遅延の第 1 引数の中に書いたインスタンスの呼び出し（とその引数）も、書いた位置で行う」は、この形では行えない（書いた位置では `v` がまだ無い）。
  読み: (a) 束縛を介した `^` も E0801。(b) `^` を読む `match~` の腕の呼び出しは全て段の終わりに行う（W7-11 U2b の i2 の仮の実装）。(c) 束縛を読む呼び出しだけ段の終わり。
  (b)・(c) では、段の終わりの保存の途中で呼び出しが走る。呼び出しがイベントを出すと（U2）、半分だけ保存した状態を受け手の段が読む。
  `match~ ^` の形は、リポジトリの `tests`・`crates`・`std`・`spec`・`design` に 0 件。
  仮の扱い: (b)（U2b の段 b のツリー。参照評価器は保存の所で、この形の `init` が前から内部の誤りになる）。
- 決定: 決定（2026-11-25、利用者。185 回目）: (a)。`^名前` を対象かガードに読む `match~`（ガードがどの腕にあっても）の全ての腕の束縛と、その束縛を対象かガードに読む内側の `match~` の束縛は、`^名前` と同じに扱い、利用者の flow の引数と修飾子の引数には書けない（E0801、候補なし、note で `match~` を下の `let` に出して `prev~(^t)` と書く形）。入れ子の遅延の第 1 引数の中の `^名前` は数えない。束縛を演算と、`^名前` を書ける所に読むのはよい。この E0801 に行き着く候補（E0811 の `~`、前方参照の E0801 の `^`）は出さない。仕様の字は §11.2・§11.5。
  利用者の経過: 親が (a)・(b)・(c) と、(b)・(c) では保存の途中で呼び出しが走ること（U2 の作り直し）を示し（推奨 (a)、独立の審査も (a)）、利用者「S-1245: (a)で。」。ガードの範囲と候補は監査の後の字で示した。 字は監査（onsa-advisor、`target/notes/185/reports/onsa-advisor-adcb0a8c6bf52140a-001.md`、高 1・中 5・低 6）の後に `target/notes/185/spec_text_next2.md` を示し、利用者「上記の字の案で良いです」。
  実装は W7-11 U2b（i3）。
- 経緯: 185 回目（2026-11-25）、W7-11 U2b の段 b の実装（onsa-impl）と参照評価器の担当（onsa-test）が別々に挙げ、独立の審査（onsa-advisor、`target/notes/185/reports/onsa-advisor-a38a900edd342c6cb-001.md`）が (a) を選んだ（確信 中の上）。親が登録した。
