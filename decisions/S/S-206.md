# S-206 `process` が 2 を返した呼び出しの出力

- 空白: `process` が 2（入出力の部分的な重なり、二つの出力が同じポインタ）を返した呼び出しの、出力の中身が書かれていない（S-199 は 1 を返す呼び出しの出力を全て 0 と決めたが、2 については何も言わない）。W1-11 の設計メモで見つけた（2026-10-07）
- 提案: 決定（2026-10-10、利用者が ID を挙げて推奨の (b) を了承。下書きと Fable が一致、第 21 組）: 2 を返す呼び出しも、全ての出力（全てのチャンネル・全てのフレーム、他の出力や入力と重なる所も）を 0 で埋め、状態を進めず、poisoned にせず、どの段も評価しない。「0 以外を返した `process` の出力は全て 0」（S-199 の 1 と同じ）。
  利用者の理由: 出力に書き込まないと落ちるホストに遭遇したことがあり、0 を書けば回避できる。手順の器の `status = 2` の手順も `output`（全て 0）を書く（`output` を省く特例は置かない）。仕様 §14.2。実装は W2-08
