# S-437 `\u{…}` の桁の数

- 空白: `\u{…}` の桁の数。§2.4 はエスケープの閉じた一覧に `\u{XXXX}` と書き、桁の数を書かない。読みは (1) 1〜6 桁で、7 桁以上は値が範囲の中でも E0001（`\u{0000041}`）、(2) 値が範囲の中なら桁は問わない、に割れる。
  今は字句解析器が 1〜6 桁、値の変換（`literal::unescape`）が 7 桁以上も受け、食い違う（W3-04 の持ち越し）。W3-04/t が見つけた（2026-10-11） 直し（2026-10-13、第 25 組の下書き）: 「値の変換が 7 桁以上も受け、食い違う」は、W3-04 が `literal::escape` の一つの文法にまとめたので当たらない。
- 提案: 決定（2026-10-13、利用者が ID を挙げて推奨の (a) を了承。下書きと Fable が一致、第 25 組）: `\u{…}` の中は 16 進の数字 1〜6 桁（大文字・小文字は問わず、`_` は書けない）で、値は Unicode のスカラー値。サロゲート、`10FFFF` を超える値、0 桁、7 桁以上、16 進でない文字、閉じない形は E0001。
  6 はスカラー値の最大の桁の数（値の幅を超えて 0 を詰めない）。仕様 §2.4 の `\u{XXXX}` を `\u{…}` と規則の一文に改める。実装は今のまま（親が `literal.rs` の `SPEC-GAP(S-437)` を外し、`tests/spec/negative/lex_escapes.onsa` に 7 桁・8 桁の E0001 を足す。作業 ID は要らない）
