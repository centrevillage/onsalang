# S-268 初期化式が発散する `let`

- 空白: 初期化式が発散する `let`（`let x = { return }`、`let x = if c { return 1 } else { return 2 }`）は、それ自体が発散する文か。
  §7 の「発散する文の後に文や最後の式があると E0503」の「発散する文」は、発散するものそのもの、それで終わるブロック、全ての枝が発散する `if` / `match` を挙げ、`let` の初期化式に触れない。後に文があるとき E0503 か、S-262 の E0406 と E0503 のどちらを先に出すか。W2-06/b の再確認で見つけた（2026-10-08）
- 提案: (c) 初期化式の全体が §7 の発散する形である `let` / `var` を発散する文に数え、到達しない最初の部分である束縛（パターン）に E0503（後の文の有無によらない）。修正候補はパターン・注釈・`=` と後の文を消し、初期化式を文として残す形。到達しない部分は文の順の検査で見つかるので、関数の終わりの検査（E0406、E0405、後回しにした E0416）より先に報告する。
  S-262 の例（`let x = { return }` の E0406）は E0503 に変わり、E0406 は `let` でない位置の網として残る（§4.7 の起点の例に `let y = f(id({ return }))` を足した）。
  常に評価される部分式の発散は S-291、候補が孤立させる束縛は S-292（利用者。実装量が (b) と同程度であることを条件に (c)。第 6 組の下書き。仕様 §4.7、§7。2026-10-08 決定。実装は W5-08）
