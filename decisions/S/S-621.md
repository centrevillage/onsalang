# S-621 §12.8 の `Str`・`Bytes`・`Array` のヒープのオブジェクトの中身の配置（長さの置き場所）

- 空白: §12.8 はヒープのオブジェクトのヘッダ（`count`・`alloc`）を定めるが、`Str`・`Bytes`・`Array` のオブジェクトの中身の配置（長さの置き場所、バイトの並び）を書いていない。第 2 期の `Str` の降下と、S-619（借用した `Str` を C の関数へ渡す形）の前に要る。C の境界に出る形なら §14.2 の約束になる。
- 決定:
- 経緯: 58 回目（2026-10-24）、第 48 組（S-615）の下書き（onsa-gap）と独立のレビューの段 1・段 2 が新しい S の候補として挙げ、利用者が了承した（S-615 の E3）。
