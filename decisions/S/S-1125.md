# S-1125 細部: `onsa test --flows` が `Bool` の `@param` を持つ export の flow に与える値（範囲の角は `true`・`false` の両方か）

- 空白: §18.2 は `--flows` で export される flow を「`@param` の範囲で」自動検査し、「角と無作為の内点でパラメータを取る」とする。`Bool` の `@param` には `min`・`max` が無い（S-87 の (3)）ので範囲が無い。
  読みは (1) `true` と `false` の両方を取る（`Bool` の角）、(2) 取らずに `default` だけを与える、に割れる。`--flows` は今無い（「unexpected argument」、S-308 の入口の問いと同じ作業）。
  仮の扱い: (1)。`--flows` を実装する作業の前に確認だけ。
