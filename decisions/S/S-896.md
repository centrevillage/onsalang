# S-896 `impl Tr for Ty` の見出しの読みの細部（trait の位置の型引数の名前と、trait の位置の型別名）

- 空白: S-895 は `impl Tr for Ty` の見出し（`Tr`、`Ty`、`impl` の `[ ]`）を名前の段まで読むとした。次の二つの形は決定の文から一つに決めきれない。
  (a) trait の位置の型引数の名前: `impl Iter[Nope] for P` を E0302 にするか、形の E0200 にするか。
  (b) trait の位置の型別名: `type A = P` の後の `impl A for Q` を、trait の位置の型の名前の E0308 にするか、別名の E0307 にするか。§4.4 の別名の E0307 は対象の位置の規則である。
  親の読み（確認だけ）: (a) は E0302。型引数も見出しの名前で、固有の `impl` の対象の型引数と同じに読む。(b) は E0308。`A` は trait の位置に要る種類でなく、別名の右辺が型でも trait にならない。どちらも誤りのプログラムのコードの違いだけである。
- 決定: 決定（2026-11-05、利用者が ID を挙げて了承。115 回目、組 86、確認だけ）: (a) `impl Iter[Nope] for P` は E0302。trait の位置の型引数も見出しの名前で、固有の `impl` の対象の型引数と同じに名前の段まで読む。型の段の誤りは報告しない。(b) `type A = P` の後の `impl A for Q` は E0308。§4.4 の別名の E0307 は対象の位置の規則で、trait の位置には §15.1 の種類の規則が当たる。
  仕様は §18.1 の見出しの範囲に型引数を足した。(b) は §15.1 の一般の規則のままで、文を足さない。実装は W5-04 の U1。
- 経緯: 115 回目（2026-11-05）、W5-04 U1/t の続き（onsa-test）が NEW-2・NEW-3 として報告した。`impl Nope for F32` の順（NEW-1）は、孤児の判定に `Tr` が要るので E0302 が先で、仕様が約束しない細部として親の読みにした。関係: S-895。
