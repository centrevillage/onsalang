# S-443

- 空白: 予約語の名前のモジュールそのものを取り込む `use kp.clock`。S-371 は `use` の経路の `.` の後を名前として読み、`kp.clock.tick()` と `use kp.clock.{tick}` を書けるとするが、`use kp.clock` が作る束縛 `clock` は式の頭で E0200 になり使えない。`use kp.clock` を誤りにするか、通して使う所で E0200 か。W3-04/t が見つけた（2026-10-11）
- 提案: W3-04 は通す（使う所は E0200）仮の扱い。後の段
- 時期: W3
- 決定: 決定（2026-10-23、利用者が ID を挙げて了承。55 回目、第 39 組）: 族の規則 S-594 から決まる。予約語の名前のモジュールそのものを取り込む `use kp.clock`・`use clock`・`pub use kp.clock`（表の 19 行）は、`clock` の位置の E0200（並びの `use kp.{clock}` と同じ）。
  キーワードの `use std.test`・`use match`（18 行）は E0002 で、並びで中の名前を取り込むか、親から辿る書き方を note で示す。経路の頭の予約語（5 行）、途中（10 行）、`use kp` の後の `kp.clock.tick()`（15 行、S-594 の (x1)）は通る。
  `SPEC-GAP(S-443)` の印（形は 5 行で S-371 が決めた）は、S-371 を指す注記にする。仕様 §15.1・§2.2
