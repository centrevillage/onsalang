# S-828 `[targets.<名前>]` の名前の形（`..`・`/`・空白を含む名前と、出力のディレクトリ）

- 空白: §15.3 の表は `[targets.<名前>]` の名前の形を書いていない。`onsa build --target <名前>` は成果物を `target/<名前>/` に置く（§18.2 の `build` の行）。
  今の実装は名前をそのまま経路につなぐ（`crates/onsa_driver/src/build.rs` の `root.join(BUILD_DIR).join(&opts.target)`）ので、`[targets."../../esc"]` と `build --target ../../esc` はパッケージの外に書き、終了コード 0（再現 `target/notes/95/w402/probe/b01_target_name_escape/`）。
  読みは (1) 名前に形の規則を置く（§2.3 のモジュール名の規則に揃える、または少なくとも `/`・`\`・`..`・空を書けない。破ればマニフェストの E1103） (2) 形は決めず、出力の経路だけを `target/` の下に閉じる（外に出る名前はビルドで使い方の誤り）に割れる。(1) は今通る名前（`"a b"` など）を誤りにしうる
- 決定: 決定（2026-11-01、利用者。95 回目）: (a)。`[targets.<名前>]` の名前は、パッケージの名前と同じ `snake_case` の識別子（§2.3）で、外れれば名前の位置に E1103（全てのコマンドのマニフェストの検査）。
  理由: ビルドは成果物を `target/<名前>/` に置くので、経路の外へ出る名前と、大文字と小文字だけが違う名前の重なり（この機械のファイルシステムでは `target/Host` と `target/host` が同じディレクトリ）を両方防ぐ。規則はパッケージ名のものを使い、新しい規則を足さない。
  リポジトリのターゲット名 17 種は全てこの規則に合い、後で緩めても通っていたものは止まらない。案 (b)（`/`・`\`・`.`・`..`・空だけを禁じる）と (c)（ビルドで出力の経路だけを見る）は、大文字と小文字の重なりを防がない。仕様 §15.3、§18.1。実装は W4-02 の U2a2（閉じた表）
- 経緯: 95 回目（2026-11-01）、W4-02 の設計メモの審査（onsa-advisor）が見つけ、親がパッケージの外に書くことを再現した。急ぎ: W4-02 U2a（閉じた表）の前
