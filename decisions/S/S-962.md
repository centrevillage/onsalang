# S-962 接する前置の `~` と `!` の重ね（`~!x`、空白のある `~ !x`）の候補 `!(!x)` は、C の `~!x`（`!` は論理の否定）と値が違う

- 空白: §2.6 は前置の `~` を E0020 とし、候補は `!`（S-123、S-938）。被演算子が前置の記号で始まる接する `~-x`・`~!x` の候補は決定が無く、今の実装は `!(`…`)` の二つの編集を出す（`~!m` は一手で誤り 0）。
  C の `!` は論理の否定（0 か 1）で、C の `~!x` は `~(x == 0)` である。Onsa の `!` は整数ではビット反転なので、候補 `!(!x)` は `x` になり、C から写した書き手の意図と値が違う。`!x` を Onsa の式と読めば、候補はその読みのとおりである。`~-x` の `-` は C と Onsa で同じ意味で、当たらない。
  読み: (1) 今のまま（候補 `!(!x)`）。(2) 被演算子が `!` で始まるときは候補を作らない（§18.1 で候補の無い E0002、`~~m` と同じ）。(3) (1) に C との違いの note を足す。どれも誤りの入力の候補と報告だけの違いで、通るプログラムは変わらない。空白のある `~ !x`（S-958）は、S-961 の答えによっては接する形に従う。
- 決定: 決定（2026-11-09、利用者。127 回目）: (2)。被演算子が `!` で始まる前置の `~`（`~!x`、`~ !x`）は候補を作らず、§18.1 の構文の段の形の E0002（`~~x` と同じ）。C の `!` は論理の否定で、C の `~!x` は -1 か -2、候補 `!(!x)` は `x` になり、書き手の意図が一つに決まらない。`~-x` の候補 `!(-x)` は残す。今の候補を消す向き。§2.6 に書いた。
- 経緯: 127 回目（2026-11-09）、第 94 組の下書き（onsa-gap）が NEW として報告し、親が登録した。族の規則は S-961。急ぎは後の段。
