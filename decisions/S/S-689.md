# S-689 署名（引数・返り値の型、型引数、const 引数）や `impl` の見出しに書いた失敗した名前・E0304 の名前は、その def の本体の検査を止めるか（`use kp.{Gone}` の後の `fn f(x: Gone) -> I32 { let a: I32 = true … }`）

- 空白: §18.1 は「読めなかった部分（引数の型、フィールドなど）は誤りの型として扱い、それを使う側には診断を出さない」とし、同じ節で「一つの単位の中では、最初のエラーで検査を止める」とする。同じ節の単位の段落は「`impl` の見出しに誤りがあれば `impl` 全体を一つの単位とし、メンバは検査しない」とする（第 61 組の下書きの指摘で、§15.1 と書いていたのを直した）。
  署名や `impl` の見出しに書いた名前が、名前の段で失敗した `use` の名前か E0304 の名前（S-462・S-675 で使う所が黙る）のとき、その def の本体を検査するかを書いていない。
  読みは (1) 誤りの型になるだけで本体は検査し、その型を使う所だけ黙る、(2) 単位の誤りとして本体を検査しない、に割れる。
  W4-03 U3b1 の実装（67 回目、WIP `7ab44a4`）は、引数・返り値の型と型引数では (2)（`sig/types.rs` で `Failed::Unit`）、配列長・const 引数と `impl Gone` のメンバでは (1)（const 引数は U3b1 の直しの担当が確かめて直した） で、形によって割れる。`use kp.{Gone}` の後の `fn f(x: Gone) -> I32 { let a: I32 = true  a }` は `use` の E0302 だけで、本体の E0401 は出ない。
  U3b1 の前は、署名の `Gone` の E0302 がその単位の最初の誤りだったので本体は同じく検査されなかった。再現は `target/notes/67/w403/u3b1/b/c3.txt`・`c14.txt`・`c18.txt`（壊す側の `pk.py` で展開する）。
