# S-812 値の関数を `!(` で呼ぶ形（`f!(x)`、`f` はローカルの関数値）

- 空白: §15.1 は値を `x(...)` の形で呼ぶと型によらず E0020（候補は `x.(...)`）、§2.6 は `名前!(引数, ...)` を `inout self` のメソッドの呼び出しとする。値を `x!(...)` の形で呼ぶ形を書いていない。
  今は型の段の E0714「`!` marks `inout self` method calls only」と候補「remove `!`」である。W4-12 の名前の段の E0020（`f(x)` の `f` が値）が入ると、候補を当てた `f(x)` に前の段（名前の段）の誤りが残り、§18.1 の約束を破る。
  読み (1): 名前の段の E0020 で、候補は `!` を `.` に置き換える（`f.(x)`）。読み (2): 型の段の E0714 のまま、候補を `!` を `.` に置き換える形にする。
  読み (3): E0714 で候補なし（§5.2 は E0714 を「修正候補は一意」とし、登録簿 `crates/onsa_diag/src/codes.rs` の E0714 は候補が必須なので、§5.2 の一文と登録簿の印と必須の一覧のテストを直す費用が要る。W4-12 の設計メモの審査、93 回目）。
  再現: 93 回目の scratchpad の `w412/i/probe/calls3.onsa` の 8 行。
- 決定: 決定（2026-10-31、利用者が ID を挙げて了承。確認だけ。93 回目、第 76 組）: S-811 の (a) から。関数型の値の `h!(x)` は型の段の E0714 で、候補は `!` の 1 字を `.` に置き換える（`h.(x)`）。
  関数でない値（定数、const パラメータ、組込み型の定数）は呼べない値の E0401、単位形の列挙子は E0412 で、候補は無い（E0714 は候補が必須なので、作れない形は E0714 にしない）。名前の段の値の E0020 は `!(` に当てない。今の `K!(x)`・`F32.PI!()` の候補が構文の誤りを作る R-341 も W4-12 の U1 で直る。
  仕様 §5.2、§15.1
