# S-1062 細部: 効果行に見つからない名前（E0302。`use` の無い `Random`、綴りの誤り）を書いたとき、S-691 の開いた行に含めるか

- 空白: §18.1 と S-691 は、効果行の失敗した `use` の名前と E0304 の名前を未知の効果にして、行を開いた行にする（指しえた効果は経路の最後の名前と同じ名前の効果。S-691 の 152 回目の補い）。
  効果行に見つからない名前（その名前そのものが E0302。`use` の無い `uses {Random}`、綴りの誤り `uses {Aloc}`）を書いたとき、同じく開いた行にするかを書かない。今は行から落とし、関数型に書くと、その位置の無名関数の行が空になる。
  関数の自分の行と無名関数に書いた行の見つからない名前は、E0302 がその単位の最初の誤りで単位の以後を検査しないので当たらない（`uses {Aloc}` の本体の確保に今 E0601 は出ない）。当たるのは、別の単位の関数型を期待型に受ける位置である。
  再現: `target/notes/152/d5adv/parent_verify/v_b6.onsa`（`use` の無い `fn() uses {Random}` の引数。今は E0302 と `use std.random.Random` の候補だけ。W6-03 U7b の後は `test` の本体の無名関数に偽の E0601 の見込み）、`v_b2.onsa`（`uses {Aloc}`。今 E0302 と無名関数の E0601）。
  読み: (1) 同じ規則で開いた行にする（`Random` は黙る。`Aloc` は同じ名前の効果が無いので今のまま） (2) 開いた行にしない（今のまま）。
  仮の扱い: (1)（独立のレビューの案。W6-03 U7a で失敗した名前と同じ欄に入れる。コードに `SPEC-GAP(S-1062)` の印）。
