# S-981 メソッド自身の型引数の、宣言の数を超えた要素の名前（`v.m::[I32, Nope](x)`、型パラメータの無い `v.plain::[Nope](x)`）: E0302 が先か、E0412 だけか

- 空白: §4.5 は「数が宣言と合わなければ E0412 で、宣言の数を超えた要素は読まない（種類も名前も判定しない。`P[Nope]` と `Ring[F32, 4, K]` は E0412 だけ）」とする。関数と型は名前の段が宣言の数を知るので、超えた要素を読まずに済む。
  メソッドは受け手の型で決まり、数が分かるのは型の段なので、名前の段は `v.m::[I32, Nope](x)`（`m` の型パラメータは一つ）と `v.plain::[Nope](x)`（`plain` は型パラメータを持たない）の `Nope` を読むか読まないかを、数を知らずに決めることになる。
  決めること: メソッドの並びでは名前の段が全ての要素の名前を読む（見つからない名前の E0302 が先に出る）か、名前の段は読まずに型の段が数の内の要素だけを読む（E0412 だけ）か。今は名前の段の E0200（式の中の型引数は未実装）。
- 決定: 決定（2026-11-10、利用者。133 回目）: (a)。メソッド自身の型引数の並びは、数が分かる前に名前の段が全ての要素の名前を読む。宣言の数を超えた要素の見つからない名前（`v.conv::[I32, Nope](1)`、型パラメータの無い `v.plain::[Nope](1)`）は名前の段の E0302 が先で、直した次の検査で型の段の E0412 が出る（名前を引くのは名前の段だけにする。利用者が実装の簡単さと管理のしやすさで選んだ）。
  種類と数の両方が誤りのとき（`v.conv::[4, U8](1)`）は、数の内の要素の種類（E0308）が先で、次に数（E0412）である（関数の `id::[4, U8](1)` と同じ結果）。
  仕様: §4.5 の「宣言の数を超えた要素は読まない」に、メソッド自身の型引数の但し書きを足す。W5-10 U2b。
