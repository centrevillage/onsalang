# S-205 関連関数・メソッド・効果の操作を値として取り出す（Fable のレビューで追加）

- 空白: 関連関数・メソッド・効果の操作を、呼ばずに値として取り出せるか（`let mk = Point.new`、`let g = p.norm`）。§5.3 の「名前付きの関数」が関連関数を含むかが読めない（S-191 の Fable のレビューで見つけた、2026-10-07）
- 提案: 関連関数と名前空間の関数は値になる（`mk.(1.0, 2.0)`）。メソッドと効果の操作は値にできない（`p.norm` は E0413、`Point.norm` と `Fs.read` は E0308。note で呼び出しだけと示す）（2026-10-07 決定。実装は W4-12、W5-02）
