# S-546

- 空白: 無名関数の `-> ()` と空の `uses {}` は、省略と同じ意味か。仕様 §6.1 の「返り値が `()` の場合だけ `->` を省略する」は名前付きの関数の規則で、無名関数は「期待型が分かる位置では注釈を省略できる…返り値の型は本体から決まる」（仕様の 712 行）。
  型の検査（`check_closure`）は、無名関数の省略を期待型の返り値と効果行で、`-> ()` と `uses {}` を明示の `()` と純粋で検査する。
  そのため fmt がこれらを外すと、型の誤りのあるプログラムが通るようになる（`take(fn(x: I32) -> () { x })` の E0401 が `take(fn(x: I32) { x })` で消える。`uses {}` も同じ）。正しいプログラムが別の正しいプログラムになる例は見つかっていない。
  S-540（全ての位置で外す）と S-539 (c)（型と合わない `init` の除去）と同じ族。W3-12/b（U1）が見つけた（2026-10-15）
- 提案: 決定（2026-10-15、利用者が助言の担当の推奨の (k2) を了承）: 無名関数の `-> ()` と空の `uses {}` は外さない（返り値の型と効果行の注釈で、省くと期待型から決まる形になり、外すと型の誤りが消える）。S-68・S-540 の範囲から無名関数を外す。あわせて一般の原則を仕様 §18.2 に置いた: fmt の書き換えは、どのプログラムでも各段の判定（合否と診断のコード）を変えない。仕様 §6.1・§8.1、`spec/tools.md` §3.3
