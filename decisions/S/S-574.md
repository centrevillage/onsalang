# S-574 境界の入出力の別のレート（`sample / N`・`sample * N`）

- 空白: §19.1 のマルチレートの項は、一番外の flow（export する flow、Onsa のコードから `process` で呼ぶ flow）の入出力の `sample / N`・`sample * N` を第 35 組まで E0810 とした（S-566 の A11）。決めること:
  1. E0810 のままにするか、生成する API と C の API の形（入出力ごとの長さ、`frames` が N の倍数でないとき）を決めるか。
  2. 形を決めるなら、位相のカウンタ（§19.1。ホストの区切りに依らない）との関係と、`render` の長さ。
- 決定: 決定（2026-10-22、利用者が ID を挙げて了承。51 回目）: 一番外の flow の入出力の `sample / N`・`sample * N` は、第 1 期の規則として E0810（誤りの位置は `process`・`process_inplace`・`render` を使う所と `[export]` の項目。note で `.down~(N)`・`.up~(N)` で包む書き方を示す）。後で `sample * N` を開いても壊れない。仕様 §19.1
- 経緯: X-7（W3 の終わり、2026-10-15、利用者）で、W4 の前に決めて第 1 期の範囲を W4〜W10 に割り当てることになった。第 35 組（境界）の一つで、第 33 組（S-555〜S-559）と第 34 組（S-560〜S-567）の決定を前提にする。S-566 の確認だけの項目 A11（`S-566.draft.md`）。関係: S-565、S-566、S-567。
