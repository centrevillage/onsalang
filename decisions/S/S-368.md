# S-368

- 空白: handler の関数の引数の型の後ろの `at`（クロック）のコード。S-356 は fn の入出力の型の後ろを名前の段の E0821、入出力でない宣言の型の後ろを構文の段の E0020 とするが、handler の関数を挙げない。W3-09/i で見つけた（2026-10-09）
- 提案: 決定（2026-10-09、利用者が ID を挙げて了承。親の案）: fn と同じく E0821（名前の段）。handler の関数の引数は関数の引数と同じ宣言の形（§5.2 の表も同じ行）で、flow の入出力でないため。仕様 §11.3。実装は W3-09（`Param.clock` に入れる）と W4-12（E0821）
