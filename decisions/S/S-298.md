# S-298

- 空白: `assert` の panic の文面が、`onsa test`（`assert <式のソース>`、§18.1）と通常の実行（C の `onsa_panic("assertion failed: …")`）で違う。§9.2 は通常の実行の「メッセージ」の形を書かない。揃えるか、通常の実行の文面は約束しないと書くか。
  式の中のコメントも C のバイナリの文字列に入る（`panic_messages = false` で除ける）。R-183（W2-10）の後は降下が文面を一か所で作るので、今の違いは確かめ直す。第 8 組の下書き（S-284）で見つけた（2026-10-08）
- 提案: 決定（2026-10-08、利用者。S-284 の回答の中で、S-284 には含めない）: 通常の実行の panic の文面を、どの環境でも同じ文字列と約束しない。理由: 同じで嬉しい場面が無い（テストでは嬉しいかもしれないが、実務では内容が判別できればよい）。約束は §18.1 の `onsa test` の `message` だけ。
  R-183（W2-10）で降下が文面を一か所で作るのは実装の都合で、約束ではない。§9.2 は今も通常の実行の文面の形を約束していないので、仕様に文は足さない（2026-10-08 決定。実装の作業は無い）
