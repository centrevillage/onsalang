# S-723 インスタンスの位置で flow の組込み名の後に `.` を書く形（`prev.x~(x, 0.0)`、`sample_rate.x~()`）は、`~` の E0812 か、名前空間でない名前の後の `.` の E0308（S-720）か

- 決定済みで戻さないもの: `.` の前の組込み名の E0308（S-720。呼び出しの形の `prev.x(…)` は既にこれ）、呼び先の名前が解けなければ E0812 より先に E0302・E0308（S-590 の決定の文、R-247）、E0812 の候補は `f(x)` で呼ぶ項目だけ（S-590）。
  表の他の行（見つからない名前、名前空間でない名前の後の `.`、flow でない種類の名前）は、この三つの決定と §2.6 の文で決まっている。
  第 67 組の下書きの「族「§15.1 の E0308 の位置」の仕組みの出所」と「S-723 の形の表」の節（写しは `target/notes/78/g67/draft.md`）。
- 論点: §11.4「組込み名は…要る種類になるのは自分の呼び出しの形の呼び先だけである。他の位置（値、…、`.` の前、…）に書くと E0308」と、§2.6「flow でないものに `~` を付けると E0812」、§15.1「その形にコードを定める位置に固有の規則があれば、そのコードが先」。
  `prev.x~(…)` の呼び先は `prev.x` で、`prev` は `.` の前にある。E0812 をインスタンスの位置に固有の規則として先にするか、`.` の前の E0308 が先かが、文の上で割れうる。
- 今の実装: 表のとおり、`P78/g67/probe/s723_0`〜`4.onsa` はどれも E0812「`prev.x` is not a flow; `~` creates a flow instance…」と候補「remove `~`」（範囲は呼び出しの全体）。登録のときと同じ。
  名前の段の歩き手は、組込み名の頭の `Place::Instance` を経路の長さによらず呼び先と数える（`paths.rs::flow_builtin` の `Place::Instance => true`。`Place::Callee` は `segs.len() == 1` のときだけ）うえ、インスタンスの位置の誤りを報告しない。
  候補を当てた `prev.x(x, 0.0)` は名前の段の E0308 になり、§18.1 の候補の約束（当てた後に同じ段か前の段の誤りを残さない）を満たさない。`prev.x` は `f(x)` で呼ぶ項目でもないので、S-590 の候補の規則にも合わない（R-247 と同じ根で、W4-12 で直る形）。
- 案: 
  - (a) `.` の前の組込み名の E0308（S-720）とする。インスタンスの位置でも、呼び出しの形（`prev.x(…)`）と値（`let a = prev.x`）と同じ診断で、note で `prev~(…)` を示す。
  - (b) インスタンスの位置に固有の E0812 とする。S-590 の候補の規則から候補は無く、note で `~` は flow と組込みの遅延の印であることを示す。
  - 書き手から見て: 例として、遅延に初期値やメソッドがあると考えて `prev.init~(x, 0.0)` や `delay.process~(x, 4)` と書く。(a) は「`prev` は呼び出しの形でだけ書く組込み名」と言い、note が正しい形（`prev~(x, 0.0)`）を示す。
    (b) は「`prev.init` は flow でない」と言い、`prev.init` が何かを書き手に探させる。どちらも一回の検査で直せる形を示すのは note で、約束ではない。
  - 修正候補: どちらの案も候補は無い（`prev.init~(x, 0.0)` の意図が `prev~(x, 0.0)` に一つに決まらない）。当て続けて `no-candidate` で止まる。今の「remove `~`」は、どちらの案でも消える。
  - 規則と例外: (a) は決定済みの S-720 と S-590 の文から決まり、規則を足さない。(b) は S-590 の「名前が解けなければ E0302・E0308」に、組込み名の頭の例外を一つ足す。
  - 実装の量（W4-12 の U3、E0811・E0812 を名前の段へ移す単位）: (a) は `flow_builtin` の `Place::Instance` を `segs.len() == 1` のときだけ呼び先と数える（約 1〜2 行）。
    インスタンスの位置の誤りを歩き手が報告する直しは R-247 のために W4-12 で行うので、その上で E0308 が出る。(b) はその直しの中で、組込み名の頭に `.` が続くインスタンスだけ E0308 を出さずに E0812（候補なし）にする枝（約 +5 行）。どちらも後の段には続かない。

  - 決定済みの S-720（組込み名の `.` の前は E0308）と S-590（名前の解決の誤りは E0812 より先）から決まり、規則を足さない。呼び出し・値・インスタンスで同じ書き間違いに同じコードが出る。
  - (b) は決定に例外を足し、文面が誤りの元（`prev` に `.` を付けたこと）を指さない。
