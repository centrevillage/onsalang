# S-89

- 空白: 字句と fmt の細則が仕様に無い: 識別子の文字、`////`、`=` の整列の範囲、後置の括弧の前の空白（`xs [0]` は E0002、`f (x)` は呼び出し、括弧の中の改行の後の `(` も呼び出し）、腕の `return`（修正候補の無い E0002）（レビュー R-101）
- 提案: 識別子は今のまま ASCII だけで、E0001 の文面に使える文字を示す。`////` は今のまま。fmt の整列は `let` と `var` の 1 行の束縛を全て含める（型注釈で列を切らない）。
  後置の `(` と `[` は、トークンの「前に空白か改行がある」印で判定し、空白なら E0020（修正候補は空白の除去。`xs [0]` には `xs([0])` も）、括弧の中の改行なら E0002（`,` の挿入と改行の除去）。呼び出し、添字、型引数、宣言の引数と型パラメータ、パターン、属性の全てで同じ関数を使う。
  腕の `return` / `break` / `continue` は E0020（修正候補はブロックで囲む形）。`tests/review-phase1/parent/r101/` の期待値と今の出力は各ファイルの先頭のコメント（2026-10-05 決定。実装は第 3 段）
