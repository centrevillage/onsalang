# S-398 二項の位置の `-`・`^` の非対称な空白

- 空白: 並びの中の非対称な空白の `-`・`^`（`[1 -1]`、`[0.5 -0.5]`、`two(a -b, 1)`、`[a ^b]`）。今は二項として黙って通り（`[1 -1]` は要素一つの `[0]`、`two(a -b, 1)` は引数の数も合う）、fmt が `[1 - 1]` にする。
  MATLAB と Julia は要素二つと読み（文書、未確認）、swiftc 6.3.1 は `,` の fix-it を出し、Python・Node・clang・Ruby は `1 - 1` と読む。§2.5 の「前置か二項かは、直前のトークンが同じ式の被演算子かどうかで決まる（`a - b` は二項）」は分類を決め、非対称な空白の受理は決めていない（改行の形は S-370 で誤り）。
  誤りにするか、候補（`a - b` と `a, -b`）、括弧の外（`let c = a -b`）の扱い、`+`（Onsa に前置の `+` は無い）の扱いを決める。第 19 組の下書きの付録が見つけ、Fable が急ぎを上げた（2026-10-10）
- 提案: 決定（2026-10-10、利用者が ID を挙げて推奨の (b) を了承。下書きと Fable が主の案で一致、第 20 組）: 二項として読む `-`・`^` の前だけに空白を空け、後ろを被演算子に接する形（`a -b`、`[1 -1]`、`two(a -b, 1)`、`[a ^b]`、`let c = a -b`）は、括弧の内外で構文の段の E0020（データのファイルに新しい行）。
  候補は両側に空白を置いた形と、式を要素とする並び（引数、配列、タプル）の中では `,` の挿入（S-370 と同じ順）。添字・構造体リテラルのフィールドの値・腕の本体・並びの外は候補一つ。
  腕の本体で `=>` が続く同じ行の形（`0 => { 1 } -1 => 2,`）は S-386 の E0002（同じ行にも広げる）。`a -(b)`、`a -1`、`x -^y` も同じ形で、`-%`・`-|` は対象外（`a - -b` は二つ目の `-` が前置で、二項の `-` の両側に空白があるので当たらず通る。下書きの「`a - -b`（二つ目は前置）…は同じ形」の読みを、2026-10-10 に利用者が ID を挙げて了承。W3-06/t2 が見つけた）。`+` は含めない（Onsa に前置の `+` が無い。前置の `+` の S-405 と一緒に決める。W3-06 の作業票に、判定に `+` を足す位置を書く）。
  §2.5 の分類の文（`a - b` は二項）は変えない。後で並びの中だけ（(a)）へ緩めても壊れない（利用者）。仕様 §2.5。
  実装は W3-06（S-370・S-123・S-386 と同じ二項の連鎖の所、約 40〜60 行）（読みの補い、2026-10-10、親: 配列の繰り返し（`[0.0 -m; 4]`、`[0.0` 改行 `-m; 4]`）は、同じ括弧の深さ 0 に `;` が続くので `,` の候補を出さない（当てると `;` で E0002 が残る、S-236。S-419 の型だけの並びの `;` と同じ走査）。同じ行の非対称な空白の `-`・`^`・`+` が `for`・`while`・項目の本体を閉じる `}` の後に続く形（`for … { } +b`）は、両側に空白を置く候補も E0002 を残すので出さない（一般の E0002）。W3-06/b（単位 2）が見つけた）
