# S-228 const 引数の負の値

- 空白: const 引数の `-1`（`Ring[F32, -1]`）のコード。定数式の文法（§4.5）に単項の `-` が無く、E0408（範囲外）か、S-184 の「符号なしへの負のリテラルは E0401」か読めない（今の事例 `negative/const_args.onsa:19` は E0408）。W2-06/t で見つけた（2026-10-08）
- 提案: (a)。
  定数式は普通の式と同じ規則で期待型 `U32` として検査し、前置の `-` も書ける形に含める。`-1`、`-0`、`-(1)`、`-N` は位置によらず（配列の長さ、const 引数、遅延線の長さ、`par` の端）E0401、`0 - 1` は E0419、E0808 は値の範囲だけ（仕様 §4.5、§4.7。2026-10-08 決定。実装は W2-06（const 引数の検査。`negative/const_args.onsa:19` の期待値を E0401 に。R-154）、W5-08（定数式の文法と型）、W7-02（flow の定数式のコード））
