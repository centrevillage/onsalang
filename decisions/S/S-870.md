# S-870 具体的な型引数の `Span` を対象にする利用者の `impl Span[F32] { … }` のコード（対象の型引数の E0307 か、第二級の対象の E0710 か）

- 空白: §15.2 の 104 行は、第二級の型 `Span[T]` を対象にする固有の `impl` を std だけに許し、std の外では E0710 とする。§6.2 と S-137 は、`impl` の対象の型引数が `impl` の型パラメータでなければ E0307 とする。
  具体的な型引数の `Span` を対象にする利用者の `impl Span[F32] { … }` は両方に当たり、どちらのコードかを書いていない。`97c584a9` では E0307（「`F32` is not a parameter of the impl」。再現は `target/notes/109/w502u5b/probe/impl_span_f32.onsa`）。
  同じく `impl[T] Span[T]`（`T` が Copy と限らない）は、§4.5 の `Span` の要素の E0416 と E0710 のどちらかが決まらない。
  読み: (1) 対象の型引数の規則が先で E0307（今のまま）。(2) 第二級の対象の E0710 が先。(3) §18.1 の単位の規則（段、次に位置）で決める。
  急ぎ: 後の段（どの読みでも誤りのプログラムのコードだけが違う）
