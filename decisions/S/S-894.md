# S-894 期待する関数型と引数の数が違う無名関数の診断のコード（E0401 か E0412）

- 空白: §8.1 は関数型の互換の規則を「引数と返り値の型が等しい」などと並べ、「これらに反する使い方は全て E0401」とする。§4.5 は型引数の数の E0412 を「関数の引数の数と同じコード」とする。
  期待する関数型と引数の数が違う無名関数は、今は E0412（`check_closure` の「this function takes 2 parameter(s) but 1 are expected here」。M2 からの形で、決定と事例が無い）で、同じ位置の項目は E0401 である。`apply(two, 2)`（`two` は引数 2 個の項目）は E0401、`apply(fn(k: U32, m: U32) -> U32 { k }, 2)` は E0412、注釈の位置の `let f: fn(U32) -> U32 = fn(k: U32, m: U32) -> U32 { k }` も E0412。
  再現は `target/notes/114/s894/n1.onsa`（`01aff7bf`）。読み: (1) 関数型の不一致なので E0401（§8.1 の字のとおり、項目と揃う）。(2) 引数の数の誤りなので E0412（今のまま）。
  急ぎ: 次の作業の前（U1 は `check_closure` の同じ所に候補を足す。読みが (1) なら同じ単位で直す）
- 決定: 決定（2026-11-05、利用者が ID を挙げて了承。114 回目）: (1)。期待する関数型と引数の数が違う無名関数は E0401 で、同じ位置の項目と揃える（§8.1 の「これらに反する使い方は全て E0401」）。引数の位置と注釈の位置の両方に当たる。候補は出さない（S-872 の候補は引数の数が一致する形だけ）。
  呼び出しの引数の数の誤りは E0412 のまま（§4.5）。作業は W5-03 の U1 の直し（`check_closure` の一か所）。仕様 §8.1
- 経緯: 114 回目（2026-11-05）、W5-03 U1/t（onsa-test）が NEW として挙げた。親が `01aff7bf` のバイナリで項目と無名関数の違いを再現した。関係: S-872、S-103
