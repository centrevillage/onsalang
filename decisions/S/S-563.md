# S-563 イベントのクロックの値と他のクロックの値を混ぜる規則

- 空白: §19.1 は「イベントのクロックの値と他のクロックの値を混ぜる規則」を入れるときに決めることに挙げる。今の規則は、遅いクロックの値を速いクロックで使うのは値を変えない（保持、§11.3）。決めること:
  1. イベントの値を `sample` の式で読む形（最後の値を保つか、`Option` か、誤りか）。
  2. `sample`・`block`・`init` の値をイベントのクロックの式で読む形（その位置の値）。
  3. イベントと信号の変換を std の flow で書く方針（`genv~`、`detect_zero~` など、§19.1）と、言語が持つ変換の境界。
