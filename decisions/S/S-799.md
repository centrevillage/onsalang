# S-799 引数に置いたブロック式の中の代入（`fn2(b, { o = None\n 1 })`、`b` は `o` から派生した借用束縛）

- 空白: §3.5 の 161 行は「代入は文なので引数の中に現れず」とするが、引数にブロック式を書けば、その中に代入を書ける。S-193 は他の引数の中の `inout` と `!` を E0702 の窓（引数の評価の始まりから呼び出しの終わりまで）に入れるが、引数の中のブロックの代入に触れない。
  `match o { Some(b) => fn2(b, { o = None
 1 }), None => 0 }`（`b` は `o` から派生した借用束縛）は、dev（`9804880`）でも W4-07 U3b の新しい modes でも通る。呼び出しの前に `o` の記憶域が破棄され、`b` が破棄済みの記憶域を指しうる。再現は `target/notes/87/s796/p2_pass.onsa` の `blk`。
  読み: (1) S-193 の「他の引数の中の変更」に、引数の中のブロックの代入（と `inout`・`!`）を含めて E0702（窓は同じ）。(2) §3.5 の 161 行を改め、引数の中の代入は §7 の変更として左から数える（後の引数と呼び出しの借用の引数で E0704）。
  急ぎ: W4-08（場所の重なりの関数、S-193）の前。
