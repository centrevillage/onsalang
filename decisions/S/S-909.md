# S-909 数の trait の境界の `T.default()`（`T: Num` の型パラメータ）

- 空白: §6.3 の `AnyNum` の項は `Copy` `Add` `Sub` `Mul` `Div` `Rem` `PartialEq` `PartialOrd` と `ZERO` を挙げ、`Default` は入っていない（`Num`・`Float`・`Int`・`Unsigned` も同じ）。組込みの数の型の行は `Default` を別に持つ。
  したがって `fn f[T: Num]() -> T { T.default() }` は、`T: Default` が無いので見つからない名前（今の E0302）と読める。
  確かめるのは `AnyNum` に `Default` を足さないことである。足すと、利用者の数の型（`impl AnyNum for Q15`、§6.3。手書きは第 2 期）が `Default` も実装することになる。0 が要るコードには `T.ZERO` がある（`AnyNum` の項目）。親の読み: E0302 のままで、書くなら `T: Num + Default`。S-906 の `Show` と同じ見方である。
