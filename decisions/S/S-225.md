# S-225 補間を含む文字列のパターン

- 空白: 補間を含む文字列のパターン（`"a{x}b" =>`）のコード。R-03 はエラーにすると決めたが、コードが仕様に無い（`Str` は第 2 期）。W2-06/t で見つけた（2026-10-08）
- 提案: (a)。E0020（修正候補はガードの形 `v if v == "a{x}b"`）で、構文の段で出す。補間する名前が全て定数でも同じ。`{{` と `}}` だけの文字列は書ける（仕様 §7、§18.1。2026-10-08 決定。実装は W3-07（検出）と W3-15（規則の表の行）。W2-06 の範囲から外した）。改め（2026-10-09、S-319）: 補間を含む文字列も構文の段のガードの形の一つの形に入り、選択の枝の規則は S-317 と同じ
