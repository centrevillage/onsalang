# S-1089 2^24 の上限の読みとコード（入れ子の比の積か、各クロックの一番外の `sample` との比か）

- 決定済みで戻さないもの: N の型・値・コード（`U32`、2 以上の 2 のべき乗、E0808・E0401・E0408・E0417。S-1077・S-969・S-1078）。上限の数 2^24（S-566 の A4）。上りを下りが包む連鎖は塊の読み（S-1207）。
  下書きの全文（「出所」「形の表」18 行、他言語）は `target/notes/175/g116/draft.md`、伏せた版は `blind.md`、入力は `probe/`・`cases/`・`given/`、段 1 の票と報告は `stage1_ticket.md`・`stage1_report.md`、段 1 の入力は `adv/`。
- 論点: §11.9「入れ子の比の積は 2^24 以内（flow をまたぐので降下で確かめる）」が何の量か（N の積か、各クロックの正味の比か）、遅い側・連鎖の途中・flow をまたぐ入れ子・式とポートの導くクロックを数えるか、検査の段で見るか降下で見るか、コードと位置。上限の理由の字は仕様にも決定にも無い（候補: `.up~` の一つの位置の走りの数と集めて配る配列の長さ、§14.2 の容量の 64 ビットの式の A、位相のカウンタ、`F32` の整数）。
- 今の実装: `check` は形の表の 1〜17 を全て通す。降下は W7-09 の Core の門で E0200。検査の仮は連鎖の比の和が 2^63 を超える形だけを最後の修飾子の E0808 にする（`crates/onsa_sema/src/flow/check.rs` の `SPEC-GAP(S-1089)`）。参照評価器の仮は正味の比の指数の絶対値が 24 を超える形を `Unavailable`（`rate.rs` の `MOST_RATIO`）。
- 案: (a) 経路の全ての `.down~`・`.up~` の N の積（向きによらず掛ける。式とポートの導くクロックの N は数えない）、(a′) (a) に式とポートの N も掛ける、(b) 各インスタンスの本体の正味の比が 2^−24〜2^24、(b′) 全ての周期のクロックの一番外の `sample` との比、(c) 符号付きの積で上側だけ、(z) 表せる範囲（2^63）だけ。確かめる段は (α) flow の検査の段（どの flow もその本体を一番外として見る）か (β) 降下。
- 他言語: Pure Data の `block~` は 2 のべき乗でなければ実行時に 1 に戻し、比の上限の検査は無い（`src/d_ugen.c`）。Max の `poly~`・Cmajor・Faust の比の上限は未確認。
- 推奨と理由: (a) ＋ (α) ＋ E0808（下書きと段 1 が一致。確度 中〜高）。上限に頼る所（一つの位置の走りの数、集めて配る配列、§14.2 の A）は N の積でだけ抑えられる（各インスタンスの比が ±24 の内でも、flow をまたぐ三段の `.up~(2^24)` は一つの刻みに 2^48 回走る、段 1 の d03）。積は経路で単調に増えるので、flow ごとに本体から見るだけで根から見たときと同じプログラムを誤りにし、`onsa check` で出る。一番厳しく他の案を含むので、後で緩めても通っていたものは止まらない。仮の 2^63 の歯止めと評価器の独自の上限が要らなくなる。式とポートの N を数えると 2^13 以上の FFT の枠（ポートと `.down~` の N が同じ）を止めるので数えない。
  コードと位置: E0808、修正候補は無い。位置は超えた修飾子の名前（連鎖一つの中で超えれば、書いた順に掛けて初めて超えた修飾子、flow をまたいで超えれば包む側の連鎖の修飾子）で、note に経路を示す。中の flow が単独で超えるときは中の flow にだけ出し、包む側には連鎖させない。細部（note の文面、同じ連鎖で二つ以上が超えるときの一つ目）は W7-16 の票で決める。
  S-566 の A4 の「flow をまたぐので降下で確かめる」は、意味の理由でなく実装の段の見込みだったので、(α) に改める（E0817 も宣言をまたぐ検査の先例）。総称の flow（N が const 引数で決まる形、今は無い）が入ったら、その形だけ具体化の時に見る。
- 影響: 仕様 §11.9 の一文（「一番外の本体からインスタンスまでの経路にある `.down~`・`.up~` の N を、向きによらず全て掛けた積は 2^24 以内である（flow をまたいで数える。`x.up~(8192).down~(8192)` も 2^26 で誤り。導くクロックと変換の flow の入出力の N は数えない）。超えると E0808 で、flow の検査の段で、どの flow もその本体を一番外として確かめる」）、§14.2 の A の句（「経路の `.up~` の N の積（§11.9 の上限で 2^24 以下）」）。`tasks/diag-codes.md` の E0808 の行。今の `tests/`・`examples/`・std で変わる事例は無い（通る N は 1024 まで）。Rust のテスト: `crates/onsa_sema/src/flow/clocks/tests.rs` の `a_chain_past_the_ratios_a_clock_names_is_e0808_and_quiet`（文面と三つ目の形）、`crates/onsa_tests/src/flow_ref/conversion_tests.rs` の三段の入れ子のテスト（検査の E0808 になる）。作業は W7-16（2^24 の確かめを検査の段の歩きに。W7-16 の段の入口の表の歩きと同じ所）。
- 独立のレビュー: 段 1（onsa-advisor、伏せた版から）は (a) ＋ (α) ＋ E0808 を選んだ（確度 中〜高）。位置は「書いた順に掛けて初めて超えた修飾子」を推し、今の仮（いつも最後の修飾子）との差は `.down~(2^31)` を三つ連ねた類だけの細部とした。S-1207 が正味の比なら緩い形 (a″) が候補になるとしたが、S-1207 は塊の読みに決まったので当たらない。段 2 は一致のため省いた。
