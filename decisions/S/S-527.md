# S-527

- 空白: `let` の属性と `let` の間の改行の除去（`spec/tools.md` §3.2「`let` の属性（`@mem(bulk)`）は `let` と同じ行に置く（間に行末のコメントがあるときを除く）」）で、間に単独の行のコメントがある形と、属性の引数を複数行に書いた形を書かない。
  前者（`@mem(bulk)` 改行 `// c` 改行 `let`）は、今の fmt（U3c）が改行を残す（コメントを書かれた行に残す §3.4 と、`let` をコメントの前へ寄せない S-497 の (β) の読み）。後者（`@mem(` 改行 `bulk` 改行 `)` 改行 `let d = …`）は、ブロック形の閉じ括弧の行に `let` が付き `) let d = …` になる。
  W3-11/b（U3c）が見つけた（2026-10-14）
- 提案: 仮の扱い: 今の実装のまま。後の段
- 時期: W3
- 決定: 決定（2026-11-09、利用者。128 回目、共通の規則 S-965 と利用者の判断 B1〜B8、`target/notes/128/r58/decisions.md`）: （出所: R12）`let` の属性は、出力で属性が 1 行で、間にコメントが無いときだけ `let` と同じ行に置く。間にコメント（行末のコメントか、コメントだけの行）があるときと、属性が複数行（引数の並びがブロック形か継続形）のときは、`let` を属性と同じ字下げの次の行に置く。
  - 仕様の節: `spec/tools.md` §3.2 の属性の項。
  - 今通るプログラムが変わるか: 変わらない。fmt の出力が一つ変わる（`@mem(` 改行 `bulk` 改行 `)` 改行 `let d = …` は今 `) let d = …`、案では `)` 改行 `let d = …`）。コメントだけの行を挟む形は今のまま。
  - 実装の見当: `onsa_syntax/src/fmt/print.rs` の `let` の属性の改行を除く所に、属性が複数行かの条件を足す（約 5〜15 行）と事例。
  - ぶつかる既存の事例: なし（`tests/spec/fmt/` に複数行の `@mem(` は無い）。
