# S-632 族: @param・@host・@latency の責任範囲

- 空白: §6.5 は `@param`・`@host`・`@latency` を「UI とホストのための情報」とし、ターゲットに固有の事情が関わらない段までの解釈を変えないとする（S-624）が、どの段がこれらの情報を持ち、使い、誤りを出すかを書かない。
  §11.6 の `params_default()`・`latency()` はターゲットを選ばない段の Onsa のコードに属性の値を見せ（S-625）、`@host` と `@latency` の場所と値の誤りの段も決まっていない（S-588）。族の規則を一つ決め、S-625 と S-588 をそこから決める。
- 決定:
- 経緯: 60 回目（2026-10-24）、同じ族の未決の S が二つ（S-625・S-588）なので族の規則の S として登録した。族と整理する範囲は S-625 の経緯（59 回目、利用者が了承）。
