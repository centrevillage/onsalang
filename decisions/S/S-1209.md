# S-1209 `when~`・`reset_if~` を上りを下りが包む連鎖（塊の読み）や `.down~` と交ぜた形の意味（§11.10 の「合成したレートで動く部品」の読みと、名前の flow で包むのと同じ読みで割れる）

- 空白: S-1207（上りを下りが包む連鎖は塊の読み、各修飾子は左の全体を一つの部品として包む）の後、`when~`・`reset_if~` を連鎖に交ぜた形の意味が §11.10 の字から一つに決まらない。
  §11.10 は「x は、連鎖のレート R（…連鎖の `.down~`・`.up~` を当てたもの）の刻みのうち、`c` が真の刻みだけで動く」「`when~`・`reset_if~` はレートを変えないので、`x.when~(c).down~(4)` と `x.down~(4).when~(c)` は同じ意味である。止めた刻みの 4 回に 1 回で動かすのは、名前の flow で包む（`slow~(r).when~(c)`）」とする（S-567 の P4・P5: 条件は連鎖のレートに合わせる）。
  読みが割れる形: (1) `x.down~(4).when~(c)` で `c` がパラメータの種類（最初の 6 サンプルだけ偽）のとき、「合成したレートで動く部品を止める」読み（§11.10 の字）では x は位置 8・12・…、「名前の flow で包むのと同じ」読みでは 6・10・… で動く（周期の条件は真の区間が格子に揃うので同じ）。
  (2) `x.up~(2).down~(2).when~(c)`（塊と交ぜた形）で、条件を境界で集めて走りごとに止めるか、塊を一つの部品として塊の機械ごと止めるか（`c` が真偽を交互に取ると、走る回数と位置が違う）。`reset_if~` も同じ（集めた輪を戻すか）。
  読み: (a) §11.10 の字のまま（`when~`・`reset_if~` は合成したレートの刻みを止め、`.down~`・`.up~` と入れ替えられる。塊と交ぜた形の規則だけを足す）、(b) 名前の flow で包むのと同じ（§11.10 の入れ替えの文と「名前の flow で包む」の文を消し、P5 の条件のクロックを改める。通るプログラムが変わる）。
  今は `when~`・`reset_if~` を交ぜた連鎖は E0200（W7-10 まで）で、W7-16・W7-21 は走らせない。計画の `PlanNode::chain` は書いた順を持つので、どちらでも W7-21 の境界の列は作り直さない見込み。
  急ぎ: W7-10 の設計メモの前に利用者が決める（S-1207 の利用者の理由「up / down が独立した flow modulator」の範囲が `when~`・`reset_if~` にも及ぶかの判断）。
- 決定: 決定（2026-11-23、利用者。179 回目）: (e) と `reset_if~` の (R-W)。各修飾子は左の全体を一つの部品として包み（S-1207）、`when~`・`reset_if~` は条件を読むクロック W で条件を読む。
  W は受け手の出力のクロックが修飾子の位置のクロック P より遅い周期ならその出力のクロック、そうでなければ P。`when~` は W の刻みで読んで真なら次の W の刻みまで動かし、出力のクロックは変わらない。`reset_if~` のパラメータの条件も W の刻みで、W より速い周期の条件は E0815（内でも外でも。NEW-1）。
  帰結: 頭の入出力が本体の `sample` なら `x.when~(c).down~(4)` と `x.down~(4).when~(c)` は同じ意味（集めるか配る頭では外の `when~` が境界ごと止める）。変換の flow の受け手も出力の格子で読む（S-567 の U-4 (i)・C2 の読みを改める）。
  C1 とその続きの利用者の答え（イベントは受け手のレートの次の格子で反映）は保つ。`when~` が W で読んだ結果は `reset_if~` で戻らない。字は §11.10・§11.9・§11.4・§19.1（`target/notes/179/g117/spec_text.md`）。
  利用者の理由: 「LLMにとって書きやすく、人間にとって読みやすいことが求められます。監理のしやすさと内部実装の統一性はその上で更に求めるものです。そうすると、whenの位置で意味が変わるのは直感に反する挙動で、避けるべき」「reset_if は when と組み合わせる使い方が多いので、評価タイミングが違うと問題が起きそうです」。条件: 「実装が収束しないとなったら考え直す」（W7-10）。混乱しうる使い方の警告は §19.1。
