# S-326

- 空白: 他言語の経路の中の型引数（`Buf::<F32>::zeroed(4)`、`Vec::<u8>::new()`）が、経路の `::` と `::<…>` を合わせて一つの構文の形（S-248）か、二つの誤りか。S-248 と S-239 は `::[…]` の前後の経路の `::` を一つの形とした（`Buf::[F32]::zeroed(4)` は一つ）が、`::<…>` が経路の中にある形を書いていない。W3-19/t で見つけた（2026-10-09）
- 提案: 決定（2026-10-09、利用者。親の案（一つの形）を退けた）: 経路の中の他言語の型引数（`Buf::<F32>::zeroed(4)`）は、`::<…>` の形と、その後の経路の `::` の形の二つの誤りとする。理由（利用者）: 一度に指摘するのは一つの誤りの箇所という原則（S-259）に従えば分けて問題なく、一緒にするとここだけ特別な規則になる。
  報告は位置の順で `::<F32>`（候補 `::[F32]`）が先、当てると経路の `::`（候補 `.zeroed`）が出る。S-248 の「経路の形は `::[` と `::<` の前で終わる」（S-239）のまま。実装は W3-19（`SPEC-GAP(S-326)` を外す）
- 時期: W3
