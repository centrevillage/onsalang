# S-1113 引数に書いた `if`・`match`・ブロックの末尾の view の場所（`two_s(if c { x } else { y }, inout x)`）を、同じ呼び出しの `inout` との E0702 に数えるか

- 空白: §5.2 は「`inout` と借用の両方に渡すと（`h(x, inout x)`）エラー（E0702）。借用の引数は、呼び出し中は変更されないと約束しているからである」とし、§5.2 の同じ節は「ブロックの末尾の式（`if` と `match` の腕、ブロック式の末尾）は、そのブロックが置かれた位置を継ぐ」とする。借用の引数の位置に置いた `if`・`match`・ブロックの末尾の場所を、同じ呼び出しの `inout` の場所との重なりに数えるかを書いていない。
  今は数えない（`if`・`match`・ブロックの末尾で選んだ `Span` と平面の配列が、同じ呼び出しの `inout` と重なっても通る）。括弧（`two_s((x), inout x)`）は E0702。
  W7-12 U2b で、借用の生成型 `In` の struct リテラルを末尾に置く形（`put_in(if c { pair.In { l: x, r: y } } else { … }, inout pair.Out { l: z, r: x })`）も同じく通るようになった（U2b の前は別の理由の E0401）。
  呼び先は、借用で受けた view の読みと、`inout` で受けた同じ場所の書き込みを重ねられる（§5.2 の約束が破れる）。束縛の見出しでは、各末尾の場所を行の派生元に数える（S-604、S-796 の `match o { Some(b) => f(b, inout o) }` は E0702）。
  読み: (1) 借用の引数の末尾の場所の全てを重なりに数え、`two_s(if c { x } else { y }, inout x)` を E0702 にする（46 行の「位置を継ぐ」と 72 行の字のとおり。束縛の見出しの S-604 と同じ読み）。今通るプログラムのうち、末尾で `inout` と同じ場所を選ぶものが誤りになる。(2) 今の実装のまま数えず、§5.2 に「引数の末尾は重なりに数えない」と書く（借用の引数は変更されないという約束に例外ができる）。
  再現は `target/notes/160/w712/u2b/b/c6/`（`span_if_tail_vs_inout`・`span_block_vs_inout`・`span_match_vs_inout`・`planar_if_tail_vs_inout`、どれも今は通る）と `c5/`（生成型のリテラルの形）。
  急ぎ: W7-12 の終わりの前（`modes/exclusive.rs::arg_places` を U2b が触った）。
- 決定（2026-11-17、利用者、161 回目）: (1) E0702。借用の引数に置いた `if`・`match`・ブロック式の各末尾の場所を、その引数の場所として、同じ呼び出しの他の引数との重なりに数える（実行されない腕も、末尾の中の末尾も）。
  末尾が平面の配列リテラル（§5.3、S-196）か引数の位置の生成型の struct リテラル（W7-12 U2b）なら、その要素の場所である（`two_pl(if c { [x, y] } else { [y, y] }, inout x)` も E0702）。印を書かずに `move` の引数へ複製して渡す Dup の値も、§5.2 のとおり借用の引数と同じ読みとして数える。仕様 §5.2。
  理由: §5.2 の「位置を継ぐ」と「借用の引数は、呼び出し中は変更されないと約束」の字のとおりで、束縛の見出しの末尾（S-604、S-796）と同じ読みになる。(2) は借用の引数の約束に例外を作る。括弧（`two_s((x), inout x)`）は前から E0702 で、末尾だけが外れていた。
  今の挙動（161 回目に U2b の最後のバイナリで確かめた）: `move` の引数の Affine の末尾（`hm(inout a, if c { move a } else { move b })`）は腕の中の移しとして前から E0702、`inout` の位置の `if` は E0415 なので、変わるのは借用の引数（Copy の値も Affine の値も）と Dup の複製の末尾だけである。
  帰結: 今通る、末尾で同じ呼び出しの `inout` と重なる場所を選ぶプログラムが E0702 になる。一行の検索で当たる今の事例は無い（全数は単位の票の前に確かめる）。実装は W7-12 の U3 の前の小さな単位で、`modes/exclusive.rs::arg_places`（W7-12 の `持ち越し`）。
- 経緯: 160 回目（2026-11-16）、W7-12 U2b の壊す側（onsa-break）が M2（中）と NEW で挙げ、親が登録した。`Span` では前から。161 回目（2026-11-17）、利用者が (1) を選んだ（段 1 は回さない）。
