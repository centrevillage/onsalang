- 決定（2026-11-17、利用者「1&2: OK。必要になったら考えるで良いと思います」、163 回目）: 第 109 組の下書きの (c) を入出力に広げ、本体に入る関数値も同じ S で閉じる（段 1 の形）。
  flow の入出力の値型（`init`・`block`・`sample`・イベントの入力と、全ての出力）は、クロックと `@export` によらず関数型を含まない（E0810）。含むかは型の構造で決める: 関数型そのもの、配列・タプルの要素、struct のフィールド（`priv` も）、enum の列挙子の要素、型引数、別名の中（長さ 0 の配列の要素型も）。
  flow の本体の式（部分式を含む）の型も関数型を含まない（E0810、flow の検査の段）。入力でない道（`const` の関数値、関数型を含む型を返す `rt fn` の呼び出し、そのフィールド、遅延と巻き上げの値）も当たる。呼び出しの呼び先に書いた名前は値でないので当たらない。項目を値に書く形と `.(` は今のまま名前の段の E0806 が先に出る。
  flow は関数値を受け取らず、返さず、状態に持たない。§12.5・§13.2 の「flow の中に関数値が無い」は flow の本体について真になり、呼んだ `rt fn` の中の関数値は S-915 に残る。イベントの値の型（S-560 の「Copy だけ」）もこの一句で狭める。仕様 §11.2・§11.3・§11.11。
  細部（段 1 の細部 2〜7、親の仮の扱い。W7 の区切りで確認だけ）: 入出力の E0810 の位置は入出力の型の全体で、Copy の判定の後、`sample` の境界の形の前に見る（一つの入出力に E0810 は一つ）。note は関数型のある経路（`Pt` の `cb`）と規則の一行で、修正候補は無い。
    この E0810 の入力は誤りの型にし、生成する `Config`・`Params` を使う所と、その入力の `@param` の E0809（値型と、export の `block` の入力の `@param` の必須）を出さない（S-1068 の E0416 の入力と同じ）。
    本体の E0810 の位置と、入れ子の式で一つにまとめる範囲は W7-14 の設計で決める。S-367 の E0020 の修正候補は変えない（当てた後の E0810 は §18.1 の約束の内）。`.(` の E0806（呼び先が値）に固定の note「flow は関数値を持たない。選ぶなら enum と `match`」を足す。
  理由: 関数型の入力の使い道は、本体で `.(` が書けないので `rt fn` に包んで渡す回り道だけで、規則が言わない。状態に関数へのポインタが入り、ホットリロード（§18.3）で前のコードを指したまま残る（§19.1 の「状態からポインタを無くす」向き、§12.4 のポインタの幅の文と合わない）。
    認めると W8-09（`Config`・`Params` の関数型のフィールドの降下と `onsa test` の与え方）、W10-02・W10-03（C の関数へのポインタの型、ホストの関数の `rt` と効果行を検査できない問題）、第 2 期の JS・WASM の境界で手当てが続く。閉じれば一つの検査で収束する。
    入力だけ閉じると、`apply(dbl, x)` が E0806 で `const F … = dbl` の `apply(F, x)` が通り、同じ値で結果が分かれ、`apply(pick(c), x)` の巻き上げの値が状態に関数へのポインタを置く。`let` だけ閉じる (d) は §11.3 の「`let` に分けても分けなくても同じ」と食い違う。
    代わりの書き方: 閉じた選択は enum と `match` を持つ `rt fn`（今 `onsa test` まで通る）、開いた選択は fn の側で作った表（`[F32; 256] at init`）、将来は §19.1 のコンパイル時に展開する flow の高階。
  開く向き（関数型の入力を認める）は、必要になったら考える（利用者）。閉じてから開くのは検査を外して負の事例を反転するだけで、通るプログラムを壊さない。総称の flow を入れるときは、型パラメータの入力にこの規則を課す場所を決める（§19.1）。
  帰結: 今 `check` を通る関数型を含む入出力と、本体の関数型の値の形が E0810 になる。実行と C のビルドは今も E0200（W8-09）なので、動いていたプログラムは無い。リポジトリの事例・examples・std で期待が変わるものは見つからない（関数値の `const` と関数を返す fn は fn の本体でだけ使われる）。
  実装は、入出力が W7-13 U3、本体が W7-14。
