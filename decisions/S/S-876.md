# S-876 E0503 の削除の候補が、前の文の型変数を決めていた到達しない文を消し、当てた後に同じ型の段の E0406・E0405 が残る形（`let o = None` / `return 1` / `let z: Option[I32] = o`）

- 空白: §7 の E0503 の候補は到達しない文を消す。到達しない文は型の検査を受けない（S-268: E0503 は関数の終わりの検査より先）。消す前のプログラムで、前の文の型変数（`let o = None` の `T`、`var acc = 0.0` の浮動小数のリテラル、`let xs = []`）を決めていたのが到達しない文だけなら、当てた後の関数の終わりの検査が E0406・E0405 を出す。
  これらは E0503 と同じ型の段なので、§18.1 の候補の約束（S-236）に当たり、その候補は出せない。どう判定して出さないか（または別の候補にするか）を仕様と計画が書いていない。
  読み: (a) 到達しない文を飛ばして単位の残りと関数の終わりの検査を続け、同じ段の誤りが出れば候補を出さない。(b) E0503 を見つけた時点で、整数のリテラル以外の型変数か後回しの検査の項目が残っていれば候補を出さない（安全側）。(c) 消す編集に型の注釈を足す。(d) この候補に限り約束の例外にする。
  今（`dd4e4e97`）は E0503 が無い。消す前の形 `decisions/S/S-876/typeinfo_before.onsa` は `z` の E0309 だけで、消した後の形 `typeinfo_after.onsa` は `None` に E0406、`var acc = 0.0` に E0405、`let xs = []` に E0406。
  W5-09 の到達しない腕（S-187）の候補にも同じ形がある。
  急ぎ: W5-08 の前（E0503 の候補を入れる単位）
- 決定: 決定（2026-11-04、利用者。110 回目、第 81 組。下書きと独立のレビューの段 1・段 2 が一致し、段 1 が判定の形を改めた。(A) の確認だけ）: (b)。E0503 の消す候補は、当てた後に同じ型の段の誤り（E0406・E0405・E0416 など）が出る形では出さない（§18.1 の当てはめ。§7 に一文）。
  判定（W5-08・W5-09 の設計の細部）: E0503 は到達しない文を検査する前に出し、その時点で関数の終わりの解決（整数の既定を当てて後回しの項目と開いた変数を見る）を報告せずに走らせ、何も出なければ候補を出す（探り）。内側のブロックで後の到達する文が型を決める形は候補なし（安全側）。W5-09 の腕は、腕の本体を検査する前に E0503 を出して同じ探りを当てる。
  下書きは `S-876.draft.md`。仕様 §7、`tasks/diag-codes.md` の E0503
