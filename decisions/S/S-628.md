# S-628 `[package] name = "std"` の診断のコード

- 空白: §15.3 の表は `[package]` の `name` に「`std` は書けない」とするが、書いたときのコード（パッケージ名の形の E1103、ルート直下の名前が依存と重なる E0304、別のコード）を書いていない。今の実装は診断 0 件で通る。
- 決定: 決定（2026-11-01、利用者が ID を挙げて了承。95 回目、第 77 組）: S-827 から。値 `"std"` に E1103（パッケージ名の形、全てのコマンドのマニフェストの検査、終了コード 2）。候補は出さず、note で `std` が埋め込みの標準ライブラリの名前であることを示す。`tasks/diag-codes.md` の E1103 の行
