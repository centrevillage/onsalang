# S-815 flow の外の `~` の呼び出しで呼び先を引くか（`nope~(x)`、`g~(x)`、`x.prev~(0.5)`）

- 空白: §11.1 は flow の外にインスタンスの呼び出し `f~(...)`（組込みの遅延を含む）を書く形を E0821、§11.4 は flow の外の `prev~(x)` を E0821 とする（`prev` は flow の外では見えない名前）。S-101 は E0811・E0812 を flow の本体の中だけとする。
  flow の外で、見つからない名前（`nope~(x)`）が E0302 か E0821 か、flow でない名前（`g~(x)` の `g` が関数、`x.prev~(0.5)` の `x` が値）が E0812 か E0821 かを書いていない。
  今は型の段の E0812「`~(` creates a flow instance and is only written inside a flow body」と候補「remove `~`」である。
  読み (1): 呼び先を引かずに E0821（§11.3 の flow の外の `at` がクロックの名前を引かないのと同じ）。読み (2): 呼び先を引き、見つからなければ E0302、それ以外は E0821。読み (3): (2) に加えて、flow でない名前は E0812。
