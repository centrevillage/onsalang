# S-1015 細部: 別名を自身の右辺の定数式に名前だけで書く形（`type A = [F32; A]`、`type A = Rg[F32, A]`）が E0311（別名の循環）か E0308（値でない名前）か

- 空白: §4.4 は別名の循環を E0311 とし（「別名は右辺に置き換えるので展開が終わらない」）、§4.5 は定数式に書いた値でない名前（型）を E0308 とし「書いた順によらずに引く」とする。別名を自身の右辺の定数式に名前だけで書く `type A = [F32; A]`・`type A = Rg[F32, A]` はどちらにも読める。(1) E0311: `type A = [F32; A.N]` が今 E0311 なのと揃い、グラフの規則のまま（R-440 の直しで自身への辺も張る）。(2) E0308: 名前の種類の誤りだけと読む。自身への辺だけを外す腕が要る。今はどちらでもなく終了 0 で通る（R-440）。通るプログラムは変えない（どちらも誤り）。再現は `target/notes/141/w513u2_memo/probe/self.txt` の `self_len`・`self_targ`（`self_mid` は今 E0311）。設計メモ `target/notes/141/w513u2_memo/memo.md` の 7 章。
- 決定: 決定（2026-11-13、利用者。143 回目、W5 の区切りの確認だけ。「推奨の通り」で了承）: 仮の扱いのとおり (1)。別名を自身の右辺の定数式に名前だけで書く形（`type A = [F32; A]`、`type A = Rg[F32, A]`）は、値でない名前の E0308 でなく循環の E0311（W5-13 U2b で R-440 を直した後の今の挙動）。循環に入った別名の `.N` の誤り（補い）も循環の E0311 だけ。§4.4 の E0311 の段落に足した。
- 経緯: 141 回目（2026-11-12）、W5-13 U2 の設計メモ（onsa-impl）が報告した。`rules/leader.md` 5.11 の細部として仮の扱い (1) E0311 で U2b を進め、W5 の区切りで確認だけで出す。
- 補い（2026-11-12、親）: W5-13 U2b の壊す側（141 回目）: 別名の循環に入った別名の `.N` の誤り（`type A0 = [F32; A1]`、`type A2 = [A0; 2]`、`type A1 = [F32; (A2.N)]`）は、前は `A2` の E0302、今は循環の E0311 だけ。仮の扱い (1) と同じ向き（循環が先）で、確認のときに添える。入力 `target/notes/141/w513u2b/` の壊す側の報告。
