# S-257 範囲 `a..b` の読みと、範囲の書き方

- 空白: `for` / `par` の見出しの `a..b` は終わりを含まない（§7、§11.5）が、Kotlin（`1..4` は 4 を含む）と Ruby（`1..3` は 3 を含む）の読みでは終わりを含み、検査を通って回数が一つ違う。§0.3 の規則 4（偽の友人を作らない）に当たるかを問い直す（Rust、C#、Python の `range` は含まない）。
  含む読みに改めると S-186・S-249 の候補も変わる。第 4 組の下書き（S-250、S-249）で見つけた（2026-10-08）
- 提案: 範囲の書き方は `a..<b`（終わりを含まない）と `a..=b`（終わりを含む）の二つ。`..` と `...` は E0020 で、候補は読みごとに `a..<b` と `a..=b`。`par i in a..=b` は `N = b - a + 1` で、空の範囲は `a > b`（E0808）。`for i in a..=b` は `b` が型の最大値でも溢れずに終わる降下にする（終わりを先に比べる）。
  範囲の記号は二項演算子より弱く、端は整数の型（E0401）。見出しの外の範囲は E0002 と note。
  範囲のパターン（S-249）と `@` の右（S-186）の候補は記号の読みで作る（`..<` は `lo <= k && k < hi`、`..=` は `lo <= k && k <= hi`、`..` は二つ）。`0..<n` と `0..=n - 1` が同じ反復の二つの書き方になるのは代償（(b)。推奨の (c) から利用者が改めた。仕様 §7、§11.5、§3.1、§3.5 と範囲の例。2026-10-08 決定。実装は W3-07（構文と候補）、W7-04（`par` の `..=`）、W8-03（`for` の `..=` の降下））
