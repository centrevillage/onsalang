# S-747 同じ境界の重なりと矛盾する組（`T: Copy + Copy`、`T: ?Dup + ?Dup`、`T: Dup + ?Dup`、`T: Copy + ?Dup`）の診断（今はどれも黙って通る）

- 空白: §4.5 は境界を `+` で並べるとだけ書き、同じ境界の重なり（`T: Copy + Copy`、`T: Show + Show`、`T: ?Dup + ?Dup`）と、矛盾する組（`T: Dup + ?Dup`、`T: Copy + ?Dup`）の扱いを書いていない。今はどれも診断なしで通る（再現は 79 回目の第 71 組の下書きの `probe/s711/` の `b06`・`b07`・`b08`・`c01`・`c02`・`c05`）。
  読み: 重なりを誤りにするか、`Dup + ?Dup` を矛盾として誤りにするか、どちらも通すか。
- 決定: 決定（2026-10-28、利用者。80 回目、第 72 組。細部は ID を挙げて了承）: (a)。
  同じ並びに同じ境界を二度書く形（重なり。`T: Copy + Copy`、`T: Show + Show`、`T: ?Dup + ?Dup`）と、`?Dup` を Dup を要する境界（`Dup`、`Copy`、`Num`、`Float`）と並べる形（矛盾。`T: Dup + ?Dup`、`T: Copy + ?Dup`、`T: ?Dup + Num`）は E0416（境界の誤り）。候補は出さない。
  重なりは前の同じ境界を note で示す。矛盾は相手の境界を note で示し、規則（`?Dup` は暗黙の `Dup` を外す印で、Dup を要する境界と並べると外すものが無い。Affine も受けるなら Dup を要する境界を外し、Copy だけでよいなら `?Dup` を外す）を述べる。
  矛盾は `?Dup` で示した意図と逆の要求を黙って足す（§0.5.1 の既定を誤解していることを示す書き方）。重なりは他の並びの同じ要素の重なり（同じ `use` の二度、型パラメータ、フィールド）と揃える。厳しい方から始めれば、後で緩めても既存のプログラムは壊れない。
  細部（確認だけ）: A1 位置は、並びを前から読んで前の要素と重なるか矛盾する最初の要素で、前の要素を note で示す（`Copy + ?Dup` は `?Dup`）。一つの単位で一つ（§18.1）。A2 段は S-711 の E0416 と同じ型の段。名前の段の誤り（E0302・E0308）と、未知の境界・この版で境界にできない trait（E0200）は比べに入れない。
  A3 当てる並びは fn・struct・enum・`impl` の型パラメータの全て。A4 含意で重なる形（`Ord + PartialOrd`、`Float + Num`）は誤りにしない（字面が同じでなく意味が一つ。誤りにすると含意の表が規則の出所になる）。A5 矛盾のある並びは、呼び出し側で未知の境界として読み、使う側に診断を出さない（§18.1）。A6 仕様は §4.5 の境界の並びの項に一文。
  仕様は §4.5 の境界の並びの項に書いた。`tasks/diag-codes.md` の E0416 の行に足した。
  実装は W4-05 の U4（`sig.rs::lower_generics` の境界の `match` の後に、並びの要素（境界、`?` の有無、位置）を前から比べる。約 +12〜18 行と、矛盾の並びを未知の境界にする一行。`implies` は U4 で署名の段から見えるようにする）。
  事例は重なり（`Copy + Copy`、`?Dup + ?Dup`）と矛盾（`Dup + ?Dup`、`?Dup + Copy`、`?Dup + Num`）を一つずつの単位に。`tests/review-phase1/types/bounds.onsa` の 5 行（R-37 の入力、`T: Copy + ?Dup`）は E0416 になる。
  関係: S-750（derive の一覧と効果行の重なり）は、後の組でこの答えに揃えるかを決める。S-751（暗黙の制約を書く `T: Dup`）は別の S。
