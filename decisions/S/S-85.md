# S-85

- 空白: 部分移動の禁止が仕様に無い規則（E0711「partial moves are not allowed」）で、修正候補も無い。`Drop` を実装する型の分解と、`drop` の本体の終わりの `self` の扱いが決まっていない（レビュー R-95）
- 提案: 取り出しで全体を消費する（§5.2）。modes は、Affine のフィールドの静的な経路を消費する位置で、根の束縛を移動済みにする（フィールドごとの状態は持たない）。降下は分解と同じ形（取り出すフィールドを移し、残りをその場で破棄する）にし、Core に新しい形は足さない。効果は残りの破棄から決める（残りが Copy なら `Alloc` は要らない）。
  配列の要素は E0711 のままで note に `for x in move xs`、取り出した後の使用の E0704 に取り出した位置の note。`Drop` の型の分解・取り出しの E0711 と、`drop` の本体の終わりのフィールドごとの破棄は第 2 期（計画 §5）。`tests/review-phase1/parent/r95.onsa` の期待値と今の出力は各項目の上のコメント（2026-10-05 決定。実装は第 3 段）
