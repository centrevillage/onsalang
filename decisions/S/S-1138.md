# S-1138 族: flow の状態の名前（状態の生成する名前を利用者の名前（入力と本体の `let`）とどう分けるか。予約で拒むか、生成する側を利用者の書けない形にするか）

- 空白: flow の状態の欄の名前は、利用者の名前（入力と本体の `let` の名前、§11.6 の「状態のフィールドは `let` の名前を保つ」）と、処理系が生成する名前（名前の無いノードの種類と番号 `prev_0`・`lp_0`・`par_0`、巻き上げの `hoist_0`、固定の欄 `sample_rate`・`poisoned`・`initialized`・`bulk`、後で足す位相のカウンタと遅れの値）が同じ状態の型に並ぶ。§11.6 は生成する名前と固定の名前を予約して入力と `let` に禁じ（E0304、R-48）、修飾した名前（`a.prev_0`）と `_<番号>` は §2.3 の頭の `_` と `__` の禁止で利用者の名前と分かれている。重なるのは修飾しない出力の式のノード、巻き上げ、固定の名前である（重なると今の降下は黙って誤った値か内部エラー、C は同じメンバの名前）。
  族の論点: 状態の生成する名前を利用者の名前とどう分けるか。予約で拒む（予約する範囲を決める、S-1081）か、生成する側を利用者の書けない形にする（予約を減らす、既決の表示の規則を変える）か。族の S: S-1081（種類と番号の形の予約の範囲）、S-1136（分解する `let` と束縛しない `let` のノードの名前）、S-1137（位相のカウンタと遅れの値の欄の名前）。
- 決定（2026-11-18、利用者、165 回目、第 110 組。段 1（onsa-advisor）と下書きがどちらも生成する側を書けない形にする案を選び、利用者が「名前の重複を避けるルールはシンプルで破綻の起きづらいやり方」「ルールが揃っている方が良い。余計な例外が不要」として、固定の名前と巻き上げも含めて採った）: 処理系が flow の状態に作る名前（修飾した名前、`_<番号>`、巻き上げと固定のフィールドの名前）は、どれも利用者の書けない形（`.` を含むか `_` で始まる、§2.3）にし、状態の名前の予約を無くす（入力の写しと `let` のフィールドは利用者の名前のまま）。出力の式の中のノードは `_out` で修飾する（`_out.lp_0`、`_out.par_0.saw_0`）。巻き上げの欄は種類 `_hoist`（`a._hoist_0`、`_out._hoist_0`）。固定の欄は `_sample_rate`・`_poisoned`・`_initialized`・`_bulk`。後で足す欄（位相のカウンタ、遅れの値）も同じ形（S-1137）。
  変える既決: R-98 の決定の (2) の「出力の式の中は修飾なし」、R-48 の予約、S-67 の入力の名前の予約（`sample_rate` は組込みの名前として §2.2 の E0304 のまま）、S-149 の flow の名前 `hoist` の予約（`.` を `__` にする写しと識別子の `__` の E0320 は残る）、S-33・R-97 の巻き上げの欄の名前 `hoist_<番号>`（`a._hoist_0` に）。§2.3 に頭の `_` が処理系の名前の形でもあることを書いた。通るプログラムは誤りにならない（予約が外れて入力と `let` に `poisoned`・`initialized`・`bulk`、flow に `hoist` が書けるようになる）。表示の名前が変わる。
  C の名前: `.` を `__` にする写しのまま、`_` で始まる生成する名前を `.` の後に持つ形（`a._hoist_0`、`main.f._out.par_0.State`）と末尾の `_` の名前（`a_.hoist_0`、`main.f_.out.par_0.State`）が同じ写しになる組は、処理系が重ならない C の名前を選ぶ（§14.2 の内部の名前。W8-11・W10-02）。`onsa graph` の出力の頂点も利用者の名前と重ならない名前にする（R-497）。
  仕様 §11.6・§12.4・§2.3、§17.3 の例を改めた（決定の字の監査（onsa-advisor）の後）。作業: W7-03（名前と固定の欄、予約の検査を入れない）、W7-05（巻き上げの名前）、W8-11・W10-02（C の名前）、W7-09（S-1137 の語）。
- 経緯: 165 回目、2026-11-18、第 110 組の S-1081 の下書き（onsa-gap）が族の論点として挙げ、同じ族の未決の S が三つになったので親が族の規則の S として登録した（`rules/process.md` 8.6 の空白の流れの 2）。
