# S-1138 族: flow の状態の名前（状態の生成する名前を利用者の名前（入力と本体の `let`）とどう分けるか。予約で拒むか、生成する側を利用者の書けない形にするか）

- 空白: flow の状態の欄の名前は、利用者の名前（入力と本体の `let` の名前、§11.6 の「状態のフィールドは `let` の名前を保つ」）と、処理系が生成する名前（名前の無いノードの種類と番号 `prev_0`・`lp_0`・`par_0`、巻き上げの `hoist_0`、固定の欄 `sample_rate`・`poisoned`・`initialized`・`bulk`、後で足す位相のカウンタと遅れの値）が同じ状態の型に並ぶ。§11.6 は生成する名前と固定の名前を予約して入力と `let` に禁じ（E0304、R-48）、修飾した名前（`a.prev_0`）と `_<番号>` は §2.3 の頭の `_` と `__` の禁止で利用者の名前と分かれている。重なるのは修飾しない出力の式のノード、巻き上げ、固定の名前である（重なると今の降下は黙って誤った値か内部エラー、C は同じメンバの名前）。
  族の論点: 状態の生成する名前を利用者の名前とどう分けるか。予約で拒む（予約する範囲を決める、S-1081）か、生成する側を利用者の書けない形にする（予約を減らす、既決の表示の規則を変える）か。族の S: S-1081（種類と番号の形の予約の範囲）、S-1136（分解する `let` と束縛しない `let` のノードの名前）、S-1137（位相のカウンタと遅れの値の欄の名前）。
