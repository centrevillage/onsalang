# S-318 選択のパターンの枝が束縛する名前の集合が違う形

- 論点: 仕様 §7「パターン（Rust と同じ意味のものだけ）」と、選択の項「`p | q`（式の `|` はビット和で、パターンの中では選択）」。選択の枝が束縛する名前の規則と、その誤りのコードが書かれていない。
  §7 は「`snake_case` の名前は束縛である」「束縛かどうかは字面で決まる」とし、§5.1 は見えている名前を二度束縛できない（E0304）とする。
  近い形は決まっている: ガードの形の候補は、置き換えた後に全ての枝が同じ形のときだけ作る（S-317、S-249。`Some(0.5) | Some(x)` は構文の段の E0002 で、`spec/foreign-forms.toml` の 4870 行の注記は束縛の規則をこの S に回した）。一つの枝の中の同じ名前の二度目は E0304（11 行）。

- 案:
  - (a) 名前の段の新しいコード（E03xx の空き。欠番の E0313 を除き、例えば E0314）。一つの選択の全ての枝は、同じ名前の集合を束縛する。違えば、最初の枝と集合が違う枝に、その枝に無い名前か余分な名前を示して報告する。
    候補は無く、note で「全ての枝で同じ名前を束縛するか、枝ごとに腕を分ける」と示す。同じ名前の型は全ての枝で同じ（8 行、今の E0401）。入れ子の選択（5 行）は選択ごとに当てる。
    実装: 名前の段のパターンの束縛を集める所で、枝ごとの集合を比べる（15〜25 行。W4-04 の `body/patterns.rs`）。事例: 1〜6 行の否定例（3 件以上）と、7 行の正例（`check`）。費用の要因: コードが一つ増える。
  - (b) 既にあるコードを使う。全ての枝に無い名前は束縛にならず、本体で使えば E0302（1 行）、使わなければ E0309（使われない束縛、2〜4 行）。実装: 束縛を枝の共通の集合にする（10〜15 行）。
    費用の要因: 一つの書き誤りが、本体で使うかどうかで二つのコードに分かれる。E0302 の「名前が見つからない」は、名前を書いた枝がある形では書き手の見る事実と違い、E0302 の直し方（名前を直す、`use` を足す）と違う直し方になる。
  - (c) 構文の段の E0002。束縛かどうかは字面で決まるので、構文の段で枝ごとの名前を比べ、違えば E0002 と note。実装: 構文解析器のパターンで 15〜25 行。
    費用の要因: E0002 は読めない形の一般の誤りで、読めた形の規則の誤りを混ぜる。ガードの形の E0002（S-317）とは、どちらも構文の段で枝の形を比べる点で揃う。
- 他言語:
  - rustc 1.94.1（手元、`orp.rs`）: E0408「variable `x` is not bound in all patterns」（`Some(x) | None => x` と、`(x, 0) | (0, y)` の両方の名前）。
  - Python 3.14.5（手元、`orp.py`）: 「SyntaxError: alternative patterns bind different names」（実行の前の誤り）。swiftc 6.3.1（手元、`orp.swift`）: 「'x' must be bound in every pattern」。
  - TypeScript と JavaScript にパターンの選択は無い。C#: 未確認。
- 推奨と理由: (a)。確度: 中〜高。
  - 一つの書き誤りに一つのコードで、直し方（全ての枝で束縛するか、腕を分ける）が一つに決まる。(b) は同じ書き誤りが使い方で二つのコードに分かれ、E0302 の直し方と違う。
  - 名前の段は束縛を作る所で、一つの枝の中の二度目（E0304）と同じ所で枝ごとの集合を見られる。(c) は字面で決まるので構文の段でも判定できるが、E0002 に規則の誤りを混ぜ、束縛の規則が構文の段と名前の段に分かれる。
  - 今の `check` は 1 行の形を通し、降下で E0200 になる。仕様が意味を持たない形を E0200 のままにせず、規則のコードにする（§18.1 の「仕様が拒否する規則には、全て本文にコードを書く」）。
  - 実装は W4-04 のパターンの束縛の中で 15〜25 行。第 2 期と JS / WASM には、名前の段を通った選択しか届かない。
  - あわせて決めること: 報告は単位の最初の誤り（§18.1）で、主の位置は最初の枝と集合が違う枝、位置付きの note は最初の枝のその名前。4 行の `x | y` も同じコード（枝ごとに名前が違う）。
  - あわせて決めること: 集合が同じ選択（7 行）の降下は、今の E0200 `OrPatternBindings` のまま（仕様が意味を定めていて、この版が扱えない形）。降下する作業は見当たらなかった（付録）。
