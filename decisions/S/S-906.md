# S-906 数の trait の境界の型パラメータの穴が `Show` を満たすか（`T: Num` の `"{x}"`）

- 空白: §2.4 は補間される値が `Show` を実装していることを求める。§6.3 の数の trait の項目は含む trait を一覧で挙げ、`Show` は入っていない。したがって `fn f[T: Num](x: T) -> Str uses {Alloc} { "{x}" }` は E0416 と読める（§6.3 の組込み型の表では全ての数の型が `Show` を持つので、具体的な型の穴は通る）。今の実装は穴の `Show` を見ないので通る。
  読みは一つで、確かめるのは `AnyNum` に `Show` を足さないことである。足すと、利用者の数の型（`impl AnyNum for Q15`、§6.3。手書きは第 2 期）が `Show` も実装することになる。親の読み: E0416 で、総称の数値のコードは `T: Num + Show` と書く。
- 決定: 決定（2026-11-06、利用者。117 回目、確認だけ）: 数の trait は `Show` を含まない（§6.3 の一覧のまま）。`T: Num` の穴は E0416 で、総称の数値のコードは `T: Num + Show` と書く。仕様の文は変えない。
- 経緯: 117 回目（2026-11-06）、W5-06 U1/t（onsa-test）が仕様の空白として挙げた。読みが一つなので確認だけで出す。事例は `tests/spec/derive/show_holes_number_bounds.onsa`。
