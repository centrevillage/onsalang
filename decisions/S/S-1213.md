# S-1213 パラメータの種類の値が導くクロックの `sample / N` のポートを越えるとき、刻みの間に読む値（ポートの刻みで取った値か、今の値か）

- 空白: パラメータの種類（`block` など）の値が、導くクロックの `sample / N` のポートを越える二つの形で、刻みの間のフレームに読む値を一文で決める字が無い。(a) 出力が `block` の値だけの遅い出力: `flow mark4(w: F32 at block) -> F32 at (sample / 4) { w }` を親が `mark4~(w) at sample` で読み、呼び出しごとに `w` を変える。(b) `block` の値を遅い入力へ渡す形: `flow sl(x: F32 at (sample / 4)) -> F32 at sample { x at sample }` に親が `block` の `w` を渡す。
  読み: (1) ポートの刻みで取った値（刻みの間は次の刻みまで前の値）、(2) 今の `w`（S-1196 (1) の「パラメータの種類の値だけで決まる式は、`at` で付けたクロックによらず値の決まる段で評価し、刻みで書くフィールドを作らない」をポートの向こうまで当てる）。
  関わる字: §11.10「`when~` で止まる部品の `at (sample / N)` の入力は、呼び出し側の値を、部品の中の刻みの時点で読む」（`when~` で止まる部品の規則で、`when~` の無い呼び出しには直には当たらない）、§11.3「刻みの値（組込みの遅延とインスタンスの結果、…）を一つでも読む式は、その式のクロックの段の式」「呼び出しの結果のクロックは出力の宣言のクロック…引数のクロックによらない」、§11.3 の刻みで書いて速い段が読むフィールド（入力の値を含む）、§11.6（S-1185）「ノードは自分の刻みで進み、欄はその刻みで書く」、S-1186 の #8。S-1196 は一つの本体の中の `at` の規則で、同じ式を一つの本体に書くと今の値になる（`(w at (sample / 4)) at sample` と `let x = w at (sample / 4)` の `x at sample` は今のバイナリで今の値）。
  advisor（W7-16 U5b2 の設計の審査、2026-11-22）は、呼び出し側の意味・欄・`Default` の要求が呼び先の見出しだけで決まることから字は (1) に決まると読んだ（確信 (b) 高、(a) 中〜高）。(2) にすると、(b) は子の関数が引数の種類で二通りになり、(a) は呼び出し側のクロックの推論と状態の配置が呼び先の本体に依る（手戻りが大きい: 評価器、U2c の表の Param の行、事例）。
  再現: `target/notes/176/w716/u5b2/gap1.onsa`（今は `check` 0 件、`test` は門の E0200）。どちらの形も今は E0200 なので、通るプログラムは変わらない。
  仮の扱い（決定の前）: (1)（W7-16 U5b2 の実装の形。事例 `tests/spec/flow_semantics/slow_port_values.onsa` の `param_in4`・`param_in2`、`slow_out_stage_values.onsa` の `S-1213` の注の付いた test）。急ぎ: W7-16 U6b の前に利用者へ確認（字で決まる見込みなので確認だけ）。§11.9 に一文足すかは決定のときに。
- 決定: 決定（2026-11-22、利用者。176 回目。「S-1213: OK」）: (1)。パラメータの種類の値が導くクロックの `sample / N` のポートを越えるときは、ポートの刻みで取った値を次の刻みまで保つ（(a) `block` の値だけの遅い出力は出力の刻みで取った値、(b) `block` の値を遅い入力へ渡すと部品の中の刻みの時点で読んだ値）。S-1196 (1) は一つの本体の中の `at` の規則で、ポートを越えない。仕様の字は今のまま（§11.3 の刻みの値を読む式と呼び出しの結果のクロック、刻みで書いて速い段が読むフィールド（入力の値を速い段で読むフィールドを含む）、§11.6 の S-1185 から決まる。§11.10 の `when~` で止まる部品の `at (sample / N)` の入力の規則も同じ向き）。W7-16 U5b2 の実装と事例（`slow_port_values.onsa` の `param_in4`・`param_in2`、`slow_out_stage_values.onsa`）のまま。
