# S-1236 同じイベントの値を一つの部品の二つのイベントの入力へ渡した形（`hit~(m, m)`）の、部品の中の刻みの数と順

- 空白: §11.11 は「インスタンスのその入力のクロックは引数のクロックに結び付く（同じインスタンスの別の入力は別のクロックでよく、同じクロックを二つの入力に渡してもよい）」とする。同じクロックを二つの入力に渡したとき、一つのイベントで部品の中の二つの入力のクロックが一度に刻むか、別々に二回刻むか、二回ならどの順かを書かない。
  ```
  flow hit(a: U32 at event, b: U32 at event) -> U32 at sample {
    cnt~(a).reset_if~(b != 0)
  }
  let h = hit~(m, m)
  ```
  直に書いた `cnt~(m).reset_if~(m != 0)` は、§11.10（その刻みに続く x の段の前に初期化する）から、戻してから数える。順が値に見えるのは `reset_if~` の条件とイベントの出力の順だけである（イベントの段の式は別の入力の値を混ぜられない）。
  読み: (1) 一回の刻み（部品の中でも一つのクロックとして、本体の式の順に、初期化は続く段の前）。(2) 入力の宣言の順に二回（a の刻み、次に b の刻み。宣言の順で値が変わる）。(3) 誤り（仕様の字を改める）。
  引いた字と下書き: S-567 の E2「同じクロックを二つの入力に渡してよい」。S-561「入力をまたいだ順は境界が渡す順で…順が無ければ外の flow の入力の宣言の順」。
  仮の扱い: W7-11 U2 では E0200（作らない）。
- 決定: 決定（2026-11-25、利用者。185 回目、第 119 組）: (D2)。同じクロックを二つ以上の入力に渡すと、部品はイベントごとに、その入力を宣言の順に一つずつ刻む（一度には刻まない。一つの刻みで出たイベントは、次の入力の刻みの前に済ませる）。`acc~(a).reset_if~(b != 0)` を本体に持つ `hit~(m, m)` は足してから戻し、直に書いた形は戻してから足す（同じにするには一つの入力で受ける）。仕様の字は §11.11 の引数の項。実装は W7-11 U2（値が見えるのは U2r から）。
- 経緯: 184 回目（2026-11-25）、W7-11 の設計メモが (2) と書き、値での審査が割れると挙げ（NEW-10）、親が登録した（`target/notes/184/w711/`）。
