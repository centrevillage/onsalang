# S-238 総称の `T: Int` / `T: Num` の値で、床除算と検査付きのメソッドを呼べるか

- 決定済みで戻さないもの: 具体的な型のメソッドの一覧（§3.4、S-98）。`Int` の演算子と関連定数（S-84）。`checked_neg` が符号付きだけであること（§3.4）。浮動小数に床除算が無いこと。`T.narrow_from` などの変換の項目（S-231）。

- 論点: `T: Int` の値で `x.checked_add(y)`・`x.rem_euclid(y)` を呼べるか。§6.3 は挙げず、§3.4 は「整数のメソッド」と書くので、読みが割れる。W5-05 が `T: Int` の境界を入れるので、その前に、これらを `Int` の項目にするかを決める。
  `T: Num` は浮動小数を含み、浮動小数にこれらのメソッドは無い（§3.4）。§6.3 の演算子の修正候補（数の trait に絞る形）は演算子についての規則で、メソッドには当たらない。

- 案:
  - (a) 何も足さない: これらは具体的な整数の型のメンバで、数の trait の項目でない。`T: Int` の `x.checked_add(y)` は E0413 である。§3.4 に一文足して読みを閉じる（下の「影響」）。総称のコードは演算子から書く。
    `rem_euclid` は `let r = a % b` の後に `if r < T.ZERO { if b < T.ZERO { r - b } else { r + b } } else { r }`、`checked_add` は `let r = a +% b` の後に `if (b >= T.ZERO) == (r >= a) { Some(r) } else { None }` である。
  - (b) `Int` の項目にする: `div_euclid`・`rem_euclid` と `checked_neg` を除く検査付きの 9 つ、合わせて 11 個を `Int` のメソッドにする。`T: Int` の `x.checked_add(y)` が通る。
    `checked_neg` は符号なしに無いので `Int` に置けず、総称では `T.ZERO.checked_sub(x)` と書く（`T: Num + Int` の組み合わせに項目を与える仕組みは無い）。`T: Num` は今の E0413 のままである。
  - (c) 床除算だけを `Int` の項目にする: `div_euclid`・`rem_euclid` の 2 個だけを `Int` に置き、検査付きは (a) と同じにする。添字と位相の折り返しに使う `rem_euclid` が総称で書ける。
  - (d) 別の trait に置く: 例 `CheckedInt` を §6.3 に足し、整数 8 型が実装する。総称のコードは `T: Int + CheckedInt` と書く。`Int` の項目は増えない。中身は (b) と同じ 11 個である。
  - (e) メソッドを `std.math` の総称の関数に移す: `checked_add[T: Int](a: T, b: T)`、`rem_euclid[T: Int](a: T, b: T)`、`checked_neg[T: Num + Int](x: T)` などにし、メソッドの形を外す。具体的な型と総称で書き方が一つになる。§3.4 の閉じた一覧（S-98）を改める案である。`abs`・`min` と同じ形になり、`checked_neg` は境界で表す。
