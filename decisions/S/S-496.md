# S-496 名指しされない記号と語の空白

- 空白: §3.2 の閉じた一覧が名指ししない記号と語の空白。キーワードや文脈の語の後の文字列（`extern "C" lib"m" {`、`test"x" {`）、`[e; N]` の `;`、パターンの `|`、境界の `+`、構造体のパターンの `..`、1 行のブロックの `{ a }` の内側。
  補い（W3-11/t の U2）: `{` の前（`fn f()->I32{`、`P{x: 1.0}`、`uses{Alloc}{`）と、キーワードの後の `(` の前（`if(a < 0) {`、`while(true) {`）。
  今の fmt は語の後に空白を一つ置き（`extern "C" lib "m" {`、`test "x" {`）、`; `、` | `、` + `、`, ..`、`{ a }` にし、`{` の前とキーワードの後に空白を一つ置く。持ち越し（W3-06/t2 の `lib"m"`、S-400）と W3-11/i の設計メモの G1（2026-10-13）
- 提案: 決定（2026-10-13、利用者が ID を挙げて推奨の (a) を了承。下書きと Fable が一致、第 29 組）: 一般の規則三つ（キーワードと文脈の語の前後、`{` の前、1 行の `{ }` の内側に空白一つ。効果行と `use` の並びと空の `{}` を除く）と、名指しの列に `;`・`|`・`+`・`?`・`@` を足す。揃える列が無い行末のコメントの前は空白一つ。
  出力は今の fmt と同じ。`spec/tools.md` §3.2。実装は W3-11 の U2（表の SPEC-GAP を外す）と U3
