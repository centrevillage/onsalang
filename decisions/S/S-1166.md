# S-1166 細部: at で速くした値を持つ let の名前を条件にしたとき（let g = (d != 0) at sample、if g）、条件が決まる段

- 空白: §11.3 は「条件が決まる段は、その条件を評価する段である（`at` は段を変えない）」とし、同じ節で「値は `let` に分けても分けなくても同じである」とする。`at` で速くした値を `let` に分けて条件にした形（`let g = (d != 0) at sample`、`if g { x * F32.round_from(100 / (d - 1)) } else { x }`、`d` は `block`）で、条件が決まる段が割れる。
  読みは (1) `g` は `sample` の `let` の名前で、条件は `sample` で決まり、枝は巻き上げない（S-1093: `let` はそのクロックの段で評価する）、(2) `at` は段を変えないので `g` の値は `block` で決まり、直接書いた `if (d != 0) at sample { … }` と同じく `block` の段の守り付きの欄にする、に割れる。違いは 0 フレームの呼び出しで枝の panic が起きるかと、枝を毎サンプル計算するかだけで、通るプログラムと値は変わらない。
  仮の扱い: (1)（W7-05 U2 の実装）。急ぎ: W7 の区切りで確認だけ（`rules/leader.md` 5.11）。
