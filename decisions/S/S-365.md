# S-365

- 空白: 一つの腕に `..` か `...` の範囲のパターンが二つ以上ある形（`(1..3, 5..7) =>`）の候補の数。§7 は `1..3` に二つの読みの候補を並べるとし、S-317 は一つの腕を一つの誤りとするが、組み合わせ（二つか四つか）を書かない。W3-21/i で見つけた（2026-10-09）
- 提案: 決定（2026-10-09、利用者が ID を挙げて了承。親の案）: 全ての範囲を同じ読みにした二つ。候補は書き手の言語の読みごとに並べるもので、一つの腕の中で読みが混ざる言語は無いため。仕様 §7。実装は W3-21
