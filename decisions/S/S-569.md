# S-569 外で作った係数の取り違えの注意（onsa audit）

- 空白: S-566 と S-567（第 34 組）の後、`sample_rate()` は書いた本体のレートなので、外の本体で `sample_rate()` から作った係数（フィルタの係数、時定数）を `.down~(N)`・`.up~(N)` の部品へ渡すと、レートの違う係数になる。この誤りは型とクロックの検査を通る（§19.1 のマルチレートの弱いところ、S-566 の A13）。
  1. この形を `onsa audit` などで注意として示すか、示すならどの形を拾うか（`sample_rate()` に依る値が別のレートのインスタンスの入力に渡る経路）。
  2. 誤りにしない理由と、正しい書き方（係数を部品の本体の中で作る）を note か文書のどこに書くか。
- 決定:
- 経緯: S-566 の確認だけの項目 A14 の 3（2026-10-20、48 回目、利用者が了承: 新しい S にする）から立てた。関係: S-566、S-567、S-586（同じ `onsa audit`）、§19.1 のマルチレート。
