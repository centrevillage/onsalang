# S-987 効果行変数を持つ struct・enum（`struct W[T, e]`）を型の位置でどう書くか（今は `W[I32]` が数の誤りの E0412、`W[I32, e]` が E0302 で、名指せない）

- 空白: §8.1 は `[…]` の並びの小文字で始まる名前を効果行変数とし、例は関数の `map[T, U, e]` だけである。struct・enum が効果行変数を宣言できるか、その型を型の位置でどう書くか（数に入れるか、効果行をどこに書くか）は仕様に無い。
  今の実装は宣言 `struct W[T, e] { f: fn(T) -> T uses {e} }` を通し、型の位置では効果行変数も数に入れるので、`W[I32]` は E0412「takes 2 type argument(s), 1 given」、`W[I32, e]` は `e` の E0302 で、型を名指す方法が無い（再現は `target/notes/133/s977-advisor/probe/q5.onsa`、dev `f90b68ed`）。
  式の中の型引数の数は S-982 で「数えない」と決めた。
  決めること: 効果行変数を持つ型を認めるか（認めないなら宣言の診断）、認めるなら型の位置の書き方。要る場面は、フィールドの関数値の効果を使う側に任せる部品（遅延の `map` の類）で、第 1 期には無い見込み。
- 決定:
- 経緯: 133 回目（2026-11-10）、S-982 を決めるときに、利用者が型の位置の扱いを後の段に回すことを了承し、親が登録した。
