# S-720 flow の本体で組込みの flow の名前を呼び出しでない形で書いたとき（`let f = sample_rate`、`prev * x`）の診断（§15.1 の「見つかったが要る種類でない」E0308 か、今の E0302「cannot find」か）

- 空白: §11.4 の表は組込みの flow の名前（`prev`・`delay`・`vdelay`・`sample_rate`・`sample_tick`）を呼び出しの形（`prev~(e)`、`sample_rate()`）だけで書き、§2.2 はそれらを flow の本体で見える名前とする。
  第 65 組で決めた §15.1（S-713）は「名前は見つかったが、その位置に要る種類でなければ、位置によらず E0308」とする。呼び出しでない形（`let f = sample_rate`、`prev * x`）を、見つかった名前の種類の誤り（E0308）と読むか、今の実装の E0302「cannot find … in this scope」のままにするかが決まっていない。`sample_rate` を関数の値として取り出せるか（§6.1）も書かれていない。
  今の実装（dev `65a1073` のバイナリ）: `let f = sample_rate` と `prev * x` は flow の本体で E0302「cannot find `sample_rate` in this scope」「cannot find `prev` in this scope」。fn の本体の `sample_rate()` も E0302（flow の外。別の規則の E0821 の範囲かも含めて見る）。
  再現は 75 回目の scratchpad の `w404/u2b/b/t2.onsa`（区切りで `target/notes/75/w404/u2b/b/` へ写す）。W4-04 の名前の段の記録（U2b）は、これらにも `FlowBuiltin` を置く。
- 決定: 決定（2026-10-27、利用者が ID を挙げて了承。76 回目、第 66 組。本体は利用者が選び、細部の A3・A4 は確認だけ）: (c)。flow の組込み名（`prev` `delay` `vdelay` `sample_rate` `sample_tick`）は、flow の見出しの型の位置と本体で見つかる名前で、要る種類になるのは自分の呼び出しの形の呼び先だけである。
  他の全ての位置（値、関数値の呼び先 `prev.(x)`、型、`.` の前、パターン、補間の穴、`^` の後）は E0308 で、修正候補は無く、note で呼び出しの形を示す（d1〜d3 は (i)）。flow の見出しの型の位置（`x: prev at sample`）も同じ（A4）。
  §15.1 の種類の並びと名前空間でない名前の並びに、flow の組込み名を足した（`prev.y` は名前空間でない名前の後の `.` の E0308）。
  flow の外（fn の本体、`test`、`const` の初期化式）では見えない名前なので、`sample_rate()`・`prev(1.0)`・`let f = sample_rate` は E0302 のまま（d4 は (i)）。`~` を付けた `prev~(x)` は §11.1 の E0821 のまま。
  仕様は §11.4、§15.1、`tasks/diag-codes.md` の E0308 の行に書いた。実装は W4-04 の U3b（U3a は今の E0302 を保った。本体は歩き手の `paths.rs::flow_builtin`、見出しの型の位置は `sig/types.rs`）。
- 経緯: 75 回目（2026-10-27）、W4-04 U2b/b（onsa-break）が空白の候補として報告し、親が再現した。期限は W4-04 の U3a（型付けが記録を読み、名前の段が診断を出す単位）の前。第 66 組に入れる。
