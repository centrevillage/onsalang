# S-844 枝の中の、状態を持つものを含まない `par~` を状態を持つものと数えるか（`if` の枝の E0811、`if~` の E0812）

- 空白: §11.5 は、`if` / `match` の枝とガードに書けない状態を持つものとして「インスタンス、組込みの遅延、`par~`」を挙げ（E0811）、§2.6 は状態を持つものを枝に含まない `if~` / `match~` を E0812 にする。
  一方 §11.5 は、本体に状態を持つもの（インスタンス、組込みの遅延）が無い `par~` は状態のフィールドを作らず、誤りにもしない（S-745 の決定 4）。
  本体に状態を持つものが無い `par~` を枝に書いた形（`if c { par~ i in 0 ..< 2 { x * F32.round_from(i) } } else { [x, x] }`）が E0811 か、そのような `par~` だけを枝に持つ `if~` が E0812 かを書いていない。S-745 より前の `par` でも同じだった。
  読みは (1) `par~` は本体によらず状態を持つものと数える（枝で E0811、`if~` の E0812 に当たらない） (2) 本体に状態を持つものがあるときだけ数える（枝で通り、`if~` は E0812）、に割れる。
  今の実装は、枝の中の `par` を本体によらず E0200（W7-06）にし、`if~` も E0200 なので、W7-06 までは結果が変わらない。
