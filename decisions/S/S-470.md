# S-470

- 空白: タプルの添字の先頭の 0 と他の言語の数の形（`t.01`・`t.017` は黙って添字の 1 と 17、`t.0o17`・`t.1u8` は一般の E0002）。§2.4 の「`0` そのもの以外は 0 で始めない」が添字にも当たるか。W3-05/b の単位 1 が見つけた（2026-10-13。`w305b1/repro/r6_tuple_index_leading_zero.onsa`、G-1）。親が単位 2 のバイナリで確かめた
- 提案: 後の段
- 時期: W3
- 決定: 取り下げ（2026-11-08、利用者が ID を挙げて了承。126 回目）: 同じ問いを S-508（2026-10-13）が決めた。`t.01`・`t.017` は E0020 で、修正候補は頭の 0 を外した形（一つ）。添字は数値リテラルの文法で読まないので、`t.0o17`・`t.1u8`・`t.0x1` は一般の E0002。仕様 §2.4 に書かれていて、dev の出力も同じ。S-470 を待っていた R-290 は、S-508 の規則で W5-11 U10d が直す。
