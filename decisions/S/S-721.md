# S-721 宣言がこの版の E0200 の handler の名前と、extern のブロックのメンバの名前を、他の位置に書いたとき（`let a = hh`・`fn g(x: hh)`・`c_sin(1.0)` は今は黙り、`fn k[T: hh]` は handler を trait と呼ぶ E0200）

- 空白: §15.1 の種類の並び（値、型、モジュール、関数、flow、trait、種の制約、効果、列挙子、定数）に handler が無い。S-713 は「形の全体がこの版に無いもの（`impl Tr for P`、`trait`・`effect` の宣言）は形の E0200 で、中の名前を読まない」とする。
  宣言がこの版の E0200 の handler の名前と、extern のブロックのメンバの名前を、他の位置に書いたときの扱いが書かれていない。読みは二つに割れる。(1) handler の種類を並びに足す（第 2 期の `with h` の位置が要る種類）か、値や関数と数え、extern のメンバは関数として読む。(2) 種類の並びに無い宣言の名前と、E0200 の形の中の名前は、失敗した名前として全ての位置で黙る。
  今の実装（dev `7cd8d17` のバイナリ）: `handler hh: Alloc { }` の後の `let a = hh` と `fn g(x: hh)` は黙り、`fn k[T: hh]` は E0200「user-defined traits as bounds」（handler を trait と呼ぶ）。`extern "C" lib "m" { fn c_sin(x: F64) -> F64 }` の後の `c_sin(1.0)` と `let a: c_sin = 1` は黙る。
  どれも宣言の単位の E0200 だけで、終了コード 1。
