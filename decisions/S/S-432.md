# S-432 属性と宣言の間の doc

- 空白: 属性と宣言の間の `///`（`@derive(Eq)` 改行 `/// d` 改行 `struct S {}`）。§2.1 は「`///` は直後の宣言に付く」とだけ書き、属性の後ろの位置を書かない。読みは (1) 直後の宣言に付く、(2) 属性と宣言の間には付かず E0004（候補 `//`）、(3) 付き、fmt が属性の前へ移す、に割れる。
  今は通る（親が dev の `826fc8a` で確かめた）。W3-04/i の設計メモで見つけた（2026-10-11）。
  逆の順（`/// d` 改行 `@fp(relaxed)` 改行 `fn f() {}`）も同じ回に確かめる（W3-04/t、仕様は属性を挟む形を書かない） 直し（2026-10-13、第 25 組の下書き）: 「今は通る」は W3-04 の前の挙動で、今は W3-04 の仮の扱いで E0004（候補 `//`）。
- 提案: 決定（2026-10-13、利用者が比べを見て (d) を選んだ。下書きは (d)、Fable は (c)、親は (c) から (d) に改めた。第 25 組）: 属性と宣言の間（属性の間と後ろ）の `///` は E0004 で、修正候補は doc の行を最初の属性の前（既にある `///` の並びの後ろ）へ移す一つ（続いた行は一つの誤り、S-442）。
  属性が行の頭に無いとき（flow の入力の `flow g(@param(…)`）は、改行を足して属性の直前に挿入する。間の `//` と空行は動かさない。逆の順（`///` の後の属性）は付く。仕様 §2.1。実装は W3-24（W3-08 から分けた。`docs.rs` の `before_the_attributes`）
