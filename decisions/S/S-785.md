# S-785 `Option`・`Result` の `unwrap` の受け手のモード（借用か `move self` か）

- 空白: §9 の 18 行は `Option` と `Result` のメソッドを両方の `unwrap` と `Result` の `map_err` とするが、19 行が `map_err` を `move self` と書くのに対し、`unwrap` の受け手のモードを書かない。
  読みは (1) `move self`（`map_err` と同じ。所有の Affine の場所を移し、借用の Affine の場所は E0711、Dup は複製）、(2) 借用の `self`（中身が Affine なら取り出せないので誤りで、`match move r` で書く）、(3) 中身の種で分ける。
  今は `r.unwrap()`（`r: Option[Buf[F32]]`）を同じ `r` に二度書いて、借用の引数からも `move` の引数からも通る（誤った受理）。再現は第 75 組の下書きの入力 `P86/g75/probe/forms/p19_unwrap_borrowed.onsa`・`p19b_unwrap_owned_twice.onsa`（写しは `target/notes/86/g75/`）。
  W4-07 の設計メモ（2.5）は、組込みのメソッドの受け手を `inout self`（`!`）でなければ借用として読む。
