# S-669 std の `target fn` の本体の書き方（宣言に書いた本体が、組込み型でも走るように読める）

- 空白: S-108 は、std の `target fn` に本体を持たせ、組込み型ではプリミティブ、それ以外の型では本体を使うとし、§15.2 と §13.4 はそれを宣言に本体を書く形（`pub target rt fn abs[T: Num](x: T) -> T { if x < T.ZERO { -x } else { x } }`）とする。
  この形では、組込み型では走らない本体が宣言に書かれ、std のソースを読む書き手は、全ての型で本体が走ると読みうる。`F32` の `abs(-0.0)`・`min(x, NaN)`・`min(0.0, -0.0)` は、本体の式どおりなら `-0.0`・`x`・`0.0`、§3.4 のプリミティブでは `+0.0`・`NaN`・`-0.0` で、§3.4 が定める端の場合で食い違う（整数では一致する）。
  本体をどの形で書くか（宣言に書くか、宣言と別に書くか、印を付けるか）と、プリミティブも本体も無い型で呼べるときの扱いを書いていない。決定済みで戻さないもの: S-108 の意味（組込み型はプリミティブ、それ以外の型は本体、単相化で選ぶ）と、`Float` を組込みの浮動小数に限ること。
- 決定:
- 経緯: 65 回目（2026-10-25）、第 53 組（S-629・S-661）の説明の中で、利用者が読み違いの恐れを挙げた。第 53 組の論点は本体の書き方に依るので、族（S-670）として下書きをやり直す。関係: S-108、S-629、S-661、D-07、S-69、S-208。
