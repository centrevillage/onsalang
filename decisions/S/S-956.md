# S-956 補間の穴の、10 進の数字だけでないタプルの添字（`"{t.0x1}"`・`"{t.1_}"`）は、穴の経路の形の E0001 か、式の `t.0x1` と同じ一般の E0002 か

- 空白: §2.4 の補間の段落は、穴に書けるのは名前の経路（名前と、`.` で続くフィールド・タプルの添字・修飾）だけで「式に書いたときと同じ規則で解決する」とし、書けない形（呼び出し、`[i]`、演算子、リテラル、書式）を E0001 とする。
  タプルの段落は「タプルの添字は 10 進の数字だけで書き」、S-508 は式の `t.0x1`・`t.1_` を一般の E0002 とする（数値リテラルの文法で読まない）。穴の `{t.0x1}`・`{t.1_}` がどちらに当たるかは書かれていない。
  読み: (1) 穴の経路として書けない形なので E0001「an interpolation holds a name path only」（今の出力。範囲は穴の全体）。(2) 式と同じ規則なので E0002（式の `t.0x1` と同じ）。どちらも誤りで、変わるのはコードと範囲だけ。通るプログラムは変わらない。
  再現は `pub fn h5(t: (I32, I32)) -> Str uses {Alloc} { "{t.0x1}" }`（固定のバイナリ `891862e` で E0001、2:4）。式の `t.0x1` は E0002（`expected newline or }`）。
