# S-1249 遅延の第 1 引数の中の、`^名前` に依って評価が段の終わりに回る所で読むイベントの値の時点（`^` の条件が選ぶ枝・ガード・右辺の中の名前、`^` を含む遅い刻みの部分式の中の名前）

- 空白: §11.3（S-1240）は「保存する値の残りが読むイベントの値は、`^名前` を読むものを除いて、評価が段の終わりでも、その読みを書いた位置までの最後の値」とし、「`^名前` を読むとは…その位置を選ぶ条件に `^名前` を書いたもの」を含む（S-1244）。
  (a) `^` の条件が選ぶ位置（`if` / `match` の枝、ガード、`if~` の連鎖の二つ目からの条件、`&&` / `||` の右辺）に書いたイベントの名前: 字面を合成すると段の終わりになるが、`let t = p at sample` に分けた形と値が割れ（S-1240 の理由「`let` に分けた形と同じ」とぶつかる）、条件の一句は守りの要る計算した部分式のために足したもの（185 回目の監査の中 2）。
  (b) `^` を含む遅い刻みの部分式（`prev~(((p at (sample / 4)) * 2 + ^k) at sample)`）の中のイベントの名前: 部分式は段の終わりに評価する（S-1244）が、その中の `p` の時点を言う文が無い。
  字で決まるもの（論点でない）: `if~`・`match~` の腕の中の名前（`prev~(match~ ^k { 0 => prev~(x), v => v + (p at sample) })`）は、腕が条件の位置でないので書いた位置。`if ^k > (p at sample) { … }` の条件の中の `p` も書いた位置。`^` で選ぶ束縛そのものは段の終わり（S-1245）。
  形（`p = prev~(^d)`、`d` は下の作り手、`k` は下の `let`。入力は助言の報告の列）:
  | 形 | 読み U（全て書いた位置） | 読み L（字面の合成） | 読み E（評価の時点） |
  |---|---|---|---|
  | F4 `prev~(if ^k > (p at sample) { p at sample } else { x })`（x = 4 5 7 5 8） | 0 0 0 4 5 7 | 0 0 4 5 7 5 | 0 0 4 5 5 5 |
  | F5 二つ目のガードの `p`（`match~ x { v if v > ^k => …, v if v > (p at sample) => v, … }`、x = 4 1 2 5 1） | 0 4 1 1 6 5 | 0 4 4 2 6 5 | 0 4 4 2 7 5 |
  | F1 `((p at (sample / 4)) * 2 + ^k) at sample` の部分式（刻みごと、x = 3 5 0 7） | 4 6 7 14 | 言い切らない | 4 12 7 18 |
  読み: U: `^名前` と `^` で選ぶ束縛で読む値だけが段の終わりで、他のイベントの名前の読みはどこに書いても書いた位置（規則は一文、`let` に分けた形と全て一致、例外 0）。L: (b) は書いた位置、(a) は段の終わり（例外 1）。E: 評価が段の終わりに回る所の中は段の終わり（例外 2）。
  条件が選ぶ枝の中の、イベントの段の計算した部分式（`prev~(if ^h { (p * 2) at sample } else { x })`、`h` は下の `init` の `let`）は、どの読みでも「`^名前` を読むイベントの段の部分式」で段の終わりにするか、U に含めるかを別に選ぶ（まれ）。
  同じ形は 3 つ（上のイベントの値・`^名前`・同じ位置で出す下の作り手）が重なるときだけで、今のプログラムの出力は変わらない（イベントの値は E0200 で動かない）。
  仮の扱い: 段 a のコードは、(a) は L（`late` に入れた名前を列から除く）、(b) は E（巻き上げで歩きが止まる）。参照評価器は (a) が `if~`・`match~` の腕にも当てていて字と違う（U なら要らなくなる）。値が動くのは W7-11 U2 の段 b から。

- 経緯: 186 回目（2026-11-25）、W7-11 U2 の設計の独立の審査（高 1）が (a) を、段 a の実装が (b) と `match~` の腕を挙げ、字だけを読ませた助言（onsa-advisor、`target/notes/186/reports/onsa-advisor-a41931e6048159488-001.md`）が U を推した（確信 中の上。親は先に (a) を「字で段の終わりに決まる」と読んだが、字が割れると改めた）。
