# S-531

- 空白: 1 行の形と継続形の並びの中の、コメントだけの行の字下げ。§3.2 は囲みの中身（ブロック形）と、継続した行と要素の中で改行した行の字下げを書くが、1 行の形と継続形の並びの中のコメントだけの行を書かない。
  今の fmt は、次の要素の前なら次の要素の桁（`g(a,` 改行 `  // c` 改行 `  b)` の `// c` は `b` の桁）、閉じ括弧の前なら基準の行より 1 段深い桁（`g(a, b` 改行 `// c` 改行 `)` の `// c` は `g(` の行より 1 段深い）。式の継続の途中のコメントだけの行も、次の行と同じ桁と読んでいる。
