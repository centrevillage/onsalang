# S-1003 細部: const 引数の位置の `.` の続かない `名前[a, b]`（`Ring[F32, TABLE[1, 2]]`）を型引数の並びの型として読み型の段の E0401 にするか、定数式として構文の段の E0020（`type_args_square_comma`）にするか

- 空白: §4.5 は const 引数を定数式とし、S-333 は名前の後の `,` を含む `[…]` を構文の段の E0020（`type_args_square_comma`）とする。型引数の並びの中の `名前[…]` は総称の型の形としても読め、W5-24 U6a の一つの読み（要素の頭の先読みで、後ろに式が続かない名前の経路は型として読む）では型として読まれる。どちらで報告するかを仕様の字は書かない。
  W5-24 U6a の後（dev `ed635d6f`）は型として読み、型の段の E0401「a `const` parameter expects an integer literal or a constant, not a type」（`Ring[F32, TABLE[1, 2]]`）。後ろに演算の続く形（`TABLE[1, 2] * 2`、`2 + TABLE[1, 2]`）は定数式として読み、E0020（事例 `type_args_const_arg_square_comma.onsa`）。
  仮の扱い: 実装の出す形のまま（`rules/leader.md` 5.11。どちらも誤りで、通るプログラムを変えない）。

- 経緯: 139 回目（2026-11-11）、文書の点検（onsa-docs）が、W5-24 の `持ち越し` の「U1d のテストの担当の NEW（決めていない）」の三つの問いに答えの記録が無いと報告した。親が dev `ed635d6f` で確かめた。入れ子の E0020 が一つ（§18.1 の単位に一つ）と、`[F32; Rg[F32].CAP]` の E0020（§4.5 の、式の中の型引数は `::[…]` の行）は仕様の字で決まるので親の読みとし、この一つを細部として登録した。
