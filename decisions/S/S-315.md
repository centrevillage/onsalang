# S-315

- 空白: E0020 の候補が複数あるときの並べ方。§18.1 は「候補が複数あるときの並べ方は、各コードの規則に従う（E0020 は下記…）」とするが、下に E0020 の規則が無い（形ごとに本文に並べて書いた順があるだけ）。第 4 組の Fable の案「Onsa 自身の読みの形を先、残りは表の行の順」は親が確認だけとしたが、利用者が ID を挙げて了承した記録が無い。W3-15/t2 で見つけた（2026-10-09）
- 提案: 決定（2026-10-09、利用者が ID を挙げて了承。親の案）: E0020 の候補の並べ方は、閉じた一覧のファイル（`spec/foreign-forms.toml`）の各行の例の候補の順を規範とする。§18.1 の「E0020 は下記」を「E0020 は一覧の各行」に改める（W3-15 のコミットで、一覧の置き場所の一文と一緒に書く）。
  第 4 組の Fable の一般の規則（Onsa 自身の読みの形を先）は採らない（判断を一か所に置く）。データのファイルの先頭のコメントの「仮」を外す。実装は W3-15
- 時期: W3
- 経緯（2026-10-17、親）: X-3 の X3-1a・X3-1d で候補の並べ方の約束を外した。E0020 の候補の順は実装が選び、`spec/foreign-forms.toml` の例の候補の順は実装の出力の写しである（§18.1、toml の頭のコメント）
