- 補い（2026-11-21、親）: 173 回目、W7-09 U4a/t の NEW-2: graph と interface に導くクロックを書く形。interface は §18.2 の `onsa interface` の行の「シグネチャの型は、読み直すと同じ型になる形で書く」、graph の入力の行は「ソースの宣言と同じ形」なので、入出力は `lf: F32 at (sample / 4)`。graph の `let` とノードのラベルも同じ「型 at クロック」なので、仮の扱い (2) に括弧の形を含める（`b: F32 at (sample / 4)`、`lp_0 = lp~.down~(4): F32 at (sample / 4)`）。診断の文の中の字は今の `sample / 4` のまま。
