# S-739 束縛が、自分の宣言の型の注釈に見えるか（`let a: a = 1` は今 E0302、無名関数の `fn(x: x)` と `fn(x: I32, y: x)` は今 E0308）

- 決定済みで戻さないもの: 前に同じ名前の束縛があれば、束縛の名前の E0304 が先（`let a = 1` の後の `let a: a = 2` は E0304、`probe/s739/let_redeclare_with_ann`）。flow の本体の `let` の自分の注釈は S-740 の形として扱う。
  第 69 組の下書きの「族「§15.1 の型の位置から見える値の束縛」の仕組みの出所」と「族の形の表」の節（写しは `target/notes/79/g69/draft.md`）。
- 論点: §5.1 は見えている束縛と同じ名前の束縛を E0304 とする（`let x = x + 1`）が、束縛が自分の宣言の型の注釈から見え始めるか、無名関数の見出しで引数がどこから見えるかを書いていない。
  `let` の初期化式からは自分が見えない（fn の `let a = a` は E0302）ので、値の位置の範囲は「文の後ろから」と読める。注釈は値の位置でないので、その読みが当たるかが割れる。
- 今の実装: 表の S-739 の行（`probe/s739.out`）。`let`・`var` は型を集める前に束縛を取り戻すので E0302、無名関数は引数を一つずつ宣言してから型を集めるので、自分と前の引数と返り値の型は E0308・E0417、後ろの引数は E0302 である。同じ見出しの `uses {x}` は E0302（S-738）。
- 案: (1)〜(3) は S-741 の (c)・(b)・(a) に当たる。どれも `let`・`var` の自分の注釈と分解の同じ文の名前は E0302 で、違うのは無名関数の見出しだけである。

  | 形 | (1) 自分の後ろから | (2) 今の形 | (3) 見出しの全体から | (4) 本体だけ | (5) 注釈は自分を見る |
  |---|---|---|---|---|---|
  | `let a: a = 1`、`let (p, q): (q, I32)` | E0302 | E0302 | E0302 | E0302 | E0308 |
  | `fn(x: x)` | E0302 | E0308 | E0308 | E0302 | E0308 |
  | `fn(x: I32, y: x)`、`fn(x: I32) -> x` | E0308 | E0308 | E0308 | E0302 | E0308 |
  | `fn(x: y, y: I32)` | E0302 | E0302 | E0308 | E0302 | E0302 |

  - (2) は引数が名前の直後から見える形で、`let` の範囲（文の後ろから）と合わず、S-741 の (a)〜(c) のどれからも出ない。(5) は `let` の注釈だけが自分を見る形で、初期化式から見えないこととの例外になる。
  - 書き手から見て: `let a: a = 1` は、TypeScript の `typeof` の感覚か、型の名前を小文字で書き違えた形である。どの案も候補は無く、E0302 と E0308 のどちらでも書き手は型を書き直す。差は一回の検査の文面だけで、書き手の数は少ない。
  - 実装の量: (1) は無名関数の二行の入れ替え、(2) は 0 行、(3) は `ahead` で仮に宣言する約 +5〜8 行、(4) は型を宣言の前に集める約 +5〜8 行、(5) は `let`・`var` の `ahead` の後で型を集める約 +5 行。
- 他言語: rustc 1.94.1 はクロージャの `|x: x|` を E0573（自分を見る）、`let a: a = 1` を E0425（見ない）とする（`probe/other/r2.rs`）。C の `int a = a;` は通り（宣言子の後ろから見える）、`typeof(c) c` は undeclared（`probe/other/c.c`）。swiftc 6.3.1 はどれも型の名前として探して見つからない。
- 推奨と理由: S-741 の規則から (3)。確度: 中。
  - S-741 (b) の理由のとおり、`let` は初期化式の後に、引数は呼び出しで一度に束縛されるので、範囲がそれぞれの束縛の時機で一つに決まる。今の (2) は、引数がどこから見えるかを名前の位置で決める形で、`let` とも署名とも違う三つ目の範囲になる。
  - `let a: a` の E0302 と `fn(a: a)` の E0308 は、束縛の種類（文の後ろからか、見出しの全体か）の違いから出るもので、同じ種類の中では揃う。
  - あわせて決めること: S-741 の一文の「`let`・`var` はその文の後ろから」が、分解の同じ文の名前（`let (p, q): (q, I32)`）も含むこと。
- 影響: 仕様 §5.1（S-741 の一文）。作業は S-741 と同じ単位。事例は `tests/spec/type_names/` に表の形を足す（(3) は `let` が E0302、無名関数が E0308・E0417）。今の期待で変わるものは見つけていない。
