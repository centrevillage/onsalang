# S-412 キーワードと印の後、列挙子の宣言の開き括弧の前の空白と改行

- 空白: キーワードの後の開き括弧の前の空白（無名関数 `fn (a: I32) -> I32 { a }`、関数型 `fn (I32) -> I32`、`pub (pkg)`、`handle … with h (args)`）。§2.5 の後置の開きの規則（S-89: 呼び出し、添字、型引数、宣言の引数と型パラメータ、パターン、属性）は、これらの位置を挙げない。
  読みは (1) 同じ E0020（候補は空白を除く形）、(2) 受ける（fmt が除く）。
  今は、無名関数と関数型の `fn (` は通り、`pub (pkg)` は E0002「expected a declaration, found `(`」、`with h (args)` は `(args)` を `handle` 式の結果の値の呼び出しと読む（fmt が `h(args)` と書いて木を変える。R-203 と同じ根。第 22 組の下書きが直した）。
  リポジトリの中に使う所は無い。`pub(pkg)` 自体は §15.1 の E0020（`pub_pkg` の行）。
  同じく一覧が挙げない位置として、列挙子の宣言の `V (I32)`（W3-06 の単位 1a は E0020 にした）と、印と `(` の間の空白（`saw~ (f0)`、`v.push! (x)`。今は E0002「expected the flow-call mark…」で候補なし。S-123 は名前と印の間だけを挙げる）も同じ回に決める（W3-06 の単位 1a の報告、2026-10-10）。
  W3-06/i の設計メモで見つけた（2026-10-10。仮の扱いは (1) と `SPEC-GAP`）
- 提案: 決定（2026-10-10、利用者が ID を挙げて推奨の (a) を了承。下書きと Fable が一致、第 22 組）: 全ての位置を同じ E0020（候補は空白を除く形）。
  §2.5 の並びを開く `(`・`[` の一覧に、handler の引数（`with h(x)`）、無名関数の引数、関数型の引数（`fn(I32)`）、列挙子の宣言の要素（`V(I32)`）を足し、前のトークンは名前・キーワード・印のどれでもよい。括弧の中の `fn` 改行 `(` と、印と `(` の間の改行（括弧の中でも外でも）は E0020 で候補は改行を除く形。
  括弧の外の `fn` 改行 `(` は今の E0002。`V` 改行 `(I32)` と `with h` 改行 `(args)` は S-89 の改行の形（括弧の外の `with h` 改行 `(args)` は二つの文）。`pub (pkg)`・`pub (crate)` は `pub_pkg`・`pub_crate` の一つの誤り（候補は可視性の全体を外す形）。`saw ~ (f0)` は一つの形で、候補は両方の空白を除く一つ。
  仕様 §2.5、§15.1。実装は W3-06（単位 1a の仮の扱いが (a) と同じなので `SPEC-GAP(S-412)` を外す。印の後の空白と改行は単位 1b）
