# S-772 flow の署名の型（入力と出力、`pub flow g(x: F32 at sample, k: N[Bool] at block)`）に書いた型引数を、§4.5 の型の位置の要求（E0416）で判定するか

- 空白: §4.5 の 146 行は、型の位置（署名、別名の右辺、`impl` の見出しの対象、本体に書いた型）に書いた型引数が型の宣言の要求を満たさなければ E0416 とする。flow の入出力は `(名前: 値型 at クロック)` と `-> 値型 at クロック`（§11.3）で、値型は Copy に限る（E0810、§11 の 91 行）。
  flow の署名が §4.5 の「署名」に入るかは書いていない。`pub flow g1(x: F32 at sample, k: N[Bool] at block) -> F32 at sample`（`N[T: Num]`）は、`N[Bool]` が Copy なので E0810 に当たらず、今は診断が無い（U4a の前も後も同じ。再現は `target/notes/82/s769/fb2.onsa`）。
  flow の本体の `let` の注釈は、W4-05 U4a で本体に書いた型として判定する。
  W4-05 の単位の決め（審査の表 5）は、flow の入力・出力の値型を `flow_sig` の E0810 に残し、整形性の表から外した（第二級の位置は E0810 が見る）。型引数の要求（E0416）をどうするかは決めていない。
  形: (1) flow の入出力の型も整形性の段の根にし、型引数の要求（E0416）と `Buf`・`Span` の要素を判定する（第二級の位置は E0810 のまま）。(2) flow の型は §11 の検査（E0810）だけに任せ、型引数の要求は判定しない。
- 決定: 決定（2026-10-29、利用者。82 回目。外出中の暫定を帰宅後に了承）: (a) は (1)、(b) は (i)。
  (a) flow の入力と出力の型も §4.5 の署名の型の位置で、型引数の要求（E0416）と `Buf`・`Span` の要素を判定する。
  (b) 入出力の根の第二級の型（`k: Span[F32] at block`、他の flow の生成型 `g.Out`）も整形性の段の E0710 で、段の順（型 → flow、§18.1）で E0810 より先に当たる。`Buf[Str] at block` は E0810 から E0416 に変わる。上の (1) の「第二級の位置は E0810 のまま」は採らない。
  理由: 関数の署名と同じ規則で、`N[Bool] at block` と `Span[F32] at block` が `check` を通る穴を塞ぐ。第二級の判定が整形性の段の一か所で済む（E0810 の Copy の判定の種の答えの無い型の穴を別に直さなくてよい）。
  U4a の前は通っていた形を誤りにするが、`tests/`・std・`examples/` に当たる形は無い。既にある期待値は 4 件が E0810 から E0710 に変わった（`tests/spec/flow/generated_order_out_as_input_g_first.onsa`・`_h_first.onsa`、`crates/onsa_cli/tests/generated_order.rs`・`declaration_order.rs`）。
  仕様は §4.5 の型の位置の文（署名に flow の入出力）と §11.3 の E0810 の項に一文。実装は W4-05 U4a（`sig/wellformed.rs` の flow の根、`sig/generated.rs` の `lower_generated` と `check_generated` の分割）。事例は `tests/spec/types/wellformed_flow_signature.onsa`。
