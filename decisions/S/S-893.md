# S-893 `unwrap` の panic の位置（呼び出しの位置か、std の本体の中の位置か）

- 空白: §9.1 は `unwrap` が `None` / `Err` で panic するとし、§9.2 は通常の実行で「メッセージと位置を出力してプロセスを終了する」、§18.1 は `failure` の `span` を「panic した式の位置」、`calls` を「panic した位置からテストの本体まで遡る呼び出しの位置」とする。§14 の `ONSA_PANIC_HANDLER` は `(const char* msg, const char* file, uint32_t line)` で呼ばれ、`panic_messages = false` では `msg` と `file` が空で行番号は残る（§9.2）。
  S-71・S-785・S-873 は `unwrap` を std の本体（`pub rt fn unwrap(move self) -> T`、`None => panic(…)`）にするので、`panic` の式は `std/core.onsa` の中になる。「panic した式の位置」が std の本体の中か、`.unwrap()` を書いた位置かを仕様が書かない。
  今（`01aff7bf`）は、組込みの表の `unwrap` は呼び出しの位置の panic で（`failed at` の行は `.unwrap()` の行で、`calls` は空）、std の `target` のメソッド（`xs.slice`、`rem_euclid`）も呼び出しの位置である。std の Onsa の本体の中の panic の今の例は `std.dsp.test.energy` の `assert` だけで、`failed at` の行は `std/dsp/test.onsa` の中で、`calls` に呼び出しの位置が入る。
