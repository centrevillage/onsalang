# S-733 署名の型の位置と定数式に引数の名前を書いたとき（`fn f(n: U32, a: [F32; n])`、`fn f(n: U32, a: n)`）、S-713 (a1) の引数の E0417・値の E0308 か、署名は引数を見ず E0302 か

- 決定済みで戻さないもの: 族の S-741 の項のとおり（S-729、S-713 (a1)・(b)）。
  第 69 組の下書きの「族「§15.1 の型の位置から見える値の束縛」の仕組みの出所」と「族の形の表」の節（写しは `target/notes/79/g69/draft.md`）。
- 論点: §15.1 の E0308 の例は「本体の型の位置では、見えているローカルの束縛と引数を含む」、§4.5 は定数式の「ローカル変数」を E0417 とするが、署名（引数と返り値の型、効果行、境界）が同じ署名の引数を見るかは書いていない。
  S-729 の決定は「頭の名前を引く関数は、S-733 で見えている束縛の一覧を渡せる形にしておく」とし、今の `Cx::locals` は署名で空である。
- 今の実装: 表の S-733 の行は全て E0302「cannot find `n`」（`probe/s733.out`）。本体の `let v: [F32; n]` と `[0.0; n]` は E0417、項目の関数の `fn f(a: [F32; h])` は E0417「`h` is a function, not a constant」。
  `fn f[const N: U32](a: [F32; N])` は通る。
  メソッドの署名の `self` も引数である（親が足した行）: `fn m(self, a: [F32; self.N])` は E0302「cannot find `self`」、本体の注釈の `let a: [F32; self.N]` は E0417「`self.N` is a local, not a constant」（`P79/parent/probe69/self_sig.onsa`・`self_body.onsa`）。
  書き手は `Self.N`（関連定数）のつもりで書く形で、S-741 の (a) では E0302、(b)・(c) では本体と同じ E0417 になる。どの案も候補は無い。
  引数と同じ名前のモジュール（`use inner` の後の `fn f(inner: I32, x: inner.T)`）は引数の E0304 で、`use` が無ければ `inner.T` は署名でも E0302 なので、どの案でも通るプログラムは変わらない（親が確かめた。`P79/parent/pkgmod/`）。
- 案: S-741 の案ごとに決まる。
  - (1) 署名も引数を引く。型の位置は E0308、型の中の定数式は E0417、境界は E0308（「`n` is a local, not a trait」の類）。範囲は (1a) 見出しの全体（S-741 (b)）か、(1b) 前の引数だけ（S-741 (c)。後ろの引数、自分の型、境界は E0302）。
  - (2) 署名は引数を見ず、全て E0302（S-741 (a)。今の実装）。
  - 書き手から見て: S-741 の「書き手から見て」のとおり。(1) は一回目で「定数式には定数を書く」を示す。(2) は名前を足す直しで E0304 を経うる。
  - 修正候補: どの案も無い。E0417 の文面に「長さを引数で変えるには `[const N: U32]` か `Span[F32]`」の note を足す形もありうるが、どの案にも要らない。
  - 実装の量: (1a) は `lower_fn` と flow の見出しで `Cx::locals` を全ての引数にし、境界の読みに一つ足す（約 +8〜12 行）。(1b) は引数を下ろすごとに足す（約 +8〜12 行、境界は変えない）。(2) は 0 行。どれも名前の段の署名に閉じ、呼ぶ側は今と同じく誤りの見出しとして読む。
- 他言語: S-741 の項のとおり（rustc は全ての引数を見る、C は前の引数を見る、Swift は見ない）。
- 推奨と理由: S-741 の規則から (1a)。確度: 中。
  - S-741 (b) の理由のとおり。この件に固有の利点は、本体の `[F32; n]` と署名の `[F32; n]` が同じ E0417 になること（今は本体だけ R-304 で E0417）である。
  - あわせて決めること: 境界（`T: n`）の E0308 の文面は、既にある「is a local, not a type」と同じ口で「not a trait」とする。note は足さない。
- 影響: 仕様 §5.1（S-741 の一文）。§4.5 の「ローカル変数」は引数を含むと読める（§5.1 がローカルに引数を含める）ので変えない。`sig.rs` の 67 行のコメント（S-733）を改める。
  作業は W4-06 の前（S-741 と同じ単位）。事例は署名の形ごとに一つの単位（(1a) は E0417・E0308、(1b) は前の引数だけ E0417・E0308 で残りは E0302、(2) は E0302）。今の期待で署名の引数を E0302 とするものは見つけていない（`git grep` の範囲）。
- 独立のレビュー: onsa-advisor の二段（79 回目）。段 1・段 2 とも (1a)（S-741 が (b) なら確度 高）で、割れは無い。
  細部: 境界 `T: n` の文面は `kind_error` の既存の「`n` is a local, not a trait or a kind constraint」。メソッドの署名の `self.N` は本体と同じ E0417 で、`Self.N` を示す note は足さない（親が `self.N` の行を下書きに足した）。
