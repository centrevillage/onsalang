# S-905 `default()` の `rt` と効果行

- 空白: §6.3・§6.4 は `default` の `rt` と効果行を書いていない。`rt fn` の中の `P.default()`・`T.default()` が通るか、手書きの `fn default` に `rt` や `uses {Alloc}` を書けるかが決まらない。
- 決定: 決定（2026-11-06、利用者。117 回目、確認だけ）: (a) `default` は `rt` で効果行は空である（`rt fn default() -> Self`）。手書きも `rt fn default() -> Self` と書く（`rt` は関数型の一部、§10。§6.3 の `Drop` と揃う）。
  書き忘れは S-904 の E0401 で、`rt` を足す候補を出す。derive の `default` は `rt` である。`rt fn` の中と `const` の初期化式で `P.default()`・`T.default()` が書ける。
  derive の `Default` の型は `priv` のフィールドがあっても他のモジュールから `P.default()` を呼べる（§15.1 の継ぐ可視性）。§6.4 の例を `rt fn` に改める。
- 経緯: 117 回目（2026-11-06）、第 88 組の下書き（onsa-gap）が新しい S の候補として挙げた。
