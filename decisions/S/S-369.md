# S-369 括弧の中の、空白を空けない位置の改行

- 空白: 括弧の中の、空白を禁じた位置の改行（後置の `?` の前 `two(o` 改行 `?, 1)`、前置の `!` と `-` の後 `two(-` 改行 `a, 1)`）。§2.5 の `?` の規則は「行の中で」、前置の記号の規則は「空白を空けずに」と書き、括弧の中の改行を書かない。
  今は括弧の中は通り、fmt が一行にする（括弧の外は E0002。`::[` の前後の改行は括弧の中でも E0002）。S-353 と同じ考え方で決める。第 15 組の下書きで見つけた（2026-10-09）
- 提案: 決定（2026-10-09、利用者が ID を挙げて推奨の (a) を了承。下書きと Fable が一致、第 16 組）: 空白を空けない位置（前置の `-` / `!` / `^` と被演算子の間、後置の `?` の前）には、括弧の中でも外でも改行も置かない。E0020 で、候補は記号を相手の行へ移す形（S-353 と同じ移し方）。`?` の文の「行の中で」は `.` だけに掛ける。
  継続の「行末が二項演算子」は「二項として読む位置の演算子」に直す（行末の前置の `-` は継続しない）。データのファイルに新しい行（前置の記号の後の改行と、`?` の前の改行）。仕様 §2.5。実装は W3-06
