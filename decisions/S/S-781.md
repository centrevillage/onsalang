# S-781 §4.6 の種の表で、Shared の部分と Affine の部分を両方含む型（`struct M { name: Str, buf: Buf[F32] }`）の種: 表の Shared の行と Affine の行の「それらを含む型」の両方に当たる

- 空白: §4.6 の種の表は、Shared の行を「`Str` `Bytes` `Array` `Map` `Set`、それらを含む型」、Affine の行を「`Buf`、`Drop` 実装型、flow の状態、それらを含む型」とする。Shared の部分と Affine の部分を両方含む型（`struct M { name: Str, buf: Buf[F32] }`）は、二つの行の「それらを含む型」の両方に当たり、どちらの種かを字では言っていない。
  今の実装は Affine（`onsa interface` の `pub struct M  // Affine`。84 回目に親が確かめた）。表の「複製: 不可（ムーブのみ）」の意味からも、複製できない部分を含む型は全体も複製できず、Affine の一つに決まる。誤りのあるプログラムの報告も、通るプログラムも変わらない（字の補いだけ）。
- 決定: 決定（2026-10-29、利用者。84 回目。確認だけ）: Shared の部分と Affine の部分を両方含む型は Affine。§4.6 の表の下に一項を足した（複製できない部分を含むので、全体も複製できない）。実装は今のまま（足す行は 0）。
- 経緯: 84 回目（2026-10-29）、S-780 の説明の中で、利用者の問い（Affine をフィールドや型引数に含む型は、元の型が別の種でも Affine か）に答えるために親が §4.6 を読み、表の二つの行が重なる字に気付いた。S-767（`Array` などの要素の Affine）が同じ重なりを題に挙げていた。利用者が「それで良い」と答えた。関係: S-767、S-780。
