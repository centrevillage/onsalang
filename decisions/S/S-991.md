# S-991 引数の型に現れない効果行変数が呼び出しで決まらないとき（`fn mid[A, e, B](a: A, b: B)` の `mid(1, true)`）: E0406 か、誤りにしないか

- 空白: §4.5 は「式の中の型引数の数に、効果行変数（§8.1）は数えない（効果行は呼び出しから決まる）」とする。宣言した効果行変数が引数の型に現れない関数（`pub fn mid[A, e, B](a: A, b: B) -> A`）では、呼び出しから効果行が決まらない。そのときの扱いを書かない。
  今の実装は、効果行変数にも型変数を作り、決まらなければ他の型パラメータと同じ E0406（「the type parameter `e` of `mid` cannot be determined」）にする。型引数を書かない `mid(1, true)` も、書いた `mid::[I32, Bool](1, true)` も同じ（dev `559b338b` と W5-10 U2a の後。W5-10 の前からの挙動）。
  読みは (1) 決まらない効果行変数は E0406（今の実装。文面は型パラメータのもの） (2) 決まらない効果行は誤りにせず、空の行とする に割れる。効果行を型引数の並びに書く形は無い（S-982）ので、(1) ではこの形の関数を呼ぶ方法が無い。
  仮の扱い: 実装は変えない（(1) のまま）。(2) の読みで書かれた事例 `tests/spec/types/type_args_fn_effect_row_declared.onsa` は、効果の検査を作り直す W6-01 まで実装待ち。
- 決定:
- 経緯: 134 回目（2026-11-10）、W5-10 U2a のテストの担当（onsa-test）が (2) の読みで事例を書き、実装の担当（onsa-impl）が今の挙動との食い違いとして報告した。親が前後のバイナリで再現した。宣言した効果行変数を署名に使わない関数は稀で、急ぎでない。関係: S-982、R-27。
- 補い（2026-11-13、親）: 第 1 期は効果行変数の宣言が E0200（R-27 (3)、144 回目に利用者が了承）なので、決めるのは第 2 期（`tasks/phase2.md` の効果行変数の項）。独立のレビューの段 1（`target/notes/144/r27/`）の見立て: (2) を「関数の終わりまでに求められた最小の行で、何も求められなければ空の行」とする読み。効果行は包含で順序のある集合で最小の解があり、(1) の E0406「annotate it」は、効果行を書く手段の無いもの（S-982）に注釈を求める。読み (3) 宣言の側の誤り（引数の型に現れない `e`）も案に足す（`run_opt(None)` の形は拾えないので (1) か (2) も要る）
