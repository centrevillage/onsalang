# S-279

- 空白: FAUST の `seq`（直列の合成）に当たる flow の構造が無い。`par` は全ての複製に同じ入力を配るので、一つ前の段の出力を次の段に渡し各段が別のインスタンスを持つ形（双二次のフィルタの縦続、オールパスの連鎖）を書けず、flow の中にはインスタンスを作りながら繰り返す手段も無い。後から足すとキーワードが既存の名前とぶつかる。利用者が提起した（2026-10-08）
- 提案: 決定（2026-10-08、利用者）: キーワード `ser` を予約する（§2.2。この版では現れた位置で E0200）。名前は `par`（並列）と対の直列（series）から採り、`seq` はシーケンサの名前（§19.1 の例の `seq~(tick)`）とぶつかり紛らわしいので避けた。`ser i in a..<b { e }` の見出しの形を想定し、一つ前の段の値を本体で受け取る構文は機能を入れるときに決める（§19.1）。字句解析器の予約は W3-04
- 時期: PH2
