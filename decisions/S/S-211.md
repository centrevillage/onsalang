# S-211 `F32.PI` / `F64.PI` の値

- 空白: `F32.PI` / `F64.PI` の値の丸め方が書かれていない。W2-01 の設計メモで見つけた（2026-10-08）
- 提案: (a)。π を最近接偶数で丸めた値で、浮動小数の関連定数の全てを同じ規則で書く。§2.4 に浮動小数のリテラルの値（R-20、R-45）と、0 でない字面が 0 に丸まる E0408（非正規化数は通す。Fable の指摘）を書いた（仕様 §2.4、§6.6。2026-10-08 決定。ベクトルの `CONSTANTS_LEFT_OUT` から `PI` を外すのは W2-12、0 に丸まる E0408 は W3-05、C の浮動小数の定数の書き方は R-164）
