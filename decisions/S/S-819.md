# S-819 flow の外で flow を `!(` で呼ぶ形（`lp!(x)`）のコード

- 空白: §11.1 は flow の外の「`~` 無しの flow の呼び出し」を E0821 とし、§2.6 の印の規則の順（S-811）は、その文脈で書けない印（flow の外の E0821）を、書いた印が呼び先に合わない規則（`!(` は E0714）より先にする。flow を `!(` で呼ぶ `lp!(x)` を「`~` 無しの flow の呼び出し」に数えるかを書いていない。
  一方、flow を `.(` で呼ぶ `lp.(x)` は、flow の本体でも外でも §15.1 の E0308（flow は値でない）と決めた（S-816）。flow の本体の `lp!(x)` は §11.2 の E0806 で、候補は `!` を `~` に置き換える（S-813、W4-12 U2）。
  読み (1): `~` 無しの flow の呼び出しとして E0821（候補なし。R-269 の `lp(x)` と同じ）。読み (2): 書いた印が呼び先に合わない形として扱う（`.(` の S-816 と同じ向きで、flow は関数値でないので E0714 でなく §15.1 の E0308 か、S-812 の「関数でない値」の E0401）。
  今の実装は W4-12 U3 の前も後も型の段の E0401「`lp` is not a function」（名前の段の E0821 は `CallKind::Plain` だけを見る）。どちらの読みでも、通るプログラムは変わらない。
  再現: 94 回目の scratchpad の `w412u3/parent/lp_bang.onsa`（写しは区切りで `target/notes/94/w412u3/`）。
- 決定: 決定（2026-10-31、利用者。94 回目）: (1)。flow の外で flow を `!(` で呼ぶ `lp!(x)` は、`~` 無しの flow の呼び出しとして E0821 で、修正候補は付けない（R-269 の `lp(x)` と同じ。S-811 の順で、文脈で書けない形が印の不一致より先）。`lp.(x)` の E0308（S-816）は変わらない。実装は W4-12 の U3（`names/body/flow.rs::call_outside`）。仕様 §11.1
- 経緯: 94 回目（2026-10-31）、W4-12 U3/i（onsa-impl）が空白の候補として報告し、親が `P94/bin/onsa-c217f7e`（U3 の前）と `onsa-w412u3`（U3 の後）で再現して登録した。関係: S-811、S-813、S-816、R-269。
