# S-880 S-875 の期待の型の範囲: 前の枝の型（`if` の `else`、`match` の二つ目以降の腕）を数えるか、型変数を含む期待（`Option[?v]`）で `Some(x as T)` を出すか

- 空白: §3.3 の 83 行は「`Option[T]` を返す `narrow_*` の候補は期待の型で選び、期待が `T` なら `x as T`、`Option[T]` なら `Some(x as T)` である（別名は解決した型で比べる）。期待の型が無いか決まっていない位置（型を注釈しない束縛の初期化式、受け手、照合の対象、`?` の左）では候補を出さず、note で二つの形を示す」とする。
  §4.7 の期待の型の一覧は、`let` の注釈、引数の型、返り値の型、フィールドの型、代入の左辺の型。次の二つの位置が文から一つに決まらない。
  (1) 前の枝の型: `let y = if c { Some(x as I64) } else { x.narrow_i64() }` と、`match` の二つ目以降の腕（`None => x.narrow_i64()`）。
  実装は `else` の枝に `then` の型を、二つ目以降の腕に一つ目の腕の型を期待の型として渡す（`body/expressions.rs` の 130 行と 444 行。`without_why` は E0416 の note の文面の印で、型付けを変えない）。§4.7 の一覧と §3.3 の括弧のどちらにも前の枝は無い。
  (1a) 渡る型で選ぶ: `Some(x as I64)`。追加の行は 0。仕様の §3.3 と §4.7 に一行。前の枝にだけ期待が渡るので、`if c { x.narrow_i64() } else { Some(x as I64) }` は候補なしで note（どちらの読みでも同じ）。
  (1b) §4.7 の一覧だけを数える: 候補なしで note。期待の型の出所を記録する欄が要る（+15〜25 行）。同じ式でも、注釈の有無で候補の有無が変わる。
  (2) 型変数を含む期待: `fn g[T](o: Option[T])` の `g(x.narrow_i64())`（期待は `Option[?T]`）と、`let y = if c { None } else { x.narrow_i64() }`（(1a) なら期待は `None` の型 `Option[?v]`）。
  (2a) 変数が残る期待は「決まっていない」とし、候補なしで note（決定の文のまま）。追加の行は 0。同じ単位の `round_*`（型が一つに決まる候補）は、期待の型に変数が残るとき構造で合いうるかで決める（`h[T: Float](y: T)` の `h(x.round_f64())` に `x as F64`）。変換の二つの族で判定が二つになる。
  (2b) `x as T` と `Some(x as T)` のうち一方だけが期待の型と構造で合うなら、それを出す（`Option[?v]` なら `Some(x as T)`。素の変数 `?T` は両方合うので候補なし）。追加は約 3 行で、判定は `round_*` と同じ一つ。
  §3.3 の「決まっていない位置」を「二つの形のどちらにも決まらない位置」と言い換える。`Some(x as T)` は元のメソッドの返り値の型 `Option[T]` を保つので、後の文との食い違いは元の書き方でも起きる（§18.1 の唯一の誤りの前提の内）。
  (3) 型の規則で決まる位置（U2a のテストの担当が挙げた）: シフトの右辺（§3.4 で `U32`）、範囲の後ろの端（前の端の型）、`&&`・`||` の右と `if` の条件（`Bool`）。実装は期待の型として渡す（`body/expressions.rs` の 582 行・571 行、`body/statements.rs` の 143 行）が、§4.7 の一覧に無い。
  (1a) と同じ読み（型の検査が渡す型で選ぶ）なら `a << n.narrow_u32()`（`n: U16`）は `a << (n as U32)`、`for i in a ..< n.narrow_u32()`（`a: U32`）は `n as U32`。(1b) と同じ読みなら候補なしで note。(1) と (3) は「期待の型を、型の検査がその位置に渡す型とするか、§4.7 の一覧から下向きに伝わる型だけとするか」の一つの問いである。
  二項演算子のもう一方の被演算子の型（`a + n.narrow_i64()`、`a: I64`）は実装が渡さない（`check_binary` は左右の算術と比較で `None`）ので、どちらの読みでも候補なし。範囲の前の端も `None`。
  今（`08412a41` のコード）はどの形も候補の無い E0413（再現は `decisions/S/S-880/branch.onsa`・`option_var.onsa`、(3) は U2a の事例 `tests/spec/negative/scalar_method_as_narrow_open.onsa`（作業ツリー `w514u2at`））。設計メモ（実装の担当）は (1a) と (2a)、独立の審査は (1a) と (2b) を推した。
  急ぎ: W5-14 U2a のテストの票の、この位置の事例だけ
- 決定: 決定（2026-11-04、利用者。111 回目。設計メモ・独立の審査・親の推奨が一致した (1)・(3) と、割れた (2) を背景の説明の後に問うた）: (1)・(3) は (A)。期待の型は、型の検査がその位置に渡す型とする（前の枝の型、シフトの右辺の `U32`、範囲の後ろの端の前の端の型を含む。§4.7 に一行）。(2) は (2b)。期待の型に型変数が残るときは、`x as T` と `Some(x as T)` のうち一方だけが期待の型と構造で合うならそれを出し、両方が合うか、どちらも合わなければ候補なしで note。§3.3 の「決まっていない位置」を「二つの形のどちらにも決まらない位置」に改めた。作業は W5-14 U2a（`decisions/S/S-880/` の入力と U2a の `scalar_method_as_narrow_open.onsa` の位置に事例を足す）。仕様 §3.3・§4.7
