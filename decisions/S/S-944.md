# S-944 自己代入の右辺を E0309 の読みに数えるか（`var y = 1` の後の `y = y` だけの本体が E0309 をすり抜ける）

- 空白: §5.1 の E0309 は「一度も参照されないもの（代入は参照に数えない）」とする。`var y = 1` の後の `y = y` は右辺が読みに数わるので、`y` が値として使われないのに E0309 にならない。S-293 で自己代入を誤りにしないと決めたので、この抜けが残る。
  読み: (1) 今のまま（右辺は読み）。(2) 左辺と同じ場所への自己代入の右辺は読みに数えない。通るプログラムの一部が E0309 になるので、S-293 の「式としては間違っていない」との関係も見る。
- 決定: 決定（2026-11-08、利用者。126 回目）: (1) 今のまま。代入の右辺の読みは参照に数え、`var y = 1` の後の `y = y` と `y = y + 1` だけを読む束縛も E0309 にしない。仕様と実装は変えない。参照の定義に例外を足さない。自己代入の右辺だけを外す (2) は `y = y` だけを捕まえ、隣の `y = y + 1` は残る。
  読まれない代入の検査（Rust の `unused_assignments` に近い (3)）は新しい種類の解析で、第 1 期の範囲の外である。Rust 1.94 の `unused_variables` も右辺を使いに数える（126 回目に確かめた）。
- 経緯: 121 回目（2026-11-07）、第 91 組の下書き（onsa-gap）が候補として挙げ、S-293 の決定の後に登録した。急ぎは後の段である。
