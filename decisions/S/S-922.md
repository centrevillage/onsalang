# S-922 見えない関数型のフィールドをメソッドの形で呼ぶ `g.curve(x)`

- 空白: §6.2 は「メソッドが無く関数型のフィールドがあれば E0020」とする。見えない（`priv`）関数型のフィールドの `g.curve(x)`・`g.curve!(x)` は書いていない。今は E0413「no method」。`g.curve.(x)` と `g.ops[0](x)` はフィールドを読むので E0303 である。
  読み (1) E0413 のまま（§6.2 の `s.f(x)` は常にメソッドの呼び出しで、見えるフィールドだけを前提に数える）。読み (2) E0303。読み (3) E0020 で候補なし（`.(` が E0303 を残す）。
- 決定: (1)。`g.curve(x)`・`g.curve!(x)` は今の E0413 のまま。`s.f(x)` は常にメソッドの呼び出しで、§6.2 の「関数型のフィールド」は受け手の位置から見えるフィールドだけを数える。仕様 §6.2（2026-11-06 決定）。
