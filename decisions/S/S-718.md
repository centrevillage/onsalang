# S-718 マニフェストの `[[plugin]]` の `flow` が名指す flow の名前の E0320 の改名の候補（`.onsa` だけを直すと E1103 が残る）

- 空白: マニフェストの `[[plugin]]` の `flow` は、プラグインにする flow を経路の文字列で名指す（§15.3、`@export` の flow でなければ E1103）。
  flow の名前が §2.3 に反するとき（`pub flow BadName`）、E0320 の候補（S-82 の全ての使用箇所の改名）が `.onsa` だけを直すと、マニフェストの文字列が古い名前のまま残り E1103 になる（マニフェストの段はソースより先、終了コード 2）。§18.1 の約束（当てた後に同じ段か前の段の誤りを残さない）を満たす形が決まっていない。
  読み: (1) マニフェストの文字列も同じ候補で直す。(2) マニフェストが名指す flow の E0320 は候補なし（note でマニフェストの行を示す）。
  今の実装の E0320 の候補は宣言だけを直す（S-82 は W4-04）。
- 決定:
- 経緯: 75 回目（2026-10-27）、W4-04 U1 の設計メモの審査（onsa-advisor）が指摘した。期限は W4-04 の候補の単位の前。
  関係: S-82、S-652、S-580。
