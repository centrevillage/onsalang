# S-1270 細部: 一つの束縛の型や一つの型の宣言に降ろせない部分が二つ以上あるとき、降下の E0200 をいくつ出すか（仮は最初の部分の一件。今の実装）

- 空白: §18.1 は「その単位の降下の診断は、降下できない型ごとに一つの E0200 だけ」、S-67 の補い (1) は数える組を降ろせない部分（機能、添える字、宣言に書いた位置）とする。一つの束縛の型（`p: (Str, Bytes)`）や一つの型の宣言（`struct Mx { a: Str, b: Bytes, n: U32 }` の `m: Mx`）に部分が二つあるときを書かない。
  読み: (1) 部分ごとに一件（二件）、(2) 束縛ごとに最初の部分の一件（`Bytes` は `Str` を直した次の回に出る）。仮は (2)（今の実装。型の変換と型の作り手が最初の失敗で戻る）。違いは誤りのプログラムの E0200 の数だけで、通るプログラムは変わらない。再現 `target/notes/192/w816/b/out10/`（`tuple_two`）・`out3/`（`two_bad_parts`）。改めるなら、`core_ty` と `lower/types.rs` の `fill_types` が失敗の後も残りの部分を変換して集める。
- 決定:
- 経緯: 192 回目（2026-11-27）、W8-16 B/b（onsa-break）が空白に挙げ、親が W8-16 の後のバイナリで再現した。誤りの場面だけの数の細部として、W8 の段の区切りで確認する（`rules/leader.md` 5.11）。担う作業が無いので W8 の依存の最も後ろの W8-18 に置く（`rules/leader.md` 7.4）。
