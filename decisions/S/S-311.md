# S-311 `--filter` の照合の範囲（ファイルで選んだテストの外にだけ当たるとき）

- 空白: パッケージの中のファイルと空でない `--filter` を `onsa test` に渡し、`--filter` がそのファイルの外のテストにだけ当たるとき（`onsa test pkg/a.onsa --filter two` で `two` がモジュール `b` のテストだけに当たる）の終了コード。
  「空でない値が一つも当たらなければ 2」の照合の範囲が、パッケージ全体か、ファイルで選んだテストか。§18.2 は「`--filter` はそれと重ねて絞る」まで書く。S-286 の反映で見つけた（2026-10-09）
- 提案: 決定（2026-10-09、利用者。(b)。下書きと Fable の推奨は (a) だったが、利用者が「(a) は S-286 の『テストが無ければエラーでなく 0 件で返す』判断から後退する」と問い、親が推奨を (b) に改めた）: `--filter` の照合（空でない値が一つも当たらなければ 2、S-242）は、渡したファイルによらずパッケージの全てのテストで行う（綴りの誤りを捕まえる）。
  ファイルの指定は重ねて絞るだけで、当たるテストが選んだ範囲の外にだけあれば、走らせるテストは 0 件で 0（S-286）。ファイルを渡すかで `--filter` の意味が変わらない。仕様 §18.2。実装は W4-02
