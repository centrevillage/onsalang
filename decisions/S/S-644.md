# S-644 マニフェストの無い単一のファイルを `.` で始まるディレクトリの下の経路で渡したとき（`onsa check .hid/ok.onsa`）のディレクトリの名前の E0320

- 空白: §15.1 は「`.` で始まる名前のファイルか、`.` で始まるディレクトリの下のファイルを経路で渡したときは、その名前に §2.3 の規則を当てる（E0320）」とするが、文はパッケージを集める段落にある。マニフェストの無い単一のファイルを `.hid/ok.onsa` の経路で渡したとき（モジュールの名前はファイル名だけ、§2.3）に `.hid` の E0320 を出すかが書いていない。今の実装は 0。
  親の案（確認だけ）: 出さない。マニフェストの無い単一のファイルのモジュールの経路はファイル名だけで、置き場所のディレクトリは経路の要素でない（`.hid/Bad.onsa` のファイル名の E0320 は出る）。W4-14 U2 はこの案を仮の扱いにする。
- 決定:
- 経緯: 61 回目（2026-10-24）、W4-14 U2/t（onsa-test）の空白の報告から。テストの票はマニフェストの下のパッケージの形だけを書いた。関係: S-300、S-313。
