# S-427

- 空白: `unsafe` と `handle` の本体の `{` を次の行に書く形（`unsafe` 改行 `{ … }`、`handle` 改行 `{ … } with h`）。§2.5 の `{` の置き場所の規則は、属する形として「宣言と見出しの本体（`fn`、…、`par` など）」を挙げ、`unsafe`・`handle` を名指ししない。
  S-416 は式の中のキーワードとその被演算子の間を置き場所の規則の外としたが、`unsafe`・`handle` の後はブロックで、被演算子ではない。W3-06/i の単位 2 は E0003（候補は `{` をキーワードの行の末尾へ移す形）で、括弧の中でも同じ。W3-06/b（単位 2）が見つけた（2026-10-10。親が作業ツリーのバイナリで確かめた）
- 提案: 決定（2026-10-10、利用者が ID を挙げて親の案（確認だけ）を了承）: 本体の `{` として置き場所の規則に入れ、仕様 §2.5 の一覧に `unsafe`・`handle` を足す（今の実装のまま）
- 時期: W3
