# S-680 flow と同じ名前の宣言（E0305。`pub fn lp` と `pub flow lp`）のとき、使う所（`lp~(x)`、`lp()`）と他のモジュールの経路が引く側

- 空白: §11.2 は flow と同じ名前の宣言を E0305 とし、「ソースの順で後の宣言に付け、前の宣言を note で示す（E0304 と同じ）」とする。使う所と他のモジュールの経路がどちらを引くかは書いていない。
  今（`c335496`）は先の宣言を引く。`pub fn lp` の後の `pub flow lp` では、flow の本体の `lp~(x)` に E0812「`lp` is not a flow」と候補「`~` を除く」が付き、当てると正しかった `lp~(x)` が `lp(x)` になり E0401 が残る（`target/notes/67/g59/probe/g_item_flow_use`）。
  順が逆（`flow` が先）なら関数の `lp()` に E0401（`g_flow_item_use`）。族の規則は S-675。
