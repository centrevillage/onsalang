# S-842 `[[plugin]]` の `version` の `major.minor.patch` の各数に、頭の 0（`"01.0.0"`）と桁の上限があるか

- 空白: §15.3 の `[[plugin]]` の表と §14.3 は「`version` | 必須。`major.minor.patch`（AU は各 255 以下）」とし、各数に頭の 0 を書けるか（`"01.0.0"`）と、桁か値に上限があるかを書いていない（AU の 255 は S-841 で第 2 期）。
  W4-02 U4（実装の担当の NEW）の仮の扱いは (1): 一つ以上の ASCII の数字なら何でもよい（`"01.0.0"`・`"10.200.3000"`・`"99999999999.0.0"` は通り、`"1.0"`・`"1.0.0-beta"`・`"1..0"`・`""` は値の E1103）。`crates/onsa_driver/src/manifest/read.rs` の `is_version` に `SPEC-GAP(S-842)`。
  読みは (1) 数字なら何でも (2) 頭の 0 を禁じる（SemVer の数の形） (3) 桁か値に上限を置く、に割れる。`version` を使うのは M10（CLAP）からで、CLAP と VST3 は版を文字列で持ち、AU（第 2 期）は各 255 以下の三つの数を一つの 32 ビットの数にする。
