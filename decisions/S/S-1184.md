# S-1184 細部: `init`・`block` の式を、刻みのクロック（`sample / N`、イベント）で決まる条件が選ぶ位置（§11.3 の守り付きの巻き上げの文の二つの句のどちらにも入らない）

- 空白: §11.3 は条件の位置の中の `init`・`block` の式を、選ぶ条件が全て `init`・`block` の段で決まるなら守り付きで巻き上げ、どれかがサンプルごとに決まるなら届いたときに評価するとするが、刻みのクロックの段で決まる条件（`if (lf > 0.5) at sample { x * F32.round_from(100 / n) } else { x }`、`at` は段を変えない）はどちらの句にも入らない。
  読み: (1) 届いたときに評価する（`block` の値は刻みの間に変わるので、刻みの段の守り付きの欄では読む位置で条件と欄が食い違う）、(2) 刻みの段で守り付きに巻き上げる。検査の `hoist.rs` は刻みの段の条件を `Cond::Late` にしていて (1) の形。
  仮の扱い: (1)（字を「`init`・`block` より後の段で決まるなら」に改める案）。S-1158 の守り付きの範囲の文と同じ段落。急ぎ: W7 の区切りで確認だけ。
- 決定: 決定（2026-11-26、利用者。189 回目、W7 の区切りの確認だけ。「(A)と(B1)はS-1148以外OKです」）: 仮の扱いのとおり。選ぶ条件のどれかが `init`・`block` より後の段で決まるなら巻き上げず、届いたときに評価する。
  突き合わせ: 助言の担当が固定のバイナリ `onsa-d02ddee` で再現し、仮の扱いが今の挙動と合い、既決とぶつからないことを確かめた（`target/notes/189/reports/onsa-advisor-a4f41d23ad112f9fe-001.md`）。
- 経緯: 170 回目（2026-11-20）、第 115 組の下書き（onsa-gap、`target/notes/170/g115/draft.md` の「新しい S の候補」）が挙げ、親が登録した。
- 補い（2026-11-21、親）: （172 回目、S-1196）条件が決まる段は、評価する段と条件の式のクロック（`at` を含む）の段のうち速い方になった。空白の例の `if (lf > 0.5) at sample { … }` は `sample` で決まる条件になり、この S の範囲を出る。範囲に入る形は、イベントの条件（`if is_on(m) { x * E(n) } else { x }`）と、パラメータの条件に刻みの `at` を付けた形（`if (d != 0) at (sample / 4) { l4 * F32.round_from(100 / (d - 1)) } else { l4 }`）である。
