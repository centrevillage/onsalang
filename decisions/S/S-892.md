# S-892 内側のループの先頭（`while` の条件、`for` の反復元）に書いた `break` は、どちらのループを抜けるか

- 空白: §7 は「内側のループの中の `break` は、内側のループを抜けるので数えない」とする。`while c { while ({ break`…`}) { } }` の条件と `for` の反復元は、内側のループの先頭で、外のループの中で評価される。
  今の実装: 外のループの `break` に数える（型の段も、条件を内側のループの深さを増やす前に検査するので、外にループが無ければ `break` outside a loop の E0002）。名前の段の `leaves_loop` も同じ。読み: (1) 外のループに数える（今のまま）、(2) 内側のループに数える。先頭の `break` は S-291 の E0503 にもなりうる形で、通るプログラムは変わらない
