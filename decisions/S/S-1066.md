# S-1066 細部: 値を介さない型の輪（`A { b: Buf[B] }`・`B { a: Buf[A] }`）で、どちらのフィールドを読めなかった部分とし、E0416 を幾つ出すか

- 空白: §18.1 は、読めなかった部分（フィールドなど）を誤りの型として扱い、それを使う側には診断を出さないとする。値を介さない型の輪（`A { b: Buf[B] }`・`B { a: Buf[A] }`。`Buf` の要素は Copy、§4.5）では、どちらのフィールドの誤りが先かで、もう一方が「使う側」になる。どちらを読めなかった部分とするか、E0416 を幾つ出すかを書かない。誤りのあるプログラムだけの形で、通るプログラムは変わらない。
  今（W6-04 U5 の後）: 宣言の依存の順（`sig/wellformed.rs::types_first`、輪の中は書いた順）で先に判定した方だけが E0416 で、もう一方はそれを誤りの型として読んで黙る。どちらの順に書いても E0416 は一件で、書いた順で先の宣言の位置（1:23）。文面の型の名前は順で変わる。U5 の前のバイナリも同じ。実装に `SPEC-GAP(NEW)` の印（`types_first`）。
  再現: `target/notes/153/w604/u5i/extra_cases.txt` の `cycle_ab`・`cycle_ba`。
  読み: (1) 先に判定した方だけが誤り、もう一方は黙る（今の実装。§18.1 の宣言をまたぐ循環の「集まりの宣言のうち診断の並べ方で最初のもの」と同じ向き） (2) 両方とも、相手の書いたフィールドで判定して報告する。
