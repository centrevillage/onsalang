# S-849 推論した型の上限（S-264）の誤りの位置: 推論の変数が後の文で決まり、上限を超える形の「型を作った式」

- 論点:
  - §4.4 は「検査が作る全ての型」に深さ 256 と大きさ 4096 を当て、位置を「上限を初めて超えた型を作った所」、本体は「型を作った式（`Some(a)`、タプル、呼び出し）」とする（S-264、決定済み）。
  - 出所と目的: §4.4 の上限は、型を辿る処理の再帰と、表示と時間を有界にする。位置の文は、超えた型の最初の一か所に出して連鎖させない形である（S-264）。本体の文は、作った時に変数が残る形を書いていない。
  - 推論の変数があると割れる。下の `(o, 1)` は作った時の深さが小さく、`o` が決まると超える。「作った式」か、「超えさせた文」か。
    ```onsa
    // type A0 = Option[I32] から type A254 = Option[A253] まで。Option[A254] の深さは 256
    pub fn f(x: Option[A254]) {
      var o = None      // L2
      let t = (o, 1)    // L3 記録した式。作った時は深さ 2
      o = x             // L4 変数を決めた文。ここで (o, 1) の深さが 257

      let _ = w
    }
    ```
