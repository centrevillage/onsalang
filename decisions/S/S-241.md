# S-241 `assert_near(a, b, tol)` の意味

- 空白: `std.dsp.test` の `assert_near(a, b, tol)` の意味。§11.8 は署名だけを書く。今の実装は `|a - b| <= tol` で、`assert_near(inf, inf, 0.0)` と NaN どうしは失敗し、負の `tol` は等しい値でも失敗し、`tol = inf` は全てを通す。
  等しい無限大と NaN どうしを通すか、負や NaN の `tol` を panic にするか、失敗の文面。W2-03/b で見つけた（2026-10-08）
- 提案: (b)。`a == b || abs(a - b) <= tol`（§3.4 の F64 の演算）で通る。`tol` は有限で負でない値に限り（`-0.0` は 0）、外れれば比べずに失敗。NaN はどちらにあっても失敗。失敗は呼び出しの位置の panic。
  文面は仕様で約束せず std の doc コメント（`std/dsp/test.onsa`）に書き、値を §6.3 の `Show` で書く一般の約束は `spec/tools.md` §4 に置く（Fable の案。仕様 §11.8。2026-10-08 決定。実装は W2-10。std の doc コメントも W2-10）
