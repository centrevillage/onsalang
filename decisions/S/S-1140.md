# S-1140 細部: `par~` の本体の中の巻き上げの欄の置き場所と番号（複製ごとの欄か。名前の無い `par~` の本体で「`let` ごと」の番号をどう分けるか）

- 空白: §11.6 は巻き上げの欄を `a.hoist_0`・`hoist_0`（`let` ごとに部分式の始まりの字面の順）とし、`par~` の本体は `par~` の名前で修飾する。`par~` の本体の中の巻き上げ（`saw~(f0 * (1.0 + detune * spread(i, N)))` の類）が複製ごとの欄か、名前の無い `par~` の本体で「`let` ごと」の番号をどう分けるかが書かれていない。巻き上げの欄は今の降下に無い（W7-05）。
  仮の扱い（2026-11-19、169 回目、W7-05 U0 の設計メモの 3.7 の案）: 欄は複製ごと（`par~` の複製の構造体の中、ノードの欄の後）に置き、番号は `par~` の本体ごとに部分式の始まりの字面の順、道は `<par~ の道>._hoist_<n>`（`let saws = par~ …` なら `saws._hoist_0`）。理由: 本体の遅い式は添字 `i` を読むことが多く値が複製ごとに違う、複製の範囲（`Scope` と `replica_loop`）が Core に既にある、§11.6 の「`par~` の本体は `par~` の名前で修飾する」をそのまま当てられる。代償は `i` を読まない遅い式も N 個の欄になること（値は同じ）。急ぎ: W7 の区切りで確認だけ（`rules/leader.md` 5.11）。
