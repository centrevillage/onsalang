# S-520

- 空白: ブロック形の並びで、1 行に複数の要素を書いた形（`two(` 改行 `a, b)`）。§3.2 はブロック形を「開き括弧の直後で改行し、要素を 1 段深くして全ての要素の後に `,` を置き、閉じ括弧を独立の行に置く」とし、要素ごとに独立の行にするかを書かない。今の fmt は `two(` 改行 `a, b,` 改行 `)` にする（要素の間に改行を足さない）。W3-11/t（U3b）が見つけた（2026-10-14）
- 提案: 決定（2026-10-14、利用者が ID を挙げて親の確認だけの読みを了承）: 要素の間の改行は書き手のまま保ち、足さない（§3.2 の「書き手の改行は保ち、行を自動で折り返さない」。改行を足す位置は閉じた一覧（項目の属性、ブロック形の並びの中の入力の属性、ブロック形の閉じ括弧の前、複数行のブロックの `{` の後と `}` の前）だけ）。出力は今の fmt と同じ。`spec/tools.md` §3.2。実装は W3-11 の U3b
