# S-46

- 空白: `Num` / `Float` の中身と組込み型の関連定数が仕様に無く、`T.ZERO` / `F32.ZERO` が E0302（レビュー R-56）
- 提案: trait の関連定数を一般の仕組みとして実装し、`T.NAME` を境界から解決する。組込みの `impl Num` が `ZERO`、`impl Float` が `ONE` `PI` `MAX` `EPSILON` `INFINITY` `NAN` を与える。整数は `MIN` `MAX` `BITS`。`F32.MIN` は E0302（修正候補は `-F32.MAX`）。
  組込みの文字列の表は R-79 の組込みの表へ移す。`std.math.sum` は `[T: Num]` と `T.ZERO`（2026-10-03 決定。実装は第 2 段。S-84 で `ZERO` は `AnyNum`、整数の `MIN` `MAX` `BITS` と `ONE` は `Int` の関連定数に、`sum` は `[T: AnyNum]` に改めた）
- 時期: M3
- 補い（2026-11-05、利用者）: 116 回目、W5-05 の設計メモで、`T: Float` の `T.MIN` も `F32.MIN` と同じく E0302 で、修正候補は `-T.MAX` とした（`Float` は `Neg` を含み、意図は同じ）。利用者が確認だけで了承（2026-11-05）。仕様 §6.6 に一文を足した。作業は W5-05 U5。
