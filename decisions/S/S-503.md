# S-503

- 空白: §3.5 の「数値リテラルは綴りではなく値で比べる」が、整数と浮動小数のリテラル（`1000` と `1000.0`）を同じとするか。また、10 進の値が違っても浮動小数に丸めると同じになる綴り（`0.1` と `0.10000000000000000001`）を同じとするか。今の `diff --ast` は整数を値で、浮動小数を綴りで比べる。W3-11/t（U1）が見つけた（2026-10-13）
- 提案: 決定（2026-10-13、利用者が ID を挙げて了承。親の確認だけの読み）: 整数と浮動小数は別の種類のリテラル（§2.4。型も違う）なので違いとし、同じ種類の中で値を比べる。浮動小数の値は丸めずに正確な 10 進の値で比べる（fmt は数字を変えないので、丸めて同じになる綴りを同じとすると fmt の誤りを見逃す）。実装は W3-11 の U1
- 時期: W3
