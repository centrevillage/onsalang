# S-1228 `reset_if~` の初期化と、`when~` で止まる部品が W の段で動かす遅い刻みの順（(P) 段で切る）

- 空白: §11.10 の `reset_if~` の項の括弧「条件の刻みより遅い刻みは、格子の上の位置でも、その位置で先に書いた後に戻す」が、`when~` が包んだ部品の遅い刻み（§11.9 の集めて配る時点「W より遅い中の刻みは、その W の段の中で先に動く」）にも当たるかが字で割れる。W7-10 U2b は当たる (Q) と読み、案 L（条件を旗に読み、寄せた遅い仕事の後で戻す）を入れた。U3ae の壊す側が、名前の flow の本体の `when~` には案 L が届かず、直に書いた連鎖と包んだ形が違う値になることを見つけた（F1。最小の再現 `slot~(1.0).when~(cb).reset_if~(c)` と `ws~(cb).reset_if~(c)`、`ws` の本体は `slot~(1.0).when~(p0)`）。S-1226（塊の内の条件の輪の戻しの順）も同じ根。
  - (P) 段で切る: `reset_if~` は条件の刻みの段で、左の全体がその段以降に持つ仕事の前に戻す。`when~` が包んだ部品の遅い刻みは W の段で動くので、外の `reset_if~` はその前に戻す。
  - (Q) 自分の格子で切る: 寄せた遅い仕事を先に動かしてから戻す（U2b の案 L）。インスタンスをまたぐと、呼び先に「頼まれた初期化」の口が要る。
  関係: S-172、S-558、S-559、S-1088、S-1129、S-1186、S-1209、S-1217、S-1226。
- 決定: 決定（2026-11-24、利用者が (P) に決めた。181 回目、182 回目に一点を確かめ直し、字を了承した）: (P)。§11.10 の `reset_if~` の項の括弧の後に一文「ただし、`when~` で止まる部品では W より遅い中の刻みも W の段で動く（§11.9 の位相のカウンタと集めて配る時点）ので、その `when~` の外（右）の `reset_if~` はその前に戻し、中の遅い刻みが動く位置では戻した後に書く（名前の flow の本体の `when~` も同じ。`x.when~(c).reset_if~(r)` は、`c` が常に真でも、その位置で `x.reset_if~(r)` と値が違いうる。`when~` の内（左）の `reset_if~` は、上のとおり先に書いた後に戻す）。」を足し、§11.9 の集めて配る時点の項の括弧を「（`when~` で止まる部品では、W より遅い中の刻みも、その W の段の中で先に動く。中の格子は動いた刻みで数え、呼び出し側の同じ比の刻みと揃うとは限らないためである（上の位相のカウンタ）。`reset_if~` だけを付けた部品の遅い刻みは、修飾子の無い部品と同じ段に入る）」に改めた。利用者の求め（`when~` の挙動が独自のカウンタに起因することと、カウンタを持つ理由を、無ければ書き、あれば参照を明記する）で、§11.9 の位相のカウンタの項に理由と参照「（受け手の本体の `sample` が動いた刻みを指し、格子もそこから数えるため、§11.3・§11.10。止まると外の格子からずれうる。…）」を足した（理由の正本はこの項の一か所で、集めて配る時点は帰結と短い理由、§11.10 は参照だけ）。
  外に `reset_if~` があるときの `X.when~(c)` と `X` の等しさ（x の遅い刻みと重なる位置）は、`c` がリテラルの `true` でも要件にしない。S-1226 は (γ)。包みの不変の約束（生成の双子）は「`when~` の周期の条件は W のポート、`reset_if~` の周期の条件は条件の刻み R のポート、遅い値は呼び出し側が `at` で渡す」。
  W7-10 の (P) の単位（182 回目）が案 L（`Op::Arm`・`Op::Fire`・`Part::Flag`、`steps::reset` の `Slower`・`fire`）と手順の札を外し、`Op::Reset` を条件の刻みの段の手順の並びの先頭に置いた。参照評価器も字から同じ順に直した。
- 経緯: 181 回目（2026-11-24）、W7-10 U3ae の壊す側が F1 を挙げ、利用者の要件「連鎖の分け方で挙動が変わるのは flow modulator として一般化できていない」で advisor の二段の検証（`target/notes/181/w710/modgen/stage1_report.md`・`stage2_report.md`）が (P) を推した（(P) は仕組みを足さずに包みの不変が成り立ち、S-1226 が一つの読みに閉じ、イベントと `sample` の条件の順が揃い、S-1217 の費用 0 を守る。(Q) はインスタンスをまたぐ約束が後の作業に付き、合わせて +330〜650 行の見当（sema 80〜150、Core 150〜300、評価器 100〜200））。利用者が (P) に決めた（「(P) で良いと思います」）。
