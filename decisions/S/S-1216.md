# S-1216 細部: 式の導くクロックと変換の flow の入出力の N 単体の上限（S-1089 で経路の積に数えない N。今は 2^31 まで通る）

- 空白: S-1089 は「経路の `.down~`・`.up~` の N を向きによらず全て掛けた積が 2^24 以内」とし、式の導くクロック（`p at (sample / N)`）と変換の flow の入出力（`x: F32 at (sample * N)`）の N は数えないと決めた。数えない N 単体の上限（2^24 か、`Ratio` の指数の範囲の 2^31 か）は、決定にも補い（2026-11-21 の 172・174 回目の問い）にも答えが無い。今の実装は 2^31 まで通す（W7-16 U5b1 の事例 `tests/spec/flow_clock/e0808_modifier_product_not_counted.onsa` の `p at (sample / 2147483648)`・`x: F32 at (sample * 2147483648)`）。通るプログラムは変わらない（今通る形のまま）。
  読み: (1) N 単体の上限は今の構文と型の上限（2^31）のまま、(2) 修飾子と同じく 2^24。
  仮の扱い: (1)（今の実装）。急ぎ: W7 の区切りで確認だけ（`rules/leader.md` 5.11）。
- 補い（2026-11-23、178 回目、W7-16 U6b3 の壊す側と段 1）: N 単体の上限だけでは閉じない。合成したクロック（宣言の指数 k に、連鎖の先頭からその境界までの比の和を足したもの、`bounds::bounds` の `outside`）が `U32` の長さを超える形が、`check` を通って降下が内部エラーになる: (a) 輪・配る配列の窓が 2^32（`h` の出力 `sample * 2^20` を `r~(h~(x).up~(4096).down~(4096))`）、(b) 束の値そのものが 2^32（`let _ = h~(7).up~(4096)`）、(c) 速い入力に定数で 2^32、(d)(e) 遅い側で比が −33 以下（`h~(7).down~(16777216)` で `h` が `sample / 512` の段を持つ、遅いポート `sample / 2^31` を `.down~(16777216)`。U6b3 の前から内部エラー。事例 `tests/spec/flow_clock/e0808_modifier_product_not_counted.onsa` の `a_caller_of_the_tick_of_the_derived_n_exactly`・`a_caller_of_the_slow_input_exactly` はこの形を受け入れると期待するが、同じファイルの E0808 で降下しないので見えなかった）。S-1089 の決定の「2^24 が集めて配る配列の長さと遅い刻みの判定のカウンタを守る」という説明は、数えない N が掛かるので守れていない。
  合成の読み: (W-a) 規則を足さず §4.1 の E0409（W9-04）に任せる、(W-b) 合成したクロックも `sample * N`・`sample / N` で N は `U32`（2^31 以内、超えれば E0808、位置は超えた修飾子）、(W-c) 宣言の N も合成の N も 2^24 以内（今 build の通る形を誤りにする）、(W-d) ポートと導くクロックの N も S-1089 の積に数える（`.down~(8192)` で動かす 8192 のフレームが 2^26 で誤りになる）、(W-e) 実際に作る配列だけ 2^31 以内。
  段 1（onsa-advisor）の推奨: W-b を S-1216 と一つの決定に（確信 中〜高。数を足さず、両側と三つの出口を一つの規則で覆い、今通る形をほぼ変えない。遅い側の境（2^31 か 2^32）は確信 低〜中で細部として一緒に確認）。束の一時の配列のスタックの大きさ（U6b2・U6b3 の壊す側の低）は上限では解けないので別の件（W7-16 の持ち越し、U7）。
  仮の扱い（補い）: 決まるまで、合成したクロックが Core で作れない形（速い側は指数 32 以上、遅い側は −33 以下）を `check` の段の E0200（この版では作らない）とし、`SPEC-GAP(S-1216)` の印を付ける（判定は sema の表の歩きの一か所で Core と共有。上限は決めない）。上の事例の二つの flow は仮の E0200 を期待に書く。
- 決定: 決定（2026-11-23、利用者。178 回目、「推奨案で良いです」）: 補いの W-b を S-1216 と一つの決定に。クロックの N は、宣言したもの（式の導くクロック、変換の flow の入出力）も、連鎖と経路で合成したもの（宣言の N に、連鎖のその所までの比を掛けたもの）も `U32`（2^31 以内）で、速い側・遅い側とも同じ（遅い側の `sample / 2^32` も誤り）。超える合成は E0808（検査の段、S-1089 の歩き。位置は超えた修飾子、note に宣言の N と経路）。S-1089 の「数えない」は変えない（宣言の N は経路の積の 2^24 に数えない）。元の二択は (1)（N 単体の上限は 2^31）。束の一時の配列のスタックは上限では解けないので別の件（`tasks/phase2.md` の `audit`）。反映は W7-16 U7d（`check` の仮の E0200（`Feature::ComposedClocks`）を E0808 に、事例 `tests/spec/flow_clock/e0808_modifier_product_not_counted.onsa` の遅い側の二つの flow の期待と、ちょうど `sample / 2^32` の形の期待を直す、§11.9 の S-1089 の項に一文、S-1089 の決定の「2^24 が配列の長さとカウンタを守る」の説明の補い）。
- 補い（2026-11-23、178 回目、U7d のテストの担当と字の監査、利用者が了承）: 合成で数えるクロックは、連鎖のどの修飾子の外から見ても、中の部品の入出力のクロックと遅い刻み（部品の中のインスタンスの刻みを含み、flow をまたいで数える）である。連鎖の途中だけで超える形も誤り（`h~(p).down~(2).up~(2)`、`h` に `sample / 2^31` の刻み。名前の flow で包んだ形と同じ）。パラメータの種類の値に付けただけの導くクロック（`(p at (sample / N)) at sample`、`p` は `block`。§11.3 で刻みも状態も作らない）と、中の flow の本体の中だけで受け渡す `sample * N` の値は数えない。決定の「宣言したもの（式の導くクロック…）」は、N 単体が 2^31 以内であることを指す。段・位置・flow をまたぐとき・中の flow が単独で超えるとき（中の flow にだけ出す）の扱いは S-1089 と同じ。仕様の字は §11.3 の導くクロックの N の段落と §11.9 の連鎖の項の新しい行（字の監査 `target/notes/178/s1218/audit/report.md`）。
