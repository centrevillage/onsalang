# S-1216 細部: 式の導くクロックと変換の flow の入出力の N 単体の上限（S-1089 で経路の積に数えない N。今は 2^31 まで通る）

- 空白: S-1089 は「経路の `.down~`・`.up~` の N を向きによらず全て掛けた積が 2^24 以内」とし、式の導くクロック（`p at (sample / N)`）と変換の flow の入出力（`x: F32 at (sample * N)`）の N は数えないと決めた。数えない N 単体の上限（2^24 か、`Ratio` の指数の範囲の 2^31 か）は、決定にも補い（2026-11-21 の 172・174 回目の問い）にも答えが無い。今の実装は 2^31 まで通す（W7-16 U5b1 の事例 `tests/spec/flow_clock/e0808_modifier_product_not_counted.onsa` の `p at (sample / 2147483648)`・`x: F32 at (sample * 2147483648)`）。通るプログラムは変わらない（今通る形のまま）。
  読み: (1) N 単体の上限は今の構文と型の上限（2^31）のまま、(2) 修飾子と同じく 2^24。
  仮の扱い: (1)（今の実装）。急ぎ: W7 の区切りで確認だけ（`rules/leader.md` 5.11）。
