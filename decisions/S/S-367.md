# S-367 関数型の返り値の後ろの `at`

- 空白: 関数型の返り値の後ろの `at`（`f: fn(F32) -> F32 at sample`）が、関数型の返り値に付くか（型の中の `at` は構文の段の E0020、S-356）、外の位置（flow の入出力の宣言、フィールド、束縛）に付くか。§3.1 と §11.3 は書かない。
  W3-09/i は外の位置に付ける読みで実装する（近い方に付けると、flow の入力で「後ろへ移す」候補が同じ文を返し、直らない。`SPEC-GAP(S-367)`）。W3-09/i で見つけた（2026-10-09）
- 提案: 決定（2026-10-09、利用者が ID を挙げて推奨の (b) を了承。下書きと Fable が一致、第 16 組）: 返り値に付く（`uses` と同じく近い方）。括弧の無い形はどの位置でも型の中の `at` の E0020（S-356）。関数型を書いた位置のクロックは関数型を括弧で囲む（`g: (fn(F32) -> F32) at block`）。
  flow の入出力の型の中の候補は、関数型を括弧で囲んでクロックを後ろへ移す形。この括弧は S-364 の括弧と同じく外すと構文の段の誤りになるので fmt は外さない。
  決め手: 関数型の位置に付く読みでは、`fn f() -> fn() -> F32 at sample uses {Alloc}` から `at` を外す候補で `uses {Alloc}` が返り値の関数型へ移り、型が黙って変わる。`x as fn() -> F32 at sample` も E0020。
  一つの型に `at` が二つ（`g: fn(F32) -> F32 at block at sample`）は内側が E0020、外側は flow の入力のクロック。仕様 §11.3、§18.2。実装は W3-09（今の仮の読みを改める、約 20〜40 行）
