# S-472

- 空白: `1.e_3`。`1e_3` は浮動小数（`_` は数字の間に書ける）だが、`1.e_3` は §2.4 の「`e`・`E` と数字が続けば」に当たらず、名前 `e_3` のメンバの `.` と読む（型の段の E0420）。W3-05/b の単位 1 が見つけた（2026-10-13。17 回目の scratchpad の `w305b1/handback_b.md` の G-4）。親が W3-05 の単位 2 のバイナリで確かめた
- 提案: 後の段（急ぎは低）
- 時期: W3
- 決定: 決定（2026-11-09、利用者。128 回目、共通の規則 S-965 と利用者の判断 B1〜B8、`target/notes/128/r58/decisions.md`）: （出所: R4）`.` の後の `e`・`E` に（符号を挟んでよい）数字を一つ以上含む数字と `_` の並びが続けば、指数の形（`1.e_3`、`1.E_3`、`1.e-_3`、`1.e__3`）で、`float_dot_exponent` の E0020（候補 `1.0e_3`）。数字の無い `1.e_` は今のままメンバの `.e_`（E0413）。
  - 仕様の節: §2.4（`.` の読み方の文）。
  - 今通るプログラム: 変わらない（整数に `e_3` などのメンバは無い）。
  - 実装の見当: `literal.rs` の `point_after_int` の `Exponent` の条件に `_` の並びを足す（5〜10 行）。
  - ぶつかる事例: なし。
