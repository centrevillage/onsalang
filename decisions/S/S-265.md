# S-265

- 空白: §2.5 の段の数え方の細部: (1) 空のタプル `()`（値と型）は一段か、リテラルと同じ 0 段か。(2) 負の整数 `-1` は、式では前置の `-` の形で一段、パターンと const 引数（`Ring[F32, -1]`）では 0 段で、同じ字面が文脈で違う段になる。
  (3) 呼び出しの引数の `inout x` は数えず、`move x` は一段（§5.2 の「`move x` は他の位置にも書く式の形」）。境界（256 と 257）の判定だけに効く。W3-14/b で見つけた（2026-10-08）
- 提案: 決定（2026-10-08、利用者が ID を挙げて了承。親の案、W3-14 の実装: 段は値でなく構文の形で数える。(1) `()` はタプルの形で一段。(2) 式の `-` は前置の演算子の形（S-227 の「リテラルに含める `-`」は範囲の検査の値の規則）で一段、パターンと const 引数の `-1` は文法でリテラルの一部で 0 段。(3) `inout` は引数の印で式の形でなく 0 段、`move x` は式の形で一段）
- 時期: W3
