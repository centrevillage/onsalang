# S-587 イベントとホストの情報の C の型の字: `onsa_event_kind`・`onsa_host_kind` の列挙子、`onsa_event_in_info`・`onsa_host_info` の欄、出力のイベントの値が `()` のときの `value`、`<P>_OUT_EVENTS_PER_FRAME` を置く flow

- 空白: §14.2 は、`onsa.h` の種類の列挙 `onsa_event_kind`（境界の型ごと）と `onsa_host_kind`（`tempo` など）、表の要素の型 `onsa_event_in_info`（名前と種類）・`onsa_host_info`（名前、種類、`offset`）、出力のイベントの `<p>_out_event` の値の欄 `value` を置くとしたが、列挙子の名前と構造体の C の定義を書いていない（`onsa_param_kind` の `ONSA_PARAM_F32` などは書いてある）。
  決めること: 1. 二つの列挙子の名前と順（「出力が無い」を表す値を含む）。2. 二つの表の要素の構造体の欄と型。3. 出力のイベントの値が `()` のときの `value`（入力の側は「`v` を置かない」）。4. `<P>_OUT_EVENTS_PER_FRAME` を全ての flow に置くか、イベントの出力のある flow だけか。
  決まったら §14.2 のヘッダの例に `<P>_EVENT_OUT_KIND` の行を足す。
