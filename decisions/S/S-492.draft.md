# S-492 `fn` 以外の宣言の前の `rt`

- 族の規則: S-593 の規則から決まる（`S-593.draft.md` の表 1 の 13・14 行。論点・今の実装・案・他言語・影響は S-593 の下書きにある）。
- 推奨と理由: S-593 の規則から（下書きの推奨は S-593 の (b)）。表 1 の 13・14 行。S-464 の修飾の並びの一つの E0002（主の範囲は最初の修飾から最後の修飾まで）にし、候補は `rt` を除き可視性を一つにした並び（`pub` と `priv` が両方なら候補なし）。置き場所の無い `rt` は記録しない。
  `impl`・`extern`・`trait`・`handler` の前の `rt` も同じで、メンバへ写す候補は作らない（extern のメンバの `rt` は検証されない主張で、候補が主張を作らないため）。
- 独立のレビュー（2026-10-23、助言の担当の二段）: 一致（読み続け、候補は `rt` を除いた並び、可視性の衝突は候補なし。`impl`・`extern`・`trait`・`handler` の前も同じで、メンバへ写す候補は作らない。`export rt struct` は 2 周）。
  段 1 は、`rt flow lp` の偽の E0812 の候補（`~` を外す）を当てると E0302 になり宣言を直した後に戻す編集になること、`flow` の本体は `rt fn` しか呼べない（§11）ので `rt` を除いても意味が変わらないことを確かめた。
- 回答（2026-10-23、会話で利用者。55 回目）: 読み続け、候補は `rt` を除いた並び（可視性の衝突は候補なし、メンバへ写す候補は作らない）。了承（(A)）。
