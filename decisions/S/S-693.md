# S-693 他のモジュールの本体の経路の最後の要素が、E0200 の `pub use` の取り込む名前のとき（`use main.inner` の後の `inner.g()`、`g` は `main/inner.onsa` の `pub use util.{g}`）

- 空白: §18.1 は、E0200 の `pub use` の取り込む名前を失敗した名前とし、他のモジュールがそれを取り込む `use main.{g}` の名前も黙らせ、経路の途中に通す `use main.inner.{g}` は E0302 とする（S-596）。他のモジュールの本体の経路の最後の要素がその名前のとき（`use main.inner` の後の `inner.g()`）を書いていない。
  読みは (1) 他のモジュールの経路は項目と子モジュールの定義だけを引くので E0302（S-611）、(2) `use main.{g}` の最後の要素と同じく失敗した名前として黙る、に割れる。
  W4-03 U3b2 の実装（69 回目）は (1)（事例は無い）。急ぎ: 後の段（本体の経路の歩き手は W4-04）。
