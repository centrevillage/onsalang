# S-1199 細部: 対象やガードに `at` を書いた `match`・`match~` の腕の束縛の段（束縛のクロックか、値の決まる段か）

- 空白: §11.3（S-1196）「数える値は…それらだけで決まる `let` の名前とパターンの束縛…で、`at` と括弧を通し、条件・対象・ガードを含める。ただし条件・対象・ガードは、下の条件が決まる段で数える」と、§11.5「腕の本体で読む束縛のクロックは、対象のクロックと…ガードのクロックのうち最も速いもの…束縛を読む式は…その式の段（§11.3）で評価する」から、`match~ (o at sample) { Some(v) => x + 100 / (v - 1), None => prev~(x) }`（`o` は `block`）の `v` の段が二つに読める。
  読み: (1) 束縛の段は束縛のクロック（`at` を含む。値が腕の選びで変わり、選びは対象の条件が決まる段で決まるため）、(2) 束縛の値はパラメータの種類だけで決まるので `block` の段（`at` を透かす）。違いは panic の時期と計算の段だけで、値は同じ（(1) は `sample` で計算し 0 フレームの呼び出しで panic しない、(2) は `block`）。
  仮の扱い: (1)（W7-09 U2s の実装 `crates/onsa_sema/src/flow/clocks/stages.rs` の `name`、参照評価器も同じ読み。親が U2s/i の票に書いた読み）。急ぎ: W7 の区切りで確認だけ（`rules/leader.md` 5.11）。
