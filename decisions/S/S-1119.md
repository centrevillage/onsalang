# S-1119 細部: 分解する `let` で束縛した局所のクロック（`let (u, v) = (x, p)` の `v` は右辺の式全体のクロックか、要素 `p` のクロックか）

- 空白: §11.3 は式のクロックを被演算子から決め（部分式も含めて、そのクロックの段で評価する。`let` に分けても分けなくても同じ）、§11.2 は `let` にタプル・struct の分解を含めるが、分解で束縛した名前のクロックを書かない。
  読みは (1) 右辺の式全体のクロック（`let (u, v) = (x, p)` の `v` は `x` と同じ `sample`）、(2) その要素の式のクロック（`v` は `p` の `block`）に割れる。違いはチェックを通るプログラムに出ず、`block` の段で panic するかだけに出る（`flow f(p: I32 at block, x: I32 at sample) -> I32 at sample { let (u, v) = (x, p) ⏎ let w = 100 / v ⏎ x + u + w }` を `p = 0`・0 フレームで `process` すると、(1) は panic しない、(2) は panic する）。
  今の実装（`aea4ce78` のインタプリタ、`onsa test`）は (1)（0 フレームで panic しない）。参照評価器（W7-18 U1a）も (1) で書いた。
  仮の扱い: (1)。W7 の区切りで確認だけ。巻き上げ（W7-05）と S-1093（`init`・`block` の `let` の panic）で `let` の段を扱うときに一緒に見る。
