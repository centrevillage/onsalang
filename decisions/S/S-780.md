# S-780 Affine の型を持つ静的な値（`let o: Option[Buf[F32]] = None`、ペイロードに Affine を持つ列挙の `E.A`）: 静的な値として借用の行にするか、`Drop` を実装する型の除外（F7）を自分の型が Affine の値に広げて所有の行にするか

- 空白: §5.4 は、静的な値（`const`、補間の無い文字列リテラル、数・真偽・文字のリテラル、ペイロードの無い列挙子と、全ての要素が静的な値の集成体のリテラル）を、構文で決まり要素の型を見ないとし（`Drop` を実装する型は除く）、`let y = CONST` などの静的な値の初期化を借用の行とする。
  また「自分の型が `Drop` を実装する（Affine の、§4.6）リテラルと列挙子は、要素によらず静的な値にも破棄の要らないリテラルにもならず、所有の行である」とする（S-610・S-613 の補いの F7）。
  `Drop` を実装しないが自分の型が Affine の静的な値は書いていない: `let o: Option[Buf[F32]] = None`（`None` はペイロードが無いが、型は Affine の `Buf` を含む）と、`enum E { A, B(Buf[F32]) }` の `let e = E.A`。§5.4 の借用束縛は Affine 型なら `move` の引数へ渡せない（E0711）。
  S-613 の補いは「W4-16 の判定はリテラルの型の `Drop` の実装を見て除く」とする。第 1 期は `impl Drop` が E0200 で書けないので、`Drop` を実装する型のリテラルは第 1 期に現れない。
  形（`target/notes/84/s780/p13_affine_static.onsa`）: 今は `let` の初期化式が場所でないので所有の行になり、`f` の `take(move o)`（`move o: Option[Buf[F32]]`）と `g` の `take_e(move e)` は通る。
  同じファイルの `h`（`for o in [None, None] { let x: Option[Buf[F32]] = o }`）は今は E0711（17:31。借用の `for` の束縛からの `let` で、R-54 の形）。
  読み: (1) 書いたとおり静的な値で借用の行（`take(move o)`・`take_e(move e)` は E0711）。
  (2) F7 の除外を自分の型が Affine のリテラルと列挙子に広げ、所有の行（今の実装と同じく通る）。
  どちらでも、§5.4 の静的な値の定義と F7 の文のどちらかの字が変わるか、例が増える。
- 決定: 決定（2026-10-29、利用者。84 回目）: (b)。
  自分の型が Dup でない（Affine か、`T: ?Dup` のように Affine でありうる、§4.5・§4.6）リテラルと列挙子は、要素によらず静的な値にも破棄の要らないリテラルにもならず、所有の行である。F7（`Drop` を実装する型の除外）はこの一つに含まれる（`Drop` を実装する型は §4.6 で Affine）。
  `let o: Option[Buf[F32]] = None; take(move o)` と `let e = E.A; take_e(move e)` は今のまま通る。判定は自分の型の種で、要素の種と同じく本体の型の推論の後の型（既定を当てた後）で行う。境界の無い `T` と `T: Copy` は Dup、`T: ?Dup` は Dup でない。
  理由: 静的な値を借用の起点にした理由（複製も破棄も何もしないので失うものが無い、S-80）は Dup の値にだけ当たる。暗黙の借用は外から見えない Dup の値にだけ当て、Affine の値は所有の Affine と同じに扱う。今通るプログラムを落とさず、除外の数も増えない。後で (c) へ緩めても既存のプログラムは壊れない。
  他言語は局所の束縛を所有にする（Rust の `const`、Swift の局所の `let`、Move、Austral。`target/notes/84/kinds-research.md`）。
  代わりに: rt の関数と `Alloc` の無い関数で、Affine の型の `None`・`E.A` を `let` に置いて破棄する形は E0901・E0601 のまま（W6-02 の後は rt の `match E.A { … }` の一時の値も E0901）。
  仕様は §5.4 の静的な値の段落の除外の括弧、要素の種の文、F7 の文。S-610・S-613 の補いの「`Drop` の実装を見て除く」は、自分の型の種で除くに改めた（補い）。実装は W4-16 の U2（`const` の名前の葉は U1a）。
- 経緯: 84 回目（2026-10-29）、W4-16 の設計メモ（onsa-impl、memo/i）が仕様の空白（NEW-1）として報告し、親が仕様の字と再現を確かめた。設計メモは F7 を `Drop` の実装でなく種（Affine か）で判定する作りを出しており、その作りでは (2) になる。期限は W4-16 の U2（ペイロードの無い列挙子とその集成体を静的な値にする単位）の前。関係: S-610、S-613、S-615、R-54。
