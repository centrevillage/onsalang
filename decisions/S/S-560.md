# S-560 イベントのクロックの意味と、クロックの順序の一般の形

- 空白: §19.1（S-171）は、flow の入力にイベントのクロックの値を渡す方向（`notes: midi.Message at event`）、イベントはブロックの中の位置を持ちホストが位置を決めること、イベントのクロックがイベントごとに一回刻む（同じサンプルの中で複数回刻みうる）ことを決めた。決めること:
  1. イベントのクロックの定義（刻みの言葉で。第 33 組の `when` のクロック、S-558 の (4a) と同じ形にする）と、flow の本体の中でイベントのクロックの式が評価される段。
  2. クロックの順序の一般の形。今は `定数 < init < block < sample` の全順序で、式のクロックは最大値で決める（§11.3）。イベントのクロックと、後で入る導くクロック（`sample / 32`、§19.1 のマルチレート）を入れても成り立つ形（半順序と、式のクロックの決め方）。
  3. イベントのクロックの入力を宣言できる型（Copy の型、利用者の型を含む、§19.1）と、一つの flow が持てるイベントの入力の数。
