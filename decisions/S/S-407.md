# S-407

- 空白: チャンネルが一つも無い flow（`sample` の入力が無く、出力が `[F32; 0] at sample` の `pub flow z() -> [F32; 0] at sample { [] }`）。
  §11.6 は `sample` の入出力の値型を「スカラ、`[スカラ; N]`、…」とし、`N = 0` を除かず（E0810 にするかを書かず）、Span が一つも無いときの `process` のループの回数（長さをどこから取るか）を書かない。
  今の実装は Core の `process` が 0 番のチャンネルの長さを読み、`index 0 out of range` で panic する（W2-08 の前からの挙動）。W2-08/i の報告で見つけた（2026-10-10。再現は 10 回目の scratchpad の `w208i/z/z2.onsa`）
