# S-1157 族: §11.3 の巻き上げの評価の段と panic（何を巻き上げるか、panic しうる式と Copy でない値をどの段のどの位置で評価するか）

- 空白: §11.3 は、遅いクロックの最大の部分式を状態に置いて巻き上げ（その段で評価し、速い段は欄を読む）、「`let` に分けても分けなくても、評価の段と結果は同じ」とし、同じ節で「`if` / `match` の取られない枝と、評価されない `&&` / `||` の右辺の部分式は、巻き上げても panic を起こさない（panic しうる部分式は巻き上げず、その位置で評価する、§11.5）」とする。§12.4 は状態の値型を Copy とする。
  何を巻き上げるか、panic しうる式と Copy でない値をどの段のどの位置で評価するかの一般の規則が一つに決まっていないので、形ごとの S（S-888 の `panic("x")`、S-1046 の Copy でない値、S-1080 の panic しうる部分式の範囲、S-1093 の `init`・`block` のクロックの `let` と出力の式）が別々に割れる。族の一般の規則を一つ決め、個々の S はそれから決める（`rules/process.md` 8.6 の「仕様の空白の流れ」の 2・3）。
  関係: 細部 S-1140（`par~` の本体の巻き上げの欄の置き場所と番号）、S-1126・S-1154（遅延の保存の panic の時期と順）、第 110 組（巻き上げの欄の名前 `_hoist`、S-1138・S-1081・S-1136・S-1137）、S-152（`at` で速くする計算した式の値の置き場、W7-05）、S-1043（flow の本体の暗黙の `Alloc`）、W9-03（定数のクロックの式の評価と E0419）。
- 決定: 決定（2026-11-19、利用者。168 回目。第 113 組。下書き（onsa-gap）と独立のレビューの段 1（onsa-advisor）と親の読みを突き合わせた。控え `target/notes/168/g113/`）: (D′)。式は、値と評価されるかどうかが決まる最も遅い段で評価する。
  条件の位置（`if` / `match` の枝、`match` のガード、`&&` / `||` の右辺。条件、`match` の対象、左辺、`if~` / `match~` の腕は含めない）の外の式と、本体の `let` の値と出力の式は、そのクロックの段で無条件に評価する。
  条件の位置の中の `init`・`block` の式は、その位置を選ぶ条件（根からその位置までの `if` の条件、`match` の対象とその腕までのパターンとガード、`&&` / `||` の左辺）が全て `init`・`block` の段で決まるなら、式のクロックと条件の段のうち最も速い段で、条件が成り立つときだけ評価する（守り付きの欄）。条件のどれかがサンプルごとに決まるなら巻き上げず、届いたときに評価する。条件は評価する段で数える（`at` は段を変えない）。
  値は (D) と同じで、panic は無条件の位置と同じ扱い（守りの条件が成り立てば 0 フレームの呼び出しと止まっている部品でも起きうる、`init` の式は `init` で）。規則は `init`・`block` の式に限り、刻みのクロック（イベント、`sample / N`）は S-1158。定数のクロックの式は S-888。Copy でない部分式は S-1046。
  定数でない引数を持つ rt でない fn の呼び出しは、その位置を選ぶ条件のどれかが `init` より速い段で決まる条件の位置では E0815（前の `let` に出す。§11.5）。
  経緯: 下書きと段 1 はまず (D)（条件の位置は巻き上げない）を推した。利用者が「遅い条件と枝を組にして巻き上げる変種の方が本来期待される処理」と見て、advisor が (D′) を確かめ（`target/notes/168/g113/dprime_report.md`）、推した。(A) 段で無条件（守りが壊れる）、(B) 使う位置（段の約束を改め後の段ごとに例外）、(C) panic しうる式の分類（演算を足すたびに手当て）は採らない。
  **条件付きの了承（利用者）:** 「想定より影響がひろがるようなら、その時は考え直す」。W7-05 の実装が advisor の見積もり（(D) に対して +200〜400 行、W7-05 の単位が一つ増える）を大きく超えるなら、利用者と考え直す（`rules/leader.md` 5.4）。仕様 §11.3、§11.5。
