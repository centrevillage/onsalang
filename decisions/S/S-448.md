# S-448

- 空白: 補間の穴の E0001 の note を選ぶ基準。§2.4 は「式には `let` で名前を付けてから補間する、書式の指定は無い、と note で示す」とし、どちらを示すかの基準を書かない。今は穴に `:` があれば「書式の指定は無い」で、`{c ? 1 : 2}`・`{a::b}`・`{f(a: 1)}` も書式の note になる。W3-04/b が見つけた（2026-10-11）
- 提案: W3-04 は今の挙動のまま。後の段
- 時期: W3
- 決定: 決定（2026-11-09、利用者。128 回目、共通の規則 S-965 と利用者の判断 B1〜B8、`target/notes/128/r58/decisions.md`）: （出所: 既存 §2.4）補間の穴の E0001 の note（`let` で名前を付ける、書式の指定は無い）のどちらを示すかは約束しない。実装は、穴の頭の名前の経路の直後に `:` があるときだけ書式の note にしてよい（今は `:` を含めば書式の note で、`{c ? 1 : 2}`・`{a::b}`・`{f(a: 1)}` もそうなる）。
  - 仕様の節: §2.4 に一句。今通るプログラム: 変わらない。実装: `lexer.rs`の条件（5〜10 行、任意）。事例: なし。
