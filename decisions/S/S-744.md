# S-744 型と定数をまたぐ循環（`type A = [F32; K]` と `const K: A = 3`、定数の型が自分の値を長さに読む）のコード: E0311・E0312 のどちらか、別のコードか

- 空白: §4.4 は型が自分自身を値として含むと E0311、§6.6 は定数の初期化式が自分自身を参照すると E0312 とし、§18.1 は宣言をまたぐ循環を集まりごとに一つ報告する（S-734）。
  型と定数をまたぐ循環（別名の型が定数を長さに読み、その定数の型がその別名、`type A = [F32; K]` と `const K: A = 3`）は、どちらの文にも当たらず、コードが書かれていない。S-725 の下書きは、定数の型が自分を指す形（`impl S { const N: [F32; S.N] = … }`）に守りを置くとしたが、報告のコードは決めていない。
  読み: (1) E0311（型が自分を含む）。(2) E0312（定数が自分を参照する。型の位置の参照も含む）。(3) 新しいコード。(4) 循環を作らない形として、この版の他の誤り（式で計算した定数の長さの E0200 など）に任せる。
  今の実装（`d8e0472` 以後、W4-19 の後も同じ）: `target/notes/79/s744/alias_const.onsa` は E0401「an integer literal cannot have type `[F32; 3]`」（落ちない）。
