# S-744 型と定数をまたぐ循環（`type A = [F32; K]` と `const K: A = 3`、定数の型が自分の値を長さに読む）のコード: E0311・E0312 のどちらか、別のコードか

- 空白: §4.4 は型が自分自身を値として含むと E0311、§6.6 は定数の初期化式が自分自身を参照すると E0312 とし、§18.1 は宣言をまたぐ循環を集まりごとに一つ報告する（S-734）。
  型と定数をまたぐ循環（別名の型が定数を長さに読み、その定数の型がその別名、`type A = [F32; K]` と `const K: A = 3`）は、どちらの文にも当たらず、コードが書かれていない。S-725 の下書きは、定数の型が自分を指す形（`impl S { const N: [F32; S.N] = … }`）に守りを置くとしたが、報告のコードは決めていない。
  読み: (1) E0311（型が自分を含む）。(2) E0312（定数が自分を参照する。型の位置の参照も含む）。(3) 新しいコード。(4) 循環を作らない形として、この版の他の誤り（式で計算した定数の長さの E0200 など）に任せる。
  今の実装（`d8e0472` 以後、W4-19 の後も同じ）: `target/notes/79/s744/alias_const.onsa` は E0401「an integer literal cannot have type `[F32; 3]`」（落ちない）。
- 決定: 決定（2026-10-28、利用者。79 回目、第 71 組。細部は ID を挙げて了承）: (1)・(x)。
  型と定数をまたぐ循環は E0311。固定長配列の長さと const 引数が読む定数は、その定数の宣言の型を辿る（`type A = [F32; K]` と `const K: A = 3`、別名を通さない `const K: [F32; K] = 3`、関連定数の `impl S { const N: [F32; Self.N] = … }`）。
  集まりが型の宣言か定数の宣言の型を通れば E0311、初期化式だけの集まりは E0312（S-734）。数・位置・note・外の扱いは §18.1（S-730・S-734）。決まらないのは型の大きさで、§4.4 の E0311 の理由がそのまま当たる。
  細部（確認だけ）: モジュールをまたぐ宣言の循環（型と定数）は E0310 だけ。S-734 の定数の規則を型にも当てる（他のモジュールの項目は `use` でだけ引け、`use` は依存に数えるので、必ず `use` の循環の中にある）。宣言の順を逆にした形は §18.1 の位置の規則のまま（`K` が先なら `K` の名前に E0311）。
  (x) は S-725 の決定の「この版では、定数の型が自分を読む形は…E0200 になり…新しい診断は要らない」を改める（S-725 の補い）。
  仕様は §4.4 の E0311 の段落、§4.5 の 137 行（初期化式の評価の循環は E0312、宣言の型を通る循環は E0311）、§6.6 の 201 行の指し、§18.1 の 66 行（モジュールをまたぐ循環）に書いた。`tasks/diag-codes.md` の E0311 の行に足した。
  実装は W4-05 の U2: 型の宣言のグラフの循環を E0311 で報告する（審査の表 1 の (i) のまま）。定数の宣言の型の長さと const 引数から定数への辺（約 +2〜3 行。`Self.N` は `impl` の対象を通すので特別扱いしない）。モジュールをまたぐ型の閉路に E0310 の守り（共通の報告の関数）。事例は別名と定数、別名の無い形、関連定数の形（最初の宣言の行だけに印）。
- 経緯: 79 回目（2026-10-28）、W4-05 の設計メモ（onsa-impl）が空白として報告し（コードの読みだけ）、親が再現した。急ぎの見立ては「後の段」（W4-05 の守りで落ちない見込み）。関係: S-725、S-730、S-734、R-02。
