# S-1155 細部: flow の遅延の値型が Copy でなく `Default` も満たさないとき（省いた `init` の `prev~(z)`、`z: Option[Str]`）、E0810 と E0816 のどちらを報告するか

- 空白: §11.3 は状態を持つものが作る値の型を名前を付けない位置でも Copy とし（E0810、S-1047 (d)、R-458）、§11.4 は省いた `init` の値型が `Default` を満たさなければ E0816 とする。二つは同じ位置（遅延の呼び出し）と同じ段（flow の検査）に当たり、§18.1 はその順を書かない。
  読みは (1) E0810、(2) E0816、(3) 両方に割れる。誤りのあるプログラムの診断のコードだけが変わり、通るプログラムは変わらない。
  再現: `let z: Option[Str] = …` の後の `prev~(z)`（省いた `init`）。今は省いた `init` の E0200 で止まる。
  仮の扱い: (1) E0810（S-1153 と同じ類）。W7-07 U2 の否定例の期待はこの扱いで書く。急ぎ: W7 の区切りで確認だけ（`rules/leader.md` 5.11）。
