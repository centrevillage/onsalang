# S-485

- 空白: FAUST の合成の演算子（`faust_compose`）の行が当たる位置。
  データのファイルの例は flow の中の `let` の値の `x : x`・`x <: x`・`x :> x`・`x, x`（空白のある `:`）だけで、空白の無い `x:y`、fn の中、`,` の範囲（`if a, b {`、`for i in …, j in …`、C の `let a = x, b = y`）、括弧と見出しの中（`xs[1 : 2]`、`lp~(x, cutoff : 1.0)`、`if c : x`）を書かない。
  仮の扱いは、flow の本体の `let` の値と文の位置の式で、括弧と見出しの外、`:` の前に空白、同じ行に被演算子があるときだけ行に当て、他は一般の E0002（`foreign/faust.rs` の `SPEC-GAP(S-485)`）。
  「文の位置」は `Block` の親が flow・`if`・`par` のときで、`while`・`for` の本体と `let y = { … }` のブロックは今は外れる（W3-23/b の再確認）。W3-23/b が見つけた（2026-10-13）
- 提案: 決定（2026-10-13、利用者）: 対象外（FAUST の文法の形は `rules/criteria.md` 7.32 で対象にしない）。今の扱いのまま残し、`foreign/faust.rs` の印を対象外のコメントに改めた
- 時期: W3
