# S-732 const 引数の位置に、名前でない型の形（タプル型 `(F32, F32)`、関数型 `fn() -> I32`、配列型 `[F32; 3]`）を書いたとき、§15.1 の「型を const 引数の位置に書く」E0308 か、名前の種類の規則の外の E0401 か

- 空白: §15.1（`spec/15-modules.md` 69 行）は「型を const 引数の位置に書く」を E0308 の例に挙げる。E0308 は「名前は見つかったが、その位置に要る種類でなければ」の規則で、名前を持たない型の形を const 引数の位置に書いたときのコードが書かれていない。
  読みは二つに割れる。(1) 型の形は全て E0308（`Ring[F32, (F32, F32)]`、`Ring[F32, fn() -> I32]`、`Ring[F32, [F32; 3]]`）。(2) E0308 は名前の種類の規則なので、名前を持たない型の形は型の誤りの E0401（頭が名前の `Option[F32]`・`Wrap[F32]` は、頭の名前が型なので E0308）。
  今の実装（W4-04 U8b、未コミットの主のツリー）: 裸の名前（`Ring[F32, F32]`、`Ring[F32, P]`）は E0308、名前でない形と型引数の付いた形は E0401（前の版も全て E0401）。頭が名前の形は U8b の直しで E0308 にする見込み。再現は 78 回目の scratchpad の `w404/u8b/b/t5.onsa`（区切りで `target/notes/78/w404/u8b/` へ写す）。
  通るプログラムは変わらない。
- 決定:
- 経緯: 78 回目（2026-10-28）、W4-04 U8b/b（onsa-break）の空白 B。期限は無い（決まるまで名前でない形は今の E0401）。関係: S-103、S-713。
