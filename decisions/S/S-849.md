# S-849 推論した型の上限（S-264）の誤りの位置: 推論の変数が後の文で決まり、上限を超える形の「型を作った式」

- 空白: §4.7 の推論した型の上限（S-264。深さ 256、大きさ 4096）は、本体で推論した型が上限を超えたときの誤りを「型を作った式」に置く。推論の変数が後の文で決まり、上限を超える形（`let t = (a, k)` の `a` の型が後の文で決まる）では、記録した式か、変数を決めた文かで位置が割れる。
  誤りの位置だけで、通るプログラムは変わらない。急ぎ: W5-16 の前（推論した型の上限の単位）。
- 決定: 決定（2026-11-07、利用者が ID を挙げて了承。121 回目、第 91 組。下書きと独立のレビュー（段 1）が一致）: (b)。位置は型を作った式で、型変数を決めた式を位置付きの note で示す（S-235 の E0416 と同じ形）。判定は変数が決まった文の後で、変数が残っていても超えていれば報告する（測りは増える方向にだけ動く）。§4.7 の後回しの検査の一覧に足す。候補は無い。通るプログラムは変わらない。
- 経緯: 104 回目（2026-11-02）、X-23 の見積もりの組 C（onsa-impl）が W5-08 の見積もりで挙げた。関係: S-264。
