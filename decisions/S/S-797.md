# S-797 派生した借用束縛の、元の場所の別の部分の変更による無効化（`let c = hh.buf`、`hh` は `match w` の腕の束縛、変更は `w.h.n`）

- 空白: §5.4 の 123 行は、`match x` の腕の束縛から派生した束縛も、腕の中で `x` を変更すると「重なるもの」が以後使えなくなるとし、§7 の 52〜53 行は重なりを `inout` の重複（E0702）と同じく判定し、異なるフィールドは重ならないとする。S-42 は派生した束縛も「一緒に」無効にするとする。
  派生の鎖で、元の束縛の場所と重なるが派生した束縛の場所とは重ならない変更（`let c = hh.buf` の後の `w.h.n` の変更）を、派生した束縛の無効化に数えるかを書いていない。
  `var w = mkwrap(); match w { Wrap { h: hh, k: kk } => { let c = hh.buf; io_n(inout w.h.n); len_of(c) } }` は、W4-07 U3b の新しい modes で E0704（派生の鎖を束縛の全体でたどる）。
  同じ意味の `match w { Wrap { h: Holder { buf: bb, n: nn }, k: kk } => { w.h.n = 2; len_of(bb) } }` は通る。dev と U3a までは通る。再現は `target/notes/87/w407/u3b/b/c18.py` の `fld_derived_field_of_binding_disj`。
  読み: (1) 派生の鎖は射影を合成する（`c` の場所は `w.h.buf` で、`w.h.n` の変更と重ならず使える）。(2) 鎖は束縛ごとに全体で数える（`hh` が無効なら派生した `c` も無効、今の実装）。
  親の読み（確認だけの案）: (1)。§5.4 の「重なるもの」と §7 の「異なるフィールドは重ならない」の判定を派生の鎖にも当てる。(2) は同じ意味の二つの書き方で結果が変わる。S-42 の「一緒に」は、重なる変更で元が無効になるときに派生も同じく判定することと読む。仕様の文は変えない（読みが一つに決まる）。
