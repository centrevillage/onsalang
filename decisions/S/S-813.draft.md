# S-813 flow の本体で flow を `!(` で呼ぶ形（`lp!(x)`）

- 決定済みで戻さないもの: flow の外の `lp!(x)` は §11.1 の E0821（`~` 無しの flow の呼び出し。名前の段で E0714 より先）、`prev!(…)` は flow の外では見えない名前で E0302（S-720）。
  flow の本体の `!` の呼び出しが名前の段の E0806 であること（S-125・S-267。実装は W7-04）。flow・遅延の `~(` と `(` の形（§2.6）。
  第 76 組の下書きの「仕組みの出所」と「族の形の表」の節（写しは `target/notes/93/g76/draft.md`）。
- 論点: §2.6（185・186 行）は flow の本体で flow を `~` 無しで呼ぶ形を E0811（候補は `~` を足す）、§11.2（39 行、S-125）は `!` の呼び出しを flow の本体の E0806 とし、§18.1（S-267）はどちらも名前の段とする。§5.2 の E0714（型の段）も当たる。
  `lp!(x)` には三つの規則が当たり、名前の段の二つ（E0806 と E0811）の順と、候補（`!` を `~` に置き換えるか）を書いていない。
- 今の実装: flow の本体の `lp!(x)` と `prev!(x, 0.0)` は flow の段の E0714「`!` marks `inout self` method calls only」と、呼び出しの全体を `lp(x)`・`prev(x, 0.0)` で置き換える候補（`m/flow.out` の w117・w125）。
  当てると E0811 と `~` の挿入の候補 → 誤りなし（`x/loop.out`、二回。当てた後に同じ flow の段の誤りが残る）。
  比べ: flow の本体の `g!(x)`（項目の関数）は型の段の E0714 と「remove `!`」で一回で直る（w029）。`Some!(x)`・`p.get!()`・`q.put!(x)`（`let` の束縛）は通る（`x/` の各入力。S-125 の E0806 が未実装、下の「別の問題」の 2）。
- 案: どの案も、flow の外の形と、flow・遅延の `(` の E0811 は変えない。
  - (a) E0806（書いた印 `!` の flow の本体の規則、S-811 の (a) の 1）。候補は `!` を `~` に置き換える。note で `lp` は flow で `lp~(…)` と呼ぶことを示す。
  - (b) E0811（`~` の欠け、§2.6）。候補は `!` を `~` に置き換える。E0806 の `!` の呼び出しは、呼び先が flow・遅延の形に当てない（E0811 が先）と一句書く。
  - (c) E0714（今の型か flow の段）。候補は無い（`!` を消すと E0811 が残り、`~` に置き換えるのは E0714 の候補の形でない）。E0714 は候補が必須なので、S-812 の (c) と同じく §5.2 と登録簿の必須の印を直す。
  - 形ごとの出力: `lp!(x)` と `prev!(x, 0.0)` は、(a) が E0806 と候補 `lp~(x)`、(b) が E0811 と候補 `lp~(x)`、(c) が E0714 だけ。`g!(x)` は (a)・(b) が E0806（S-125、候補は `!` を消す）、(c) が E0714。
  - 書き手から見て（修復のループの回数）: (a)・(b) は一回、(c) は二回。`lp!(x)` は、`~` と `!`（どちらも「名前の直後の印 + `(`」）の取り違えか、flow を状態を変える呼び出しと読んだ誤解である。
    (b) の文面は「`lp` は flow で `~` が要る」と直す所を名指す。(a) の文面は「flow の本体に `!` の呼び出しは書けない」で、flow を呼ぶ形は note で示す。
  - 修正候補: (a)・(b) の候補 `lp~(x)`・`prev~(x, 0.0)` は当てた後に誤りなし（`m/flow.out` の w119・w127）。当て続けて止まる。編集は `!` の 1 字の置き換えで、R-285 と同じ全体の置き換えは無くなる。(c) は候補なしで止まる。
  - 通るプログラム: どの案も変えない。
  - 規則と例外: (a) は S-811 の (a) の 1 から決まり、S-125 の文のまま（例外なし）。E0806 と E0811 が同じ名前の段で同じ呼び出しに当たる順は S-811 の (a) の順の一文が決める。
    (b) は、E0806 の `!` の呼び出しから flow・遅延の呼び先を除く一句（S-125 への例外）か、E0811 を E0806 より先にする順の一句が要る。(c) は §18.1 の段の順（E0806 は名前の段で E0714 より先）と食い違い、W7-04 で変わる。

  - 後の作業への手当て: (a) は、W7-04 の E0806 の一般の形が U2 の flow・遅延の分と同じ候補の規則（S-811 の (a)）を使う。(b) は、W7-04 が E0806 を名前の段で出すとき、flow・遅延の呼び先を除く分岐を足す。(c) は W7-04 で出力と候補を決め直す。
