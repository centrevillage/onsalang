# S-715 型の段で無いと分かった `process_inplace` を取り込む `use` の名前を、本体の注釈（`let x: process_inplace = 1`）に書いたとき、S-708 の「有無によらず E0308」か、§11.6・§18.1 の「以後の使う所は失敗した名前として黙る」か

- 決定済みで戻さないもの: 型の位置（署名、型引数、関数の型、`impl` の見出し、本体の注釈）の `process_inplace` は、有無によらず E0308（S-708）。`use` は名前の段で解決した束縛で、E0304 と E0310 に数える（S-694、S-709）。値の位置（`let f = process_inplace`）の使う所は黙る（§18.1）。
  残るのは、本体の注釈で、失敗した名前の黙りと S-708 の E0308 のどちらを先にするかだけである。
  第 65 組の下書きの「仕組みの出所」の節と「族の形の表」（写しは `target/notes/75/g65/draft.md`。表の行の番号はその表のもの）。
- 論点: §11.6 は、無い flow から取り込む `use`（`use dsp.synth.one.{process_inplace}`）を「型の段の E0302 になる（以後の本体の使う所には診断を出さない、§18.1）」とし、次の文で「型の位置（署名と本体の注釈）に書いても…有無によらず型でない名前の誤りである」とする。
  §18.1 は「型の段で無いと分かれば、その `use` に E0302 を出し、以後その名前を失敗した名前として扱う」。署名は型の段の前に読むので E0308 が先に決まるが、本体の注釈は型の段の後に読むので、二つの文の両方に当たる。
- 今の実装: `P75/w404/parent/f1/main.onsa` で、`let x: process_inplace = 1` は黙り、`use` の E0302「cannot find `one.process_inplace`」だけ。同じ所の `let x: reset = 1` は E0302「`reset` is not a type」（U8 で E0308）。終了コード 1。
- 案:
  - (p) 本体の注釈も E0308。種類は §11.6 の一覧で決まっているので、失敗した名前の黙りは、名前が指しえたものに頼る判定（値の位置、型の推論）に限り、種類で決まる E0308 は黙らない。
  - (q) 黙る。§18.1 の失敗した名前の扱いを先にし、S-708 の「本体の注釈」は、有る flow のときだけになる（S-708 の決定を改める）。
  - 出力の違い: (p) は `use` の E0302 と注釈の E0308 の二つ。二つは別の誤りで、flow に `sample` の入出力を足しても注釈の E0308 は残り、注釈を直しても `use` の E0302 は残る。偽の連鎖ではない。
    (q) は `use` の E0302 だけで、flow を直した二回目の検査で E0308 が出る。同じ名前を署名に書くと一回目から E0308 なので、署名と本体の注釈で出方が分かれる（S-708 が退けた形）。
  - 修正候補: どの案も無い。
  - 後の作業の費用: どちらの案も、後の段と後の作業に続く手当ては無い。(q) は決定済みの S-708 の文と §11.6 を改める。
  - 実装: (p) は、W4-04 の U3a で本体の型の位置も名前の段が解決した後は、名前の段の種類の判定（`process_inplace` は名前の段で解決した関数の束縛、S-694）に含まれ、追加はほぼ無い見込み（U3a の前の形なら、`lower_type_in_body` が失敗した名前として読む前に生成項目の関数の名前の表を引く約 +5 行）。(q) は 0 行（今のまま）と、§11.6 の文と S-708 の改め。
- 他言語: 調べていない（S-713 の下書きの他言語を見る）。
- 推奨と理由: (p)。確度: 中〜高。
  - 失敗した名前の黙りは、名前の指すものが分からないときの偽の連鎖を避けるためにある。ここでは種類が §11.6 の一覧で分かっていて、E0308 は有無と独立の誤りなので、黙る理由が当たらない。
  - S-708 の「型の位置では有無が直し方を変えない」と「署名と本体の注釈で分けない」がそのまま当たり、例外の規則が要らない。実装も約 +5 行で、W4-04 の U8 の S-708 の所に入る。
  - あわせて決めること: §18.1 の文を「以後その名前を失敗した名前として扱う（型の位置の E0308 は §11.6 の項目の種類で出す）」に、§11.6 の「以後の本体の使う所には診断を出さない」を「値の位置の使う所には」に改める。
    同じ回に、§11.6 の「署名と本体の注釈」を S-708 の位置の並び（署名、型引数、関数の型、`impl` の見出し、本体の注釈）に揃える（文書の点検の F7）。

  (p) では本体の注釈の事例が E0308、(q) では診断なし。
