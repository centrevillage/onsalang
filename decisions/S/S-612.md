# S-612 `const` と静的な値の置き場所（組込みの Flash と RAM）を書き手が選べるか（`@mem` の適用範囲と記憶域の種類）

- 空白: §6.6 は `const` の結果を「読み取り専用の静的領域（組込みではフラッシュ）」に置くとし、§12.4 の `@mem(...)` は flow の本体の遅延線の `let` に付ける `bulk` だけ（閉じた一覧、fast が既定。S-43 で領域ごとの属性を `@mem` にまとめた）である。
  組込みでは、静的領域は通常 Flash に置かれて RAM より読み込みが遅く、Flash と RAM の容量の制限も別である。頻繁に参照する表（`const SINE: [F32; 1024]` など）を RAM に置いて速くすることもよくある（利用者、58 回目）。
  `const` と静的な値の置き場所を書き手が選ぶ手段（`@mem(flash)`・`@mem(ram)` のような `@mem` の適用範囲と記憶域の種類の拡張）を入れるか、入れるならどの場所（`const`、関連定数、静的な値のリテラル、flow の定数のクロックの値）にどの記憶域を書けるか、既定の置き場所、マニフェストのターゲットの設定と C API との関係（§12.4「記憶域を足すときは、C API とマニフェストの設定を一緒に定める」）が書かれていない。
  S-610 で静的な値にした集成体のリテラルの置き場所は約束しない（スタックに組んでも静的領域に置いてもよい）ので、その置き場所もこの S の範囲。
- 決定:
- 経緯: 58 回目（2026-10-23）、第 44 組の S-610（静的な値の範囲）の判断のときに、利用者が組込みの論点（Flash と RAM の速さと容量、表を RAM に置く高速化、既にある `@mem` を広げる案）を挙げ、別の論点として検討するとして親が登録した。関係: S-610、S-43、S-31、§6.6、§12.4、W9-06。
