# S-722 一つの無名関数が捕捉できない値を二つ以上捕捉するとき（`inout` 引数と Affine 値）、E0712 がどの捕捉を名指すか

- 空白: §5.3 は `inout` 引数と Affine 値は捕捉できない（E0712）とする。一つの無名関数が両方を捕捉するとき（`apply(fn(x: U32) -> U32 { apply2(fn(y: U32) -> U32 { k }, b.len()) })`、`k` は `inout`、`b` は `Buf`）、一つの E0712 がどの捕捉を名指すかが決まっていない。
  §18.1 の並べ方（開始、終わり、コード、文面）で文面の順に選ぶ読みもある。今の実装は、U3b（W4-04）の前は型付けの検査の順（`b`）、後は歩き手の読みの順（ソースで最初に読む `k`）で、位置とコードは同じで文面だけが変わった。再現は `target/notes/76/w404/u3b/b/h/ord.onsa`。
- 決定: 決定（2026-10-28、利用者が ID を挙げて了承。確認だけ。78 回目、第 67 組）: (a)。
  無名関数ごとに E0712 を一つにし、本体で最初に読む（ソースの順の）捕捉できない値を名指す（今の実装、W4-04 U3b から）。どれを名指すかに頼る使い手は無いので約束にせず、仕様に書かない。
  W4-09 の事例に t1〜t3（`target/notes/76/w404/u3b/b/h/ord.onsa`）を足し、今の選びを確かめる。
- 経緯: 76 回目（2026-10-27）、W4-04 U3b/b（onsa-break）が空白の候補として報告し、親が登録した。重大度は低（文面だけ）。期限は E0712 と捕捉の検査を直す W4-09 の前。関係: S-80。
- 補い（2026-10-30、親）: 担う作業を W4-09 から W4-07 に改めた。利用者が了承した（86 回目、W4-07 の設計メモの審査の A1）。W4-07 の捕捉の検査（U4）が、本体で最初に読む捕捉できない値を名指す。
