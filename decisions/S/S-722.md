# S-722 一つの無名関数が捕捉できない値を二つ以上捕捉するとき（`inout` 引数と Affine 値）、E0712 がどの捕捉を名指すか

- 空白: §5.3 は `inout` 引数と Affine 値は捕捉できない（E0712）とする。一つの無名関数が両方を捕捉するとき（`apply(fn(x: U32) -> U32 { apply2(fn(y: U32) -> U32 { k }, b.len()) })`、`k` は `inout`、`b` は `Buf`）、一つの E0712 がどの捕捉を名指すかが決まっていない。
  §18.1 の並べ方（開始、終わり、コード、文面）で文面の順に選ぶ読みもある。今の実装は、U3b（W4-04）の前は型付けの検査の順（`b`）、後は歩き手の読みの順（ソースで最初に読む `k`）で、位置とコードは同じで文面だけが変わった。再現は `target/notes/76/w404/u3b/b/h/ord.onsa`。
