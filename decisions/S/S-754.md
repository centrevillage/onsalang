# S-754 `impl` の対象に書いた別名が誤りの型のとき（`type A = S[I32]`、`type A = Nope`、値の循環の後の `impl A`）、見出しに E0307 を出すか（同じ別名を対象の型引数に書いた `impl W[A]` には S-753 で出す）

- 空白: §4.4 は `impl` の対象に別名を書けない（E0307）とし、§18.1 は誤りのある宣言の読めなかった部分を誤りの型として扱い、それを使う側に診断を出さない（見出しに書いた失敗した名前では `impl` の全体を一つの単位にしない、61 行）。
  §6.2 は対象の型引数に書いた別名を、別名そのものが誤りの型でも E0307 とする（S-753。別名は正しい宣言でも引数に書けず、別名を直しても残る誤りで、連鎖でない）。対象そのものに書いた別名が誤りの型のときに見出しの E0307 を出すかは書いていない。
  形: `type A = S[I32]`（総称でない `S` に型引数、E0302）、`type A = Nope`（E0302）、`struct S { a: A }` と `type A = S`（値の循環、E0311）の後の `impl A { … }`。
  今の実装（W4-05 U3a、`sig.rs::alias_impl` の誤りの型の枝）は見出しに E0307 を出さない（S-752 の補い、親）。`impl A` は別名の誤りだけで、別名を直すと `impl A` に E0307 が出る。同じ別名を引数に書いた `impl[T] W[A]` は、別名の誤りと E0307 が一度に出る。S-752 の題と `決定` は、この形の見出しを E0307 としている。
  読み: (1) 出す。S-753 と同じく、別名は正しい宣言でも対象に書けず、この E0307 は別名を直しても残る誤りで、連鎖でない。候補は出さない（元の型が誤りの型）。見出しの誤りなので `impl` の全体が一つの単位になり、メンバは S-752 のとおり右辺の頭の型の `.` の空間に数える。
  後ろに書いた別名の `impl` のメンバの E0304 は、正しい別名の `impl`（`tests/spec/types/impl_e0307_members_last.onsa`）と同じく単位に隠れる。(2) 出さない（今のまま）。対象の位置と型引数の位置で答えが逆になることを仕様に書く。
  どちらも誤りのあるプログラムの報告だけが変わり、通るプログラムは変わらない。(1) は `alias_impl` の誤りの型の枝で候補なしの E0307 を出す（約 +2〜4 行）。
  事例 `tests/spec/types/impl_e0307_members_alias_error.onsa` は、`impl A1`・`impl A2`・`impl A4`・`impl A5` に E0307 が足され、`impl A5` の `N` の E0304 が消える。
  再現は `target/notes/81/s754/`（`fine.onsa`・`arity.onsa`・`missing.onsa`・`cycle.onsa`・`arg_arity.onsa`）。
- 決定: 決定（2026-10-29、利用者。81 回目）: (1)。
  `impl` の対象に書いた別名は、別名そのものが誤りの型（型引数の数の誤り、右辺が見つからない名前、値の循環）でも E0307 を出す。S-753（対象の型引数に書いた別名）と同じく、別名は正しい宣言でも対象に書けず、この E0307 は別名を直しても残る誤りで、連鎖でない。候補は出さない（元の型が誤りの型）。
  見出しの誤りなので `impl` の全体が一つの単位になり、メンバは S-752 のとおり右辺の頭の型の `.` の空間に数える。後ろに書いた別名の `impl` のメンバの E0304 は、正しい別名の `impl` と同じく単位に隠れる。誤りのあるプログラムの報告だけが変わり、通るプログラムは変わらない。
  仕様は §18.1 の誤りのある宣言の段落の、E0307 の `impl` の文の後に一文（対象と対象の型引数の別名をまとめて書く）。§4.4 と §6.2 はそこを指す。S-752 の補い（見出しに E0307 は出ない）はこの決定で改めた。
  実装は W4-05 U4c（`sig.rs::alias_impl` の誤りの型の枝、約 +2〜4 行）。事例は `tests/spec/types/impl_e0307_members_alias_error.onsa` の印を改め（E0307 を 4 か所に足し、`impl A5` の `N` の E0304 を外す）、右辺が見つからない名前の別名（`type A = Nope`）の形を足す。
- 経緯: 81 回目（2026-10-29）、文書の点検（onsa-docs、範囲 `65a61b6..5aa4557`）の指摘 1・2 として挙がった（§6.2 の引数の別名の E0307 が §18.1 の一般則の例外なのに §18.1 に書かれていない、対象の位置の別名は誤りの型なら E0307 が出ず、仕様の §4.4 は無条件に読める）。
