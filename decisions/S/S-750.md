# S-750 derive の一覧と効果行の同じ要素の重なり（`struct P: PartialEq + PartialEq`、`uses {Alloc, Alloc}`）の診断（今はどちらも黙って通る）

- 空白: §6.4 の derive の一覧と §8.1 の効果行は、同じ要素を二度書く形を書いていない。`pub struct P: PartialEq + PartialEq { … }` と `fn n(x: I32) -> I32 uses {Alloc, Alloc}` は今どちらも診断なしで通る（再現は 80 回目の第 72 組の下書きの `probe/s747/b12`・`b13`）。
  読み: 並びの同じ要素の重なりを誤りにする（同じ名前の二度の `use`、型パラメータ、struct リテラルのフィールド、`@latency` の項は誤りで、候補なし）、意味を変えない余分として受理して fmt が除く（§0.5.1）、そのまま通す。境界の並びの重なり（S-747）と、属性の重なり（S-490、族「§6.5 の同じ属性の重なり」）と揃えるかも決める。
