# S-791 構築子の呼び出しに付けた `!`（`Some!(1)`）の診断

- 空白: §5.2 の 69 行は、`inout self` のメソッドの呼び出しに `!` を付け、無ければ E0713、`inout self` でないメソッドに付ければ E0714 とする。メソッドでない呼び出しの `!` には触れない。
  型の段は、関数と関数値の呼び出しの `!` を E0714 にする（`f!(1)` は E0714「`!` marks `inout self` method calls only」、dev `9804880`）。構築子の呼び出し `Some!(1)` は、dev では型の段も古い modes も見ず、診断なしで通る。
  W4-07 U3a の新しい modes は、構築子の `!` を E0714 にして `!` を消す候補を付ける（`SPEC-GAP(S-791)`）。再現は W4-07 U3a の担当の入力 `bang_ctor.onsa`（写しは `target/notes/87/w407/u3a/probe/`）。
  読み: (1) 関数と関数値の呼び出しと同じく E0714（`!` を消す候補）。(2) 別のコードか構文の誤り。
  親の読み（確認だけの案）: (1)。`!` は `inout self` の受け手を持つ呼び出しの印で、受け手の無い呼び出しは関数でも構築子でも同じ扱いにする。仕様の 69 行の「`inout self` でないメソッドに付ければ E0714」を「`inout self` のメソッドでない呼び出し（関数、関数値、構築子を含む）に付ければ E0714」に改める案。
- 決定: 決定（2026-10-30、利用者。87 回目。確認だけ。親の読み）: (1)。`!` は `inout self` の受け手を持つ呼び出しの印で、`inout self` のメソッドでない呼び出し（関数、関数値、構築子を含む）に付ければ E0714（`!` を消す候補）。仕様 §5.2
- 経緯: 87 回目（2026-10-30）、W4-07 U3a/i（onsa-impl）が空白として報告した。親が dev のバイナリで再現して登録した。
