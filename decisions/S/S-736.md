# S-736 E0320 の規則に揃えた名前が、元の名前の末尾の `_` を残すか（`_g_` は `g_` か `g`、`Foo_` は `foo_` か `foo`）

- 空白: §2.3 は名前の三つの形を「英字で始まる芯と、任意の末尾の一つの `_`」とし、末尾の `_` を予約語を避ける綴りとする。E0320 の候補の規則に揃えた名前が、元の名前の末尾の `_` を残すかが書かれていない。
  読みは二つに割れる。(1) 残す（`_g_` は `g_`、`Foo_` は `foo_`）。(2) 予約語を避ける必要が無ければ外す（今の実装。`_g_` は `g`、`Foo_` は `foo`、`fooBar_` は `foo_bar`、`a__b_` は `a_b`）。
  S-652 の重なりの判定が、揃えた名前で変わる（`g` が既にあれば候補なし、`g_` は空いていても見ない）。前からある（U9 の前も同じ）。再現は 78 回目の scratchpad の `w404/u9/b/`（区切りで `target/notes/78/w404/u9/` へ写す） の `repro_trailing_underscore.onsa`（`Some(_v_)` が `v`）。
