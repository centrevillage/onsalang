# S-640 export する関数のシグネチャが §14.1 の型でないとき（型パラメータ、`Ptr`、struct、集成体）の誤りのコードと段

- 空白: §14.2 は export する関数の「引数と返り値は FFI で `unsafe` を要しない型（§14.1）に限る」とし、この版で使えるのはスカラとスカラの `Span` だけ（`@repr(c)` の構造体、借用した `Str`、集成体の返り値は E0200）とするが、総称の関数（型パラメータを C に出せない）と `Ptr` の引数の誤りのコードを書いていない。
  今の実装は、総称の関数を「cannot find the function `util.id` to export」の E0302（関数は在るので文面が誤り）、型の種類によって E0200 にする（第 51 組の試した入力 `a10`・`a12`）。
  読みは (1) E0810 を「export の境界（flow の入出力と関数のシグネチャ）の型と形」に広げる（§11.11 が export の境界の型に E0810 を使う）、(2) 新しいコードを立てる、に割れる。段は S-639 の (a) により `onsa check`（宣言の位置）。
- 決定:
- 経緯: 60 回目（2026-10-24）、第 51 組（S-639）の下書き（onsa-gap）の新しい S の候補と、独立のレビューの段 1・段 2（別の S にする。助言の傾きは (1)、確度 低〜中）から。利用者が S-639 の (a) と 51-A1〜A11 を了承した後に登録した。
