# S-1231 細部: 条件の位置の中の、イベントの値の名前に遅い刻みの `at` を付けた式（`if c { (v at (sample / 4)) at sample } else { 0.0 }`）が E0815 か、書けるか

- 空白: §11.3 は、`sample_tick()` だけに刻みのクロックの `at` を付けた式を刻みの計算した部分式と同じに扱い、条件の位置の中では、選ぶ条件が全て定数・`init`・その刻みで決まるときだけ書けるとし（S-1210）、名前とそのフィールドを読むだけなら書ける（`lf at sample`）とする。
  イベントの値の名前に遅い刻みの `at` を付けた式（`v at (sample / 4)`）は、§11.11「変換の場所を留める（値の欄は §11.3 の巻き上げの隠れた欄）」で刻みごとに値を留めるので、値は `let m = v at (sample / 4)` に分けた形と同じに字で決まるが、条件の位置の中で `sample_tick()` と同じに E0815 か、名前を読むだけとして書けるかが字に無い。
  読み: (i) `sample_tick()` と同じ E0815（直しは前の `let m = v at (sample / 4)` に出す 1 回）。(ii) 書ける。今は `at event` が E0302 で書けない。
  仮の扱い: (i)（値を刻みで留める式は置き場所を作り、`sample_tick()` と扱いが分かれない。後で緩められる）。W7 の区切りで確認だけ。
- 決定: 決定（2026-11-26、利用者。189 回目、W7 の区切りの確認だけ。「(A)と(B1)はS-1148以外OKです」）: 仮の扱いのとおり。イベントの値に遅い刻みの `at` を付けた式は刻みの計算した部分式で、他の段の条件の下は E0815。
  突き合わせ: 助言の担当が固定のバイナリ `onsa-d02ddee` で再現し、仮の扱いが今の挙動と合い、既決とぶつからないことを確かめた（`target/notes/189/reports/onsa-advisor-a4f41d23ad112f9fe-001.md`）。
