# S-325

- 空白: モジュールの経路の要素（ファイル名とディレクトリの名前）が予約語のとき（`match/x.onsa`、`match.onsa`）の E0320 の note。§2.3 は識別子の候補に末尾の `_` を足した名前を出すが、ファイル名とディレクトリの名前は候補を出さない。第 11 組の Fable のレビューで見つけた（2026-10-09）
- 提案: 後の段（W4-02 の前）
- 時期: W4
- 決定: 決定（2026-10-23、利用者が ID を挙げて了承。55 回目、第 37 組）: (a)。規則に合わないファイル名の E0320 の note は規則だけを示し、名前を作らない（§2.3 の今の文のまま）。キーワードの名前のファイルとディレクトリは規則に合い、§2.2 のとおり経路で書ける。
  あわせて: `_` だけの名前、数字で始まる名前、ASCII でない名前のファイルとディレクトリは E0320（§2.3 の規則は識別子であることを含む）。`_` を足す文は識別子の候補だけの規則。仕様 §2.3
- 経緯（2026-10-23、親）: X-8: W4-02 を分け、期限を W4-14（パッケージの入力と命名）にした。W4 に着手する前に決める。
