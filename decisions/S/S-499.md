# S-499 並びの要素の間の空行

- 空白: 並び（フィールド、列挙子、`match` の腕、要素）の要素の間の空行。§3.2 は項目と文の間の空行を 0 か 1 で保つとし、並びは先頭と末尾の空行だけを書く。今の fmt は要素の間の空行を消す（`struct` のフィールドの間、`match` の腕の間）。W3-11/i の設計メモの G4（2026-10-13）
- 提案: 決定（2026-10-13、利用者が ID を挙げて推奨の (1) を了承。下書きと Fable が一致、第 28 組）: 並びの要素の間の空行も、項目と文と同じく 0 か 1 で保つ（並びの形と種類によらない）。先頭と末尾、継続の間、要素の中の空行は除く。
  理由: 空行の規則が項目・文・要素で一つになり、書き手のまとまり（係数の段、状態のフィールド、腕）を保つ。`spec/tools.md` §3.2。実装は W3-11 の U3。補い（2026-10-14、S-510）: 列挙子の要素、効果行と `use` の並びも並びである（第 28 組の推奨の細部で、決定の文から漏れていた）
