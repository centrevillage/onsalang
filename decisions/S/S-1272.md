# S-1272 細部: 式の形の E0200 の穴を持つ定数の初期化式が局所変数も持つとき、`ConstBindings` の E0200 を出すか（仮は出さない。今の実装）

- 空白: S-67 は型で止めない単位の未対応を全て報告するとし、降下の `lower_const` は局所変数を持つ初期化式を E0200（`ConstBindings`、「a `const` initializer with local bindings」）にする。初期化式に式の形の E0200 の穴（代わりの局所変数 `__unsupported`）かパターンの穴があると、穴の局所変数を初期化式の局所変数と分けられないので、その確かめを飛ばす。`let x = 1` と `A < A`（配列の順の比べ）を両方持つ定数や、束縛を持つ or パターンの `match` を持つ定数は、式の形の E0200 の一件だけで、`ConstBindings` は穴を直した次の回に出る。
  読み: (1) 出さない（今の実装。穴の有無の印は本体ごとの `FnCx` の欄）、(2) 出す。(2) は穴の局所変数を数えて引くだけでは足りない: 無名関数を初期化式にした定数（`tests/spec/effects/closure_scope_ok_kept.onsa` の `const F_PURE: fn(U32) -> U32 = fn(x: U32) -> U32 { x + 1 }`）は、無名関数が穴になり、その引数 `x` が sema の局所変数に入るので、E0200 が 6 件増える（局所変数の `let` は無い）。穴の範囲の中で sema が宣言した局所変数も数える手当てが要る。違いは誤りのプログラムの E0200 の数だけで、通るプログラムは変わらない。`ConstBindings` は W9-03 が定数の評価を作り直すときに無くなる見込み。
- 決定: 決定（2026-11-28、利用者。193 回目、「S-1272: OK」）: 仮の扱いのとおり。穴を持つ定数の初期化式は `ConstBindings` の確かめを飛ばし、E0200 を出さない（穴の局所変数を見分けないため）。`ConstBindings` は W9-03 が定数の評価を作り直すときに無くなる見込み。
- 経緯: 193 回目（2026-11-27）、W8-16 B2 の壊す側（onsa-break）が、確かめの印が読む側の試みの穴で黙る形（定数を読む定数が先にあると順で数が変わる）を挙げ、印を本体ごとにする直しの後に、実装の担当（onsa-impl）が穴の局所変数を数える案で上の 6 件を見つけた。親は手当てが W9-03 まで続く案を採らず、本体ごとの真偽の印（順によらない）に戻した。誤りの場面だけの数の細部として、W8 の段の区切りで確認する（`rules/leader.md` 5.11）。
