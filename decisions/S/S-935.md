# S-935 見出しが失敗した定数をパターンに書いた単位の扱い

- 空白: `const L: Nope = 1` の `L` をパターンに書いた単位。§18.1 は「値の位置（失敗した名前を経路として書いた式とパターン…）では、その単位の以後を検査しない」とし、同じ節は「誤りの型の部分は、`match` の網羅性では何にでも一致する」ともする。式の `x == L` は誤りの型として続ける。
  読み (1) 失敗した名前と同じく単位の以後を検査しない（U1a の実装。後ろの `let y: Bool = 3` の E0401 は出ず、`y` の E0309 が出る）。読み (2) 誤りの型の値として何にでも一致し、検査を続ける。診断が増えるか減るかだけで、通るプログラムは変わらない。
- 決定: 決定（2026-11-12、利用者「他の (A) は現状で OK」。140 回目、W5-13 の前の確認だけ）: 今の実装の (1)。見出しの失敗した定数をパターンに書いた単位は、失敗した名前と同じく以後を検査しない（後ろの型の誤りは出ず、使わない束縛の E0309 が出る）。診断の数だけの違いなので、仕様は変えない。`body/patterns.rs` の `SPEC-GAP(S-935)` の印は W5-13 で外す。
- 経緯: 119 回目（2026-11-06）、W5-09 U1a/b（onsa-break）が見つけ、親が登録した。再現は `target/notes/119/` の壊す側の報告の `failed_const_pat_then_unused`。急ぎは後の段で、W5-13 の前にまとめる。
