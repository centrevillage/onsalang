# S-920 コンパイル時に畳めなかったフィールドの既定値の `onsa interface` の表示

- 空白: §18.2 は `onsa interface` が「struct のフィールドの既定値（§4.4）」を出すと書く。S-697 の下書きの形は `y: F32 = 0.0` である。
  今の `consteval` は畳める形（リテラル、定数の読み、struct リテラル）だけを値にし、畳めない `const` は値を出さない（`pub const A: U32 = 1 + 2` は `pub const A: U32`）。W9-03 が評価を作り直すまで、同じ畳めない既定値（`y: U32 = 1 + 2`、呼び出し）をどう出すかの文が無い。
  再現: `target/notes/118/w522/memo/probe/g5_iface.onsa`（宣言）と `s4.onsa`（今の `const` の表示）。
- 決定: 決定（2026-11-06、利用者。118 回目）: W9-03 が評価を作り直すまでの一時の形を許容する（リリース前である）。形は親が簡単な方を選んだ: 畳めた既定値だけ値を出し（`y: F32 = 0.0`）、畳めない既定値は今の `const` と同じく値を出さない（`y: U32`）。W9-03 の後も、struct のパラメータを読む既定値（S-918）は具体化で値が変わるので値を出さない（§18.2）。
- 経緯: 118 回目（2026-11-06）、W5-22 の設計メモが挙げた（G5）。親が問題を説明し、利用者が「一時的な話であれば、リリース前の言語なので許容できます」と答えた。
