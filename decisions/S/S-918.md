# S-918 フィールドの既定値の式が struct の型引数を読めるか（`struct G[T: AnyNum] { v: T, b: Bool = T.ZERO == T.ZERO }`）

- 空白: §4.4 は「既定値の式は `const` の初期化式の規則（§6.6）に従い、コンパイル時に一度だけ評価して焼き込む」「型引数に頼る型のフィールドの既定値は E0200 で、型引数を持つ struct の他のフィールドには書ける」と書く。
  フィールドの型は型引数に頼らず、式だけが型引数を読む形（`struct G[T: AnyNum] { v: T, b: Bool = T.ZERO == T.ZERO }`）の文は無い。
  読みは (1) 読めない（トップレベルの `const` と同じく名前が無く E0302。既定値は struct に一つ）、(2) 読める（具体化ごとに一つの定数。§6.6 の `impl[T]` の定数と同じ）、(3) E0200 で第 2 期に開く、の三つである。
  再現: `target/notes/118/w522/memo/probe/g2_param_in_value.onsa`。今は宣言の `=` が E0002 で止まる。
- 決定: 決定（2026-11-06、利用者。118 回目）: (1) 既定値の式から struct の型引数は見えず、E0302 である。既定値は struct に一つで、トップレベルの `const` と同じである。型引数に頼る型の既定値を第 2 期に開くときに見直す。
- 経緯: 118 回目（2026-11-06）、W5-22 の設計メモが挙げた（G2）。親が「確認だけ」で出し、利用者が了承した。
