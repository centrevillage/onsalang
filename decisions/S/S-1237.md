# S-1237 細部: 自分の出力で刻むイベントの源（`let d = g~(prev~(^d))`、`g` は入力のイベントごとに出す）を誤りにするか、決して刻まない値として通すか

- 空白: イベントの入力のイベントごとに出す flow `g`（`flow g(m: U32 at event) -> U32 at event { Some(m) }`）を、自分の出力に刻ませる形 `let d = g~(prev~(^d))` は、クロックの検査を通る（引数のクロックは `d` のクロック、`d` のクロックは `g~` の出力）が、外から刻むものが無いので決して刻まない。誤りにするか、最初のイベントの前の値のまま通すかが字に無い。
