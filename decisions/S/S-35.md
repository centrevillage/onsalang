# S-35

- 空白: フィールドの可視性が仕様に無く、実装は `pub` を受理するだけ（レビュー R-38）
- 提案: フィールドは struct の可視性を継ぐ。狭めるときだけ `priv`（`pub(pkg)` は S-36 で外した）。フィールドの `pub` は E0020。見えないフィールドの読み書きとリテラルは E0303（2026-10-03 決定。実装は第 3 段。メソッドの可視性の検査は第 2 段）
- 補い（2026-10-26、70 回目、利用者が了承）: 見えないフィールドを持つ struct は、そのフィールドが見えない場所では、フィールドを書いても省いてもリテラルで作れず、パターンでも分解できない（E0303）。
  位置はリテラルとパターンの型の名前で、書いたフィールドが見えなければそのフィールド（Rust の「cannot construct … due to private fields」と同じ扱い）。パターンの分は S-366 の補い。仕様 §15.1 の 37 行。W4-03 の U4a。
  見えない名前・フィールド・メンバの E0303 は名前の段の誤りで（§18.1 に一文、同じ回に利用者が了承）、同じリテラルとパターンの中の型の段の誤り（未知のフィールド、重複、型の不一致）より先に出る。
