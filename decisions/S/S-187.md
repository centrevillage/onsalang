# S-187 `Bool` の網羅と到達しない腕

- 空白: `match` の網羅性: `Bool` の `true` と `false` の腕だけで網羅か。到達しない腕（前の腕で覆われる）は誤りか（§7、E0501）
- 提案: 網羅に数えるのは `Bool`、enum、それらのタプルと struct だけ。前の腕で覆われる腕は E0503（候補は腕を消す形と、`_` か束縛の腕を最後へ移す形）。`match~` も同じ（2026-10-07 決定。実装は W5-09）
