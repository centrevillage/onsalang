# S-820 flow の外の束縛の型の後ろの `at`（`let y: F32 at sample = x`）の E0020 の修正候補: 値に移すか除くか

- 空白: §11.3 の 82 行は、入出力でない宣言の型と型の中の `at` を構文の段の E0020 とし、修正候補を「クロックを書ける場所へ移す形（クロックの無い flow の入出力の型の後ろ、束縛では値の式）か、場所が無ければ除く形」とする。flow の外（fn の本体、`test`、`const` の初期化式）では、値の式の `at` も §11.1 の E0821 なので、クロックを書ける場所が無い。
  今の実装は flow の本体と同じく「値に移す」候補を出し（`let y: F32 at sample = x` → `let y: F32 = x at sample`）、当てると名前の段の E0821 と「クロックを外す」候補になる（2 手で止まる。§18.1 の約束は後の段の診断を許すので約束の内）。
  誤りが二つある形（`let y: F32 at sample = x at block`）では、二つの候補が打ち消し合い、`--fix-loop-gate` の `cycles (undo)` が 0 から 4 になった（`tests/spec/fixes/e0020_clock_in_types.onsa`・`e0020_clock_in_types_multi.onsa`）。
  親の読み: flow の外では値の式もクロックを書けない場所なので、§11.3 の「場所が無ければ除く形」で、候補は束縛の型の後ろの `at` とクロックを除く。flow の本体は今の「値に移す」のまま。仕様の文は変わらない（「束縛では値の式」は flow の本体の束縛を指すと補う）。
  再現: 94 回目の scratchpad の `w412u3/parent/gaps.onsa` の `a1`、`w412u3/b/t5.onsa` の `a2`・`a4`（写しは区切りで `target/notes/94/w412u3/`）。
- 決定: 決定（2026-10-31、利用者が ID を挙げて了承。確認だけ。94 回目）: 親の読み。flow の外（fn の本体、`test`、`const` の初期化式）の束縛の型の後ろと型の中の `at` の E0020 は、値の式にもクロックを書けないので、`at` とクロックを除く候補を示す。flow の本体の束縛は今の「値に移す」候補のまま。実装は W4-12 の U3（構文の段の候補）。仕様 §11.3
- 経緯: 94 回目（2026-10-31）、W4-12 U3/b（onsa-break）が低の指摘と空白の候補として報告し、親が §11.3 の 82 行から読みが一つに決まると見て、確認だけの S として登録した。関係: S-356、S-815、R-269。
