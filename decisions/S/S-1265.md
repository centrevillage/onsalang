# S-1265 細部: 上書きの代入で前の値を破棄する時機と、§12.7 の代入先への直接構築（破棄の要る宛先は右辺と添字の後・書く前に破棄して一時から移すか、右辺が宛先を読まず添字が検査を持たないときは先に破棄して直接構築するか。第 1 期は観測できない。仮は前者、W8-01 の設計メモ部 1 の 3.4）

- 空白: §12.7 は集成体を返す式を置き場所（代入先を含む）に直接構築するとし、§12.2 の表は代入で上書きされる前の値の破棄を数えるが時機を書かない。§3.5 は代入の右辺を先に評価し、その後に代入先の場所を評価する。破棄の要る宛先への上書きで、(1) 破棄は右辺と添字の後・書く前で、一時に作って移す（§12.7 の直接構築の外）、(2) 右辺が宛先を読まず添字が検査を持たないときは、前の値を先に破棄して直接構築する（破棄が右辺の効果より先になる）、が割れる。
  第 1 期は観測できない（破棄の要る値はインタプリタだけの `Buf` を含む値で、C に届かない。違うのは `audit --memory` の写しの数だけの見込み）。第 2 期の `impl Drop` で破棄の副作用と右辺の効果の順が観測できる。仮の扱いは (1)（W8-01 の設計メモ部 1 の 3.4・16.2、`target/notes/191/w801/p1v2/memo.md`）。
- 決定（2026-11-27、利用者。191 回目）: (1)。上書きの代入は「右辺、代入先の場所、前の値の破棄、書き込み」の順で、破棄の要る宛先は一時に作ってから移す（W8-01 の設計メモ部 1 の 3.4）。仕様の字（§3.5 の代入の箇条に「代入先の前の値は、場所を評価した後、書き込む直前に破棄する（§12.2）。」の類の一句）は第 2 期の `impl Drop` の回に置く（第 1 期は観測できない）。
  利用者「(1)で。ただし対応する実行環境に組み込みがあるので、メモリの最適化は必要です」。親が次の約束にして W8-04 と第 2 期の持ち越しに渡す:
  - M1 一時を通すのは、前の値が生きていて破棄の要る宛先だけ。移した後の宛先（`h = mkh()`）と破棄の要らない型は直接作る。
  - M2 前の値の後始末の要る部分（ハンドル）だけを退けて宛先に直接作る形（案 (3)、順は (1) と同じ）を、第 2 期に Core と後端を作り直さずに足せる形で W8-01 のメモに決める。
  - M3 第 2 期に `impl Drop` と Shared を C に入れるとき、組込みのヒープの尖頭（`st.buf = Buf.zeroed(n)` で前の値と新しい値が同時に生きる）と破棄の要る宛先の写しを減らす最適化を設計に入れる（M2 の形と、破棄が解放のほかに効果を持たず右辺が前の値を読まないときに解放を右辺より前にしてよいとする許可。後者は確保の失敗の起き方を変えるので、その回の空白として決める）。
  第 1 期は破棄の要る値が C に届かないので、C の写しは増えない（S-1264 の P4 で確かめる）。
- 経緯: 191 回目（2026-11-27）、W8-01 の設計メモ部 1 を独立の審査の M3（上書きの破棄の位置）に当てて書き直した担当が挙げた。通るプログラムを変えないので細部として登録し、W8 の段の区切りで確認する（`rules/leader.md` 5.11）。
- 補い（2026-11-27、親）: 191 回目、W8-01 を閉じるとき: M2（ハンドルだけを退けて宛先に直接作る形）と M1 の絞りは、W8-01 の設計メモ部 1 の 3.4 に入らなかった（部 1 はこの決定の前の版）。W8-04 のメモで決める（`tasks/W/W8-04.md` の持ち越し）。
