# S-422

- 空白: 前置の `+` と前置の `-`・`!` が接する形（`-+a`、`+-a`、`!+a`）。§3.1 は「前置の `+` は無く、`+x` は E0020」と「前置演算子を重ねるには括弧が要る（`-(-x)`、E0012）」を書き、二つが重なる形を書かない。
  読みは (1) `+` は前置の演算子でないので前置の `+` の E0020 一つ（候補は `+` を除く `-a`・`-a`・`!a`）、(2) 重ねとして E0012、(3) 混ぜる、に割れうる。今は `+` の位置の E0002「expected an expression, found `+`」。
  W3-06/t3 が見つけた（2026-10-10。親が dev の `ade4450` で確かめた）
- 提案: 決定（2026-10-10、利用者が ID を挙げて親の案（確認だけ）を了承）: (1)。E0012 は Onsa の前置の演算子の重ねの規則で、`+` は既存言語の形なので重ねに数えない。候補は `+` を除く形で、残る前置の演算子は一つ。仕様 §3.1 の前置の `+` の文に「`-+x` も同じ（候補は `-x`）」を足す。実装は W3-06 の単位 2（`prefix_plus` の行のまま。専用の分岐は置かない）
