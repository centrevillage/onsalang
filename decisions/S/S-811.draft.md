# S-811 族: 呼び出しの印（`(`・`.(`・`!(`・`~(`）と呼び先の種類が合わない形の、コードの順と修正候補

- 決定済みで戻さないもの: 形の表の「決」の欄の全て。とくに、値の `~` の E0812（候補なし、S-590）、見つかった flow でない種類の `~` の E0812（S-723）、関数・関数値・構築子の `!` の E0714（S-791）、`prev.(x)` の E0308（S-720）、flow の外の `prev~(x)` の E0821（S-720）。
  タプルの添字で終わる呼び先（S-606・S-591・S-630・S-631）、定数の `K(1)`・`F32.PI()` の候補（R-301）、組込み型の関連関数を値に置く形（W4-12 メモの F3）、`s.f(x)`（W5-02）。
  第 76 組の下書きの「仕組みの出所」と「族の形の表」の節（写しは `target/notes/93/g76/draft.md`）。
- 論点: §6.1・§2.6・§5.2・§11.1・§15.1 は、呼び先の種類ごとに正しい印を決め、印の誤りに別々のコードを定める（値の `x(...)` と項目の `.(` は E0020、`~` の欠けは E0811、flow でないものの `~` は E0812、`!` の誤りは E0714、flow の外は E0821、種類の誤りは E0308）。
  書いた印が呼び先に合わず、しかも呼び先の種類が求める印が別にある形（`f!(x)` は `!` が誤りで `.` が欠け、`lp!(x)` は `!` が誤りで `~` が欠ける）では、二つの規則が当たる。どちらのコードを報告するか（段と順）と、修正候補の形を一つの規則で決められるかが問いである。
  今の候補は書いた印を消すだけで、当てた後に欠けた印の規則（多くは名前の段）が残り、§18.1 の約束を破る形が S-812〜S-814 にある。
- 今の実装: 形の表と「今の修復のループ」のとおり。名前の段は値の `x(...)` の E0020 を `!(` にも当て、flow の段は `~` と flow・遅延の `!` を、型の段は他の `!` と flow の外の `~` を扱う。
- 案: どの案も、形の表の決定済みの欄と、名前の解決の誤り（E0302、E0303、名前空間でない名前の後の `.` の E0308）が先であること（S-590・S-723・R-247）は変えない。
  - (a) 書いた印の規則を先にする: 呼び出しの誤りのコードは、次の順の最初の当たる規則で決める。
    1. 書いた印がその文脈で書けない: flow の外の `~(`（E0821、§11.1）。flow の本体の `!(` と、値を呼び先にした `.(`（E0806、§11.2）。
    2. 書いた印が呼び先の種類に合わない: `~(` は E0812。`!(` は E0714（型の段。呼べない値は型の段の E0401。E0714 は候補が必須なので、候補を作れない形は E0714 にしない）。`.(` は呼び先の値の位置の規則（値でない名前は E0308、`f(x)` で呼ぶ項目は E0020、関数でない値は E0401）。
    3. 印の無い `(` は、呼び先の種類が求める印の規則: 値は E0020、flow・遅延は E0811（flow の外は E0821）、`inout self` のメソッドは E0713、型の名前で書いたメソッドと呼べない名前は E0308、単位形の列挙子は E0412。
    flow の外で flow を直接に呼ぶ形（`lp(x)`、`lp!(x)`）は印によらず E0821（§11.1。§15.1 の 73 行で E0308 より先）。
    修正候補は、書いた印を呼び先の種類の印に置き換える一つの編集（種類の印が無ければ書いた印を消す）で、当てた後に同じ段か前の段の誤りが残らないときだけ出す。値の `~`（S-590）と種類の誤りの E0308（S-713・S-720。§15.1 のメソッドの形の候補を除く）は候補なし。
  - (b) 呼び先の種類が求める印の規則を先にする: 名前の段で種類が分かる呼び先は、書いた印によらず、種類が求める呼び方の規則のコードを名前の段で報告する。
    値は `!(`・`~(` も E0020（候補は `.(`）、flow・遅延は `!(`・`.(` も E0811（外は E0821、候補は `~(`）、型・モジュール・trait は `~(` も E0308、型の名前で書いたメソッドは `~(` も E0308。
    `f(x)` で呼ぶ項目の誤った印は、書いた印の規則（`.(` の E0020、`~(` の E0812、`!(` の E0714）のまま。候補は (a) と同じ条件。
  - (c) 今のコードと段のまま: 書いた印の今のコードを保ち、当てた後に同じ段か前の段の誤りが残る候補だけを外す（候補なしにする）。候補が必須の E0714・E0811 で候補を外す形は、§5.2 の「一意」の文と登録簿の必須の印（とそのテスト）を直すか、候補の無い診断が E0002 に変わるのを受け入れる。
