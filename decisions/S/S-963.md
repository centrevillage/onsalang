# S-963 経路の区切り `::` の前後の空白と改行（`F32:: PI`、`std:: math:: sqrt`、`use std:: {math}`、`F32::` 改行 `PI`）のコードと候補

- 空白: S-248 は経路の全ての `::`（Rust の区切り）を一つの形の E0020 とし、一つの候補が全てを `.` に直す。`::` の前後の空白と改行は書かれていない。
  今の出力（`P/bin/onsa-u10d2i3`）: `F32:: PI`・`F32 :: PI` は E0020 で、候補は `::` を `.` にするだけで空白を残し、当てた後に空白のある `.` の E0020（2 回。fuzz の `tests/fuzz/94679d99.onsa` の `d:: F` は S-384 で許した）。`std:: math:: sqrt(2.0)` は 4 回。`use std:: {math}` は同じ文面の E0002 で候補なし。`F32::` 改行 `PI` は E0002「expected newline or `}`, found `::`」で候補なし（`use std::` 改行 `math` は E0002 が二つ）。
  行頭の `::`（`F32` 改行 `::PI`）は E0002（§2.5、決定済み）。
  読み: 族の規則 S-961 の (iii)（同じ所の形の誤りが先で、その候補が隙間も除く）に従うなら、候補は `::` を `.` にして前後の空白も除き（一回）、後ろの改行は `.` を次の行の頭へ移す（`F32` 改行 `.PI`。行頭の `.` は継続）。どれも誤りの入力の報告と候補だけの違いで、通るプログラムは変わらない。
- 決定:
- 経緯: 127 回目（2026-11-09）、親が fuzz で見つけた `d:: F`（W5-11 U10h の gate）から、第 94 組の下書き（onsa-gap）が族の表に行を立て、独立のレビューの段 1（onsa-advisor）が別の S を勧めたので親が登録した。族の規則は S-961。
