# S-1211 細部: `.down~` の本体のための上の桁の欄（§11.4「プログラムに一つ置く」）と、flow ごとの状態の配置（§12.4）で、一番外になりうる flow ごとに欄が出る形

- 空白: §11.4 は「`.down~(N)` の本体では 1/N（上の桁の `U32` の欄をプログラムに一つ置く）」とし、§12.4 は「位相のカウンタと、続けて `.down~` の本体のための上の桁の欄（どちらも置くとき。誰が持つかは実装の選択）」とする。flow の状態の配置は flow ごとに決まり、どの flow が一番外になるかは配置を決める時に分からないので、上の桁の欄は経路に `.down~` があってその先で時間を読む flow（`wide`）ごとに出る（埋め込まれた flow の欄は使わない）。通るプログラムは変わらず、`onsa interface` の写しと C の構造体の欄が変わる。
  読み: (1) 使うのは一番外の flow の欄一つで、一番外になりうる flow ごとに配置に欄があってよい（埋め込みでは使わない）。§11.4 の「プログラムに一つ」は使う欄の数と読む。(2) 字のとおりプログラムに一つだけで、埋め込みの flow の配置に欄を出さない（flow ごとの配置では書けない）。
  仮の扱い: (1)。欄を書くのは U6a（U5b の間は連鎖が門で止まるので `wide` の flow は生じない）で、`SPEC-GAP(S-1211)` の印を付ける。急ぎ: U6a の前に確認だけ（`rules/leader.md` 5.11）。
