# S-723 インスタンスの位置で flow の組込み名の後に `.` を書く形（`prev.x~(x, 0.0)`、`sample_rate.x~()`）は、`~` の E0812 か、名前空間でない名前の後の `.` の E0308（S-720）か

- 空白: S-720 は、flow の組込み名を `.` の前に書く形（`prev.y`）を名前空間でない名前の後の `.` の E0308 とする。インスタンスの位置（`prev.x~(x, 0.0)`、`sample_rate.x~()`、`delay.process~(…)`）は、今は §2.6 の `~` の E0812「`prev.x` is not a flow」である（W4-04 U3b の前と後で同じ）。
  §15.1 は位置に固有の規則のコードを先にする（S-713）が、E0812 がその位置の固有の規則か、名前の種類の誤り（E0308）が先かが書かれていない。再現は `target/notes/76/w404/u3b/b/h/in.txt` の case 0〜4。
- 決定: 決定（2026-10-28、利用者が ID を挙げて了承。確認だけ。78 回目、第 67 組）: (a)。
  インスタンスの位置で flow の組込み名の後に `.` を書く形（`prev.x~(x, 0.0)`、`sample_rate.x~()`）は、決定済みの S-720（組込み名の `.` の前は E0308）と S-590（名前の解決の誤りは E0812 より先）から、名前空間でない名前の後の `.` の E0308 で、候補は無い（note の文面は W4-12 の細部）。仕様は変わらない（§11.4 の「`.` の前」で決まっている）。
  flow でない種類の名前（`P~(x)`、`math~(x)`、`Show~(x)`、`lp.State~()`）は §2.6 の E0812 で候補なし。実装は W4-12 の U3（`flow_builtin` の `Place::Instance` を一要素の経路だけ呼び先と数える 1〜2 行と、R-247 の直し）。
- 経緯: 76 回目（2026-10-27）、W4-04 U3b/b（onsa-break）が空白の候補として報告し、親が登録した。期限は E0811・E0812 を名前の段へ移す W4-12 の前（R-286 と同じ領域）。関係: S-720、S-713、S-590。
- 補い（2026-10-31、親）: `決定` の「実装は W4-12 の U3」は、W4-12 の単位を振り直した後の U2 である（`c217f7e4`。94 回目の文書の点検）。
