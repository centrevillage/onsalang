# S-555 インスタンスの修飾子の構文

- 空白: §19.1 は、インスタンスの停止・再開・初期化を、呼び出しに付ける節 `when c`・`reset_if r` で書く方向とした（S-170。`seq~(tick) when running reset_if start`。語は S-169 で予約、§2.2）。X-7 で、呼び出しに修飾子を連鎖の形で付け、新しい flow を合成する形（`saw~(f0).when(active).reset_if(on_start) + sin~(f0)`）が論点になった。決めること:
  1. 後置の節か、呼び出しへの連鎖か。
  2. 連鎖なら、修飾子を呼ぶ名前に印を付けるか（印なし・`~`・`~~`・`$` など）。今の実装は `saw~(f0).when(active)` を出力の値のメソッド呼び出しと読み、E0413（「`F32` has no method `when`」。`.` の直後の予約語は名前として読む、S-371）。後置の `saw~(f0) when active` は E0200（2026-10-20、`19a9e78` の release のバイナリで確かめた）。
  3. 呼び出しを `let` で受けた後に修飾子をかける形（`let s1 = saw~(f0)`、`let s2 = s1.when(active)`）を認めるか。認めるなら、インスタンスがいくつできるか（修飾子ごとに別か、一つか）と、`s1` と `s2` の両方を使ったときの意味。
  4. 関数の形（`when(saw~(f0), active)` など）を認めるか。flow の引数には出力の値が渡るので、flow そのものを受ける形と見分けが要る（P3）。
  5. §19.1 の文と例（クロック付きの `if` の `let y = lp~(x) when c`、MIDI の Start / Stop / Continue の対応）と、§2.2 の予約の書き直し。
- 決定:
- 経緯: X-7（W3 の終わり、2026-10-15、利用者）で、W4 の前に決めて第 1 期の範囲を W4〜W10 に割り当てることになった。第 33 組（修飾子）の一つ。関係: S-169、S-170、S-171、S-172、S-371。
