# S-1256 細部: `onsa graph` で、名前 `_` の入力が二つ以上ある flow の入力の頂点の名前（今は二つとも `_` で一つの頂点にまとまる。仮は今のまま、R-525）

- 空白: `spec/tools.md` の 1.1 節 は入力のラベルを「`名前: 型 at クロック`（ソースの宣言と同じ形）」とし、入力の頂点の名前（ノード名）を決めていない（決めているのは `let` の名前、添字（`spec/tools.md` の 1.3 節、入れ子でも重ならない）、出力の `_out`）。
  名前 `_` の入力が二つ以上ある flow（`pub flow g(_: F32 at sample, _: F32 at sample, x: F32 at sample) -> F32 at sample { x }`）の `onsa graph g` は、DOT に `"_"` の頂点が二行出て、二つの入力が一つにまとまる（R-525。前から）。
  案: (1) 入力の位置で名前を付ける（`_<k>` は `let _` の頂点の `_0`・`_1`（S-1169 の仮）と重なるので `_in<k>` の類。約 3 行と試験 約 10 行）。(2) `_` の入力を描かない（読まれないので辺も無い。約 2 行）。(3) 二つ目からだけ添字を付ける（形が揃わない）。どの案もラベルは `_: F32 at sample` のまま。`tests/` と `examples` に `_` の入力を持つ flow は 0 件。
  仮の扱い: 今のまま。W7 の区切りで確認だけ（実装の担当の見立ては (1)）。
