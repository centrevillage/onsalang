# S-740 flow の本体の `let` の型の位置で、後ろの `let` の名前を指す前方参照（`let b: [F32; a]` の後に `let a`）は、値の位置と同じ E0801 か、名前の引きの E0302 か

- 空白: §11.2 は「名前は上から順に定義する。定義より前で名前を参照するには `^名前`」とし、印の無い前方参照を E0801 とする。flow の本体の `let` の型の位置（注釈、配列長）で、後ろの `let` の名前を指す形のコードが書かれていない。
  今の実装（W4-04 U10、`b4b6dce`）: 値の位置の `let b = a`（後ろに `let a`）は E0801、型の位置の `let b: a = x` と `let b: [F32; a] = …` は E0302（U10 は flow の `let` の型が上の束縛だけを見ると決めた。事例 `tests/spec/type_names/body_locals_not_visible.onsa` の 126 行が E0302 を期待）。
  読みは二つに割れる。(1) 型の位置の前方参照も E0801。(2) 型の位置は名前の引きで E0302（今の形）。再現は `target/notes/78/w404/u10/`（W4-04 U10/b の入力の写し）の `c4.txt`。
- 決定: 決定（2026-10-28、利用者が ID を挙げて了承。79 回目、第 69 組）: (3)。
  §11.2 の順の規則は値を読む参照の規則で、型の位置（注釈、`as`、型の中の定数式）には当たらない。flow の本体の型の位置は順によらず本体の全ての `let` と入力を見て、値を型の位置に書いた E0308（定数式は E0417）。自分の注釈（`let a: a = x`、`let (a, b): (F32, a)`）も E0308。`as` は今のまま E0308 で、注釈を揃える。
  仕様は §11.2 に一句書いた（§5.1 の S-741 の文も flow の本体の `let` を本体の全体とする）。`tasks/diag-codes.md` の E0308 の行に足した。
  実装は W4-19（`walk_flow` の最初のループで型の site を取る位置を、全ての `let` の宣言の後へ移す、約 ±5 行）。W7-04 には「型の位置の E0308 は名前の段で、E0801 を名前の段へ移した後は位置の順で並ぶ。手当て無し」と引き継ぐ。
  事例 `tests/spec/type_names/body_locals_not_visible.onsa` の 126 行（`name_declared_later_in_a_flow`、今は E0302）を E0308 にして `kind_body_locals.onsa` の flow の節へ移し、`as` の前方参照と自分の注釈の形を足す。
- 経緯: 78 回目（2026-10-28）、W4-04 U10/b（onsa-break）の空白の NEW-3。期限は W7-04（flow の本体の名前の段の E0801・E0806）の前。関係: S-729、S-267。
