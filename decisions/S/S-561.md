# S-561 同じサンプルの位置のイベントの順

- 空白: §19.1 は、同じ位置のイベントをキューに溜め、イベントのクロックがイベントごとに一回刻んで順に処理し、サンプルのクロックの式からはその位置のイベントを全て処理した後の状態が見える、とした。決めること:
  1. 一つの入力の同じ位置のイベントの順（ホストが渡した順か）。
  2. 二つ以上のイベントの入力が同じ位置にイベントを持つときの、入力の間の順（宣言の順、一つの刻みにまとめる、など）と、その順が flow の結果に現れる場面。
  3. 同じ位置のイベントの刻みの間で、`sample` と `block` の値は同じか（イベントの刻みの中から見える値）。
- 決定: 決定（2026-10-21、利用者が ID を挙げて了承。47・50 回目）: 一つの入力の同じ位置のイベントはホストの列の順。入力をまたいだ順は境界が渡す順で、境界はホストの列の順を保ち、順が無ければ外の flow の入力の宣言の順で並べる（渡し方と `render` の書き方は第 35 組）。flow の出力のイベントの順は、出した刻みの位置で決まる。仕様 §19.1
- 経緯: X-7（W3 の終わり、2026-10-15、利用者）で、W4 の前に決めて第 1 期の範囲を W4〜W10 に割り当てることになった。第 34 組（イベントのクロック）の一つで、第 33 組（S-555〜S-559）の決定を前提にする。export の形・C の API・std の型・`onsa test` と `render` での与え方は第 35 組。
