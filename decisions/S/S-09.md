# S-09

- 空白: `std.math` の関数の型。F32 と F64 の両方に使うが多重定義は無い（§6.1）
- 提案: `Float` でジェネリック: `exp[T: Float](x: T) -> T`。`abs` / `min` / `max` は `Num`。`F32.to_bits() -> U32` / `F32.from_bits(U32)`（F64 は U64）を組込みメソッドに加える（D-11 と `std.math.exact` に要る）（S-84 で `abs` は `Num`、`min` / `max` は `AnyNum` に改めた）
- 時期: M3
