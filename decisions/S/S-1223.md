# S-1223 細部: 遅延の第 1 引数の中の修飾子の条件で、見えている名前に `^` を付けた形の診断（E0801 か E0020 か）

- 空白: §11.2 は、`^名前` を遅延の第 1 引数の中の修飾子の引数（`when~`・`reset_if~` の条件）に書けない（E0801）と書き、見えている名前（上で定義した `let`、入力、定数）に `^` を付けると E0020（遅延の第 1 引数の中では候補は `^` を外すこと）と書く。両方が当たる形（`let c = x > 0.0` の後の `prev~(lp~(x).when~(^c))`）でどちらを出すかが字に無い。どちらでも誤りで、変わるのは診断の番号と候補だけ。
  再現: `pub flow g2(x: F32 at sample) -> F32 at sample { let c = x > 0.0  let a = prev~(lp~(x).when~(^c))  a }` → 今は E0020（`^` を外す候補、当てると通る）。
  仮の扱い: 今の挙動（E0020、`^` を外す候補）。設計メモ（`target/notes/179/w710/memo/memo.md` 2.5）の見込みと同じ。段の区切りで確認だけ。
