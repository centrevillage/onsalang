# S-677 E0304 になった項目と同じ名前の子モジュール（`a.onsa` の `pub fn b` と `a/b.onsa`）があるとき、他のモジュールの `use a.b.{c}` が指す方

- 空白: R-177 と S-666 は、モジュールの項目と同じ名前の子モジュールを E0304（位置は項目）とする。そのとき、他のモジュールの経路（`main.onsa` の `use a.b.{c}`、`a.b()`）がどちらを引くかを書いていない。§18.1 は、誤りのある宣言も名前まで読めれば名前解決に見せるとする。
  W4-03 の単位（64 回目、親）は、名前空間を子モジュール → 項目の順で引く（子モジュールを残す）とした。今（dev `30b09c5`）は E0304 が無く、項目が勝って `use a.b.{c}` が「`b` has no members」の E0302 になり、使う所の E0302 が続く（`tests/review-phase1/types/itemmod/`）。
  仮の扱いは W4-03 の単位の答えで、事例は他のモジュールからの使用を約束しない。族の規則は S-675。
- 決定: 決定（2026-10-25、利用者。67 回目、第 59 組、ID を挙げて確認だけで了承（A3））: S-675 の残す側の規則から、他のモジュールの経路（`a.b…`、`use a.{b}`、`use a.b.{c}`）はどちらも引かず、その名前は黙る。`a` の本体の `b()` は項目を引く（本体の空間に重なりは無い）。実装は W4-03 の U3b（`SPEC-GAP(S-677)` の印を外す）。
- 経緯: 66 回目（2026-10-25）、W4-03 U3a1 のテストの票（onsa-test）が見つけた。関係: S-675、R-177、S-666、S-611。
- 補い（2026-10-25、親）: W4-03 U3a1 の壊す側（66 回目）: 仮の扱い（子モジュールを引く）では、項目を意図した他のモジュールの使用（`use a` の後の `a.b()`、`use a.{b}` の後の `b()`）に新しい E0401（`a.b` is not a function）が付く。U3a1 の前は終了コード 0（項目を引いた）。
  再現は `P66/w403/u3a/b/cases1.py` の `itemchild_member_item`・`itemchild_use_b_then_call`（写しは `target/notes/66/w403/u3a/b/`）。
