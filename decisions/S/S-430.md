# S-430

- 空白: 付ける宣言の無い位置の `//!`（`fn f() {}` 改行 `//! late` のファイルの末尾）の修正候補。§2.1 は「ファイルの先頭以外の `//!` も E0004 で、修正候補は `///`」とし、§18.1 は約束を満たす候補を作れなければ出さないとする。`///` にしても付く宣言が無ければ E0004 が残る。
  親の読み: §18.1 の一般の規則から、付けられる要素が続くときだけ `///` を出し、他は候補なし（W3-04/i の設計メモの読み (2)。確認だけ）。今は通る（親が dev の `826fc8a` で確かめた）。W3-04/i の設計メモで見つけた（2026-10-11）
- 提案: 決定（2026-10-11、利用者が ID を挙げて親の読みを了承、確認だけ）: 先頭以外の `//!` の候補 `///` は、付けられる宣言が続くときだけ出し、他は候補なし（§18.1 の一般の規則）。仕様 §2.1。実装は W3-04
