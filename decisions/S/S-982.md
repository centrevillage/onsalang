# S-982 型引数の数に効果行変数を数えるか（`fn apply[T, e](…)` への `apply::[I32](f)`、型の位置の `W[I32]`）

- 空白: §4.5 は式の中の型引数の数を「型引数と const 引数」の数として書き、効果行変数（§8.1。`fn apply[T, e](f: fn(T) -> T uses {e}, x: T)` の `e`）を数えるかを書かない。`apply::[I32](f, 1)` が数の合った形か、E0412 か、効果行を並びに書く形があるかが決まらない。
  型の位置の今の実装は効果行変数も数に入れる（`struct W[T, e]` への `W[I32]` は E0412「`W` takes 2 type argument(s), 1 given」、`W[I32, e]` は `e` の E0302。133 回目の scratchpad の `s977-advisor/probe/q5.onsa`、dev `f90b68ed`）。
  決めること: 式の中の `::[…]` の数に効果行変数を数えるか（数えないなら型の位置の今の数え方と揃えるか）。
- 決定: 決定（2026-11-10、利用者。133 回目）: (a)。式の中の型引数の数に、効果行変数は数えない。`fn apply[T, e](f: fn(T) -> T uses {e}, x: T)` には `apply::[I32](inc, 1)` と書き、効果行は呼び出しから決まる（効果行を `[…]` の並びに書く形は無い。数えると、効果行変数を持つ関数に型引数を書く方法が無くなる）。
  型の位置の、効果行変数を持つ struct・enum の書き方（今の実装は数に入れ、名指せない）は、この決定に含めない。第 1 期に要る場面が無い（std と examples に 0 件、std の最初の版は効果の多相の `map`・`filter` を置かない、§19.1）ので、効果の多相を広げるときに書き方ごと決める（S-987）。
  仕様: §4.5 に一文。W5-10 U2a。
- 経緯: 133 回目（2026-11-10）、W5-10 の設計メモの独立の審査（onsa-advisor）が挙げ、親が登録した。親が型の位置の今の挙動を固定のバイナリで再現した。
- 補い（2026-11-13、親）: 実装は第 2 期（R-27 (3)、144 回目に利用者が了承）。第 1 期は W6-01 で効果行変数の宣言を E0200 にするので、この決定の数え方が効くのは第 2 期に E0200 を外した後である。実装待ちの `types/type_args_fn_effect_row.onsa` などの 4 事例は、W6-01 で E0200 の形に書き直す（W6-01 の持ち越し）
