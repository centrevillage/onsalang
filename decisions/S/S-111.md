# S-111

- 空白: `strict` の生成コードが、ホストの浮動小数の設定（FTZ / DAZ、丸め、トラップ）の下で黙って計算し、ビット一致が崩れる。仕組みは `strict-ftz` の入口にしか無い（点検 C-42）
- 提案: export の全ての入口で、浮動小数の状態の全体を保存してプロファイルの環境（最近接偶数、トラップなし、FTZ / DAZ はプロファイルどおり）に設定し、全ての出口（`longjmp` を含む）と panic のフックの前に戻す。値が違うときだけ書く。
  x86（MXCSR）と ARM（FPSCR、AArch64 は FPCR と FPSR）は組込み関数で、それ以外は `<fenv.h>`。補助はランタイム（`onsa__runtime.h`）に一つ置き、S-105 と共有する。
  テストは、ホストが FTZ と丸めとトラップを変えた状態で呼び、出力のビット一致とホストの状態の復元を確かめる（2026-10-06 決定。実装は C の API の段、S-105 と同じ回）
- 時期: M4
