# S-817 flow の組込み名 `sample_rate`・`sample_tick` に `~` を付ける形（`sample_rate~()`）の E0812 に、`~` を消す修正候補を出すか

- 空白: §2.6 は flow の本体で flow でないものに `~` を付ける形を E0812 とし、S-590 は `~` を外す修正候補を、呼び先が `f(x)` で呼ぶ項目（関数、関連関数、名前空間の関数、効果の操作、要素を持つ列挙子）を指すときだけ出すとする。flow の組込み名 `sample_rate`・`sample_tick`（§11.4 の表、`sample_rate()` と呼ぶ）はこの列挙に無い。
  今は flow の段の E0812 と候補で、`sample_rate~()` は呼び出しの全体を `sample_rate()` に置き換え、`sample_tick~()` は `~` だけを消す（R-285 は候補を `~` だけを消す形に揃える直しで、候補があることを前提にしている）。
  読み (1): 候補を出す（`~` 無しの `sample_rate()` が唯一の正しい形で、書き手の意図が一つに決まる）。§2.6 の S-590 の列挙に flow の組込み名を足す。読み (2): 候補を出さず note だけ（S-590 の列挙のとおり）。R-285 は候補が無くなって閉じる。
  再現: `issues/R/R-285/`（`sample_rate_tilde.onsa`・`sample_tick_tilde.onsa`）。
- 決定: 決定（2026-10-31、利用者が ID を挙げて了承。確認だけ。93 回目、第 76 組）: (a)（S-811 の候補の規則から）。flow の本体の `sample_rate~()`・`sample_tick~()` の E0812 は、`~` の 1 字を消す修正候補を示す（R-285 の形）。§2.6 の候補を出す並びに「`~` 無しで呼ぶ flow の組込み名」を足した。仕様 §2.6
- 経緯: 93 回目（2026-10-31）、W4-12 の設計メモの独立の審査（onsa-advisor）が見つけ、親が登録した。関係: S-590、R-285。
