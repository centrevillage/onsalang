# S-459 項目の見出しの、表に無い語

- 空白: 項目の見出しの、表に無い語（`export fn h`、`public fn h`、`static fn h`、`async fn h`、`unsafe fn h`。`pub pub fn h`・`rt pub fn h` は順の誤り）。どれも一般の E0002「expected a declaration, found …」で、項目が消えて使う所に E0302 が出る。
  7 章の 32 の一覧の言語の形。行を立てるか（語ごとに候補の有無が割れる: `export`・`public` は `pub` か外すか、`static` は C では `priv` に当たる、`async`・`unsafe fn` は同じ意味が無い）、S-435 の読み続ける規則を「宣言のキーワードの前の一語」に広げるか。
  第 25 組の下書きの付録で見つけた（2026-10-13） 補い（2026-10-13、第 26 組の下書き）: `export` は JS・TS に加えて旧版 0.2 の `export "C" fn` の語でもある（文字列が続く形は S-464）。
- 提案: 決定（2026-10-13、利用者が ID を挙げて推奨の (c) を了承し、段階は「メンテナンス性が良い方」として親が `Failed::Unit` を選んだ。下書きと Fable が一致、第 26 組）: 行は立てない。
  項目の位置（トップレベルと impl・trait・extern のメンバ）で、同じ行に名前か `unsafe` が一つ以上並び、その直後が見出しを始められるトークン（可視性、`@`・`#[`、項目のキーワード）のとき、並びを一つの E0002 と note（見出しは `pub`・`priv` と宣言のキーワードで始まり、他の言語の修飾は無い）にし、その後ろから読み続けて登録する（S-435 の形を広げる）。
  読み続けた項目は `Failed::Unit`（外した後の署名は読めた署名そのもの）、可視性は無指定。改行を挟む形は今のまま。`pub pub fn`・`rt pub fn` は S-464。仕様 §18.1 の S-435 の文に一句。実装は W3-08（`parse_item` とメンバの入口、15〜25 行）
