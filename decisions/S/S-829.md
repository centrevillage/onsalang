# S-829 `main` の無い `kind`（`staticlib`・`source`・プラグイン）に書いた `main_frame`

- 空白: §12.5 の `main_frame` は `main` のローカルの置き場所で、`main` を持つのは `kind = "exe"` だけである（§16.1。プラグインと `staticlib` には `main` が無い）。`kind = "staticlib"`・`"source"`・プラグインのターゲットに書いた `main_frame = "static"`（`examples/voice_host` の `daisy`）は、対応した版でも生成物を変えない。
  誤り（E1103）にするか通すかを §15.3 は書いていない
- 決定:
- 経緯: 95 回目（2026-11-01）、第 77 組の下書き（onsa-gap）が新しい S の候補として挙げた。この版では `exe` が E0200 なので、S-825 の答えのとおり E0200 か通るかになり、急ぎは後の段
