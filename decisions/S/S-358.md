# S-358

- 空白: `^` の後ろが名前でない形（`prev~(^(y))`、`prev~(^1.0)`、`prev~(^^y)`）のコード。§2.6 と §3.1 は「`^名前` は名前の一部で、名前の直前に空白を空けずに書く」とするが、名前の続かない `^` のコードを書かない。W3-09/t で見つけた（2026-10-09）
- 提案: 決定（2026-10-09、利用者が ID を挙げて了承。親の案）: `^` は名前の一部で演算子でないので、名前の続かない前置の `^` は構文の段の E0002 と note（`^` は `let` の名前の直前にだけ書く）。仕様 §2.6。実装は W3-09
- 時期: W3
