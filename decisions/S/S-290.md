# S-290

- 空白: 多相再帰と具体化の数。`fn g[T](x: T, n: U32)` が `g(Some(x), n - 1)` を呼ぶと具体化が終わらない。今の `check` は通り、降下の具体化（`onsa_core::lower` の worklist）に上限が無い。
  型の上限（S-264）は一つ一つの具体化の型を抑えるが、数を抑えない（`g[T]` が `g[Option[T]]` と `g[(T, I32)]` を呼ぶと、上限の中で 2^256 通り）。案: 呼び出しの閉路の中で型引数が型パラメータを包む呼び出しを型の段の誤りにする（Go の InvalidInstanceCycle と同じ考え）、具体化の数の上限、など。
  あわせて、具体化を検査の段で作るか（`check` で見つかるか）と、具体化の型の E0422 の段を決める。第 6 組の下書き（S-264）で見つけた（2026-10-08）
- 提案: W5 の推論の作業か W8-01（降下）の前に決める。空白の流れで下書きに回す
