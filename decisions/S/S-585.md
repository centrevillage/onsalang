# S-585 プラグインの独自の画面（GUI）: CLAP の `gui`、VST3 の `IPlugView`、AU の画面と、GUI の文脈とパラメータの受け渡し

- 空白: §16 は、プラグインの GUI のスレッドをターゲットが与える文脈の一つに挙げ、文脈の間は同期型で値を受け渡すとする。一方、第 36 組（S-580〜S-583）のプラグインの出力は、プラグインの独自の画面を決めていない（§19.1 の「決めていないこと」。画面の無いプラグインのパラメータは、ホストの汎用の画面で操作する）。決めること:
  1. 独自の画面を何で書くか（Onsa の関数か、外の枠組みか、宣言的な記述か）と、三つの形式の口（CLAP の `gui` の拡張、VST3 の `IPlugView`、AU の画面）への写し方。
  2. 画面の文脈とオーディオの文脈の受け渡し（パラメータの値と変更の知らせ、メータなどの表示の値を返す道）。§16 の同期型を使うか、ラッパーが持つ原子的な変数（S-581）を使うか。

- 経緯: 第 36 組（X-7）の S-580 の下書き（onsa-gap）の新しい S の候補と、独立のレビューの段 2（別の S にする。第 2 期。§16 の GUI の文脈とあわせる）から立てた（2026-10-22、52 回目）。関係: S-580、S-581。
