# S-1143 細部: 括弧や `at` で包んだ `let` の値が「呼び出しそのもの」か（`let a = (prev~(x))` と `let b = prev~(x) at sample` のノードは `a`・`b` か `a.prev_0`・`b.prev_0` か）

- 空白: §11.6 は「`let` の値がインスタンス・遅延・`par~` の呼び出しそのものなら」ノードを `let` の名前で呼ぶとする。括弧で包んだ値（`(prev~(x))`）と `at` で包んだ値（`prev~(x) at sample`）が「呼び出しそのもの」かが書かれていない（§12.4 の `@mem(bulk)` の同じ句にも効く）。今は通し番号で `let` の名前を取らない。再現は 165 回目の scratchpad の `w703/review/g1.txt`・`g2.txt`（`compare.py probe --cmd 'dump --core'`）。表示の名前（`onsa interface`、生成コード、graph、プローブの宛先）だけが変わり、通るプログラムは変わらない。
  仮の扱い: 括弧は透かす（値は同じ）、`at` は透かさない（`at` は値のクロックを変える式）。急ぎ: W7 の区切りで確認だけ。
- 決定: 決定（2026-11-26、利用者。189 回目、W7 の区切りの確認だけ。「(A)と(B1)はS-1148以外OKです」）: 仮の扱いのとおり（括弧は透かす、`at` は透かさない）。（全体を囲む括弧は fmt が外すので、透かさないと fmt で名前が変わる）
  突き合わせ: 助言の担当が固定のバイナリ `onsa-d02ddee` で再現し、仮の扱いが今の挙動と合い、既決とぶつからないことを確かめた（`target/notes/189/reports/onsa-advisor-a5d87f2cf05f2cfce-001.md`）。
