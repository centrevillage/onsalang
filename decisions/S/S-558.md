# S-558 止まっているインスタンスの出力と時間（`when` が作るクロック）

- 空白: §19.1 が「入れるときに決めること」に挙げたもの。
  1. 止まっている間の出力（最後の出力を保ち、一度も動いていなければ `T.default()` の方向。Lustre と FAUST は保持、Pure Data は 0）。
  2. 時間の数え方: `prev~` と遅延の長さは動いた刻みで数える方向（Lustre、SCADE、Esterel と同じ）、`sample_rate()` は変わらない（§11.3、S-172）。
  3. 条件の値のクロック（`sample` か `block` か）とインスタンスのクロックの関係、`block` のクロックで動くインスタンスや `init` の値に修飾子をかけた形。
  4. `when` が作るクロックの定義。イベントのクロック（同じサンプルの中で複数回刻みうる、§19.1。第 34 組の予定）が、そのまま使える形にする（X-7）。
