# S-558 止まっているインスタンスの出力と時間（`when` が作るクロック）

- 空白: §19.1 が「入れるときに決めること」に挙げたもの。
  1. 止まっている間の出力（最後の出力を保ち、一度も動いていなければ `T.default()` の方向。Lustre と FAUST は保持、Pure Data は 0）。
  2. 時間の数え方: `prev~` と遅延の長さは動いた刻みで数える方向（Lustre、SCADE、Esterel と同じ）、`sample_rate()` は変わらない（§11.3、S-172）。
  3. 条件の値のクロック（`sample` か `block` か）とインスタンスのクロックの関係、`block` のクロックで動くインスタンスや `init` の値に修飾子をかけた形。
  4. `when` が作るクロックの定義。イベントのクロック（同じサンプルの中で複数回刻みうる、§19.1。第 34 組の予定）が、そのまま使える形にする（X-7）。
- 決定: 決定（2026-10-20、利用者が ID を挙げて了承。47 回目）: 止まっている間は最後の出力を保つ（一度も動いていなければ `T.default()`、無ければ E0816）。`when` のクロックは、呼び出しの位置のクロック K の刻みのうち条件が真の刻み。条件は `Bool` で呼び出し側のクロック以下、引数と `block` の段は止まっている間も評価する。
  受け手は flow の呼び出し（組込みの遅延を含む）か修飾子の連鎖で、`par`・`if~` / `match~`・値・`let` の名前は E0812。時間の数え方は S-172 のまま。仕様 §19.1
- 経緯: X-7（W3 の終わり、2026-10-15、利用者）で、W4 の前に決めて第 1 期の範囲を W4〜W10 に割り当てることになった。第 33 組（修飾子）の一つ。下書きと二段の独立のレビューと利用者の回答は `S-558.draft.md`。関係: S-169、S-170、S-171、S-172、S-371。
- 補い（2026-10-21、親）: S-562・S-567（2026-10-21、第 34 組）で、`when~` の刻みは連鎖のレート R の刻みに、条件は R の値・パラメータの種類・イベントの値（最後の値の水準）・R より遅い周期のクロックの値に、出力は受け手の出力のクロックの刻みで読むことに改めた。止めるのはサンプルレートに結び付く処理だけで、イベントの刻みの処理は止めない（仕様 §19.1）
