# S-483

- 空白: `#[name(…)]` と旧形の属性（`@relaxed`、`@bulk`、`@derive`）の候補は、置き換え先がその場所で属性の表（§6.5）に受けられるときだけ作る。`#[inline]`・`#[repr(rust)]`・fn の `#[derive]`、struct の `@relaxed` は候補なしの行（`hash_attribute_no_candidate`、`old_attribute_no_candidate`）の E0002。`#[repr(C)]` は綴りだけの違いを写して `@repr(c)`（`rules/criteria.md` 7.33）。
  §18.1 の候補の約束（E0005 は構文の段）から読みが一つ。W3-08/t2 と W3-08/i の設計メモで見つけた（2026-10-13）
- 提案: 決定（2026-10-13、利用者が ID を挙げて了承。確認だけ）: `#[…]`（Rust）の候補は、置き換え先をその場所で表が受けるときだけ（仮の扱いのとおり。`#[repr(C)]` は `@repr(c)`、`#[inline]` は候補なし）。旧形の属性の部分は、Onsa の旧版を正式なリリースまで対象にしない（`rules/criteria.md` 7.32）ので扱わない。
  W3-08 で入れた `old_attribute_no_candidate` は RF-11 で整理する
- 時期: W3
