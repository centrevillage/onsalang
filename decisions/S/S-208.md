# S-208 `abs(-0.0)`

- 空白: `abs(-0.0)`。組込み型の `abs` はプリミティブで「符号付きゼロは上の規則に従う」（§13.4）が、その規則が無い。std の本体 `if x < T.ZERO { -x } else { x }` は `-0.0` を返し、IEEE・C・WASM の `abs` は `+0.0`。W2-01 の設計メモで見つけた（2026-10-08）
- 提案: (a)。組込みの浮動小数の `abs` は符号のビットを 0 にした値。std の本体は利用者の数の型のためのまま（仕様 §3.4、§13.4。2026-10-08 決定。ベクトルの `held-S208` は W2-12。std の `abs` の doc コメントと、組込みの浮動小数がプリミティブに行くことのテストは W5-02）
