# S-1052 細部: 総称の `T` の値の破棄の E0601（`fn first[T](move x: T, n: U32) -> U32 { n }`）に、`[T: Copy]` の境界でも直ることを note で示すか

- 空白: 総称の `T` の値の破棄（`fn first[T](move x: T, n: U32) -> U32 { n }`）は、`T` が `Copy` でなければ `Alloc` を要しうるので E0601 になる（検査は宣言ごとで、具体化ごとの診断は無い）。直しは `uses {Alloc}` と `[T: Copy]` の二つあり、§8.1 の修正候補は効果行への追加だけを書く。
  `uses {Alloc}` は呼ぶ側へ伝わり、`rt` の関数からは呼べなくなる。Copy の型で使う総称には `[T: Copy]` の方が短い（`tasks/phase2.md` の L6 の逃げ道）。
  読み: (1) 候補は `uses {Alloc}` だけで、`[T: Copy]` を示さない（今のまま） (2) 候補は `uses {Alloc}` だけで、note で `[T: Copy]` でも直ることを示す（W6-03 の持ち越しの W6-02 U5a の項、148 回目の独立のレビューの提案）。どちらも `[T: Copy]` を候補にしない（直し方が一つに決まらない）。
  仮の扱い: (2)（通るプログラムも候補も変えない。`rules/leader.md` 5.11）。W6-03 の実装はこの形で作る（持ち越しの W6-02 U5a の項）。
  急ぎ: W6 の区切りで確認だけ。
