# S-100

- 空白: ブロックの末尾の式の `move` が行き止まりになる。`let y = if c { a } else { b }` は E0711（修正候補は `move` の挿入）で、その候補どおりに書くと E0002。引数の位置の E0703 は `move if c { … }` を修正候補にする（R-42 で通らない形）。返り値の位置の `move` は E0002（impl-review の P-7）
- 提案: 構文: `move` を、消費する位置に置いたブロックの末尾の式（`if` / `match` の腕、ブロック式）に書けるようにする。返り値の位置（`return`、関数の末尾、そこに置いたブロックの腕）の `move` も受け付ける。検査: 末尾の式は置かれた位置を継ぎ、腕ごとに `let` と同じ規則で E0711（修正候補は各腕への挿入。E0703 も同じ）。
  返り値の位置の `move` は通す。fmt: 返り値の位置の `move` を取り除く（S-56 の書き換えの一覧に足す。どこが返り値の位置かは構文だけで決まる）。安全装置の比較も同じ書き換えを施した AST で行う。`tests/review-phase1/parent/p7.onsa` の期待値と今の出力は各関数の上のコメント（2026-10-05 決定。実装は第 3 段）。
  改め（2026-10-15、S-541）: fmt の除去を撤回した（`move K` の定数は E0711 で、外すと通る。§18.2 の原則）。返り値の位置の `move` は受理し、資料は書かない形で書く
