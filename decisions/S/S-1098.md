# S-1098 変換の flow の `sample / N` の出力に、より遅い周期のクロックの式を `at` なしで書けるか

- 空白: §11.9 は「`sample / N` の出力は、出力の式のクロックが `sample / N` 以下（パラメータの種類とイベントの値を含む）でなければ E0815」、§11.3 は「周期の刻みのクロックの値を別の周期のクロックで使うには `at` を書く」とする。`sample / 8` の式を `sample / 4` の出力へ書く形が決まらない。
  読み: (1) 順序で以下なら通る。(2) 周期の間は `at` が要る（E0815）。通るプログラムが変わる。
  今は導くクロックの構文が無く書けない（E0002）。
  仮の扱い: W7-02 の設計メモの `readable_at` は (2)（同じ比だけ）。
- 決定: 決定（2026-11-20、利用者。170 回目、第 115 組）: (b)。変換の flow の出力の式も §11.3 の読み方のとおりで、より遅い周期のクロックの式は `at` で昇格する（無ければ E0815）。§11.9 の「以下」は S-567 の軸 2 の前（S-566 の B2 の暗黙の保持）の字が残ったもので、改めた。実装は `check_out` が `readable_at` を呼ぶ（+0）。下書き・段 1・親が一致。
- 経緯: 158 回目、2026-11-16、W7-02 U0 の設計メモの独立の審査（onsa-advisor）が挙げ、親が登録した。
