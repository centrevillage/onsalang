# S-1150 細部: flow の本体で、誤りのクロックの引数（E0805 の作る式、誤りの `prev~` など）を含む呼び出しの外側の検査が、他の引数だけで決まる誤り（`slow2(x, mk(1).len())` の E0815）も黙るか

- 空白: flow の本体のクロックの歩きは、引数のどれかのクロックが誤り（`Clock::Error`。E0805 の作る式（S-1043 C6）、失敗した `prev~` の第 1 引数など）なら呼び出しの join を誤りにし（`crates/onsa_sema/src/clock.rs` の `join`）、外側の検査（非 `rt` の fn の E0815、`at` の E0200、遅延の第 1 引数の E0813）を黙らせる。
  そのため、誤りの引数に頼らず他の引数だけで決まる外側の誤りも黙る。`slow2(x, mk(1).len())`（`slow2` は `rt` でない fn、`x` は `sample`）は、U4 の前は呼び出しの頭の E0815、後は `mk(1)` の E0805 だけ（§18.1 の位置の順なら E0815 が先）。`gb~(x + F32.round_from(mk(1).len()))`、`slow4(x, prev~(p))`（前から E0813 だけ）も同じ。
  読み: (1) 誤りの引数が一つでもあれば外側の検査を黙らせる（今の挙動、前からの仕組み）。(2) 外側の検査が読む他の引数で決まる誤りは、位置の順で先なら報告する。誤りのあるプログラムの診断だけが変わり、通るプログラムは変わらない（E0805 を直すと次の検査で E0815 が出る）。再現は横の `S-1150/nonrt_outer.onsa`・`old_prev.onsa`。
  仮の扱い: (1)。急ぎ: W7 の区切りで確認だけ（`rules/leader.md` 5.11）。
- 決定: 決定（2026-11-26、利用者。189 回目、W7 の区切りの確認だけ。「(A)と(B1)はS-1148以外OKです」）: 仮の扱いのとおり（(1) 誤りの引数があれば外側の検査を黙らせる）。
