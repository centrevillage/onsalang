# S-523

- 空白: fmt の字下げと桁そろえの「桁」の単位。`spec/tools.md` §3.2 の「最初の要素の下に揃え」（継続形）と「連続する行の行末のコメントは桁を揃える」は、桁を文字数・表示幅（東アジアの全角を 2）・バイトのどれで数えるかを書かない。
  今の実装（W3-11 の U3a の印字器と U1 の `align.rs`）は文字数で数え、文字列に全角の文字を含む行では、端末で見た桁がずれる（`g("日本語", f(a,` 改行 `b))` の `b` と、行末のコメントの桁）。一貫していて冪等。名前は ASCII なので、当たるのは文字列リテラルとコメントの前置きだけ。W3-11/b（U3a）が見つけた（2026-10-14）
- 提案: 仮の扱い: 文字数（今のまま）。後の段（W3 の字句の空白と一緒の組で）
