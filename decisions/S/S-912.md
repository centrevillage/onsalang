# S-912 別名を通したタプル・配列・`()` の `default()`（`type A = (F32, I32)` の `A.default()`）

- 空白: §6.3 は「具体的な型では `P.default()`」と書き、表はタプルと `[T; N]` と `()` が `Default` を実装するとする。これらの型には名前の後の `.` の空間が無い。
  別名を通した `type A = (F32, I32)` の `A.default()` は、(1) 別名はその型を表すので通る、(2) タプルと配列に `.` の空間は無く（`T2.x` と同じ）、総称の `T.default()` だけが届く、の二つに読める。今は E0302（`` `A` has no members ``）。
  W5-06 は (2) のまま進めた（通らない側で、後で開いても通るプログラムは壊れない）。
- 決定: 決定（2026-11-12、利用者「advisor の提案通りで良い」。140 回目。親の意見を伏せた onsa-advisor の段 1（`target/notes/140/b3-advisor/`）が (2) を選び、親も同じ読みで段 2 は省いた）: (2)。タプル・`[T; N]`・`()`・関数型は宣言の名前を持たず、型の名前の後の `.` で引く関連項目を持たない。別名でも同じで、`type A = (F32, I32)` の `A.default()` は E0302（別名は元の型と同じに使えるもので、元の型に書けない形を足さない、§4.4）。既定値はリテラル（`(0.0, 0)`、`[0.0; N]`、`()`）か総称の `T.default()`（`dflt::[(F32, I32)]()` も通る）で書く。別名なら通す (1) は、名前の無い型に別名を通したときだけ `.` の空間を作る仕組み（名前・型・降下・定数の評価・道具に通して計 50〜95 行の見当）が要り、入る名前は `default` の一つだけ（利用者の trait はタプルに実装できず E0307、演算子の trait の項目は型の名前から引けない）なので採らない。後で (1) に緩めても今通るプログラムは止まらない。E0302 に、これらの型の既定値はリテラルか `T.default()` で書くことを示す note を足す（W5-13、5〜10 行の見当）。`names/typed.rs` の `SPEC-GAP(S-912)` の印も W5-13 で外す。§4.4 に足した。
