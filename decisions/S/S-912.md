# S-912 別名を通したタプル・配列・`()` の `default()`（`type A = (F32, I32)` の `A.default()`）

- 空白: §6.3 は「具体的な型では `P.default()`」と書き、表はタプルと `[T; N]` と `()` が `Default` を実装するとする。これらの型には名前の後の `.` の空間が無い。
  別名を通した `type A = (F32, I32)` の `A.default()` は、(1) 別名はその型を表すので通る、(2) タプルと配列に `.` の空間は無く（`T2.x` と同じ）、総称の `T.default()` だけが届く、の二つに読める。今は E0302（`` `A` has no members ``）。
  W5-06 は (2) のまま進めた（通らない側で、後で開いても通るプログラムは壊れない）。
