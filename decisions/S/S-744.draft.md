# S-744 型と定数をまたぐ循環（`type A = [F32; K]` と `const K: A = 3`、定数の型が自分の値を長さに読む）のコード: E0311・E0312 のどちらか、別のコードか

- 決定済みで戻さないもの: 報告の数・位置・note・外の扱い（S-730・S-734、§18.1）。型の宣言のグラフに定数の型の点を足す実装の形（W4-05、利用者の (i)）。E0312 の定数を読む型の中の長さがこの版で E0200 のままであること（メモの確認 1）。
  第 71 組の下書きの「S-744 の仕組みの出所」と「S-744 の形の表」の節（写しは `target/notes/79/g71/draft.md`）。
- 論点: §4.4 の E0311 は「値として含む位置を辿って同じ型に戻る定義」と別名の循環を、§6.6 の E0312 は「初期化式が自分自身を参照する」形を書く。
  型の長さが定数を読み、その定数の宣言の型がその型に戻る循環は、どちらの文にも当たらない。`K` の初期化式 `3` は何も参照せず、`A` は自分を値として含まない。決まらないのは `A` の大きさと `K` の型である。
  §4.5 の「定数の評価が循環すると E0312」は、`K` の型を確かめることを評価に含めれば当たると読め、読みが割れる。
  - あわせて決める点（親が論点に移した）: 定数の宣言の型の中の長さと const 引数が読む定数への辺（別名を通さない `const K: [F32; K] = 3` と、関連定数の `impl S { const N: [F32; Self.N] = … }`）も、型の宣言のグラフに入れるか。
    - (x) 入れる。別名を通す形と同じ循環として、上の案のコードで報告する（W4-05 の U2 に約 +2〜3 行。S-725 の守り（`ensure_const_ty` の下ろし中）に当たる形が減る）。S-725 の決定の文「この版では、定数の型が自分を読む形は式で計算した定数の配列長の E0200 になり…新しい診断は要らない」を改める。
    - (y) 入れない。S-725 の文のまま、別名の無い形は E0401（初期化式がリテラル）か E0200（計算した長さ）で、別名を書くかどうかだけで循環のコードと E0401・E0200 に分かれる（0 行）。W9-03 で長さを計算するときに、定数の型が自分の値を読む形への別の守りが要る見込み（未確認）。
- 今の実装: 形の表のとおり。循環の形は E0401（初期化式のリテラルが `[F32; 3]` でない）か E0200（計算した定数の長さ）で、修正候補は無い。
- 案: どの案も、集まりの数・位置・note は §18.1 の規則による。
  - (1) E0311。集まりが型（型の宣言か、定数の宣言の型）を通れば E0311、定数の初期化式だけの集まりは E0312。§4.4 に「長さと const 引数が読む定数の宣言の型も辿る」の一句、§4.5 の文を「初期化式の評価が循環すると E0312」に絞る。
  - (2) E0312。集まりに定数（初期化式か宣言の型）が入れば E0312、型の宣言だけの集まりは E0311。§6.6 の文を「初期化式か宣言の型が…参照すると」に広げる。§6.6 の「型は宣言に書くので値に頼らない」に、集まりの定数の型は誤りの型である旨を足す。
  - (3) 新しいコード（例: E0315「型と定数をまたぐ循環」）。型の宣言だけは E0311、初期化式だけは E0312、両方を含む集まりは新しいコード。
  - (4) 循環のコードにしない。この版では、値の辺を通らない循環を長さの位置の E0401（定数の型が `U32` でない）、値の辺を通る循環を計算した長さの E0200 で報告し、値の辺を通る循環のコードは W9-03 で決める。
  - 形ごとの出力: 別名と定数は、(1) が `A` の名前に E0311（note は `K`）、(2) が `A` の名前に E0312、(3) が `A` の名前に新しいコード、(4) が `A` の長さの `K` に E0401。宣言の順を逆にすると、(1)〜(3) は `K` の名前に付く（定数に「型の循環」、型に「定数の循環」のコードが付く形が、(1) と (2) にそれぞれ出る）。
    struct の値の循環と一緒の形は、(1) が E0311 一つ、(2) が E0312 一つ（`S` が自分を値として含むのに定数のコード）、(3) が新しいコード一つ、(4) は `S` の E0311 と、`K` の E0401 か E0200 を別に出す工夫が要る。

- 他言語: 
  - rustc 1.94.1（`probe/other/s744.rs`）: `type A = [f32; K]; const K: A = [0.0; 3];` は E0391「cycle detected when evaluating type-level constant」で、型の不一致（`K` が `usize` でない）は報告しない。
    値の辺を通る `const J: usize = L[0]; const L: [usize; J] = [2, 2];` も同じ E0391。rustc は型・定数・値の循環を区別せず一つのコードで報告する。
  - Apple clang 21（`probe/other/s744.cpp`、C++20）: `using A = float[K]; constexpr A K = {};` は宣言の前の使用で「use of undeclared identifier 'K'」。宣言の順に頼るので、この循環は書けない。
  - Swift は定数の長さを型に書けず、比べられない。TypeScript の `type A = typeof K; const K: A = 3`（TS2502）は手元に tsc が無く未確認。
