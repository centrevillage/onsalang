# S-383 パターンの最初の選択肢の前の `|`

- 空白: `match` の腕の最初の選択肢の前の `|`（`| 0 | 1 =>`、前の腕の `,` の後の行頭の `| 1 =>`）。Rust などの書き方（leading vert）。今は E0002 で候補なし。S-380 を行末に決めると、行頭の `|` のうち前の行へ移せないのがこの形で、`|` を除く候補を出すか今のままかを決める。第 17 組の下書きで見つけ、Fable が S-380 と同じ回を勧めた（2026-10-10）
- 提案: 決定（2026-10-10、利用者が ID を挙げて推奨の (a) を了承。下書きと Fable が一致、第 18 組）: パターンの選択の `|` は選択肢の間にだけ書く。パターンを読み始める位置（腕、入れ子の `(` や `,` の後、`let` と `for` の束縛）の `|` は構文の段の E0020（データのファイルに新しい行）で、修正候補は `|` と後ろの空白を除く形。
  S-380 の行（選択肢の後の行頭の `|`）とはパーサーの位置で分かれ、前の行へ移す候補は作らない。`|` を除いた後にパターンが続かない形（`| =>`、`| x > 0 =>`）は候補を作れず E0002。`|` だけの行は除く候補を出してよい（空行が残り、腕の並びの中の空行は通る）。`| | 0` は一つずつ二回、`| 0` 改行 `| 1 =>` は S-383 と S-380 の二回で直る。
  データの行の kind（"redundant" か "foreign"）は W3-06 で決める。仕様 §7。実装は W3-06
