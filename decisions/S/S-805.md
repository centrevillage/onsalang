# S-805 部分ビューどうしの重なりで範囲を比べるか（`f(inout a.slice(0, 4), a.slice(4, 8))`、`a.slice(0, 4).copy_from!(a.slice(4, 8))`）

- 空白: §5.3 の 96 行は `inout xs.slice(from, to)` を書けるとするが、部分ビューが同じ呼び出しの他の引数と重なるかを書いていない。§5.2 の 69 行は「同じ配列の添字どうしは、添字が等しいかを静的に判定しないので、重なるものとして扱う」、§5.4 の 119 行は借用の `for` の部分ビューを「範囲によらず `xs` の場所を反復元とする」とする。
  範囲が定数で分かれる二つのビュー（`f(inout a.slice(0, 4), a.slice(4, 8))`、`a.slice(0, 4).copy_from!(a.slice(4, 8))`）を重なるとするか。
  dev（`d73e460c`）では、ビューを `inout` に渡す形と受け手にする形は全て E0701（場所でない）、借用のビューと `inout a` の重なり（`add(inout a, a.slice(0, 8))`）は通る（R-31 のすり抜け、W4-08 で直す）。再現は `target/notes/90/w408/i/probe/u2.onsa` の `q11_two_views`。
  読み: (1) 部分ビューは元の場所の要素の集まりで、添字と同じく範囲によらず、元の全体・添字・同じ元のほかのビューと重なる（上の二つも E0702）。(2) 範囲が定数で分かれていれば重ならない（範囲の静的な判定を足す）。
  急ぎ: W4-08 U2（部分ビューと平面の要素の場所）のテストの票の前。
- 決定: 決定（2026-10-31、利用者。90 回目。確認だけ。親の読み）: (1)。
  部分ビューは元の場所の要素の集まりで、添字（§5.2 の「同じ配列の添字どうしは重なるものとして扱う」）と同じく範囲によらず、元の場所の全体、その添字、同じ元のほかの部分ビューと重なる。`f(inout a.slice(0, 4), a.slice(4, 8))` と `a.slice(0, 4).copy_from!(a.slice(4, 8))` は E0702。
  §5.4 の借用の `for` の部分ビュー（範囲によらず `xs` の場所を反復元とする）とも揃う。
  同じ元の前半と後半を一つの呼び出しに同時に渡す形は書けず、別の値に分けるか写す。今通るプログラムで誤りになるのは R-31 のすり抜け（`add(inout a, a.slice(0, 8))`、W4-08 で直すと決まっている）だけ（ビューを `inout` に渡す形と受け手にする形は今は全て E0701）。
  仕様 §5.2（69 行）に一文を足した。担う作業は W4-08 U2（ビューを元の場所の添字の射影として重ねる、設計メモ `target/notes/90/w408/i/memo.md` の 1.3）。
- 経緯: 90 回目（2026-10-31）、W4-08 の設計メモ（onsa-impl、`target/notes/90/w408/i/memo.md` の NEW-1）が挙げた。親が dev のバイナリで再現して登録した。前からある（ビューの `inout` は W4-08 まで E0701）。
