# S-688 E0304 になった `use` の名前（S-675 の (d1) で黙る名前）を、E0310 の辺に数えるか（`a.onsa` の項目 `b` と `use b`、`b.onsa` の `use a`）

- 空白: S-678 は、名前の段で失敗した `use` の名前を依存（E0310 の辺）に数えないとし、S-675 の (d1) は、E0304・E0305 になった名前を S-462 の誤りの名前の集合に入れて使う所を黙らせるとした。E0304 になった `use` の名前（解決はした）を辺に数えるかを書いていない。
  読みは (1) 解決はしたので辺を張る、(2) 誤りの名前なので失敗した `use` と同じく辺を張らない、に割れる。形は `a.onsa` に項目 `b` と `use b`、`b.onsa` に `use a`（(1) では E0304 と E0310 の両方、(2) では E0304 だけ）。
  W4-03 U3b1 の実装（67 回目）は (1)（印は置いていない）。

- 経緯: 67 回目（2026-10-25）、W4-03 U3b1/i（onsa-impl）が見つけた。急ぎは後の段。関係: S-678、S-675、S-462。
