# S-67

- 空白: 入力名 `sample_rate` の flow が `check` を通り、降下の内部の失敗が E0200 として同じ位置で 7 回出る。降下は関数の中の最初の失敗で止まり、同じ関数の 2 つ目の未対応の機能を報告しない（レビュー R-77）
- 提案: 入力名に予約名と状態の固定のフィールド名を使ったら E0304（R-48 の `let` の検査と同じ表）。`internal(...)`（約 100 か所）を内部エラー（終了コード 101、診断コードなし、項目の位置と内部の文面）にし、コマンドを止める。降下とビルドの診断は単位で絞らず、位置・コード・文面で重複を除く。
  降下の診断は原因のソースの位置と文面で出し、生成した関数の名前を含めない。未対応の機能を全て報告できるよう、降下が関数の中の最初の E0200 で止まらないようにする（未対応の機能の検出を降下の前の一つの段にまとめるのが一つの形）。
  全体に関わる診断（E1011、E0820、ポリシー）は宣言の単位に入れない。`tests/review-phase1/parent/r77.onsa` の期待値は各項目の上のコメント（2026-10-04 決定。実装は第 2 段）
- 時期: M3
- 補い（2026-11-18、親）: 165 回目、第 110 組の S-1138（族: flow の状態の名前）で、状態の固定のフィールド名を `_sample_rate`・`_poisoned`・`_initialized`・`_bulk` にし、入力と `let` の名前の予約を外した。入力 `sample_rate` は組込みの名前（§2.2）として E0304 のまま。
- 判断（2026-11-27、親）: 191 回目、W8-01 の設計メモ部 3（`target/notes/191/w801/p3v2/memo.md` の 3 章・13 章の B2・B3）を利用者が決めた（「推奨案で良いです」、§18.1 の字に「良いです」）: この決定（同じ関数の二つ目の未対応も報告する）を狭める。単位の引数・返り値・ローカルの束縛・式の型がこの版で E0200 になれば、その単位は降下せず、降下の診断は降下できない型ごとに一つの E0200 だけ（総称の単位は具体化ごと）。降下しなかった flow のインスタンスを作る flow も診断を出さずに降下しない（§18.1 に一文）。止めた定数を読む単位は止めず、その式を報告なしの穴にして続ける（読む側の他の E0200 は全て出る）。仮の型（`()` など）を作らないので、R-293・R-170・R-434・R-332・R-335・R-529 の族が構造で無くなり、穴のやり直しの O(穴 × 大きさ) も消える。位置（決定の字だけに置く）: 束縛の宣言（引数とローカルの束縛は名前、返り値は返り値の型。sema の `FnDef` に `ret_span` を足す）に、型ごとに単位で一件。フィールド経由は宣言に書いた型を指す note。式だけに現れる型は単位の最初の一件。`panic("…")` の文字列は降下が値として降ろさないので数えない（部 3 の審査の H1）。実装は新しい作業 B（W8-14 の後、W8-02 の前）。
