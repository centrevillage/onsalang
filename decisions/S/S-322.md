# S-322

- 空白: 複合代入と増減の左辺の「フィールドの経路」に、タプルの添字（`t.0 += 1`、`t.0++`）を含めるか。S-250 は「名前かフィールドの経路なら候補 `x = x + 1` の形、添字など評価が二度になる左辺は候補なし」と書く。今の W3-15 の実装は含めない（候補なしの E0002）。W3-15/b で見つけた（2026-10-09）
- 提案: 決定（2026-10-09、利用者が ID を挙げて了承。親の案）: 複合代入と増減の左辺の「フィールドの経路」にタプルの添字（`t.0`）を含める。評価が無いので二度になる問題が無い（S-250 が候補を出さないとしたのは添字など評価が二度になる左辺）。候補は `t.0 = t.0 + 1`。実装は W3-07（`is_place` とデータのファイルの例、`SPEC-GAP(S-322)` を外す）
- 時期: W3
