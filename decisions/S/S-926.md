# S-926 `T: Escape + ?Escape` と `T: ?Escape + ?Escape`

- 空白: §4.5 の矛盾の一覧は「`?Dup` を Dup を要する境界と並べる形」だけで、`T: Escape + ?Escape` が無い（W5-17 の持ち越し、109 回目の文書の点検）。今は `?Escape` が E0200 なので当たらない。`T: ?Escape + ?Escape` は同じ文の「同じ境界を二度書く形」で E0416 と読める。`T: Copy + ?Escape` は §4.5 の「種の制約を満たすものとして扱い」で通る。
  読み (1) `?Escape` を `Escape` と並べる形は `?Dup` と `Dup` と同じ矛盾の E0416（候補なし）。読み (2) `Escape` を先に E0020 で外す。S-751 の細部は「S-747 の重なりと矛盾の判定を先に行い、それが無い並びにだけ当てる」なので (1) に揃う。
- 決定: (1)。`T: Escape + ?Escape` は `T: Dup + ?Dup` と同じ矛盾の E0416（候補なし）。`T: ?Escape + ?Escape` は同じ境界の二度書きの E0416。`T: Copy + ?Escape` は矛盾でない（§4.5 の「種の制約を満たすものとして扱い」）。仕様 §4.5（2026-11-06 決定）。
- 経緯: 119 回目（2026-11-06）、親が W5-17 の票を書くときに `持ち越し` の項から登録した。固定のバイナリでは `Dup + ?Dup` が E0416、`Escape + ?Escape` が `?Escape` の E0200。
