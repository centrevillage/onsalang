# S-1082 細部: 後置の `when` と、修飾子の位置の外の `when`・`reset_if` の、修飾子を入れた後のコード

- 空白: §2.2 は「後置の節（`saw~(f0) when c`）は構文の段の誤りで、note で連鎖の形を示す」とする。`tasks/diag-codes.md` の E0200 の行は S-169・S-555 を括弧に並べ、E0200 に含むとも外すとも読める。修飾子を入れた後は「この版で未対応」でなくなる。
  今: 後置の `lp~(x) when c` は E0200（予約語 `when`）、`let when = x` も E0200。読み: (1) E0200 のまま note、(2) 構文の誤りのコード（E0002 の類）と note。どちらも誤りのプログラムで、コードだけが違う。
  仮の扱い: (2)（§2.2 の字は構文の段の誤り）。
  急ぎ: W7 の区切りで確認だけ（`rules/leader.md` 5.11）。
  W7-09 U1（2026-11-21、172 回目）で仮 (2) を入れた: E0002 と連鎖の形の note にするのは、インスタンスの呼び出し `f~(…)` の `)` の直後の `when`・`reset_if`（`lp~(x) when c`、`lp~(x).down~(2) when c`、`lp~(x) reset_if r`）だけ。値の後の `x when 1`、`let when = 1`、行頭の `when c` は予約語の E0200 のまま（既にある構文のテストの期待を変えない）。
  W7-09 U1/b が範囲の読みを挙げた: (2a) `f~(…)` の `)` の直後だけ（今の仮）、(2b) 修飾子の連鎖の受け手になりうる式の後ろ全て（改行を挟む `lp~(x)` 改行 `when c`、`(lp~(x)) when c`、`par~ … { } when c`、`if~ … { } else { } when r`）。(2b) の形は今は予約語の E0200。どちらも誤りのプログラムのコードと note だけが違う。
