# S-850 見出しで失敗した `impl` の後の、メソッドの探索の失敗（E0413）を黙らせる範囲（R-180）

- 空白: R-180 の決定は、見出しで失敗した `impl` と途中で失敗した `use` を使う側に偽の診断を出さないとし、`use` の側はモジュール単位の印に限った（S-462 の補い）。`impl` の側で、黙らせるメソッドの探索の失敗（E0413）の範囲を書いていない。
  見出しが失敗した `impl`（`impl S[ {`）は対象の型が分からないので、(1) そのモジュールの全ての型のメソッドの探索の失敗を黙らせる、(2) 受け手の型が同じモジュールで宣言されたものだけ、(3) 名前が読めた型（`S`）だけ、に割れる。`85400d9b` は `impl S[ {` の E0002 の後に、使う側の `s.f()` に E0413 を出す（`target/notes/104/x23est/B/p/c.onsa`）。
  急ぎ: W5-04 の U2（R-180 の `impl` の側）の前。
- 決定: 決定（2026-11-05、利用者。115 回目、組 86。細部は ID を挙げて了承）: (2')。見出しを読めなかった構文の段の誤りの `impl` があるモジュールで宣言した型は、メンバと満たす trait が読めなかった部分である。その型の使う側には、使う所のモジュールによらず診断を出さない。
  孤児規則（§6.3、W5-04 の U1）の後、固有の `impl` が足せるのは定義したモジュールの型のメンバだけなので、印の鍵は使う所でなく型の定義のモジュールにする。
  細部（確認だけ）: B1 黙らせるのはメソッドの探索の失敗（E0413）、型の名前の後の `.` の見つからない名前（E0302。`S.make()`、`S.K`）、trait を満たすかの判定（境界の E0416、演算子の E0401）。B2 黙らせないのは、フィールドの E0413、組込み型の受け手、他のモジュールの型の受け手（`Option[S]` を含む）、型パラメータの受け手。B3 印を立てるのは見出しを読めなかった `impl` だけで、見出しが読めて本体で切れた形は読めたメンバを名前に数える。B4 仕様は §18.1 の失敗した `use` の段落の後の一段落。B5 W5-04 の U2。
  代償: その型の本物の綴りの誤り（`s.ff()`）も見出しを直すまで隠れる。
  独立のレビュー（段 1）も (2') で親の読みと一致し、段 2 は省いた。形の表と想定漏れの表、読む所の案（`lookup.rs::member`、`bounds.rs::traits_unknown`）は `target/notes/115/s895-advisor/`。
- 経緯: 104 回目（2026-11-02）、X-23 の見積もりの組 B（onsa-impl）が W5-04 の見積もりで挙げた。親が `85400d9b` のバイナリで E0413 を再現した。関係: R-180、S-462。
