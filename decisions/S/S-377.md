# S-377

- 提案: W4 の名前の作業の前に決める
- 時期: W4
- 決定: 決定（2026-10-23、利用者が ID を挙げて了承。55 回目、第 40 組）: 族の規則 S-595 から決まる。`impl` の本体の中の struct リテラルとパターンの `Self { x: a }`（表の 5〜7 行）は書け、全てのフィールドを書く規則（E0410）と見えないフィールドの規則（E0303）は型の名前で書いたときと同じ。仕様 §2.2・§4.4
