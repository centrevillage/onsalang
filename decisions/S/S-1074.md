# S-1074 細部: 値の循環（E0311）の型を値として含まない位置で名指す宣言（`struct VA { v: VB, b: Buf[VC] }`・`struct VB { v: VA }`・`struct VC { c: Buf[VA] }` の `VC`）が、その型を書いたとおりに読んで判定するか
