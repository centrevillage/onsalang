# S-207 結果が 0 のときの符号

- 空白: 浮動小数の演算の結果が 0 のときの符号（ちょうど打ち消す和と差、0 との積と商、`sqrt(-0.0)`、丸めで 0 になった結果、`floor` / `ceil` / `trunc` / `round` と `F64` → `F32` の 0）。§3.4 は「数学的な結果を丸めた値」とだけ書く。`to_bits()`、`1 / x`、`min` / `max` で見える。W2-01 の設計メモで見つけた（2026-10-08）
- 提案: (a)。§3.4 に 0 の符号の規則を自己完結の文で書き、§13.4 の文と §6.3 の `ZERO`（`+0.0`）を改めた。`@fp(relaxed)` の中では 0 の符号を約束しない（理由は縮約。Fable の指摘）。`relaxed` が許すのは縮約と再結合だけで、GCC では縮約だけを緩める（仕様 §3.4、§6.3、§13.4、§15.5。2026-10-08 決定。ベクトルの `held-S207` は W2-12、GCC の緩和は W2-09）
