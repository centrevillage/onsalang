# S-1260 細部: 属性の行・`?` で終わる型の境界・既定値のある欄の後の改行の `when c`（`@export` 改行 `when c`）に、連鎖の形の note を付けるか（S-1082 の「式の後ろ」。仮は付ける、行頭の演算子の読み §2.5 に揃える）

- 空白: S-1082 は、修飾子の位置の外の `when`・`reset_if` が式の後ろ（`x when c`、改行の後の `when c`）に来たら E0002 と連鎖の形の note（`lp~(x).when~(c)`）とする。改行の後の `when c` が「式の後ろ」かは、前の行が何で終わるかで決まる。
  W7-17 L4b（L-1 の直し）は、この判定を行頭の二項演算子が前の行に続くかの判定（§2.5、S-124・S-370。腕の始まり S-386 を除く）と同じ一か所に置いた（`foreign::after_an_expression` と `foreign/lines.rs` の `goes_on_after_operand`）。
  その結果、前の行が式でない次の形にも note が付く: 属性の行の後（`@export` 改行 `when c` 改行 `pub fn f() {}`）、`?` で終わる型の境界の後（`T: ?` 改行 `when c Dup`）、既定値のある欄の後（`a: I32 = 1` 改行 `when: I32 = 2,`）。同じ所の行頭の `+ c` も「前の行に続く」の E0002 になる（前から）。同じ行の `@export when c` には付かない。
  読み: (1) 前の行が式で終わるときだけ付ける（属性・型の境界は式でない。判定を §2.5 の判定から分ける）。(2) 行頭の演算子の判定に揃え、今のまま付ける。コードと候補はどちらも同じ（E0002、候補なし）で、note の有無だけが違う。誤りのプログラムだけで、通るプログラムは変わらない。
  仮の扱い: (2)（判定が一か所のまま）。再現は `target/notes/190/l4b_b/` の `attr_newline_when.onsa`・`attr_newline_plus.onsa`・`bound_newline_when.onsa`・`field_default_newline_when.onsa`。W7 の区切りで確認だけ。
