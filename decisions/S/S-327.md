# S-327

- 空白: `::` と `[` の間の改行（`id::` の次の行の `[U8](250)`）。§2.5 は名前と `::`・`::` と `[` の間の空白を E0020 とし、行頭の `::` を E0002 とするが、`::` の後の改行は書かない。
  W3-19/t で見つけた（2026-10-09） 追加の形（2026-10-10、RF/t）: `id ::` 改行、`id:: // x` 改行、括弧の中の `two(id::` 改行 `[I32](a), 1)` も今は `::` の位置の E0002。`id::[` 改行 `I32](a)` は構文を通る。W3-06 は今の挙動のまま済んだ。
- 提案: 後の段（W3-06 の前）
- 時期: W3
- 決定: 決定（2026-11-09、利用者。127 回目）: S-961 の族の規則から。`::` と `[` の間の改行は E0020 で、候補は改行を除く形（間の行コメントは残し、行コメントがあれば `[` からをコメントの前へ上げる）。前に空白もある `id ::` 改行 `[U8]` は一つの形で、候補は両方を除く一つ。括弧の中も同じ。
  名前と `::` の間の改行は行頭の `::` で、括弧の中でも E0002 のまま。候補を当てた後のこの版の E0200（式の型引数の具体化）は後の段で、約束の外ではない。型の位置の `Buf::` 改行 `[F32]` も同じ行の空白（`Buf:: [F32]`）と同じ E0020 で、候補は `::` と改行を除く `Buf[F32]`（点検で見つかり、利用者が了承）。§2.5 に書いた。
