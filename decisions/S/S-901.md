# S-901 同じ型パラメータへの `T.trunc_from(x)`・`T.trunc_sat_from(x)`・`T.narrow_from(x)`（`x: T`）の判定と修正候補
- 空白: §3.3 が同じ型パラメータへの呼び出しとして名指すのは `T.round_from(x)`（`x: T`）だけである。`T: Int` の `T.trunc_from(x)`・`T.trunc_sat_from(x)`（`x: T`）は、同じ型への呼び出しで E0413 とも、変換元の境界 `Float` に反するので E0416 とも読める。`T.narrow_from(x)`（`x: T`）の修正候補は、具体的な型と同じく期待の型で選ぶとも、候補なしとも読める。通るプログラムは変わらず、診断のコードと候補だけの違いである。
- 決定: 決定（2026-11-05、利用者。117 回目、確認だけ）: どちらも具体的な型と同じに読む。`T.trunc_from(x)`・`T.trunc_sat_from(x)`（`x: T`）は E0413 で、修正候補は呼び出しを外した `x` である（§3.3 の「この判定は、宣言の境界と返り値の型の検査より前に行う」。変換先が別の型パラメータなら E0416）。`T.narrow_from(x)`（`x: T`）の候補は期待の型で選び、`T` なら `x`、`Option[T]` なら `Some(x)`、期待の型が無い位置では候補なしで note を出す（S-231 の補い）。仕様 §3.3。作業は W5-05 U3（事例 `tests/spec/num_traits/tp_conv_same_type_trunc_e0413.onsa`、`tp_conv_same_type_narrow_e0413.onsa`、`tp_conv_same_type_narrow_no_candidate_e0413.onsa`）。
- 経緯: 117 回目（2026-11-05）、W5-05 U3/t（onsa-test）が空白として挙げ、親が §3.3 の文から読みを一つに絞って実装の票に書き、確認だけで利用者に出した。
