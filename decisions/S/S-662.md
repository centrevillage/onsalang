# S-662 固有の `impl` のメンバの可視性が、型の可視性より広いとき（無指定の `struct Inner` の `impl Inner { pub fn new() -> Inner }`）に S-144 の E0303 にするか

- 空白: §15.1 は、公開の宣言に書いた型がそれより狭い可視性なら E0303 とし（S-144）、当たる位置（関数の引数と返り値、別名の右辺、定数の型、フィールドと列挙子の中身、trait のメンバ）を並べるが、固有の `impl` のメンバを並べていない。
  無指定（パッケージ内）の `struct Inner` の `impl Inner { pub fn new() -> Inner }` で、メンバの `pub` を見せる可視性として返り値の `Inner` を E0303 にするか、メンバの見える範囲は型の可視性を超えないとしてメンバの可視性と型の可視性の狭い方で比べるか（この形は通る）、`pub` を書くこと自体を誤りにするかを書いていない。
  W4-03 U1 の設計メモは、メンバ自身の可視性を見せる可視性にする（E0303 になる）。
- 決定:
- 経緯: 64 回目（2026-10-24）、W4-03 U1 の設計メモの独立の審査（onsa-advisor）が見つけた。仮の扱いは設計メモのとおり厳しい方（E0303）で `SPEC-GAP` の印を付ける。待つのは W4-03 の U4（可視性）。関係: S-144、S-491、S-36。
