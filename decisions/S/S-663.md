# S-663 自分のパッケージ名を頭に書いた `use` の修正候補の形（`use fx.{a}`、`use fx.{a, b}`、`use fx`）

- 空白: §15.1 は「自分のパッケージ名を頭に書くと E0302（修正候補はパッケージ名を外すこと。同じ名前のルート直下のモジュールがあれば、それを指す）」とする。
  `use fx.util.{helper}` は `fx.` を外して `use util.{helper}` になるが、`use fx.{util}` は `fx.` を外すと読めない `use {util}` になり、`use fx.{a, b}` と、パッケージそのものを取り込む `use fx` は、外した形が一つの `use` に決まらない。§18.1 は修正候補を当てた後に誤りが残らないことを約束する。
  親の案（確認だけ）: `use fx.a…` は `fx.` を外す。`use fx.{a}` は `use a` にする。`use fx.{a, b}` と `use fx` は候補を出さず、note で形（`use a` と `use b` に分ける、モジュールを直接取り込む）を示す。
- 決定:
- 経緯: 64 回目（2026-10-24）、W4-03 U1 の設計メモの独立の審査（onsa-advisor）が見つけた。設計メモの「`name.` を除く編集」は `use fx.{util}` で E0002 の形を作る。事例 `tests/spec/fixes/pkg_own_name` は `use fx.util.{helper}` の形だけ。待つのは W4-03 の U3a。関係: S-37、R-106、S-258。
