# S-746 境界の `?Sized`（Rust の書き方）の診断（今は E0302「cannot find `Sized`」。他の言語の書き方の E0020 と、境界を外す候補にするか）

- 空白: §4.5 は境界の `?` を `Dup` に付けて暗黙の制約を外す形だけを書く。Rust の `T: ?Sized` は、Onsa の型が全て大きさの決まる形なので意味を持たない。今は E0302「cannot find `Sized`」（再現は 79 回目の第 71 組の下書きの `probe/s711/b24_sized.onsa`）。
  読み: (1) 他の言語の書き方として E0020 と、境界を外す候補（`spec/foreign-forms.toml` の行）。(2) 今の E0302 のまま。S-711 の答え（`?` を `Dup` 以外に付けた形の扱い）によって形が変わる。
- 決定: 決定（2026-11-08、利用者。126 回目）: (1)。
  境界の Rust の `?Sized` と `Sized` は、名前 `Sized` が見つからないとき、型の段の E0020（`spec/foreign-forms.toml` の `implicit_bound` と同じ種類の行、Rust 由来）で、修正候補は要素を外す一つ（隣の `+`、残りが無ければ `:` ごと。`T: ?Sized` → `T`、`T: Show + ?Sized` → `T: Show`）。
  Onsa の型は全て大きさが決まるので、外しても意味は変わらない。`?Dup` は意味が変わる（複製できない型も受ける）ので候補にしない。利用者が `Sized` を宣言していれば名前が見つかり、この行は当たらない（`?` なら S-711 の E0416）。未知の名前を引いた後に判定する S-711 の順は、`Sized` だけこの行が E0302 の代わりになる。§4.5 に書いた。
  実装は W5-11 U10d（型の段の境界の名前を引く所、約 15〜25 行。候補は `implicit_bound` の外す編集を使い回す。行と例を `spec/foreign-forms.toml` に足す）。
- 経緯: 79 回目（2026-10-28）、第 71 組の下書き（onsa-gap）が新しい S の候補として挙げた。関係: S-711。
