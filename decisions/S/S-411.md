# S-411

- 空白: パターンの負のリテラルの `-` の後の空白（`- 1 =>`、`- (8)`）。§2.5 の前置の記号の後の空白の規則（S-123）は式の前置の記号を挙げ、§7 のパターンの負のリテラルを挙げない。読みは (1) 同じ規則で `space_after_prefix` の E0020（候補は空白を除く形）、(2) パターンでは受ける（fmt が除く）。
  今は通る（`tests/cst/trivia_neg_literal_pattern.onsa` の 19 行の `- ( ( 8 ) )`）。W3-06/i の設計メモで見つけた（2026-10-10）
- 提案: 決定（2026-10-10、利用者が ID を挙げて親の案（確認だけ）を了承）: (1)。パターンの負のリテラルの `-` の後にも空白を空けない。`- 1 =>` は `space_after_prefix` の E0020 で、修正候補は空白を除いた形。理由: §2.5 の前置の記号の空白の規則は場所を限らず、§7 はパターンの負の整数を式のリテラルと同じに扱う。
  パターンだけ受けると、同じ字面を場所で受けたり拒んだりする（R-62）。仕様 §2.5。
  実装は W3-06 の単位 1b（`tests/cst/trivia_neg_literal_pattern.onsa` の 19 行を `-( ( 8 ) )` に直す）（読みの補い、2026-10-10、親: 当てるのは被演算子が整数のリテラルで後ろに範囲の記号が続かないときだけ。範囲・浮動小数・定数の形はそれぞれの行が報告し、整数でない被演算子（`- x`、`- _`）は空白を除いても誤りが残るので候補なしの E0002（S-236）。W3-06/b（単位 1b）が見つけた）
