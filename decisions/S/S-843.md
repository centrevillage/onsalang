# S-843 `[[plugin]]` の `id`・`name`・`vendor` の文字列の中身（空、空白だけ、改行）と、`id` の重複の比べ方（大文字と小文字）

- 空白: §14.3 は「`flow`・`id`・`name`・`vendor`・`version`・`category` を書き（全て必須、閉じた一覧）」、§15.3 の表は「`id`、`name`、`vendor` | 必須。文字列。同じ `id` の重複は誤り」とし、空の文字列（`id = ""`）、空白だけ（`vendor = " "`）、改行を含む字を書けるか、`id` の重複を字のとおりに比べるか大文字と小文字を畳むか（`"P"` と `"p"`）を書いていない。
  §14.3 は VST3 のクラスの ID を `id` から作る。
  W4-02 U4 の仮の扱いは (1): どの文字列も通り、`id` は字のとおりに比べる（`crates/onsa_driver/src/manifest/read.rs` の `plugin` に `SPEC-GAP(S-843)`）。読みは (1) 今のまま (2) 空と空白だけを誤りにする (3) `id` を大文字と小文字を畳んで比べる、に割れる。`[[plugin]]` を使うのは M10（CLAP）からで、M10 までは実害が無い。
