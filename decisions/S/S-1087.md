# S-1087 細部: 同じモジュールの、失敗した二つの `use` が同じ名前を束縛するとき（`use a.plain.Config` と `use a.with_par.Config`、どちらも E0302）に E0304 を出すか

- 空白: §15.1 は「一つのモジュールで名前は一度だけ束縛」とし、§18.1 は失敗した名前を S-462 の誤りの名前の集合に入れて使う所で黙らせる。S-675 は、解決した名前どうしの重なり（E0304・E0305）の報告する側と残す側を決めたが、二つとも解決に失敗した `use` が同じ名前を束縛するかは決めていない。
  W7-12 U1 の後、`init` の入力の無い flow の `Config` は名前空間に無い（S-112）ので、別の二つの flow の `Config` を同じモジュールで `use` すると両方が E0302 になる。今（`f74bfef`）は両方が解決し、E0304 が出る。
  読み: (1) 失敗した `use` は名前を束縛せず、二つ目も E0302 だけ、(2) 失敗した名前も束縛を占め、二つ目に E0304 も出す。どちらも誤りのプログラムで、E0304 が一つ余分に出るかだけが違う。
  仮の扱い: W7-12 U1 の実装の出す診断（事例は一つのモジュールに同じ名前の失敗した `use` を一つだけ置く）。
  急ぎ: W7 の区切りで確認だけ（`rules/leader.md` 5.11）。
