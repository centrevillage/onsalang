# S-795 族: 意味を変えない位置（代入の右辺、リテラルと構築子の要素）に書いた Dup の値の `move` を E0703 にするか

- 空白: Dup の値の `move` が意味を持つのは、`let` / `var` の初期化と `match`・`for` の見出し（束縛の行を所有にする、§5.4）だけで、代入の右辺・struct / 配列 / タプルのリテラルと構築子の要素では何も変えない（Dup の値は複製される）。
  §5.2 は `move` の引数の位置だけを E0703 とし（64〜65 行、S-609）、48 行の「`let` などの位置の Dup の値の `move` は所有の束縛を選ぶ印として受け付ける」の「など」の範囲は決めていない。今はどの位置でも受け付ける（`(move n, 1)`、`Some(move n)`、`x = move n`）。
  S-609 の原則（`move` の印は所有が移って前の値が以後使えなくなる所にだけ付ける）を、意味を変えない位置まで締めるか（E0703 で `move` を消す候補）、今のまま受け付けるか。S-793 で構築子の要素をリテラルの要素と同じ族に置いたので、決めるときは族で一度に決める。
  急ぎ: 後の段（W4-09 の S-605 の残りの前に見る）。
