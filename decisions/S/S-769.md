# S-769 固有の `impl` の対象に第二級の生成型を書く形（`impl voice.Out { … }`）: 対象の型の位置の E0710 にするか、補助のメソッドを書ける形にするか

- 空白: §11.6 の 241 行は、生成された型を flow を宣言したモジュールで定義されたものとして扱い、同じモジュールに `impl voice.State { ... }` で補助メソッドを書けるとする。生成型の `Out`（219 行。出力のフィールドごとの `Span` を持つ）は §5.3 の 89 行で第二級（返り値・フィールド・`move` の引数にできない、引数の位置にだけ現れる）である。
  `impl voice.Out { pub fn helper(self) -> U32 { 1 } }` を書けるかは書いていない。メソッドの `self` は引数の位置である。
  W4-05 U4a の実装は、固有の `impl` の対象を整形性の段の根にし、第二級の型の位置として E0710 にする。U4a の前は診断が無かった（再現は `target/notes/82/s769/fl1.onsa` の 9 行）。
  形: (1) 対象の位置の E0710（第二級の型は型の位置に書けない）。(2) 対象には書け、メソッドの `self` を引数の位置として読む（`State` と同じく補助メソッドを書ける）。
- 決定: 決定（2026-10-29、利用者。82 回目。外出中の暫定 (1) を帰宅後に了承）: (1)。
  第二級の生成型（`In`・`Out`）は固有の `impl` の対象に書けず、対象の位置の E0710（候補なし）。`impl` の見出しは型の位置で、第二級の型は引数の位置にだけ書ける（§5.3）。補助の処理は自由関数 `fn h(o: voice.Out)` で書く。
  理由: 既決の読み（見出しは型の位置、`In`・`Out` は引数の位置だけ）から一つに決まる。(2) は `move self`・メンバの返り値の `Self`・将来の trait の `impl` と W4-07 の経路に派生の規則が要る。後で (2) に緩めても既にあるプログラムを壊さない。
  U4a の前は通っていた形を誤りにするが、`tests/`・std・`examples/` に当たる形は無い。仕様は §5.3 の生成型の段落と §11.6 の 241 行。実装は W4-05 U4a（`sig/wellformed.rs` の `Slot::Target`）。事例は `tests/spec/types/wellformed_generated_out_positions.onsa`。
- 経緯: 82 回目（2026-10-29）、W4-05 U4a の壊す側（onsa-break、U4a/b）が仕様の空白として報告した（登録は `48f5085`）。利用者の外出中に、助言の担当の段 1 と親の読みが一致した読みを U4a の直し（i2）で暫定に作り（補い）、帰宅後に利用者が了承した（`ce74d51`）。
- 補い（2026-10-29、親）: 82 回目、利用者の外出中: 助言の担当の段 1（親の読みを伏せた票。報告の写しは `target/notes/82/advisor_s769.md`）が (1) を推奨し、既決の決定と仕様から読みが一つ（確認だけ）と分類した。親の読みも (1) で一致したので段 2 は省き、W4-05 U4a の直し（i2）に (1) を暫定で入れ、`SPEC-GAP(S-769)` の印を付けた。仕様の文は帰宅後の決定まで変えない。
