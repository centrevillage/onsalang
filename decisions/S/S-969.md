# S-969 修飾子 `.down~(N)`・`.up~(N)` の N の期待型（§4.5 の定数式の型の位置の一覧に無い）

- 空白: §11.9 は `.down~(N)`・`.up~(N)` の N を「2 以上の 2 のべき乗の定数式（違えば E0808・E0417 の類）」とする。§4.5 は定数式の型を「大きさを表す位置（配列の長さ、配列リテラルの繰り返しの数、遅延線の長さ、`vdelay~` の最大、`par~` の端）では `U32` で、const 引数では const パラメータの型」とし、N の位置はどちらの一覧にも無い。`.down~(2.0)` や `I32` の定数を書いたときの期待型とコード（E0401 か）が決まらない。
  親の読み（未確認の案）: 比は正の整数なので、大きさの位置と同じ `U32` に読むのが自然（§11.4 の「上の桁の `U32` の欄」とも合う）。
  今の実装（dev `f5eced1d`）は修飾子を読まず、`lp~(x).down~(2)` も `lp~(x).down~(2.0)` も E0812（W7-09 で入れる）。
- 決定:
- 経緯: 130 回目（2026-11-10）の文書の点検（onsa-docs、範囲 `b45edc42..7d24fc04`）が、§4.5 の位置の一覧と §11.9 を突き合わせて見つけた。W7-09（修飾子の N の検査）の前に決める。
