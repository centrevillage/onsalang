# S-479

- 空白: FAUST の `~ _` の候補 `prev~(^y)` の名前が決まらない位置（`let y = ~ _`、`let _ = x + ~ _`、タプルの `let`、fn の本体、`par` の本体）。
  仮の扱いは、flow の本体の名前一つの `let` の値の中で、二項演算子の右の被演算子の `~ _` だけを `faust_feedback` の E0020 にし、他は候補の無い `faust_feedback_unnamed` の E0002（`foreign/faust.rs` の `SPEC-GAP(S-479)`）。W3-23/t で見つけた（2026-10-13）
- 提案: 決定（2026-10-13、利用者）: 対象外（FAUST の文法の形は `rules/criteria.md` 7.32 で対象にしない）。今の扱いのまま残し、`foreign/faust.rs` の印を対象外のコメントに改めた
