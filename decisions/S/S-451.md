# S-451

- 空白: `0o` に 8 進でない数字がある形（`0o19`、`0o8`）と、数字の無い `0o`。§2.4「8 進の接頭辞は無い（`0o17` は E0020、候補は `15`）」、§18.1「接頭辞の後に数字が無いもの（`0x_`）は E0001」。読みは (1) E0001 (2) 候補の無い形の E0002 と note（E0020 は候補が必須、D-04）。
  今は E0020「literals have no type suffix」（`0` と接尾辞 `o19` と読む）。
  W3-05/i の設計メモで見つけた（2026-10-13） 補い（2026-10-13、W3-05/b の単位 1 の G-3）: 2 進の `0b12` は `0b1` と `2` に分かれて一般の E0002 で、W3-05 の `0o19` の E0001 と揃わない（親が単位 2 のバイナリで確かめた）
- 提案: W3-05 は (1) の仮の扱い（`SPEC-GAP(S-451)`）。後の段
