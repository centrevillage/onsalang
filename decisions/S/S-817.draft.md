# S-817 flow の組込み名 `sample_rate`・`sample_tick` に `~` を付ける形（`sample_rate~()`）の E0812 に、`~` を消す修正候補を出すか

- 決定済みで戻さないもの: `sample_rate~()` が E0812 であること（§2.6）と名前の段であること（S-267）。候補を出すなら編集は `~` の 1 字（R-285、§18.1 の最小の編集）。flow の外の `sample_rate~()` は S-815（E0821 か E0302）。
  第 76 組の下書きの「仕組みの出所」と「族の形の表」の節（写しは `target/notes/93/g76/draft.md`）。
- 論点: §2.6（187 行、S-590）は、呼び出しに付けた `~` の E0812 の候補（`~` を外す）を、呼び先が `f(x)` で呼ぶ項目（関数、関連関数、名前空間の関数、効果の操作、要素を持つ列挙子）のときだけ出し、値なら候補なしで note とする。
  §11.4 の表の flow の組込み名 `sample_rate`・`sample_tick` は、印なしの `sample_rate()` と呼ぶ名前で、値でも並びの項目でもない（S-720 は flow の組込み名を自分の呼び出しの形の呼び先でだけ要る種類とする）。候補を出す並びにも出さない並びにも無い。
  R-285（直す、W4-12）は候補の編集を `~` だけを消す形に揃える直しで、候補があることを前提にしている。
- 今の実装: flow の本体の `sample_rate~()` は flow の段の E0812「`sample_rate` is not a flow」と、呼び出しの全体を `sample_rate()` で置き換える候補（`m/flow.out` の w135）。当てると誤りなし（`probe/x/srate_tilde_flow.onsa`、clean、1 回）。
  `sample_tick~()` は E0812 と `~` だけを消す候補（w143）。当てると flow の段の E0200「this version does not support the builtin `sample_tick()`」（`probe/x/stick_tilde_flow.onsa`、no-candidate。E0200 は後の段で約束の内）。
- 案: (a) 候補を出す: 編集は `~` だけを消す（R-285）。§2.6 の 187 行の候補を出す並びに flow の組込み名 `sample_rate`・`sample_tick` を足す。
  (b) 候補を出さず note だけ: S-590 の並びのとおり。note で `sample_rate()` と書くことを示す。R-285 は候補が無くなって閉じる。
  - 形ごとの出力: `sample_rate~()` は、(a) が E0812 と候補 `sample_rate()`、(b) が E0812 と note。`sample_tick~()` は、(a) が E0812 と候補（当てるとこの版の E0200）、(b) が E0812 と note。
