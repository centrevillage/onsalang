# S-940 `Array`・`Ptr`・関数型を通して増える宣言（`R[T] { t: T, a: Array[R[(T, T)]] }`）を宣言の段で誤りにするか

- 空白: §4.4 の E0311 は値として含む位置だけを辿るので、`R[T] { t: T, a: Array[R[(T, T)]] }` は `check` を通る。`R[I32]` の値は作れるが、全ての `R[…]` を具体化できない。`Ptr` と関数型を通す形も同じである（`a: fn(R[(T, T)]) -> I32`）。
  読み: (1) 宣言の段の誤りにする（E0311 を増える引数に広げる）。(2) S-290 の降下の上限で足りる。今の降下は `Array`・`Ptr` の E0200 で止まるので急がない。関数型の形は S-290 の型の深さの判定が受ける。
