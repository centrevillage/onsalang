# S-355 `else` の無い `if~` と `else if~`

- 空白: `if~` の `else` の省略（`if~ c { 1.0 }`）と、連鎖の `else if~`（`if~ c { … } else if~ d { … } else { … }`）のコード。§11.5 は「`else` は省けない」「`~` は連鎖の全体に掛かる」とするが、違反のコードを書かない（構文の E0002、`else if~` は誤解を示す印として E0020、型の段の誤り、に割れる）。W3-09/t で見つけた（2026-10-09）
- 提案: 決定（2026-10-09、利用者が ID を挙げて了承。下書きと Fable が一致、第 14 組）: `else` の無い `if~` は構文の段の E0002（候補なし、note。次の行の `else` は今どおり E0003 が先）。`else if~` は構文の段の E0020（データのファイルに新しい行）で、候補は一つ: 連鎖の頭に `~` があれば後ろの `~` を除く形、無ければ `~` を頭の `if` へ移す形。
  一つの連鎖に複数あれば `~` ごとの誤り（S-259）。計画の M1 の文法の写しを直した。仕様 §11.5。実装は W3-09
