# S-538

- 空白: fmt の書き換えで文や並びの要素が消えたときの、その行の行末のコメント（値の無い末尾の `return` だけの行の `return // c`、ブロック形の並びの `init` の行の `0.0, // c`、継続形の `prev~(x, // c` 改行 `0.0) // d`）。`spec/tools.md` §3.4 は「コメントを書かれた行に残す」と書き、行の頭の `,` を前の要素へ移して行にコードが残らない形だけを例に挙げる。
  W3-12/t（U1）が見つけた（2026-10-15）
- 提案: 決定（2026-10-15、利用者が (s2) を選んだ。親の確認だけの案と違う）: 行末のコメントは、その行の最後のコードに付く。最後のコードが落とすトークンなら、そのコメントは落とす範囲の中にあり、S-536 (1) によりその書き換えはしない（`return // done` は残る。値のある `return e // c` は `e // c`）。
  理由: コメントの付く先を一つの規則で決め、S-536 (1) と同じ規則で扱う。`spec/tools.md` §3.4。実装は W3-12 の U1
