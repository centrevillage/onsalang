# S-1047 flow の本体の `par~` の結果の要素型が Copy でない形（`(par~ i in 0 ..< 2 { "a" })[0].len()`）を受け付けるか

- 空白: §5.4 の破棄の要らないリテラルと静的な値の一覧に `par~` の結果が無く、§11.3 の E0810（信号の値型は Copy）は名前を付けた値と境界の値に掛かる。`(par~ i in 0 ..< 2 { "a" })[0].len()` と、呼び出しの結果を要素にする形は通る（段 1 の `a1.txt` の `par_static`・`par_call`）。
  E0810 にするか、§5.4 でリテラルと同じに数えるか。R-458（遅延）と一緒に「flow の構文が作る値の型は信号の値型」の一文で決める案がある。
  急ぎ: W7-04 の前。
- 決定: 決定（2026-11-18、利用者。166 回目、第 111 組。「(d)で良いです」）: (d) 状態を持つもの（インスタンス、組込みの遅延、`par~`）が作る値（インスタンスの出力、遅延の値、`par~` の結果の要素）の型は信号の値型で、名前を付けない位置でも Copy でなければならない（E0810。位置はその式で、入れ子なら外の式）。`if~`・`match~` の結果は含めない。
  遅延の値の R-458（W7-07）も同じ文に入る。検査は型が確定した後のクロックの歩きの `par~` の腕（`let` の E0810 と同じ所、段 1 の補い）。仕様は §11.3。
