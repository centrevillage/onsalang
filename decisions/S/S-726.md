# S-726 使われない束縛の E0309 を報告する段（名前の段か、後の段か）と、同じ単位の後の段の誤りとの順（S-129・S-716 の決め直し）

- 空白: S-129 は fn の世界の使われない束縛の E0309 を名前の段で報告するとし（flow の本体は flow の検査の段）、S-716 は同じ位置の E0320 より先に E0309 を報告するとした。
  §18.1 は一つの単位で段の順（構文 → 名前 → 型 → flow の検査 → 引数のモードと移動 → rt と効果）の最初の誤りだけを報告するので、名前の段の E0309 は、同じ単位の型・モード・rt と効果の誤りより先に出て、それらを隠す（`let a: I32 = true` を読まないと、E0401 でなく E0309）。
  W4-04 U7b の前に親が既存の事例への当たりを見積もった（正規表現による推定。`P78/w404/u7a/parent/count129.py`・`count129b.py`）: 正例で新しく E0309 が出る単位が約 140（67 ファイル）、期待している後の段の誤り（多くは E0401）が E0309 に隠れる単位が約 190（61 ファイル）。仕様の ```onsa の例と std には当たらない。
  決めること: E0309 を報告する段（名前の段のまま、型の段の直後、全ての段の後など）と、flow の本体の E0309 の段、それに伴う S-716（E0320 との順）の扱い。
