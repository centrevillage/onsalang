# S-112

- 空白: flow が生成する C の名前の一覧が閉じておらず、E1011 の範囲が決まらない。flow どうしの名前が重なる。Config の渡し方と、空のときの形が決まっていない（点検 C-43）
- 提案: 名前を仕様 §14.2 の表で閉じ、export の計画（R-89）がこの表から flow ごとの名前の集合を作って E1011 を判定する。Config は `const <p>_config*`。
  形は空かどうかによらず一定（空の構造体は予約のメンバ `_unused`、今の `onsa_empty` を改める。`_params_default` と `_param_index` は常に、`_param_info` は長さを書かない配列）。`bulk` の引数は常に置き、`BULK_ALIGN` は 0 のとき 1。
  要るのに NULL の `bulk` / `cfg` は `_init` の失敗（値は S-113 で 2）。`_new` は bulk も確保し、`_free` は両方を解放する。IR の B-2 と B-6 の形を改めた（2026-10-06 決定。実装は C の API の段）
- 時期: M4
