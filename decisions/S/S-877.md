# S-877 `std.math` の関数と、整数・浮動小数のメソッド（§3.3 の変換、§3.4 の床除算と検査付き）が `rt` であることを仕様が書いていない

- 空白: §10 の例（`rt fn soft_clip` の中の `std.math` の `abs`）と §11.2 の 37 行（flow の本体で呼べるのは効果行が空の `rt fn`、メソッドを含む）は、`std.math` の関数と数のメソッドを `rt` の文脈で呼べる前提で書かれているが、それらが `rt` であることを書く文が無い。
  std は全てを `rt` で宣言している（`std/math.onsa` の `pub target rt fn`、`std/core/num.onsa` の `checked_add` などの `pub rt fn`）。S-873 で `unwrap` も `rt` にした。
  読み: (1) `std.math` の関数と §3.3・§3.4 の数のメソッドは全て `rt`（確保も待ちも再帰もしない）。(2) 宣言ごとに決まり、呼べるとは限らない。
  事例: W5-14 U1/t の `checked_rt_new.onsa`・`is_nan_is_finite_callers.onsa`・`packages/checked_is_nan_modules/` は (1) で書いた（断り書き付き）。既にある `scalar_checked_rt.onsa` も同じ前提。
  急ぎ: W5-14 の終わりまで（親の読みは (1)、確認だけの見込み）
