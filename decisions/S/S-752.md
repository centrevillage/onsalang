# S-752 見出しが E0307 の固有の `impl` の対象に書いた別名が誤りの型になるとき（`type A = S[I32]` の型引数の数の誤り、`struct S { a: A }` と `type A = S` の値の循環）、メンバを別名の右辺の頭が名指す型の `.` の空間に数えるか

- 空白: §18.1 は、見出しが E0307 の固有の `impl`（対象に書いた別名など）も「対象の型が決まれば」メンバをその型の名前の後の `.` の空間に数えるとする（S-748）。S-748 の A2 は、別名の右辺が名前の無い型（タプル、配列）ならメンバはどこにも入らないとする。別名そのものが誤りの型になるが、右辺の頭は型を名指す形で「対象の型が決まる」かは書いていない。
  形: `type A = S[I32]`（総称でない `S` に型引数、E0302）、`struct S { a: A }` と `type A = S`（値の循環、E0311）、`type A = Option[A]`（E0311）。今の実装は別名を下ろして誤りの型ならメンバをどこにも入れない（`type A = S[I32]` の後の `impl A { const N }` と `impl S { const N }` は E0302 だけ）。
  読み: (1) 右辺の頭が型を名指せば対象の型は決まるとし、数える（A2 の「名前の無い型なら入らない」と同じ線で、W4-05 U3 の別名の頭を下ろさずに辿る鍵がそのまま出す答え。上の形では `impl S` の `N` に E0304 が足される）。(2) 別名が誤りの型なら決まらないとし、数えない（今の答え。名付けの環が二段に戻り約 +10〜15 行）。
  どちらも誤りのあるプログラムの診断だけが変わり、通るプログラムは変わらない。再現は `target/notes/80/w405/u3/probe/alias_err_rhs_impl.onsa`・`alias_value_cycle_impl.onsa`。
- 決定: 決定（2026-10-29、利用者。80 回目）: (1)。
  見出しが E0307 の固有の `impl` の対象に書いた別名は、右辺の頭の名前が型を名指せば、別名そのものが誤りの型（型引数の数の誤り、値の循環の E0311）でも、その型を対象の型とし、メンバをその型の名前の後の `.` の空間に数える。S-748 の A2（右辺が名前の無い型ならメンバはどこにも入らない）と同じく、右辺の頭の名前で決める。
  誤りのあるプログラムの報告だけが変わり、通るプログラムは変わらない。`type A = S[I32]` の後の `impl A { const N }` と `impl S { const N }` は、別名の E0302 と、ソースの順で後の `N` の E0304。数える E0304 は別名を直しても残る重なりで、偽の連鎖エラーではない。
  仕様は §18.1 の誤りのある宣言を名前解決に見せる段落の、E0307 の `impl` の文の後に一文。
  実装は W4-05 U3a（`sig/decls.rs::alias_heads` が別名を下ろさずに右辺の頭を辿る形が、この答えを出す）。事例は二つの形（型引数の数の誤り、値の循環）。
- 経緯: 80 回目（2026-10-29）、W4-05 U3/i の見積もり直し（onsa-impl）が仕様の空白の候補（NEW 2）として挙げ、親が dev `0f1cdbce`（コードは `fb45620`）の写し `P80/bin/onsa-w405u2b3` で再現した。親は S-748 の A2 から読みが一つ（(1)）と見て、確認だけにする（`rules/process.md` 8.6 の「仕様の空白の流れ」の 2）。期限は W4-05 U3a。関係: S-748、S-730。
- 補い（2026-10-29、親）: 80 回目（W4-05 U3a/t の報告の NEW 3）: 別名が誤りの型のとき、その別名を対象にした `impl` の見出しに E0307 は出ない。§18.1 の誤りのある宣言の段落（誤りの型を使う側には診断を出さない）による。
  見出しに書いた失敗した名前で `impl` の全体は一つの単位にならない（§18.1 の 61 行）ので、メンバは別々の単位で、後ろに書いた別名の `impl` のメンバにも E0304 が付く（`type A = S[I32]`、`impl S { const N }`、`impl A { const N }` は E0302 と後ろの `N` の E0304）。
- 補い（2026-10-29、親）: 81 回目（S-754）: 上の補いの「見出しに E0307 は出ない」は S-754 (1) で改めた。誤りの型の別名を対象にした `impl` も見出しが E0307 で、`impl` の全体が一つの単位になり、後ろに書いた別名の `impl` のメンバの E0304 は単位に隠れる。メンバを `.` の空間に数えることは変わらない。
