# S-354 `if` / `match` と `~` の間の空白

- 空白: `if` / `match` と `~` の間の空白（`if ~ c {`、`match ~ x {`）のコード。§2.6 は「`if` / `match` の直後に空白を空けずに `~` を書く」とするが、違反のコードを書かない。
  読みは (1) E0020 で空白を除く候補（§2.5 の名前と `~` の空白に倣う）、(2) 前置の `~` の行（`faust_bit_not`、E0020 で `!c`）、(3) E0002 に割れる。今は `let a = if ~ c { 1 } else { 2 }` が E0002「expected an expression, found `~`」。
  W3-09/t で見つけた（2026-10-09）
- 提案: 決定（2026-10-09、利用者が ID を挙げて了承。下書きと Fable が一致、第 14 組）: (a)。`if` / `match` の直後（同じ行）の空白の後の `~` は構文の段の E0020（データのファイルに新しい行）。
  候補の一つ目は空白を除く `if~ c`。`~` が被演算子に接する `if ~c` だけ、二つ目に前置の `~` の読みの `if !c`（`faust_bit_not` の読みそのもの）。`else if ~ d` は S-355 の形として報告し、空白を除く候補は出さない（接した `~d` には `!d` を二つ目に）。
  対象は `if` / `match` だけ（`while ~c` は今どおり `faust_bit_not`）。`if~c` は受理し fmt が `if~ c` にする。仕様 §2.6。実装は W3-09
