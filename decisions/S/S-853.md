# S-853 族: §5.3 の要素が Dup でない列のメソッド

- 空白: 族の S（S-794 の `get`、S-847 の `fill!`・`slice`・`add_from!`・`copy_from!`）は、要素が Dup でない（Affine の）`[T; N]` を受け手にしたとき、どのメソッドを持ち、値を複製するか取り出すメソッドをどう扱うかを、仕様が書いていないことから出た。
  §5.3 は `[T; N]` に `Span[T]` と同じメソッドを与え、§4.5 が要素の型を `T: Copy` に限るのは `Buf[T]` と `Span[T]` だけである。
  族の一般の規則（要素の種ごとに、列のメソッドのどれを持つか）を一つ決め、個々の形はそこから決める。関係: R-349（`fill!` が Affine の値を複製したまま通る）
