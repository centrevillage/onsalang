# S-1219 細部: 合成して `U32` を超える引数で、引数のクロックの E0815 と合成したクロックの E0808 のどちらを先に出すか（今は E0815 が先で、文に書けないクロックが出る）

- 空白: S-1216 は連鎖と合成したクロックの N が `U32` を超える形を E0808（位置は超えた修飾子）とし、§11.3・§11.9 は引数のクロックが入力より速いか遅い形を E0815 とする。合成して `U32` を超える引数（出力 `sample * 2^20` の `h` を `r~(h~(x).up~(4096))` で受ける、入力 `sample / 2^31` の `h` を `h~(p).down~(2)`）は両方に当たり、今は検査の段の順で E0815 だけが出て、文に書けないクロック（`sample * 4294967296`、`sample / 4294967296`）が出る。どちらを先に出すかは字で決まらない。
  読み: (1) 合成が `U32` を超えるなら E0808 を先に（E0815 は出さない）、(2) 今のまま E0815 が先で、文のクロックを書ける形に寄せる。通るプログラムは変わらず、診断のコードと文だけが変わる。
  仮の扱い: (2)（今の実装）。急ぎ: W7 の区切りで確認だけ（`rules/leader.md` 5.11）。再現は W7-16 U7d の壊す側の報告 `target/notes/178/w716/u7d/b_report.md` の指摘 3。
- 決定: 決定（2026-11-26、利用者。189 回目、W7 の区切りの確認だけ。「(A)と(B1)はS-1148以外OKです」）: 仮の扱いのとおり。引数の E0815 と合成の E0808 は §18.1 の位置の順（引数が先）。文のクロックの表記は約束にしない。
  突き合わせ: 助言の担当が固定のバイナリ `onsa-d02ddee` で再現し、仮の扱いが今の挙動と合い、既決とぶつからないことを確かめた（`target/notes/189/reports/onsa-advisor-a4f41d23ad112f9fe-001.md`）。
- 経緯: 178 回目（2026-11-23）、W7-16 U7d の壊す側（onsa-break）が挙げ、親が細部として登録した。W7-17 の持ち越し「W7-16 U7d から」が名指す。
