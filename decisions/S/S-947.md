# S-947 継続のトークンの次の行の項目が前の単位に飲まれ、宣言が消える（`let y = x *` の次の `fn z()`）

- 空白: S-47 の決定の文は「エラー回復で行頭の項目キーワードまで読み飛ばすとき、前の行が継続のトークンで終わっていれば項目の始まりとみなさない（関数型 `fn(I32) -> I32` で始まる継続の行のため）」とする（§2.5 と §18.1 の字には無い）。このため本体が `let y = x *` で切れると、次の行の `fn z()` が前の単位に飲まれて宣言が消え、`z` を呼ぶ側に偽の E0302 が出る。メンバでは偽の E0413 になる。
  `struct`・`const`・`pub fn`・`export fn`・`///` の行も同じで、`@fp(relaxed)` の行だけ宣言が残る。`let g = fn(x: I32) ->` の次の行と、`enum` の `B(` の次の行では、型の読みが `fn` を消費して `z` の位置で失敗する。
  読み: 行頭の項目の始まりは前の行が継続でも項目の始まりとし、名前の続かない `fn`（`fn(`）だけ今のままにする案がある。`type Op =` の次の `fn(I32) -> I32` は通るので変えてはならない。通るプログラムは変わらない見込みである。
  再現は `target/notes/122/adv92/in/` の `y1`・`y3`・`y11`・`c1`〜`c10`。
  同じ族の形: 字下げのある `@fp(relaxed)` だけの行（属性の行は次の行に続く）の次の 1 桁の `fn canary` が、閉じない `impl` のメンバに取り込まれ、使う側に E0302 が出る（W5-11 U3 の壊す側、入力 `target/notes/122/u3b/impl_member_body__attr_only__2.onsa`）。
- 決定: 決定（2026-11-08、利用者。124 回目、第 93 組）: (b)。誤りの後の回復は、前の行が続く行（§2.5 の継続のトークンか属性で終わる行の次の行）の頭も行頭とし、そこにある項目の始まりで止まる。`fn` と `rt fn` の後ろに同じ行で `(` が続く形（関数型と無名関数）は、項目の始まりでない。S-47 の決定の回復の例外の文をこれで置き換え、継続の規則は変えない。
  細部（確認だけ）: 947-1 型の読みも、式の読みと同じく `fn`（`rt fn`）の後に名前が続けば `fn`（`rt`）の位置で失敗する（R-396 を同じ単位で直す）。947-2 属性だけの行の次の行も同じ規則で、閉じない括弧の単位の字下げは、属性が付く項目の行で比べる。947-3 `fn` と `(` の間の空白とコメント（`fn (`）は見ず、`fn(` と同じに除く。
  947-4 仕様は §18.1 の項目の始まりの定義と閉じない括弧の段落に文を足した。§2.5 は変えない。947-5 `the_recovery_does_not_start_a_unit_on_a_continued_line` の期待（E0002 一つ）は保ち、名前と注釈を理由に合わせて改め、継続しない行頭の `fn(`（`p01`）と `fn (`（`p14`）の事例を足す。
  通るプログラムと修正候補は変わらない。実装は W5-11 の残りの単位。後で項目のキーワードで始まる型や式（第 2 期の `extern "C" fn(…)` の型など）を足すときは、同じ除く判定に足す。
  理由: 継続した行の頭の宣言が前の単位に飲まれると、使う側に偽の E0302・E0413 が出て、書き手を宣言を足す誤った直しへ向ける。`fn(` は名前を持たず宣言にならないので、除いても回復は何も失わず、S-47 の目的（継続の行の関数型を項目と取り違えない）は保たれる。
- 経緯: 122 回目（2026-11-07）、第 92 組の独立のレビューの段 1 が想定漏れとして見つけ、親が `y1`・`y11` を再現した。段 2 は第 92 組と別の問い（単位の境目）とした。124 回目（2026-11-08）、第 93 組で S-950 と決めた。下書きは `decisions/S/S-947.draft.md`。
