# S-289 `ONSA_ALLOW_INEXACT_FP` のビルドと、警告なしの約束

- 空白: `ONSA_ALLOW_INEXACT_FP` で浮動小数の `#error` の検査を外したビルド（`-ffast-math` を付けたもの）にも、§13.4 の「生成した C は `-Wall -Wextra -pedantic` で警告を出さない」が及ぶか。
  今は clang の `-ffast-math -Werror` で、`min` / `max` の `NAN` に `-Wnan-infinity-disabled` が 8 件出る。警告なしの約束は厳密なビルドだけか。W2-09/t で見つけた（2026-10-08）
- 提案: (b) 警告なしの約束は、§13.4 の必要なフラグでコンパイルするビルドに限り、最適化の水準は問わない。`ONSA_ALLOW_INEXACT_FP` のビルドに約束するのはコンパイルできることだけで、警告なしの約束も当てはまらず、NaN と無限大に依る振る舞い（§3.4 の比較、`is_nan`、`min` / `max`、変換の panic）は約束しない（Fable の案。S-294 を含めた）。
  ALLOW の例の `-Ofast` を「`-O3 -ffast-math` など」に改めた（clang 21 では `-Ofast` 自体が警告）。条件: ALLOW のビルドで出る警告のうち、明らかに無くした方が良く、無くすのが大した費用でないものは、見つけたら報告し、利用者が個別に対応を決める（約束にはしない）。
  対象のコンパイラの版は S-295（利用者。第 7 組の下書き。仕様 §13.4。2026-10-08 決定。実装は W2-09（ALLOW のビルドの事例は `-Werror` なしでコンパイルできることを見る））
