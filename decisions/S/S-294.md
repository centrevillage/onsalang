# S-294

- 空白: `ONSA_ALLOW_INEXACT_FP` のビルドで残す Onsa の意味。`-ffast-math` の `-O2` で、ソースの `x != x` は NaN で偽になり、`is_nan()`、`min` の NaN、`trunc_i32()` の NaN の panic は残った（clang 21、gcc-15.2。版で変わりうる）。変換の panic は C の未定義の動作を防ぐ検査でもある。第 7 組の下書き（S-289）で見つけた（2026-10-08）
- 提案: S-289 に含めた（NaN と無限大に依る振る舞いは約束しない。仕様 §13.4。2026-10-08 決定）
- 時期: W2
