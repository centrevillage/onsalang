# S-1230 塊の内の修飾子の条件に書いた `sample_tick()` だけの式が、条件を読む刻みの時点の時間か、呼び出し側の刻みの時間（頭の引数と同じ）か

- 空白: §11.4 は「使う所の刻みのクロックに合わせる」「巻き上げず、使う所の段で評価する」、§11.10 は「修飾子が働く刻みは…`when~` は動いた刻みだけ」「境界の内に書いた修飾子の条件は、同じクロックの頭の入力と同じ時点の値を読む」とする。
  塊（`.up~(M)` を `.down~(N)` が包む形）の内の `when~`・`reset_if~` の条件が `sample_tick()` だけ（と定数・パラメータの種類）からなり、塊の外にそれより速い W の `when~` があって塊の刻みが呼び出し側の格子からずれると、読む時間が割れる。
  読み: (T) 条件を読む刻みが動いた時点の時間（今の実装と参照評価器。182 回目に F2 として直した形）。(G) 呼び出し側の刻みの時間（頭の引数に渡した `sample_tick()` と同じ。条件を呼び出し側の式とみる）。(E) `at` を求める誤り。
  例: `acc~(1.0).up~(2).when~(sample_tick() % 3 == 0).down~(2).when~(c)`（`c` は `1 1 1 0 1 0 1 0 0 0 0 1 0 1 1 0`）の塊の刻みは位置 0・2・6・13 で、最後の刻みが読む時間は (T) 13、(G) 12。
  今は、直の形と、条件を部品の本体の中に書いて包んだ形が 13、条件をポートで渡して包んだ形・`at (sample / 2)` を付けた形・遅い信号と混ぜた形・頭の引数に渡した形が 12。
  通るプログラムは (T)・(G) では変わらない（値だけ）。
  仮の扱い: 今の実装（(T)）のまま。W7-10 を閉じる前に決める。
