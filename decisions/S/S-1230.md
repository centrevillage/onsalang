# S-1230 塊の内の修飾子の条件に書いた `sample_tick()` だけの式が、条件を読む刻みの時点の時間か、呼び出し側の刻みの時間（頭の引数と同じ）か

- 空白: §11.4 は「使う所の刻みのクロックに合わせる」「巻き上げず、使う所の段で評価する」、§11.10 は「修飾子が働く刻みは…`when~` は動いた刻みだけ」「境界の内に書いた修飾子の条件は、同じクロックの頭の入力と同じ時点の値を読む」とする。
  塊（`.up~(M)` を `.down~(N)` が包む形）の内の `when~`・`reset_if~` の条件が `sample_tick()` だけ（と定数・パラメータの種類）からなり、塊の外にそれより速い W の `when~` があって塊の刻みが呼び出し側の格子からずれると、読む時間が割れる。
  読み: (T) 条件を読む刻みが動いた時点の時間（今の実装と参照評価器。182 回目に F2 として直した形）。(G) 呼び出し側の刻みの時間（頭の引数に渡した `sample_tick()` と同じ。条件を呼び出し側の式とみる）。(E) `at` を求める誤り。
  例: `acc~(1.0).up~(2).when~(sample_tick() % 3 == 0).down~(2).when~(c)`（`c` は `1 1 1 0 1 0 1 0 0 0 0 1 0 1 1 0`）の塊の刻みは位置 0・2・6・13 で、最後の刻みが読む時間は (T) 13、(G) 12。
  今は、直の形と、条件を部品の本体の中に書いて包んだ形が 13、条件をポートで渡して包んだ形・`at (sample / 2)` を付けた形・遅い信号と混ぜた形・頭の引数に渡した形が 12。
  通るプログラムは (T)・(G) では変わらない（値だけ）。
  仮の扱い: 今の実装（(T)）のまま。W7-10 を閉じる前に決める。
- 決定: 決定（2026-11-24、利用者。183 回目）: (G)。
  修飾子 `when~`・`reset_if~` の条件は、頭の引数と同じに呼び出し側の式で、条件の `sample_tick()` が合わせるのは、条件を読むクロック W（W が `sample * N` なら本体の `sample`。`reset_if~` も W）の、書いた本体の刻みである。`sample_tick()` の他に刻みの値もイベントの値も読まない条件は（定数・`init`・`block` の値と混ぜた式を含む）、式の全体に W の `at` を付けた形と同じ値で、外の `when~` で条件を読む刻みがずれても、その時点までの最後の値を読む。
  輪で集める条件も同じ。動いた刻みの時点の時間を読むには、条件を部品の本体の中に書く。仕様の字は §11.4（頭の引数と条件の文、「合わせた刻みの段で評価する」）・§11.10（合成の項の括弧）。
  利用者の経過: 親が書き方ごとの時間の表と (T)・(G)・(E) の比べを示し（推奨 (G)、確信 中）、利用者「(G) で正確な今の時間を出す処理を具体的に提示して」に、条件を塊だけを本体に持つ flow の中に書く形（`note~(t0, len).when~(c)` が位置 13 の時間を読む値）を示した後に、利用者「分かりました、(G)にしましょう」。字は監査の後に示し「仕様の字はそれで良いです」。
  実装: sema の `guard_cond` の F2 の行（182 回目）を外した（条件の `Ambient` は `at W` を付けた条件と同じ道。欄が要るかは `Choose::place` の一か所）。裸の形と `at` の形の Core が、`.up~`・`.down~`・`when~`・`reset_if~` の連鎖の全数 3174 形で一致。
- 経緯: 181 回目（2026-11-24）、W7-10 U3ae の壊す側が F2（Core が `N*floor(q/N)` を読む）を挙げ、親と助言の担当（`target/notes/182/w710/p/adv_f2_report.md`）が字から (T) と読んで 182 回目に直した。
  183 回目に、閉じる前の字の監査（onsa-advisor、`target/notes/183/w710/close/reports/`）が、直の形と包んだ形で値が割れるので確認だけで出さない方がよいと挙げ、親が登録した。
  伏せた段 1（onsa-advisor、`target/notes/183/w710/close/amb/`）は、字では一つに決まらないとし、(G) を選んだ（確信 中）。 182 回目の F2 の直しと、親の「字から (T) に決まる」という読みは言い過ぎだった（§11.4 の「使う所の段で評価する」と §11.10 の「同じクロックの頭の入力と同じ時点の値を読む」が別の答えを指す）。
