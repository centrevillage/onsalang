# S-425

- 空白: 前置の `+` の後の改行（`let y = +` 改行 `a`、`two(+` 改行 `a, 1)`、パターンの `+` 改行 `1`）。§3.1 は「`+x` は E0020 で、修正候補は `+` と後ろの空白を除く形」とし、後ろの空白が改行を含むかを書かない。前置の `-`・`!`・`^` の後の改行は S-369 で E0020（候補は記号を相手の行へ移す形）。
  今（W3-06/i の単位 2）は `+` の位置の E0002「expected an expression, found `+`」で候補なし。同じ行の `+ a` は E0020 で `+` と空白を除く候補が出る。W3-06/b（単位 2）が見つけた（2026-10-10。親が作業ツリーのバイナリで確かめた）
- 提案: 決定（2026-10-10、利用者が ID を挙げて親の案（確認だけ）を了承）: 後ろの空白に改行を含め、E0020 で候補は `+` と後ろの空白（改行を含む）を除く形（`let y = a`、`two(a, 1)`）。`-` の改行（S-369、移す形）と候補の形は違うが、どちらも E0020 で候補がある（利用者の注意の `-` と `+` の食い違いを残さない）。仕様 §3.1 の文に「後ろの空白（改行を含む）」と書く。実装は W3-06 の単位 2
