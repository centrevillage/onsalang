# S-1274 入れ子の添字 `grid[i][j]` で、基 `grid[i]` の範囲の検査と後の添字 `j` の式の評価のどちらが先か（`grid[i][1 / z]` で `i` が範囲外、`z` が 0 のとき、どちらの panic を報告するか）

- 空白: §3.5 は「panic しうる式が複数あるときは、この順で最初に panic する式が報告される」とし、例に「`xs[i][j]` で両方が範囲外なら `i`」を挙げる。入れ子の添字 `grid[i][j]` で、基 `grid[i]` の「評価」が `i` の範囲の検査を含むなら、`j` の式の評価の前に検査して範囲外を報告し、含まないなら（添字の式を評価してから検査するなら）`j` の式の panic を報告する。`grid[i][1 / z]`（`i` が範囲外、`z` が 0）で、範囲外か 0 で割るかが割れる。§3.5 の例は両方が範囲の検査なので、どちらの読みとも合う。同じ問いは代入先（`grid[i][1 / z] = v`）、フィールドの経路の添字（`s.xs[i].ys[1 / z]`）、借用と `inout` の引数の場所にも当たる。W8-03 の設計メモの独立の審査（194 回目、5 節）で見つけた。再現の入力 `target/notes/194/w803/review/probe/p2/`（`l2`・`l9`）。S-1273 と同じく「添字の基の評価」の族（S-1275）。
