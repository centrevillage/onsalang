# S-822 型引数を付けた `~` 無しの flow の呼び出し（`lp[F32](x)`）のコード

- 空白: §11.1 は flow の外の「`~` 無しの flow の呼び出し」を E0821 とし、§6.1 は名前の経路に `[…]` を付けた呼び出し（`P[…](…)`）を、`P` が項目なら型引数の `P::[…](x)` に直す E0020 とする（候補の `::` の挿入は W5-10）。flow に型引数を付けて呼ぶ `lp[F32](x)`（この版では flow は型引数を取れない）が、どちらに当たるかを書いていない。
  読み (1): flow の呼び出しなので E0821。読み (2): 項目の `P[…](…)` の E0020（W5-10）。読み (3): 今のとおり、呼び先の式 `lp[F32]` の値の位置の E0308（flow は値でない）。
  今の実装は W4-12 U3 の前も後も、型の段の E0308「`lp` is a flow, not a value」。通るプログラムは変わらない。項目と型の `P[…](…)` を扱う W5-10 で一緒に決める。
  再現: 94 回目の scratchpad の `w412u3/parent/gaps.onsa` の `a3`、`w412u3/b/c10.txt` の `targs_callee`（写しは区切りで `target/notes/94/w412u3/`）。
- 決定: 決定（2026-11-10、利用者。132 回目、第 95 組。材料は `target/notes/132/g95/`）: (a)。flow の名前に `[…]` を付けた形（`lp[F32](x)`、`lp[0](x)`、`lp[F32].(x)`、`let f = lp[F32]`）は、flow の本体でも外でも、flow を値の位置に書く E0308 で候補なし（S-816 の `lp.(x)` と同じ）。note で、flow の本体なら `lp~(…)`、外なら名前空間の関数（§11.6）を示す。§6.1 の `P[…](…)` の E0020 は `f(x)` で呼ぶ項目か型だけで、flow を含めない。理由（利用者）: どの案も誤りであることは同じなので、例外が少なく実装が簡単なもの。§15.1 と §6.1 に書いた（S-816 の note の反映の抜けも §15.1 に一緒に書いた。R-422）。
  W5-10 U1b: note（R-422 の `lp.(x)` の note と同じ所）と、`spec/foreign-forms.toml` の `type_args_square` の注記に「flow の名前に付けた `[…]` はこの行でない（§15.1）」。
- 経緯: 94 回目（2026-10-31）、W4-12 U3/b（onsa-break）が空白の候補として報告し、親が登録した。期限は項目と型の `P[…](…)` を扱う W5-10 の前。関係: S-191、S-816、R-269。
