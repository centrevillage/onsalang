# S-1133 細部: flow の検査の段の誤りが一つの flow に二つ以上あるとき、どの検査の失敗がその式のクロックを誤りにするか（外側の検査の診断を出すか）

- 空白: §18.1 は、一つの単位では「残った診断のうち、`diagnostics` の並べ方（開始の位置、終わりの位置、コード、文面）で最初のもの」を報告し、「読めなかった部分は誤りの型として扱い、それを使う側には診断を出さない」とする。flow の検査の段で、ある式の検査が誤りになったとき、その式を含む外側の式の検査（開始の位置が先になりうる）を本物の診断に数えるかが、検査ごとに書かれていない（W7-02 U3 が R-473 で位置の順にする）。
  読み: (1) その式のクロックを与える規則が、失敗した条件そのものに頼るとき、その式は誤りのクロックで、それを使う外側の検査は出さない（誤りにする: 第 1 引数が E0813 の遅延の結果、効果を持つ fn の E0805 の呼び出し（§11.5 の表にクロックの規則が無い）、S-147 の非 `rt` の fn の E0815 の呼び出し（`init` で評価する規則が引数の条件に頼る）、`if~`・`match~`・枝の中の状態の E0200。変えない: `let` の E0810、E0416、`DefaultInit`、`e at k` の E0815 と `ClockPromotion`（結果は書いた `k`）、インスタンスの引数の E0815（結果は出力の宣言）、遅延の `init` の E0815）。
  (2) 誤りにするのは E0813 の遅延と、中を歩かない門だけで、E0805・非 `rt` の E0815 の呼び出しは引数の合流のクロックを持つ（`(noisy(x)) at block` は外の E0815、`slow2(c, slow(x))` は外の E0815）。
  (3) 誤りのクロックは読めた被演算子を下限に持ち、上限の検査は報告する（`(prev~(p) + x) at block` は外の E0815）。
  形の例（`x` は `sample`、`p` は `block`、`c` は `init`）: `(noisy(x)) at block` は (1) E0805、(2) E0815。`slow2(c, slow(x))` は (1) 内の E0815、(2) 外の E0815。`(prev~(p) + x) at block` は (1)(2) E0813、(3) E0815。どの読みでも通るプログラムは変わらない（誤りの flow で報告する一つだけが変わる）。
  仮の扱い: (1)（165 回目、利用者の離席中。親の案は (2) で、助言の担当の段 1 の独立の読み（`target/notes/165/advisor_u3/`）が (1) を推し、検査ごとに一つの原理で説明できるので親が (1) を採った。暫定）。W7-02 U3 が実装する。
  事例 `tests/spec/flow_clock/order_outer_before_inner.onsa`・`order_error_clock_not_used.onsa`・`order_nested_non_rt.onsa`。
  `NonRtCallAtClock` の E0200 は印の歩きが `let` の単位で読む（`Error` の `let` は印さない）。読む側の式ごとの判定（助言は `let y = x * design(c) + prev~(p)` でも `design(c)` の門を出すとした）は、W7-05 で門が消えるので入れない（親、5.10）。
- 決定（2026-11-18、利用者が了承、165 回目。利用者の基準「既決と整合性が取れている範囲で、管理がしやすくシンプルなもの」を親が当てた結果を、ID ごとに了承）: 読みの (1)。仮の扱いがそのまま決定である（W7-02 U3 の実装と事例のまま）。`^名前` の先の `let` が誤りの部分のときも同じで、読む側は診断を出さない（補い。R-496 を W7-09 で直す）。
  理由: §11.5 の表は効果を持つ fn の呼び出しにクロックの規則を持たず、§18.1 は読めなかった部分を使う側に診断を出さない。(1) はこの二つから、規則を足さずに一つの原理（式のクロックを与える規則が失敗した条件に頼るなら、その式は誤りのクロック）で説明できる。(2) は表に無い「呼び出しは引数の合流のクロックを持つ」を足す。
- 経緯: 165 回目、2026-11-18、W7-02 U3 の票の前に親が §18.1 から読みを決め、利用者の離席中に助言の担当（onsa-advisor）に親の案を伏せて独立に読ませた（段 1）。割れた F2・F5 の形で助言の線を採った。
- 補い（2026-11-18、親）: 165 回目（2026-11-18）、W7-02 U3 の壊す側: `^名前` の先の `let` が誤りの部分のときも、`^` で読む側は診断を出さない（助言の担当、確信は高。§11.3 は `^名前` も `let` のクロックを読むとし、§18.1 の線を `^` だけ外す字は無い）。今の実装は段 1 のクロックで読んで使う側に診断が出る（前から）ので R-496 に登録し、W7-09 で直す。
