# S-44

- 空白: `prev` / `delay` / `vdelay` は状態を作るのに点ごとの関数と同じ見た目で、閉路を切れることも字面に現れない
- 提案: `prev~(x)` などと書き、`prev(` は E0811（修正候補は `~` の挿入）。帰還の参照 `^名前`: 字句は名前の直前の前置 `^`（二項の `^` とは位置で分ける）、遅延の組込みの第 1 引数の中だけ。印の無い前方参照は E0801（修正候補は `^` の挿入）、遅延の外の `^` も E0801、定義済みの名前の `^` は E0020。
  fmt と LSP も対応する。`tests/`（spec / conformance / golden）と `examples/` の 13 ファイルを書き換える（2026-10-03 決定。実装は第 3 段、S-34 などの構文の変更と同じ回）
- 時期: M3
