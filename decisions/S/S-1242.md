# S-1242 細部: 組込みの遅延の `init` の引数を `init` の段のどこで評価するか（遅延を書いた位置か、全ての `init` の `let` の後か）

- 空白: 組込みの遅延の `init` の引数（`prev~(x, 100 / c)`、`c` は `init`）を、`init` の段のどこで評価するかが字に無い。違いは panic の順だけ。
  読み: (1) 遅延を書いた位置（S-1206 の (A1) の「式の評価の順」と同じ）。(2) 全ての `init` の `let` の後に、遅延の前順（今の実装。`let a = prev~(x, 100 / c)` の下の `let b = 200 / c` は、`b` が先に報告される見込み。走らせていない）。
  仮の扱い: (1)（§11.3 の「各式を、部分式も含めて…段で評価する」と S-1206 の案から決まる読み）。W7-11 U2b で入れる。W7 の区切りで確認だけ。
- 決定: 決定（2026-11-25、利用者。185 回目、第 119 組、確認だけ）: (1)（族の規則 S-1233）。組込みの遅延の `init` の引数は、`init` の段で、遅延を書いた位置で評価する（仕様の字は §11.3 の「巻き上げた部分式（遅延の `init` の引数も）」）。実装は W7-11 U2b。
- 経緯: 184 回目（2026-11-25）、W7-11 U2b の設計メモ（onsa-impl、NEW-1）が挙げ、独立の審査が (1) に同意し、親が細部として登録した。
