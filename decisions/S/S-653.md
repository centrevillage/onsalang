# S-653 export する名前の末尾の `_` が生成する C の名前に `__` を作る（flow `lp_` の `t_lp__init`。§14.2 は `prefix` の `__` を禁じるが、名前の側を書いていない）

- 空白: §14.2 は `prefix` に `__`（C++ では予約の名前）を禁じるが、export する flow と関数の名前の側を書いていない。名前の末尾が `_` の flow を出すと、生成する名前が `__` を含む（flow `lp_` の `t_lp__init`・`t_lp__reset`・`t_lp__params`。dev `fdc4fa5`、`P62/gap52f/probe/cflow/`。62 回目の scratchpad）。
  読みは、export する名前の末尾の `_` を誤りにする、C の名前で `_` を一つにまとめる、C++ の予約を受け入れる、に割れる。族「§2.3 の名前の形」（S-650）で末尾の `_` を受けるなら残る。
