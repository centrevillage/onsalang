# S-889 §7 の常に評価される部分式の位置の一覧に無い位置（`({ return 1 }).x`、`.0`、`for v in ({ return 1 }) {}`、`f(move ({ return 1 }))`）

- 空白: §7（S-291）は常に評価される部分式の位置を「演算の被演算子、呼び出しとメソッドの引数と受け手、構築子・リテラルの要素とフィールド、`if`・`while` の条件、`match` の対象、添字、`as` と `?` の左、範囲の端、代入の右辺、`return` と `assert` の式」と並べる。フィールドの基、タプルの添字の基、`for` の反復元、`move` の被演算子は並びに無い。
  読み: (1) 並びは例で、これらも外の式に E0503、(2) 閉じた一覧で、これらは今の E0420 か E0406 のまま。通るプログラムはどちらでも変わらず、コードだけが違う
- 決定: 決定（2026-11-04、利用者。113 回目、第 84 組。設計メモと独立のレビューの段 1・段 2 が一致。(A) の確認だけ。利用者「(A): OK」）: (1)。§7 の位置の並びは例で、規範は「外」の閉じた一覧（`&&`・`||` の右と腕のガード、無名関数の本体の中、初期化式の全体、`if` の枝とブロックの最後の式）にする。
  `({ return 1 }).x`、`.0`、`for v in ({ return 1 }) {}`、`f(move ({ return 1 }))`、関数値の呼び先も E0503。判定は括弧と `move` を透かす。文の見出しの位置はその文に出す。腕のガードは外で、`Some(x) if { return 1 } => x` は通る（段 1 は当てる読みで、段 2 で、E0503 を置く外の式が無いので外にした）。
  作業は W5-08。仕様 §7。
- 経緯: 113 回目（2026-11-04）、W5-08 の設計メモの担当（onsa-impl）が空白として報告した。中立の要約と段 1・段 2 は `target/notes/113/g84/`。
