# S-165

- 空白: export する flow の `pub`、`flows` / `fns` の種類の誤りと重複にコードが無い（点検 C-56）
- 提案: `pub` でなければ E0303、種類の誤りは E0308、重複は E1103（`span` は `onsa.toml`）（2026-10-06 決定。実装は export の計画の段）
  改め（2026-10-24、S-639）: `flows` / `fns` を外したので、種類の誤り（E0308）と重複（E1103）は当たらない。`pub` でない `@export` の項目は E0303 で、`onsa check` が宣言の位置で出す（`span` は宣言）。
