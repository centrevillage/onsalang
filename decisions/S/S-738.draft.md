# S-738 本体の型の位置と効果行（`uses {n}`）に、見えているローカルや引数を書いたとき、S-729 と同じく E0308 か、効果行はローカルを見ず E0302 か

- 決定済みで戻さないもの: 効果行の型・関数・型パラメータは E0308（S-713 (b)）。見つからない名前は E0302 で、`use` の無い標準の効果には候補（§8.1）。
  第 69 組の下書きの「族「§15.1 の型の位置から見える値の束縛」の仕組みの出所」と「族の形の表」の節（写しは `target/notes/79/g69/draft.md`）。
- 論点: §8.1 は「効果行の名前は、他の名前と同じく解決する（§15.1）」とし、S-729 は本体の型の位置がローカルを引くと決めたが、効果行は S-729 の決定の文に挙がっていない。
  効果行の名前も見えているローカルを引いて E0308 か、効果行はローカルを見ず E0302 かが書かれていない。署名の効果行の引数は S-733 と同じ問いである。
- 今の実装: 表の S-738 の行は全て E0302（`probe/s738.out`）。同じ本体の注釈の `fn(a) -> I32` の `a` は E0308、無名関数の `-> x` は E0308 で、同じ見出しの `uses {x}` は E0302 である。
  `uses {helper}`（関数）は E0308「`helper` is a function, not an effect」。
- 案: 
  - (1) 効果行も型の位置と同じ範囲の束縛を引き、ローカルと引数は E0308（「`n` is a local, not an effect」）。本体の効果行は S-741 の (a)〜(c) のどれでもこの形で、署名と無名関数の自分の引数は (b)・(c) で E0308、(a) で E0302。
  - (2) 効果行はローカルを見ず、全て E0302（今の実装）。S-741 の (a)〜(c) のどれを採っても、効果行だけを外す例外の一文が要る。
  - 書き手から見て: `uses {n}` を書く場面は少ない。小文字の名前は効果行変数の形なので、宣言し忘れた効果行変数のつもりもありうるが、引数と同じ名前の効果行変数は E0304 で作れない。
    (1) は「`n` は引数で効果でない」と一回目で示す。(2) は「見つからない」と言い、`[n]` を足す直しは E0304 になる。
  - 修正候補: どちらも無い。
  - 実装の量: (1) は S-741 の共通の分（`heads` と `read_effects`、約 +11〜17 行）と、無名関数の効果行（約 +5 行か、名前の段へ移して約 +15〜25 行）。(2) は 0 行で、§8.1 に例外の一文。
- 他言語: 効果行に当たるものを持つ言語は 7.32 の一覧に無い（Rust・Swift の `throws`・`async` は名前を取らない）。調べていない。
- 推奨と理由: S-741 の規則から (1)。確度: 中〜高。
  - 効果行は §8.1 で「他の名前と同じく解決する」とされ、同じ関数型の引数の型は既にローカルを見る。(2) は一つの関数型の中で引きが二つになる例外を足す。差は名前の段の約 +11〜17 行（無名関数の分を除く）である。
  - あわせて決めること: 無名関数の効果行の読みは、ローカルの名前を型付けに渡すだけにするか、名前の段の歩き手へ移すか（移すと下の「別の問題」の順の誤りも直る。名前を一度だけ解決する段の原則にも合う）。
- 影響: 仕様 §8.1（効果行も型の位置と同じ範囲で引く一句。(2) は例外の一文）、`tasks/diag-codes.md` の E0308 の行。
  作業は S-741 と同じ単位（期限は無いが同時に入れると費用がほとんど変わらない）。事例 `tests/spec/effects/kind_effect_row.onsa` に本体・無名関数・署名の `uses {n}` を足す（(1) は E0308、(2) は E0302）。今の期待で変わるものは見つけていない。
