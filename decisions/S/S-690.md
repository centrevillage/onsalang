# S-690 本体の型の位置（`let o: Gone`）に書いた失敗した名前・E0304 の名前は、以後の本体の検査を止めるか（S-260 の切れた def のメンバの型を含む）

- 空白: §18.1 の同じ二つの文（読めなかった部分は誤りの型、単位は最初の誤りで止める）について、本体の型の位置（`let o: Gone = 1`）に書いた失敗した名前か E0304 の名前のとき、以後の本体を検査するかを書いていない。
  読みは (1) 型だけ誤りの型にして検査を続ける、(2) 単位を止める（値の位置の黙らせ方と同じ）、に割れる。
  W4-03 U3b1 の実装（67 回目、`body.rs::lower_type_expr` の `holds_error`）は (2)。`let o: Gone = 1  let a: I32 = true` の E0401 は出ない（前にあれば出る）。
  S-260 の切れた def のメンバの型（`let x: E.Zed = 1` の後）は、U3b1 の前は検査を続けて E0401 を出していた（`target/notes/67/w403/u3b1/b/c2.txt` の `s260_type_member`、`c15.txt` の `local_type_before_after`）。
- 決定: 決定（2026-10-25、利用者。68 回目、第 61 組、ID を挙げて確認だけで了承（A2））: (1)。族の規則 S-692 から。本体の型の注釈、配列長、クロージャの引数、test の本体の型、切れた def のメンバの型の後も、本体の以後を検査する。注釈の型が局所にも式にも残らない形（`let _: Gone = g()`）でも、その def は fix-contract の一覧（`unread_users`）に入れる（道具の層）。
- 経緯: 67 回目（2026-10-25）、W4-03 U3b1 の壊す側（onsa-break）が中の指摘として挙げた。急ぎは後の段。関係: S-689、S-260、S-462、S-675。
