# S-98

- 空白: 組込みのメソッドの一覧が仕様で閉じていない。整数の `abs` / `min` / `max`、`as` と二重の変換メソッド（`F32` の `round_f64()` など）、列の `is_empty` が通り、§3.4 が触れる `checked_rem` は無い。`is_nan` を外した後の代わりが無い（レビュー R-126）
- 提案: 組込みのメソッドを §3.3 の表と §3.4 の一覧に合わせる: 整数の `abs` / `min` / `max` と浮動小数のメソッドの形（A-04）を外して E0413（修正候補は `std.math` の関数の形と `use` の追加）。変換メソッドは `as` で書けない組にだけ置き、書ける組では E0413（修正候補は `as`）。
  E0411 の修正候補を読みごとに（浮動小数から整数は `trunc_<型>_sat()` と `trunc_<型>()`、整数の縮小は候補なしで note）。`Str` と列の `is_empty` を外して E0413（修正候補は `len() == 0`）。`checked_rem` `checked_neg`（符号付き） `checked_shl` `checked_shr` `checked_div_euclid` `checked_rem_euclid` を足す。`std.math` に `is_nan` / `is_finite` を宣言する（Onsa で書けるなら本体ごと std に、D-07）。`tests/review-phase1/parent/r126.onsa` の期待値と今の出力は各項目の上のコメント（2026-10-05 決定。実装は第 3 段。std の宣言への移行は R-79 の第 4 段）。
  std の `fmod` 関数は浮動小数の `%` と同じ計算なので外す（仕様 §3.4、点検 C-87）
