# S-685 自分のモジュールと他の名前を並べた `use`（`d/b.onsa` の `use d.{b, e}`）で、他の要素を取り込むか（`use` 全体が失敗か、自分の要素だけが失敗か）

- 空白: S-679 は、モジュールが自分自身を取り込む `use` を E0302 とする。§18.1 は失敗した `use` の名前を「経路が失敗すれば並びの全ての名前、要素が失敗すればその名前」とする。自分のモジュールと他の名前を並べた `use`（`d/b.onsa` の `use d.{b, e}`）で、他の要素（`e`）を取り込むかを書いていない。
  読みは (1) `use` 全体が失敗（他の要素も束縛と辺を作らない）、(2) 自分の要素だけが失敗し、他の要素は取り込む（束縛と辺が残る）、に割れる。
  今（`c77f3f3`）は (2) に近い: `g1` は E0302 だけ。`g2`（`d/e.onsa` が `use d.b`）は E0310（`d.b`・`d.e`）だけで、同じ `use` の E0302 は単位ごとに一つの規則で出ない。`g3`（`use d.e.{f, a}` と自分の項目 `f`）は E0304 だけ（`target/notes/67/w403/u3a2/t2/g1`〜`g3`）。
  W4-03 U3a2/t2 の `use_model.rs` は、自分を取り込む形を枝の無いモジュールの単独の要素に限る（`SPEC-GAP(S-685)`）。
  親の案（確認だけ、67 回目）: (2)。§18.1 の「要素が失敗すればその名前」（S-462）から、自分の要素（S-679 の E0302）だけが失敗し、他の要素は取り込む。今の実装と同じ。
- 決定: 決定（2026-10-25、利用者。67 回目、第 60 組、ID を挙げて確認だけで了承（A4））: (2)。§18.1 の「要素が失敗すればその名前」（S-462）から、自分の要素（S-679 の E0302）だけが失敗し、他の要素は取り込む。今の実装と同じ。
- 経緯: 67 回目（2026-10-25）、W4-03 U3a2/t2（onsa-test）が NEW-2 として挙げた。急ぎは U3b1 の前（失敗した名前の集合と S-678 の辺に関わる）。関係: S-679、S-462、S-678、S-675。
