# S-568 std の変換の flow: 名前、フィルタの係数と演算の順

- 空白: S-566 と S-567（第 34 組）で、レートの変換は変換の flow（入出力の宣言に `at (sample * N)`・`at (sample / N)` を書き、速い側を配列 `[T; N]` で受ける flow）で書き、組込みの変換は持たないと決めた（§19.1 のマルチレート）。std が持つ変換の flow を決める。
  1. 一覧と名前（補間の上げ `up2`、間引きの下げ `down2`、保持 `hold2`、間引きだけの `dec2` など。比ごとに別の flow か、比を引数に取る形か）。
  2. フィルタの係数と演算の順。§13.4 のビット一致の対象になるので、係数と演算の順を仕様か std に固定する。
  3. 型ごとの扱い（flow は型引数を持たないので、std の型の分を std が持つか、総称の flow を待つか。S-563 の新しい S の候補）。
- 決定: 決定（2026-10-22、利用者が ID を挙げて了承。51 回目）: 第 1 期の std は 2 倍のオーバーサンプリングの `fir_up2`・`fir_down2`（`std.dsp`。線形位相のハーフバンドの FIR、型は `F32` だけ）を置き、4 倍以上は入れ子で書く。名前は方式・`up` / `down`・比の順で、番号は方式の名前の後ろ（`fir2_up2`）。
  IIR の版（`iir_up2`・`iir_down2`）は要ると分かったときに足す。係数は std の本体に 10 進のリテラルで書き（§2.4 の丸めで値は一つに決まり、生成する C は 16 進で出す）、和は書いた順。仕様には形（タップの数、遅れ）を書き、値は M5 で決める。制御のレートの変換は S-577。仕様 §19.1
- 経緯: S-566 の確認だけの項目 A14 の 2（2026-10-20、48 回目、利用者が了承: 新しい S にする）と、S-567 の決まった形の A-13（2026-10-21、50 回目）から立てた。第 35 組（std の型）と一緒に決められる。関係: S-566、S-567、S-563、§19.1 のマルチレート。
