# S-214 fmt と `diff --ast` を止める条件

- 空白: fmt と `diff --ast` を止める条件。§18.2 と S-120 は「構文の診断（字句解析と構文解析が出す E00xx）」とするが、構文解析器は E00xx でない診断（タプルの添字の溢れの E0408、W3-04 の予約語の E0200）でも項目を失敗させる。字面どおりだと fmt が止まらず、失敗した項目をファイルから消す（R-146）。W3-02 の設計メモで見つけた（2026-10-08）
- 提案: (a) と (i)。止める条件は構文の段の診断（コードによらない）で、報告は `check` と同じ選び方。§18.1 の選び方も改め、構文の誤りがある単位では見出しの命名の誤り E0320 も報告しない（Fable の指摘。利用者: どのみち `check` は直すので fmt と同じ回に）。
  大きすぎる整数リテラルとタプルの添字の E0408 を構文の段で出すことを §2.4 に書いた（仕様 §2.4、§18.1、§18.2。2026-10-08 決定。実装は W3-03（`SPEC-GAP(S-214)` を外す）。診断の出し先は S-232）
