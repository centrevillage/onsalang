# S-429

- 空白: 文の位置の、`--`・`++` の前に空白がある増減（`x --`、`x ++`）。増減の行（`spec/foreign-forms.toml` の `increment`）の例は `x--` だけで、§2.5 は被演算子と `--` の間の空白を決めない。今は `x--` が E0020（候補 `x = x - 1`）、`x --` が E0002（候補なし）。RF/t が見つけた（2026-10-10。親が報告の再現を読んだ）
- 提案: 後の段（次の空白の組）
- 時期: W3
- 決定: 決定（2026-11-09、利用者。127 回目）: S-961 の族の規則から。文の位置の空白のある後置の増減（`x --`、`x ++`、タブ、後ろの行コメント、`}` の前）は増減の E0020 で、候補は `x = x - 1`。前置の `-- x` と、行末の `--` と次の行の被演算子（`--` 改行 `x`）も同じ。
  行頭の `--` は前の行に続かず、`x` の行と `--` だけの行は今の E0002 のまま。式の位置（`let y = x --`、`two(x --, 1)`）は今の E0002 のまま。`x --` 改行 `y = 0` は次の行を触らない。§2.5 に書いた。
