# S-929 `?Escape` の `T` の値を `?Escape` の無い型パラメータへ渡す形のコード

- 空白: `fn probe[U](x: U)` に `T: ?Escape` の値 `x` を渡す `probe(x)`（`Some(x)`、`Slot { v: x }` も）のコードを書いていない。読み (1) 第二級かもしれない型が `?Escape` の無い型パラメータを具体化するので、§4.5 の推論した型引数の E0710。読み (2) 暗黙の `Escape` の要求の E0416。
- 決定: (1)。`T: ?Escape` の値を `?Escape` の無い型パラメータへ渡す形（`probe(x)`、`Some(x)`、`Slot { v: x }`）は、§4.5 の推論した型引数の E0710 である。`?Escape` の型パラメータへ渡す形は通る。`[T; N]` の `get`・`slice`・`fill!`・`copy_from!` も同じ E0710 で（`Option[Span]` が外へ出る穴を塞ぐ）、`?Escape` の本体で通るのは `?Dup + ?Escape` の `impl` の `len` である。
  推論した型引数の E0710 の note に「型パラメータに `?Escape` を付ける」を足す（既にある出力の note が増える。候補は変わらない）。仕様 §4.5（2026-11-06 決定）。

  119 回目（2026-11-06）、利用者の求めで独立のレビューに回した（中立の要約 22 形、助言の担当の段 1、`target/notes/119/s927-advisor/`）。段 1 は三つとも親の読みと同じ案を確度「高」で選び、親が根拠を抜き取りで再現したので段 2 を省いた。段 1 の想定漏れの表から、`[T; N]` のメソッドの E0710、生成型の E0710、note の字を足した。利用者が ID を挙げて了承した。
