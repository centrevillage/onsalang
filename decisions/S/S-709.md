# S-709 型の段で無いと分かった `process_inplace` を取り込む `use` と、同じ名前を取り込む別の `use` の E0304（§15.1 の「失敗した `use` の名前は数えない」が型の段の E0302 の後の名前も指すか）

- 空白: §15.1 は「名前の段で失敗した `use` の名前は数えない」（S-462）とする。
  型の段で無いと分かった `process_inplace` を取り込む `use`（S-694）と、同じ名前を取り込む別の `use`（`use a.src.{process_inplace}` と `use a.gain.{process_inplace}` を同じモジュールに書く）の E0304 を、この規則が型の段の E0302 の後の名前にも当てるかが明記されていない。
  今の実装は数えない（E0304 を出さない）。
- 決定:
- 経緯: 71 回目（2026-10-26）、W4-03 U5a/t（onsa-test）が見つけた。事例は別のモジュールに分けて避けた。関係: S-694、S-462、S-675。
- 補い（2026-10-26、親）: 72 回目の文書の点検の指摘: §18.1 の「型の段で無いと分かれば、その `use` に E0302 を出し、以後その名前を失敗した名前として扱う」も関係する。本当の空白は、名前の段の E0304 の相手の名前が後の型の段で無いと分かったとき、その E0304 を出さないか（段の順）に絞れる。
