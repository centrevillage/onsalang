# S-94

- 空白: 借用の配列を `Span` に渡すと `const` が外れ、clang の `-Werror` で失敗する。ホストが用意した `uint8_t` の配列を状態に使うのが、実効型の規則に反する（レビュー R-109）
- 提案: C の `Span` の型を借用（`const T*`）と `inout`（`T*`）に分け、`SpanOf` は引数のモードで選ぶ。
  内部の状態の型と bulk 領域の要素の読み書きに `ONSA_MAY_ALIAS`（GCC / Clang で `__attribute__((__may_alias__))`、それ以外は空。S-95 の規則で内部の名前は `ONSA__` で始めるので、`ONSA__MAY_ALIAS` とする）を付ける。
  テストの基盤（R-113）で、生成した C を GCC と Clang の `-Wall -Wextra -Werror` でコンパイルする。`tests/review-phase1/parent/r109/` の期待値と今の出力は `m.onsa` の先頭のコメント（2026-10-05 決定。実装は第 3 段）
