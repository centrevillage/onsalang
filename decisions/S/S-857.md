# S-857 同じ文の中で、型が演算子の位置で決まっている演算子の E0401 と、後回しにした演算子の E0401（と同じ文の別の型の誤り）の報告の順

- 空白: §4.7 の 202〜203 行（演算子の trait は型変数が無くなった文で検査する。後回しにした検査は文の検査の後なので、同じ文の中の別の型の誤りが先に報告される。同じ時点で複数なら項目を作った順）は、被演算子の型が演算子の位置で既に決まっている演算子の判定を、その場で行うか、文の検査の後に回すかを書いていない。
  W5-01 U1 の実装は、型変数の無い被演算子をその場で判定し（前からの挙動）、型変数の残る被演算子だけを文の後に回す。そのため `let v = make()` の後の `let _: (Bool, Bool) = (v + v, false + false)` は `false + false` の E0401 が先になる（文の後に揃えれば `v + v`）。
  また、`let _: (Bool, Bool) = (true + true, 3)` は演算子の E0401 が `3` の型の不一致より先だが、型パラメータの要求（`need(true)`）は不一致が先で、同じ文の別の型の誤りとの順が演算子と要求で違う。
  読み: (1) 演算子の trait は被演算子の型によらず全て文の検査の後に判定し、項目を作った順で報告する。(2) 型が決まっている演算子はその場で判定し、後回しの項目だけを文の後に判定する（今の実装）。どちらでも通るプログラムは変わらず、一つの文に二つ以上の誤りがあるときに最初に報告する誤りだけが変わる。
  再現は `target/notes/105/w501b/g10.txt`（`op_open_then_same_stmt_op_known`）。急ぎ: 後の段（W5 の終わりの前）
