# S-504

- 空白: `_` が数字と数字の間に無い綴り（`1_.5`、`1_e3`、`1e_3`、`1e+_3`）と、`_` の混じった整数部の余分な 0（`01_0.5`、`0_1.5`）の fmt の正規形。§2.4 は `_` を値に影響しないとし、`spec/tools.md` §3.2 は「`_` は数字と数字の間に一つずつ」「浮動小数の整数部の余分な 0 は外す」とする。今の fmt は変えない。W3-11/t（U1）が見つけた（2026-10-13）
- 提案: 決定（2026-10-13、利用者が ID を挙げて了承。親の確認だけの読み）: 正規形は数字の並びから作り、`_` は出力に残る二つの数字の間にあったものだけを一つ残す（`1_.5` は `1.5`、`1_e3` と `1e_3` と `1e+_3` は `1e3`、`01_0.5` は `1_0.5`、`0_1.5` は `1.5`）。§3.2 の `1_` は `1`、`0x_1F` は `0x1F` と同じ読み。実装は W3-11 の U1
- 時期: W3
