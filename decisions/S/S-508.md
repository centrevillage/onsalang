# S-508

- 空白: タプルの添字の綴り（`t.01`、`t.00`）。§2.4 と `spec/tools.md` §3.2 の閉じた一覧は添字の書き換えを書かないが、今の fmt は `t.01` を `t.1` に書き換え、`diff --ast` は `t.00` と `t.0` を同じとする。U3 で印字器をトークンの歩きにすると、決めない限り綴りのまま残る。W3-11/b（U1）が見つけた（2026-10-13）
- 提案: 決定（2026-10-13、利用者が ID を挙げて親の改めた案を了承）: `t.01` は E0020 で、修正候補は頭の 0 を外した `t.1`（一つ）。
  親は初め fmt が揃える案を出したが、添字は数値リテラルの文法で読まず（`t.0x1`・`t.1_` は E0002）、整数の `017` は E0020（S-62）なので、揃える方が一貫しないと確かめて改めた（Rust 1.94 はフィールド名としてエラー、Swift 6.3 は 1 と読む）。仕様 §2.4。実装は W3-13
- 時期: W3
