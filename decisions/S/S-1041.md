# S-1041 細部: 期待する関数型の無い無名関数の E0601（本体の最初の使用）に修正候補を出すか、行の決まり方を示す note と、`rt` の関数の中でそれを呼ぶ E0901 の note

- 空白: S-1032 で期待する関数型の無い無名関数を空の行（名前付きの関数の省略と同じ）とする読み（第 99 組の (a)）を採ると、本体で `Alloc` を使う無名関数に E0601 が出る（位置は本体の最初の使用、S-82）。
  (1) 修正候補 ` uses {Alloc}`（返り値の型の後、本体の前）を出すか。当てると無名関数の型が変わり、同じ単位に型の段の E0401（`ap(l)`）か外の E0601（`l.(1)`）を作りうる。返り値の型が関数型で終わる形では挿入が返り値の型に付く（R-455 と同じ）。
  読み: 出さず note で書き方を示す（段 1 の推奨）／当てた後に検査し直して誤りが残らないときだけ出す（型・modes・効果を回し直す新しい経路が要る）／外の関数にも同時に足す（入れ子と `rt` と純粋な位置で成り立たない）。
  (2) note: 行の出所（書いた、期待する型、どちらも無い）と、期待型のある無名関数で行が決まった所（`var l = cp` の後の `l = ca` は最初の `var` を直す）。
  (3) `rt` の関数の中で期待型の無い無名関数を呼ぶ E0901 に、`rt fn` の型を期待する位置に置く書き方（`let l: rt fn(U32) -> U32 = fn(y) { y }`）か、捕捉する無名関数なら補助の `rt fn` へ渡す形を示す note。
  仮の扱い: W6-03 の実装の担当が出す形（候補は出さない、文面は約束でない、§18.1）。S-1032 が (a) でなければ (1) は外の関数の候補の話になる。
- 決定: 決定（2026-11-15、利用者。152 回目、W6 の区切りの確認だけ。「上記はすべて OK」で了承）: 仮の扱いのとおり。期待する関数型の無い無名関数の E0601 は候補を出さず、行の決まり方を note で示す（W6-03 U6b）。`rt` の関数の中でそれを呼ぶ E0901 にも note を付ける。§8.1 は既に「修正候補は無く、note で効果行の決まり方を示す」と書く。コードの `SPEC-GAP(S-1041)` の印は W6-04 で外す。
- 経緯: 146 回目（2026-11-13）、第 99 組（S-1032）の下書き（onsa-gap）が新しい S の候補として (1) を、独立のレビューの段 1（onsa-advisor）が (2)・(3) を細部として挙げた。材料は `target/notes/146/g99/`。関係: S-1032、R-455、S-82、S-1033
