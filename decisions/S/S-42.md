# S-42

- 空白: 借用の `match x` のガードと腕の中で対象を変更でき、振り分けが変わり（R-110）、Copy でない束縛が破棄済みの記憶域を指す（R-118）
- 提案: ガードの中の対象の変更は E0715。腕の本体での変更は、重なる Copy でない束縛を move と同じく無効にし、以後の使用を E0704 にする（moves の流れ解析に載せる。重なりは E0702 と同じ判定）。Copy の束縛は束縛の時点の複製のまま。`match` の腕の束縛も借用の起点にし、派生した束縛も対象の変更で一緒に無効にする（2026-10-03 決定。実装は第 3 段、R-85 の所有の状態の後）
- 時期: M3
- 補い（2026-10-30、親）: 腕の中の変更の E0704 の部分（R-118）を W4-07（U3）に移した。利用者が了承した（86 回目、W4-07 の設計メモの審査の A1）。ガードの中の変更の E0715（R-110）は W4-10。
- 補い（2026-10-31、親）: ガードの E0715 の重なりの判定と当たらない形は借用の `for` と同じ（§5.4）と §7 の 51 行に一文を足した。S-796・S-798（W4-10 も解決した場所で）と S-808 の理由（§5.2）から決まる反映の漏れ（W4-10 の設計メモの NEW-1、助言の担当の審査、92 回目に利用者が了承）。対象が Copy の値でも E0715（W4-10 の A1）。
