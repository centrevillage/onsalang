# S-756 総称の `impl` の対象が、型の宣言の型パラメータの境界を満たさない形（`struct N[T: Num]` の後の `impl[T] N[T]`）: 見出しの E0416 にするか、`impl` の型パラメータが型の宣言の境界を受け継ぐか

- 空白: §6.2 は、総称の `impl` の対象の型引数を `impl` の型パラメータを一度ずつ並べたものに限る（E0307）。§4.5 は型の宣言の型パラメータに境界を書け（`struct N[T: Num]`）、R-37 の決定は署名の型の整形性を位置と型構成子の組で判定し、型引数が境界を満たさない `N[Bool]` を誤りにする（E0416）。§18.1 は `impl` の見出しを型の位置に数える。
  `struct N[T: Num]` の後の `impl[T] N[T]`（`impl` の `T` に `Num` が無い）で、見出しが誤りか、`impl` の `T` が型の宣言の境界を受け継ぐかは書いていない。
  今: 見出しに何も出ず、`impl` の `T` は `Num` を持たない。メンバの `self.a + self.a` に E0401「`+` is not defined for `T` (it needs `Num`; §3.2)」が出て、`self.a` を返すだけのメンバは通る。
  読み: (a) 見出しの E0416（境界は `impl[T: Num]` と書く）。見出しの誤りなので `impl` の全体が一つの単位になる。今通る `impl[T] N[T] { pub fn get(self) -> T { self.a } }` が誤りになる。
  (b) 受け継ぐ（型の宣言の境界が `impl` の `T` に含まれる）。今の E0401 が消え、メンバで `+` が使える。(c) 今のまま（見出しを誤りにせず、受け継がない）。
  再現は `target/notes/81/u4/new3.onsa`。
