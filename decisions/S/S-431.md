# S-431 効果の操作、handler のメンバ、extern の関数に付けた doc

- 空白: 効果の操作、handler のメンバ、extern の関数に付けた doc（`effect E {` 改行 `/// op` 改行 `fn op() -> I32` 改行 `}`）。
  §2.1 の付く先の一覧は「`impl` / `trait` のメンバ（関連定数を含む）」を挙げ、`effect`・`handler`・`extern` のメンバを挙げない（項目の並びには「など」があるが、メンバの並びには無い）。読みは (1) 一覧のとおり E0004、(2) 宣言なので付く、に割れる。今は付く（効果の定義は全体が E0200）。
  W3-04/i の設計メモで見つけた（2026-10-11） 直し（2026-10-13、第 25 組の下書き）: 「今は付く」は W3-04 の前の挙動で、今は W3-04 の仮の扱いで E0004（候補 `//`）。インライン形式の handler のメンバだけは E0004 にならない（`docs.rs` の `documents` が `HandleExpr` を見ない）。
- 提案: 決定（2026-10-13、利用者が ID を挙げて推奨の (b) を了承し、細部も Fable の案を了承。下書きと Fable が一致、第 25 組）: 付く。
  §2.1 の付く先を「`use` と `test` 以外の項目（`fn`、`flow`、`struct`、`enum`、`trait`、`effect`、`handler`、`extern`、`target` の宣言、`const`、`type`、`impl`）、`impl` / `trait` / `effect` / `handler` / `extern` のメンバ（関連定数、効果の操作、extern の関数と不透明型を含む。インライン形式の handler のメンバも同じ）、struct のフィールド、enum の列挙子、flow の入力」の閉じた一覧にする（§18.1 の単位の並びとそろえる）。
  仕様 §2.1。実装は W3-24（W3-08 から分けた。`docs.rs` の付く先の述語を構文解析器と `foreign/comments.rs` が読む）
