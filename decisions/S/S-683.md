# S-683 E0310 の狭め方の note を付ける条件（狭めた形が書けない取り込み: `use b` の `b` がファイルの無いディレクトリで、本体は `b.c.s()`）

- 空白: §15.1（S-594）は「この数え方で循環になるときは、取り込む経路を狭めて直し、E0310 の note で狭め方を示す」とする。どの狭め方を数えるかを書いていない。
  U3a2 の直し（67 回目、親の読み）は、成分の中のモジュールを取り込む `use` を全て同じモジュールの項目の取り込み（`At`）に狭めると成分が切れるときだけ狭め方の note を付け、切れなければ「狭めても切れない」の rule にした。
  その判定では、取り込む相手がファイルの無いディレクトリだけのモジュール（S-666。項目が無い）でも `At` に狭めたとみなすので、`a.onsa` の `use b` と本体の `b.c.s()`、`b/c.onsa` の `use a.{f}` に note「`use b.{…}` に狭めよ」が付く。勧めに従って `use b.c` か `use b.c.{s}` にしても循環は残る（`target/notes/67/w403/u3a2/b2/t/n4.txt` の r1〜r3）。
  読みは (1) 今の判定、(2) 項目の無いモジュールへの `At` は書けないので数えない（狭めの外に置く）、(3) 子孫のモジュールへの狭め方（`use b` から `use b.c`）も数える、に割れる。(3) は本体の経路を見ないと決まらない（S-594 の数え方は本体を見ない。正確な検査は第 2 期）。
  親の案（確認だけ）: (2)。note は書ける狭め方で切れるときだけにし、rule の文は「狭めた後も」と補う。実装は `check_cycles` の狭めたグラフで、項目の無いモジュールへの `Below` を狭めない形（約 +5 行）。仮の扱いは (1)。
- 決定: 決定（2026-10-25、利用者。67 回目、第 59 組、ID を挙げて確認だけで了承（A11）。利用者は「ひとまず親の推奨で進めて良い」）: (2)。E0310 の狭め方の note は、成分の中のモジュールを取り込む `use` を書ける形に狭めて切れるときだけ付ける。項目の無いモジュール（自分のファイルが無く、ディレクトリだけで在るモジュール、S-666）への項目の取り込みは書けないので数えない。切れないときの rule は「狭めた後も」と補う。
  本体の経路が子孫のモジュールを使う形は見分けない（S-594 の数え方は本体を見ない。正確な検査は第 2 期）。仕様は §15.1 の E0310 の note の文に一文。実装は W4-03 の U3b（約 +5 行）。
- 経緯: 67 回目（2026-10-25）、W4-03 U3a2 の壊す側の再確認（onsa-break）が見つけた。関係: S-594、S-666、R-39。
