# S-1264 検査付きの添字の代入先に集成体を直接構築する形（`ps[i] = mk(k)`）で、右辺の panic と添字の検査のどちらが先か（§3.5 の「右辺を先に評価し、その後に代入先の場所」と、§12.7 の代入先への直接構築がぶつかる）

- 空白: §3.5 は「代入は右辺を先に評価し、その後に代入先の場所（添字の式）を評価する」「この順で最初に panic する式が報告される」とし、§12.7 は集成体を返す式を置き場所（代入先を含む）に直接構築するとする。添字の検査の前には代入先の番地が決まらないので、検査付きの添字の代入先 `ps[i] = mk(k)`（`mk` が集成体を返す）では、(1) §3.5 のとおり右辺を先に評価し、一時に作って写す（§12.7 の直接構築の外）か、(2) 直接構築を保ち、添字の検査を右辺より先にする（§3.5 の例外）かが割れる。
  今: 解釈器は右辺が先（`i = 5`、右辺が 0 で割る入力で `division by zero`）。C は `emit/fns.rs` の `assign_into` と `index_access` で `mk(&ps.a[onsa_idx(…)], k)` となり添字が先の見込み（走らせていない）。大きな状態（`self.voices[i] = voice.init(…)`）では、(1) はスタックの一時と写しが増える。再現の入力 `target/notes/191/w801/p1review/probe/p3b.onsa`。
