# S-1018 細部: 定数式の文法の外の形の中で宣言した名前の命名規則の誤り（`[F32; (fn(Aa: U32) { 1 })]` の E0320）と、形の E0417 のどちらを出すか

- 空白: S-989 の改め（(3)）で、§4.5 は「名前の段は定数式の文法の中だけを読み、文法の外の形の中…は読まない。そのため、中の名前の誤り（E0302・E0308）…より、形の E0417 が先」とする。命名規則の E0320（§2.3）は挙げていない。今は前後とも、`pub fn f(a: [F32; (fn(Aa: U32) { 1 })]) -> U32 { 1 }` が E0320 だけ（1:23）で、形の中の同じ名前の E0304 が消えた形（`fn(A: U32)`）も E0320 が出る。読みは (1) 命名規則は名前の綴りの規則で、歩きによらずどこでも当たる（E0320 が先。今の挙動） (2) 文法の外の形の中は名前の段が見ないので E0417 が先。どちらも誤りとして拒む（通るプログラムは変わらない）。仮の扱いは (1)（コードを変えない）。再現は `target/notes/141/w513u2b/n1.txt` の `naming_sig`。
