# S-730 二つ以上の型別名の循環（`type C = D`、`type D = C`）の E0311 を、循環ごとに一つ報告するか、循環の中の別名ごとに報告するか

- 空白: §4.4 は「型別名の循環 `type A = B`、`type B = A` も同じ（E0311）」とするが、二つ以上の別名の循環で E0311 を循環ごとに一つ報告するか、循環の中の別名（それぞれ診断の単位）ごとに報告するかを書いていない。
  読みは二つに割れる。(1) 循環ごとに一つ（どの宣言に付けるかも決める）。(2) 循環の中の別名ごとに一つ（どの単位にも誤りがある）。
  今の実装（`P78/bin/onsa-u7b2`）: `type C = D`・`type D = C` は二つの宣言のそれぞれに E0310「type alias refers to itself」（コードは W4-05 の R-182 で E0311 に揃える）。自分を指す `type Lp = Lp` は一つ。
  再現は 78 回目の scratchpad の `w404/u8a/parent/local_ty.onsa` の 12・13 行。

- 経緯: 78 回目（2026-10-28）、W4-04 U8a/t（onsa-test）が空白として報告し、親が再現した。事例 `tests/spec/module/kind_alias_cycle.onsa` は自分を指す別名だけを書いた。期限は別名の閉路の E0311 を入れる W4-05 の前。関係: R-182、S-91。
