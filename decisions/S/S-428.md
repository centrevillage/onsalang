# S-428

- 空白: 範囲のパターンの端が、別の既存言語の形を含むとき（`1..<3u8 =>`、`1..<+3`、`1..<--3`、`1..<3 /* c */`）。§7 は「端が式として読めないときは E0002」、§18.1 は約束を満たす候補を作れなければ出さないとする。今は範囲の始点から端の終わりまでの E0002（候補なし）。
  範囲のパターンの E0020（候補は端を写したガード、端の誤りは次の検査）にするか。(1) なら当てた後に残る誤りの位置が束縛の名前の長さに依る（S-253）。RF/t が見つけた（2026-10-10）
- 提案: 後の段（次の空白の組）
- 時期: W3
