# S-933 対象と型の違う定数のパターン

- 空白: パターンの定数の型が対象の型と違う形（`x: U8` の `match` の `LIMIT`、`LIMIT: I32`）。今は定数のパターン全体が E0302。読み (1) E0401（`x == LIMIT` の式と同じ）。読み (2) ガードの形の候補を持つ E0020。候補 `v if v == LIMIT` を当てても同じ段の E0401 が残る。
- 決定: (1)。定数の型が対象の型と違うパターンは E0401（`x == LIMIT` の式と同じ）で、候補なし。仕様 §7（2026-11-06 決定）。
- 経緯: 119 回目（2026-11-06）、W5-09 の設計メモ（onsa-impl）と独立の審査（onsa-advisor）が挙げ、親が固定のバイナリ `1bbe4eb` で確かめて登録した。控えは `target/notes/119/w509_memo/`。
  119 回目（2026-11-06）、親と独立の審査の読みが一致し、利用者が ID を挙げて了承した（確認だけ）。
- 補い（2026-11-06、親）: 書けない型の定数が対象の型とも違う形（`const LIMIT: F32` と `x: I32`）も E0401 である（§7 の文のとおり。候補を当てても E0401 が残るので E0020 にしない）。W5-09 のテストの担当の報告、119 回目。
