# S-424

- 空白: S-414 の「`else` の後の `if`（`if~` を含む）も `else` と同じ行に書く」（§2.5）の「`if~` を含む」の読み。`else if~` は §2.6 で E0020（`~` は連鎖の最初の `if` にだけ書く）なので、`if c { 1 } else` 改行 `if~ d { 2 } else { 3 }` は E0003 と E0020 の誤りが二つある入力になる。
  「`if~` を含む」は、`if~ c { … } else` 改行 `if d { … }`（`if~` で始まる連鎖の後ろの `if`）と読むほかない。W3-06/t3 が見つけた（2026-10-10。親が dev の `ade4450` で、今は `else` の行末の E0002 であることを確かめた）
- 提案: 決定（2026-10-10、利用者が ID を挙げて親の案（確認だけ）を了承）: 読みは上のとおり。仕様 §2.5 の文を「`else` の後の `if`（`if~` で始まる連鎖の中でも）」に直す。`else` 改行 `if~ d` は誤りが二つある入力（S-384）として約束の外。実装は W3-06 の単位 2 のまま（変わらない）
- 時期: W3
