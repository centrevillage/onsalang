# S-1235 作り手より上に書いた式と受け手が `^名前` を通して読むイベントの値の時点（`let h = hh~(prev~(^d))` と、下の `let d = det~(x)`）

- 空白: §11.11 は「受け手は名前の順で作り手より下にあり」とするが、`^名前`（§11.2）を第 1 引数に取る組込みの遅延を通すと、作り手より上に書いた式と受け手がイベントの値を読める。
  ```
  let p = prev~(^d)            // d のイベントごとに、一つ前の d
  let s = (p at sample) + x    // 上の sample の式
  let h = hh~(prev~(^d))       // 上の受け手（イベントの入力）
  let d = det~(y)              // 下の作り手（sample の段で出す）
  ```
  読み: (1) 本体の式の順: 上の式と受け手の、その段の仕事は、d がその位置で出す前に済み、見えるのは前の位置までのイベント。(2) その位置の d のイベントを全て処理した後の値（§11.11「その位置のイベントを全て処理した後の値」を字のまま。d が上の式に頼る形では作れない）。
  `hh` が中に遅い刻みの欄を持つ形では、値を読まない仕事を段の終わりにまとめると（S-1206 の今の順）、上の受け手の仕事が下の作り手の後になり、(1) と違う値になる。
  仮の扱い: 段 1 の後に書く。W7-11 U2 の場所と U3・U5 の事例が待つ。
- 決定: 決定（2026-11-25、利用者。185 回目、第 119 組）: (1)。`^名前` を通して作り手より上に書いた式が読むのは、その式を評価した時点までに出たイベントまでの値である（同じ位置に二度出る形と、イベントの段で出す作り手では、その位置のイベントも見える）。上の受け手のイベントの刻みは、出た時に行う。仕様の字は §11.11 の出力の項・読み方の項・同じ位置の順の項。実装は W7-11 U2。
- 経緯: 184 回目（2026-11-25）、W7-11 の設計メモ（NEW-2）と値での審査が挙げ、親が登録した（`target/notes/184/w711/`）。
