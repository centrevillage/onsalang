# S-91

- 空白: 型別名を型の位置でしか使えず（`P.new()`、`P { x }`、`Sample.PI`、`S.Circle` が E0401 / E0302）、別名を通した `impl` が孤児規則をすり抜け、総称の別名の誤りの文面が理由を示さず、循環に E0310 を流用している（レビュー R-105）
- 提案: 名前の段（§3.3、R-84）で別名を一度だけ元の型（型引数を含む）に解決し、型・値・パターン・struct リテラルの全ての位置がそれを読む。`impl` の見出しは解決の前に別名かを確かめて E0307（修正候補は元の名前）。総称の別名は E0002 の文面で理由を示す。
  循環は E0311（R-02 の型定義の閉路の検出と同じ道）。`tests/review-phase1/parent/r105/` の期待値と今の出力は各項目の上のコメント（`impl/` は `onsa.toml` の先頭）（2026-10-05 決定。実装は第 3 段。名前の段と同じ回なら第 4 段）
- 時期: M2
