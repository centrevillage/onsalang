- 補い（2026-11-26、親）: S-1261（191 回目）で、`onsa test` の `assert` の値の行と `--json` の `left`・`right` に、中に入れた `Char`（タプル・配列・`Option` の中と、最上位の値）が第 1 期から出る。そのエスケープの細部はこの S のまま決めず、W8-13 の実装は今のインタプリタの書き方（Rust の `{:?}`。エスケープにする文字は Rust の Unicode の表に依る）を使い、SPEC-GAP の印（S-270）を付ける。事例は珍しい文字（NBSP、結合文字）の字を固めない。
