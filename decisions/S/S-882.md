# S-882 修正候補が受け手や周りの型を決め、E0413 で隠れていた同じ段の別の誤りが当てた後に現れる形は、§18.1 の「唯一の誤り」の前提の内か外か（`let k = 1.0` の後の `a.max(k)` の候補 `max(a, k)` が `k` を `F32` に決め、後の `let b: F64 = k` が E0401 になる）

- 空白: §18.1 は「どの候補も、一つだけを当てて検査し直したとき、元の診断が、当てる前の触れた単位の全てで同じ段かそれより前の段の唯一の誤りなら、当てた後の触れた単位の全てに、同じ段かそれより前の段の診断を残さない」とする。E0413 で本体の検査が止まるので、候補が型を決めると、隠れていた食い違いが当てた後に同じ段の誤りとして現れる形がある。
  例: `let k = 1.0` の後の `a.max(k)`（`a: F32`）の候補 `max(a, k)` が `k` を `F32` に決め、後の `let b: F64 = k` が E0401 になる（当てる前は E0413 だけ）。引数の試しは同じ本体の後の文を見ない。
  同じ類に、`1 + x.abs()`（整数のリテラルと `F32`）、`let z = x.abs()` の後の `z + 1`、`x.trunc() as I32` がある。器の `fix-contract`（`onsa_cases --run`）は違反と数える。読み: (1) 前提の外（「無いメソッドが返したはずの型」で見れば元のプログラムにも別の誤りがある。今の実装と U2 の票の読み）。
  器の事例には `leaves` で書く。(2) 前提の内（当てる前に報告される誤りは E0413 だけなので）。候補を出さないか、候補が決める型の変数が後の文で使われないことを確かめてから出す。(3) 線引き: 同じ式・同じ文の中だけを前提の外とし、別の文で使う束縛の型を決める候補（`a.max(k)` の `k` が前の文の束縛でリテラルの型変数）は出さない。
  今（`72c08b4c`）は候補を出す（再現は `decisions/S/S-882/leak1.onsa`、壊す側の入力 `target/notes/111/w514u2/u2bb/` の報告）。U2a の `as` の形の候補（`x as T`・`Some(x as T)`）にも同じ問いが当たる。急ぎ: W5-14 の U2a の前（U2a の候補の判定に効く）
- 決定: 決定（2026-11-04、利用者。112 回目、第 83 組。親の読みと伏せた独立のレビューの段 1 が一致、段 2 は省いた。下書きは作らず要約 `target/notes/112/g83/summary.md`）: (1)。候補が周りの型を決めて現れる同じ段の誤りは §18.1 の前提の外とする。候補が置く式は元の式が持つはずだった型を持つので、その型を受ける隣の被演算子や後の文の誤りは元から二つ目の誤りである。候補は今のとおり出し、候補が自分の位置に合うこと（期待の型と親の式、`place_fits`）は候補の責任のまま。事例は `leaves` で残る誤りを書く。仕様 §18.1
