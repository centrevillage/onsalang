# S-1014 `Show` のメンバ: 第 1 期の `Show` はメソッド（`x.show()`）を持つか、§15.1 の `Show.show(1)` の note が示す形

- 空白: §6.3 は `Show` を標準 trait の一覧と表に載せ、メンバ（メソッド `show`）を定めない。実装にも無い（`x.show()` は `I32` でも E0413）。一方 §15.1 は `Show.show(1)` を E0308 とし、note でメソッドの形 `x.show()` を示すとし、実装もそう出すので、note が無いメソッドを直し方として示す（R-405）。読み: (1) 第 1 期の `Show` はメソッドを持たないと書き、§15.1 の例と note を直す (2) `Show` にメソッド `show(self) -> Str` を足す（仕様・std の宣言・インタプリタと C。この版の C は `Str` の値を降下できず E0200）。
- 決定: 決定（2026-11-12、利用者「R-405: (1)」。140 回目、W5-13 の判断の 3）: (1)。第 1 期の `Show` は補間（§2.4）が値に求める trait で、メソッドを持たない（§6.3 に足した）。§15.1 の trait の名前の後の `.` の例は、メンバのある `Int.checked_add(1, 2)`（note はメソッドの形 `x.checked_add(y)`）に替えた。note は、書いた名前がその trait のメンバに無いときはメソッドの形を示さない（`Show` なら補間で書くことを示す。note の文面は約束しない）。W5-13 U1 で note と事例 `tests/spec/module/dot_after_trait_name.onsa` を直す。`Show` がメソッド `show` を持つかは、第 2 期の `Str` の作業（`Str` との変換、`FixedStr` の `Show`）で決める（`tasks/phase2.md`）。
- 経緯: 140 回目（2026-11-12）、W5-13 の前の洗い出しの領域 2（onsa-advisor）が、R-405 の場所（`traits.rs` の `MEMBERS` に `Show` の行が無く、仕様に `show` の字が無い）を確かめ、親が仕様の決めとして出した。関係: R-405、S-713。
