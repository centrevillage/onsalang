# S-681 ローカルの束縛と見えている束縛の E0304（`use std.math.{sin}` の後の `let sin`）のとき、使う所が引く側

- 空白: §5.1 はローカルの束縛と見えている束縛（`use` の束縛、項目、prelude）の同じ名前を E0304 とし、位置はローカルとする（S-79）。使う所がどちらを引くかは書いていない。
  今（`c335496`）は通る（`target/notes/67/g59/probe/g_local`。ローカルの E0304 は W4-04 の本体の歩き手で入る）。族の規則は S-675。W4-04 の設計で決めるので、族の規則から決まる形か、別に決めるかは族の回答で決める。
- 決定: 決定（2026-10-25、利用者。67 回目、第 59 組、ID を挙げて確認だけで了承（A5））: 別に決める点は無い。ローカルの E0304 はその関数か flow の単位の名前の段の誤りで、§18.1 の単位の規則（最初の誤りで検査を止める）により同じ単位の以後の使用は報告されないので、使う所が何を引くかは出力に現れない（W4-04 の本体の歩き手の内部の細部）。
  S-675 の決定と §18.1 の S-462 の段落の一文で閉じる。W4-04 はローカルの E0304（§5.1）を実装するだけ。
- 経緯: 67 回目（2026-10-25）、第 59 組の下書き（onsa-gap）が見つけた。関係: S-675、S-79。
- 補い（2026-10-28、親）: 79 回目（W4-19）: S-741 (b) で引数と flow の入力は見出しの全体で見えるので、見出しでは E0304 になった引数より前の型の位置の同じ名前が出力に現れうる（`fn f(a: Item, Item: U32)` の `a: Item`）。
  §5.1 の一文（E0304 になったローカルは束縛として数えず、同じ名前は重なった相手を指す。失敗した `use` の名前と同じ、§18.1）で閉じ、報告は E0304 だけである。本体では今も出力に現れない。
- 補い（2026-10-28、親）: 80 回目の文書の点検（F-I）: §18.1 の E0304・E0305 の段落（その名前は使う所でどちらの宣言も引かない）がローカルを除くと書かず、§5.1 の一文と読みが割れた（`fn f(a: Item, Item: U32)` の後の `f(3, 1)` の E0401 の有無）。利用者の了承で、§18.1 のその段落に「ローカル（引数と flow の入力を含む）の E0304 は §5.1 による」を足した。実装は変えない。
