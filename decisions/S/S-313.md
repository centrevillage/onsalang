# S-313 パッケージの中のディレクトリの名前

- 空白: パッケージの中のディレクトリの名前（`My-Dir/a.onsa` のモジュールの経路の途中）に §2.3 のモジュールの名前の規則と E0320 を当てるか。当てるなら位置と note の形。§15.1 はモジュールのパスをパッケージルートからのファイルパスとし、§2.3 はファイル名の規則だけを書く。S-300 の反映で見つけた（2026-10-09）
- 提案: 決定（2026-10-09、利用者。親の案を利用者が自分の提案（明示した経路の不正な名前はエラー、集めるときに見つけた不正な名前は通知して除く）と突き合わせ、親の分け方を了承）: モジュールの経路の途中のディレクトリの名前にも §2.3 の規則を当て、違反は E0320（一つのディレクトリに一つ、位置は下の `.onsa` ファイルのうち診断の並べ方で最初のものの先頭、候補なし、note）。
  パッケージを集めるとき、`.` で始まる名前のディレクトリは集めない（道具の場所の慣習。Go の `...` と同じ）。経路で明示して渡したファイルの経路の名前は、`.` で始まるディレクトリでも規則を当てる（E0320）。ファイル名とディレクトリの E0320 は宣言の単位に入らない。通知（警告）の種類は足さない（Onsa の診断は全て誤り）。仕様 §2.3、§15.1。
  実装は W4-02（経路の要素の並びでモジュールの同一性を決め、文字列を分け直さない）
