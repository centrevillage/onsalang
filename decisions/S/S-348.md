# S-348

- 空白: 二項演算子の被演算子に裸の `as` が複数ある連鎖（`x as I64 + y as I64`）の E0011 を、`as` ごとの誤りとするか、一つの連鎖で一つの誤り（全ての `as` を括弧で囲む一つの候補）とするか。§18.1 の「一つの構文の形は一つの誤り」の閉じた一覧に `as` は無い。W3-07 の実装は後者（`SPEC-GAP(S-348)`）。W3-07/b で見つけた（2026-10-09）
- 提案: 後の段
- 時期: W3
- 決定: 決定（2026-11-09、利用者。128 回目、共通の規則 S-965 と利用者の判断 B1〜B8、`target/notes/128/r58/decisions.md`）: （出所: R6）一つの式（括弧で切れる二項演算子の式の単位）の被演算子の位置に並ぶ括弧の無い `as` / `at` と、見出しの範囲の両端の `as` / `at` は、全てで一つの E0011 で、候補はそれらを全て括弧で囲む一つの形である（E0013 と同じ形）。今の実装のとおり。
  - 仕様の節: §3.3 の E0011 の段落に一文。§18.1 の「一つの構文の形」の一覧に足す（親が置く文、3）。
  - 今通るプログラムが変わるか: 変わらない（`x as I64 + y as I64 == z as I64` は今も一つの E0011 と一つの候補）。
  - 実装の見当: `onsa_syntax/src/groups.rs` の `SPEC-GAP(S-348)` の印を注釈に改める（数行）。
  - ぶつかる既存の事例: `tests/spec/negative/syntax_clock_operands.onsa`の注記「open, S-348」を改める。
