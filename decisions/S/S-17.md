# S-17

- 空白: §17.3 と §17.4 は同じモジュールだが、`use std.math.{exp, cos}` と `use std.math.{floor, exp}` で `exp` を二度取り込む
- 提案: 同じ名前の二度目の `use` は E0304（束縛の重複）とし、§17.4 の行を `use std.math.{floor}` に直す。`use` はモジュールのどの位置にも書ける（Rust と同じ）
- 時期: M2
