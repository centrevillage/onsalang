# S-204 長さが 0 の `process`（S-196 の調べで追加）

- 空白: 長さが 0 の `process`（0 フレームの呼び出し）が正しい呼び出しか、`block` の段を評価するかが書かれていない。C の API では、二つの出力が NULL のときに重なりの検査が誤り（2）を返しうる（S-196 の調べで見つけた、2026-10-07）
- 提案: 正しい呼び出し。`block` の段は 1 回、`sample` の段は 0 回評価する。`frames` が 0 なら入出力のポインタ（`In` / `Out` の構造体へのポインタも）を読まず NULL でよく、重なりを検査しない。poisoned か未初期化なら評価せずに 1 を返す（2026-10-07 決定。実装は W2-08、W10-03）
