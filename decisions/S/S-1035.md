# S-1035 細部: 所有の Dup の束縛を、最後の使用で借用の見出し（`match o`、`for s in xs`）に置き腕・本体で束縛を消費する形と、手放さずに複製した消費の E0601・E0901 に、理由と直し方の note を付けるか

- 空白: S-1030 で、所有する Dup の値を消費する位置で最後の使用なら移す読み（第 98 組の (b)）を採ると、移せずに複製した消費（後でまた使う、同じ呼び出しで借りている、ループの中）の後の破棄が `Alloc` を要する。E0601・E0901 の今の文面（「`x` owns a `Str`, whose destruction needs `Alloc`」）からは、なぜ移らなかったかと直し方が読めない。
  とくに、所有の束縛 `o` を借用の見出しに置く `match o { Some(s) => W.A(s), None => W.B }` は、腕の束縛が借用（§5.4）なので `W.A(s)` が複製になり、直しは `match move o` である（`for s in xs` も同じ）。
  読み: (1) note を付けない（今のまま） (2) 複製した位置と理由（後の使用の位置、同じ呼び出しの借用、ループ）を note で示し、借用の見出しの形には `match move o` を示す。修正候補はどちらも足さない（直し方が一つに決まらない）。S-1030 が (b) でなければ要らない。
  仮の扱い: W6-02・W6-03 の実装の担当が出す形（文面は約束でない、§18.1）。
