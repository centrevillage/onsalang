# S-149

- 空白: C のフィールド名の `.` → `_` が単射でない。flow `hoist` のノードと巻き上げのフィールドが重なる（点検 C-37）
- 提案: `.` は `__`、識別子の `__` は E0320、`hoist` は予約（E0304）。生成した `.c` は C11 の翻訳単位（仕様 §14.2）（2026-10-06 決定。実装は C のバックエンドと名前の段）
