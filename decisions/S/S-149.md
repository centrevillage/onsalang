# S-149

- 空白: C のフィールド名の `.` → `_` が単射でない。flow `hoist` のノードと巻き上げのフィールドが重なる（点検 C-37）
- 提案: `.` は `__`、識別子の `__` は E0320、`hoist` は予約（E0304）。生成した `.c` は C11 の翻訳単位（仕様 §14.2）（2026-10-06 決定。実装は C のバックエンドと名前の段）
- 時期: M4
- 補い（2026-11-18、親）: 165 回目、第 110 組の S-1138（族: flow の状態の名前）で、flow の名前 `hoist` の予約を外した。巻き上げの欄を `a._hoist_0` と呼ぶので flow `hoist` のノード `a.hoist_0` と重ならない。`.` を `__` にする写しと識別子の `__` の E0320 は変わらない（`a._hoist_0` と `a_.hoist_0` の C の名前の組は W8-11・W10-02 で処理系が重ならない名前を選ぶ）。
