# S-316

- 空白: E0020 の主の位置（`span` の始まり）。仕様は形ごとの主の位置を書かない。
  W3-15/t2 のデータのファイルは「形の最初の誤ったトークン」（`;`、`<`、`::`、`&`、型の名前、`+=`、`++`、`~`、`@`、ブロックコメントの `/*`。呼び出しの形は呼び出しの式の最初のトークン）とし、仕様が決めない形（空白の誤り、`let mut` のように複数のトークンを置き換える形、項目の全体が誤りの形）は位置を書かなかった。
  W3-15/i の設計メモは「今の位置のまま（`<T>` の全体、`&mut`、`::` のトークン）」。W3-15/t2 で見つけた（2026-10-09）
- 提案: 決定（2026-10-09、利用者が ID を挙げて了承。親の案）: E0020 の主の範囲は外来の形の範囲（形を作る最初のトークンから最後のトークンまで）で、始まりは形の最初のトークン（`let mut` は `let` から、`<T>` は `<` から `>` まで）。空白の誤りの位置は W3-06 で決める。仕様 §18.1（W3-15 のコミットで書く）。
  データのファイルの `at` の注記の「仮」を外す。実装は W3-15。読み（2026-10-09、利用者が了承）: 呼び先の形（行 `callee_expression`、`(s.f)(x)`）の範囲は呼び先の先頭から `(` まで（引数は形の外。読んでいない引数の中の誤りは別の誤り、S-259）。
  呼び先が同じトークンで閉じる式のうち最も外側から始まる（`if … else { … }(x)` は `if` から）
- 時期: W3
