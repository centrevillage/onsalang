- 他言語: 
  - Go 1.27.2（手元。7.32 の一覧の外で参考）: パッケージ `a` に `import "ex/b"` と `func b()`、`b` に `import "ex/a"` では、`go build` は「import cycle not allowed」だけを出す（読み込みで止まり、型検査の重なりは出ない）。循環を除くと「b already declared through import of package b」。重なった import も依存に数える。
  - rustc 1.94.1（手元、`--edition 2021`）: `mod a { use crate::b; pub fn b() … }` と `mod b { use crate::a; … }` は警告だけで通る。関数とモジュールは名前空間が違って重ならず、モジュールの循環も許すので、当たる形が無い。
  - Python 3.14.5（手元）: `a.py` の `import b` と `def b()`、`b.py` の `import a` は通り、`def b` が取り込んだ名前を黙って上書きする。循環の取り込みを誤りにしないので、当たる形が無い。
  - TypeScript、Swift、C 系: 未確認。
