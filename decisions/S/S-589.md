# S-589 `let` の初期化式が `if`・`match`・ブロック式で、末尾が借用の起点や静的な値のときの借用か所有か

- 空白: §5.4 の表は、借用の行を「`let y = x`、`let y = x.f`、`let y = x[i]`、分解（`x` は借用の起点、または起点から派生した借用束縛）。`let y = CONST`、`let s = "abc"`（静的な値）」とし、所有の行を「`let y = f(...)`、`let y = move x`、静的でないリテラルや演算の結果」とする。
  初期化式が `if`・`match`・ブロック式で、その末尾が借用の起点（`let t = if c { x } else { y }`、`let t = { x }`。`x`・`y` は借用引数）のとき、どちらの行か書いていない。§5.2 の S-100 の文は、Affine の末尾の式が置かれた位置を継ぐとだけ書く。
  割れる読み: (1) 末尾を継ぎ、全ての末尾が借用の行なら借用。(2) 表の行に無いので所有で、複製する。
  今の実装は所有で、`rt fn` の中の `Str` では E0901 になる（再現は 54 回目の scratchpad の `x8est/C/t/d1.onsa`）。
- 決定: 決定（2026-10-23、利用者が ID を挙げて了承。57 回目、第 42 組）: 族の規則 S-604 から決まる。全ての末尾が借用の起点か静的な値の `if`・`match`・ブロック式（`let t = if c { x } else { y }`）は借用で、rt の関数でも破棄が起きない。
  末尾の一つが所有の行なら所有で、借用の Dup は複製、借用の Affine と `inout` 引数の腕は候補なしの E0711、ローカルの Affine は `move` の挿入の候補。仕様 §5.4
- 経緯: 54 回目（2026-10-23）、X-8 の第一弾の見積もり（組 C）で W4-07 の束縛の状態の関数を見積もるときに見つけた。関係: S-41、S-80、S-100。
  57 回目、第 42 組（族 S-604、下書き `S-589.draft.md`、助言の担当の二段。全て一致。`inout` の腕の候補なしは段 1 の補い）。
