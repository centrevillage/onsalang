# S-1273 添字の中の変更がその基を書く形（`xs[reset(inout xs)]`）で、基の要素をいつ読むか

- 位置付け: 第 123 組。族の規則 S-1275 から決まる（表と案と値の帰結は S-1275 の下書き）。
- 論点: `reset(inout xs)` が `xs = [7, 8, 9]` にして 1 を返すとき（初め `[1, 2, 3]`）、`let v = xs[reset(inout xs)]` は、基の評価が場所を決めるだけなら変更の後の 8、値を読むなら変更の前の 2。E0702 の窓は呼び出しの引数に限るので、sema は誤りにしない。
- 今の実装: 場所の経路の基は解釈器も C も 8。場所でない基は割れるか、移した・破棄した `Buf` を読む（R-531・R-532）。
- 案: S-1275 の F4 なら E0702（場所でない基も、末尾の場所・部分ビューの元・`move` を借用の引数と同じに数える）。F1′ なら場所の経路の基は変更の後の値（8）、場所でない基は E0702。
  あわせて決める点（どちらの案でも）: 借用束縛の `hh.xs[set_xs(inout w.h.xs)]` と `b[take(move b)]` は今 E0704 で、E0702 にも当たる。S-799 の「同じ位置の E0704 は出さない」に揃えて E0702 の一件にする（`tests/spec/negative/binding_path_use.onsa` の印が一つ変わる）。右辺が代入先の基を変更する `xs[0] = reset(inout xs)` は対象外（S-1264 の順のまま有効）。
- 推奨と理由: S-1275 の規則から（下書きは F4、確度 中）。E0704 との重なりは E0702 に揃える（確度 高。診断の数の細部）。
- 独立のレビュー: 段 1・段 2 とも一致（S-1275 の下書きの独立のレビュー）。
