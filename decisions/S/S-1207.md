# S-1207 上りを下りが包む連鎖（`x.up~(M).down~(N)`）の時間: 境界で集めて配る（§11.9・S-566 の A10）か、連鎖のレート一つ（§11.10、今の検査と参照評価器）か

- 空白: §11.9 は「`x.up~(M).down~(N)` も、中の部品の入出力を境界で集めて配る形で読む」とし、S-566 の A10 は「`x.up~(2).down~(2)` は 2 サンプルの塊で処理し、x と同じで 2 サンプル遅れる（音声の入力の無い `osc~(f).up~(2).down~(2)` は遅れず `osc~(f)` と同じ）」とする。一方 §11.10 は「x は、連鎖のレート R（…連鎖の `.down~`・`.up~` を当てたもの）の刻みのうち…動く」「`x.when~(c).down~(4)` と `x.down~(4).when~(c)` は同じ意味」と、連鎖を一つのレートに畳んで書く。M ≠ N の集め方と配り方は字に無い。
  今の実装（W7-09）は連鎖のレート一つ: 検査は `Char` の `sample` の入力を `id~(v).up~(2).down~(2)` に渡す形を通し（`.down~(2)` で集める変換の flow なら E0816）、参照評価器は連鎖を比の和一つにし（`crates/onsa_tests/src/flow_ref/rate.rs` の `chain_of`・`gathers`）、事例 `tests/spec/flow_clock/e0816_conversion_flow_gather_deal.onsa` は「a chain of the ratio one」を `Default` の要らない形とする。W7-16 の設計メモ（4.3）も比の和で降ろす。
  読み: (i) 字のとおり境界で集めて配る（入力のある部品は N サンプル遅れ、集める型と配る型に `Default` が要る。M ≠ N と `when~`・`reset_if~` を交ぜた形の規則を足す）、(ii) 連鎖のレート一つ（遅れない。§11.9 の一句と A10 の一文を改める）。通るプログラム（E0816）と値（遅れ）が変わる。
  仮の扱い: 今の実装（(ii) の形）のまま。W7-16 の `.up~`・連鎖の単位（U6b）の前に決める。
