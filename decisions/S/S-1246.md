# S-1246 細部: `match~` の対象の遅延の `init` の引数に `^名前` を書いた形（`prev~(match~ prev~(x, ^k) { b => g~(b) })`）の束縛を flow の引数に読むのが E0801 か

- 空白: §11.2（S-1245）は「対象とガードの中の、入れ子の遅延の第 1 引数の中の `^名前` は、その遅延の出力なので数えない」とする。対象の遅延の `init` の引数に書いた `^名前`（`match~ prev~(x, ^k) { b => g~(b) }`、`k` は `init` の `let`）は、字のとおり数えて E0801 になる。
  束縛の値は遅延の出力で、書いた位置で決まる（`^k` が効くのは `init` の段の終わりだけ）ので、許す読みもある。
  読み: (1) 字のとおり E0801（今の実装）。(2) `init` の引数の `^名前` も数えない。
  仮の扱い: (1)（保守的な側。後で (2) に緩めても今通る形は壊れない）。`d439fac` では通っていた（E0815 が別に出る形を除く）。W7 の区切りで確認だけ。
- 決定:
- 経緯: 185 回目（2026-11-25）、W7-11 U2b の実装（i3）が細部として挙げ、壊す側が字と合うと確かめ、親が登録した。
