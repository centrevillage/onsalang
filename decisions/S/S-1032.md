# S-1032 注釈も期待する型も無い無名関数（`let l = fn(y: I32) -> I32 { bump(y) }`）の効果行

- 空白: §8.1 は「無名関数の `uses {}` は効果行の注釈で、省くと期待型から決まる形」「無名関数は、期待する関数型の効果行と `rt` に照らして本体を検査する」とし、注釈も期待する型も無い無名関数（`let l = fn(y: I32) -> I32 { bump(y) }`、`bump` は `uses {Alloc}`）の効果行を書かない。
  今の実装（dev `ea8d73f6`）: 効果行は空（`body/expressions.rs` の `check_closure`）、`rt` は偽で、本体の `Alloc` は外側の関数に数える（外側が `uses {Alloc}` なら通り（`k7`）、純粋なら外側の E0601（`k8`））。
  読み: (1) 空の行（名前付きの関数の `uses` の省略と同じ。本体の `Alloc` は無名関数の E0601） (2) 本体から決まる（効果の段でしか決まらず、型の段で閉じない。R-27 の補い） (3) 外側の関数の効果行。
  急ぎ: 無名関数の本体を期待する型の効果行で照合する作業（R-27 (1)。設計メモは W6-03 へ移す案）の前。W6-01 は型を今のまま（空の行）にする。
- 決定: 決定（2026-11-13、利用者。146 回目、第 99 組。下書きと独立のレビューの段 1 が一致、段 2 は省いた）: (a)・(ii-3)・`rt` でない。無名関数の型の効果行は、書いた効果行（`uses {}` を含む）、書かなければ期待する関数型の効果行、期待する関数型も無ければ空（名前付きの関数の省略と同じ）。`rt` は書けず、期待する関数型が `rt` のときだけ `rt`。期待する関数型が無いのは、注釈の無い `let`・`var`、その場で呼ぶ対象、期待型の無い合流の枝、未決の型変数を期待型とする位置。本体はその型で照らし、外側の関数と外側の無名関数の効果行に数えない（外側が数えるのは関数値の呼び出し）。`rt` でない無名関数の本体は、外側が `rt` でも `rt fn` の規則で見ない。
  (ii) は (ii-3): 合流の後の枝の無名関数は、前の枝の型から引数と返り値の型だけを受け、効果行と `rt` は受けない（W6-01 の U2b が仮に置いた (ii-2) を W6-03 で改める、`check_closure` の 1〜3 行）。当たるのは一番外の枝そのもので、枝の中のタプルの要素や `Some(…)` の引数は S-1031 のとおり期待型として全てを受ける。
  細部: 無名関数の E0601 の位置は本体の最初の使用（S-82・R-87 (6)）、note で無名関数の頭と行の決まり方を示す。修正候補は出さない（S-1041 の細部、当てると無名関数の型が変わり同じ単位に別の誤りを作りうる）。R-451 は「期待する型の無い無名関数も `rt` でないので本体を `rt` の規則で見ない。呼べば呼ぶ位置の E0901」に改める。
  理由: 名前付きの関数の省略と同じ一つの規則で、型の段で閉じ、W6-03 は全ての無名関数を自分の型で照らす一つの規則になる。(f)（今の数え方）は、`const` の初期化式のブロックを経ると純粋な関数が確保する穴が第 1 期に既にある（R-359 の補い）。(c) は型の段で閉じず E0401 が二つの段に分かれる（R-27 (3) で第 1 期に入れないとした形）。(e) は純粋な無名関数に外の `Alloc` を付ける。今の木で変わる事例は見つからない。(a) から (c) へは緩める向きで、第 2 期の効果行変数の項で一緒に開き直せる（`tasks/phase2.md` に一行）。
  `rt` の関数の中で捕捉する無名関数を `rt` にする書き方が無い点（段 1 の B2、今も E0901）は、無名関数の `rt` の印として A-21 に登録した（利用者の指示で、A-16 の `auto` の印との関係を論点に含めた）。
  作業は W6-03（R-27 (1)・R-26 の後半・R-451 と同じ規則、(ii-3) の分岐、E0601 の位置）。仕様 §8.1（無名関数の項）、§4.7（合わせの後の一文）、§10（一文）。下書きは `S-1032.draft.md`
