# S-1032 注釈も期待する型も無い無名関数（`let l = fn(y: I32) -> I32 { bump(y) }`）の効果行

- 空白: §8.1 は「無名関数の `uses {}` は効果行の注釈で、省くと期待型から決まる形」「無名関数は、期待する関数型の効果行と `rt` に照らして本体を検査する」とし、注釈も期待する型も無い無名関数（`let l = fn(y: I32) -> I32 { bump(y) }`、`bump` は `uses {Alloc}`）の効果行を書かない。
  今の実装（dev `ea8d73f6`）: 効果行は空（`body/expressions.rs` の `check_closure`）、`rt` は偽で、本体の `Alloc` は外側の関数に数える（外側が `uses {Alloc}` なら通り（`k7`）、純粋なら外側の E0601（`k8`））。
  読み: (1) 空の行（名前付きの関数の `uses` の省略と同じ。本体の `Alloc` は無名関数の E0601） (2) 本体から決まる（効果の段でしか決まらず、型の段で閉じない。R-27 の補い） (3) 外側の関数の効果行。
  急ぎ: 無名関数の本体を期待する型の効果行で照合する作業（R-27 (1)。設計メモは W6-03 へ移す案）の前。W6-01 は型を今のまま（空の行）にする。
