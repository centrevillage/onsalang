# S-897 見出しを読めなかった `impl` の範囲の細部（`impl S` の後の改行と、trait を満たすかの判定の範囲）

- 空白: S-850 の §18.1 の段落は、見出しを読めなかった `impl` の例を `impl S[ {`、`impl` だけで切れた形とし、見出しまで読めて本体で切れた `impl` を分ける。次の二つが決定の文から一つに決めきれない。
  (a) `impl S` の後の改行（`{` が無い）は、見出しを読めなかった形か、本体で切れた形か。`d4fb06d1` は E0002「expected `{`, found newline」と使う側の E0413。
  (b) 「trait を満たすかの判定（境界、演算子）」の括弧は例か全てか。文字列補間の `Show`（§2.2）、derive の要求（§6.4）、`Map` の鍵は、今は判定が無いか、後の作業で入る。
  親の読み（確認だけ）: (a) は見出しを読めなかった形。見出しは `{` までで、メンバは一つも読めていない。§18.1 の例に足す。(b) は例で、`Bounds::satisfies` を通る判定は全て黙る。実装は `traits_unknown` の一か所で、後の作業が足す判定も同じ道を通る。
- 決定: 決定（2026-11-05、利用者が ID を挙げて了承。115 回目、組 86、確認だけ）: (a) `impl S` の後の改行（`{` が無い形）は、見出しを読めなかった形で、使う側を黙らせる。見出しは `{` までで、メンバは一つも読めていない。(b) 「trait を満たすかの判定」は境界と演算子を例とし、`Bounds::satisfies` を通る判定は全て黙る。後の作業が足す補間の `Show`・derive の要求も同じ道を通る。
  仕様は §18.1 の段落の例を改めた。実装は W5-04 の U2。
- 経緯: 115 回目（2026-11-05）、W5-04 U2/t（onsa-test）が報告した。関係: S-850、R-180。
- 補い（2026-11-05、親）: 115 回目の文書の点検から（2026-11-05）: 「`satisfies` を通る判定」は trait の判定で、種の制約（`Copy`、`Dup`）を含まない（S-850 の B1。§4.6 で種は構造で決まる）。§18.1 に明記した
