# S-1226 細部: 塊の内で外の `reset_if~` が戻す条件の輪を、同じ刻みの後の走りが読む順（仮は順に実行する読み (α)）

- 空白: 塊の内（修飾子の外に `.up~`、その外に `.down~`）で、外の `reset_if~` の刻みが境界の刻みと重なり、内に R より遅い仕事があると、初期化は塊の走り 0 の途中（遅い仕事の後）に入る。初期化は集めた条件の輪も戻すので、同じ刻みの後の走りの守りが読む値が字で一つに決まらない。読み (α) 順に実行（前の読みは集めた値、後の読みは戻した値）、(γ) 輪は境界の刻みの前に戻す（その刻みの全ての走りが偽）。(β)（刻みの始めに写し取る）は §11.9「次の遅い刻みが集める配列は、初期化の前の所が `T.default()`」で外れる。例と読みごとの値は `target/notes/181/w710/u3a/adv_report.md` の 4 章（`slot8~(1.0).when~(c).up~(2).down~(2).reset_if~(h2~(r))`）。
  仮の扱い: (α)（今の実装のまま。U2b で決めた順「条件を読む → 遅い仕事 → 初期化 → 残り」をそのまま輪に当てた形）。`SPEC-GAP(S-1226)` の印。通るプログラムは変わらない（W7-10 U3a の前は塊の内の修飾子が E0200）。段の区切りで確認だけ。
  補い（181 回目、W7-10 U3ae/i）: 今の実装（Core と評価器）の (α) の境は静的で、内の `when~` が R より遅い仕事を W へ動かす形（表の上で遅い仕事がある形）だけ走り 0 の途中で戻し、遅い仕事の無い形は境界の刻みの前に輪を戻す（その形では (γ) と同じ値、例 `cnt~().when~(c).up~(2).down~(2).reset_if~(h2~(r))` は `[0,0,1,2,0,0,1,2]`）。遅い仕事がその刻みに実際には動かない位置（`reset_ring_order_s1226.onsa` の位置 4）でも (α) の側。確認のときに、この境も示す。
- 決定: 決定（2026-11-24、S-1228 の (P) から。利用者が (P) に決めたときに (γ) で閉じると了承した。181 回目）: (γ)。外の `reset_if~` の刻みが塊の境界の刻みと重なるとき、集めた条件の輪は、その刻みの走りの前に戻る（その刻みの全ての走りが戻した値 `false` を読む）。(P)（その刻みの段の左の全体の仕事の前に戻す）と、§11.9 の集めて配る時点の項（次の遅い刻みが集める配列は、初期化の前の所が `T.default()`）と、§11.10 の合成の項（境界の内に書いた修飾子の条件は、同じクロックの頭の入力と同じ時点の値を読む）から決まり、字は足さない。実装の (α) の静的な境（補いの行）は W7-10 の (P) の単位で無くなり、`SPEC-GAP(S-1226)` の印を Core と評価器から外した。
- 経緯: 181 回目（2026-11-24）、W7-10 U3a の実装の担当が掃引の未分類に挙げ、advisor が原因と読みの表を出し、親が細部として登録した（利用者が「推奨案で進めて」と了承した U3a の直しの範囲）。
