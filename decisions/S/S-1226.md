# S-1226 細部: 塊の内で外の `reset_if~` が戻す条件の輪を、同じ刻みの後の走りが読む順（仮は順に実行する読み (α)）

- 空白: 塊の内（修飾子の外に `.up~`、その外に `.down~`）で、外の `reset_if~` の刻みが境界の刻みと重なり、内に R より遅い仕事があると、初期化は塊の走り 0 の途中（遅い仕事の後）に入る。初期化は集めた条件の輪も戻すので、同じ刻みの後の走りの守りが読む値が字で一つに決まらない。読み (α) 順に実行（前の読みは集めた値、後の読みは戻した値）、(γ) 輪は境界の刻みの前に戻す（その刻みの全ての走りが偽）。(β)（刻みの始めに写し取る）は §11.9「次の遅い刻みが集める配列は、初期化の前の所が `T.default()`」で外れる。例と読みごとの値は `target/notes/181/w710/u3a/adv_report.md` の 4 章（`slot8~(1.0).when~(c).up~(2).down~(2).reset_if~(h2~(r))`）。
  仮の扱い: (α)（今の実装のまま。U2b で決めた順「条件を読む → 遅い仕事 → 初期化 → 残り」をそのまま輪に当てた形）。`SPEC-GAP(S-1226)` の印。通るプログラムは変わらない（W7-10 U3a の前は塊の内の修飾子が E0200）。段の区切りで確認だけ。
