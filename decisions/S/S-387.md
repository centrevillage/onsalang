# S-387 同じ行で空白だけで並べた要素

- 空白: 同じ行で空白だけで並べた要素（`[0.1 0.2 0.3]`、`two(a b)`）。MATLAB と Julia の行ベクトルの書き方。今は E0002 で候補なし。S-384 は改行の形だけで、S-89 は同じ行の `two(xs [0])` に `,` を並べず空白を除く候補にした。同じ行の並置には関数適用の読みもあるので、候補の組が S-384 と違う。`,` の候補を出すか。第 18 組の下書きで見つけた（2026-10-10）
- 提案: 決定（2026-10-10、利用者が ID を挙げて推奨の (a) を了承。下書きと Fable が一致、第 19 組）: S-384 の規則を要素の間の空白によらない形にする。
  並びの中で、完結した要素の後に `,` も閉じ括弧も無く、次のトークンがその並びの要素を始められる字句なら、改行・空白・タブ・何も無い、のどれを挟んでも `,` の無い二つの要素の E0002 で、修正候補は `,` の挿入（S-384 の字句の条件のまま、次の要素を試しに読まない）。
  既にある規則が先に読む形（S-89 の空白の後の `(`・`[`、S-123 の `!(`・`~(`、二項演算子、メンバの `.`、S-388 の文字列）はその規則のまま。関数適用の候補（`a(b)`）は出さない（引数の範囲が言語で割れ、範囲を決めるには次の要素を読む必要がある）。腕の `0 1 =>` のように前の要素が完結していない形は当たらない。抜けが複数なら一つずつ直る。
  括弧の外・括弧の中のブロック・無名関数の本体の同じ行の並置は S-401。前が名前でないトークンの後の同じ行の `(`・`[` は S-399、名前に接する文字列は S-400、非対称な空白の `-`・`^` は S-398。文面は S-384 と同じく「expected `,` or `)`」の形。実装は S-384 の関数の条件から改行の判定を外すだけ。仕様 §2.5。実装は W3-06
