# S-280

- 空白: 閉じていない `(` と `[` の中の行頭にある項目のキーワード（複数行の flow の引数の `@param`）で、回復が新しい単位を始めてよいか。§18.1 は `{` の字下げの規則だけを書く。今は `(` の中の `@param` で止まり、一つの flow に E0002 が二つ出る。W3-03/b で見つけた（2026-10-08）
- 提案: 決定（2026-10-08、利用者が ID を挙げて了承。実装は W3-03 で済み、`SPEC-GAP(S-280)` の印は W3-15 で外す。親の案: `{` と同じ規則を `(` と `[` にも当てる。開いた括弧の行と同じか浅い字下げの行頭の項目のキーワードでだけ止まる。深く字下げした `@param` では止まらない）。W3-03 で実装し `SPEC-GAP(S-280)`
- 時期: W3
