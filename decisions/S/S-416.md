# S-416 キーワードとその後ろの被演算子の間の改行

- 空白: 行末のキーワードの後の改行（`two(if` 改行 `c { 1 } else { 2 }, 1)`、`while` 改行 `c {`、`match` 改行 `x {`、`with` 改行 handler の名前、効果行の `uses` 改行 `{Alloc}` は S-413 の決定で `{` の規則に入れたので外れた）。
  括弧の外はどれもキーワードの行の末尾の E0002（候補なし）で、括弧の中は通り、fmt が一行にする。S-374 の扱い（置き場所の規則を持たないものは括弧の中で改行も空白）に入れるか、キーワードの後ろの被演算子を同じ行に置く規則にするか。第 22 組の下書きの付録で見つけた（2026-10-10）
- 提案: 決定（2026-10-10、利用者が ID を挙げて推奨の (a) を了承。下書きと Fable が一致、第 23 組）: 式の中のキーワードとその被演算子の間（`if`・`match` と条件や対象、`else` の後の `if` の条件、`with` と handler、`move`・`inout` と被演算子）は置き場所の規則を持たず、`as`・`at` と同じく括弧の中では改行も空白（fmt が一行にする）、括弧の外はキーワードで行が終わる今の E0002（候補なし）。
  §2.6 の S-385 の文（括弧の中の `if` 改行 `~c`）はこの読みを前提にする。仕様 §2.5。実装は 0 行（W3-06 の単位 2 で事例を確かめる）
