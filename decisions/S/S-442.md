# S-442

- 空白: 続いた付ける宣言の無い `///`（`/// a` 改行 `/// b` 改行 文）の数え方。§2.1 は一つの `///` の E0004 だけを書く。親の読み: 続いた並びは一つの誤りで、候補は全ての行を `//` にする一つの候補（§18.1 の「続いた `;`（`;;`）は一つの誤り」と同じ。行ごとの誤りでは一つ目の候補が S-236 の約束を満たさない）。W3-04/t と W3-04/i が見つけた（2026-10-11）
- 提案: 決定（2026-10-11、利用者が ID を挙げて親の読みを了承、確認だけ）: 続いた付ける宣言の無い `///` の行は一つの誤りで、候補は全ての行を `//` にする一つの候補（続いた `;` と同じ）。仕様 §2.1。実装は W3-04
- 時期: W3
