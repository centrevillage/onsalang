# S-433

- 空白: タプル形の struct の要素と、列挙子の要素の型に付けた doc（`struct P(` 改行 `/// x` 改行 `F32)`、`V(` 改行 `/// x` 改行 `I32)`）。§2.1 の付く先の一覧の「struct のフィールド」に入るか。タプル形の struct は E0020（W3-08）。W3-04/i の設計メモで見つけた（2026-10-11）
- 提案: W3-04 は入らない（E0004）の仮の扱い（`SPEC-GAP(S-433)`）。後の段
- 時期: W3
- 決定: 決定（2026-11-09、利用者。128 回目、共通の規則 S-965 と利用者の判断 B1〜B8、`target/notes/128/r58/decisions.md`）: （出所: 既存 §2.1）タプル形の struct の要素と列挙子の要素の型は doc の付く先でなく、E0004 で候補 `//`（列挙子は今のまま）。タプル形の struct は位置が前の `tuple_struct` の E0020 が先。改行したタプル形の struct が E0002 になるのは R-414 で、その後に確かめる。
  - 仕様の節: §2.1。
  - 今通るプログラム: 変わらない。
  - 実装の見当: `SPEC-GAP(S-433)` を外すだけ（タプル形は R-414 の直し）。
  - ぶつかる事例: なし。
