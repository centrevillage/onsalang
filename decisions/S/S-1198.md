# S-1198 細部: 互いに頼る二つ以上の `let`（帰還の輪）で、外から入る刻みのクロックの比が揃わないときの E0815 の位置

- 空白: §11.3「互いに頼る `let`（帰還の輪）は一つのクロックを持ち、それは外から入る被演算子の刻みのクロックから、帰還の無い式と同じ規則で決まる（周期の刻みのクロックが揃わなければ E0815…）」は、輪が二つ以上の `let` にまたがるとき、誤りをどの位置に出すかを書いていない（`let a = p at (sample / 4)`、`let c = q at (sample / 2)`、`let u = prev~(^v)`、`let v = u + a + c`）。
  読み: (1) 外から入る二つ目の被演算子を持つ `let` の初期化式（輪を歩き終えた所で一つ、W7-09 の設計メモ 2.4）、(2) 輪を閉じる `let`（`^` で読まれる先）、(3) 輪の最初の `let`。どれも誤りは一つで、輪の他の `let` は誤りのクロックとして読む側に診断を出さない（S-1133）。
  仮の扱い: (1)（設計メモ 2.4 の形、+0）。一つの `let` で閉じる自己の輪（`let u = prev~(^u + a) + c`）は位置が一つに決まるので当たらない。急ぎ: W7 の区切りで確認だけ（`rules/leader.md` 5.11）。
