# S-1191 細部: `if~` の連鎖の二つ目からの条件にだけ状態を持つものがあり、枝には無い形（`if~ x > 1.0 { 1.0 } else if prev~(x) > 0.0 { 2.0 } else { 3.0 }`）で、条件の E0811 に加えて E0812 も出すか

- 空白: §11.5 は「状態を持つものを枝に含まなければ E0812」と「`if~` の連鎖の二つ目からの条件 … には、状態を持つものを書けない（E0811）」を書き、条件にある状態を持つものを `if~` の E0812 の数えに入れるかを書いていない。
