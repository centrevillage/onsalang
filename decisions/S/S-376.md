# S-376

- 空白: 見出しの「括弧の外」の `{`（S-338）が、丸括弧でない囲みの中にあるとき。入れ子の `match` の腕の本体（`if match n { _ => { true } } { 1 } else { 2 }`）と添字の `[ ]`（`if xs[{ 0 }] == 1 {`）は E0002、配列リテラルの `[{ 0 }]` と呼び出しの引数の `id({ 1 })` は通る。
  struct リテラルの既存の判定も同じ分かれ方。§4.4 は「括弧の外」の範囲を書かない。E0002 の文面「a `{` at the start of an expression in a header starts the body」は、これらの `{` に当たらない。W3-21/b で見つけた（2026-10-09）
