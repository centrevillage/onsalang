# S-1016 細部: 定数式の文法の外の形（比較 `K < 1`、`!K`）の下の名前を、別名と定数の順のグラフが辿るか（`type A = [F32; (K < 1)]` と `const K: A` が E0311 か E0417 か）

- 空白: S-989 の改め（(3)）で、名前の段は定数式の文法の外の形の中を読まなくなる。別名と定数の循環と順のグラフ（`sig/decls.rs` の `Graph::expr`）は `constarg::operands` で全ての単項・二項の演算子の下を辿り、文法の表（`Ast::const_form`、`+ - * / %` と前置 `-`）より緩い。今は `type A = [F32; (K < 1)]` と `const K: A = …` が E0311、`!K` も E0311、`f(K)` は E0417（`target/notes/141/w513u2_review/p6.txt`）。(1) グラフも `const_form` で分岐し、文法の外の形の下を辿らない（E0417。表が一つになる） (2) 今の上界のまま（E0311）。どちらも誤りとして拒む（通るプログラムは変わらない）。仮の扱いは (1)（判断が一つで、(3) の「文法の外の形の中は読まない」と揃う）。
