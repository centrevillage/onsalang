### S-623 束縛を持つ選択の腕のガードが偽のとき、同じ腕の次の枝を試すか

- **論点:** §7 は「選択の全ての枝は、同じ名前の集合を束縛する（`(x, 0) | (0, x) => x`）」とし、腕にガードを持てるが、二つ以上の枝が同じ値に当たり、名前を値の違う部分に束縛するとき、どの枝で束縛するかと、ガードが偽のときに同じ腕の次の枝を試すかを書いていない。
  `match p { (x, _) | (_, x) if x > 5 => x, _ => -1 }` に `(1, 9)` を渡すと、(1) なら -1、(2) なら 9 になる。§3.5 の「取る腕だけを評価する」はガードの評価の回数を決めない。§7 の見出しの「Rust と同じ意味のものだけ」は書ける形の範囲を限る字で、S-318 も評価の順を空白とした。
  S-318 の決定の文は「腕のガードと枝の順は S-623」とするので、ガードの無い腕の枝の順（14）もここで決める。
- **今の実装:** 束縛を持つ選択は、`check` が通り、`test` と `build` は Core の降下の E0200 `OrPatternBindings`（当たる形の表の 1〜8・11〜14、`P/g122/probe/s623/`）。束縛の無い重なる選択 `1 | _ if tick(inout n)` は `test` が通り、ガードを一度だけ評価する（9、`n = 1`）。
  道具の層の flow の参照評価器は (2) を実装し、`pattern_tests.rs` の 7 件のうち 6 件が (2) の値を確かめる（18）。今の事例 `pattern_choice_bindings_same.onsa` の `with_a_guard`（`(x, 0) | (0, x) if x > 1`）は `check` が通る（17）。
- **案:**
  (1) 選択は左の枝から試し、最初に当たった枝の束縛でガードを一度だけ評価する。偽なら次の腕へ進み、同じ腕の後の枝は試さない。
  (2) 選択は左の枝から試し、当たる枝ごとにその束縛でガードを評価し、真になった最初の枝で腕を選ぶ。入れ子や複数の選択は、後の選択の枝を先に進める順（表の 7 の 29）。ガードは同じ腕で複数回評価されうる。束縛の無い選択にも同じに当てるか（9 の値が変わる）、束縛を持つ選択に限るかを併せて決める。
  (3a) ガードを持つ腕で、同じ値に当たりうる二つの枝が、ある名前を値の違う部分（タプルの位置、フィールド、列挙子の中身の経路）に束縛すると誤りにする。当たりえない枝の組は、同じ位置に違う列挙子か違うリテラルを持つものとし、定数は当たりうるとする。残る形は (1) の規則で評価する。修正候補は無く、note で二つの書き方（枝ごとに腕を分ける、条件を本体へ移す）を示す。
  (3b) 束縛を持つ選択の腕にガードを付けると全て誤りにする（4 の別の列挙子の形も）。残る形は (1) の規則で評価する。
- **他言語:** 上の「他言語の調べ」。Rust は (2)、Python と OCaml は (1)、Swift は `where` を付けたパターンごとに試し、C# は束縛を持つ選択を書けない。
- **推奨と理由:** (3a)。確度: 中。
  - 同じ書き方で、一覧の言語の間で値が割れ（Rust の 9 と Python の -1）、panic と `?` で関数を抜けるかまで割れる（11・13）。書き手がどちらの読みで書いたかは字から分からず、どちらに決めても他方の読みの書き手には黙って違う値になるので、値が割れる形だけを誤りにする。
  - (3a) は後で (1) にも (2) にも、誤りだった形を開くだけで移れる。残る形は (1) と同じに一度だけガードを評価するので、今の束縛の無い選択の挙動（9）を変えず、W8-06 の降下は (1) と同じ簡単な形で済む。生成コードも (1) と同じで、ガードの写しや評価の回数が増えない。
  - 費用: 新しいコードと二つの枝を並べて歩く判定（見込み 40〜80 行）が増える。重なりの判定は値を見ないので、3・17 の `(x, 0) | (0, x) if g` のように、重なる点で値が同じ形も誤りにする（今の事例 1 件の期待値が変わる）。参照評価器の 6 件の事例も改める。
  - (3b) は判定が短いが、DSP で書きうる 4 の形（別の列挙子の枝にガード）を、値が割れないのに誤りにする。(2) は読みの一つを選ぶ案で、ガードの評価の回数が書き方で増え、降下は当たる組の数に比例して大きくなる。(1) は最も簡単だが、Rust の読みの書き手に黙って違う値を返す。
  - あわせて決めること: 選択の枝は左から試し、ガードの無い腕は最初に当たった枝で束縛する（14。どの案でも同じ）。ガードは腕ごとに一度だけ評価する（(3a) の残る形）。誤りのコードは名前の段（E0314 と同じ所、列挙子の解決の後）か型の段かを、登録のときに決める。
  - 別の S にしてよい論点: 重なりの判定を、重なる点で値が同じ形（3・17）まで通すように細かくするか（規則が増える）。
- **影響:** 仕様 §7（選択の段落に二文）、§18.1 の段の一覧（新しいコードの段）。診断のコードは新しく一つ（番号は登録のとき。`tasks/diag-codes.md`、`codes.rs`）。
