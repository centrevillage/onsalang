# S-962 接する前置の `~` と `!` の重ね（`~!x`、空白のある `~ !x`）の候補 `!(!x)` は、C の `~!x`（`!` は論理の否定）と値が違う

- 決定済みで戻さないもの: S-961 の決定と、その決定済みで戻さないもの。第 94 組の下書きの全文（「族の仕組みの出所」「族の形の表」）の写しは `target/notes/127/g94/draft.md`、入力は `P127/g94/probe/`（消えうる。`P127` は 127 回目の scratchpad）
- 論点: §2.6 は前置の `~` を E0020 とし、候補は `!`（S-123、S-938）。被演算子が前置の記号で始まる接する形（`~-x`、`~!x`）の候補は、決定が無い。今の実装は `!(`…`)` の二つの編集を出す。
  C の `!` は論理の否定（0 か 1 を返す）で、C の `~!x` は `~(x == 0)`（-1 か -2）である。Onsa の `!` は整数ではビット反転（§2.6）なので、候補 `!(!x)` は `x` になる。`!x` を Onsa の式と読めば、候補はその読みのとおりである。`~-x` の `-` は C と Onsa で同じ意味で、当たらない。
  - 決定済み（論点から外す）: `~` の E0020 と候補 `!`（S-123、S-938）、空白と改行の形（S-938、S-957）。空白のある `~ !x` は S-958 の形で、S-961 の答えによっては接する形に従う。
- 今の実装: `let n = ~!m` は E0020「bits are negated with the prefix `!`」で、候補は `~` を `!(` に置き換えて `m` の後に `)` を挿入する（一手で誤り 0。`P/g94/spot/tbm.onsa`）。`~-x` は `!(-x)`。`~~m`・`!~m`・`-~m` は E0002（候補なし）。
- 案: 
  - (1) 今のまま: `~!x` の候補は `!(!x)`。
  - (2) 被演算子が `!` で始まるときは候補を作らない。§18.1 の「候補を作れない構文の段の形は E0002」で、`~~m` と同じ候補の無い E0002 になる。`~-x` は今のまま。
  - (3) (1) の候補に、C の `!` は論理の否定だという note を足す。
  - 形ごとの出力: `~!m` は、(1) が E0020 と候補 `!(!m)`、(2) が E0002（候補なし）、(3) が E0020 と候補 `!(!m)` と note。`~-x` はどの案も E0020 と `!(-x)`。
  - 書き手（LLM を含む）から見て: (1) は一手で誤りが消えるが、C から写した書き手には値の違う式が残り、検査は何も言わない。(2) は候補が無く、文面の E0002 から手で直す一回が要る。(3) は一手で直り、note を読めば違いに気付ける。
  - 修正候補: どの案も当て続けて止まる。(1)・(3) の候補は、書き手の意図（C の論理の否定か、Onsa のビット反転か）が一つに決まらない形に出る。(2) は候補を出さない。
  - 通るプログラム: どの案も変わらない（`~!x` は今も誤り）。`tests/`・std・`examples/` に当たる形は無い（`git grep '~!'` で当たるのは字句の並びの `tests/cst/lex_operators.onsa` だけ）。
  - 規則と例外: (1) は足さない。(2) は `faust_bit_not` の候補の条件に一つ（被演算子が `!` で始まるとき）。(3) は note の一つ。
  - 実装の量（`crates/onsa_syntax/src/foreign/faust.rs`）: (1) は 0。(2) は候補を作る所の条件に約 +2〜4。(3) は note の文と条件に約 +4〜6。
  - 後の作業への手当て: どの案も `faust_bit_not` の行の中で閉じる。
- 他言語: C の `!` は論理の否定、`~` はビット反転（C の規格の単項演算子の節）。値は親が手元で確かめていない。
- 推奨と理由: (2)。確度: 中。
  - 候補は書き手の意図が一つに決まるときだけ出す。`~` を書く書き手は C から写していることが多く、その `!x` は論理の否定と読める。Onsa の読みとの間で意図が割れる。
  - 実装は条件の一つで小さい。`~-x` は意図が一つなので候補を残す。
- 影響: 仕様は変えない（候補の形は約束でない）。`spec/foreign-forms.toml` の `faust_bit_not` に候補の無い `~!m` の例。作業は W5-11 の S-961 と同じ単位。
