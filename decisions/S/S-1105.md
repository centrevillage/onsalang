# S-1105 細部: flow の本体の、入力・項目・型・組込みの名前への代入の E0806 に付ける note（`let` で定義した名前と同じ累積の形を示すか）

- 空白: §18.1 は flow の本体の代入（E0806）を「代入先がまだ定義されていなければ `let` を付ける修正候補を示す。定義済み（`let y = 0.0` の後の `y = y + x`）なら、累積の意図なので、修正候補は付けず、`let y = prev~(^y) + x` と書く形を note で示す」とする。代入先が入力（`x = 2.0`）・項目（`g = x`）・型（`Pt = x`）・組込みの名前のときが決まらない。
  読み: (1) 「定義済み」は名前が見えること全般で、同じ note を付ける（`let x = prev~(^x) + x` は入力の名前と重なり E0304 になる書き方）。(2) `let` で定義した名前だけに付け、他には付けない。通るプログラムは変わらない（note の文面は約束でない）。
  W7-04 U1b の実装は (1)。再現は `target/notes/158/w704/u1b/b/assign/a.onsa` の `tgt_input`・`tgt_item`・`tgt_type`。
  仮の扱い: (2)（親。書けない形を勧めない方が保守的）。W7-04 U1b の直しで入れる。
  急ぎ: W7 の区切りで確認だけ（`rules/leader.md` 5.11）。
