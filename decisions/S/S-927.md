# S-927 `?Escape` の型パラメータを持つ struct・enum の型引数に書いた第二級の型 `Rack[Span[F32]]`

- 空白: §4.5 は `?Escape` の無い型パラメータの型引数に第二級の型を書くと E0710 とする。`?Escape` のある struct・enum の型引数（`struct Rack[T: ?Escape] { n: U32 }` の `Rack[Span[F32]]`）に書いた形と、その型の値の扱いは書いていない。`T` はフィールドに置けず（E0710）、置けるのは関数型の引数の並びだけ（`f: fn(T)`）なので、その値は第二級の値を持たない。
  今の `struct H { f: fn(Span[F32]) -> F32 }` は第一級である。今は `?Escape` が E0200。
  読み (a) 今の E0710 のまま書けない（struct・enum の `?Escape` は意味を持たない）。読み (b) 書けて、値は第一級のまま（`H` と同じ）。読み (c) 書けて、その型は第二級で引数の位置だけ。
- 決定: (b)。`?Escape` の型パラメータの型引数には `Span` と平面の配列を書ける（推論でも決まる）。その型の値は第二級にならず、種はフィールドで決まる（`struct Handler[T: ?Escape] { f: fn(T) -> F32 }` の `Handler[Span[F32]]` は `H` と同じく返せて保存でき、`Option[…]` にも置ける）。`T` はフィールドに直接置けないので、値は第二級の値を持たない。
  flow の生成型 `In` / `Out` は §5.3 で束縛できないので、`?Escape` の型引数でも E0710 である（本体の `let y = x` が書けるため。後で緩められる）。`derive` の `PartialEq` などは §6.4 の「型引数が満たすときだけ」のままで、`Rack[Span[F32]]` の `==` は E0401。仕様 §4.5・§4.6（2026-11-06 決定）。
