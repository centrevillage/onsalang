# S-436

- 空白: 文字列の中の `${x}`（`"a${x}"`）。§2.4 の読みでは `$` と `x` の補間（値は `a$3`）で、通る。
  JS / TS のテンプレート（`` `a${x}` ``）を `"` に直して `${x}` を残した書き手は、黙って値に `$` が入る。`$` の後に穴が続く形を誤りにして note で `{x}` を示すか、今のまま（`"${price}"` は「$12」を作る自然な書き方でもある）か。誤りにするなら、`$` と穴を並べる書き方も決める。
  第 24 組の下書きで見つけた（2026-10-11。親が dev の `826fc8a` で、`"a${x}"` が通ることを確かめた）
- 提案: 後の段（急ぎは低。S-406 の note で一部は手当てできる）
- 時期: W3
- 決定: 決定（2026-11-09、利用者。128 回目、共通の規則 S-965 と利用者の判断 B1〜B8、`target/notes/128/r58/decisions.md`）: （出所: R1）`"…"` の中の `$` は普通の文字で、`"${x}"` は `$` と補間（通るまま）。一重の `"…"` の中の `${…}` を補間と読む対象の言語は無い（JS・TS はテンプレートの `` `…` `` だけ。Kotlin・Dart は対象の外）。
