# S-1196 部分式の中の `at` でパラメータの種類の値に刻みのクロックを付けた式（`((p at (sample / 4)) * 2.0) at sample`、`p` は `block`）と、#12 の `let m = p at (sample / 4)` を読む計算した部分式（`(m * 2.0) at sample`）を、値の決まる段（`block`）で評価するか、式のクロックの刻みで評価するか

- 空白: §11.3 は「各式を、部分式も含めて、その値と評価されるかどうかが決まる最も遅い段で評価する」「`at` は値も評価の段も変えず」とし、S-1186 の #12 で「パラメータの種類の値に刻みのクロックを書いた `let`（`let m = p at (sample / 4)`、`p` は `block`）は刻みで書くフィールドを作らない」と決めた。一方で S-1158 の「刻みのクロックの計算した部分式は、より速い式の中でもその刻みで評価し」がある。`(p at (sample / 4)) * 2.0` と `(m * 2.0)` はクロックが `sample / 4` の計算した部分式で、値は `block` で決まる。
  読み: (1) 値の決まる段（`block`）で評価する（`Default` は要らず、値は読む所の `p`）、(2) 式のクロックの刻みで評価して刻みの欄に置く（値は最後の刻みの `p`、`Default` が要る）。刻みの間隔がブロックより長いと、読む値そのものが違う（S-1161・S-1166 の `sample` の形では panic の時期だけが違った）。急ぎ: W7-09 U2r2 の前（評価器 U2a の期待値にも効く）。段 1（onsa-advisor）に回す。
- 決定: 決定（2026-11-21、利用者。172 回目）: (1) を範囲を限って。整理（利用者）は「`at` は変換を行わず、それを読む側の解釈を変える。変換を行うときは変換の flow を呼ぶ」（S-152、§11.3 の「これは値の変換ではない」、S-566・S-567 の K3、S-577）。
  パラメータの種類の値だけで決まる式（数える値は定数・`init`・`block` の入力・`sample_rate()`・`par`・`par~` の添字と、それらだけで決まる `let` の名前とパターンの束縛。`at` と括弧を通し、条件・対象・ガードを含める）は、`at` で付けたクロックによらず値の決まる段で評価し、刻みで書くフィールドを作らない（`((p at (sample / 4)) * 2.0) at sample` は読む位置の `p` の 2 倍。格子の刻みで取った値は `.down~(N)` の部品か `prev~(p at (sample / N))`）。刻みの値を一つでも読む式は今の字のまま、その式のクロックの段（S-1158 (c) の直し方「読む名前に `at`」と S-567 の E6 は改めない）。
  `at` で付けたクロックは、クロックの検査と、式のクロックが時機を決める所に効く: 遅延の第 1 引数、帰還の輪、`reset_if~` の条件、イベントの出力の式、条件の位置を選ぶ条件（利用者: 「`if` などの条件式に入れた場合は、評価のタイミングは `at` の刻みになる。`at` は変換はしないが、使う側の解釈は変える」）。条件が決まる段は、評価する段と、条件の式のクロック（`at` を含む）の段のうち速い方（S-1157 の「`at` は段を変えない」を改めた）。S-1161 は (2)、S-1166 は (1) の向きで揃う。
  条件に `at` を書いた式は、全体がパラメータの種類の値でも条件が決まる段で選ぶ（利用者が (ii) を選んだ。監査の推した「全体がパラメータだけなら式の段」(F1) は採らない）: `let y = if (d != 0) at sample { 100 / (d - 1) } else { 0 }` は `sample` の段で割り算は届いたとき、`let m = if (c at (sample / 4)) { p } else { 0.0 }` は `sample / 4` の刻みで選び次の刻みまで保つ（刻みの欄、`Default`）。
  経緯の補い: 字の監査（onsa-advisor）で、`at` を全ての値で透かす案 (A) は S-1158 (c) の直し方と E6 を改め、値の変わる形が五つ出ると分かり、範囲を限った (C) を親と助言の担当が推した。親はイベントの値の読みを E6 を確かめずに書いた誤りを訂正した。条件の位置の一句で、(C) で誤りになるはずだった形（`if (p at (sample / 4)) > 0.0 { l4 * 2.0 } else { 0.0 }`）は通るままになる。代わりに、条件に `at` を書いて速くした形が E0815 になる（利用者が了承）: A1 `if (a != 0) at sample { x * F32.round_from(mk(a)) } else { x }`（`a` は `init`、`mk` は rt でない fn。今の実装で通る。条件が `sample` で決まるので §11.5 の E0815）、A2 `if (c4 at sample) { (l4 * 2.0) at sample } else { x }`（`c4`・`l4` は `sample / 4`。字では書けた。S-1158 (c) の E0815、刻みの `let` に分ける）。周期の刻みの守り付きの欄は、定数・`init` の条件の下にだけ残る。親は先に「今の字で書ける形を誤りにする形は無い」「S-1157 は条件の `at` を議論していない」と利用者に誤って伝え、3 回目の監査の後に訂正した。仕様 §11.3、§11.5、§11.10、§11.11。実装は W7-09 U2s。控え `target/notes/172/s1196/`（段 1、監査 2 回）。
