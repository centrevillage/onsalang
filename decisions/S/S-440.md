# S-440

- 空白: 補間の穴の中の空白・キーワード・`_`（`"{ a }"`、`"{a }"`、`"{fn}"`、`"{let}"`、`"{_}"`、`"{true}"`、`"{Self.N}"`）。§2.4 は「補間に書けるのは名前の経路」とする。今は空白の形が E0001、`{fn}`・`{let}`・`{_}`・`{true}` が E0302。
  親の読み: 名前の経路は空白を含まず、頭は名前か `self`・`Self`（`.` の後のキーワードは名前、S-357）で、それ以外のキーワード、`_`、リテラル（`true`）、空白は E0001（S-90 の文面と note）。予約語の頭は E0200（S-371）。W3-04/t と W3-04/i が見つけた（2026-10-11）
- 提案: 決定（2026-10-11、利用者が ID を挙げて親の読みを了承、確認だけ）: 名前の経路は空白を含まず、頭は名前か `self`・`Self`、`.` の後のキーワードは名前（S-357）。他のキーワード、`_`、リテラル（`{true}`）、空白を含む形は E0001（S-90 の文面と note）、予約語の頭は E0200（S-371）。仕様 §2.4。実装は W3-04
- 時期: W3
