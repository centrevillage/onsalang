# S-678 名前の段で失敗した `use`（E0302）が E0310 の辺を張るか（`use fx.b.{g}` と `use fx.a.{f}` の取り込み合い、最後の名前が見つからない `use`）

- 空白: §15.1 は「依存は `use` だけで決まるので、この検査は `use` の一覧で閉じる」とし、モジュールを取り込む `use` を下の全てのモジュールへの依存として数える（S-594）。名前の段で失敗した `use`（E0302）を依存に数えるかを書いていない。§18.1 は失敗した `use` の名前を束縛として数えない（E0304 の相手にしない、S-462）が、辺には触れない。
  形は二つある。(i) 頭が解決しない `use`（自分のパッケージ名の `use fx.b.{g}`、S-663 の候補で外す形）。`tests/review-phase1/types/cyc3` は `use fx.b.{g}` と `use fx.a.{f}` で取り込み合い、今は E0302 が二つで E0310 は無い。
  (ii) 頭は解決し、途中か最後の名前が見つからない `use`（`use b.nosuch.{x}`）。W4-03 U1 の設計メモ（3.2）は「経路の最後が見つからない `use` も、頭のモジュールまでは書いた依存として数える」とした。
  読みは、(1) 失敗した `use` は辺を張らない、(2) 解決した経路の範囲で辺を張る、(3) 書いた経路から意図したモジュールを読んで辺を張る（(i) で候補を当てた後の形）、がある。候補を一つずつ当てると、(1) と (2) では E0302 が一つずつ減って最後に E0310 が出るが、(3) では各候補が E0310 を残す。
  仮の扱いは W4-03 U3a2 のテストの票のとおり (i) は辺を張らない（`tests/spec/fixes/pkg_own_name_mutual`）。(ii) は設計メモのとおり頭のモジュールまで数える。

- 補い（2026-10-25、親）: W4-03 U3a2 の壊す側（67 回目）: 仮の扱い (ii) では、E0310 が失敗した `use` の全体に付き、同じ `use` の E0302 が単位ごとに一つの規則で出なくなる。
  最後の名前（`use b.{nosuch}`）、途中の名前（`use b.nosuch.{x}`）、列挙子を取り込む `use b.Color.{Red}`（`target/notes/67/w403/u3a2/b/t/c_m3_missing_last.txt`・`c_m4_missing_mid.txt`・`c_m7_enum_variant_use.txt`）。
  U3a2 の前は E0302 と E0310 が別のファイルに出ていた。
