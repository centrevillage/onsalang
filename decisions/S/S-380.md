# S-380 パターンの選択の `|` の置き場所

- 空白: `match` の腕のパターンの選択の `|` を行頭に置く形（`0` 改行 `| 1 =>`）と行末に置く形。今はどちらも通り、fmt が一行にする。パターンの `|` は式の演算子でなく選択の区切りで、§2.5 の行頭の演算子の規則（S-124）にも括弧の中の置き場所の規則（S-370）にも当たらない。第 16 組の下書きの S-370 の「あわせて決めること」を、Fable の指摘で別の項目にした（2026-10-09）
- 提案: 決定（2026-10-10、利用者が ID を挙げて推奨の (a) を了承。下書きと Fable が一致、第 17 組）: パターンの選択の `|` は二項演算子と同じく行末に置く。行頭の `|` は E0020（データのファイルの `leading_operator` の例）で、候補は前の行の末尾へ移す形。選択肢が複数行にわたる形は S-124 と同じく一つずつ直す。最初の選択肢の前の `|` は S-383 で決める。仕様 §2.5。実装は W3-06
