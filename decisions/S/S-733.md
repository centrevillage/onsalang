# S-733 署名の型の位置と定数式に引数の名前を書いたとき（`fn f(n: U32, a: [F32; n])`、`fn f(n: U32, a: n)`）、S-713 (a1) の引数の E0417・値の E0308 か、署名は引数を見ず E0302 か

- 空白: §15.1 は「値やモジュールを型の位置に書く」を E0308 とし、S-713 (a1) は定数式の位置の「値だが定数でない名前（関数、列挙子、ローカル、引数）」を E0417 とする。署名（引数の型、返り値の型）が、同じ署名の引数の名前を引くかは書いていない。
  読みは二つに割れる。(1) 署名も引数の名前を引き、型の位置は E0308、定数式は E0417。(2) 署名は引数を見ず、見つからない名前の E0302（今の実装）。本体の注釈の同じ形は S-729。
  今の実装（`P78/bin/onsa-7560d6e`）: `fn p4(n: U32, a: [F32; n])` は E0302「cannot find `n`」。再現は 78 回目の scratchpad の `g68/parent/a.onsa` の 16 行（写しは `issues/R/R-304/local_lengths.onsa`）。
- 決定: 決定（2026-10-28、利用者が ID を挙げて了承。確認だけ。79 回目、第 69 組）: (1a)（S-741 の規則から）。
  署名（引数と返り値の型、効果行、境界）は同じ署名の全ての引数を引く。型の位置は E0308、型の中の定数式は E0417（`fn g(n: U32, a: [F32; n])`）、境界の `fn f[T: n](n: I32, x: T)` は E0308（文面は既存の「`n` is a local, not a trait or a kind constraint」）。メソッドの署名の `self.N` は本体と同じ E0417 で、note は足さない。
  仕様は §5.1 の S-741 の文に含まれる。実装は W4-19（S-741 の実装の点）。事例は `tests/spec/type_names/` に署名の形（前の引数、後ろの引数、自分、返り値、境界、`self.N`、`n.T`）と、`tests/spec/fixes/e0320_type_place_uses.onsa` に署名の `_n` の E0320 の候補が使用も直す形を足す。
- 経緯: 78 回目（2026-10-28）、第 68 組の S-729 の下書き（onsa-gap）が新しい S の候補として挙げた（78 回目の scratchpad の `g68/draft.md`（区切りで `target/notes/78/g68/` へ写す））。S-729 の答えで読みが絞れるので、第 68 組の後の組で決める。期限は名前の検査の残りの W4-06 の前。関係: S-729、S-713。
