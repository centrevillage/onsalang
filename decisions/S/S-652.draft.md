# S-652 E0320 の改名の候補が、同じ範囲の既にある名前と重なる（`[Item, Item_]` の候補で `[Item, Item]`、`struct Item` と `struct Item_`）

- 位置付け: 族「§2.3 の名前の形」（S-650、組 52）の一つ。試した入力と独立のレビューは `S-650.draft.md`。
- 論点: §2.3「E0320 の修正候補は一つで、宣言と、パッケージの中の全ての使用箇所の名前を直す」（S-82）。直した名前が同じ範囲の別の宣言と同じになるとき（`pub fn foo` と `pub fn Foo`、`struct Item` と `struct Item_`、`fn f[Item, Item_]`、`let x = 1` と `let _x = 2`）に候補を出すかが書かれていない。
  §18.1 は「この約束を満たす候補を作れなければ、候補を出さない」とし、E0320 と E0304 はどちらも名前の段の診断（`naming.rs` の `Stage::Names`）なので、重なる候補を当てると同じ段の E0304 が残る。
  - 決定済み（論点から外す）: 全ての使用箇所を直すこと（S-82、W4-04）。重なりそのものが誤りか（型パラメータは S-649、族の外。項目と束縛は §5.1 の E0304）。
- 今の実装: `pub fn foo` と `pub fn Foo` は E0320 で候補 `foo`、当てた形は E0304「`foo` is already declared in this module」。`struct Item` と `struct Item_` も候補 `Item` で、当てると E0304（`target/notes/62/gap52f/probe/dup_*.onsa`）。`fn f[Item, Item_]` の候補 `Item` を当てた `[Item, Item]` は通る（S-649、`target/notes/62/gap52/probe/c/c2.onsa`）。
- 案:
  - (a) 直した名前が、改名する宣言の見える範囲（同じモジュールの項目、同じ並びの型パラメータ、同じスコープの束縛）にある名前と同じなら、候補を出さず note で規則に揃えた名前を示す。重なりを見るには名前の段の記録が要る（S-82 の使用箇所を集めるのと同じ記録）。
  - (b) 重ならない別の名前を作る（末尾に数字を足す `Item2` など）。規則に揃えた名前と違う規則が一つ増え、足した名前がさらに重なれば繰り返す。
  - (c) 重なっても候補を出す（今の実装）。当てると同じ段の E0304 が残り、§18.1 の約束に反する。S-649 が型パラメータの重なりを誤りにしなければ、`[Item, Item]` は黙って二つの型パラメータを一つの名前にする。
- 他言語: rustc 1.94.1 の命名の lint の help は重なりを見ずに名前を示す（`fn Bad` は `bad`。適用は機械の修正の印を付けない。重なる形は未確認）。
- 推奨と理由: (a)。確度: 中〜高。重なるときは候補を出さず、note で規則に揃えた名前を示す。
  - §18.1 の約束から一つに決まる。(c) は約束に反し、(b) は書き手の意図でない名前を全ての使用箇所に広げる（候補は書き手の意図が一つに決まるときだけ出す）。
  - 重なりは、候補を作る規則（S-650 の族の規則）に依らず全ての種類に当たる一般の問題で、どの案の族の規則でも残る。頭の `_` を禁じる族の規則（S-650 の (α)・(γ)）では `let x` と `let _x` の形が増える。
  - 実装は W4-04 の名前の段で、S-82 の使用箇所の改名と同じ記録から重なりを見る（約 15〜30 行、見積もり）。それまでの W4-14 U3 では、同じ並び（`[Item, Item_]`）だけを構文の段で見るか、W4-04 まで今のままにするかを U3 の設計で決める。
  - あわせて決めること: 重なりの判定の範囲は、§5.1 の「見えている束縛」（モジュールの項目、`use` の名前、prelude、組込み型）と同じにする（`struct F32_` の候補 `F32` も重なる）。
- 影響: 仕様 §2.3 の E0320 の候補の文に「直した名前が見えている名前と重なるときは候補を出さない」を足す（§18.1 は変えない）。診断のコードは E0320。作業は W4-04（S-82 と同じ回）、S-649（型パラメータの重なりの判定）と関係する。
  事例: E0320 の候補の事例に重なる形を足す。今の事例の期待値に重なる形は無い（`tests/spec/fixes/e0320_rename.onsa` は重ならない）。
- 回答（2026-10-24、62 回目、会話）: A-8 として「A1-10: OKです。」
