# S-1158 刻みのクロック（イベント、`sample / N`）の計算した部分式を、より速い式の条件の位置（枝・ガード・短絡の右辺）に書いた形の評価（位置で評価すると値が変わる）と、巻き上げた欄の最初の刻みの前の値

- 空白: §11.3 の「巻き上げても値は変わらない」は、パラメータの種類（`init`・`block`）の式にだけ成り立つ。刻みのクロックの式は「その刻みごとに評価する」（§11.11）もので、イベントの段の式は `block` の値と `sample_tick()`（「その位置の値」、§11.4）を読み、`sample / N` も刻みの間にブロックの境目が来うる。
  そのため、刻みのクロックの計算した部分式を、より速い式の条件の位置（`if c { F32.round_from(m.note) * r } else { 0.0 }`、`m` はイベント、`c` は `sample`）に書いて位置で評価すると、留まる値でなく今の値になり、同じ式の値が枝の中か外かで変わる。
  読み: (i) 位置で評価する（値が変わる）、(ii) 刻みのクロックだけは条件の位置でも段で評価する（取られない枝でも panic し、条件の位置に欄を置く）、(iii) 誤りにする（刻みのクロックの計算した部分式は条件の位置に書けず、前の `let` に出す。名前を読むのはよい）。
  あわせて、イベントのクロックの部分式を巻き上げた欄の、最初のイベントの前の値（§11.11 は「最初のイベントの前は `T.default()`」。`init` で既定値の入力から計算するか、欄の型の既定値を置くか。式が `block` の値を読むと `init` では計算できない）。
  今はクロック `event` が E0302、`sample / N` の構文が E0002 で試せない。
  関係: 族の規則 S-1157（`init`・`block` の巻き上げ）、第 113 組の段 1 の想定漏れの表の行 23〜25（`target/notes/168/g113/stage1_report.md` の N1）。
- 決定: 決定（2026-11-20、利用者。170 回目、第 115 組）: (c)。刻みのクロックの計算した部分式は、より速い式の中でもその刻みで評価して欄に置く。条件の位置では、選ぶ条件が全て定数・`init`・同じ刻みで決まるときだけ書け、守り付き（条件が成り立つ刻みだけ）で評価する。他の段（`block`、別の刻み、`sample`）で決まる条件の位置は E0815（前の `let` に出すか、読む名前に `at`）。欄の初めの値と `reset` の戻り先は (α) `T.default()`（`Default` でなければ E0816）。守り付きの刻みの欄は今実装する（当面 E0200 にしない。利用者）。利用者は既決の `init`・`block` の規則（§11.3、S-1157）との整合を問い、親が「守り付き・届いたときに計算・計算できない所は E0815」の三つの扱いで (c) が揃うと答えた。§11.3 に入れた。下書き・段 1（次点 (c′)）・親が (c)。
- 経緯: 168 回目、2026-11-19、第 113 組の独立のレビューの段 1（onsa-advisor）が下書きの見落としとして挙げ（下書きの「新しい S の候補」の最初のイベントの前の値を含む）、親が登録した。W7-09（`sample / N`）の前に決める。S-1157 の文は `init`・`block` に限って書く。
