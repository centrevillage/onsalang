# S-349

- 空白: S-320 の `a--b` の E0020 に、`--` の前に空白がある `a --b` を含めるか。決定の文は「空白を空けずに書いた形」とだけ書く。W3-07 の実装は含める（候補 `a - -b`、`SPEC-GAP(S-349)`）。`a-- b`・`a---b` は増減の E0002。
  W3-07/b で見つけた（2026-10-09） 追加の形（2026-10-10、RF/t）: 後ろが改行の `let c = a --` 改行 `b`（今は E0002、候補なし。`a --b` の同じ行は E0020 で候補 `- -`）と、コメントを挟む形。
  前置の `-` の後の改行（S-369）として E0020 で二つ目の `-` を次の行へ移すか、増減の `--` として E0002 か。
- 提案: 後の段
- 時期: W3
- 決定: 決定（2026-11-09、利用者。127 回目）: (c)。`--` の前後の同じ行の空白（`a --b`、`a-- b`、`a -- b`、タブ）は S-320 の E0020 で、候補 `a - -b` が隙間も除く（並びの中でも候補は一つで、`,` の挿入は並べない）。
  行末の `--` の後の改行（`a --` 改行 `b`、間の行コメント、括弧の中）は継続の規則で行が終わり、増減の E0002 のまま（文の位置の `x --` は S-429）。`a -- -b` は増減の E0002。§2.5 に書いた。
