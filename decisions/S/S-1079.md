# S-1079 同じ位置の、比の違う遅い刻みどうしの順（`sample / 4` と `sample / 2`）

- 空白: §11.9 は「同じ位置では、入力のイベントの刻み、遅い刻み、`sample` の刻みの順に並ぶ」とし、遅い刻みどうしの順を書かない。
  読み: (1) 遅い方が先（`a at (sample / 2)` が同じ位置の新しい `a` を読む）、(2) 決めない（前の値を読む）。段 1 の見立ては (1)（§11.3 の段の順の原則と §13.4）だが、`sample / N` から別の `sample / M` への `at` を §11.3 の「行き先は本体の `sample` まで」がどう読むかに依る。
  今: 構文が無く E0002。
- 決定: 決定（2026-11-16、利用者。157 回目、第 105 組。確認だけの一覧で了承）: S-1077 の順。`a at (sample / 2)`（`a` は `sample / 4`）は昇格し、逆向きの `b at (sample / 4)`（`b` は `sample / 2`）は E0815。同じ位置は、入力のイベントの刻み、遅い刻み（遅い順。同じ比は本体の式の順）、`sample` の刻みの順。`.down~(N)` の部品が `sample * M` の入力を集める範囲は、入力のクロックの直前の M 刻み（W7-16 で事例）。
- 経緯: 157 回目、2026-11-16、X-26 の W7 の見積もり（組 C）と仕分けの段 1（onsa-advisor）が挙げ、利用者が一覧で登録を了承した（X26-26）。
