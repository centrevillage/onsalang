# S-1079 同じ位置の、比の違う遅い刻みどうしの順（`sample / 4` と `sample / 2`）

- 空白: §11.9 は「同じ位置では、入力のイベントの刻み、遅い刻み、`sample` の刻みの順に並ぶ」とし、遅い刻みどうしの順を書かない。
  読み: (1) 遅い方が先（`a at (sample / 2)` が同じ位置の新しい `a` を読む）、(2) 決めない（前の値を読む）。段 1 の見立ては (1)（§11.3 の段の順の原則と §13.4）だが、`sample / N` から別の `sample / M` への `at` を §11.3 の「行き先は本体の `sample` まで」がどう読むかに依る。
  今: 構文が無く E0002。
