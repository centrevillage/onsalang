# S-809 第二級の関数値（既定のモードの関数型の引数、捕捉する無名関数）を、関数型でない既定のモードの引数（総称の `T`、組込みのメソッドの引数）へ渡せるか（`id(f)`、`fs.fill!(fn(x) { x + k })`）

- 空白: §5.2 の 87 行は、既定のモードの関数型の引数（`f: fn(I32) -> I32`）を関数の中で第二級とし、「呼ぶことと、別の関数の既定のモードの関数型の引数へ渡すことはでき、返す、保存する（`let` / `var` の初期化、代入、フィールド、要素）、無名関数で捕捉する、`move` の引数へ渡すと E0710」とする。
  §5.3 の 102 行は捕捉する無名関数を「既定のモードの関数型の引数（§5.2）に渡せる」とし、92 行は第二級の値を「引数の位置にだけ現れる」とする。
  関数型でない既定のモードの引数（総称の `T` の引数 `id(f)`、組込みのメソッドの引数 `fs.fill!(f)`）へ渡す形は、できる側の列挙にも E0710 の列挙にも無い。関数型 `fn(I32) -> I32` は Copy の第一級の型（§4.1）なので、`T` に入っても型の種では止まらず、`T` の本体は値を写して返せる（`id(f)` の結果を `let` に保存できる）。
  読み: (1) 既定のモードの引数は全て「引数の位置」で、渡せる。(2) 渡せるのは関数型の引数だけで、`T` と組込みのメソッドの引数は E0710。(3) 本体が値を写せない引数（`T: ?Dup` など）にだけ渡せる。
  dev（`6de1620d`）はどの形も通す（捕捉する無名関数の `id(fn(x: I32) -> I32 { x + k }).(1)` と `fs.fill!(fn(x: I32) -> I32 { x + k })` も）。再現は `target/notes/92/w411/i/probe/forms.onsa` の g1・g6・g7・g15 と `given/fnparam.onsa` の f14。
- 決定: 決定（2026-10-31、利用者。92 回目）: (2)。第二級の関数値（既定のモードの関数型の引数、捕捉する無名関数）を渡せるのは、宣言の型の頭が関数型（別名を通してもよい）の既定のモードの引数だけである。型パラメータの引数（境界によらない）と組込みのメソッドの引数へ渡すと、渡した値の位置で E0710（`if`・`match`・ブロックの末尾と括弧は位置を継ぐ）。修正候補は無い。
  組込みのメソッドの引数は、第 1 期に関数型のものが無いので関数型でない扱いにする。関数型の引数を持つ `map_err` を入れる W5-02 が、宣言の型を検査に渡す。`id(move f)` は E0703（`move` を消す候補）を出さず E0710 だけ（当てた後に E0710 が残るので、§18.1 の 27 行。W4-11 の設計メモの審査の B1、利用者が了承）。仕様 §5.2 の 87 行に足した。
  理由: §13.5 の 91 行の表現（既定のモードの関数型の引数は関数と環境の組、保存できる関数値は関数だけ）を保つため。型パラメータの本体は値を写して持ち出せる。実装は W4-11。
