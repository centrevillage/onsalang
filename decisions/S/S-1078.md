# S-1078 導くクロック `at (sample / N)`・`at (sample * N)` の N の形・型・制約とコード

- 空白: §11.3 は「`at` の後ろは名前一つか、括弧で包んだ導くクロック（`(sample / N)`、`(sample * N)`）で、経路（`x at a.b`）は E0002」とする。§4.5 の大きさの位置の一覧に N は無く、2 のべき乗の制約は §11.9 の修飾子の N だけに書かれる。底が `sample` でない形（`(block / 2)`）のコードも書かれない。
  読み: (1) N は整数のリテラルだけ、(2) 定数式で `U32`、2 以上の 2 のべき乗（違えば E0808・E0417 の類）。N が 2 のべき乗に限られるかで、比の合成が閉じるか（クロックの表現）が変わる。
  今（`f74bfef`）: 導くクロックの構文が無く、`at (sample / 4)` も `(block / 2)` も E0002。量（組 C）: N を整数のリテラルだけにすると構文は約 30 行、定数式にすると 60〜80 行。
- 決定: 決定（2026-11-16、利用者。157 回目、第 105 組。底は (b)「導くクロックの件は(b)で」、他は確認だけの一覧で了承）: N は S-1077 の規則。括弧の中は、底の名前一つ、`/` か `*`、N の被演算子一つ（§4.5 の定数式の単項の形）で、他の形（他の演算子、逆の順、連ねた `(sample / K * 2)`、括弧だけの `(sample)`、二重の括弧）は構文の段の E0002（note で二つの形を示す。`(sample)` は今のまま候補なし）。
  底はクロックの名前空間で引き、無い名前は E0302（S-359 のまま）、flow の外は引かずに E0821。`sample` でない底（`block`・`init`・`event`）は、入出力の宣言では E0810、式では E0815。式に書ける導くクロックは `(sample / N)` だけで、式の `e at (sample * N)` は E0815（S-567 の K3 で誤りと既決、候補なし）。
  宣言の括弧の無い `at sample / 4` は E0002 で、候補は括弧で包むこと。式の括弧の無い `x at sample / 2` は E0011 のまま、今の候補 `(x at sample) / 2` に `x at (sample / 2)` を並べる（`/` で、右が整数のリテラルか定数の名前のときだけ）。
  理由（底）: S-359 の「`at` の後ろの名前はクロックの名前空間で引く」に例外を作らず、構文解析器にクロックの名前の綴りを持たせない。flow の外の崩れた形が一度で E0821 になる。種類の検査は今も宣言（名前の段）と式（flow の段）に分かれていて、そこに一行ずつ足す。
