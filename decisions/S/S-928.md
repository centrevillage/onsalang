# S-928 `?Escape` の `T` を書ける宣言の位置

- 空白: §4.5 は `T: ?Escape` を「第二級の型を置けない位置（返り値、フィールドなど）」に書いた宣言を E0710 とする。引数の根の下の `x: Option[T]`、`x: (T, U32)`、`move x: T`、`k: fn() -> T` を書いていない。今の `Span[F32]` は、この全てが E0710 で、`[Span[F32]; 2]` と `fn(Span[F32])` は書ける。
  読み (1) `T` の位置の判定は `Span` と同じ。読み (2) 根の下でも通す。
- 決定: (1)。`?Escape` の `T` の位置の判定は `Span` と同じである。`x: T`、`inout x: T`、`x: [T; N]`、関数型の引数の並びの `T`（`f: fn(T)`、フィールドの `fn(T) -> F32`）は書ける。`move x: T`、`Option[T]`、`(T, U32)`、`Span[T]`、`k: fn() -> T`、`[[T; 2]; 3]`、返り値、フィールド、`?Escape` の無い型パラメータの型引数は E0710。
  仕様 §4.5（2026-11-06 決定）。
