# S-262

- 空白: 発散する式だけが決める型変数（`let x = { return }`、`let x = if c { return } else { return }`）。§7 は発散を表す型を書けず、どの型の位置にも置けるとし、§4.7 の E0406 の起点の例（`None`、`none()`、`Buf.zeroed(4)`、`[]`）に発散するブロックは無い。今は検査を通り、降下で内部エラー（unresolved type、101）。W2-06/b で見つけた（2026-10-08）
- 提案: 決定（2026-10-08、利用者が ID を挙げて了承。親の案: 型が決まらないので、§4.7 の一般の規則どおりその式（ブロック、`if`）に E0406。条文は起点の例を一つ足す程度）。W2-06 の直しで実装（関数の終わりに残った型変数を全て拾う網）。S-268 で例を改めた（`let x = { return }` は束縛の E0503。E0406 は `let` でない位置の網として残る。W5-08）
- 時期: W2
