# S-936 誤りの型の列を含む腕の到達（E0503）

- 空白: §18.1 は誤りの型の部分を「`match` の網羅性では何にでも一致する」と読むが、到達しない腕（E0503）の判定での読みを書いていない（S-692 の補い (A2) は E0501 だけを決めた）。同じ問いが、構文の誤りで読めなかった型の列（S-260）にもある。
  読み (1) 到達でも何にでも一致すると読み、前の腕が後の腕を覆えば E0503 を出す。読み (2) 到達ではその列を持つ腕は到達すると読み、E0503 を出さない（今の実装、W5-09 U2）。
  例 `struct Z { z: Zork, b: Bool }`（`Zork` は見つからない名前）の `match q { Z { z: _, b: _ } => 1, Z { z: _, b: true } => 2 }`。(1) は 2 つ目の腕に E0503、(2) は E0302 だけである。
  (1) は `Z { z: 1, b: _ }` の後の `Z { z: 2, b: _ }` も覆われたと読むので、誤りの型の症状の E0503 が出る。(2) は本物の E0503 を、元の誤りを直した次の検査まで出さない。どちらも通るプログラムは変えない（元の誤りで通らない）。
- 決定: （未決）親の読み: (2)。§18.1 の「症状を出さない」に合い、誤りの型を直せば次の検査で E0503 が出る。
