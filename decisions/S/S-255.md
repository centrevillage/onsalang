# S-255

- 空白: 後回しにした型の検査（S-235 の要求、リテラルの範囲と符号なしの `-`、S-174 の E0406）の報告の順。(i) 同じ文の中に要求の誤りと別の型の誤りがあるとき、(ii) 同じ時点で満たさない項目が複数あるとき、(iii) 後で型が決まる `-(-1)`（`let a = -(-1)` の後に `let b: U8 = a`）の E0401 をどちらの `-` に出すか。
  §4.5・§4.7 は検査の時点だけを書き、§18.1 の「位置が最初のもの」は段の間の規則。S-235 の Fable のレビューと W2-06/i で見つけた（2026-10-08）
- 提案: (i) 要求は文の検査の後に検査するので、文の中の誤りが先。(ii) 同じ時点の項目は、検査が項目を作った順（被演算子が演算子より先）。(iii) (ii) の帰結で内側の `-1`。型がすぐ決まる `-(-1): U32`（R-163）と同じ位置（親の案、利用者が了承。仕様 §4.7。2026-10-08 決定。W2-06 で実装済み）
- 時期: W2
