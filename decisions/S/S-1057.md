# S-1057 `rt` の無名関数の本体の名前で決まる呼び出しを、外側の `rt` の関数の再帰（E0903、§10 の規則 5）の辺に数えるか

- 空白: §10 の規則 5 は「呼び先が名前で決まる呼び出しの循環」を E0903 とし、「関数値を経る呼び出しは数えない」とする。`rt` の無名関数の本体に書いた名前で決まる呼び出しを、外側の `rt` の関数の辺に数えるかを書かない。今は数える。
  再現: `target/notes/150/w603/review/a3.txt` の `rt_recursion_via_closure`（今は E0903@2:30）。
  `rt` でない無名関数の本体の呼び出しは、§8.1 の「`rt` でない無名関数の本体は、外側が `rt` でも `rt fn` の規則で検査しない」と、規則 5 が §10 の `rt fn` の検査規則の一つであることから、辺に数えないと読める（確認だけ。W6-03 の審査）。今は数えるが、R-451 の E0901 が先に出るので見えない（`a3.txt` の `rt_recursion_nonrt_closure` は E0901@3:23）。W6-03 の U5 で R-451 が直ると、数えたままでは偽の E0903 になる。
  読み: (1) 数える（今のまま） (2) 数えない（無名関数の値の呼び出しを経て初めて呼ばれるので、関数値を経る呼び出しとして扱う）。
  急ぎ: W6-03 の U5（無名関数ごとの仕分けと E0903 の辺）の前。
- 決定: 決定（2026-11-14、利用者。150 回目。段 1 の選択と親の読みが一致し、段 2 は省いた）: (2) 数えない。§10 の規則 5 の辺に数えるのは `rt` の関数の本体そのものに書いた呼び出しで、無名関数の本体に書いた呼び出しは、`rt` の無名関数でも、それを書いた関数の辺に数えない（無名関数は関数値としてだけ呼ばれるので、無名関数を通る循環は関数値を経る循環）。
  理由: (1)・(3) は書き方だけで結果が変わる（名前の関数を値で渡す `ap(b, n)` は通り、同じ値を無名関数で包む `ap(fn(y) { b(y) }, n)` は E0903）。再帰しない形（無名関数を作って返すだけの `mk`）も拒む。規則 5 の目的のスタックの上限は、`.()` に届くエントリが §12.5 で「不明」なので、数えても計算できるようにならない。§8.1 の「外側が数えるのは関数値の呼び出し」と同じ原則で規則が増えず、Core の `rt_cycles`（値として使った関数は呼び出しでない）と揃う。代償: `rt` の無名関数を通る本当の再帰が `check` を通る（上限は「不明」）。後で (1) に戻すと通るプログラムが止まる。この版は無名関数と `.()` の降下が E0200 で、実害は小さい。
  実装は W6-03 の U5（辺を本体の範囲の呼び出しに絞る。`unread.rs::rt_held` も同じ集め方）、正例を 2〜3 件。仕様は §10 の規則 5 に 2 文。
