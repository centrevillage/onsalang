# S-794 `[T; N]` の `get(i) -> Option[T]` で、要素の型 `T` が Dup でないとき（借用の配列から Affine の要素を所有の値として取り出せる）

- 空白: §5.3 の `Span[T]` の行は、メソッド `get(i) -> Option[T]` を挙げ、「`[T; N]` と `Buf[T]` にも同じものがある」とする。§5.2 は「配列の要素は取り出せない（`move xs[i]` は E0711）」とする。
  要素の型 `T` が Dup でない `[T; N]`（`[Buf[F32]; 2]`）の `get` が、借用の配列から Affine の要素を所有の `Option[T]` として返すかを決めていない（`Span` と `Buf` は要素が Copy でなければ E0416 なので、当たるのは `[T; N]` だけ）。
  dev（`9804880`）は、借用の `xs: [Buf[F32]; 2]` から `let a = xs.get(0)` と `let b = xs.get(0)` を通し、同じ要素を二つ所有する（再現は `target/notes/87/get_affine.onsa`）。組込みの表は `get` を全ての列の受け手に置く（`crates/onsa_sema/src/builtin.rs` の `Recv::Seq`）。
  関連: 仕様に無い組込みのメソッド（`unwrap_or`、`is_some`、`is_none`、`is_ok`、`is_err`）も同じく借用から中身を返すが、W5-03 が取り除く（R-96）。
  読み: (1) `get` は要素の型が Dup のときだけ（Dup でなければ E0413 か E0401、`match`・添字の借用の形を note）。(2) `get` を残し、Dup でない要素は別の形（借用の `Option` は第 2 期）にする。
  急ぎ: W5-02（組込みのメソッドの閉じた一覧）の前。W4-07 は組込みの受け手のモードを読むだけで、`get` の判定は変えない。
