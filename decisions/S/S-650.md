# S-650 族: §2.3 の名前の形

- 空白: §2.3 は名前の種類ごとに形（`snake_case`・`UpperCamel`・`UPPER_SNAKE` と、型パラメータ・効果行変数の「1 語」）を決め、「大文字と小文字で種別を決める」とするが、各形の定義（頭と末尾の `_`、大文字の並びと数字の語の境）を書いていない。
  名前を扱う三つの所が、それぞれ別の判定を持つ: (1) 名前の規則の検査（E0320、`crates/onsa_syntax/src/naming.rs` の `Shape::matches`）、(2) 字面で種類を決める所（`[…]` の型パラメータと効果行変数は `parser/signatures.rs` 106 行の先頭の小文字、パターンの束縛は `naming.rs` の `is_binding_name` の先頭の小文字、定数は `is_constant_name`、`Name {` の構造体リテラルは `is_type_name` の先頭の大文字）、(3) 修正候補の作り方（`convert`・`split_words`、S-243 の予約語の `_`）。
  そのため同じ名前を所によって違う形と読む（`fn _g` は通るが `let _x = 1` は束縛の位置で E0302、`[_e]` は型パラメータ、`struct Self_` の候補が元の名前に戻る R-260）。
  族の S: S-642（型パラメータと効果行変数の「1 語」）、S-648（字面で種類を決める所の `_` で始まる名前）、S-375（`UpperCamel` と `UPPER_SNAKE` の両方に合う `A`・`OK`・`N`）、S-651（各形の定義と、受理と候補の語の分け方）、S-652（改名の候補が既にある名前と重なる）。関係: R-260（候補が元の名前と同じになる実装の誤り、W4-14 U3）。
  族の規則: 三つの形をそれぞれ一か所で一度だけ定義し、(1)〜(3) の全てがその定義を使い、§2.3 の表は各種類を三つの形のどれかに当てるだけにするか。
- 決定:
- 経緯: 62 回目（2026-10-24）、S-642 の空白の流れ（第 52 組）の途中で、親が名前の頭と末尾の `_` の今の扱いを示した後、利用者が 「名前関連の規則は統一的に決めた方がいいので、関連する名前規則全てを議論しましょう。最終的にsnake_case/UpperCamel/UPPER_SNAKE系の規則が揃うようにしたいです。例外規則を増やしたくないので。」
  親が範囲（含める論点: 各形の頭と末尾の `_`、字面で種類を決める所の `_`、「1 語」、二つの形に合う名前、大文字の並びと数字、予約語に当たる候補、候補が既にある名前と重なる形。外すもの: S-649、S-480、署名に使われない型パラメータ。決定済みの S-01・S-82・S-149・S-243・S-300・S-313・S-325・S-319・S-352 は表に「決定済み」で並べ、S-243 は改めうる前提）を例のコードで言い直し、利用者が「はい。異論はありません。」と了承した。
  S-642 の下書き（`P62/gap52/draft.md`）と助言の二段の結果（62 回目の scratchpad）は材料として使い、族の全体で下書きと助言の二段をやり直す。期限は W4-14 を DONE にする前（S-642 に合わせる）。
  族の下書きの途中に、利用者が案を出した（下書きの案 (ε)）: 「一応私の案を言っておきます: UPPER_SNAKE / scale_case : `_` を前か後ろに一つだけなら付けられる。二つ以上つけるとエラー / CamelCase: `_` はどの位置にも付けられず、エラー / UPPER_SNAKEとCamelCaseが曖昧な場合: 曖昧な場合はどちらのケースを要求する場所でも許可(HTTPはUPPER_CASEとしてもCamelCaseとしても有効)」。
  親の二つの問いへの答え: 「1: 通すで良いと思います。2: はい。頭の`_`があればそれを飛ばして判別で。S-375: はい、名前が競合した場合はエラーになると思います。S-243: そうなります。適当に `x` などを末尾につけるなどでもいいかもしれませんが。」
  助言の段 1 の間に、利用者が案を足した（下書きの案 (ζ)）: 「C のexportだけが問題ですか？exportする名前だけ前後の`_`をかけないという例外を儲ける選択肢もあります（例外規則は避けるとしましたが、実害がある場合は別なので)」。親の言い直し（(ε) に export の項目の名前の例外を足し、R-261 は C の内部の名前の写し方を変えて直す）に「はい、その形であっています。」どの案も、利用者は決定とは言っていない（案の一つとして比べる）。
