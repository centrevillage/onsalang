# S-395

- 空白: 後の `let` を指す `^名前` の型をその位置でどう決めるか。§4.7 は「フィールドアクセス・メソッド・添字・`as` の左辺は対象の型の頭が解決済みでなければならない（E0420）。未解決なら注釈を書く」、§3.1 は「`^y.l` は `y` のフィールド `l`」、§11.2 は「名前は上から順に定義する」。
  後の `let` の注釈は W3-10 で前方の参照にも効くようにした（W3-10/b の M1）。注釈の無いとき（`let s = St { … }`）に後の `let` の右辺から型を決めるか、注釈を要するか（今は E0420）。
  仕様の例 `tests/spec/flow_syntax/feedback_references.onsa`（mode = parse）は注釈の無い形で、`check` に掛けると E0420 が 8 件出る。W3-10/b で見つけた（2026-10-10）
