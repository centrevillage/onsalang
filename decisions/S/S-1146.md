# S-1146 flow の本体の `match` の腕の束縛を E0309 に数えるか（`let k = match o { Some(v) => 1.0, None => 0.0 }` の `v`。§5.1 の flow の文が `let` の判定を置き換えるのか、足すのか）

- 空白: §5.1 は E0309 の対象を「`let` / `var`（分解を含む）、`match` の腕、`for` の束縛で、一度も参照されないもの」とし、続けて「flow の本体では、出力と `let _` から辿れない `let` が使われない束縛である」とする。後の文が flow の本体の対象を `let` に置き換えるのか、`let` の判定だけを足すのか（`match` の腕の束縛は fn と同じく参照の数で数えるのか）が字で決まらない。
  今（`onsa-4c744d9`）: flow の本体の `let k = match o { Some(v) => 1.0, None => 0.0 }`（出力で `k` を読む）と `match o { 0 => x, v => 0.0 }` は通る（flow の E0309 がまだ無い。fn の同じ形は E0309）。
  数える読みなら今通るこれらの flow が E0309 になる（候補は `v` を `_` に）。再現は 166 回目の scratchpad の `w714/memo/probe/unused.txt` の `match_bind_unused` と `g111/probe/`。
  読み: (1) 数える（腕の束縛は fn と同じく参照の数）。(2) 数えない（flow の本体の対象は `let` だけ）。急ぎ: W7-14 の前（flow の E0309 の単位の前）。
