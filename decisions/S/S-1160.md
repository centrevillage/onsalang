# S-1160 rt でない関数の呼び出しで、結果の型が Copy でないもの（S-1046 (a) で巻き上げない）の評価の段（§11.5 の init の段と §11.3 の読む側の段）

- 空白: §11.5 の表は、効果行が空の rt でない fn の呼び出しを「引数が全て定数ならコンパイル時、そうでなければ `init` の段で評価される」とし、§11.3 は「型が Copy でない部分式（静的な値の `Option[Str]` を選ぶ式など）は巻き上げず、読む側の段で評価し」とする（S-1046 (a)）。結果の型が Copy でない rt でない fn の呼び出しを速い段で読むと、二つの文が食い違う。
  読みは (1) 読む側の段で評価する（`tick` から rt でない関数を呼ぶ。R-17 の害）、(2) E0815（前の `let` に出しても `let` の値型は Copy なので書けず、`rt fn` にするしかない）、(3) 静的な値なら状態の外（静的な領域）に置く、に割れる。
  例: `pub fn name_of(n: I32) -> Option[Str] { if n > 0 { Some("on") } else { None } }`、`pub rt fn pick(o: Option[Str], x: F32) -> F32 { match o { Some(_) => x, None => 0.0 } }`、`pub flow f(x: F32 at sample, a: I32 at init) -> F32 at sample { pick(name_of(a), x) }` は、今 `NonRtCallAtClock` の E0200。
  仮の扱い: この版では E0200 のまま（`SPEC-GAP(S-1160)`、W7-05 U2）。通るプログラムは変わらない。(3) は静的な値の置き場（W9-03）と関わる。
