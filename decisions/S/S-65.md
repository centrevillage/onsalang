# S-65

- 空白: `onsa interface` が大きさを Core の降下から取り、状態を含む型（`Poly`）の大きさが出ない。一か所の降下の失敗で全ての flow の大きさが消える。状態のフィールドに型が無い。`voice.SIZE` を `pub const` として出す。`--target` が無い（レビュー R-75）
- 提案: T4-10 の配置の段（S-32）の結果から、flow ごとに大きさを出す。`--target <名前>` を CLI に足す。付けなければ bulk 無効の配置で計算し、`@mem(bulk)` を持つ状態とハンドルを含む値に条件を添える。bulk を持つ状態を普通の値に置いた型は、bulk 有効のターゲットで E0819 を示す。
  状態のフィールドは `名前: 型`（`saw.State`、`prev[F32]`、`delay[F32, N]`、`vdelay[F32, N]`）、`.buf` / `.w` / `.init` は内訳、`let` に由来しないフィールドに印（JSON は `"implicit": true`）。
  大きさを出せない flow には理由。`tests/review-phase1/parent/r75/` の期待値は `dsp.onsa` の先頭のコメント（2026-10-04 決定。実装は第 4 段、T4-10 の後）
