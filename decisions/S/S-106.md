# S-106

- 空白: 仕様の演算の意味が「Rust と同じ」で、NaN のビット表現が決まっていない。同じ式の `to_bits()` が、インタプリタ・clang・gcc・x86 で違う（レビュー R-133）
- 提案: `to_bits()` を、NaN なら正の quiet NaN を返す形にする（インタプリタと C の補助関数。比較と選択が一つ）。適合性テストは出力の NaN どうしを等しいとして比べる。§3.3 / §3.4 の表からテストベクトルを作る（D-16 の 2）。`tests/review-phase1/parent/r133/` の期待値と今の出力は `m.onsa` の先頭のコメント（2026-10-06 決定。実装は第 3 段）
