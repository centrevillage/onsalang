# S-49

- 空白: `Default` の値を作る手段が無く（`P.default()` が E0401、`T.default()` が E0302）、enum の `Default` の derive がどの列挙子かを決めずに通る（レビュー R-60）
- 提案: `default()` を降下する。`P.default()` と、境界からの `T.default()`（S-46 の `T.NAME` の解決と同じ道）。struct は各フィールドの既定値、組込み型は §6.3 の表の値。enum の `Default` の derive は E0416。S-29 の `prev~` の初期値の省略も同じ仕組みを使う（2026-10-04 決定。実装は第 2 段、S-46 と同じ回）
- 時期: M3
