# S-494

- 空白: タプル形の struct（Rust の newtype、`pub struct Hz(F32)`）の E0020 の候補のフィールド。§4.1 の例は `pub struct Q { priv value: F32 }`。W3-08 の実装は `value: F32` で、struct の可視性を継いで公開になり、`pub` の無い Rust の要素（非公開）と意味が変わる。W3-08/b1 の空白 G-5（2026-10-13）
- 提案: 決定（2026-10-13、利用者が親の改めた案を了承）: 候補のフィールドは `priv value`（§4.1 の例。Rust の要素は `pub` が無ければ非公開で、`rules/criteria.md` 7.33 の同じ概念の写し）。`priv struct` では `priv` が冗長（§15.1）なので `value`。
  Rust の `pub` の付いた要素（`pub struct Hz(pub F32)`）は今の行が型として読まず範囲の外。要素が二つ以上は今のまま候補なし。実装は W3-08 の直し B
- 時期: W3
- 補い（2026-10-25、親）: S-672（2026-10-25 決定）で、`priv struct` のフィールドには `priv` も語の無い形も書けることになった。上の「`priv struct` では `priv` が冗長」の理由は古いが、候補の `value` は変わらない（S-672。66 回目の文書の点検 A）。
