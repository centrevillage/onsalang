# S-1271 細部: 式の型で止めた単位が、止める前に降ろした呼び出しで作った総称の具体化を残すか（仮は残し、具体化は自分の E0200 を出す。今の実装）

- 空白: §18.1 は降ろせない型を持つ単位を「降下せず」とし、S-67 の補い (3) は束縛の段で止めた単位の中の呼び出しの具体化を作らないとする。式だけに現れる型で止めた単位では、止める前に降ろした呼び出しが総称の関数の具体化を作り、その具体化は後で降りて自分の E0200 を出す。文の順で E0200 の数が変わる: `fn g[T](x: T, a: [I32; 2], b: [I32; 2]) -> Bool { a < b }` を `u` が `let _ = g(1, [1, 2], [1, 3])` で呼んでから `"x".len()` で止まると二件（`g` の `a < b` と `"x"`）、`"x".len()` が先なら一件。
  読み: (1) 作った具体化を残す（今の実装）、(2) 止めた単位が作った具体化を戻す（文の順によらない）。仮は (1)。どの E0200 も本物の誤りで、違いは誤りのプログラムの E0200 の数だけ。再現 `target/notes/192/w816/b/rep1/`（`before`・`after`）。改めるなら、`lower_item` が止めた試みの作った具体化（待ち行列と `fn_ids`）を戻すか遅らせる。
