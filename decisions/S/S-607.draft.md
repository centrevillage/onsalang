# S-607 族: 列挙子の名前と呼び出し

- 決定済みで戻さないもの: `Option`・`Result` は std の enum で prelude にあり、違うのは `use` なしで見えること、列挙子を修飾なしで書けること、`?` に使えること（S-71、§4.1）。他の enum の列挙子は常に `Type.Variant`（§4.1）。
  タプル形の列挙子は関数値としても使え、単位形の列挙子は値で括弧を付けない（§4.4）。項目（列挙子の構築を含む）は `f(x)` で呼び、`.(` は E0020（S-191、§6.1）。flow の本体では列挙子を関数値にできない（S-195）。
  式の型引数は prelude の列挙子は名前に（`None::[I32]`）、他の総称の enum は型に（`E::[I32].B`）、列挙子の名前に付ければ E0412、パターンの `None::[I32] =>` は E0002（S-239、§4.5、W5-10）。
  パターンの空の括弧（`E.A()`・`None()`・`Some()`）は構文の段の E0002 で、候補は括弧を除く形（S-513）。prelude の名前は隠せない（§15.1、S-79）。型別名は列挙子の位置にも書ける（§4.4）。
  型の名前の後の `.` の名前が無いのは E0302（R-249、§15.1、W4-04）。

- 案:
  - (a) 列挙子の書き方は種類ごとに一つにし、それ以外の規則とコードは宣言した列挙子と prelude の列挙子で同じにする。
    prelude の列挙子は名前だけで書き、型や別名で修飾しない（4〜7・10 行）。修飾した形は名前の段の E0302（型の名前空間に無い名前、§15.1。R-249 と同じコード）で、候補は修飾を除く形（`Option.None` は `None`）。宣言した列挙子は `型.列挙子`（決定済み）。
    単位形は値、要素を持つ形は構築の項目で、呼び出しの誤り（14・15 行）は宣言と prelude で同じコード（コードは S-514）。
    実装: 名前の段（W4-04 の `body/names.rs` の作り直し）で、型の名前の後の名前が prelude の列挙子なら E0302 と候補（10〜20 行）。W5-03 で std の enum にした後も、`Option`・`Result` の型の名前空間から列挙子を引かない一行の条件（lang item の表で判定、5〜10 行）。§4.1 の一文。
    事例: 否定例（E0302 と候補）を 3 件以上。費用の要因: `Option`・`Result` だけが、型の名前空間から自分の列挙子を引けない enum になる（§4.1 の三つの違いに一つ足す）。Swift の `Optional.none` や Rust の `Option::None` から書く書き手は、往復が一つ増える。
    別名 `O.None` の候補 `None` は、期待型が無ければ型の段の E0406 になる（型引数を残す候補 `None::[I32]` は W5-10）。
  - (b) prelude の列挙子は、宣言した列挙子の規則（`型.列挙子`）でも書け、名前だけでも書ける（「違うのは…だけ」をそのまま読む）。4〜7・10 行は通る。fmt は揃えない。14・15 行のコードは (a) と同じくそろえる。
    実装: W5-03 の後は一般の列挙子の道でそのまま通る（0〜5 行）。それまでは組込みの名前を型の名前空間から引く分岐（5〜10 行）。
