# S-865 見出しが効果行 `uses {…}` で終わる `target fn` の `else` の本体（`-> Buf[T] uses {Alloc} else { … }`）が読める形か

- 空白: §15.2 の 101〜103 行は `else` を見出しの最後のトークンと同じ行に置くとするが、見出しが効果行で終わる形の例が無い。
  読み: (1) 読める（`target` 宣言のシグネチャは `rt` と効果行を含む、§15.2 の 97 行。見出しの最後のトークンは効果行の `}` で、`uses {Alloc} else {`）。(2) `else` は効果行を持たない見出しだけ。
  親の読みは (1)（97 行と、D-07 の追記の例 `pub target fn zeroed(n: U32) -> Buf[T] uses {Alloc}`）。U2 のテストの担当は (1) で `tests/cst/target_else_uses.onsa` と fmt の 2 件の `grow` の行を書いた
- 決定: 決定（2026-11-03、利用者が確認だけで了承。106 回目）: (1)。`target` 宣言のシグネチャは `rt` と効果行を含む（§15.2 の 97 行）ので、見出しが効果行で終わる形の `else` は効果行の `}` と同じ行に書ける（`uses {Alloc} else {`）。仕様 §15.2 の 103 行に括弧書きで添えた。実装は W5-02 の U2
- 経緯: 106 回目（2026-11-03）、W5-02 U2 のテストの担当（onsa-test）が NEW として挙げ、(1) で事例に書いた。親が §15.2 の 97 行から (1) に読めるので確認だけで出す
