# S-735 E0320 の候補の「全ての使用箇所」に、誤りで止まった単位の後ろの使用（型や名前の誤りの後、構文の誤りで切れた本体、E0304 の空間）を含めるか

- 空白: §2.3 は「E0320 の修正候補は一つで、宣言と、パッケージの中の全ての使用箇所の名前を直す」とし、§18.1 の候補の約束は触れた単位に限る。誤りで止まった単位の後ろの使用を「全ての使用箇所」に含めるかが書かれていない。
  読みは二つに割れる。(1) 段が名前を解決した所に限る（誤りで止まった後ろ、構文の誤りで切れた本体、E0304 の空間の使用は直さない。触れた単位に元から誤りがあるので §18.1 の約束の外）。(2) 誤りのある単位でも、止まった後ろの名前まで拾って直す。
  今の実装（W4-04 U9、`171a085`）は (1)。`let a: I32 = "s"` の後ろの `p.someX + p.GetIt()`、`let a = undefined_name` の後ろの `BadFn()`、`p.someX + }`、`use a.{BadFn}` を二度書いた後の `BadFn()` は直らない。U9 の前は宣言だけを直した。
  再現は 78 回目の scratchpad の `w404/u9/b/`（区切りで `target/notes/78/w404/u9/` へ写す） の `repro_partial_*.onsa` と `cyc2/`。flow の本体の最初の代入（E0806）の後ろの使用（W7-04）も同じ族。
- 決定: 決定（2026-10-28、利用者が ID を挙げて了承。確認だけ。79 回目、第 70 組）: (a)。
  E0320 の候補が直す使用箇所は、検査の段が解決して記録したもの（S-82）である。誤りで検査を止めた単位の止めた所より後ろと、検査しなかった部分（見出しに誤りのある `impl` のメンバ、構文の誤りのある本体）の使用は含まない。シャドーイングが無いので、残った古い名前は黙って別のものを指さず、その誤りを直した後の検査で E0302・E0413 として出る。
  仕様は §2.3 の 73 行に一句書いた。実装は今のまま（0 行）。誤りで止まった単位の後ろの使用が候補に含まれないことを期待に書く事例を、足すなら W4-18 で足す。
- 経緯: 78 回目（2026-10-28）、W4-04 U9/b（onsa-break）の指摘 1 と空白の NEW-1。期限は無い（決まるまで今の (1)）。関係: S-82、R-87、S-236。
