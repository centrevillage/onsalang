# S-51

- 空白: doc コメントがどこにも出ず、付く先の規則が無く、std のファイル先頭の説明が次の宣言に付き、フィールドなどの doc コメントを黙って捨てる。`onsa doc` が仕様の一部にだけある（レビュー R-63）
- 提案: 字句: `//!` を独立のトークンにする（今は普通のコメント）。構文: フィールド、列挙子、flow の入力にも doc コメントを付ける。
  付ける宣言の無い `///` と、先頭以外の `//!` は E0004（新設）。`onsa interface` に doc コメントとモジュールの `//!` を出す（LSP のホバーは M7 の T7-1、`onsa primer` は T5-7）。
  std の先頭は `//!` に改めた（2026-10-04 決定。仕様、std、`tests/spec/lex/comments.onsa` は反映済み。実装は第 2 段）
