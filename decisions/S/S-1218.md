# S-1218 `sample_tick()` を束のポート（`sample * N`）の引数に直に書いた形のクロックと値（§11.4 の「使う所の刻みのクロック」と、`let` に置いた形の E0815 で読みが割れる）

- 空白: §11.4 の表は `sample_tick()` の型を「`U32`（使う所の刻みのクロック）」とし、本文は「`reset` からの時間を、書いた場所の `sample_rate()` の刻みの数で表した `U32`」とする。§11.9 と S-1214 (3) は、束のポート（`sample * N`、本体の見え方は `[T; N]`）に束でない引数（定数、パラメータの種類）を渡すと各要素が同じ値になるとし、呼び出し側の `sample` の値を連鎖の無い束のポートへ渡す形は E0815 である。`sample_tick()` を束のポートの引数に直に書いた形（`g2~(sample_tick())`、`g2~(sample_tick() *% 2)`。`g2` の入力は `U32 at (sample * 2)`）のクロックと値が、この字から一つに決まらない。同じ値を `let t = sample_tick()` に置いて `g2~(t)` と書く形と、`g2~(sample_tick() at sample)` は E0815 である（`let` の `sample_tick()` は本体の `sample`、S-1180 の仮 (1)）。
  読み: (1) 呼び出し側の `sample` の値として E0815（`let` に置いた形と揃う。§11.9 の「点ごとの演算は当面は誤り」と同じく、後で緩められる）、(2) 使う所（ポート）の刻みのクロック `sample * N` の値として、時間の束（呼び出し側の刻み k で要素 j は N k + j。`tk~().up~(N)` の束と同じ値、S-1217 の上りの時間）、(3) 束でない値として、呼び出し側の時間 k を N 個複製する（S-1214 (3) の定数・パラメータと同じ）。
  範囲（段 1 が足した）: 束のポートの引数だけでなく、`.up~(N)` の連鎖の頭の引数（`pass~(sample_tick()).up~(2)`。ポートは `sample`、呼び出し側の枠で `sample * 2`。`pass~(x).up~(2)` は E0815）と、上りの連鎖に付けた `when~`・`reset_if~` の条件（W7-10）も同じ位置である。足した読み: (4) 字のとおり（クロックは `sample * N` で、§11.9 の呼び出し側の束への演算の E0815 に当たる。裸の形だけ通り、その値は (2) か (3) かが残る）、(5) 意味を (2) か (3) に決めて、この版では E0200 のままにする。
  段 1（onsa-advisor、178 回目）の推奨: (1) を「`sample_tick()` が合わせる刻みのクロックは、書いた本体の刻み（イベント、`sample / N`、`sample`）まで。呼び出し側の `sample * N` の位置では本体の `sample` の値で、変換の flow で渡す（E0815、§11.3）」と言い直した形。(2) は外す（確信 高: S-1217 の単位は書いた場所の `sample_rate()` で、遅いポートでは単位が変わらない（`hold4~(sample_tick())` は 0, 4, 8）のに、速い側だけ N 倍の単位になる）。(1) を (3) より上に置く（確信 中）: 「使う所に合わせる」の出所（S-567 の K6）は遅い段で読んでも式のクロックを引き上げないための規則で、速い位置は範囲の外。(2) と (3) はどちらも一行の変換の flow（時間の束 `mkt`、複製 `hold2`）で今書けて動く。(1) だけが後で (2) にも (3) にも緩められる（(2) と (3) の間は値が黙って変わるので後から移れない）。`x`・`let`・`at sample` の形と揃う。実装の量は (1) と (3) がほぼ同じ（sema の一か所）、(2) だけが大きい（呼び出し側で時間の配列を作る降下、評価器、U6b3・W7-10 で手当てが続く）。参照評価器は今、束でない値を束のポートで複製する（(3) の値、コードの読み）。
  今の実装: W7-16 U6b2 の後のバイナリでは `check` が通り、降下が内部エラー（sema の `clock::rooted` が `sample_tick()` に引数の位置のクロック `sample * N` を与え、Core が式の型を `[U32; N]` に包むが値は `U32` のまま）。U6b2 の前は Core の門で E0200。
  仮の扱い: 決まるまで、`sample_tick()` を束のクロックの位置で読む形は `check` の段の E0200（この版では作らない）とし、`SPEC-GAP(S-1218)` の印を付ける（判定は sema の一か所: `Ambient` を `burst_len` のある位置で読む。裸の形・演算・ブロック・上りの頭を形ごとに数えない。U6b2 の前は `check` が通り降下で E0200 だったが、どの読みに決まっても置き換えるだけで、今動くプログラムは変わらない）。急ぎ: W7-16 を閉じる前（`before`）。再現は `target/notes/178/w716/u6b2/b/repro_sample_tick/main.onsa`。
