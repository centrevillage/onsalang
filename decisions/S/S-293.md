# S-293

- 空白: 言語の側で、意味が型や被演算子の同一性で決まる書き方を誤りにするか: 整数と `Bool` の `x == x`（常に真）、符号なしの `x >= 0` と `x >= T.MIN`、自己代入 `y = y`、浮動小数の NaN の判定の `x != x`（`x.is_nan()` がある）。どれも今は `onsa check` を通る。
  誤りにするなら候補（`x != x` は `x.is_nan()`）と note。名前の付いた定数との比較（`x >= LO`、`LO = 0`）を含めるかで割れる。仕様には警告の概念が無く、黙って捨てる・消し忘れの形を誤りにする前例（E0309、E0418、E0503）がある。第 7 組の下書き（S-288）で見つけた（2026-10-08）
- 提案: 型の段の作業（W5）の前に決める。S-288 の決定とは独立
- 時期: W5
