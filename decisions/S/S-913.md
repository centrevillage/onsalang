# S-913 署名が E0401 の trait の `impl` のメンバを使う所の診断

- 空白: §6.3 の「足りない項目と `Tr` に無いメンバは E0410…それらの `impl` を使う所には診断を出さない（§18.1）」は過不足の文で、次の行の署名の E0401 には同じ言葉が無い。`impl Default for M { rt fn default(n: I32) -> M { … } }` の後の `M.default()` は、(1) 署名の誤りも `impl` の誤りで使う所は黙る、(2) メンバの書いた署名で使う所を検査する（引数の数の誤り）、の二つに読める。
  親の読みは (1) で、直すと消える誤りを使う側に出さない §18.1 の見方である。
- 決定: 決定（2026-11-06、利用者。117 回目、確認だけ）: (1) 署名が E0401 の trait の `impl` のメンバを使う所には診断を出さない（E0410 と同じ見方。§6.3 に足した）。
- 経緯: 117 回目（2026-11-06）、W5-06 U2〜U4 の設計メモ（onsa-impl）が仕様の空白として挙げた。期限は U4 の前。
