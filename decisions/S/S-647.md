# S-647 族: 絞った check の診断の範囲

- 空白: §15.1 は「`check` と LSP は、そのファイルの診断だけを出す」とするが、絞った `check` で、どの診断を「そのファイルの診断」とするか（ファイルの外の原因を持つ診断、一つにまとめて別のファイルに位置を置く診断）と終了コードの決め方を、一つの規則で書いていない。
  族の S: S-636（そのファイルに診断が無く他のファイルにあるときの終了コード）、S-645（ディレクトリの名前の E0320 の位置が別のファイル）。族の規則を一つ決め、二つをそこから決める。
- 決定:
- 経緯: 61 回目（2026-10-24）、同じ族の未決の S が二つ（S-636・S-645）になったので族の規則の S として登録した。
