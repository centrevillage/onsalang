# S-516

- 空白: unit のパターン `()`。`let () = p`（`p: ()`）は構文の段で通り、検査で E0401「expected a tuple pattern target, found `()`」になる（`()` をタプルのパターンと読んだ内部の言い方）。§7 のパターンの一覧は `()` を挙げない。案は、unit のパターンを書ける形にするか、構文の段の E0002 にして候補 `_` を示すか（Fable は後者）。第 30 組の下書きの付録（2026-10-14）
- 提案: 後の段
- 時期: W3
- 決定: 決定（2026-11-09、利用者。128 回目、共通の規則 S-965 と利用者の判断 B1〜B8、`target/notes/128/r58/decisions.md`）: （出所: B4）unit のパターン `()` を書ける（`()` 型の値に当たり、反駁不能。`let () = g()`、`Some(())`、`(a, ())`）。網羅の判定に数え、`()` の後の `_` は E0503（`Bool` の `true` と `false` の後の `_` と同じ）。`()` 以外の型の対象に書けば今の型の段の E0401。
  - 仕様の節: §7 の網羅の一覧、E0503 の例、パターンの一覧、`let` の分解の一覧。§2.5 の空の括弧が意味を持つ形に「パターン」（親が置く文、3）。
  - 今通るプログラムが変わるか: 増える（`let () = g()`、`match u { () => 1 }`、`Some(()) => …`、`let (a, ()) = t` は今は E0401「expected a tuple pattern target, found `()`」）。
  - 実装の見当: `onsa_sema` のパターンの型付け（要素 0 のタプルのパターンを unit に当てる）と網羅・到達の判定（unit を値一つの型に数える）、Core への降下（照合は常に成り立つ）。約 30〜60 行。構文の段は今も読む。
  - ぶつかる既存の事例: なし（`()` のパターンを E0401 とする事例は `git grep` で見つからない）。
