# S-717 引数（fn・無名関数・flow の入力）が、項目・`use` の束縛・prelude と同じ名前のとき（`fn gain` のあるモジュールの `fn f(gain: F32)`）、§5.1 の E0304 の束縛に含めるか

- 空白: §5.1 は「ある名前の束縛が見えている間は、同じ名前を束縛できない（E0304）」とし、見えている束縛にモジュールの項目・`use` で取り込んだ名前・prelude・組込み型を含め、「ローカルがそれらと同じ名前を使うと E0304」と例（`let math`・`let gain`・`let env`）を挙げる。
  引数（fn・無名関数・flow の入力）が「ローカル」に入るかを字で書いていない。§5.1 の E0309 は「関数と flow の引数は対象外」とわざわざ除き、§2.2・S-542 は flow の入力を本体から見える束縛に数える。
  今の実装: `fn gain` のあるモジュールの `fn f(gain: F32)`、`use std.math.{sin}` の後の `fn f(sin: F32)`、prelude と同じ名前の引数、項目と同じ名前の flow の入力は通る。無名関数の引数と外のローカルの重なりは E0304。
  再現は 75 回目の scratchpad の `w404/i/probe/c/param_item.onsa`・`param_use.onsa`、`w404-advisor/probe/param_prelude.onsa`・`flow_input_item.onsa`・`d/closure_shadow.onsa`。
  影響: std と examples の `.onsa` に当たる形は無い（親の正規表現の見当、`w404/parent/param_clash.py`）。`tests/` の事例に当たる数は W4-04 の隠蔽の単位の初めに数える。
- 決定: 決定（2026-10-27、利用者が ID を挙げて了承。75 回目、確認だけ）: 含める。fn と無名関数の引数と flow の入力も §5.1 の束縛で、項目・`use` の束縛・prelude・組込み型と同じ名前は E0304（§5.1 の「一つの名前は、見える範囲で常に一つのものを指す」）。
  仕様 §5.1 の「ローカルが」を「ローカル（引数と flow の入力を含む）が」とし、例に `fn f(gain: F32)` を足す。実装は W4-04（隠蔽の単位）。`tests/` の事例に当たる数は、その単位の初めに数え、多ければ直す前に親が利用者に知らせる。
- 経緯: 75 回目（2026-10-27）、W4-04 U1/i（onsa-impl の設計メモ）が確認として出し、設計メモの審査（onsa-advisor）は含める読みが §5.1 の他の文と整合するとした。期限は W4-04 の隠蔽の単位の前。
  関係: S-79、S-542、S-681、S-129。
