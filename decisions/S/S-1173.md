# S-1173 細部: `&&` / `||` の右辺の状態を持つものの E0806 の段（名前の段か flow の段か）

- 空白: §18.1 は「flow の検査のうち名前と字面で決まるものは名前の段である: …本体の制限（E0806。代入の形を含む）…」「`if` / `match` の枝の状態を持つものの E0811 と、状態を持つものの無い `if~` / `match~` の E0812（§2.6）は flow の検査の段である」とし、`&&` / `||` の右辺の状態を持つものの E0806 の段を書かない。
  読みは (1) 名前の段（「本体の制限」に入る。名前の段の歩きに枝の位置の記録が要る）、(2) flow の段（枝の E0811 と同じ判定で同じ所に置ける）、に割れる。違いは型の誤りと並ぶときにどちらを報告するか（段の順）だけで、通るプログラムは変わらない。
  再現: `target/notes/170/w706/memo/probe/c1.txt` の `and_right`（今は flow の段の E0200）。
  仮の扱い: (2)。`codes.rs` の E0806 の段の欄に `Flow` を足し、`SPEC-GAP(S-1173)` の印を付ける。急ぎ: W7 の区切りで確認だけ（`rules/leader.md` 5.11）。
- 決定: 決定（2026-11-26、利用者。189 回目、W7 の区切りの確認だけ。「(A)と(B1)はS-1148以外OKです」）: 仮の扱いのとおり。`&&` / `||` の右辺の状態を持つものの E0806 は、枝の E0811 と同じ flow の検査の段。
  突き合わせ: 助言の担当が固定のバイナリ `onsa-d02ddee` で再現し、仮の扱いが今の挙動と合い、既決とぶつからないことを確かめた（`target/notes/189/reports/onsa-advisor-a4f41d23ad112f9fe-001.md`）。
