# S-1050 細部: 所有の値の破棄を含む `rt` の関数の E0601 に、同じ効果の他の使用を note で並べるか

- 空白: §8.1 は「`rt` でない関数では…同じ効果の他の使用を note に並べる」とし、`rt` の関数の E0601（W6-03 の後。修正候補なし、§10 の規則 1 の note、S-77）に他の使用の note を書かない。
  S-783 で破棄の使用の位置を値を書いた所にしたので、`rt` の `let b: Buf[F32] = Buf.zeroed(n)` は束縛 `b` の破棄（作る呼び出しより前）を報告し、`Buf.zeroed(n)` の呼び出しは単位ごとに一つの報告（§18.1）に隠れる。書き手が `b` を返す直しをすると、次の回に呼び出しの E0601 が出る。
  読み: (1) 並べない（§8.1 の字のとおり、`rt` でない関数だけ） (2) `rt` の関数でも同じ効果の他の使用を note に並べる（`rt` でない関数と同じ道で作る。使用ごとに直しが別なので、note は位置だけを示す）。
  仮の扱い: (2)（通るプログラムを変えない。`rules/leader.md` 5.11）。W6-03 の実装はこの形で作る。
  急ぎ: W6 の区切りで確認だけ。
