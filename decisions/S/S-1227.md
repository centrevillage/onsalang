# S-1227 細部: 塊の内で、信号とパラメータの種類を一つの条件に混ぜた形（`when~(c && b)`）と分けた形（`when~(c).when~(b)`）の読む時点（仮は混ぜた式の全体を集める）

- 空白: 塊の内（修飾子の外に `.up~`、その外に `.down~`）の修飾子の条件は、境界の刻みより速い周期の値を頭の入力と同じに境界で集め、パラメータの種類は走りの時点で読む（§11.10 の合成の項）。信号 `c` とパラメータの種類 `b` を一つの条件 `c && b` に混ぜると、式のクロックは信号（§11.3）なので式の全体を集め、`b` は集めた時点の値になる（読み (1)）。
  分けた `x.when~(c).when~(b)` は `b` を走りの時点で読むので、§11.10 の「`x.when~(a).when~(b)` は `a && b` の刻みで動く」と、`b` が呼び出しの間で変わるときだけ値が割れる。読み (2) は混ぜた式でも `b` を走りの時点で読む（式を分けて読む仕組みが要る）。
  再現は `cnt~().when~(c).when~(b).up~(2).down~(2)` と `cnt~().when~(c && b).up~(2).down~(2)`（`c` は常に真、4 フレームを `b` 真、2 フレームを `b` 偽で呼ぶ: 分けた形 `[0,0,1,2,2,2]`、混ぜた形 `[0,0,1,2,3,4]`。`target/notes/181/w710/u3a/t2_report.md` の 4 章）。`reset_if~(a).reset_if~(b)` と `reset_if~(a || b)` も同じ。
  仮の扱い: 読み (1)（今の実装、§11.10 の「値」を式の値として読む字のまま）。通るプログラムは変わらない（W7-10 U3a の前は塊の内の修飾子が E0200）。§13.4 の「同じ params なら分けても同じ」は守られる。生成の双子は塊の内で信号と `block` の値を一つの条件に混ぜない（`twin_when::kinds_apart`）。段の区切りで確認だけ。

- 経緯: 181 回目（2026-11-24）、W7-10 U3a/t2（onsa-test）が生成の双子（種 1324）で見つけて空白に挙げ、親が細部として登録した。
- 補い（2026-11-24、183 回目）（2026-11-24、親）: 本文の「`b` が呼び出しの間で変わるときだけ値が割れる」は `&&`（`when~`）の形のこと。`||`（`reset_if~`）では、`b` が変わらなくても割れる: 混ぜた式は全体を集めるので、輪の位相 0 は `false`（§11.9）で、`b` が真（`block`・`init`・リテラル）でも最初の境界の刻みでは初期化しない。
  分けた `x.reset_if~(a).reset_if~(b)` は走りの時点の `b` を読んで初期化する。`cnt~().reset_if~(c).reset_if~(true).up~(2).down~(2)` と `cnt~().reset_if~(c || true).up~(2).down~(2)` で親が再現した（`&&` の `when~` の形は、`b` が変わらなければ割れない）。
