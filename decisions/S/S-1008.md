# S-1008 細部: `FixedStr` を平面の引数 `[Span[U8]; N]` の要素と、総称の `Span[T]` の引数に渡せるか（渡すと `T = U8`）

- 空白: §4.2 は `FixedStr` を「`Span[U8]` の引数に渡すと、使った長さの部分を見る」とし、§5.3 は平面の引数 `[Span[T]; N]` と総称の `Span[T]` を書ける。`FixedStr` を平面の引数の要素に置けるか、総称の `Span[T]` に渡すと `T = U8` に決まるかを書かない。
  仮の扱い: どちらも受ける（`Span[U8]` に渡せる値の判定を一か所にし、平面の引数の要素と総称の引数も同じ判定を通る。`rules/leader.md` 5.11）。
- 決定: 決定（2026-11-12、利用者。140 回目、W5 の区切りの確認だけ。「全て現状のまま」で了承）: 仮の扱いのとおり。`FixedStr` は平面の引数 `[Span[U8]; N]` の要素と、総称の `Span[T]` の引数にも渡せる（`T` は `U8` に決まる。`Span[U8]` に渡せる値の判定は一か所）。§4.2 の出口の行に足した。`onsa_sema` の `body/calls.rs` の `SPEC-GAP(S-1008)` の印は W5-13 で外す。
- 経緯: 139 回目（2026-11-11）、W5-12 の設計メモ（onsa-impl、`P/w512/memo/memo.md` の 9 章）が挙げた。
