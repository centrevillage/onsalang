# S-848 文の時点で型が決まっていない式を文の位置に置いたとき（`fn make[T: Default]() -> T` の文 `make()`）の E0418

- 空白: §6.1 は「ブロックの途中の文に書いた式は、型が `()` でなければ E0418（発散する式は除く）」とする。文の時点で型が決まっていない式（`fn make[T: Default]() -> T` の文 `make()`）は、`()` と単一化して通すか、E0418 か、関数の終わりまで待って型が決まらない E0406 かを書いていない。
  読み: (a) `()` に決めて通す、(b) E0418、(c) 終わりまで待って E0406。(a) だけが通すので、通るプログラムが変わりうる。
  急ぎ: W5-08 の前（E0418 を入れる単位）。
- 決定: 決定（2026-11-04、利用者。110 回目、第 81 組。下書きと独立のレビューの段 2 は (b)、段 1 は (d)。利用者「B3: (b)」）: (b)。文の時点で型が `()` と決まっていなければ E0418（型がまだ決まっていない式も、後の文を待たない）。文面は「ここでは `()` と決まっていない」の形。
  候補 `let _ = e` は、`e` の型に整数のリテラル以外のまだ決まっていない型変数が残るときは出さず、note で `let _: T = e` を示す（頭が分かって中が開く `None`・`Some(make())` も同じ）。今 E0406 の文 `make()` は E0418 になる。作業は W5-08。下書きは `S-848.draft.md`。仕様 §6.1、`tasks/diag-codes.md` の E0418
