# S-578 集めて配る形の時点: 同じ位置の遅い刻みと `sample` の刻みの順、位相 0 の遅い刻みの配列

- 空白: §19.1 のマルチレートは「集めて配ると N サンプル遅れる（`delay~(x, N)` と同じ）」「`sample / N` の刻みは…最初の刻みで動く」とし、S-566 の A3・A10 は「直前の N サンプル（`x[N - 1]` が最新）を渡し、出力の配列は N 刻みに順に配る」とした。
  S-567 の二度目の独立のレビューの A-14 は、字の無いものとして三つ（遅い刻みとその位置の `sample` の刻みの順、位相 0 の基準、配った後の値を `sample` で読めること）を挙げたが、§19.1 に書かれていない。S-577 の下書き（第 35 組）の遅れの数がこれに依る。
- 提案（親。「`delay~(x, N)` と同じ」から読みが一つに決まると見て、確認だけ）:
  1. 同じ位置では、入力のイベントの刻み、遅い刻み、`sample` の刻みの順に並ぶ（イベントの値は遅い刻みでもその位置のイベントを全て処理した後の値で読む、§19.1）。位置 c の遅い刻みが集めるのは c − N 〜 c − 1 の N サンプルで、配る出力は位置 c 〜 c + N − 1 の `sample` の刻みが順に読む。
     同じ位置で `sample` の段が出したイベントは、遅い周期の刻みには次の遅い刻みで見える（部品のイベントの段は、その位置で処理する）。
  2. 位相 0 の遅い刻み（`init` と生成する `reset` の後の最初の刻み）の配列は、前のサンプルの無い所を `T.default()` で埋める（`delay~` の初めの値と同じ）。これで出力は入力のちょうど N サンプル遅れになる。集める入力の型が `Default` を満たさなければ E0816（`when~` の保持と同じ）。
  3. 配った値は呼び出し側の `sample` の値で、他の `sample` の値と同じく読める。集めた値と同じく呼び出し側の値なので、`reset_if~` は触れない。
- 決定: 決定（2026-10-22、利用者が ID を挙げて了承。51 回目）: 提案の 1〜3 のとおり（同じ位置はイベント、遅い刻み、`sample` の刻みの順で、位置 c の遅い刻みは c − N 〜 c − 1 を集めて c 〜 c + N − 1 に配る。位相 0 の配列は `T.default()` で埋め、`Default` が無ければ E0816。配った値に `reset_if~` は触れない）。仕様 §19.1
- 経緯: S-577 の下書き（onsa-gap、2026-10-22、51 回目）が「仕様や決定の中で見つけた別の問題」として挙げた。S-577 の独立のレビュー（段 1・段 2）が、1〜3 は §19.1 の段の順（`block < sample / N`）、「最初の刻みで動く」、出力のクロックの合成から一つに決まると確かめ、三つの一文（イベントの見え方、`Default`、`reset_if~`）を足した。関係: S-566、S-567、S-577。
