# S-973 数を書けない位置（`as` の型、項目の位置）の E0001 の形の数（`x as 0b12`）と、基数に合わない数字に浮動小数の接尾辞が続く形（`0b12f32`）のコード: E0001 か E0002 か

- 空白: §2.4 は「接頭辞の後に基数で読めない数字のある形（`0o19`、`0b12`）も一つのトークンで、§18.1 の E0001」とし、「数のトークンの形の誤り（接頭辞、接尾辞、先頭の 0、小数点）…数を書けない位置（`as` の型、項目の位置）では、同じ範囲の置き場所の E0002 が先である（§18.1）」とする（S-471、S-281 による）。
  §18.1（S-281）は、同じ段で同じ単位の診断を開始・終わり・コード・文面の順で選ぶ。E0001 と E0002 はどちらも構文の段（`codes.rs`）である。
  割れる形は二つ。(A) 数を書けない位置の E0001 の形（`x as 0o19`、`x as 0b12`、項目の位置の `0o19`）: (1) S-281 の並べ方でコードの小さい E0001 が先（今の `x as 0o19` と項目の位置の `0o19` の出力）、(2) §2.4 の文のとおり置き場所の E0002 が先（「形の誤り」に E0001 の形も含める読み）。
  S-281 の例（項目の位置の `1.`・`1u8` が E0002）は E0020 の形で、コードの順でも E0002 が先になる。
  (B) 基数に合わない数字に浮動小数の接尾辞が続く形（`0b12f32`、`0o19f32`）: 数字の E0001（§18.1「接頭辞の後に基数で読めない数字のあるもの…は E0001」）か、接尾辞の E0002（§18.1「接頭辞の付いた整数（`0b11f32`）は…E0002」）か。一つのトークンの同じ範囲なら、S-281 の並べ方で E0001。今の `0o19f32` は E0001。
  どれも誤りのプログラムで、違うのはコードだけ。候補はどの読みでも無い（E0001 は候補なし、§18.1。置き場所の E0002 も数の形に候補を作らない）。
  今（dev `cdc74d99`）: `x as 0o19`・項目の `0o19`・`0o19f32` は E0001、`x as 0b12`・項目の `0b12`・`0b12f32` は二つのトークンに割れた E0002（S-451 で W5-24 U1a が一つのトークンにする）。再現は scratchpad の `s973/`。
  親の仮の扱い: (A)(1)、(B) E0001（S-281 の一般の並べ方で、例外を足さない。W5-24 U1a で `0b12` を一つのトークンにすると `0o19` と同じ出力に揃う）。§2.4 の文は「E0020 と E0002 の形の誤り」に限ると読む。
