# S-706 `Block` を `main` と export する関数の効果行に持つときの `provides` と E0610（ターゲットが `Block` を与えるとは何か）

- 空白: §8.5 は「`main` の効果行の各効果について、ビルドターゲットが handler を提供しなければならない（E0610）」、§15.3 は「`main` または export される関数の効果行に、`provides` に無い効果が含まれていれば E0610」とする。
  extern の HAL の関数が `uses {Block}` と主張すると（§14.1）、それを呼ぶ `main` と export する関数の効果行にも `Block` が現れる。`Block` は操作を持たず prelude にある（§8.2、S-702）が、ターゲットが `Block` を与える（`provides` に書く）とは何か、`Block` を E0610 の対象にするかが書かれていない。
  `Alloc` は「`provides` に `Alloc` を持たない」ターゲットの扱いが §12.3・§15.3 にある。

- 経緯: 71 回目（2026-10-26）、文書の点検（onsa-docs、`a335789..25164ec`）が見つけた。S-702 で `Block` を prelude に入れ、`use` 無しで効果行に書けるようになって表に出た。第 1 期は extern も handler も E0200 なので、第 2 期の handler と extern の作業（`tasks/phase2.md` の S-705 の行）の前に決める。関係: S-702、S-704、S-705。
