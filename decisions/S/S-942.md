# S-942 名前に接する `'''`（FAUST の三重の遅延 `x'''`）が、区切りの並びか、`x'` の遅延の形か

- 空白: §2.4 は `'''…'''` を他の言語の文字列の区切りとする。`spec/foreign-forms.toml` の `string_prefix` の例の読み（S-466）は、名前に接する `'` を文字リテラルの始まりとし、FAUST の遅延を note で示す。名前に接する `'''` はどちらにも読める。
  読み: (1) `x` と区切り `'''` の並びで、`string_delimiter` の行、範囲は `x'''`。(2) `x'` の遅延で、`string_prefix` の行、FAUST の note 付き。どちらも E0002 で、変わるのは行の字と範囲と note だけである。通るプログラムは変わらない。
  再現は `let a = x'''` で、今は `'''` だけの区切りの行（`tests/spec/negative/syntax_string_prefix_faust.onsa` の同じ行）。
  仮の扱い: W5-11 U2 は S-856 の並びの読み (1) で実装し、`SPEC-GAP(S-942)` を付ける。
