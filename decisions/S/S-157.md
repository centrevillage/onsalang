# S-157

- 空白: 単精度の FPU だけの機器で、F64 だけが `strict-ftz` の FZ に従わない（点検 C-48）
- 提案: 生成コードがソフトウェアの F64 の演算の入力と結果の非正規化数を 0 にする。F64 がハードウェアかどうかの欄をプラットフォームの表（IR の B-11）に足す。Onsa の soft-double は仕様 §19.1（2026-10-06 決定。実装は C のバックエンド、S-105 と同じ回）
- 時期: M4
