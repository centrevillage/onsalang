# S-466 FAUST の `x'` と、名前に接する文字リテラル

- 空白: FAUST の `x'`（S-48 の `faust_prime`、E0020、候補 `prev~(x)`）と S-400 の改め（名前に接する閉じない文字リテラルは `string_prefix`）の衝突。
  W3-05 の単位 2 では `x'` が `string_prefix` の E0002 になり、`x' + y'` と `f(x', y')` は `' + y'`・`', y'` を一つの文字リテラルとして読む（親が単位 2 のバイナリで `x' + y'` の範囲を確かめた）。`e0020_faust.onsa:25` は実装待ち（W3-08）。
  W3-05/b の単位 2 が見つけた（2026-10-13。`w305b2/c15.py`、NEW-FAUST）
- 提案: 決定（2026-10-13、利用者が (a) を選んだ。下書きと Fable は (b) の字句の判定で一致していたが、利用者は誤った候補が出うる形を候補なしとしてきた判断に揃えた。第 27 組）: 名前に接する `'` は文字リテラルの始まりで `string_prefix` の E0002（候補なし、中身を読まない、S-400 のまま）。
