# S-876 E0503 の削除の候補が、前の文の型変数を決めていた到達しない文を消し、当てた後に同じ型の段の E0406・E0405 が残る形（`let o = None` / `return 1` / `let z: Option[I32] = o`）

- 決定済みで戻さないもの: 候補の約束（S-236）、E0503 の順（S-268）、E0309 が最後の段であること（S-726、S-292 の表）。
  第 81 組の下書きの「S-292 の形の表」の節（写しは `target/notes/110/g81/draft.md`、入力は `target/notes/110/g81/probe/`）。
- 論点: §7（64・66 行）の E0503 の候補は到達しない文を消す。到達しない文は、文の順の検査で E0503 が見つかった所で単位の検査が止まるので、型の検査を受けない（S-268: E0503 は関数の終わりの検査より先）。
  消す前のプログラムで、前の文の型変数（`let o = None` の `T`、`var acc = 0.0` の浮動小数のリテラル）を決めていたのが到達しない文だけなら、当てた後の関数の終わりの検査が E0406・E0405（または後回しの E0416）を出す。
  これらは E0503 と同じ型の段なので、§18.1 の約束（S-236）に当たり、その候補は出せない。どう判定して出さないか（または別の候補にするか）を仕様と計画が書いていない。
- 今の実装: E0503 が無い。消す前の形（`probe/s292/typeinfo_before.onsa`: `let o = None`、`return 1`、`let z: Option[I32] = o`）は、到達しない文で型が決まり、`z` の E0309 だけ。
  消した後の形（`typeinfo_after.onsa`）は、`None` に E0406「the type in `None` cannot be determined」、`var acc = 0.0` に E0405、`let xs = []` に E0406。
- 案: 
  - (a) 正確に判定: E0503 を見つけたら、到達しない文を飛ばしたまま単位の残りと関数の終わりの検査を続け、同じ段の誤りが出れば E0503 の候補を出さない（E0503 は先の誤りとしてそのまま報告する）。
  - (b) その時点の型で判定: E0503 を見つけた時点で、整数のリテラル以外の型変数か、後回しの検査の項目が残っていれば候補を出さない。関数の本体の一番外のブロックでは、その後に到達する文が無いので (a) と同じ結果で、内側のブロックでは、後に到達する文が決める形でも出さない（安全側）。
  - (c) 候補に注釈を足す: 消す編集に、型変数を作った式の注釈を足す。到達しない文は検査しないので、注釈する型が分からず、作れない形が残る。
  - (d) 約束の例外: E0503 の削除の候補は、当てた後の E0406・E0405 を許す。
  - 書き手から見て: (a)・(b) は候補が出ない形で、書き手が消す範囲と注釈を自分で決める（一回）。(d) は候補を当てて E0406 を見てから注釈する（二回）。
  - 修正候補: (a)・(b) は約束を満たす。(c) は作れる形だけ満たす。(d) は約束に例外を作る。
  - 通るプログラム: どの案も変わらない。
  - 規則と例外: (a)・(b) は §18.1 の一般の規則の当てはめで、仕様に文は要らない（(b) は内側のブロックで出さない形が増えるが、出さないことは約束の範囲）。(c) は候補の形の一文。(d) は §18.1 に例外を一つ足す。
  - 実装の量（W5-08）: (a) は E0503 を止める誤りでなく記録にして、残りを飛ばして検査を続ける分岐（約 +20〜30。続けた後の誤りの扱いも要る）。(b) は E0503 の所で推論の状態と後回しの項目を見る判定（約 +8〜12）。(c) は (a) の上に注釈を書く処理（約 +30 以上）。(d) は 0 と、器の約束の確かめの例外（`fix_contract`）。
