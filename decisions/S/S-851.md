# S-851 手書きの `impl Default for Ty` のメンバ（`default`）が型の名前の後の `.` の空間に入るか、固有の `impl` の同名のメンバと E0304 か

- 空白: X-23 で、手書きの `impl Default for Ty` を W5-06 で受け付けることにした（他の標準 trait の手書きの実装は第 2 期）。§6.2 は型の名前の後の `.` で引く名前（メソッド、関連定数、列挙子）を一つの空間とし、重なると E0304 とする。§6.4 は「手で実装するときは `impl Tr for Ty` と書き、宣言には並べない（両方に書くと E0304）」とする。
  trait の `impl` のメンバ（`default`）がその空間に入るか、固有の `impl Mode { pub fn default() … }` の同名のメンバと E0304 になるかを書いていない。読み: (1) 同じ空間に入り E0304。(2) 別の空間で、`Mode.default()` がどちらを指すかに規則が要る。
  急ぎ: W5-06 の前。
- 決定: 決定（2026-11-06、利用者。117 回目）: (a) 一つの空間で E0304。trait の `impl` のメンバと derive が作るメンバ（`default`、`ordinal`、`from_ordinal`）は型の名前の後の `.` の空間に入る。derive が作るメンバとの重なりは書いた順によらず固有のメンバに付け、宣言の一覧を note で示す。
  手書きの `impl` と固有のメンバはソースの順で後の宣言に付ける。見出しが E0307 の trait の `impl` も、対象の型が決まれば数える（S-748 と同じ）。
  `struct P: Default` と固有の `default` の組は W5-06 で E0304 になる（リポジトリに 0 件）。§6.2 の文は標準 trait に限らず一般に書き、第 2 期に利用者の trait の同名を開くときに文を改める。
- 経緯: 104 回目（2026-11-02）、X-23 の見積もりの組 B（onsa-impl）が X23-8（手書きの `impl Trait for Type`）の案を見積もって挙げた。利用者が X23-8 の (2) を了承した後に親が登録した。再現（今は `impl Default for Mode` が E0200）は `target/notes/104/x23est/B/p/g1.onsa`。関係: S-748、S-49。
- 補い（2026-11-06、親）: 第 88 組で決めた。下書き `decisions/S/S-851.draft.md`。
- 補い（2026-11-06、親）: 117 回目の文書の点検から: §6.2 の「固有のメンバに付け」を「手で書いたメンバに付け」に改めた。trait の `impl` のメンバも同じである（W5-06 U4）。
- 補い（2026-11-12、親）: 142 回目（2026-11-12）、S-1019 で決めた: 決定の「見出しが E0307 の trait の `impl` も、対象の型が決まれば数える」は、手書きの `impl Default for Ty`（この版で開いた形）の範囲である。この版でメンバを読まない trait の `impl`（`impl Hash for Al`）は、見出しに誤りがあっても数えない（S-1019 の (1)、§18.1 の「この版でメンバを読まない trait の `impl`」の文）。
