# S-423

- 空白: 腕の本体の後の同じ行の非対称な空白の `-`・`+`（`0 => { 1 } -1 => 2,`、`0 => { 1 } +1 => 2,`）が §2.5 の本文に無い。S-398 の決定は `-` の同じ行の形を S-386 の E0002 にした（「同じ行にも広げる」）が、仕様の S-386 の文は改行の形（`0 => { 1 }` 改行 `-1 => 2,`）だけを書く。
  S-405 の (ii) と細部は `+` を S-398 の行と S-386 の改行の形に入れ、同じ行の `+` を書かない。今は `-` の同じ行が `asymmetric_binary_space` の E0020（候補 `{ 1 } - 1`）、`+` の同じ行が `=>` の位置の E0002（候補なし）。
  W3-06/t3 が見つけた（2026-10-10。親が dev の `ade4450` で確かめた）
- 提案: 決定（2026-10-10、利用者が ID を挙げて親の案（確認だけ）を了承）: 仕様 §2.5 の S-386 の文に「後ろに `=>` が続く同じ行の形（`0 => { 1 } -1 => 2,`、`0 => { 1 } +1 => 2,`）も同じ E0002 で、候補も同じ（`+` は `,` の挿入と、`+` と後ろの空白の削除を一つにした形）」を足す。
  両側に空白のある `{ 1 } - 1 =>`・`{ 1 } + 1 =>` は二項として読み、今の `=>` の位置の E0002（候補なし）のまま。実装は W3-06 の単位 2（補いの設計メモの形のまま）
