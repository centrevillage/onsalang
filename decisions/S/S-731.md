# S-731 一つの単位に、要る種類でない名前の E0308 と、離れた位置のこの版の E0200 が並ぶとき（`fn f(x: Zq) -> I32 uses {Ef}`）、§15.1 の「E0200 より先に E0308」を単位の全体の順とするか、同じ並び（効果行・境界）の中の順とし離れた位置は §18.1 の位置の順とするか

- 空白: §15.1（`spec/15-modules.md` 75 行）は「E0308 は版によらない誤りなので、要る種類でない名前は E0200 より先に E0308 にする」とし、§18.1 は一つの単位の誤りを段、次に位置の順で選ぶ。要る種類でない名前と、別の名前のこの版の E0200 が一つの単位に並ぶときの順が書かれていない。
  読みは二つに割れる。(1) 単位の全体で E0308 を E0200 より先にする（`fn f(x: Zq) -> I32 uses {Ef}` の効果行の E0200 より、前の位置でも後ろの位置でも E0308）。(2) 「先に」は一つの名前に E0200 でなく E0308 を付けることと、同じ並び（効果行・境界）の中の順で、離れた位置は §18.1 の位置の順。
  今の実装（W4-04 U8b、未コミットの主のツリー）: 同じ効果行と同じ型パラメータの並びの中だけ E0308 が先（`uses {Ef, I32}`・`T: Tr + I32` は E0308。事例 `tests/spec/effects/kind_effect_row.onsa`・`tests/spec/types/kind_bounds.onsa`）。単位の全体では位置の順。
  通るプログラムは変わらない。変わるのは一つの単位に二つの誤りがあるときに最初に報告する一つだけである。
- 決定: 決定（2026-10-28、利用者が ID を挙げて了承。78 回目、第 68 組）: (3)。
  §15.1 の「E0308 は版によらない誤り」は、一つの名前に E0200 でなく E0308 を付ける規則（S-713 の A7 の出所）で、一つの単位に E0308 と E0200 があるときの順は §18.1 の単位の規則（段、次に位置）のとおり。同じ並び（一つの効果行、一つの型パラメータの並び）の中も位置の順（`uses {Ef, I32}` は `Ef` の E0200）。
  仕様は §15.1 の 75 行と §18.1 の E0200 の段落を「付ける」に言い換え、順の一句を足した。実装は W4-04 の最後の単位（`sig.rs::lower_generics` と `read_effects` の `filter(|_| !wrong)` と `wrong` を外す、約 −6 行）。
  W4-04 U8b で入れた並びの中の順を戻し、事例 `tests/spec/effects/kind_effect_row.onsa`（`uses {Ef, I32}`）と `tests/spec/types/kind_bounds.onsa`（`[T: Tr + I32]`）の期待を E0200 に直し、頭のコメントを改める。
- 経緯: 78 回目（2026-10-28）、W4-04 U8b/i（onsa-impl）が空白として報告した。同じ並びの中の順は U8b/t の事例の期待（親が §15.1 の 75 行と S-713 の A7 から読んだ）。期限は無い（決まるまで今の実装のまま）。関係: S-713、S-719。
