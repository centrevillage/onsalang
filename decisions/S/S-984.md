# S-984 型の読めない宣言（`static mut`・C の `static` の名前、見出しの切れた宣言）を型の位置・パターン・定数式・`.(`・`~(` に書いた所の診断を黙らせるか

- 空白: §18.1 は「読めなかった部分は誤りの型として扱い、それを使う側には診断を出さない」とし、`static mut` と C の `static` の名前を「型の読めない宣言として見せ（使う所に診断を出さない）」とする（S-620）。
  今の実装（W5-24 U2b）は、値の読み・呼び出し・メソッドの受け手・代入・`inout` を黙らせるが、宣言の種類を読む位置には診断が残る: 型の位置の `let y: X = 1` は E0308「`X` is a function, not a type」、パターンの `X =>` は E0308、定数式の `[F32; X]` は E0417「`X` is a function, not a constant」、`X.(1)` は E0020（候補は `.` を外す）、`X~(1)` は E0821。`static mut` と C の形は名前だけの切れた `fn` として表しているので、文面が変数を関数と呼ぶ。
  見出しの切れた `fn X(` でも同じ出方で、W5-24 U2b の前からある仕組みである。
  決めること: 型の読めない宣言の名前を、これらの位置でも黙らせるか（種類も不明として扱う）、今のまま宣言の種類で診断するか。再現は 133 回目の scratchpad の `w524u2b/b/in/g1/mut_*.onsa`（壊す側の低 3 の表）。
