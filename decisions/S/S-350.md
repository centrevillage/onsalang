# S-350 `1.(x)` の読み

- 空白: `1.(x)` を、浮動小数のリテラル `1.`（§2.4 の E0020、候補 `1.0`）と読むか、整数 `1` の関数値の呼び出し `1.(x)`（§6.1。型の段の誤り）と読むか。今の字句は `1.abs()` を `1` と `.abs` に分けるが、`1.(` は `1.` と読む。
  W3-20 は字句を今のままにし、直後が `(` のリテラルの候補と、整数リテラルの呼び先の候補を出さない（どちらの読みでも誤りの形）。W3-20/i で見つけた（2026-10-09）。
  直後が `(` のリテラルの候補を出さない扱いは他のリテラルの行にも及び、`017(2)`・`0o17(2)` は 8 進の E0020 でなく呼び先の E0002 になる（W3-20/b）。`1 .(2)` の空白を除く候補も同じ理由で出さない 直し（2026-10-11、第 24 組の下書き）: `0o17(2)` は今は呼び先の E0002 でなく、`literal_suffix` の文面の E0002（字句が `0o17` を `0` と接尾辞に読む。W3-05 まで）。`017(2)` は呼び先の E0002。 追加の論点（2026-10-10、RF/t）: 16 進・2 進の整数（`0x1F(x)`）は `.(` の候補が浮動小数と紛れない。
- 提案: 決定（2026-10-11、利用者が ID を挙げて推奨の (b) を了承。下書きと Fable が一致、第 24 組）: 整数の数字の後の `.` は、数字が続けば小数点、名前か `(` が続けばメンバの `.`（`1.abs()`、`1.(x)`）、`e`・`E` と数字が続けば `1.e3` の E0020（S-62）、それ以外は `1.` の E0020。
  W3-20 の三つの例外（整数の呼び先、`1 .(x)`、`1i32.(x)` の候補）を外し、候補を出す（当てた後は型の段の誤りだけ）。`tests/spec/negative/syntax_no_candidate_forms.onsa` の `1 .(2)`・`1 . (2)` は `fixes/` へ移す。
  型の段の数値リテラルの呼び先の文面（E0420 より E0401 が合う）は W4 / W5 の記録。仕様 §2.4。実装は W3-05
