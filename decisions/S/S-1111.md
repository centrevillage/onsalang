# S-1111 総称の struct の具体（`G[F32]`）を `sample` の出力にできるか（今は E0810「nested arrays cannot cross the boundary」）

- 空白: §11.6 は境界の型を「数・`Bool`・配列とそれらをフィールドに持つ struct」とし、総称の struct を除いていない。`pub struct G[T] { a: T, priv b: T }` の `-> G[F32] at sample` は今 E0810（`target/notes/159/g106/advisor/a667.txt` の `generic_out`）で、文は「nested arrays cannot cross the boundary」と原因と合わない（境界の出力の検査が型引数の無い struct だけを見るため）。認めるなら `Out` のフィールドの型は型引数を当てたものになる。低。
