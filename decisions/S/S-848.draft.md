# S-848 文の時点で型が決まっていない式を文の位置に置いたとき（`fn make[T: Default]() -> T` の文 `make()`）の E0418

- 決定済みで戻さないもの: E0418 の規則と候補（S-127）。後の文からの決定と E0406（§4.7、S-262）。発散する式の除外（§7。範囲は S-291）。
  第 81 組の下書きの「S-848 の仕組みの出所」と「S-848 の形の表」の節（写しは `target/notes/110/g81/draft.md`、入力は `target/notes/110/g81/probe/`）。
- 論点: §6.1（20 行）は、途中の文の式の型が `()` でなければ E0418 とする。文の時点で型の頭が決まっていない式（型変数そのもの）は、`()` に決めて通すか、その場で E0418 か、後の文や関数の終わりを待つかを書いていない。
  型の頭が分かる式（`None` は `Option`、`[]` は配列）は `()` でないと決まるので、どの案でも E0418 で、論点はこの S の外である。整数・浮動小数のリテラルの型変数も、候補の種類だけで `()` でないと決まる（§4.7 の「候補の種類だけで誤りと決まる操作」と同じ）。
- 今の実装: 形の表のとおり。E0418 が無いので、文の型は問わない。決まらない型引数は関数の終わりに E0406。
- 案: 
  - (a) `()` に決める: 途中の文の式の型が型変数なら `()` と単一化する。文 `make()` は `T = ()`（`()` は `Default` を実装する）で通る。後の文で `I32` に決まる形（`id(v)` の後の `let w: I32 = v`）は、`let w` に E0401（expected `I32`, found `()`）。
  - (b) その場で E0418: 文の時点で `()` と決まっていなければ E0418（型変数そのものを含む）。文 `make()` は E0418。後の文で `()` に決まる形も E0418。
  - (c) その場で E0420: 途中の文を「その場で既知を要する」位置（§4.7 の E0420 の一覧）に足す。文 `make()` は E0420（注釈を求める）で、注釈して `I32` になれば次の検査で E0418。
  - (d) 待つ: 型変数なら後回しの検査に入れ、決まった文で `()` でなければ E0418、関数の終わりまで決まらなければ §4.7 の E0406（今の出力）。後の文で `I32` に決まる形は `id(v)` に E0418、`()` に決まる形は通る。
  - 形ごとの出力: 文 `make()` は、(a) が通り、(b) が E0418、(c) が E0420、(d) が E0406。`let v = make()` の後の文 `id(v)` と `let w: I32 = v` は、(a) が `let w` に E0401、(b) が `id(v)` に E0418、(c) が `id(v)` に E0420、(d) が `id(v)` に E0418（関数の終わりの検査で）。
  - 書き手から見て（修復のループ）: 文 `make()` の書き手が値を捨てるつもりなら、`let _: I32 = make()` と書けば終わる。(a) は黙って通る（副作用を期待した誤りは残る）。(b) は E0418 の note（値を捨てるなら注釈して `let _`）で一回。
    (c) と (d) は注釈を求め、`make::[I32]()` と書くと次に E0418 になり二回、`let _: I32 = make()` と書けば一回。
  - 修正候補: E0418 の候補 `let _ = e` は、`e` の型に関数の終わりまで決まらない型変数が残ると、当てた後に E0406（同じ型の段）を残し、§18.1 の約束に当たる（下のあわせて決めること）。
    (a) は E0418 を出さない。(b) の型変数そのものの形は、候補 `let _ = make()` が E0406 を残すので候補を出さない。(c) の E0420 は候補なし。(d) は決まった型で出すので、候補は約束を満たす（関数の終わりの E0406 は候補なし）。
  - 通るプログラム: (a) は、今 E0406 の文 `make()` を通し、`()` に決まる形以外の後の使い方を E0401 にする。(b)・(c) は、後の文で `()` に決まる形（`let w: () = v`）を誤りにする。(d) は E0418 の規則どおりで、通るプログラムは決まった型だけで決まる。どれも `examples/` と `tests/` の正例に当たらない（E0418 の事例は W5-08 で作る）。
  - 規則と例外: (a) は §6.1 の「途中の文は `()` の位置でない」区別に例外（型変数なら `()` の位置）を足す。(b) は §6.1 の文を「文の時点で `()` と決まっていなければ」に改める。(c) は §4.7 の E0420 の一覧に一つ足す。(d) は §4.7 の後回しの検査の一覧に E0418 を足す（後回しの仕組みは既にある）。
  - 実装の量（W5-08）: E0418 の判定（`()`・誤りの型・発散を除き、型の頭が分かれば E0418）は、どの案でも約 15〜25 行で作る。(a) は型変数の分岐で単一化を一つ（約 +3）。(b) は分岐が要らない（型変数も「`()` と決まっていない」に入る、約 0）。
