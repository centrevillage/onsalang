# S-665 族: §15.1 の公開の宣言に書いた型の位置

- 決定済みで戻さないもの: 論点の表の「決定」の列のとおり（決定済みの行は S-144）。
- 論点: §15.1「宣言の外に見える部分（関数の引数と返り値、型別名の右辺、定数の型、フィールドと列挙子の中身、trait のメンバ）に、その宣言より狭い可視性の型を書くと E0303」（S-144）。位置を並べるが、並べ方の一般の規則を書いていない。
  一覧に無い位置が見つかった: 固有の `impl` のメンバ（S-662）、flow の入出力と効果の操作（S-664）。下の表のとおり、handler の引数、型の中の型、型でない名前（境界の trait、上位の trait、効果行の効果）も一覧に無い。
  論点は二つある。(1) どの位置を含めるか（一覧を足すか、一般の規則にするか。型だけか、trait と効果の名前も含むか）。(2)「その宣言の可視性」を宣言自身の可視性とするか、持ち主との狭い方（宣言の届く範囲）とするか。(2) で読みが割れるのは、自分の語を持ち、持ち主が型であるメンバ（固有の `impl` のメンバ）だけである。
- 今の実装: S-144 の検査はまだ無い（W4-03 の U4）。表の「通る」の形は全て `check` が診断なしで終了コード 0。
  trait・効果・handler・extern のブロックは、宣言そのものが今は E0200 である（利用者の trait は第 2 期、`tasks/phase2.md`）。

- 他言語:
  - rustc 1.94.1: `pub fn f(i: Inner)` と `pub struct Outer` の `pub fn leak() -> Inner` は `private_interfaces` の警告（既定で warn。`other/lib.rs`）。非公開の型 `Inner` の `pub fn new() -> Inner` には出ない。
    非公開の trait の境界 `pub fn f<T: Tr>` と上位の trait `pub trait A: Tr` は「trait `Tr` is more private than the item `f`」（`private_bounds`、既定で warn。`other/bound.rs`）。
  - Swift 6.3.1: `public func f(_ i: Inner)` と `public struct Outer` の `public func leak() -> Inner` は誤り（`other/a.swift`）。`internal` の型の `public` のメンバは通る。
    `internal` の protocol の境界 `public func f<T: Tr>` は「cannot be declared public because its generic parameter uses an internal type」、`public protocol A: Tr` は「public protocol cannot refine an internal protocol」の誤り（`other/b.swift`）。
  - Go 1.27.2: 公開の `func New() inner` を `go vet` も含めて通す（`other/gomod`）。Kotlin は未確認（手元に無い）。
- 推奨と理由: (d)。確度: 中。
  - S-144 が守るのは、宣言に届く利用者がその見出しに書いた名前にも届くことである。害は位置の種類によらない。今回の二つの空白は、位置を並べた一覧が宣言の種類の増え方に追いつかないことから生じた。見出し全体を一文で覆えば、第 2 期に宣言の種類が増えても仕様の文が変わらない。
  - trait と効果の名前も、使う側が書く名前である。効果行は全ての関数で完全に注釈する（P1）ので、無指定の効果を `uses` に持つ `pub fn` は、外の呼び手が自分の効果行に書けず、呼べない。境界の trait は、外の書き手が `impl` も境界の受け渡しもできない。型に限る (c) は、同じ害の形を第 2 期の空白として残す。
  - 比べる可視性を届く範囲にするのは、表の 8・9 の害が起きないからである（理由は S-662）。持ち主を継ぐ宣言（5・6・7・11〜13）では二つの読みが同じなので、規則が増えるのは固有の `impl` のメンバに当てる一句だけである。
  - (d) の 15〜18 は今は E0200 の宣言の中にしか無いので、今の実装の量は (c) と同じである。厳しい方を先に決めておけば、後で緩めても壊れない。
