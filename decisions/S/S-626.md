# S-626 `onsa --version` の出力の形と、埋め込みの std の版の値

- 空白: §15.3 は「埋め込みの std の版は `onsa --version` で表示する」とするが、版の値（コンパイラの版と同じか、std が自分の版を持つか、仕様の版に結ぶか）と、出力の形（`onsa x.y.z` と `std x.y.z` の 2 行か、`onsa x.y.z (std x.y.z)` の 1 行か、標準出力か）を書いていない。§18.2 のコマンドの表に `--version` が無い。
  今の実装は標準出力に `onsa 0.1.0` の 1 行だけで、std の版を出さない。W4-02 の E1103 は、この値と `std = "x.y.z"` を比べる。
- 決定:
- 経緯: 59 回目（2026-10-24）、W4-01 U1 の実装の担当（設計メモ）とテストの担当が、それぞれ見つけた。実装の担当の仮の扱いは、値はコンパイラの版、形は 2 行（`SPEC-GAP(S-626)` を付ける）。テストの担当は、`std` の語を含む行の最初の `x.y.z` を読む形で書いた（`crates/onsa_cli/tests/package_model.rs`）。
