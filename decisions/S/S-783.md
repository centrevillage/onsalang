# S-783 暗黙の破棄の E0601 の位置（所有の束縛の行か、破棄の点か）

- 空白: §8.1 は E0601 を「最初の使用の位置」に置くとし、暗黙の `Alloc` の使用に「それらを所有する値の破棄」を含めるが、破棄には式が無く、その位置を書かない。読みは (1) 所有する束縛の位置（今の rt の関数の E0901 と同じ）、(2) 破棄の点（スコープの終わり、上書き。W6-02 が記録する破棄点）、(3) 関数の見出し（今の実装の E0601）。補間などで値を作る使用は式の位置で決まる。
  再現は `tests/spec/negative/binding_literal_owned_plain.onsa`（`uses {Alloc}` の無い通常の関数で、所有の集成体の束縛の破棄。今は E0601 が関数名の行）。
  W4-16 U2/t のテストの担当は印を束縛の行に書き、この事例と `binding_literal_generic_owned_plain.onsa`・`binding_static_affine_type_plain.onsa` を W6-03 の実装待ちにした（理由は既にある `binding_static_interp.onsa` と同じ R-87・S-82）。
  W6-03 が E0601 の位置を入れるとき、S-77 で rt の関数の E0901 を E0601 にまとめる位置と一緒に決める。
- 決定: 決定（2026-11-14、利用者。149 回目、第 103 組。下書きと独立のレビューの段 1 が (d) で一致し、段 2 は省いた）: (d)。破棄の使用の位置は、破棄される値を書いた所である。所有の束縛（引数と `self`、`let`・`var`、腕と `for` のパターンの束縛）はその名前、束縛の無い値（一時の値、早い出口が残す値、所有の `for` が残す反復元）はその式、上書きは代入先、束縛しなかった部分はそれを書いた所（`_`）、取り出しの残りは取り出す式。
  最初は §18.1 の並べ方（位置の始まりの順）で決め、束縛の名前は作る式より前に来る（S-77・S-82 が採った `tests/review-phase1/parent/r83.onsa` の 22:7・`r87.onsa` の `no_row` の `a` と同じ）。書いた所と別の所で破棄される値は、破棄の点を位置付きの note で示す（文面・並び・範囲は約束にしない）。`fn` と `rt fn`（W6-03 の後は E0601、S-77）の両方に当たる。
  B3（利用者）: (1) 字のとおり。`rt` の関数の中の、`Alloc` を持つ関数の呼び出しは、§8.1 の使用（E0601）と §10 の規則 4 の `rt` でない関数の呼び出し（E0901）の両方に当たり、同じ範囲なので §18.1 の並べ方で E0601 を報告する。例外は足さない。`Alloc` を持たない `rt` でない関数の呼び出しは E0901 のまま。
  細部（利用者が推奨のとおり了承）: C1 一つの値は破棄の点がいくつあっても一つの使用で、note は全ての点を `DropPoint.at` の位置のまま示す。C2 同じ範囲の作る使用（呼び出し・補間）と破棄は作る使用を先（`mk(n).len()`）。C3 無名関数の引数の破棄はその無名関数の使用で、位置は引数の名前（S-1032 の「本体の最初の使用」をこの読みに揃える）。C4 上書きは代入先、取り出しの残りは取り出す式（W6-03 の持ち越しの W4-09 U2 の項と同じ）、`move self` は `self`。
  C5 仕様は §8.1 の E0601 の項（破棄の使用の位置、一つの使用と最初の決め方と note、`rt` の関数の中の `Alloc` を持つ関数の呼び出し）と無名関数の項、§6.3 の `Drop` の文に §8.1 を指す一句。§10・§12.2・§18.1 は変えず、コードを足さない。細部の S（`rules/leader.md` 5.11、仮の扱いで進め W6 の区切りで確認だけ）: N1 は S-1050、N4 は S-1051、N3 は S-1052。N2 は S-1035 に補い。
  理由: 直すのは値で（移す・返す・借用にする）、位置が値を指し、note が捨てる道を示す。既決の期待値と今の `rt fn` の E0901 の位置と同じなので、W6-03 はコードを替えるだけで報告する使用は変わらない。「最初」は §18.1 の並べ方だけを使う。
  費用: `rt` の `let b = Buf.zeroed(n)` は、作る呼び出しより束縛の破棄が先に報告され、修復のループが一回増えうる（S-1050 の note で和らげる）。他言語: rustc の `const fn` の E0493（主は束縛か値の式、ラベル「value is dropped here」が `}`）、Swift の複製できない型の note「consumed here」。
