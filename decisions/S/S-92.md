# S-92

- 空白: C の生成 API と設定に、仕様に無い項目がある（`platform = "host"`、`PARAM_COUNT`、`onsa_reset_hook`、`ONSA_PANIC_HANDLER`、`ONSA_NO_TLS`、export した関数の C の形と `take_panic`）。`panic_messages = false` でもランタイムのメッセージが残る（レビュー R-107）
- 提案: export した関数の wrapper を「状態の `int` を返し、結果は最後の `T* out`」に改め、`<prefix>take_panic()` と、panic の印のスレッドごとの変数を消す。`panic_messages = false` では、生成した `.c` がランタイムを取り込む前にマクロを定義し、補助関数のメッセージを空の文字列にする。
  生成した呼び出しは `onsa_panic("", "", 行)`（行を残す。S-95 の規則で内部の記号は `onsa__` で始めるので、`onsa__panic`）。OS の無いプラットフォームでは `onsa build` が `ONSA_NO_TLS` を定義する。
  ヘッダの例の注釈（未初期化の `process`）を直す。`tests/review-phase1/parent/r107/` の期待値と今の出力は `m.onsa` の先頭のコメント（2026-10-05 決定。実装は第 3 段）
