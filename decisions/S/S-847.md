# S-847 要素が Dup でない `[T; N]` の、`get` 以外の列のメソッド（`fill!`・`slice`・`add_from!`・`copy_from!`）

- 空白: §5.3 の `Span[T]` の行は、メソッドを `len()`、`slice(from, to)`、`get(i) -> Option[T]`、`fill!(v)`、`add_from!(other)`、`copy_from!(other)` で全てとし、`[T; N]` と `Buf[T]` にも同じものがあるとする。§4.5 は `Buf[T]` と `Span[T]` の要素型を `T: Copy` に限る（E0416）。
  要素の型が Dup でない `[T; N]`（`[Buf[F32]; 2]`）が、`get` 以外の列のメソッドを持つかを決めていない（`get` は S-794）。`85400d9b` は `xs.fill!(b)`（`inout xs: [Buf[F32]; 2]`、`b: Buf[F32]`）を誤りなく通し、一つの Affine の値を二つの要素へ複製する（R-349）。`xs.slice(0, 1)` は `Span[Buf[F32]]` を作り、引数の位置で初めて E0401 になる。
  再現は `target/notes/104/x23est/A/p/s2.onsa`。
  読み: (1) 要素が Dup でない `[T; N]` は `len()` だけを持ち、他は E0413（か E0416）。(2) 全てを持ち、`fill!(v)` などは値を複製しない形の規則を足す。
  急ぎ: W5-02 の前（組込みのメソッドを std に宣言するときに受け手の境界が要る）。S-794 と同じ族で、一緒に決める。

- 経緯: 104 回目（2026-11-02）、X-23 の見積もりの組 A（onsa-impl）が見つけた。親が `85400d9b` のバイナリで再現した。前からある。関係: S-794、R-349、D-07 の追記（`[T; N]` と `Buf[T]` の受け手は `Span[T]` のメソッドを引く）。
