# S-321

- 空白: 構文の誤りの回復で、`#`（他言語の属性 `#[…]` の始まり）を項目の始まりとみなすか。§18.1 は回復の点を「字下げの行頭にある項目のキーワード（`fn`、`pub`、`struct`、`flow`、`impl` など）」とする。今の W3-15 の実装はみなす（`@` の属性と同じ）。W3-15/b で見つけた（2026-10-09）
- 提案: 決定（2026-10-09、利用者が ID を挙げて了承。親の案）: 構文の誤りの回復で、`#`（他言語の属性 `#[…]` の始まり）を、`@` の属性と同じく項目の始まりとみなす（宣言の頭なので）。仕様 §18.1 の回復の点の一覧に「属性の始まり（`@` と、他言語の属性の `#[`）」を足した。W3-15 の実装のまま。`SPEC-GAP(S-321)` の印は W3-19 で外す
