# S-1104 要素の型が `Default` を満たさない長さ 0 の配列（`[Char; 0]`）が `Default` を満たすか

- 空白: §6.3 の表は「タプル、`[T; N]` | 要素が全て実装するとき … `Default`」とする。長さ 0 の配列の要素は無いので、型 `T` が `Default` を満たさない `[Char; 0]` が割れる。
  読み: (1) 型 `T` が満たすときだけ `[T; N]` が満たす（長さ 0 でも `[Char; 0]` は満たさない、E0416）。(2) 要素が無ければ「全て」は空で成り立ち、長さ 0 は要素の型によらず満たす（空）。通るプログラムが変わる（`[Char; 0]` を `T: Default` に渡す形、flow の省いた `init` の `T.default()`）。
  今は (1)（インタプリタの側の検査は E0416 `[Char; 0] does not satisfy the bound T: Default`）。W7-01 の参照評価器も (1)。再現は `target/notes/158/w701/u2/b/d1/d1.onsa`（`onsa test`）。
  仮の扱い: (1)。

- 経緯: 158 回目、2026-11-16、W7-01 U2/b（onsa-break）が空白として挙げ、親が登録した。flow の省いた `init`（W7-07 の `T.default()`）の前に決める。
