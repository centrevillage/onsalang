# S-1104 要素の型が `Default` を満たさない長さ 0 の配列（`[Char; 0]`）が `Default` を満たすか

- 空白: §6.3 の表は「タプル、`[T; N]` | 要素が全て実装するとき … `Default`」とする。長さ 0 の配列の要素は無いので、型 `T` が `Default` を満たさない `[Char; 0]` が割れる。
  読み: (1) 型 `T` が満たすときだけ `[T; N]` が満たす（長さ 0 でも `[Char; 0]` は満たさない、E0416）。(2) 要素が無ければ「全て」は空で成り立ち、長さ 0 は要素の型によらず満たす（空）。通るプログラムが変わる（`[Char; 0]` を `T: Default` に渡す形、flow の省いた `init` の `T.default()`）。
  今は (1)（インタプリタの側の検査は E0416 `[Char; 0] does not satisfy the bound T: Default`）。W7-01 の参照評価器も (1)。再現は `target/notes/158/w701/u2/b/d1/d1.onsa`（`onsa test`）。
  仮の扱い: (1)。
- 決定: 決定（2026-11-19、利用者。168 回目。第 112 組。独立のレビューの段 1（onsa-advisor）が (1)、親も (1) で、段 2 は省いた）: (1) 要素の型で決める（長さによらない）。
  タプルと `[T; N]` が §6.3 の表の行の trait を満たすかは要素の型で決まり、長さ 0 でも同じ（`[Char; 0]` は `Default` を満たさない。境界と derive は E0416、W7-07 の後の遅延の省いた `init` は E0816）。種も同じ（§4.1・§4.6、`[Str; 0]` は Shared）。
  書き手は、遅延なら `init` を書き（`prev~(z, [])`）、struct ならフィールドに既定値を書く（`e: [Char; 0] = []`）。どちらも今通る。
  (2) 長さ 0 は空で満たす案は採らない。同じ型が、総称の定数の長さ（`z::[Char, 0]()`）と具体的な型（`mk::[[Char; 0]]()`）で結果を変え、総称の struct の derive（`R[Char, 0]`）と食い違う。種まで広げると今通る `take(move e)`（`e: [Buf[F32]; 0]`）を止める。後の版で広げても、通っていたものは止まらない。
  今の実装のまま（W7-07 の E0816 は要素の型の判定を使う）。仕様 §6.3（表の行を「要素の型が全て実装するとき」に改め、表の下に一文）。
- 経緯: 158 回目、2026-11-16、W7-01 U2/b（onsa-break）が空白として挙げ、親が登録した。flow の省いた `init`（W7-07 の `T.default()`）の前に決める。168 回目（2026-11-19）、第 112 組（S-1104・S-360・S-550）として親の中立の要約で段 1 に回し（`target/notes/168/g112/`）、利用者が (1) に決めた。
