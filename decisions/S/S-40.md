# S-40

- 空白: §9.2 の `panic(msg)` が prelude に無く、発散の規則も無い（レビュー R-52）
- 提案: `panic` を prelude の関数にする。引数は文字列リテラルだけ（それ以外の `Str` の式は E0200）。`return` / `break` / `continue` / `panic(...)` は発散し、どの型の位置にも置ける。`break` を含まない `while true` も発散する。Core の `panic(msg_id)` へ下ろす。
  末尾の型の不一致は、シグネチャではなく末尾の式（または最後の文）の位置に出す（2026-10-03 決定。実装は第 3 段）
- 時期: M3
