# S-945 具体化の上限で止めるとき、前に見つけた降下の診断も捨てるか

- 空白: §18.1 は降下の診断を「全て報告」とし、例外として「具体化の上限（§4.4 の E0422、§4.5 の E0423）を超えたら、そこで降下を止め、その一つだけを報告する」とする。止める前に見つけた降下の診断（E0200。`rt_cycles` の E0903 は降下の後に回るので出ない）を残すか捨てるかが、文から一つに読めるかを確かめる。S-290 の決定に「一つだけ報告する」とあり、捨てる読みが字のままである。
  親の読み: 捨てる。報告はその一つだけで、直した後の次の `build` で E0200 が出る。残すと、どの E0200 が先に見つかるかが具体化の順に依るので、報告の集まりが順で変わる。W5-23 U2 はこの読みで実装した（`lower_item` が `Diagnostics(vec![d])` で止める）。
