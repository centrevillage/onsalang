# S-547

- 空白: 値の無い末尾の `return` の直前が値のある `return` か発散する文の形。`fn f(a: I32) -> I32 {` 改行 `return a` 改行 `return` 改行 `}` は E0401 だが、fmt は S-545 の「式でない文の後は外す」で後ろの `return` を外し、末尾になった `return a` も外して `a` にするので、通るプログラムになる（§18.2 の原則に反する）。
  同じ形の `return // c` は fmt の 101。`while true {}` の後の `return` も、E0503 を実装すると同じ型の食い違いになる。W3-12/b2（U1）が見つけた（2026-10-15、`scratchpad/w312u1b2/repro/`）
- 提案: 決定（2026-10-15、利用者が (C) を選んだ。親の推奨と同じ）: fmt は値の無い末尾の `return` を外さない（S-68 の「値の無い `return` を含む」を撤回）。外すのは末尾の位置の値のある `return e` だけ。値の無い末尾の `return` は受理し、書かない。
  理由: 正しく外すには型と発散の判断が要り、例外の規則が重なる（(A) は S-545 に直前が `return`・`break`・`continue` の例外を足し、E0503 の後も例外が要る）。値の無い `return` を末尾に書く書き手はまれで、C でも省略できる。S-545 の規則と、範囲のコメントの判断は要らなくなった。
  仕様 §0.2・§6.1、`spec/tools.md` §3.3。実装は W3-12 の U1
