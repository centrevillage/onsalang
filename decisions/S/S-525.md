# S-525

- 空白: 項目の本体とブロックの 1 行の形の判定（§3.2「メンバ一つで `{` と `}` が同じ行なら 1 行、それ以外は複数行」）を、書き手の入力の行で見るか、整形した後の出力の行で見るか。`fn h() { h(a, b` 改行 `) }` は、閉じ括弧を寄せると 1 行に収まるが、今の fmt（古い印字器も新しい印字器も）は入力の `{` と `}` が別の行なので複数行にする。
  U3c で要素の中の改行を除くと、この形が増える。W3-11/b（U3b）が見つけた（2026-10-14）
- 提案: 決定（2026-10-14、利用者が ID を挙げて親の確認だけの読みを了承）: 書き手の入力の行で見る（並びの三つの形と同じく、形は書き手の改行で決まる。§3.2「どの形かは書き手の改行で決まる」）。出力は今のまま。`spec/tools.md` §3.2 を「書き手が `{` と `}` を同じ行に書いていれば 1 行」と書き改めた。事例は W3-11 の U3c
