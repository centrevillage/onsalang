# S-907 derive が作る `ordinal`・`from_ordinal` の `rt` と効果行

- 空白: §6.4 は `m.ordinal() -> U32` と `Mode.from_ordinal(n: U32) -> Option[Mode]` と書き、`rt` と効果行を書かない。`default` は S-905 で `rt` で効果行は空と決めた。同じく derive が作る関数で、番号の変換は確保も panic もしない（範囲外は `None`、§6.4）ので、親の読みは `rt` で効果行は空である。
  `rt fn` の中と `const` の初期化式で呼べる（§6.6 は効果行が空の関数を呼べる）。§10 の規則 1〜5 に当たる処理が無い（§10 の数のメソッドは全て `rt`）。
- 決定: 決定（2026-11-06、利用者。117 回目、確認だけ）: `ordinal` と `from_ordinal` は `rt` で、効果行は空である。`rt fn` の中と `const` の初期化式から呼べる。手書きの `impl Ordinal` は E0307 なので、利用者が `rt` を書く場面は無い。
- 経緯: 117 回目（2026-11-06）、親が W5-06 U2 の票を書くときに §6.4 の文に `rt` が無いことに気付いた。読みが一つなので確認だけで出す。
