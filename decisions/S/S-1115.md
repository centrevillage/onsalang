# S-1115 借用の位置の末尾に、その腕・ブロックの中で宣言した束縛のビュー（`take(if c { var t = … ⏎ t.slice(0, 2) } else { … })`）や、Copy でない束縛そのもの（`hb({ let t = move a ⏎ t })`）を置く形を、誤りにするか、値として外へ出すか

- 空白: §5.2 は末尾が置かれた位置を継ぐとし、S-1113 は借用の引数の末尾の場所をその引数の場所とする。末尾がその腕・ブロックの中で宣言した束縛を根とする場所のとき、束縛はブロックの終わりで寿命を終えるが、呼び出しはその後に読む。どの文もこの形を書いていない。
  形は二つある。(i) 束縛のビュー: `take(if c { var t: [F32; 4] = … ⏎ t.slice(0, 2) } else { y.slice(0, 2) })`、所有の腕の束縛の `take(match mk(v) { Some(b) => b.slice(0, 2), … })`、`for v in if c { var t … ⏎ t.slice(0, 2) } else { … }`。(ii) Copy でない束縛そのもの: `hb({ let t = move a ⏎ t })`、`hb(match move o { Some(b) => b, None => y })`。
  今は全て通る。(i) は生成した C で、腕の `{ }` の中の変数のビューを腕の外の呼び出しで読む（未定義の動作。腕でないブロックは C で平らになり偶然動く）。(ii) は sema の破棄点がブロック・腕の終わりで、呼び出しはその後に読む（Core はまだ破棄を降ろさないので、W8-04 で解放後の使用になる）。`move t` と書くと E0703 で、正しく書く方法が無い。`let s = { … t.slice(0, 2) }` は E0710。
  読み: (b) 禁止: 借用の位置の末尾に、その腕・ブロックの中の Copy でない束縛を根とする場所とそのビューを置けない（誤り）。書き手は束縛を呼び出しの前に出す。Copy の束縛（`hb({ var t: F32 = 1.0 … t }, inout n)`）は今のまま通す。
  (a') 消費: そういう末尾は「ブロックの値」として消費して呼び出しの一時に移す（Affine は移し、Dup は S-1030 の解放）。ビューは外へ出せないので E0710。(i) はどちらの読みでも誤り。違うのは (ii) で、(a') は `hb(mk())`（呼び出しの結果の一時を借用の引数に渡す）と揃い、(b) は規則が一つで降下に条件付きの破棄が要らない。
  再現は `target/notes/161/w712/u2c/audit/advisor/`（`in/p1.txt` の `block_local_view_tail_if`・`arm_owned_view_tail`・`for_head_if_local_view`、`in/p4.txt` の `rt_arg_local_buf_block`・`rt_arg_arm_binding_owned`、C は `c/c2/onsa_cprobe.c` の `main__block_local_if`・`main__arm_owned`）。
  急ぎ: W7-12 U2c1 の前（共通の構造の寿命の述語が読む）。
- 決定（2026-11-17、利用者、161 回目）: (b) 禁止、新しいコード E0716。借用の引数と借用の行の見出し（`for`・`match`、§5.4）の末尾に、その腕・ブロックの中で宣言した束縛（腕のパターンの束縛を含む）を根とする部分ビューと、そういう Copy でない束縛の場所を置けない。
  根は値がその位置で指す場所の根で、派生した借用束縛は派生元を根とする（S-796。`{ let s = x.slice(0, 2) … s }` の根は外の `x` で、置ける）。Copy の束縛そのもの（`hb({ var t: F32 = 1.0 … t }, inout n)`）は値を写して渡すので置ける（ビューの位置に置いた Copy の配列の束縛も、値を呼び出しの一時へ写す）。仕様 §5.2。
  コードは新しい E0716（モードの段、修正候補なし）。§5.4 の所有の行の `let s = { … t.slice(0, 2) }` は今のまま E0710。コードの選びは親の仮の扱いで、W7 の区切りで確認だけに出す（既にある E0704 は移動後の使用、E0710 は第二級の値の置き場で、Copy でない束縛そのもの（`hb({ let t = move a … t })`）に当たらない）。
  理由: 規則が一つで、降下に条件付きの破棄（片方の腕だけが一時を作る形）が要らない。(a') へは後で緩めても、通っていたものは止まらない。(i) の束縛のビューは (a') でも誤り（E0710）。段 1（onsa-advisor の監査）が (b) を推し、親の読みと一致した。
  補い（2026-11-17、利用者「letも含めるで良い」、161 回目）: 借用の行の見出しには `let` も入る（`let s = match o { Some(b) => b.slice(0, 2), None => y.slice(0, 2) }`、`o: Option[[F32; 4]]`、`b` は腕の中の Copy の値で、`s` はそのビューを腕の外で読む。今は通り、生成した C で未定義の動作）。
    決めた時の問いは「借用の位置の末尾」で、親が仕様に書いた文が見出しを（`for`・`match`）とだけ挙げて `let` を落としていた（W7-12 U2c の設計メモの改めの空白の候補 G3、`target/notes/161/w712/u2c/memo2/memo.md` の 6 章）。仕様 §5.2 の文を（`let`・`for`・`match`）に直した。同じ種類の見落としが無いかを助言の担当に監査させる。
  帰結: 今 `check` を通る (i)・(ii) の形が E0716 になる（(i) は今の C の未定義の動作が止まる）。書き手は束縛を呼び出しの前の `let` に出す。今の事例に当たる形は単位の票の前に数える。実装は W7-12 U2c1 の共通の構造の寿命の述語（`持ち越し`）。
- 経緯: 161 回目（2026-11-17）、W7-12 U2c の想定漏れの監査（onsa-advisor、段 1）が最重として挙げ、(b) を推した。親が (i) を再現した（C の未定義の動作）。前からの形（S-1113・U2b と無関係）。利用者が (b) を選んだ。
