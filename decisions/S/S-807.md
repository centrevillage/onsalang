# S-807 R-198 の修正候補（場所でない被演算子の外の `move` を消して各末尾の Affine の変数に `move` を置く形）を、消費しない位置と返り値の位置にも出すか（`rd(move if c { x } else { y })`、`rd` は借用の引数）

- 空白: §5.2 の 54 行は、場所でない被演算子（ブロック、`if`・`match`）に付けた `move` の E0711（R-198）の修正候補を「外の `move` を消して各末尾の Affine の変数に `move` を置く形」とし、位置を限らない。
  同じ節の 52 行は、消費しない位置（文、条件、二項演算子の被演算子、添字、範囲の端、借用と `inout` の引数）に置いたブロックの末尾の `move` を E0703 とし、51 行は返り値の位置の `move` を書かないとする。§18.1 の 27 行は、候補を当てた後に同じ段の診断を残さないとする。
  借用の引数の `rd(move if c { x } else { y })` に 54 行の候補を当てると `rd(if c { move x } else { move y })` になり、52 行の E0703 が二つ残る。
  dev（`e8df4957`）では、R-198 の E0711 にどの位置でも候補が無い（再現は `target/notes/90/w409/i/probe/s605.onsa` の `c14`・`c24`）。
  読み: (1) 末尾に `move` を置く候補は消費する位置（束縛の見出し、値を置く位置、`move` の引数）でだけ出し、消費しない位置と返り値の位置では外の `move` を消すだけの候補にする（§18.1 の 27 行から）。(2) 54 行の字のとおりどの位置でも末尾に置く。
  どちらでも、末尾に借用か `inout` の Affine の場所があれば候補を出さない（当てると候補の無い E0711 が残る）。
  急ぎ: W4-09 U3（R-198 の候補）のテストの票の前。
- 決定: 決定（2026-10-31、利用者。90 回目。確認だけ。親の読み）: (1)。R-198 の E0711（場所でない被演算子のブロック・`if`・`match` に付けた `move`）の修正候補で、外の `move` を消して各末尾の Affine の変数に `move` を置く形は、消費する位置（束縛の見出し、値を置く位置、`move` の引数）でだけ出す。
  消費しない位置（借用・`inout` の引数など）と返り値の位置では、外の `move` を消すだけの候補にする（末尾の `move` が §5.2 の E0703 になり、§18.1 の 27 行の「当てた後に同じ段の診断を残さない」に反するため）。
  どちらの位置でも、末尾に借用か `inout` の Affine の場所があれば候補を出さない（当てると候補の無い E0711 が残る）。仕様 §5.2 の 54 行に一文を足した。担う作業は W4-09 U3（`modes/marks.rs` の候補）。
