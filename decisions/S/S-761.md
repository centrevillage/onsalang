# S-761 名前の段の誤りで本体の歩きが止まった単位で、止まった後に書いた名前を、定数と flow の循環（E0312・E0817）の辺に数えるか（`const A: U32 = nope + B` と `const B: U32 = A`）

- 空白: §18.1 は、一つの単位の中では最初のエラーで検査を止め、宣言をまたぐ循環を互いに辿り合う宣言の集まりごとに一つ報告する。定数と flow の循環の辺は、名前の段の本体の歩きの記録（W4-05 U5）から作る。単位の中で名前の段の誤りが出て歩きが止まったとき、止まった後に書いた名前を循環の辺に数えるかは書いていない。
  形: `const A: U32 = nope + B` と `const B: U32 = A`（`A` の値に見つからない名前）。flow の `fb` の本体で `var v = 0.0` の E0806 の後に `fa~(x)`、`fa` は `fb~(x)` をインスタンスにする。
  今（`0eb4575`）: `A` に E0302「cannot find `nope`」だけ、`fb` に E0806 だけ（E0312・E0817 は W4-05 U5 で入る）。
  読み: (1) 数えない（歩きの記録のとおり）。循環は名前の誤りを直した次の検査で出る。(2) 数える（書いたとおりの辺で集まりを決める）。`A` の単位に E0312 が残り（集まりの最初の名前、E0302 と同じ名前の段で位置が先）、`B` は集まりの他の宣言として note。
  どちらも誤りのあるプログラムの報告だけが変わり、降下には進まない。(2) は止まった後も辺を集める歩きの分岐が要る。再現は `target/notes/81/u5/c7_earlier_err.onsa`・`f4_assign_before.onsa`・`f5_nope_before.onsa`。
