# S-1234 イベントのクロックの刻みの中で、その刻みから出したイベントの刻みと、同じ刻みで動く他の受け手の順（`let e1 = fwd~(m)` と `cnt~(m).reset_if~(e1 != 0)`）

- 空白: §11.11 は「出す位置は出した刻みの位置で、出したイベントの刻みは出した刻みの直後に並ぶ（受け手は名前の順で作り手より下にあり、その位置の受け手の段の前に届く）」とする。作り手が `sample` の段で出す形は、受け手の `sample` の段の前に届く。
  作り手がイベントの入力のイベントごとに出す形（`flow fwd(m: U32 at event) -> U32 at event { Some(m) }`）で、呼び出し側の同じ m の刻みに、作り手より下の別の受け手がいるとき、「出した刻み」が作り手の部品の分か、呼び出し側の m の刻みの全体かが割れる。順が値に見えるのは `reset_if~` の条件の形:
  ```
  let e1 = fwd~(m)
  let n = cnt~(m).reset_if~(e1 != 0)   // m のイベントを数え、e1 のイベントで戻す
  ```
  読み: (1) 作り手の呼び出しの直後に e1 の刻み（受け手の初期化）、その後に m の刻みの残り（`cnt` が数える）。(2) m の刻みの全体（`cnt` が数える）の後に e1 の刻み（初期化）。(2) の中で、出した e1 の刻みからさらに出す形は深さ優先と幅優先がある。
  引いた字と下書き: S-564 の下書き「出力のイベントのクロックは作り手のノードの直後に刻み」（48 行）と「(1b) なら作り手の入力のその刻みの直後」「受け手は名前の順で作り手より下にあるので、その位置の受け手の段の前に届く」（59・60 行、利用者が 50 回目に了承）、S-567 の E3・E4 の補。
  仮の扱い: 段 1 の後に書く。W7-11 U2 の期待値が待つ。
- 決定: 決定（2026-11-25、利用者。185 回目、第 119 組）: (1)。作り手の呼び出しのその刻みの仕事（保存まで）が済んだ直後に、出したイベントの刻み（受け手の初期化と処理）を、呼び出し側の段の途中で行い、m の刻みの残りはその後に続く。深さ優先。引数と修飾子の条件は字面の順に評価するので、`acc~(fwd~(m)).reset_if~(m != 0)` は足してから戻し、`let e1 = fwd~(m)` の下の `acc~(m).reset_if~(e1 != 0)` は戻してから足す。仕様の字は §11.11 の出力の項。実装は W7-11 U2（値が見えるのは U2r から）。
- 経緯: 184 回目（2026-11-25）、W7-11 の設計メモ（NEW-1）と字だけの値の模型（U1）が別々に挙げ、親が登録した（`target/notes/184/w711/`）。
