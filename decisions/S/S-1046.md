# S-1046 巻き上げ（§11.3）で、状態の隠れたフィールドに Copy でない値（`Option[Str]` の静的な値など）を置くか

- 空白: §11.3 は遅いクロックの最大の部分式を状態に置く（巻き上げ）とし、§12.4 は状態の値型を Copy とするが、巻き上げる部分式の型を限らない。`pick(if c { Some("a") } else { None }, x)`（`c` は `block`、`Option[Str]` の静的な値）を巻き上げると、状態の隠れたフィールドに Copy でない値を置く。今は呼び出しの巻き上げが未実装（Core は毎サンプル呼ぶ。第 104 組の下書きの `hoist.txt`）。
  読み: (1) Copy の部分式だけを巻き上げる（Copy でない値は Copy の部分まで降りる）。(2) E0810 にする。(3) 静的な値なら置いてよい。S-1043 の決定（flow の本体の暗黙の `Alloc`）で、静的な値でない形は先に誤りになりうる。
  急ぎ: W7-05（巻き上げ）の前。
- 決定: 決定（2026-11-19、利用者。168 回目。第 113 組。下書き（onsa-gap）と独立のレビューの段 1（onsa-advisor）と親の読みを突き合わせた。控え `target/notes/168/g113/`）: (a)。巻き上げるのは型が Copy の部分式だけ。最大の遅い部分式が Copy でなければ巻き上げず、読む側の段で評価し、その中の Copy の部分式を S-1157 の規則で巻き上げる。(b) E0810（同じ式が条件のクロックだけで誤りになる）と (c) 静的な値を状態に置く（§12.4 の Copy の約束を破り、第 2 期まで実装できない）は採らない。仕様 §11.3。
