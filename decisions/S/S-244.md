# S-244 `test` の名前の文字列の規則

- 空白: `test` の名前の文字列の規則。補間を書けるか（今は `test "a{X}b"` が式の補間の E0001 で、名前なのに文面が合わない）、空の名前（`test ""`）、改行を含む名前（今は通り、テキストの出力が改行をそのまま出す）。S-242 の下書きで見つけた（2026-10-08）
- 提案: 名前は空でない、補間を含まない文字列リテラルで、値に制御文字（改行とタブを含む）、U+2028 / U+2029、双方向の制御文字を含めない（エスケープで書いても）。違反は構文の段の E0002 と note で、候補は出さない。同じ名前かは値（コードポイントの並び）で比べ、正規化しない。完全な名前のテキストのエスケープは `\`、`"`、`{`、`}` の四つ。入れ子のまとまりは S-275（(a)。利用者。仕様 §11.8。2026-10-08 決定。実装は W2-10）
