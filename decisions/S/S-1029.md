# S-1029 型パラメータを関数型で具体化した総称の関数の値（`keep_t::[fn(U32) -> U32]`）の引数が、捕捉する無名関数を受けるか（S-809 の E0710 を関数値の経路でどう守るか、R-450）

- 空白: S-809 は、第二級の関数値（既定のモードの関数型の引数、捕捉する無名関数）を渡せるのは宣言の型の頭が関数型の既定のモードの引数だけとし、型パラメータの引数へ渡すと E0710 とする。総称の関数を関数型で具体化して値に置くと、値の型 `fn(fn(U32) -> U32) -> fn(U32) -> U32` は既定のモードの関数型の引数を持つので、捕捉する無名関数を渡せ、本体は `x: T` として検査済みなので返せる（R-450、再現は `issues/R/R-450/escape.onsa`）。
  決めること: 具体化した値の型の引数を `move` にする（`fn(move fn(U32) -> U32) -> …`。単相化した本体は関数だけを受けるので §13.5 の表し方と合う）か、関数型で具体化した総称の関数を値に置く形を誤りにするか、ほかの形か。今通る形（`ap[T](f: fn(T) -> U32, x: T)` の `ap(hof, inc)`、`hof` は既定のモードの関数型の引数を持つ）が誤りになるかも案ごとに示す。
  急ぎ: W8-09（関数値の降下）の前。S-874 の読み (2)（Copy の引数のモードの互換）を採るなら、その前に決める。
