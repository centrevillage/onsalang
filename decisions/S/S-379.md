# S-379

- 空白: 無名関数の引数と返り値の型の後ろの `at`（`fn(x: F32 at sample) -> F32 at sample { … }`）のコード。S-356 は fn の入出力の型の後ろを名前の段の E0821、S-368 は handler の関数の引数も同じとしたが、無名関数を挙げない。W3-09 は `Param.clock` と `Closure.ret_clock` に入れて名前の段に任せている。W3-09/b で見つけた（2026-10-09）
- 提案: 決定（2026-10-09、利用者が ID を挙げて了承。親の案）: fn と同じく E0821（名前の段）。無名関数の引数と返り値は関数と同じ宣言の形で、flow の入出力でないため。仕様 §11.3。実装は W3-09（`Param.clock` と `Closure.ret_clock` に入れる）と W4-12（E0821）
