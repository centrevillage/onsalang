# S-97

- 空白: std のテスト用の補助をどこから呼べるかが仕様に無い。`std/test.onsa` の doc は「第 1 期は `test` の本体の中だけ」とするが、検査していない。効果行の無い関数から `check`（`uses {Random}`）を呼んでも検査を通る（第 1 期の効果の検査は `Alloc` だけ）。`Gen { seed: 7 }` と生成器を通さずに `Gen` を作れる（レビュー R-125）
- 提案: 補助は普通の std の関数として扱い、`test` の本体に限る規則は作らない。E0601 は第 1 期から std が宣言する全ての効果の使用を検査する（S-23 の「第 1 期は `Alloc`」を改めた。判定は S-77 の使用の記録を読む）。
  第 1 期の `Random` の E0601 は修正候補（効果行への追加）を出さず、「この版では `Random` はテストの本体でだけ与えられる」と note で示す（足すと E0200 になるため。D-08 の追記）。
  std の `Gen` のフィールドを `priv` にし、`std/test.onsa` の doc を「`Random` はテストの本体でだけ与えられる」に改める。`tests/review-phase1/parent/r125.onsa` の期待値と今の出力は各項目の上のコメント（2026-10-05 決定。実装は第 3 段。E0601 は R-83 と同じ回）
