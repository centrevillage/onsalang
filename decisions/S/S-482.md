# S-482

- 空白: S-435・S-459・S-464 で読み続けた宣言のうち、可視性が正しく書かれているもの（`#[inline] pub fn h`、`pub async fn h`、`pub const fn h`）の可視性。§18.1 は「読み続けた宣言の可視性は無指定」と書く。
  仮の扱いは、可視性の形そのものが誤り（`pub(crate)` など）か衝突（`pub priv`）のときだけ無指定にし、正しく書かれた `pub`・`priv` は記録する（`lower.rs` の `SPEC-GAP(S-482)`）。W3-08/t2 と W3-08/i の設計メモが別々に見つけた（2026-10-13）
- 提案: 後の段（W4-03 の前）
- 時期: W3
- 決定: 決定（2026-10-23、利用者が ID を挙げて了承。55 回目、第 38 組）: 族の規則 S-593 の (2) から決まる。読み続けた宣言の可視性は、正しく書かれた可視性が一種類（`pub pub fn` の重なりは一つと数える、S-464）で、可視性の形が無ければ書かれたとおり、それ以外は無指定（今の実装の `lower/failed.rs`）。`pub(crate) pub fn` は無指定（独立のレビューの段 2）。
  §18.1 の「読み続けた宣言の可視性は無指定である」と、S-435・S-459 の決定の文を、この記録の文に置き換えた（両方の決定に改めを書いた）。仕様 §18.1
- 経緯: 55 回目（2026-10-23）、W4 の前の S の下書き（X-8）の第 38 組（族 S-593、下書き `S-482.draft.md`、助言の担当の二段）。
