# S-482

- 空白: S-435・S-459・S-464 で読み続けた宣言のうち、可視性が正しく書かれているもの（`#[inline] pub fn h`、`pub async fn h`、`pub const fn h`）の可視性。§18.1 は「読み続けた宣言の可視性は無指定」と書く。
  仮の扱いは、可視性の形そのものが誤り（`pub(crate)` など）か衝突（`pub priv`）のときだけ無指定にし、正しく書かれた `pub`・`priv` は記録する（`lower.rs` の `SPEC-GAP(S-482)`）。W3-08/t2 と W3-08/i の設計メモが別々に見つけた（2026-10-13）
- 提案: 後の段（W4-03 の前）
- 時期: W3
