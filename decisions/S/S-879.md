# S-879 `assert x, "msg"`（Python）と `assert!(x, "msg")`（Rust）を、他の言語の書き方の E0020 と修正候補にするか（今は一般の E0002「expected newline or `}`, found `,`」）

- 空白: - 空白: `assert x > 0, "positive"`（Python の形）と `assert!(x > 0, "positive")`（Rust の形）は、今は一般の E0002「expected newline or `}`, found `,`」（第 81 組の下書きの `probe/s554/rules.onsa`）。
  Python と Rust は §18.1 の他の言語の書き方の一覧（E0020）の対象の言語だが、`assert` の文面を付ける形を E0020 と修正候補にするかが決まっていない。
  候補の読み: (1) 文面を落とす `assert x > 0`（安全側）、(2) 文面を保つ `if !(x > 0) { panic("positive") }`（文面がリテラルのときだけ書ける）、(3) 候補なしで note。
