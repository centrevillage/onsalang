# S-699 見出しの配列の長さと const 引数に書いた定数の名前（`pub fn f(a: [F32; N])` の無指定の `const N`）を、S-665 の「見出しに書いた名前」に数えるか

- 空白: §15.1 は、見出しに書いた名前（型・trait・効果。型の中の型を含む）が宣言の届く範囲より狭いと E0303 とする。配列の長さと const 引数の定数式に書いた定数の名前（§4.5）が、この「名前」に入るかは文に無い。
  `const N: U32 = 4`（無指定）と `pub fn arr(a: [F32; N])` は今通る。再現は `target/notes/70/w403/u4b/t/probe/gap1.onsa`。
- 親の案（確認だけ）: 入らない。§15.1 の並びは名前の種類を型・trait・効果に限っていて、定数は無い。外の利用者は長さを数で書けるので、名前を書けない型を受け取ることにはならない（§15.1 の理由に当たらない）。仕様の文は変えない。
- 決定:
- 経緯: 70 回目（2026-10-26）、W4-03 U4b/t（onsa-test）が空白として報告した。R-277（関連定数を長さに書くと E0302、W5-08）の周辺と見たが、届く範囲の問いは別。U4b の実装は E0303 にしない。
