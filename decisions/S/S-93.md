# S-93

- 空白: `const` の評価とインタプリタが、超越関数をビルドする機械の libm（Rust の `f32::sin` など）で計算する。成果物が機械に依存しうる（レビュー R-108）
- 提案: インタプリタの `std.math` の超越関数（`MathFn`）を、Rust の標準ではなく D-11 の `std/math/soft.onsa` に結び付ける（`const` の評価、`onsa test`、`play` のインタプリタの実行の全て。外部のクレートは使わない、D-09）。D-11 ができるまでは既知の制限（成果物が機械に依存しうる）。
  D-11 を M6 から前倒しするかは、レビューの後に着手の時期を決めるときに決める。`tests/review-phase1/parent/r108/` は、二台の機械で生成した C の表を比べる手順（2026-10-05 決定）
- 時期: M5
