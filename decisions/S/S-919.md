# S-919 `...` が定数の循環に数える既定値の範囲（書かなかったフィールドだけか、struct の全ての既定値か）

- 空白: §4.4 は「`...` は定数の循環の判定に数える（既定値が読む定数が同じ struct を `...` で作る形は E0312、§6.6）」と書く。
  S-697 の決定も「`...` は循環の判定に数える（E0312）」である。`...` が埋めないフィールドの既定値が読む形（`struct S { x: U32 = A.y, y: U32 = 0 }` と `const A: S = S { x: 1, ... }`。`x` は書いたので既定値を評価しない）は、値の上では閉じない。
  読みは (1) 書かなかったフィールドの既定値だけを辺にする、(2) 括弧の文のとおり struct の全ての既定値を辺にする、の二つである。
  再現: `target/notes/118/w522/memo/probe/g3_left_out.onsa`。今は宣言の `=` が E0002 で止まる。
- 決定: 決定（2026-11-06、利用者。118 回目）: (2) `...` は struct の全ての既定値を循環の辺にする。§4.4 の括弧の文のとおりで、書いたフィールドの既定値が読む形も E0312 である。拒む側なので、後で緩めても通るプログラムは壊れない。
- 経緯: 118 回目（2026-11-06）、W5-22 の設計メモが挙げた（G3）。親が「確認だけ」で出し、利用者が了承した。
