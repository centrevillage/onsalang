# S-296

- 空白: 閉じない穴を含む `test` の名前（`test "a{b" {`）のコード。§11.8 は補間を含む名前を構文の段の E0002 とするが、閉じない穴は文字列リテラル自体が不正。今は字句の E0001「unterminated interpolation」。W2-10/i で見つけた（2026-10-08）
- 提案: 決定（2026-10-08、利用者が ID を挙げて了承。親の案: 今どおり文字列リテラル自体の字句の誤りとして E0001。字句の段は構文の段より前）
- 時期: W2
