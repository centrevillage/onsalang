# S-707 本体の経路で flow の名前空間に無い名前（`g.nosuch(…)`、型で無いと決まった `one.process_inplace(…)`）を呼ぶ・読むときの診断のコード（E0302 か、今の E0401 か）

- 空白: §15.1 は「名前が見つからなければ E0302」とし、§11.6 は「中の項目の名前は上の一覧に固定され」とするが、本体の経路が flow の名前空間に無い名前を引く形の規則は書かれていない。
  今の実装は E0401（「`one` is a flow; outside a flow body use its namespace」）を出す。`pub type Count = I32` と `pub flow one(x: F32 at sample) -> Count at sample { x.trunc_i32() }` の後の test の `one.process_inplace(inout st, one.Params {}, inout xs)`（型で無いと決まった生成項目）、`two.nosuch(inout st)`、`let f = one.process_inplace` のどれも E0401。
  読みは (1) 一般の規則どおり E0302 か、(2) 今の E0401 かで割れる。
- 決定:
- 経緯: 71 回目（2026-10-26）、W4-03 U5a/t（onsa-test）が見つけ、親が dev で再現した（`one.process_inplace` の形が E0401）。U5a の事例には入れていない。本体の名前は W4-04 の範囲。関係: S-694。
