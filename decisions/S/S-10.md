# S-10

- 空白: `std.dsp.sum` の演算順と `magnitude_at` の定義
- 提案: `sum[const N](xs: [F32; N]) -> F32` は `xs[0]` から順に左へ畳む（ビット一致のため順序を固定）。`magnitude_at` は F64 の Goertzel で、結果を F32 に丸める（`sum` は S-46 / S-84 とレビュー R-23 で `std.math.sum[T: AnyNum, const N: U32]` に改めた）
- 時期: M5
