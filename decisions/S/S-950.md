# S-950 項目の後ろの余分なトークンが継続のトークンで終わるとき、次の行が同じ単位に入るか（`pub type Op = I32 =` の次の行の `fn(I32) -> I32`）

- 空白: S-274 の決定は、項目と同じ行の後ろの余分なトークン（`;` 以外も）をその項目の単位に入れる（§18.1 の字は `;` の例だけ）。その行が継続のトークン（§2.5）で終わるとき（`pub type Op = I32 =` の次の行の `fn(I32) -> I32`）、次の行が同じ単位に入るかは決めていない。
  今の実装（`parser/file.rs` の `skip_unit` の行の読み飛ばし）は括弧の外の改行で止まり、継続を見ないので、次の行の `fn(` に「expected function name, found `(`」の E0002 が足される（入力 `b17`・`b18`・`b14`）。次の行が `fn z` なら `z` は残る（`b19`）。
  同じ単位の誤りの後の読み飛ばしは S-47 の決定の文に従って継続を見るので、二つの読み飛ばしが食い違う。
  読み: (1) 継続した次の行も同じ単位に入る。(2) 改行で止まる（今のまま）。(3) 継続しない改行か、次の行の頭が項目の始まりのときに止まる。S-947 の案と組になる。
