# S-1118 末尾に、その腕・ブロックの中で静的な値（破棄の要らないリテラル）から作った束縛の部分ビュー（`take(if c { let t = [1.0, 2.0, 3.0, 4.0] … t.slice(0, 2) } else { … })`）を置く形を、E0716 にするか、静的な値を指すとして通すか

- 空白: S-1115 は、借用の位置の末尾に、その腕・ブロックの中で宣言した束縛を根とする部分ビューを置けない（E0716）とし、根は派生した借用束縛なら派生元とした（S-796）。§5.4 は破棄の要らない値（静的な値と破棄の要らないリテラル）から `let` で作った束縛を借用束縛の起点として扱う。
  その束縛のビューを末尾に置く形（`take(if c { let t = [1.0, 2.0, 3.0, 4.0] … t.slice(0, 2) } else { y.slice(0, 2) })`）は、派生元が静的な値で根の場所が無いので S-1115 の字では置けるが、降下は `t` を腕の中のローカルな配列（Core の `let t: [F32; 4] = [1.0, …]`）にし、生成した C ではブロックの外でビューを読む（S-1115 の他の形と同じ未定義の動作）。今は通る。
  読み: (1) 腕・ブロックの中で宣言した束縛は、静的な値から作った束縛も根として E0716 にする（降下を変えない。後で静的な記憶域に置けば緩められる）。(2) 静的な値を指すとして通し、降下がその値を静的な記憶域（C の `static const`）に置く。
  再現は `target/notes/161/w712/u2c/t2/static_binding_view/`（Core）と `t2/p5.txt` の `new4_static_binding_view`。
  急ぎ: W7-12 U2c1 の前（寿命の述語の形）。
