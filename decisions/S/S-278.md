# S-278

- 空白: 範囲のパターンのうち、決定（S-249、S-257）が名指ししない形: パターンの `1...3`（`...` は一般の規則で E0020 だが、パターンでの候補の形が書かれていない）と、片側の範囲（`5..`、`..=5`、`..<5`）。第 4・5 組の決定の反映で見つけた（2026-10-08）
- 提案: 決定（2026-10-08、利用者が ID を挙げて了承。親の案: どれも S-249 と同じ構文の段の E0020 で候補はガード。`1...3` は `..` と同じく二つの読み（`1 <= k && k < 3` と `1 <= k && k <= 3`）を並べる。片側は `5..` は `k if 5 <= k`、`..<5` は `k if k < 5`、`..=5` は `k if k <= 5`、`..5` は二つ。`for` / `par` の見出しの片側の範囲は E0002 と note）。
