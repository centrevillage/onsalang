# S-284 複数行にわたる `assert` の式の `message` と結果のテキストの行

- 空白: 複数行にわたる `assert` の式の `message`（`assert <式のソース>`）と、`onsa test` の結果のテキストの行。式のソースの改行と字下げをそのまま出すか、一行に詰めるか。§11.8 は `assert <式のソース>` だけを書き、テキストの行（`spec/tools.md` §4）は一行を前提にしている。W2-10/t で見つけた（2026-10-08）
- 提案: 決定（2026-10-08、利用者。(a) と (t3)。Fable は (b) 一行に詰める と (t1) で分岐）: `message` の `assert <式のソース>` の式のソースは、式の範囲のソースの文字列（`found` と同じ切り出し）を書いたまま（改行・字下げ・範囲の中のコメントを詰めない。文の後ろの行末のコメントは範囲の外で入らない）。
  文面の改行は LF にそろえる（fmt が CR LF を LF にそろえる規則（§2.5、`spec/tools.md` §3.2）と同じ。Fable の指摘）。結果のテキストは (t3): 文面の最初の行を結果の行に置き、続く行を字下げして出す（行は §2.5 の改行で分け、字下げの幅は約束しない）。
  条件付きの了承（(t3) に他の判断事項が無く実装量が少なければ (t3)、そうでなければ (t1)）は、親の見積もり（`render_text` の十数行とテスト 1 件。(t3) に固有の判断は下書きのあわせて決めることに含まれる）で満たした。S-298 は含めない（仕様 §18.1、`spec/tools.md` §4。2026-10-08 決定。実装は W2-13）
