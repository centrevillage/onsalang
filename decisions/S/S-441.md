# S-441

- 空白: Unicode の空白（NBSP、U+2000〜U+200A、U+3000 など）の E0001 の `found`。§18.1 は「範囲が空か空白だけなら `found` を出さない」とする。親の読み: ここの「空白」は §2.5 の閉じた一覧（U+0020 とタブ）で、NBSP などは空白でない書けない文字なので `found`（その文字）を付ける。
  今は付かない（`tests/spec/negative/lex_chars_unicode_spaces_code.onsa` の 20 件が事例の器で落ちる）。W3-04/t が見つけた（2026-10-11）
- 提案: 決定（2026-10-11、利用者が ID を挙げて親の読みを了承。親が解説した後に確認）: §18.2 の「`found` は範囲が空か空白だけなら出さない」の空白は §2.5 の閉じた一覧（U+0020 とタブと改行）。
  NBSP、U+2000〜U+200A、U+3000、垂直タブなどの書けない文字の E0001 には `found`（その文字）を付ける（今は Unicode の空白の分類で判断し、NBSP と垂直タブに付かず、ゼロ幅空白には付く）。「空白だけか」の判定は字句の空白の定義から引く。仕様 §18.2。実装は W3-04
