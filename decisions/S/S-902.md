# S-902 `Hash` に上位の trait を置くか（`T: Hash` の `==`、`struct K: Hash` の derive）

- 空白: §6.3 の約束「`Hash` は、`==` で等しい値に等しいハッシュを与える」は `==` を前提にするが、§6.3 と §6.4 は `Hash` の上位の trait を書かない。今の実装に `Hash` の上位は無く、`T: Hash` の `==` は E0401（候補は `PartialEq` を足す形）である。
- 決定: 決定（2026-11-06、利用者。117 回目、確認だけ）: `Hash` に上位の trait を置かない。ハッシュの計算に `==` は要らず、§6.3 の約束は `==` を持つ型にだけ意味を持つ。`struct K: Hash` は `PartialEq` を生成しない。
- 経緯: 117 回目（2026-11-05）、S-900 の独立のレビューが新しい S の候補として挙げ、親が確認だけで出した。
