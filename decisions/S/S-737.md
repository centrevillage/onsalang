# S-737 同じ enum の列挙子と、その型の `impl` の関連定数が同じ名前のとき（`pub enum E { A(I32) }` と `impl E { pub const A: I32 = 1 }` の `E.A` が両方を指す）、E0304 か

- 空白: §4.4（95 行）は同じ enum の列挙子名の重複を、§6.6（83 行）は同じ型のメソッドと関連定数の名前の重なりを E0304 とするが、列挙子と、同じ型の `impl` の関連関数（や関連定数）が同じ名前のときを書いていない。
  関数の名前は snake_case、列挙子は UpperCamel なので、関連関数と列挙子は同じ名前にできない（`impl Sh { pub fn Circle(…) }` は E0320）。重なりうるのは関連定数で、`pub enum E { A(I32) }` と `impl E { pub const A: I32 = 1 }` は今通り、`E.A` は列挙子に解決されて関連定数に届く書き方が無い（W4-04 U9/b の報告の例を、文書の点検（78 回目）の確かめで改めた）。
  読み: (1) 型の名前の後の `.` の空間は一つとして E0304。(2) 重なってよく、列挙子が先（今の実装）。
