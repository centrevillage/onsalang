# S-737 同じ enum の列挙子と、その型の `impl` の関連関数が同じ名前のとき（`Sh.Circle` が列挙子と関連関数の両方を指す）、E0304 か

- 空白: §4.4（95 行）は同じ enum の列挙子名の重複を、§6.6（83 行）は同じ型のメソッドと関連定数の名前の重なりを E0304 とするが、列挙子と、同じ型の `impl` の関連関数（や関連定数）が同じ名前のときを書いていない。
  `pub enum Sh { Circle(I32) }` と `impl Sh { pub fn Circle(r: I32) -> Sh { … } }` は今通り、`Sh.Circle(…)` は列挙子に解決されて関連関数に届く書き方が無い（W4-04 U9/b の報告。確かめきっていない）。
  読み: (1) 型の名前の後の `.` の空間は一つとして E0304。(2) 重なってよく、列挙子が先（今の実装）。
