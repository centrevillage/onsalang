# S-1007 `FixedStr` の桁を決めた浮動小数の書き足しの、NaN・無限大・収まらない値の文字と、桁の数 `d` の上限、`d = 0` の小数点（S-614 の A3）

- 空白: §4.2 は桁を決めた浮動小数の書き足しを「値を `F64` に広げて `10^d` を掛け、最近接偶数で整数に丸め、10 進で書いて小数点を入れた文字とする（NaN・無限大・収まらない値の文字は std で定める）」とし、S-614 の決定（A3）も同じ。std で定める文字（NaN、無限大、`|round(v·10^d)|` が整数に収まらない値）と、`d` の上限（上限が無いと `d > 308` で `10^d` が無限大になり、値 0 が `0 · ∞` の NaN になる）と、`d = 0` で小数点を書くか（`12` か `12.`）が決まっていない。
  仕様の式から一つに決まると読む所（W5-12 の設計メモ）: 負の 0 と 0 に丸まる負の値は `0.00`（整数に丸めた 0 は符号を持たない）、1 より小さい値は 0 を詰めて `0.05`。
