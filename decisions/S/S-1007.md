# S-1007 `FixedStr` の桁を決めた浮動小数の書き足しの、NaN・無限大・収まらない値の文字と、桁の数 `d` の上限、`d = 0` の小数点（S-614 の A3）

- 空白: §4.2 は桁を決めた浮動小数の書き足しを「値を `F64` に広げて `10^d` を掛け、最近接偶数で整数に丸め、10 進で書いて小数点を入れた文字とする（NaN・無限大・収まらない値の文字は std で定める）」とし、S-614 の決定（A3）も同じ。std で定める文字（NaN、無限大、`|round(v·10^d)|` が整数に収まらない値）と、`d` の上限（上限が無いと `d > 308` で `10^d` が無限大になり、値 0 が `0 · ∞` の NaN になる）と、`d = 0` で小数点を書くか（`12` か `12.`）が決まっていない。
  仕様の式から一つに決まると読む所（W5-12 の設計メモ）: 負の 0 と 0 に丸まる負の値は `0.00`（整数に丸めた 0 は符号を持たない）、1 より小さい値は 0 を詰めて `0.05`。
  待つもの: W5-12 U3b の書き足しの関数とその事例。
- 決定: 決定（2026-11-11、利用者「いったん良さそう」。139 回目。設計メモの仮の形と、親の意見を伏せた onsa-advisor の段 1 を比べ、割れた 3 は段 1 の再現できる事実で親も段 1 の案を推した）: NaN は `NaN`、無限大は `inf`・`-inf`（§6.3 の `Show` と同じ綴り。`d` によらない）。有限の値で、`d` が 22 を超えるか、丸めた整数の絶対値が 2^64 以上なら、`*` の一字（符号なし。`d` が大きめの普通の値（`440.0` の `d = 17`）も当たる）。22 は `10^d` が `F64` で正確に表せる最大。`d = 0` は小数点を書かない（`12`）。`10^d` を掛けるのは `F64` の乗算（`1.075` の 2 桁は `1.08`）。書く長さは多くて 25 バイト（`d` が 19 以下なら 22 バイト）。std の文書にこれらと「正確な 10 進の丸めと違うことがある」ことを書く。「いったん」の了承なので、W5-12 U3b の実装と壊す側の結果で見直してよい。
- 経緯: 139 回目（2026-11-11）、W5-12 の設計メモ（onsa-impl、`P/w512/memo/memo.md` の 9 章）が挙げた。
