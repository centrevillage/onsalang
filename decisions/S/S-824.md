# S-824 マニフェストの E0200 の閉じた一覧に無い、今の実装が拒む値（`provides` の `Alloc` 以外、`bind`、未知の `platform`）

- 空白: §15.3 は「仕様にあってこの版のコンパイラが未対応のもの（`kind` の `clap`、`lang` の `js`、std 以外の依存、`main_frame` など）は、使った位置で E0200」とし、`tasks/diag-codes.md` の E0200 の行は「マニフェストの未対応の値の閉じた一覧」を挙げる。
  その一覧は、今の実装が拒む `provides` の `Alloc` 以外、`bind`、未知のアーキテクチャと OS の `platform` を挙げない。
  読みは (1) 閉じた一覧に足す（そのターゲットのビルドで E0200） (2) 形の誤りの E1103（全てのコマンド）に割れる。
  三つ組でない `platform`（`zz80-none`）をどちらにするかも書いていない。
  今の実装は `platform = "zz80-none"` で `build` だけが使い方の誤り「unknown architecture」（コードなし、終了コード 2）、`check` は 0（`target/notes/95/w402/probe/` の `a25_bad_platform`）。
  `provides = ["Fs"]` と `bind` は `Feature::ManifestProvides`・`ManifestBind` の文面（`(E0200)`、位置なし、`build` だけ）
- 決定: 決定（2026-11-01、利用者が ID を挙げて了承。95 回目、第 77 組）: (a)。この版が扱えない `provides` の効果（`Alloc` 以外）、中身のある `bind`、この版が見分けられない `platform` は E0200 で、そのターゲットのビルドと `--target` を取るコマンドで出す。
  `platform` は欄の数で分けず一つの E0200 にし、note にこの版のアーキテクチャと OS の表と `"host"` を示す。`provides` は未対応の効果の要素ごとに一件、`bind` は表の見出しに一件。`platform` に形の規則は足さない。
  理由: 効果の名前と `platform` は仕様が集合を閉じない値で、この版が扱える部分は版で広がるので E0200 に当たる。E1103 を版によらない規則に保ち、未対応のターゲットで `check`・`test` を止めない S-154 とも揃う。§15.3 は変えず、`tasks/diag-codes.md` の E0200 の閉じた一覧に足した
- 経緯: 95 回目（2026-11-01）、W4-02 の設計メモ（onsa-impl）が見つけた。急ぎ: W4-02 U3 の前
