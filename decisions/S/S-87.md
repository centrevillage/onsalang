# S-87

- 空白: `@param` の値の型と範囲を検査しない。値はリテラルだけで、補間を黙って捨てる。`Bool` と enum の入力は内部エラー。C の表は `float` と NAN で型の情報が無い（レビュー R-99）
- 提案: sema で入力の値型を確かめ（E0809）、数値と文字列のキーを `const` の初期化式と同じ道で型付けし（E0401）、定数の評価の段（R-89）で評価して制約を確かめる（E0809）。`ParamMeta` は評価済みの型付きの値（浮動小数・整数・真偽）を持ち、`f64` に潰さない。`params_default` の降下は型付きの値から作る（`v as i128` をやめる）。`onsa interface` は書かれていないキーを出さない。`onsa.h` の `onsa_param_info` を §14.2 の形にする（`onsa_clamp_*` と NaN の注釈は R-21 と一緒に消す）。`Str` の `const` は第 2 期なので、それまで文字列のキーはリテラル。`tests/review-phase1/parent/r99.onsa` の期待値と今の出力は各 flow の上のコメント（2026-10-05 決定。実装は第 3 段）
