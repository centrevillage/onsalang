# S-978 モジュール名と組込みの flow の名前の後の `::[…]`（`util::[I32].id(x)`、`prev::[F32]~(x, 0.0)`）のコード: E0412 か E0308 か

- 空白: §4.5 は「型パラメータを持たない項目（総称でない関数、flow、型パラメータ、列挙子の名前）に書いても E0412、ローカルの束縛と引数（関数値。一つの具体化を指し、型引数を取らない）に書くと E0308」とし、モジュールの名前（`util::[I32].id(x)`）と組込みの flow の名前（`prev::[F32]~(x, 0.0)`）を挙げない。
  決めること: E0412（型パラメータを持たないものへの並び。報告は型の段）か、E0308（名前の種類の誤り。名前の段）か。今は名前の段の E0200（`p16`）。組込みの flow の名前を呼び先でない形に書く `let p = prev` は今 E0308（`p17`）。
- 決定: 決定（2026-11-10、利用者。133 回目）: (a)。モジュールの名前（パッケージと子モジュールを含む）の後の並び（`util::[I32].id(x)`）と、組込みの flow の名前の後の並び（`prev::[F32]~(x, 0.0)`）は E0412 である（型パラメータを持たないものへの並び。判定は名前の段が持ち、報告は型の段。総称でない関数、利用者の flow の `lp::[F32]~(x)` と同じ道で、修正候補は無い）。
  名前がその位置自体で誤りの形（`let m = util::[I32]`、`let p = prev::[F32]`）は、今ある名前の段の診断（E0308）が先である。
  仕様: §4.5 の E0412 の列挙にモジュールの名前と組込みの flow の名前を足す。W5-10 U1a。実装の担当の設計メモと独立のレビュー（onsa-advisor の段 1、`target/notes/133/s977-advisor/`）が一致した。
- 経緯: 133 回目（2026-11-10）、W5-10 の設計メモ（onsa-impl、U1a/i）が決めていないこととして挙げ、親が固定のバイナリ（dev `f90b68ed`）で再現して登録した。再現の入力は 133 回目の scratchpad の `s977-advisor/probe/`（写しは区切りで `target/notes/133/s977-advisor/`）。
