# S-1077 族: 導くクロックと修飾子の比

- 空白: 導くクロック `at (sample / N)`・`at (sample * N)` と修飾子 `.down~(N)`・`.up~(N)` の比 N の形・型・制約と、比の違う遅い刻みの順を決める一般の規則。個々の形は S-969（修飾子の N の期待型）、S-1078（導くクロックの N）、S-1079（同じ位置の比の違う遅い刻みの順）。
  W7-02 の設計メモ（クロックの型に比を持たせる形）の前に決める（X26-18）。
- 決定: 決定（2026-11-16、利用者。157 回目、第 105 組。確認だけの一覧で了承「そのほかは記載の通りで良いです」）: 比の値は (a)、順は (p)。
  比の値: 修飾子 `.down~(N)`・`.up~(N)` の N と導くクロック `(sample / N)`・`(sample * N)` の N は、どちらも §4.5 の大きさを表す位置の定数式（型は `U32`）で、値は 2 以上の 2 のべき乗（違えば E0808）。期待型でない値と前置の `-` は E0401、`U32` に入らないリテラルは E0408、定数式でないものは E0417（遅延線の長さと同じ表、S-969）。同じ比は値で比べる。
  順: 周期の刻みのクロックは比で一列に並ぶ（`sample / 4 < sample / 2 < sample < sample * 2`）。同じ位置の遅い刻みは遅い方（N の大きい方）から並び、同じ比の刻みは本体の式の順。同じ位置で速い段が出したイベントは、それより遅い刻みには次の刻みで見える。部品の中の遅い刻みは呼び出し側の同じ比の段に入る（S-1088）。
  理由: 三つの N（`.up~(N)`、`at (sample * N)`、本体の `[T; N]`）は同じ刻みの数で、例外を足さずに遅延線の長さと同じ規則とコードになる。同じ位置の依存は遅い→速いの向きだけ（`at`、配る出力。集める入力は過去）なので、遅い方から並べればどの依存とも食い違わず、`at` は値を変えない（§11.3）ことと S-578 の入れ子の読みの両方に合う。
  W7-02 の設計メモへ: 周期の刻みのクロックは本体の `sample` × 2^k の整数 k 一つで表せる。誤りの比を持つ入出力を使う側に誤りを連鎖させない。2^24 の上限の読みは S-1089。仕様は §4.5（大きさを表す位置）、§11.3（順序、導くクロック）、§11.9（N、集めて配る時点）。
