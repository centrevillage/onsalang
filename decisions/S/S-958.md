# S-958 空白のある前置の `~` の重ね（`~ -x`、`~ !x`、`~ ~x`、`!~ x`）の診断と候補

- 空白: S-938 の `決定` は、空白のある前置の `~`（`~ a`）を接する `~a` と同じ E0020 にし、候補を `~` と空白を `!` に置き換える形とする。§3.1 は前置演算子の重ねに括弧を要る（E0012）。被演算子が前置の記号で始まる形（`~ -x`、`~ !x`、`~ ~x`）と、前置の `!` の後の空白のある `~`（`!~ x`）は書かれていない。
  読み: (1) `~a` の規則で E0020 だが、候補 `!-x` は当てた後に E0012 が残るので候補なし。(2) 接する `~-x` が今出す括弧付きの `!(-x)`（二つの編集）と同じ候補。(3) E0012。
  今の出力（固定のバイナリ `891862e`）: `let n = ~ -x`、`~ !x`、`~ ~x`、`!~ x` はどれも E0002「found `~`」で候補なし。接する `~-x` は E0020 で候補は `!(`…`)` の二編集、接する `~~x` は E0002。
- 決定: 決定（2026-11-09、利用者。127 回目）: S-961 の族の規則から。空白と改行のある前置の `~` の被演算子が前置の `-` で始まる形（`~ -x`、タブ、`~` 改行 `-x`）は E0020 で、候補 `!(-x)`（改行は被演算子の行へ移す）。`~ ~m`・`!~ m`・`- ~m` は接する形と同じ候補の無い E0002。
  二つの空白のある `~ - x` は、`-` の後の空白が `-` の所の別の誤りなので、候補の無い E0002。E0012 にはしない（`~` は Onsa の前置の演算子でなく、重ねに数えない。S-422 の `+` と同じ）。`~ !x` は S-962。§2.5 と §2.6 に書いた。
- 経緯: 126 回目（2026-11-09）、W5-11 U10d2/t（onsa-test）が仕様の空白（NEW）として報告した。事例は書いていない。急ぎは後の段。S-938 の答え（S-363 との関係を利用者に確かめている）による。
