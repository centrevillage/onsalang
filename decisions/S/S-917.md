# S-917 `enum Mode: Default`（E0416）と手書きの `impl Default for Mode` の組の E0304

- 空白: `enum Mode: Default { … }` と `impl Default for Mode { rt fn default() -> Mode { … } }` を両方書く形である。§6.4 は enum に `Default` を並べられないとし（E0416）、並べた trait を手でも書くと E0304 とする。
  §18.1 は、一覧の名前を型が満たさない E0416 の後は書いた trait として満たすとする（S-774 の (9a)）。読み: (1) 一覧は読めているので、`default` のメンバもあり、手書きのメンバとの重なりは E0304（E0416 と二件。一覧から `Default` を消せば両方消える）。(2) E0416 の連鎖として E0304 を出さない。
  親の読み: (1)。U2 の実装は `enum E: Default` にもメンバを作るので、固有のメンバとの組は既に E0416 と E0304 が並び、追加の分岐が要らない。§6.4 の文のとおりで、§18.1 に例外を足さない。二つの診断はどちらも「一覧から `Default` を消す」を指すので、書き手を迷わせない。
- 決定: 決定（2026-11-06、利用者。117 回目、確認だけ）: (1) `enum Mode: Default` と `impl Default for Mode` の組は E0416 と E0304 の二件である。一覧は読めているのでメンバがあり（S-774 の (9a)）、§6.4 の「両方に書くと E0304」のとおりで、§18.1 に例外を足さない。仕様の文は変えない。
