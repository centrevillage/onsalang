# S-36

- 空白: 可視性の既定がモジュール内で、パッケージ内の共有に `pub(pkg)` を多用することになる。`pub(pkg) use` は黙って非公開、`pub use` で可視性を広げられ、`pub(pkg) flow` の生成項目は仕様に無い（レビュー R-50 / R-106）
- 提案: `pub` / 無指定（パッケージ内）/ `priv`（モジュール内）。`pub(pkg)` は E0020。`use` の束縛は無指定でもモジュール内で、`priv use` は E0020。`pub use` は `pub` の項目だけ（E0303）。フィールドの狭め方は `priv` だけ。flow の生成項目は flow の可視性を継ぐ。
  std の `Gen.seed` は `priv` にし、作る関数を無指定で置く。`tests/spec/packages/visibility` は実装と一緒に直す。`pub(crate)` の E0020 の修正候補（今は `pub(pkg)`、`parser.rs:406`）は「外す」に改める（2026-10-03 決定。実装は第 3 段、S-35 のフィールドと同じ回）
- 時期: M2
