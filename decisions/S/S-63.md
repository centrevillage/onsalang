# S-63

- 空白: 先頭が 0 の整数 `017` を 10 進の 17 として通す。C・Go・Java の読み（8 進の 15）と違う偽の友人（レビュー R-124）
- 提案: 字句解析で、`0` 以外の 10 進の整数が 0 で始まれば E0020。候補は `17` と `15`（読みが一つなら一つ。`00` は `0`）。浮動小数の整数部の余分な 0 は S-62 で fmt が外す（2026-10-04 決定。実装は第 2 段）
- 時期: M1
