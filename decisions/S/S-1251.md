# S-1251 中で出たイベントを自分の出力にする flow（一回の段で複数出すものを含む）を呼んだとき、呼び出し側の受け手の刻みを、その flow の段の仕事の途中（中で出た刻みごと）に行うか、段の仕事の全体の後に行うか

- 空白: §11.11 は「出したイベントの刻みは、作り手の呼び出しのその刻みの仕事（保存まで）が済んだ直後に、呼び出し側の段の途中で行い」「`.up~`・`.down~` の部品の中から出るイベントは…走りごとに、その走りの直後に受け手の刻みを行う」とする。中の部品が出したイベントを自分の出力にする flow（`flow w(…) -> U32 at event { let d = beat~(…).up~(2)` と `Some(d) }`）を呼んだとき、「その刻み」が、中のイベント `d` の刻み（走りごと）か、呼び出し側の段でその呼び出しが行う仕事の全体かが割れる。
  値に見えるのは、出たイベントが同じ呼び出しに戻る形（`^` を通して同じ flow のイベントの入力へ、または同じ呼び出しの `reset_if~` の条件へ）だけで、他は panic の順だけである。
  読み: (1) 呼び出しの仕事の全体（保存まで）の後に、出た順に一つずつ。(2) 中で出た刻みの直後（flow の段の仕事の途中）。
  形は `target/notes/188/w717/s1251/forms.onsa`。待つもの: W7-17 U4（一回に複数出す flow）の期待。
