# S-1206 細部: 連鎖で動かす部品と、出力が刻みの部品の段を、呼び出し側の段のどこで走らせるか（見えるのは panic の順だけ）

- 空白: §11.9「修飾子の無い部品の中の遅い刻みは、呼び出し側の同じ比の段に呼び出しの位置で入る」（S-1088）は、連鎖（`.down~(N)`・`.up~(N)`）で動かす部品の段と、出力が刻み（`sample / N`）の部品の、出力でない段（本体の `sample` の段など）を、呼び出し側の段のどこ（呼び出しの位置か、段の終わりか）で走らせるかを書いていない。
  読み: (1) 全て呼び出しの位置（式の順）、(2) 出力の刻みは呼び出しの位置、他は段の終わり（W7-09 U2b の参照評価器）。値は変わらず、見えるのは二つの panic のどちらを報告するか（§9.2）だけ。同じ段の中の親の `let` と子の段の順は S-1159。
  仮の扱い: 参照評価器の形（W7-09 U2d、`crates/onsa_tests/src/flow_ref/chain.rs`（W7-21 U2 で `state.rs` から移した）の `run_unit` に `SPEC-GAP(S-1206)`（`run_children` の印は S-1128））: 部品の本体の段 x は呼び出し側の段 min(x + r, 0) の、その段の `let` の後・第二相の前に、呼び出しの置き場所の順で走る。ただし呼び出し側の `sample` の段に写る出力の段（r = 0 の本体の `sample`、`.up~(N)` の走り）と、出力が刻みで読み手がその刻みの段にある形は、呼び出しを読む所で走る（第二相で読む呼び出しが腕の束縛を読むため、と同じ位置で新しい刻みの値を読むため）。同じ段の子どうしの順は置き場所の順。急ぎ: W7-16 で Core と panic の位置を比べる前（`rules/leader.md` 5.11 の確認だけ）。
