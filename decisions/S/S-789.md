# S-789 移した変数の後の使用を制御の流れでどう数えるか（ループの次の反復、`var` の全体への代入、移した変数のフィールドと要素への代入）

- 空白: §5.2 は、片方の腕でだけ消費した変数はその後で使えない（47 行）、Affine のフィールドを取り出した後は `s` を使えない（55 行）と書くが、制御の流れの次の三つの形を書かない。
  (1) ループの本体で移した変数を、次の反復（`while` の条件の再評価、`continue` の道を含む）で使う形: `var b = mk(); while c { take(move b) }`、`for i in 0 ..< 1 { take(move b) }`。
  (2) 移した `var` の全体に代入して、再び使う形: `take(move b); b = mk(); b.len()`。
  (3) 移した変数のフィールドや要素に代入する形: `take(move h); h.buf = mk()`、`take(move xs); xs[0] = mk()`。
  E0704 の note の「assign it before the loop ends」も仕様に無い。古い modes と W4-07 の新しい側はどちらも、(1) は反復の回数によらず E0704、(2) は通る、(3) は移した変数の使用として E0704 にする（U1 の壊す側が `check` で確かめた）。
  親の読み（確認だけの案）: 三つとも今の実装のとおり。47 行の規則は道ごとの静的な規則で条件の値を見ないので、(1) も反復の回数を見ない。(2) は全体の代入が新しい値を置く。(3) は残りのフィールドの値が無い（フィールドごとに移動の状態を持たない、56 行）ので部分だけを書けない。
  §5.2 の 47 行の後に足す文の案: 「移動は制御の流れに沿って数える。ループの本体で移した変数を次の反復（条件の再評価と `continue` の道を含む）で使うと、反復の回数によらず E0704 である。移した `var` は全体に代入すると再び使え、フィールドや要素への代入は使用に数える（E0704）。」
- 決定: 決定（2026-10-30、利用者。87 回目。確認だけ。親の読み）: 三つとも今の実装のとおり。(1) ループの本体で移した変数を次の反復（条件の再評価と `continue` の道を含む）で使うと、反復の回数によらず E0704。(2) 移した `var` は全体に代入すると再び使える。(3) 移した変数のフィールドや要素への代入は使用に数え、E0704（フィールドごとに移動の状態を持たない）。仕様 §5.2
- 経緯: 87 回目（2026-10-30）、W4-07 U1 の壊す側（onsa-break）が空白として報告した。親が仕様の文を確かめて登録した。実装は今の形のままで、決定を待たない。
