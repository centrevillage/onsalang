# S-1182 変換の flow の本体の「状態は本体の `sample` だけ」（§11.9）は、遅い刻みの状態（`prev~(lf)`、`lf` は `sample / N` の入力）を禁じるか

- 空白: §11.9 は「本体の状態は本体の `sample` だけで、`sample_rate()` は本体の `sample` のレートである」とし、§11.4 は一般の形として `prev~(lf)` を 1/32 の刻みで一つ前とする。変換の flow の本体の、本体の `sample` でない刻みの状態を誤りにするかと、そのコードを書いていない。
  読み: (1) 説明の文（遅い刻みの状態も他の flow と同じく書ける）、(2) 制限（変換の flow の本体の、比が 0 でない刻みの状態は誤り。コードは E0813 の類）。今は導くクロックが E0002 で書けない。
  仮の扱い: (2) の E0200（保守的な側。`SPEC-GAP` は `checks.rs` の遅延の検査）。急ぎ: W7-09 U4a の前（決まれば門が要らない）。利用者が決める。
- 決定: 決定（2026-11-20、利用者。170 回目、第 115 組）: (a)。§11.9 の「本体の状態は本体の `sample` だけ」は説明の文で、変換の flow の本体にも `sample / N` とイベントのクロックの状態を書ける（§11.4 の総称の遅延）。字は S-566 の A8 のときのもので S-567 の P2 の後に残っていた。制限と読むと §11.9 の std の `avg_down32` などの作り（中で `.down~(N)` のインスタンス）が書けない。§11.9 の字を改めた。W7-09 U4a の E0200 の門は要らない。下書き・段 1・親が一致。
- 経緯: 170 回目（2026-11-20）、W7-09 U0 の設計メモ（onsa-impl、`target/notes/170/w709/memo/memo.md` の 11.2）が挙げ、親が登録した。
