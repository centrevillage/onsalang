# S-110

- 空白: flow の分岐の中で何を評価するかが節によって違う（R-14 はインスタンスの引数、S-75 は分岐の中の全て）。flow の中の守りの `if`（`if d != 0 { 100 / d }`）が効かず、fn と挙動が違う。取られない腕の束縛の値が無い（点検 C-33）
- 提案: `if` / `match` / `&&` / `||` は fn と同じく取る枝だけを評価し、枝・ガード・右辺には状態を持つものを書けない（枝とガードは E0811、右辺は E0806）。
  全ての枝を評価して状態を進める `if~` / `match~` を足す（`~` は連鎖の全体に掛かる。状態を持つものが無ければ E0812。`match~` の取られない腕の束縛は `T.default()`、無ければ E0816）。巻き上げは値と panic の有無を変えない。R-14 の決定を改めた（2026-10-06 決定。実装は flow の計画の段）
- 時期: M3
