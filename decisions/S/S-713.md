# S-713 §15.1 の E0308 の一般則と、列挙に無い位置の名前の種類の誤り（配列長の関数の名前、効果行の効果でない名前、境界の trait でない名前、fn の本体で flow を関数の形で呼ぶ `lp()`、prelude の trait の経路の呼び出し `Show.show(1)`、`panic.x()`）

- 空白: §15.1 は「名前は見つかったが、その位置に要る種類（値、型、モジュール、関数、flow、trait、列挙子、定数）でなければ E0308」とし、続けて「E0308 になるのは、…場合である」と位置を列挙する。
  列挙に無い位置の名前の種類の誤りを、一般則で E0308 にするか（列挙は主な例）、列挙を閉じた一覧として他の規則のコードのままにするかが決まっていない。
  当たる形: (a) 配列長に関数・型の名前（`[I32; g]`、`[I32; process_inplace]`）。(b) 効果行に効果でない名前（`uses {I32}`、`uses {Show}`、利用者の struct、総称パラメータの `uses {T}`）。(c) 境界に trait でない名前（`T: I32`、`[T, U: T]`、`impl` の中の `Self`）。
  (d) fn の本体で flow を関数の形で呼ぶ `lp()`（R-269）。(e) prelude の trait の名前の経路の呼び出し（`Show.show(1)`、`Float.from_bits(1)`。列挙の「名前空間でない名前の後に `.` を書く」か「メソッドを関数の形で呼ぶ」か。違うのは修正候補の有無）。
  (f) prelude の関数の名前の後の `.`（`panic.x()`。値の後のフィールドの読みか、名前空間でない名前の後の `.` か）。
  今の実装（dev `381bb7e`）: (a) E0302「array length must be a constant」、(b) E0200「effects other than `Alloc`」、(c) E0200「user-defined traits as bounds」（`I32` は trait でないのに利用者の trait の文面）、
  (d) E0401「`lp` is not a function」、(e) E0413「`Show.show` does not exist」、(f) E0413「`panic.x` does not exist」。
  再現は 75 回目の scratchpad の `w404/i/probe/b/`・`probe/c/` の `cases.txt`（区切りで `target/notes/75/w404/i/probe/` へ写す）。
- 決定: 決定（2026-10-27、利用者が ID を挙げて了承。75 回目、第 65 組。A6〜A10・A12 は確認だけ、B2 (a1)・B3 (e1)・B4 (i)）:
  - 族の規則（A6）: §15.1 の一般則が全ての位置を決め、列挙は例とする。要る種類の並びに種の制約と効果を足し、型パラメータと `Self` は型、const パラメータは値であり定数、効果行変数は効果として数える。その形にコードを定める位置に固有の規則があれば、そのコードが先（値の `x(...)` の E0020、flow の外の E0821、ローカルの配列長の E0417 など。一覧でなく優先の一文）。
  - E0200 との順（A7）: 要る種類でない名前は版によらず E0308 で、E0200 より先。E0200 は要る種類の名前でこの版が扱えないもの（この版が扱えない効果、利用者の trait の境界）に限る。形の全体がこの版に無いもの（`impl Tr for P`、`trait`・`effect` の宣言）は形の E0200 で、中の名前を読まない。(b) `uses {I32}`・(c) `T: I32` は E0308。
  - 名前空間でない名前（A8）: 名前空間はパッケージ、モジュール、型（型パラメータと `Self` を含む）、flow、効果。名前空間でない名前は、名前空間でも値でもない名前（trait、種の制約、効果行変数）。値の後の `.` は型の段のフィールドとメソッド。
  - (a)（B2、(a1)）: 定数式の位置の、値だが定数でない名前（関数、列挙子、ローカル、引数）は E0417、値でない名前は E0308。
  - (d)（A9）: fn の本体・`test`・`const` の初期化式の `lp()` は §11.1・§2.6 の E0821 で決定済み（S-101・S-267）。R-269 の `判断` を改め、`fix` を W4-12 の U4 へ移す。
  - (e)（B3、(e1)）: `Show.show(1)` は名前空間でない名前の後の `.` の E0308 で、候補なし。note でメソッドの形 `x.show()` と、関連関数は型の名前で呼ぶこと（§6.6）を示す。
  - (f)（A10、(f1)）: 関数の名前の後の `.` は型の段のフィールドとメソッド（`g.y` は E0413）。`panic.x()` はこの版では `panic` の値の位置の E0200（W5-08）。
  - 種類の中の形の違い（B4、(i)）: 同じ種類の中の形の違い（struct でない型の struct リテラル、総称でない型への型引数、関連関数をメソッドの形で呼ぶこと）は、メソッドを関数の形で呼ぶ形を除き E0308 にしない。`Option { … }` は今の E0401 のまま（仕様にコードの無い形で、実装を変えない）。
  - 宣言がこの版の E0200 の利用者の trait と効果の名前（A12）は、別の S（S-719）で決める。
  仕様は §15.1（一般則、種類の並び、優先の一文、種類の中の形の境、例の列挙、名前空間でない名前、E0200 との順）、§4.5、§8.1、§18.1 の E0200 の段落と `tasks/diag-codes.md` の E0308・E0417 に書いた。
  実装は W4-04 の U8（コードの割り当て）。U3a（型付けの切り替え）の `Show.show(1)`・`panic.x()` の出力はこの決定に従う。今 E0200 を期待する `tests/spec/effects/names_not_effects.onsa`・`names_not_effects_params.onsa` の期待は U8 で E0308 に直す。
