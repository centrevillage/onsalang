# S-1026 細部: S-908 の note（生成された型は trait を実装しない）を、生成された型を中に含む型（`Option[g.Params]`、`(g.Params, F32)`）に trait の境界を求めた E0416 にも付けるか

- 空白: S-908 は、生成された型に trait を求めた E0401・E0416 に「生成された型は trait を持たず、フィールドで比べるか補助のメソッドを書く」の note を足すとした。生成された型を中に含む型に trait の境界を求めた形は書いていない。
  今（W5-13 U5b の後）は、生成された型そのもの（`g.Params`・`g.Config`・`g.State`）の E0416 にだけ、全ての位置（値の使用、型を書いた位置、定数式）で note が付く。`struct N[T: Eq] { a: T }` の `N[Option[g.Params]]` は E0416（`T: Eq`）で、note は宣言の位置だけ（値の使用 `mk(x)` でも同じ、前から）。
  読みは (1) 中に含む型にも note を付ける (2) 生成された型そのものだけ（今のまま）。どちらも誤りとして拒む（通るプログラムは変わらない、note だけ）。仮の扱いは (2)。
