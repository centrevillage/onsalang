# S-1094 `match~` の、取られた腕より後ろの腕のガードを評価するか

- 空白: §11.5 は「`if~ c { a } else { b }` と `match~ x { ... }` は、全ての枝を評価してから一つを選ぶ」「腕は `match` と同じく、パターンとガードで選ぶ」とする。ガードが panic しうるとき（`x if 100 / d > 1 => …`）に、取られた腕より後ろの腕のガードを評価するかが決まらない。
  読み: (1) 選ぶ側は `match` と同じで、最初に合った腕で止める（後ろのガードは評価しない）。(2) 全ての腕のガードも評価する。panic の有無が変わる。
  今は `match~` が E0200（W7-06）で試せない（`target/notes/158/w701/memo/probe/q_matchtilde.onsa`）。
  仮の扱い: W7-01 の参照評価器は (1) で書き、`SPEC-GAP(S-1094)` を付ける。期待値は書かない。
