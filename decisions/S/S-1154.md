# S-1154 細部: flow の遅延の第二相で、保存する式どうしの評価の順（二つが panic するとき、どちらを報告するか。`prev~(prev~(1 / k) + 0) + prev~(3 / k)`、`k = 0`）

- 空白: §11.4 は「各サンプルで、全ての遅延の出力（保存値）を先に読み、保存する値 `e` を全て評価してから、まとめて保存する」とし、S-1126（仮の (1)）は保存する式の panic が本体の panic の後かだけを決める。保存する式どうしの評価の順を書いていない。
  読みは (1) 字面の前順（Core の表の順。外の遅延が先、入れ子は囲む遅延の保存の式の中）、(2) 第一相で読んだ遅延の順に並べ、第二相で見つけた入れ子を後ろに足す順（参照評価器 `crates/onsa_tests/src/flow_ref/` の `commit`）に割れる。違いは二つが panic するときの報告の位置だけで、値と panic の有無は変わらない。
  再現: `k = 0` の `prev~(prev~(1 / k) + 0) + prev~(3 / k)` は (1) で `1 / k`、(2) で `3 / k` で止まる見込み（W7-07 U0 の設計メモの推論。今は入れ子の遅延が E0200 の門で止まる）。
  仮の扱い: (1)（Core の `store_nodes` に `SPEC-GAP(S-1154)`）。W7-19 の参照評価器と Core の比べで違いが出れば、そこで揃える。急ぎ: W7 の区切りで、S-1126 と一緒に確認だけ（`rules/leader.md` 5.11）。
- 決定: 決定（2026-11-25、利用者。185 回目、第 119 組、確認だけ）: (1)（族の規則 S-1233）。保存する式どうしは、遅延の名前が字面に現れる順（入れ子は外が先、§11.6 の番号の順）に評価する。Core は変わらず、参照評価器の順を改める（W7-11 U2b-e）。
- 経緯: 168 回目、2026-11-19、W7-07 U0 の設計メモ（onsa-impl、`target/notes/168/w707/memo/`）が仕様の空白として挙げ、親が「細部:」で登録した。
