# S-1174 細部: `match~` の取られない腕の束縛で E0816 を当てる範囲（本体で読まない束縛、ガードだけで読む束縛）

- 空白: §11.5 は「`match~` の取られない腕の束縛は、値型の既定値 `T.default()` になり、`T` が `Default` を満たさなければ E0816」とする。本体で読まない束縛、ガードだけで読む束縛（`match~ o { Some(c) if c == 'a' => prev~(x), _ => x }`、`c: Char`）、必ず取られる腕の束縛にも当てるかを書かない（S-1131 の段 1 の報告 3 章が別の空白の候補に挙げた）。
  読みは (1) 全ての腕の全ての束縛（字のとおり）、(2) 取られない腕で既定値が観測される束縛だけ（本体で読む束縛。「読むか」の判定が要り、本体で読まない束縛は E0309 と重なる）、に割れる。誤りのプログラムの範囲だけが変わる（(1) は (2) より多くを誤りにする）。
  再現: 上の形（今は `match~` の E0200 が先）。
  仮の扱い: (1)。急ぎ: W7 の区切りで確認だけ（`rules/leader.md` 5.11）。
