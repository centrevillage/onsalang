# S-729 本体の型の位置（注釈）にローカルの束縛や引数の名前を書いたとき（`let a = 1` の後の `let _: a = 2`）、値として見つかった名前の E0308 か、型の位置はローカルを見ず E0302 か

- 空白: §15.1 は「名前は見つかったが、その位置に要る種類でなければ E0308」「値やモジュールを型の位置に書く」とするが、本体の型の位置（`let x: T`、`as T`、無名関数の引数の型）の名前の引きがローカルの束縛と引数を見るかを書いていない。
  読みは二つに割れる。(1) 型の位置もローカルを見るので、値として見つかった名前の E0308。(2) 型の位置はローカルを見ず、見つからない名前の E0302。
  今の実装（`P78/bin/onsa-u7b2`、dev `727ad03` のコード）: `let a = 1` の後の `let _: a = 2` と、引数 `n` の `let _: n = 2` は E0302「cannot find `a`」「cannot find `n`」。項目の値（関数・定数）を本体の注釈に書く形は U8a で E0308 にする（S-103）。
  再現は 78 回目の scratchpad の `w404/u8a/parent/local_ty.onsa`（区切りで `target/notes/78/w404/u8a/` へ写す）。
