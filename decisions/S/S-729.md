# S-729 本体の型の位置（注釈）にローカルの束縛や引数の名前を書いたとき（`let a = 1` の後の `let _: a = 2`）、値として見つかった名前の E0308 か、型の位置はローカルを見ず E0302 か

- 空白: §15.1 は「名前は見つかったが、その位置に要る種類でなければ E0308」「値やモジュールを型の位置に書く」とするが、本体の型の位置（`let x: T`、`as T`、無名関数の引数の型）の名前の引きがローカルの束縛と引数を見るかを書いていない。
  読みは二つに割れる。(1) 型の位置もローカルを見るので、値として見つかった名前の E0308。(2) 型の位置はローカルを見ず、見つからない名前の E0302。
  今の実装（`P78/bin/onsa-u7b2`、dev `727ad03` のコード）: `let a = 1` の後の `let _: a = 2` と、引数 `n` の `let _: n = 2` は E0302「cannot find `a`」「cannot find `n`」。項目の値（関数・定数）を本体の注釈に書く形は U8a で E0308 にする（S-103）。
  再現は 78 回目の scratchpad の `w404/u8a/parent/local_ty.onsa`（区切りで `target/notes/78/w404/u8a/` へ写す）。
- 決定: 決定（2026-10-28、利用者が ID を挙げて了承。確認だけ。78 回目、第 68 組）: (1)。
  本体の型の位置（注釈、`as`、無名関数の引数と返り値の型、型引数）も見えているローカルの束縛と引数を引き、値を型の位置に書いた E0308 にする（`let a = 1` の後の `let _: a = 2`）。§5.1 は名前空間を分けず、見えている `a` は見つかった名前である。
  型の中の定数式（配列長、const 引数）のローカルと引数は、決定済みの §4.5・S-713 (a1) の E0417 で、R-304（今は E0302）を同じ作業で直す。
  仕様は §15.1 の E0308 の例に「値（ローカルの束縛と引数を含む）」と書いた。`tasks/diag-codes.md` の E0308 の行に足した。実装は W4-04 の最後の単位（約 +30〜45 行、名前の段に閉じる）。頭の名前を引く関数は、S-733（署名の引数の名前）で見えている束縛の一覧を渡せる形にしておく。
- 経緯: 78 回目（2026-10-28）、W4-04 U8a/t（onsa-test）が空白として報告し、親が再現した。事例 `tests/spec/type_names/kind_body_annotations.onsa` は、この形を書かずに頭のコメントに空白と書いた。期限は W4-04 を終える前（本体の型の位置の名前の段は W4-04）。関係: S-103、S-713。
