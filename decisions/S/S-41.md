# S-41

- 空白: 借用束縛の判定が検査器ごとに違い、借用引数からの `let c = b`（Affine）が E0711、`inout` 引数からの `let c = move b` が通る。分解する `let` と派生の起点が仕様に無い（レビュー R-54 / R-117 / R-85）
- 提案: `LocalInfo` に所有の状態（借用 / `inout` / 所有）を一つ持たせ、全ての段がそれを参照する。借用の起点は借用引数（既定のモードと `self`）と借用の `for` の束縛、そこから派生した借用束縛。`inout` 引数は起点にならず、`move` で取り出せない（E0711）。分解する `let` は元が起点なら借用束縛（2026-10-03 決定。実装は第 2 段）
- 時期: M3
