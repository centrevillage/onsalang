# S-748 別名を対象にした `impl`（E0307）のメンバを、同じ型の直接の `impl` のメンバとの E0304 の相手に数えるか（W4-05 U2 で、前に書いた E0307 の `impl` のメンバとの E0304 が出なくなった）

- 空白: §4.4（92 行）は `impl` の対象に別名を書けない（E0307）とし、§18.1 は E0307 を `impl` の見出しの誤りとしてメンバを検査しない。§6.2 の型の名前の後の `.` の空間の E0304（S-737）に、E0307 の `impl` のメンバを相手として数えるかは書いていない。
  §18.1 の 86 行は「誤りのある宣言も、名前まで読めれば名前解決に見せる」とする一方、失敗した `use` の名前は束縛として数えない（§18.1 の 90 行）。
  読み: (1) 数えない（E0307 の単位のメンバは名前を持たない）。(2) 書いた順に数える。
  今の実装（W4-05 U2 の後、未コミット）: `type A = S`、`impl A { fn f }`、後に `impl S { fn f }` は E0307 だけ（U2 の前の `2296e83` は E0307 と、`impl S` の `f` に E0304）。順を逆にした形は前も今も E0307 だけで、今は順によらず (1) の形。
  再現は `target/notes/79/s748/`（`e0307_first.onsa`・`e0307_last.onsa`・`e0307_two_direct.onsa`）。
- 決定:
- 経緯: 79 回目（2026-10-28）、W4-05 U2/i2（onsa-impl）が空白として報告した（U2 の `decls.rs::name_members` が直接の `impl` のメンバの名前を先に入れるため）。期限は `impl` のメンバの同名を扱う W4-05 の U3 の前。関係: S-737、S-134、R-307。
