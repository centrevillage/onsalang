# S-739 束縛が、自分の宣言の型の注釈に見えるか（`let a: a = 1` は今 E0302、無名関数の `fn(x: x)` と `fn(x: I32, y: x)` は今 E0308）

- 空白: §5.1 は、見えている束縛と同じ名前を束縛できない（E0304、`let x = x + 1` もエラー）とするが、束縛が自分の宣言の型の注釈から見え始めるかを書いていない。
  今の実装（W4-04 U10、`b4b6dce`）は宣言の形で分かれる: `let a: a = 1`・`var a: a = 1` は E0302（型を記録する前に束縛を取り戻す）、無名関数の `fn(x: x) -> I32 { 1 }`・`fn(x: I32, y: x)`・返り値の `fn(x: I32) -> x` は E0308（引数を宣言した後に型を記録する）、`fn(x: y, y: I32)` は E0302。前の版は全て E0302。
  読みは二つに割れる。(1) 宣言の型の注釈には自分の名前（と同じ並びの後ろの引数）は見えない。(2) 無名関数の引数の型には前の引数が見え、返り値の型には全ての引数が見える（今の無名関数の形）。再現は `target/notes/78/w404/u10/`（W4-04 U10/b の入力の写し）の `c10.txt`。
- 決定: 決定（2026-10-28、利用者が ID を挙げて了承。確認だけ。79 回目、第 69 組）: (3)（S-741 の規則から）。
  fn の本体の `let`・`var`（分解を含む）の自分の注釈からは自分が見えず E0302（`let a: a = 1`、`let (p, q): (q, I32)`、今のまま）。無名関数の引数は見出しの全体で見え、`fn(x: x)`・`fn(x: I32, y: x)`・`fn(x: y, y: I32)`・`fn(x: I32) -> x` は E0308（定数式は E0417）。
  仕様は §5.1 の S-741 の文に含まれる。実装は W4-19（無名関数の `ahead` で仮に宣言して型を集め、本当の宣言は今の位置、約 +5〜8 行）。事例は `tests/spec/type_names/` に `let a: a`・分解の形（E0302）と無名関数の形（E0308）を足す。
- 経緯: 78 回目（2026-10-28）、W4-04 U10/b（onsa-break）の空白の NEW-2。期限は無い（診断のコードが違うだけ）。関係: S-729、S-733。
