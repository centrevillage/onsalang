# S-566 レートの変換の単位: インスタンスの修飾子か、値のクロックか

- 空白: 制御のレートとオーバーサンプリングを入れる形として、二つの設計がある。
  1. インスタンスの単位（修飾子）: `x.down~(N)` / `x.up~(N)` がインスタンスの動くレートを変え、レートを変えた区間はインスタンスの本体の中に閉じる。呼び出し側の式には、呼び出し側のクロックの値しか出ない（`down~` は保持、`up~` は N 回目の値）。補間とフィルタは本体の中か前後に flow で書く。
  2. 値の単位（値のクロック）: 値がクロックを持ち（`sample` の N 倍、1/N など）、式のクロックの規則で混ぜ方を決める。レートの違う値をつなぐには明示の変換（補間・間引きの flow）が要り、書き忘れはクロックの誤りになる。
  1 では、`decimate~(osc~(f).up~(2)).down~(2)` のように呼び出し側でレートをまたいだ流れを組むと、検査は通るが期待と違う意味になる（`decimate` は捨てた後の値しか見ない）。2 ではこの形が期待どおりの意味になるが、クロックの格子・クロックごとの段・昇格の規則が要る。
  決めること: どちらの設計（または組み合わせ）にするか。比べの基準は、誤解の少なさと誤解する書き方を防げるか、計算の費用、メモリの費用、保守の費用で、今の修正の量より将来の影響を重く見る（利用者の指示）。
- 決定: 決定（2026-10-20・21、利用者が ID を挙げて了承。48・50 回目）: 部品のレートを変えるのは修飾子 `.down~(N)`・`.up~(N)` だけで、引数やつなぎ方からは決めない。変換の flow は速い側を配列 `[T; N]` で受ける。
  周期の刻みのクロックの間は `at` で明示する（遅い→速い、本体の `sample` まで。B2 の暗黙の保持は 50 回目に S-567 で改めた）。`block < sample / N`。位相のカウンタは `init` と生成する `reset` でだけ 0 で、`reset_if~` は触れない。組込みの遅延はクロックに総称（A8 は S-567 で改めた）。
  境界の別のレートは第 35 組。仕様 §19.1
- 経緯: S-565 の確認（2026-10-20、47 回目）で、レートの変換の修飾子の対の案に、値のクロックの案との分かれ目があると分かった。関係: S-565、S-558、S-557、S-560、S-567、§19.1 のマルチレート。下書きと独立のレビューと利用者の回答は `S-566.draft.md`。
