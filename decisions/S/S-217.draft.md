# S-217 平面の要素の `let`（第二級の値の束縛）

- 決定済みで戻さないもの: 既定のモードの関数型の引数は `let` に束縛できない（S-190、36 行）。受け手と添字の左辺は引数の位置（S-181）。
- 論点: §5.3「次のものは引数の位置にだけ現れる。返り値、構造体のフィールドにはできない（E0710）。…借用だけは、§5.4 の規則で `let` と `for` に束縛できる」。表の平面の行は「`xs[k]` は `Span[T]` で、引数の位置にだけ現れる（メソッドの受け手 `xs[k].len()` と添字の左辺 `xs[k][i]` も引数の位置に含む）」と書く。

  同じ問いが、`Span` の引数の名前（28 行）、`if` の末尾（30 行）、`for ch in xs`（33 行）、`match` の対象（34 行）にある。反復元に置く `for v in xs[0]`（35 行）が引数の位置かも書いていない。

- 案: (a) 第二級の型の値は、どの束縛の場所（`let`・`var`、`for` の束縛、`match` の腕）でも束縛できない（E0710）。27〜34 行は全て E0710。反復元（35 行の `for v in xs[0]`）は引数の位置に含める。
  実装: 束縛の場所で束縛する値の型を見る述語を一つにし、`for` と `match` の腕にも当てる（約 5〜10 行）。事例は約 4 件。費用の要因: 今通る 33 行が誤りになる。チャンネルごとに回すときは添字で書く（`for k in 0 ..< 2 { out.add_from!(input[k]) }`）。
  (b) 借用の行に当たる第二級の値は、借用束縛として束縛できる。束縛した名前も第二級のままで、返す・保存する・捕捉する・`move` は E0710。所有の行（29 行の `slice` の呼び出し、31 行の `move`、32 行の `inout` の元）は E0710。
  実装: 第二級かを束縛の名前に持たせ、E0710 を束縛の場所でなく名前の使用で出す（約 30〜50 行）。W4-08 の重なりの関数が、束縛した名前を元の場所の射影（`xs[0]`）として扱う（約 10〜20 行）。事例は約 8 件。
  費用の要因: `span_stored` の期待値（E0710）を改める。関数型の引数（S-190 で E0710）とだけ扱いが分かれ、その区別の規則が一つ増える。
  (c) 今のまま。`let`・`match` は E0710、`for` の束縛は通る（`for` の束縛を借用の起点として扱う）。実装は 0 行。費用の要因: 同じ平面の要素が `let ch = xs[0]` では誤りで `for ch in xs` では通り、§5.3 の「引数の位置にだけ」と 33 行が食い違う。
  - 書き手から見える違い（`input: [Span[F32]; 2]` の借用引数、`inout out: Span[F32]`）: `let l = input[0]` と `out.add_from!(l)` は (a)・(c) で E0710、(b) で通る。`for ch in input { out.add_from!(ch) }` は (a) で E0710、(b)・(c) で通る。

- 親の補い（2026-10-23、57 回目、利用者の問い「Span を第二級にした理由は」から）: 第二級の理由は値ごとに違う。捕捉する関数値は、捕捉の環境を呼び出し側のスタックに置いてヒープ（`Alloc`）を使わないため。`Span` は他人の記憶域を指すビューで、ライフタイムを持たない（最初の草案の「参照は第二級に限定し、ライフタイムを持たない」）ため。
  §5.4 の借用束縛は、0.2 の「`let` の右辺にはできない」を、借用の起点は呼び出しの間に変わらず消えないという理由で緩めたもので、そのとき `Span` は見直されなかった。借用の起点から取った `Span` をローカルに置いても同じ理由で安全なので、(a) と (b) の違いは安全性でなく規則の単純さ（S-190 と揃うか）である。
- 回答（2026-10-23、会話で利用者。57 回目）: (b)。理由: 実用性。引数の位置だけにすると、`Span` を受け取るためだけの関数ができてしまう。同じ第二級でも、ヒープの要否（関数値）とライフタイムの要否（`Span`）で理由が違うので、扱いを変えるのは自然。
  範囲（親が示した案）: 借用の起点（借用引数、借用の `for`、`match` の腕）から来る `Span` と平面の要素は `let` と `for` に置ける。`inout` 引数からは置けない（E0710）。返す・保存するは E0710 のまま。
