# S-878 `std.math` の関数の一覧が仕様に無い（§3.4 の 138 行と §13.4 の 72 行が名を挙げるだけで、閉じた一覧の文が無い。`fmod` を外したことと `is_infinite` が無いことの根拠が S-98 だけ）

- 空白: §3.4 の 121・138 行と §13.4 の 72・76 行は `std.math` の関数を名で挙げる（`abs`・`min`・`max`・`sqrt`・`floor`・`ceil`・`trunc`・`round`・`is_nan`・`is_finite`・`exp`・`sin`・`sum` など）が、`std.math` の関数の閉じた一覧を述べる文が無い。§6.3 の組込みの trait と §6.6 の関連定数には「閉じた一覧」の表がある。
  S-98 は std の `fmod` を外すと決め、`is_infinite` は仕様に無い。読み: (1) 仕様に名の無い `std.math` の関数は無い（E0302）で、§13.4 に一覧を書く。(2) 仕様が挙げない関数を std が足してよい。
  事例: W5-14 U1/t の `std_math_fmod_removed_*.onsa` は (1) で E0302 を期待した（`fmod` は今通る）。
  急ぎ: W5-14 の終わりまで（親の読みは (1)、確認だけの見込み）
- 決定: 決定（2026-11-04、利用者。110 回目、第 81 組と一緒に (A) の確認だけ。独立のレビューの段 2 が確かめた）: (1)。
  §13.4 に `std.math` の閉じた一覧を書いた（正確に計算する `floor`・`ceil`・`trunc`・`round`・`abs`・`min`・`max`・`sqrt`・`is_nan`・`is_finite`、超越関数 `exp`・`exp2`・`log`・`log2`・`sin`・`cos`・`tan`・`tanh`・`pow`、`sum`）。名の無い関数は E0302。
  `std.math.sum` は今の std に無く（`std.dsp.sum` は `F32` だけ）、W5-07 の実装待ち（`tests/pending.toml` の `par_sum.onsa`）。仕様 §13.4
- 経緯: 110 回目（2026-11-04）、W5-14 U1/t（onsa-test）が NEW として挙げた。関係: S-98、R-126、`decisions/A/` の閉じた一覧の方針
