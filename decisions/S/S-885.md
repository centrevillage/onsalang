# S-885 `as` で書ける組の変換の関連関数を、呼ばずに値として取る形（`let g: fn(F32) -> F64 = F64.round_from`）

- 空白: §3.3（S-231 の反映の案）は `as` で書ける組について「変換の関連関数は無い（E0413）」と書き、決定は「呼び出しは E0413」と書く。`let g: fn(F32) -> F64 = F64.round_from` は呼び出しでなく、組込みの型の関連関数を値として取る形（§6.1、R-295）で、`S` は期待の型で `F32` に決まる。読み: (1) 値の形も E0413（候補なし）。(2) 呼び出しだけを E0413 にし、値の形は通す。
  今の変換メソッドを値として取る形は E0413（`x.round_f64` は「no field」）。関連関数の値の実行は今 E0200。W5-14 の S1 の判定に当たる（同じ見積もりの NEW-3）
