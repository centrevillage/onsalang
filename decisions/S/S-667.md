# S-667 flow の出力の struct の `priv` のフィールドが、生成項目の `Out` と `process` の引数に flow の可視性で出る（`pub struct P { x: F32, priv tag: F32 }` を返す `pub flow g`）

- 空白: §15.1 はフィールドを struct の可視性を継ぐか `priv` で狭めるとし（S-35）、見えないフィールドを読み書きすると E0303 とする。§11.6 は flow の出力の struct をフィールドごとの `Out` の欄と `process` の `inout` の引数に開く。
  `pub struct P { x: F32, priv tag: F32 }` を返す `pub flow g` は今の `check` を通り（`target/notes/64/g54-advisor/probe/privout.onsa`、終了コード 0）、`onsa interface` は `pub struct g.Out` の `tag: Buf[F32]` と `g.process(…, inout tag: Span[F32])` を出す。`Out` は別の型なので名前の可視性の違反ではないが、`priv` で守った不変条件が `Out` のフィールドとして外に出る。
  出力の型の位置の E0303 にするか、§11.6 に「`Out` のフィールドは出力の struct の可視性を見ない」と書いて許すかを書いていない。族「§15.1 の公開の宣言に書いた型の位置」（S-665）の外（名前でなくフィールドの話）。
