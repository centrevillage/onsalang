# S-263

- 空白: `impl` / `trait` / `effect` / `handler` / `extern` の中に書ける宣言の閉じた一覧。
  §18.1 は各メンバを「メソッド、関連定数」とするが、今は `impl` の中の `struct`・`enum`・`use`・`test`・`type`・`flow` が黙って通り（`impl` の中の `test` を `onsa test` が走らせる）、W3-14 は `trait`・`impl`・`effect`・`handler`・`extern` の入れ子だけを（スタックを溢れさせないために）E0002 にした。
  W3-14/b で見つけた（2026-10-08）
- 提案: 決定（2026-10-08、利用者が ID を挙げて了承。親の案: メンバは関数と `const` だけ（各節の規則どおり。`effect` の操作、`handler` と `extern` の関数を含む）。他の宣言はメンバの位置で E0002 と note（閉世界、Q-09）。W3-14 の直しで、拒む一覧を許す一覧に改める）
- 時期: W3
