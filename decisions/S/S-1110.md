# S-1110 フィールドの無い struct（`struct U {}`）を `sample` の出力にする flow を E0810 にするか、出力の無い flow として認めるか

- 空白: §11.6 は `Out` を「`sample` の出力が struct のとき」に作り、各フィールドを `Span[T]` とする。フィールドの無い struct（`struct U {}`）の出力は今の `check` を通り（`target/notes/159/g106/advisor/a1087.txt` の `empty_struct_out`、終了コード 0）、`onsa interface` は `a.Out // Copy; size 0` と出力の引数の無い `process` を出す。`Out` のリテラルは `a.Out {}` で、C の `<p>_out` は空の struct になり、ISO C には無い（C11 の 6.7.2.1 は struct に名前付きのメンバを一つ以上求める）。E0810 にするか、出力の無い flow として認めて `Out` を作らないかを書いていない。
  S-218 の (b) の確かめでは、フィールドの無い `Out` のリテラルは種が Copy なので借用の行になりうる（`empty_out_literal_let`）。
  急ぎ: W7-12 U2（`Out` を作る）か U3（境界の降下）の前。
