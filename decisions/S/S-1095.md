# S-1095 二項の木の中の、イベントの値だけの部分式のクロック（`(a.x + b.y) + z`、`z` は周期の刻みのクロック）

- 空白: §11.3 は「周期の刻みのクロックの被演算子は揃っていること、パラメータの種類とイベントの値は自由に混ざること、最大が無ければ E0815」、§11.11 は「周期の刻みのクロックの被演算子の無いイベントの値の式は、そのイベントのクロックの式」とする。S-567 の K4 の [確 13] は `(a.x + z) + b.y` を例にする。内側が二つのイベントの値だけの `(a.x + b.y) + z` が決まらない。
  読み: (1) 各部分式が自分の被演算子で決まり、内側の `a.x + b.y` は最大が無く E0815（「`let` に分けても同じ」と合う）。(2) 一番外の式に周期の被演算子があれば、内側のイベントの値も外の刻みで最後の値として読み、通る（`let s = a.x + b.y; s + z` と同じにするには、`let` のクロックを使う所から決めるか、複数の源を持つイベントのクロックが要る）。通るプログラムが変わる。
  今は `at event` が E0302 で書けない（W7-11）。
  仮の扱い: W7-02 の設計メモは (1) で書く（`target/notes/157/w702/memo/memo.md` の 8 章）。W7-02 U1 はイベントの行の単体テストと `EventSrc` の形を固定しない（審査、`target/notes/158/w702/review/`）。
