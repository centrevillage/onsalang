# S-755 `const` の値の位置に失敗した名前を書いたとき（`pub const C: Str = "{KK}"`、`KK` は失敗した `use`）、宣言の型の誤り（この版の Shared を含む型の E0200、`Map`・Affine を含む型の E0407）を出すか（関数の見出しの型の段の E0303 は、本体に失敗した名前があっても出る）

- 空白: §18.1 は、値の位置に失敗した名前を書いた単位では「その単位の以後を検査しない」とし、理由に後の段（引数のモードと移動、効果、rt、flow の状態の大きさ、定数の評価）を挙げる。型と宣言の位置の失敗した名前では検査を続ける（止めると単位の全体が診断の無いまま未検査になるため）。§6.6（S-610）は、`const` の宣言の型が静的に配置できなければ E0407、この版の Shared を含む型は E0200 とする。
  値の位置の失敗した名前が、同じ単位の宣言の型の判定（値に頼らない）を止めるかは書いていない。
  今: `body/entry.rs::check_const` が値の検査の後に型を判定するので、`pub const C1: Str = "{KK}"`（`KK` は失敗した `use`）には何も出ない。値が正しい `pub const C2: Str = "a"` は E0407「must be Copy in this version」（U4 で E0200 になる）。
  関数では、見出しの型の段の E0303（見えない型、§15.1）は本体に失敗した名前があっても出る（`fn f2(x: Hid) -> I32 { KK }`）。
  読み: (1) 出さない。「以後」を検査の順と読み、宣言の型の判定は値の後に置く（今の `check_const` の置き場所のまま、分類だけ改める）。(2) 出す。宣言の型は関数の見出しと同じく署名で、値に頼らずに判定でき、名前を直しても残る誤り（S-753・S-754 と同じ見方）。判定を署名の段（W4-05 U4 の整形性の段）に置く。
  どちらも誤りのあるプログラムの報告だけが変わり、通るプログラムは変わらない。(1) は U4 の見積もりの足す 35〜50 行のまま、(2) はそれに約 +3〜5 行（評価を止める印）。(2) では事例 `tests/spec/packages/failed_use_interp_holes/main.onsa` の 111 行に E0200 が足される。
  再現は `target/notes/81/u4/held/`（`C1`・`C2`・`f2`）。
- 決定: 決定（2026-10-29、利用者。81 回目、第 73 組。下書きと独立のレビューの推奨が一致）: (b)。
  `const` の宣言の型の判定（E0407 と、この版の Shared を含む型の E0200）は、値に頼らない判定として値の検査より先に行い、値に失敗した名前があっても報告する。位置は宣言の型（今の値の位置から移す）。
  `tasks/diag-codes.md` の E0407 の段の欄を「型」に改める。値の型の誤りと型の誤りが両方ある `const C15: Buf[F32] = 1` は型の E0407 が先（同じ型の段で位置が先）。置き場所は約束しない（`check_const` の頭でも署名の段でも出力は同じ）。
  理由: 型の誤りは型の構造だけで決まり（§6.6）、名前を直しても残る（S-753・S-754 と同じ見方）。§18.1 が値の位置で止める理由（後の段が分からない値を扱う）は、値に頼らない判定に当たらない。関数の見出しの型の段の誤りと、U4a が署名の段で出す `const` の型の E0710・E0416 と同じ扱いになり、修復のループが一回短い。
  誤りのあるプログラムの報告だけが変わり、通るプログラムは変わらない。仕様は §6.6 の結果の型の項に一文。実装は W4-05 U4b（`body/entry.rs::check_const` の判定を値の検査の前に。約 +0〜4 行）。
  事例 `tests/spec/packages/failed_use_interp_holes/main.onsa` の 111 行（`pub const IN_A_CONST: Str = "{KK}"`）に E0200 が足される。事例は失敗した名前の値と Shared・`Map`・Affine の型の組、`const C15: Buf[F32] = 1`、関連定数を一つずつの単位に。
- 経緯: 81 回目（2026-10-29）、W4-05 U4/i の見積もり直し（onsa-impl）が仕様の空白の候補（NEW 1）として挙げ（推奨は (1)）、親が dev `5aa4557` の `target/debug/onsa` で再現した。期限は W4-05 U4（`const` の型の判定の単位）。関係: S-610、S-753、S-754、R-85。
