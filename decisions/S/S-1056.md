# S-1056 E0610 の照合（§15.3、§8.5）で `main` とはどの関数か（ルートのモジュールの最上位の `main`、`pub fn main` だけ、どのモジュールの `main` も、`kind = "exe"` のビルドだけ）

- 空白: §15.3 は「`main` または export される関数の効果行に、`provides` に無い効果が含まれていれば E0610」、§8.5 は `main` の効果行の各効果を書く。どの `main` か（ルートのモジュールか、`pub` か、メソッドを除くか、`kind = "exe"` のときだけか）を書かない。今は `check` で照合せず、ビルドの `check_exports`（`crates/onsa_driver/src/build.rs`）は export だけを見る（R-134）。
  再現: `target/notes/150/w603/memo/probe/p4.txt` の `main_alloc`（`provides = []`、`pub fn main() uses {Alloc}`。今は x0）。実装待ちの `tests/spec/negative/build_provides_main.onsa` は `kind = "source"` のターゲットに E0610 を期待する。
  読み: (1) ルートのモジュールの最上位の関数 `main`（可視性によらない） (2) `pub fn main` だけ (3) どのモジュールの `main` も (4) `kind = "exe"` のビルドだけ（実装待ちの事例の期待とぶつかる）。
  急ぎ: W6-03 の R-134 の単位の前。
