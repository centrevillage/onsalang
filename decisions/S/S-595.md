# S-595 族: Self の名前

- 空白: `impl` の中で `Self` を書ける位置（型の位置、関連定数の型、式の経路の頭、構造体のリテラルとパターンの経路）を、仕様は位置ごとに書かない。族の規則を一つ決め、S-377（構造体のリテラルとパターンの `Self { … }`）と S-446（式の `Self.N`）をそこから決める。
- 決定: 決定（2026-10-23、利用者が ID を挙げて了承。55 回目、第 40 組）: (a)。`impl`（固有の `impl` と `impl Tr for Ty`。trait の宣言の中では実装する型）の本体の中の `Self` は、対象の型を右辺にした型別名と同じ（§4.4）で、型、関連関数と関連定数、struct リテラル、パターン、列挙子、補間の頭に書ける。総称の `impl` では型引数を `impl` の型パラメータに決めた型を指す。
  `Self[…]` は E0412（今の型引数を黙って捨てる読みを直す）、値の位置の `Self` だけは E0308、`impl` の外と見出しは E0302。補い（独立のレビュー）: 束縛は `impl` の本体だけで、中の無名関数からも見える。`onsa interface` は別名と同じく展開して表示する。fmt は `Self` と型の名前を書き換えない。
  仕様 §2.2・§4.4。S-377・S-446 はこの規則から決まる
- 経緯: 55 回目（2026-10-23）、W4 の前の S の下書き（X-8）で、同じ族の未決の S が二つなので族の規則の S として登録した。族の分けは X-8 の族の分け（54 回目、onsa-gap）。
  第 40 組の下書き（onsa-gap、`S-595.draft.md`）と助言の担当の二段で、全て一致した。
