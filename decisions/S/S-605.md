# S-605 族: §5.2 の move を書ける位置

- 空白: §5.2 は `move` を書ける位置（消費する位置と、そこに置いたブロックの末尾。S-100）と被演算子の形（後置式）を書くが、消費しない位置に置いた `move` と、`for` の見出しの `move` が範囲に付く形の段とコードを、位置ごとに書かない。族の規則を一つ決め、S-343（消費しない位置のブロックの末尾の `move`）と S-362（`for` の見出しの `move` と範囲）をそこから決める。
- 決定: 決定（2026-10-23、利用者が ID を挙げて了承。57 回目、第 42 組）: (a)。位置を継ぐ判定は modes の一か所で行う。`match`・`for` の見出しに置いたブロックの末尾の `move` は受理し、腕の束縛と反復は所有。それ以外の位置に置いたブロックの末尾の `move` は E0703 で、末尾の `move` ごとに一件、その `move` を消す候補。
  `move` の被演算子が場所でない値（呼び出しの結果、リテラル、定数、ブロック、`if`・`match`）は位置によらず modes の E0711（R-198 の段とコード）。候補は、ブロック・`if`・`match` なら外の `move` を消して各末尾の Affine の変数に `move` を置く形、それ以外は `move` を消す形。新しい値と Copy のリテラルは `move` 無しで `move` の引数に渡す（`take(Buf.zeroed(4))`）。
  括弧で囲んだ場所（`move (a)`）は中身と同じ。`par` の見出しの `move` は E0002 のまま。W5-08 の後、文の位置の末尾で型の段の E0418 と modes の E0703 を同じ文に出さない（型の段に誤りのある本体では modes を走らせない）。Copy の変数の印の非対称は S-609。仕様 §5.2、§7
