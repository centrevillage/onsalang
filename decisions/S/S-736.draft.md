# S-736 E0320 の規則に揃えた名前が、元の名前の末尾の `_` を残すか（`_g_` は `g_` か `g`、`Foo_` は `foo_` か `foo`）

- 決定済みで戻さないもの: 予約語になる名前に `_` を足すこと（S-243）、重なれば候補なし（S-652。空いている別の綴りを探さない）、語の境を仕様に書かないこと（S-651）、`@export` の名前は末尾の `_` を除くこと（S-653）。
  第 70 組の下書きの「S-736 の仕組みの出所」と「S-736 の形の表」の節（写しは `target/notes/79/g70/draft.md`）。
- 論点: §2.3 は名前を「芯と任意の末尾の一つの `_`」とし、末尾の `_` を予約語を避ける綴りとするが、E0320 の候補の「規則に揃えた名前」が元の名前の末尾の `_` を残すかを書いていない。§2.3 の例は `a__b` を `a_b` にするだけで、末尾の `_` の付いた例は無い。
  揃えた名前は S-652 の重なりの判定（候補を出すか）を決めるので、候補の数（§18.1 の約束）に関わる。
- 今の実装: 表のとおり。末尾の `_` は落ち、予約語になるときだけ付く。修復のループは一回で `clean`（`probe/s736/fixloop.out`）。`fn gain` のあるモジュールの `fn Gain_` は、揃えた名前 `gain` が重なって候補なし。
- 案: 
  - (1) 元の名前の末尾に `_` があれば、揃えた名前の末尾にも一つ残す（`_g_` は `g_`、`Foo_` は `foo_`、`a__b_` は `a_b_`）。`@export` の名前は S-653 のとおり除く（例外の一つ）。§2.3 に書く。
  - (2) 末尾の `_` は残さず、予約語を避けるときだけ付ける（今の実装）。§2.3 に書く。
  - (3) 仕様に書かず、候補の名前の細部とする（今の実装のまま）。S-651 の語の境と同じく、揃えた名前の作り方は約束しない。
  - 書き手から見て: 差が出るのは、元の名前に末尾の `_` があり、揃えた芯が予約語でない名前だけである。末尾の `_` は、予約語を避けるか、シャドーイングが無いので既にある名前と重ならないよう付けることが多い（`gain` のある所の `gain_`）。
    後者で形も誤った名前（`Gain_`）では、(1) は `gain_` の候補を出し、(2)・(3) は `gain` が重なって候補なしになり、書き手が手で改名する（検査が一回増えうる）。末尾の `_` と形の誤りが重なる名前は、現実には少ない見込みである（`git grep` で、std と examples に末尾の `_` の名前はほぼ無く、事例のものは予約語を避ける形（`type_`、`match_`、`Self_`、`inout_`）と名前の規則を試す形が主）。
  - 修正候補を当て続けて止まるか: どの案も揃えた名前は規則に合う識別子で、一回で止まる。(1) は `@export` の名前で `_` を残すと、当てた後に同じ E0320 が残るので、例外が要る。
  - 通るプログラム: どの案も変わらない。変わるのは候補の名前と、重なりによる候補の有無だけである。
  - 規則と例外: (1) は §2.3 に一文と、`@export` の例外を一つ。(2) は §2.3 に一文（例外なし）。(3) は文を足さない。
  - 実装の量: (1) は `Shape::candidate` で元の名前の末尾の `_` を見て足す（約 +3 行）と、W4-02 の `@export` の候補で除く（約 +1〜2 行）。今の事例の候補の期待で、末尾の `_` の付いた名前のもの（変異の掃引の `_v_` の形）を直す。(2)・(3) は 0 行。
    後の段への手当てはどの案にも無い。第 2 期に名前の種類が増えても、作り方は一つの関数にある。
- 他言語: 
  - rustc 1.94.1（`probe/other/s736.rs`）: 名前の規則の警告の候補は末尾の `_` を落とす（`Foo_` は `foo`、`fooBar_` は `foo_bar`、`max_` は `MAX`、`point_` は `Point`、`Abc_` は `abc`）。頭の `_` は残す（`_gX_` は `_g_x`）。`Type_` は予約語になるので「raw identifier」を勧める。
  - Python の PEP 8（https://peps.python.org/pep-0008/#descriptive-naming-styles）: 末尾の一つの `_` は、予約語との衝突を避ける慣習（`class_`）とする。名前の規則の道具（pylint、ruff）はこの機械に無く、候補は未確認。
