# S-344

- 空白: 強弱の無い群（剰余と加法など）が、木の中で被演算子として隣り合わない式（`a % b == c + d`、`x + 1 == y % n`、`a * b < c % d`）を E0010 にするか。
  §3.1 は「強弱の無い群どうしを括弧なしで混在させるとエラー（E0010）」とし、字面では一つの式に強弱の無い群が二つあれば誤りと読めるが、部分順序で読みが一つに決まる（`(a % b) == (c + d)`）。W3-07 の実装は木の辺（被演算子として直接つながる演算子どうし）で判定し、これを通す（`SPEC-GAP(S-344)`）。W3-07/t で見つけた（2026-10-09）
- 提案: 親の案: 木の辺で判定する形に §3.1 の文を明確にする（読みが一つに決まる式は誤りにしない）。後の段で確かめる
- 時期: W3
