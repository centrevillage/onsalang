# S-529 `,` だけの行の行末のコメント

- 空白: `,` だけの行の行末のコメント（`[1 // c1` 改行 `, // c2` 改行 `2]`）。fmt は `,` を前の要素の後ろへ移す（S-497）ので、その行に要素が残らず、§3.4 の「行末のコメントは、その行の要素の後ろ」が当たらない。
  今の fmt は `[1, // c1` 改行 `// c2` 改行 `2]`（コメントを次の要素の前のコメントだけの行にする）。`tests/cst/trivia_comments_brackets.onsa` の `// c39` がこの形で、gate の `fmt-comments` が落とす。W3-11/t（U4）が見つけた（U3b/i の報告にもある。2026-10-14）
- 提案: 決定（2026-10-14、利用者が ID を挙げて推奨の (1) を了承。下書きと Fable が一致、第 31 組）: 今の挙動。`,` を前の要素へ移し、行末のコメントはコメントだけの行として同じ位置に残る（`[1,` 改行 `// c` 改行 `2]`）。前の要素の行のコメントの有無によらない（S-497 の細部と同じ）。`spec/tools.md` §3.2（`,` の移動）・§3.4。fmt の変更は無く、gate の判定を W3-11 の U4 で直す
- 時期: W3
