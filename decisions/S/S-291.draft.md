- 他言語: 
  - rustc 1.94.1（`probe/other/r1.rs`）: `f(return 1);` と `let y = f(return 1);` は警告「unreachable call」（呼び出しの位置。既定で警告の lint `unreachable_code`）。`1 + return 5` は警告「unreachable expression」（`+` の式）。
    `c && return true` は警告なし（右は常には評価されない）。式の型は変えず、`let x: i32 = 1 + return 5;` は型の誤り「cannot add `()` to `i32`」も出す。
  - swiftc 6.3.1（`probe/other/s1.swift`・`s2.swift`）: `1 + fatalError("a")` と `f(fatalError("c"))` は誤り「cannot convert value of type 'Never' to expected argument type 'Int'」（`Never` の式を被演算子・引数に置けない）。
    文の `fatalError("e")` の後の `return 2` は警告「will never be executed」（SIL の段で出る。`-typecheck` だけでは出ない）。
  - Kotlin: `Nothing` を返す呼び出しの後のコードに「Unreachable code」の警告が出る（[Kotlin のフォーラム](https://discuss.kotlinlang.org/t/unreachable-code/813)、[DEV Community](https://dev.to/khushpanchal123/understanding-kotlins-any-unit-nothing-25hp)）。
