# S-798 `for` の反復元が派生した借用束縛のとき、本体で派生元（親）を書く形（`match o { Some(bs) => for x in bs { o = None } }`）

- 空白: §5.4 の 121〜124 行は、借用の `for`（`for s in xs`）の本体で反復元 `xs` とその一部を変更すると E0715 とする。反復元が派生した借用束縛（`match o` の腕の `bs`）のとき、本体で派生元（親）の `o` を書く形を挙げない。§7 の無効化は、次の反復の暗黙の読み（反復の続き）を使用に数えるかを書かない。W4-07 の新しい modes の §7 の索引は `for` の束縛を入れない（独立の審査の指摘 5。E0715 が担う前提）。
  `match o { Some(bs) => for x in bs { o = None } }` と `match o { Some(bs) => for x in bs { o = None; n = n + x.len() } }`（`o: Option[[Buf[F32]; 2]]` の `var`）は、dev（`9804880`）でも W4-07 U3b の新しい modes でも通る。`o = None` で `bs` の記憶域が破棄され、反復の続きと `x` が破棄済みの記憶域を指しうる。
  再現は `target/notes/87/s796/p3_place.onsa` の `p12`・`p13`。
  読み: (1) E0715 を、反復元の解決した場所（派生した束縛は派生元の場所）との重なりで判定する（S-796 の独立のレビューの案。E0702 と同じ置き換え）。(2) §7 の索引に `for` の束縛を入れ、親の変更の後の `x` と反復の続きを E0704 にする。
  急ぎ: W4-09（E0715）の前。
- 決定: 決定（2026-10-31、利用者。90 回目。独立のレビュー（onsa-advisor の段 1、想定漏れの表 約 25 形）と親の読みが一致し、段 2 を省いた）: (1)。借用の `for` の本体の E0715 は、反復元の解決した場所で判定する。
  反復元が派生した借用束縛かその経路（`match` の腕の束縛、`let` の鎖、`bs.0`、部分ビュー）なら、派生元の場所に経路を合成した場所（S-796 の E0702 と同じ置き換え）と重なる変更（代入、`inout` への受け渡し、`!` のメソッドの呼び出し、`move`）も E0715。
  異なるフィールドは重ならない（`match w.a { Some(bs) => for x in bs { w.c = 1 } }` は書ける）。Copy の束縛は束縛した時点の値なので当たらない。Dup の値の所有の反復（`for s in move bs`）は複製を反復するので当たらない。範囲の端（`for i in 0 ..< k { k = 0 }`）は場所でないので当たらない。書いた後に `break` する形も構造の規則で E0715。
  診断の位置は書き込み（代入の左辺、`inout` の引数、`!` の受け手、`move` の被演算子）、note は `for` の見出しと、派生のときは束縛の位置。修正候補は無い。書けない場所の E0701 を先にし、E0715 の書き込みは状態を変えない（`move` が E0715 のとき、前の反復で移した E0704 を出さない）。入れ子の `for` は書き込みに一件で、重なる見出しごとに note。
  §5.4 の 132 行の E0715 の一覧に `!` のメソッドの呼び出しを足し（§3.5 と §7 の変更の定義に合わせる）、派生元の文を足した。S-796 の「担う作業」の「W4-09・W4-10（E0715 も解決した場所で）」の確認に当たる。担う作業は W4-09（E0715）、ガードの E0715 は W4-10 で同じ口。
  要約・票・入力は `target/notes/90/s795-798/`。
