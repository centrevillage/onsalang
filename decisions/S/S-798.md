# S-798 `for` の反復元が派生した借用束縛のとき、本体で派生元（親）を書く形（`match o { Some(bs) => for x in bs { o = None } }`）

- 空白: §5.4 の 121〜124 行は、借用の `for`（`for s in xs`）の本体で反復元 `xs` とその一部を変更すると E0715 とする。反復元が派生した借用束縛（`match o` の腕の `bs`）のとき、本体で派生元（親）の `o` を書く形を挙げない。§7 の無効化は、次の反復の暗黙の読み（反復の続き）を使用に数えるかを書かない。W4-07 の新しい modes の §7 の索引は `for` の束縛を入れない（独立の審査の指摘 5。E0715 が担う前提）。
  `match o { Some(bs) => for x in bs { o = None } }` と `match o { Some(bs) => for x in bs { o = None; n = n + x.len() } }`（`o: Option[[Buf[F32]; 2]]` の `var`）は、dev（`9804880`）でも W4-07 U3b の新しい modes でも通る。`o = None` で `bs` の記憶域が破棄され、反復の続きと `x` が破棄済みの記憶域を指しうる。
  再現は `target/notes/87/s796/p3_place.onsa` の `p12`・`p13`。
  読み: (1) E0715 を、反復元の解決した場所（派生した束縛は派生元の場所）との重なりで判定する（S-796 の独立のレビューの案。E0702 と同じ置き換え）。(2) §7 の索引に `for` の束縛を入れ、親の変更の後の `x` と反復の続きを E0704 にする。
  急ぎ: W4-09（E0715）の前。
