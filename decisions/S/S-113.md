# S-113

- 空白: 要るのに NULL の `bulk` / `cfg` を渡された `_init` が返す値が無い（R-49 の決定と S-112 は失敗とだけ書いた。点検 C-44）
- 提案: 2 を返し（`_process` の 2 と同じく呼び出し側の引数の誤り）、状態をゼロで埋めて未初期化の印を付ける。`_new` は NULL を返す。テストは、`BULK_SIZE` が 0 でない flow と Config が空でない flow で、それぞれ NULL を渡して 2 が返り、続く `_process` が 1 を返して出力が 0 になることを確かめる（2026-10-06 決定。実装は C の API の段、R-49 と同じ回）
