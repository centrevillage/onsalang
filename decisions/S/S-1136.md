# S-1136 細部: 分解する `let` と名前を束縛しない `let` の値そのものがノードのとき、そのノードの名前（`let (p, q) = g~(x)` は `p` か `p.g_0` か、`let _ = f~(x)` は `_0` か `_0.f_0` か）

- 空白: §11.6 は「`let` の値がインスタンス・遅延・`par~` の呼び出しそのものなら、そのノードは `let` の名前で呼ぶ」「分解する `let` は、パターンの中で最初に束縛する名前で修飾する」「名前を一つも束縛しない `let` は、名前の代わりに `_<番号>` を使う」とする。値そのものがノードの分解する `let`（`let (p, q) = g~(x)`、`g` はタプルか struct を出す flow）と束縛しない `let`（`let _ = f~(x)`）のノードの名前が一つに決まらない。
  読み: (1) 「`let` の名前」は単一の名前の `let` だけにあり、`p.g_0`・`_0.f_0`。(2) 最初に束縛する名前と `_<番号>` が `let` の名前の代わりになり、`p`・`_0`。表示の名前だけが変わり、通るプログラムは変わらない（(2) の `p` は分解の束縛 `p` の欄と同じ名前になりうる。族の S-1138 と関わる）。
  今: 名前は flow 全体の通し番号（R-98 の前の形）で、`let _ = lp~(x)` は `lp_1`（`P25/w703/memo/names.txt` の `n2_destructure`、`P25` は 165 回目の scratchpad）。
