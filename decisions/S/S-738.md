# S-738 本体の型の位置と効果行（`uses {n}`）に、見えているローカルや引数を書いたとき、S-729 と同じく E0308 か、効果行はローカルを見ず E0302 か

- 空白: §15.1 は「名前は見つかったが、その位置に要る種類でなければ、位置によらず E0308」「効果行に効果でない名前を書く（`uses {I32}`、§8.1）のも E0308」とし、S-729 は本体の型の位置（注釈、`as`、無名関数の引数と返り値の型、型引数）が見えているローカルと引数を引くと決めた。効果行の名前は S-729 の決定の文に挙がっていない。
  読みは二つに割れる。(1) 効果行も見えているローカルと引数を引き、E0308。(2) 効果行はローカルを見ず、見つからない名前の E0302（今の実装）。
  今の実装（W4-04 U10、`b4b6dce`）: 本体の注釈の関数型の効果行 `let _: fn() -> I32 uses {n} = …`、無名関数の `fn(x: I32) -> I32 uses {n} { x }`、署名の `fn f(n: I32) -> I32 uses {n}` は E0302（前の版も同じ）。署名の形は S-733 と同じ問い。再現は `target/notes/78/w404/u10/`（W4-04 U10/b の入力の写し）の `c18.txt`。
- 決定: 決定（2026-10-28、利用者が ID を挙げて了承。確認だけ。79 回目、第 69 組）: (1)（S-741 の規則から）。
  効果行の名前も型の位置と同じ範囲の束縛を引き、見えているローカルと引数は E0308「`n` is a local, not an effect」。
  無名関数の効果行は名前の段の歩き手が読む形に移す（型の `type_sites` と同じく site を記録して `lower_types` で読み、結果を型付けが読む。`body/expressions.rs` の 617 行の `read_effects` を外す）。R-308（効果行の見つからない名前が後ろの名前の段の誤りに隠れる）が同時に直る。
  仕様は §8.1 の E0308 の例に `uses {n}` を足した。実装は W4-19（約 +20〜30 行）。事例 `tests/spec/effects/kind_effect_row.onsa` に本体・無名関数・署名の `uses {n}` と、順の形（`issues/R/R-308/closure_row_then_name.onsa` の形で 2 行の E0302）を足す。
- 経緯: 78 回目（2026-10-28）、W4-04 U10/b（onsa-break）の F3 と空白の NEW-1。期限は無い。S-733 と同じ組で決めるとよい。関係: S-729、S-733。
