# S-47

- 空白: 行の継続の規則がブロックの中に限られ、トップレベルでは `const` の `=` の後だけ継続し、`type` の `=` と `->` の後は E0002（レビュー R-58）
- 提案: 継続の規則をトップレベルにも適用する。次の行が `uses` で始まる場合も継続。ブロックの `{` が次の行にあれば E0003（修正候補は前の行へ移す）。`else` と `{` の位置は、改行を空白として扱う場所（括弧・腕の中、クロージャの `fn(i)` の後）でも検査する（レビュー R-62）。
  エラー回復で行頭の項目キーワードまで読み飛ばすとき、前の行が継続のトークンで終わっていれば項目の始まりとみなさない（関数型 `fn(I32) -> I32` で始まる継続の行のため）（2026-10-03 決定。実装は第 2 段）
