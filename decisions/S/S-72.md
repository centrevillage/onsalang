# S-72

- 空白: 標準 trait がコンパイラの閉じた列挙 `Bound` と含意の表 `implies` で、§6.3 の組込み型の実装も Rust の表。上位の trait（`Ord` は `PartialOrd` と `Eq` を要する）を宣言に書く構文が無い（レビュー R-127）
- 提案: 標準 trait は std の `trait` 宣言、組込み型の実装は std の `impl` とし、コンパイラは lang item（演算子の脱糖、補間の `Show`、`T.default()`、`Drop`、derive、`for` の `Iter`）だけを知る。
  上位の trait は宣言の頭に `: trait + trait`（§4.5 / §6.4 と同じ読み）、満たさない型への `impl` は E0416。第 1 期の `Bound`・`implies`・Rust の表は暫定で、R-79 の第 4 段では 1 行が 1 つの `impl` に対応する形で作る。
  第 2 期の trait の実装で置き換える（計画 `implementation-plan.md` §5 の持ち越しの一覧）（2026-10-04 決定）
- 時期: 第 2 期（第 1 期は暫定）
