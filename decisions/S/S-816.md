# S-816 flow を `.(` で呼ぶ形（`lp.(x)`）

- 空白: §6.1 は `.(` で呼ぶもの（関数値）と `f(x)` で呼ぶ項目を並べるが、flow はどちらにも無い。§15.1 は flow を値の位置に書く形を E0308、§11.1 は flow の外で flow を `~` 無しで呼ぶ形を E0821、§2.6 は flow の本体で flow を `~` 無しで呼ぶ形を E0811 とする。`lp.(x)` がどれに当たるかを書いていない。
  今は名前の段の E0308「`lp` is a flow, not a value」で候補なし。
  読み (1): 今の E0308。読み (2): flow の本体は E0811、外は E0821。読み (3): `.(` で項目を呼ぶ形の E0020 で、候補なし（候補 `lp(x)` は、当てると同じ名前の段の E0811 か E0821 が残り、§18.1 の約束を破るので出せない。W4-12 の設計メモの審査、93 回目）。
