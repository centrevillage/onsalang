# S-914 再帰する型の `==` が `rt` の中でデータの深さだけ再帰する形（`enum L: PartialEq { Nil, Cons(Array[L]) }`）

- 空白: `enum L: PartialEq { Nil, Cons(Array[L]) }` と `rt fn same(a: L, b: L) -> Bool { a == b }` は今 `check` を通る（`Array` の `==` の降下は E0200）。
  生成する `__eq` は `rt: true`（`crates/onsa_core/src/lower/eq.rs`）で、`Array` の `==` を降下すると循環になる見込みである。§10 の規則 5 は生成する関数を書かず、深さは値で決まるので §12.5 の上限の主張に当たる。読み: (1) `rt` の中の再帰する型の `==` を誤りにする。
  (2) 値の深さで決まるので `onsa audit --stack` が「不明」と報告する。
- 決定:
- 経緯: 117 回目（2026-11-06）、第 89 組の下書き（onsa-gap）が新しい S の候補として挙げた。S-911 の (d) で生成する関数だけの循環を報告しないことと関係する。期限の候補は `Array` の `==` を降下する作業の前である。
