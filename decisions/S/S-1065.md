# S-1065 静的な値の経路（`["a", "bc"][i]`）と、末尾が全て静的な値の `if`・`match`・ブロックを、`let` を経ずに値を置く位置（リテラルの要素、早い出口で待つ値、`[e; N]` の要素）に直書きしたとき、破棄が要らないと数えるか

- 空白: §5.4 は、`let` の束縛が破棄の要らない束縛になる初期値を「場所か、静的な値か、破棄の要らないリテラルか、それらの経路」とし、`if`・`match`・ブロック式は発散しない全ての末尾で決める。破棄の要らないリテラルの要素は「静的な値か、第一級の Copy の型の式か、破棄の要らないリテラルか、破棄の要らない束縛の名前とその経路」で、静的な値の経路と、末尾で決まる式を挙げない。静的な値は構文で決まり、ローカルの名前を含む式は静的な値でない。
  このため同じ式が、`let` を経ると破棄が要らず、直書きで値を置く位置に置くと所有の新しい値として破棄が要る（`rt` の関数で E0601）。
  今（`eed963f9`、W6-04 U2 の後）: `let t = ["a", "bc"][i]` の後の `Ok(((t, v), r?))` は誤りなし、直書きの `Ok(((["a", "bc"][i], v), r?))` は E0601。`let t = if c { "a" } else { "b" }` の後の `[t; 0]` は誤りなし、直書きの `[if c { "a" } else { "b" }; 0]`・`[{ "a" }; 0]` は E0601（U2 の S-1045 (1) で新しく出る）、`Ok((if c { "a" } else { "b" }, r?))` は前も後も E0601。
  静的な値の経路を単独で待たせる `Ok((["a", "bc"][i], r?))` は U2 の R-461 の直しで誤りなし（modes は `binding::no_drop` を読み、静的な値の経路を含む）。リテラルの分類（`binding/literal.rs`）は要素に `no_drop_binding`（束縛とその経路）だけを読む。
  再現: `target/notes/153/w604/u2b/gap.txt`（`g1`〜`g9`、W6-04 U2 の壊す側の入力）。
  読み: (1) 字のとおり。直書きの静的な値の経路と、末尾で決まる式は、値を置く位置では所有の新しい値（今の実装）。(2) `let` の初期値と同じ読みを値を置く位置にも当て、破棄が要らないと数える（`binding::no_drop` を、リテラルの要素の分類と末尾で決まる式にも使う）。
