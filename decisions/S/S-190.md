# S-190 捕捉する無名関数を、関数型の引数に渡せるか

- 空白: 捕捉する無名関数を、関数型の引数（`f: fn(I32) -> I32`）を持つ利用者の関数に渡せるか。§5.3 は引数の位置に置けるとし、§4.1 は関数型を「捕捉なし」とする
- 提案: 渡せる。既定のモードの関数型の引数は関数の中で第二級（返す・保存する・捕捉する・`move` の引数へ渡すは E0710）。保存する関数は `move f: fn(...)` で、捕捉の無い関数値だけを受ける。§16.1 の `run` は `move audio` / `move control`（2026-10-07 決定。実装は W4-11、W6-01、W8-09）
  改め（2026-10-23、S-609）: 呼び出し側の `make_op(1, move inc)` と §16.1 の `move on_audio` を、`make_op(1, inc)` と `device.run(move st, inout params, on_audio, on_control)` に改めた。
  関数の項目の名前は場所でなく（`move inc` は E0711）、関数値は Dup で `move` の引数に `move` を書かない。保存する側の印（P10）は宣言の `move f`。
