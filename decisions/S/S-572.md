# S-572 境界のイベントの値の型と、std のイベントの型（MIDI、トランスポート）

- 空白: §19.1 は、イベントの値を利用者の型を含む Copy の型とし、MIDI と組込みのイベント（トランスポートの Start / Stop / Continue など）を std の型にし、C の ABI での表し方は std の型ごとに境界の形として決める、とした。§11.6 と §14.2 で境界に出せる値型は、スカラ、`[スカラ; N]`、出力の struct だけである（enum と `Option` は E0810、R-245）。決めること:
  1. 境界（export）のイベントの入出力に出せる型と、C の ABI での表し方（利用者の struct・enum、`()`）。
  2. std の MIDI の型（MIDI 1.0 か UMP か、メッセージの型の形、C での表し方）と、トランスポートの型（Start / Stop / Continue のほかにテンポや位置を含めるか）。置くモジュールと名前。
  3. イベントと信号の変換の std の flow（最後の値、イベントのあった位置で真の脈など。S-563 の `latest~`・`pulse~`）の名前と置き場所。
