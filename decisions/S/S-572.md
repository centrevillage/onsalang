# S-572 境界のイベントの値の型と、std のイベントの型（MIDI、トランスポート）

- 空白: §19.1 は、イベントの値を利用者の型を含む Copy の型とし、MIDI と組込みのイベント（トランスポートの Start / Stop / Continue など）を std の型にし、C の ABI での表し方は std の型ごとに境界の形として決める、とした。§11.6 と §14.2 で境界に出せる値型は、スカラ、`[スカラ; N]`、出力の struct だけである（enum と `Option` は E0810、R-245）。決めること:
  1. 境界（export）のイベントの入出力に出せる型と、C の ABI での表し方（利用者の struct・enum、`()`）。
  2. std の MIDI の型（MIDI 1.0 か UMP か、メッセージの型の形、C での表し方）と、トランスポートの型（Start / Stop / Continue のほかにテンポや位置を含めるか）。置くモジュールと名前。
  3. イベントと信号の変換の std の flow（最後の値、イベントのあった位置で真の脈など。S-563 の `latest~`・`pulse~`）の名前と置き場所。
- 決定: 決定（2026-10-22、利用者が ID を挙げて了承。51 回目）: export の境界のイベントの入出力に出せる型は、`@param` と同じスカラ・`()`・std のイベントの型だけで、他は E0810（flow の中と、Onsa から呼ぶ生成する API では自由。回答の (i)）。`std.midi` の `midi.Message`（MIDI 1.0 の短いメッセージを `U32` に詰める。C は `uint32_t`）と `std.transport` の `transport.Event`（Start / Stop / Continue。関連定数で作る）を置き、`Default` は 0 の語と Stop。
  テンポと位置は `block` の入力（S-575）。脈の flow は `std.dsp` で、名前は M5（`pulse` は仮）。仕様 §19.1
- 経緯: X-7（W3 の終わり、2026-10-15、利用者）で、W4 の前に決めて第 1 期の範囲を W4〜W10 に割り当てることになった。第 35 組（境界）の一つで、第 33 組（S-555〜S-559）と第 34 組（S-560〜S-567）の決定を前提にする。関係: S-171、S-560、S-563、S-564、S-568、R-245。
