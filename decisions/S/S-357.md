# S-357

- 空白: メンバの名前としての `at`（`xs.at(0)`、`s.at`）。`at` は W3-09 で予約語になる。§2.2 はキーワードをパスの `.` の直後でモジュール名として使えるとし、フィールドとメソッドの名前としての扱いを書かない。今の実装は `.` の直後のキーワードを名前として読み、型の段で解決できずに誤る（`s.if` は E0413）。W3-09/t で見つけた（2026-10-09）
- 提案: 決定（2026-10-09、利用者が ID を挙げて了承。親の案）: `.` の直後のキーワードは名前として読む（§2.2 のモジュール名のため、構文の段はキーワードを受ける）。キーワードのフィールドとメソッドは宣言できないので、`xs.at(0)` は今の `s.if` と同じく後の段の誤り。仕様 §2.2。実装は W3-09
- 時期: W3
