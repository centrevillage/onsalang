# S-285

- 空白: `std.dsp.test.energy(xs, from, to)` の範囲の外（`from > to`、`to > xs.len()`）の挙動。§11.8 は「半開区間 `[from, to)` の二乗和」だけを書く。今は std の中の `assert` で panic する。W2-10/t で見つけた（2026-10-08）
- 提案: 決定（2026-10-08、利用者が ID を挙げて了承。実装は W2-10 で済み、`SPEC-GAP(S-285)` の印は W2-13 で外す。親の案: `from <= to` かつ `to <= xs.len()` でなければ panic。添字の範囲外と同じ扱いで、範囲を切り詰めない。条件は `std/dsp/test.onsa` の doc コメントに書く）。W2-10 で実装
