# S-934 E0503 の移す候補の「覆っている腕が `_` か束縛だけ」の読み

- 空白: §7 の「修正候補は腕を消す形と、覆っている腕が `_` か束縛だけのときは、それを最後へ移す形」の「`_` か束縛だけ」の読み。読み (a) 覆う腕のパターンが `_` か束縛そのもの（`(_, _)`・`Item { _ }` は当たらない）。読み (b) 覆う腕が一つで、その腕だけで全ての値を覆う（`(_, x)` も当たる）。
- 決定: (a)。移す候補を出すのは、覆う腕のパターンが `_` か束縛そのものの形だけである（`(_, _)`・`(_, x)`・`Item { _ }` には消す候補だけを出す）。§7 の文は変えない。後で (b) に広げても候補が増えるだけである（2026-11-06 決定）。
- 経緯: 119 回目（2026-11-06）、W5-09 の設計メモ（onsa-impl）と独立の審査（onsa-advisor）が挙げ、親が固定のバイナリ `1bbe4eb` で確かめて登録した。控えは `target/notes/119/w509_memo/`。
  119 回目（2026-11-06）、利用者: どちらでも良さそうなので、実装が楽な方。親が (a) と読んだ（パターンの形を見るだけで済む）。
