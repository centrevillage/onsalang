# S-518

- 空白: 見出しの継続の行に置いた効果行のブロック形（`pub fn f(n: U32) -> U32` 改行 `uses {` 改行 `Alloc,` 改行 `} {` 改行 `n` 改行 `}`）の字下げの基準。S-498 は `{` の囲みの基準を「それを持つ形が始まる行」とし、効果行の `{` を持つ形が効果行（`uses` の行）か項目の見出し（`pub fn` の行）かを書かない。
  今の fmt は 1 行に継ぐ（S-510 の前の畳む扱い）。W3-11/t（U3a）が見つけた（2026-10-14）
- 提案: 決定（2026-10-14、利用者が ID を挙げて親の確認だけの読みを了承）: 効果行の `{` を持つ形は効果行で、基準は `uses` の行（開き括弧の行でもある）。中身はその行より 1 段深く、`}` は `uses` の行にそろえる。続く本体の `{` を持つ形は項目で、基準は見出しの最初の行。`spec/tools.md` §3.2 の字下げの箇条。実装は W3-11 の U3a
