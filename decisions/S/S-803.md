# S-803 変更で使えなくなった借用束縛の、変更と重ならない経路の使用（`w.h.n = 5` の後の `len_of(hh.buf)`、`hh` は `match w` の腕の束縛）

- 空白: §7 の 52 行は、変更した場所と重なる Copy でない束縛（腕の束縛と、そこから派生した借用束縛）を以後使えない（E0704）とし、束縛の単位で書く。S-797 は派生の鎖の射影を合成し、`let c = hh.buf` の後の `w.h.n` の変更では `c` を使えるとした（同じ意味の書き方で結果が変わらないため）。変更で使えなくなった束縛の、変更と重ならない経路を直に使う形に、文は触れない。
  `match w { W3 { h: hh, k: _ } => { w.h.n = 5; len_of(hh.buf) } }` は、W4-07 U3b からの新しい modes（`P88/bin/onsa-u4awired`）で E0704。`let c = hh.buf` を変更の前に挟む形と、明示のパターン `Holder { buf: bb, n: _ }` は通る。
  引数に渡す `fn3(hh.buf, inout w.h.n)` は E0702 の側で場所を合成して通る（S-796）。dev（`c867200`）は §7 を持たないので 3 形とも通し、U4b で配線すると前の形が新しく拒否される。
  再現は `target/notes/88/s803/`（U4a の壊す側の `c21.py`、U4 のテストの票 t3 の `g2.onsa`）。
  読み: (1) 束縛の経路の使用は、束縛の派生元の場所に経路を合成した場所で判定する（変更と重ならなければ使える。束縛の全体の使用は E0704）。(2) 束縛の単位で判定し、使えなくなった束縛の経路の使用も E0704（今の実装、§7 の 52 行の字面）。

- 経緯: 88 回目（2026-10-30）、W4-07 U4 のテストの票（t3）と U4a の壊す側（onsa-break）がそれぞれ空白として報告した。親は §7 の 52 行で決まると読んだが、S-797 の理由との食い違いと dev からの後退があるので登録した。
