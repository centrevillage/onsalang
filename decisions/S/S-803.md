# S-803 変更で使えなくなった借用束縛の、変更と重ならない経路の使用（`w.h.n = 5` の後の `len_of(hh.buf)`、`hh` は `match w` の腕の束縛）

- 空白: §7 の 52 行は、変更した場所と重なる Copy でない束縛（腕の束縛と、そこから派生した借用束縛）を以後使えない（E0704）とし、束縛の単位で書く。S-797 は派生の鎖の射影を合成し、`let c = hh.buf` の後の `w.h.n` の変更では `c` を使えるとした（同じ意味の書き方で結果が変わらないため）。変更で使えなくなった束縛の、変更と重ならない経路を直に使う形に、文は触れない。
  `match w { W3 { h: hh, k: _ } => { w.h.n = 5; len_of(hh.buf) } }` は、W4-07 U3b からの新しい modes（`P88/bin/onsa-u4awired`）で E0704。`let c = hh.buf` を変更の前に挟む形と、明示のパターン `Holder { buf: bb, n: _ }` は通る。
  引数に渡す `fn3(hh.buf, inout w.h.n)` は E0702 の側で場所を合成して通る（S-796）。dev（`c867200`）は §7 を持たないので 3 形とも通し、U4b で配線すると前の形が新しく拒否される。
  再現は `target/notes/88/s803/`（U4a の壊す側の `c21.py`、U4 のテストの票 t3 の `g2.onsa`）。
  読み: (1) 束縛の経路の使用は、束縛の派生元の場所に経路を合成した場所で判定する（変更と重ならなければ使える。束縛の全体の使用は E0704）。(2) 束縛の単位で判定し、使えなくなった束縛の経路の使用も E0704（今の実装、§7 の 52 行の字面）。
- 決定: 決定（2026-10-30、利用者。89 回目。独立のレビュー（onsa-advisor の段 1 と段 2、想定漏れの表 約 40 形）が (1) を選び、親は (2) の推奨を (1) に改めた）: (1)。
  使えなくなった束縛の経路の使用は、派生元の場所に経路を合成した場所（§5.2 の E0702 と同じ、S-796・S-797）で判定し、変更した場所と重ならなければ使える（`w.h.n = 5` の後の `hh.buf`、Copy の兄弟フィールドの `hh.m`）。
  束縛の全体の使用（`use_h(hh)`、`let g = hh`）は束縛の場所で判定し、一部の変更の後は E0704。文字列の補間の穴の経路（`"{hh.m}"`）も同じく判定する。仕様 §7（52 行と、その後の二行）。
  補い（2026-10-30、利用者。89 回目。D1・D2 の (a)）: 分解する `let` の右辺と `match` の見出しに置いた束縛かその経路は、束縛の全体の使用でなく、パターンが読む要素の経路の使用（§5.4 の 128 行の「分解する `let` は各要素の `let` と同じ」に揃え、例外を足さない）。
  読むのは束縛する要素と、リテラル・定数と比べる要素で、`_` は読まず、列挙子のパターンはその位置の値の全体を読む（`w.h.n = 5` の後も `let Holder { buf: bb, n: _ } = hh` と `match hh { Holder { buf: bb, n: _ } => … }` は使え、`Holder { buf: bb, n: 0 }` は `hh.n` を読むので E0704）。
  補い（2026-10-30、利用者。89 回目。E1、確認だけ）: 経路の中の添字の式は先に評価し、要素を読むのはその後（§3.5 の 157 行「添字 `xs[i]` は、`xs` の後に `i` を評価する」）なので、`hh.xs[{ w.h.xs[0] = 1 \n 0 }]` は E0704。仕様の文は変えない。
  E0704 の位置（経路の全体）と文面（重なった場所を名指す）は W4-07 U4b の票で親が決める（仕様は診断の位置を約束しない、S-800）。
