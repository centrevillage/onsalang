# S-247 ブロックコメントの診断のコードと修正候補

- 空白: ブロックコメント（§2.1「ブロックコメントは無い」）の診断のコードと修正候補。§18.1 の既存言語の書き方の一覧に無い。
  今は E0020 で `/* x */` を `// x` に置き換え、後ろにコードが続く行（`let a = 1 /* one */ + 2`）では後のコードがコメントに入り、複数行は一行目だけ変わって E0002 が残る。`/**/`、`/** c */`、閉じない `/* c` も E0020。後ろのコードを残す候補（コメントを行末へ移すなど）か、候補なしの E0002 か。
  W3-15/t で見つけた（2026-10-08）
- 提案: 閉じたブロックコメントは E0020 で、候補は言葉を `//` に残し、コメントの外のトークンの並びと行の切れ目を変えない（置き場所は仕様で決めず性質で約束する。その場か、始まる行の上の独立した行）。
  閉じないものと入れ子（`/* a /* b */ c */`）は候補なしの E0002 と note。`/** */` は付けられる宣言が続けば `///`、無ければ `//`（継続行の ` * ` は剥がない）。`/*! */` はファイルの先頭なら `//!` と `///` を並べる。
  字句解析器は `*/` を行をまたいで探す（R-174）（(a)。利用者。仕様 §2.1。2026-10-08 決定。実装は W3-15、W3-17）
