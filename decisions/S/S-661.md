# S-661 `impl` のメンバの `target` 宣言（std の `impl F32 { pub target rt fn to_bits(self) -> U32 }` と、利用者の `impl` の同じ形）

- 空白: D-07 の追記（2026-10-04、R-79、S-69）は、組込み型のメソッド・関連関数・関連定数を std の `impl` に Onsa で宣言するとし（`impl F32 { pub target rt fn to_bits(self) -> U32 }`）、§15.2 も「組込み型のプリミティブのメソッド」を std の `target` 宣言に数える。
  今の構文の段は、std を含む全てのパッケージで `impl` の中の `target` を E0002「`target` cannot be declared in an `impl`」にする（`target/notes/64/s629/probe2/impl_body.onsa`・`impl_nobody.onsa`）。std の `impl` の `target` メンバを構文の段で受けることと、利用者の `impl` の同じ形をどの段のどのコードで止めるかを書いていない。
- 決定:
- 経緯: 64 回目（2026-10-24）、第 53 組（S-629）の下書き（onsa-gap）が新しい S の候補として挙げ、独立のレビューの段 1・段 2 も別の S とした。期限は std の `impl` に `target` を書く W5-02 の前。関係: S-629、D-07、S-108。
