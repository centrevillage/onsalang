# S-980 const パラメータにローカルを書いた他言語の形の型引数（`z[k]()`）の候補 `::`: 当てた後に残るのは型の段の E0417

- 空白: §4.5（S-974）は「名前の段で見つける形は、当てた後に名前の段までの誤りが残る中身（項目 `f` に書いた中身がローカルの値の `f[i](x)`、型パラメータに書いた整数の `f[4](x)`、型として読めない `f[[1; 4]](x)`）には修正候補を出さない」とする。
  const パラメータを持つ `fn z[const N: U32]()` にローカルを書いた `z[k]()` は、当てた後の `z::[k]()` に残るのが型の段の E0417 の見込みで（型の位置の `Ring[F32, k]` は今「`k` is a local, not a constant」の E0417。`p14`）、名前の段の誤りではない。
  決めること: 一般の条件（名前の段までの誤りが残らない）どおり候補を出すか、§4.5 の例「ローカルの値の `f[i](x)`」を全てのローカルと読んで出さないか。今は `z[k]()` が型の段の E0413「cannot be indexed」（`p12`）。
- 決定: 決定（2026-11-10、利用者。133 回目）: (a)。const パラメータにローカルを書いた他言語の形（`z[k]()`）は、名前の段の E0020 に候補 `z::[k]()` を出す。候補の条件は一般のまま（当てた後に名前の段までの誤りが残らない）で、当てた後に残る型の段の E0417（`k` はローカルで定数でない）は後の段の誤りである（§18.1）。型パラメータに書いたローカル（`f[i](x)`。当てた後に名前の段の E0308 が残る）には出さない（S-974 のまま）。
  S-974 の限る案（中身が一つの名前か整数のリテラル）でも `k` は一つの名前で、判定はその名前の種類（型か値か）が宣言の位置と合うかを見る。
  仕様: §4.5 の候補を出さない例を「型パラメータに書いたローカルの値の `f[i](x)`」と言い直す。W5-10 U3。実装の担当の設計メモと独立のレビュー（onsa-advisor の段 1、`target/notes/133/s977-advisor/`）が一致した。
- 経緯: 133 回目（2026-11-10）、W5-10 の設計メモ（onsa-impl、U1a/i）が決めていないこととして挙げ、親が固定のバイナリ（dev `f90b68ed`）で再現して登録した。再現の入力は 133 回目の scratchpad の `s977-advisor/probe/`（写しは区切りで `target/notes/133/s977-advisor/`）。
