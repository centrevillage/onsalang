# S-1078 導くクロック `at (sample / N)`・`at (sample * N)` の N の形・型・制約とコード

- 決定済みで戻さないもの: `at` の後ろの一つの名前がクロックの名前空間に無いときの E0302（S-359）、経路の E0002（§11.3）、flow の外の E0821（行 33）、型の中の E0020（§11.3、S-356）。
- 論点: §11.3（89 行）は「`at` の後ろは名前一つか、括弧で包んだ導くクロック（`(sample / N)`、`(sample * N)`）で、経路（`x at a.b`）は E0002」とする。
  N の扱いは S-1077 の規則から決まる。残るのは、括弧の中が二つの形でないとき（行 24〜29）と、括弧の無い形（行 30・31）のコードである。
  底は `sample` だけである。クロックの宣言（`clock fast = sample / 32`）は使わない（§11.9、語の予約は残す）。`block` と `init` は周期を持たず、`event` は入力ごとのクロックなので、どれも比を掛ける底にならない。
- 今の実装: 括弧を読まないので、行 24〜29 はどれも `(` の位置の E0002「expected the name of a clock, found `(`」。行 30 は `/` の位置の E0002（候補なし）、行 31 は E0011 で候補は `(x at sample) / 2` の一つ（`P17/g105/probe/out*/`）。
- 案:   - (a) 構文の段で形を決める: 括弧の中は `sample`、`/` か `*`、N の被演算子一つ（リテラル、定数の名前、括弧で囲んだ式、前置の `-`）だけを読む。他の形（行 24〜29）は全て構文の段の E0002 で、note で二つの形を示す。
    `sample` はこの形の字として読み、名前の段はこの底を引かない（`(smaple / 2)` も E0002）。
    費用の要因: 名前の後ろに続く字で `sample` の綴りを見る所が構文解析器に一つ増える（文脈の語）。
  - (b) 底は名前の段で引く: 構文の段は `( 名前 (/ か *) 被演算子 )` を読み、他の形は E0002。底はクロックの名前空間で引き、無ければ E0302（S-359 と同じ）。
    `sample` 以外のクロック（`block`・`init`・`event`）は、入出力の宣言では E0810、式では E0815（書いたクロックの種類の誤りと同じコード）。
    費用の要因: 名前の段に、底の種類を見て位置で二つのコードに分ける枝が増える。`(foo / 2)` は E0302 の後に `(block / 2)` と直すと E0810 になりうる。
  - (c) 括弧の中を式として読み、形は後の段で判定する: 構文の段は `(` の後を一つの式として読み（配列の長さ `[F32; N]` と同じ）、名前の段が形を見て、二つの形でなければ入出力では E0810、式では E0815。
    費用の要因: `(sample / 2 * 2)` は普通の優先順位で `(sample / 2) * 2` に読まれ、形の判定に、木の形と書いた字のずれの説明が要る。底の `sample` が値の名前として引かれないよう、名前の段に除く枝が要る。
- 他言語: SOUL と Cmajor は比を処理器の名前の後ろに `* 4`・`/ 100` と書き、底の名前を書かない（S-1077 の項目の出典）。Pure Data と Max は比を `block~`・`poly~` の引数の数で与える。底の誤りのコードを持つ例は無い。
- 推奨と理由: (a)。確度: 中。
  クロックの名前空間は閉じていて、比を掛けられる底は `sample` だけなので、括弧の中の形は字で一つに決まる。(a) は誤りを一つの段の一つのコードにまとめ、書き手は note の二つの形を見て一回で直せる。
  (b) は今の言語では `sample` 以外の底が全て誤りなのに、名前の段を通して位置で二つのコードに分け、typo の後にもう一回の往復が起こりうる。(c) は配列の長さと揃うが、木の形と字の形のずれを判定と文面で説明し続ける。
  将来クロックの宣言を使うことになっても、(a) の E0002 を通るように緩める変更は今のプログラムを壊さない。
  - 括弧だけの `at (sample)`（行 29）: E0002 で、候補は括弧を外す形（意図は一つ）。`at (block)` も同じ。
  - 宣言の括弧の無い形（行 30）: 宣言の型の後ろに二項演算子は来ないので読みは導くクロックだけで、E0002 の候補は `at (sample / 4)` と括弧で包む形。
  - 式の括弧の無い形（行 31）: §11.3 の 67 行のとおり読みが二つに割れるので、今の E0011 の候補 `(x at sample) / 2` に `x at (sample / 2)` を並べる（新しい S の候補 4。既にあるコードの候補を変えるので分けてよい）。
  - 連ねた形（行 28）: `(sample / 2 * 2)` は `sample / (2 * 2)` と `(sample / 2) * 2` に読みが割れるので E0002 で候補なし。note で N を括弧で包む書き方を示す。
