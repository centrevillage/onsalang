# S-617 `Show` の操作の形（`Str` を返すか、書き先に書くか）

- 空白: §6.3 は `Show` の文字（浮動小数は読み戻せる最短の表記）を定めるが、`Show` の操作のシグネチャ（`Str` を返すか、書き込み先を受けて書くか）を書いていない。書き込み先に書く形なら、S-614 の `FixedStr` にも同じ `Show` で書け、補間の降下と一つになる。第 2 期の `Show` の derive の前に決める。

- 経緯: 58 回目（2026-10-24）、S-614（組込みの容量付き文字列）の下書き（onsa-gap）と独立のレビューの段 2 が新しい S の候補として挙げ、利用者が了承した（S-614 の A10）。
