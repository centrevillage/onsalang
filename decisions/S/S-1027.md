# S-1027 細部: E0418 の「前の行につなぐ」候補を、後の文で型が決まる型変数の式（`make()` 改行 `-make()`）にも出すか

- 空白: §6.1 は、つないだ形を「前の行の式が括弧なしで `-` の左に読め…、演算が型に合い、結果が返り値に合うときだけ出す」とし、型がまだ決まっていない式（`fn make[T: Default]() -> T` の文 `make()`）も後の文を待たずに E0418 とする。演算が型に合うかを、後の文が決める型を含めて見るかは書いていない。
  今（`d8503f23`）は、`make()` 改行 `-make()` で後の文が `I32` に決める形（設計メモ `target/notes/142/w513u8_memo/cases2.txt` の `g1_gain_undecided`）は E0418 で、つなぐ候補は出ない（`let _` と note だけ）。W5-13 U8b は候補を読み直し（本体の全体）で判定するので、後の文が決める型で演算が合えば候補が出る見込み。
  読みは (1) 後の文が決める型を含めて見て、合えば出す (2) 試す時点で型が決まっていなければ出さない（U8b の前の挙動）。どちらも誤りとして拒む（通るプログラムは変わらない、候補の有無だけ）。仮の扱いは U8b の実装の帰結（見込みは (1)）で、実装の担当が Rust のテストで留める。
- 決定:
- 経緯: 142 回目（2026-11-12）、W5-13 U8b のテストの担当が仕様から期待を書けない形として報告した。`rules/leader.md` 5.11 の細部として U8b の帰結で進め、W5 の区切りで出す。
