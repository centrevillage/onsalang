# S-108

- 空白: 数の trait は利用者が実装できるのに、`std.math` の `abs` / `min` / `max`、超越関数、`vdelay` は組込み型のプリミティブだけで、`abs(q)`（`q: Q15`）に実装が無い（点検 C-16）
- 提案: `Float` は組込みの浮動小数だけが実装する（利用者の `impl Float` は E0307）。std の `target` 宣言は本体を持てる（std の特権）。`abs` / `min` / `max` は std に本体を書き、組込み型ではプリミティブ（`Prim` の表）、それ以外の型では本体を使う。
  単相化のときに、具体的な型でどちらを使うかを決め、Core には決めた方だけを出す（2026-10-06 決定。実装は R-79 の組込みの表の段。利用者の数の型の本体の経路は第 2 期の trait の実装で確かめる、全体計画 §5）
- 時期: M2
- 改め（2026-10-25、親）: S-669（2026-10-25）: 本体は宣言の後ろの `else` に書く（`pub target rt fn abs[T: Num](x: T) -> T else { … }`）。プリミティブも本体も無い型での使用は、使った位置で E0200（§15.2）
