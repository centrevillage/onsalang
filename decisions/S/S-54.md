# S-54

- 空白: GCC は STDC のプラグマを無視し、`onsa build` の外のコンパイルで FMA に縮約される。golden の C が `-Wall -Wextra -Werror` で失敗する（レビュー R-67）
- 提案: 内部のランタイム（`onsa__runtime.h`）に `#error` の検査: GCC で `__STRICT_ANSI__` も `ONSA_FP_CONTRACT_OFF` も無い、`__FAST_MATH__`、`__FINITE_MATH_ONLY__`、`_M_FP_FAST`、`FLT_EVAL_METHOD`。`ONSA_ALLOW_INEXACT_FP` で全て外す。
  STDC のプラグマは GCC には出さない。`-Wtype-limits` に当たる検査を生成しない。`@fp(relaxed)`（S-57）の関数は Clang の `#pragma clang fp contract(fast) reassociate(on)`、GCC の関数属性で緩める。生成した `.c` の先頭に必要なフラグを書く。
  golden の C を gcc と clang の `-Wall -Wextra -Werror` でコンパイルするテストを R-113 に入れる（2026-10-04 決定。実装は第 2 段、テストは第 1 段）
