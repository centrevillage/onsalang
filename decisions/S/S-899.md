# S-899 総称の `impl` の定数が型引数の違う具体化を経る形（`A[4]` が `A[8]` を読み、`A[8]` が値で終わる）の E0312

- 空白: §6.6 は「初期化式が、直接または他の定数を経由して自分自身を参照すると E0312」とする。総称の `impl` の定数は型引数ごとに値を持つ（S-304）ので、`impl[T, const N: U32] Rg[T, N] { const A: U32 = if N == 8 { 1 } else { R8.A } }`（`type R8 = Rg[F32, 8]`）の `R4.A` は、具体化で見れば `A[4]` が `A[8]` を読み、`A[8]` が値で終わる。
  読み: 宣言単位で見て E0312（今の出力。`names/body/cycles.rs` は定数の宣言を辺で結ぶ）、具体化単位で見て循環でなく通る（値は 1）。再現は `target/notes/116/w505/probe/s899_cycle_instances.onsa`。どの具体化でも発散する形（`A = Self.A`、`A = R4.A`）はどちらの読みでも E0312。
  親の読み: 宣言単位で E0312。定数の依存が宣言で閉じるので、検査は定数の数で止まり、具体化の数に依らない。緩める向きなので、後で具体化単位に変えても通るプログラムは壊れない。実装の変更は無い。
  急ぎ: 確認だけ。W5-05 U2 は止めない。
