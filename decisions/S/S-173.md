# S-173

- 空白: 関数を経由する定数の閉路（`const N: U32 = f()` で、`f` の署名か本体が `N` を長さに使う）が、E0312 の「直接または他の定数を経由して自分自身を参照」（仕様 §6.6）に含まれるかが決まっていない（落とし込みの K-05 / K-10）
- 提案: W9-03 の設計メモ（型の位置の定数を要るときに評価する形、K-05）と同じ回に決める。それまで、定数の初期化式の名前による閉路は W4-05 で E0312 にする
- 時期: W9
- 補い（2026-11-06、親）: W5-22（S-697）のフィールドの既定値で、derive の `default()` を経る形（`struct P: Default { x: U32 = A.x }` と `const A: P = P.default()`）も同じ問いである。§4.4 が循環に数えるのはリテラルの `...` だけなので、W5-22 はこの形を名前の段で E0312 にしない。`const A: U32 = f()` と `fn f() -> U32 { A }` と同じ扱いで、`check` は通り、評価は `const_cycle` の panic で止まる（異常終了はしない）。
