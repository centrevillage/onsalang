# S-530 （確認だけ） 前の要素と `,` の間のコメントだけの行

- 空白: 前の要素と `,` の間のコメントだけの行（`g(a` 改行 `// c` 改行 `, b)`）。§3.4 はコメントだけの行を「次の要素の前」に残すとし、`,` との順を書かない。今の fmt は `,` を前の要素の後ろへ移し（S-497）、コメントを次の要素の前に残す（`g(a,` 改行 `// c` 改行 `b)`）。W3-11/t（U4）が見つけた（2026-10-14）
- 提案: 決定（2026-10-14、利用者が ID を挙げて親の確認だけの案を了承）: `,` は前の要素の後ろへ移り、コメントだけの行は次の要素の前に残る（S-529 と同じ出力）。`spec/tools.md` §3.4 に例を足した。実装は済み（U3）
