# S-931 定数に引数を付けたパターン `LIMIT(y) =>` のコード

- 空白: 定数に引数を付けたパターン `LIMIT(y) =>` のコードが書かれていない。今は E0302。`LIMIT { x: 1 }` は今も E0308。読み (1) §15.1 の「その位置に要る種類でなければ E0308」。読み (2) E0302 のまま。
- 決定: (1)。定数に引数を付けたパターン `LIMIT(y) =>` は §15.1 の「その位置に要る種類でなければ E0308」である（`LIMIT { x: 1 }` と揃う）。候補なし。仕様 §7（2026-11-06 決定）。
