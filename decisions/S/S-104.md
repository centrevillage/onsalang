# S-104

- 空白: パラメータの ID の作り方が仕様に無い。実装は名前の文字列をそのまま使い、`id` の文字と重複を検査しない。数値の ID が無い（impl-review の §11.7 `id`）
- 提案: `id` の文字（ASCII の英字・数字・`_`・`.`、空でない）と、同じ flow の中の重複と、数値の ID（FNV-1a 32 ビットの下位 31 ビット）の衝突を、検査の段で E0809 にする（ターゲットに依らない）。
  C の `onsa_param_info` に `uint32_t number` を足し（ランタイムの `onsa.h` と生成する表）、`<prefix><flow>_param_index(uint32_t number)` を `switch` で生成する。`tests/review-phase1/parent/param_id/` の期待値と今の出力は `m.onsa` の先頭のコメント（2026-10-06 決定。実装は第 3 段。`onsa.h` は S-87 の配置の変更と同じ回に）
- 時期: M4
