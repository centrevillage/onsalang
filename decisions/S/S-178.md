# S-178 `const` の名前への代入

- 空白: `const` の名前への代入（`LIMIT = 3`）のコード。代入先が場所でない（E0415）か、変更できない（E0701 の側）か
- 提案: E0415。`inout` に場所でないもの（定数、一時値、呼び出しの結果）を渡すのも E0415 で、E0701 は場所だが変更できないものだけ（2026-10-07 決定。実装は W4-07）
- 時期: W4
- 元の下書き: `spec-gaps-w1.md` の「### S-178 `const` の名前への代入」
- 補い（2026-10-29、親）: 84 回目、W4-16 の設計メモから（利用者が了承、A4）: `inout self` の受け手も `inout` の引数なので、場所でない受け手（`mk().fill!(1.0)`、定数の `K.fill!(1.0)`）も E0415。実装は W4-16 の U3（型の段の `body/calls.rs`）。部分ビューと平面の配列リテラルは場所の並びとして除き、W4-08 の実装待ちに残す。
- 補い（2026-10-29、親）: 85 回目の文書の点検（F4、利用者が了承）: §5.2 のレシーバの文に、場所でないレシーバ（呼び出しの結果、定数）は E0415、場所だが変更できないもの（`let` の束縛、借用の引数）は E0701 を足した（84 回目の補いの `inout self` の受け手を仕様の字にした。§5.1 の `inout` に渡す値と同じ）。実装は W4-16 の U3 で、今は E0701。
