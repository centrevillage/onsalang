# S-619 借用した `Str`・`Bytes` を `Span[U8]` の引数と C の関数へ渡す形と、`Log` の操作の引数の型

- 空白: §5.3 の `Span[T]` の引数に渡せる値は `[T; N]`・`Buf[T]`・`Span[T]` で、借用した `Str`・`Bytes` を `Span[U8]` の引数に渡せるかが書かれていない。§14.1 の `extern` に渡せる「借用した `Str`」を C の関数へ渡す形（ポインタと長さか、NUL 終端か）も書かれていない。
  S-614 で `FixedStr` は `Span[U8]` の引数に渡せ、`Log` に `Span[U8]` を受ける rt の操作を一つ足すことにした。`Str` も `Span[U8]` に渡せるなら、`Log` の `info(msg: Str)` と新しい操作を一つに畳める。S-615（静的な Shared 型）の「`Str` を受ける所へ値を変えずに渡せる」とも関わるので、S-615 の後か同時に決める。
- 決定:
- 経緯: 58 回目（2026-10-24）、S-614（組込みの容量付き文字列）の下書き（onsa-gap）と独立のレビューの段 2 が新しい S の候補として挙げ、利用者が了承した（S-614 の A10）。
