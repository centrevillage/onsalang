# S-604 族: §5.4 の let の束縛の状態の表

- 空白: §5.4 の表は `let` の束縛が借用か所有かを初期化式の形で並べるが、表の行に無い初期化式の形（`if`・`match`・ブロック式の末尾、平面の要素）がどの行かを書かない。族の規則を一つ決め、S-589（`if`・`match`・ブロック式の末尾が借用の起点や静的な値のとき）と S-217（平面の要素 `xs[0]` の `Span` を `let` に束縛する形）をそこから決める。
- 決定: 決定（2026-10-23、利用者が ID を挙げて了承。57 回目、第 42 組）: (a)。表に無い初期化の元は末尾で決める。括弧は中身と同じ。`if`・`match`・ブロック式は発散しない全ての末尾で決め、全てが借用の行なら借用、一つでも所有の行なら所有。
  所有のとき、各末尾は所有の束縛の初期化として検査する（借用の Dup は複製、借用の Affine と `inout` 引数の値は候補なしの E0711、ローカルの Affine は `move` の挿入を候補にする E0711）。`for` と `match` の見出しも同じ規則で、見出しの借用の行は場所か静的な値。借用のとき派生元は末尾の場所の全てで、E0715 と S-42 の無効化はその各々に当たる。混ざる末尾を誤りにする (d) は採らない。
  場所でない `for` の反復元（`for s in f(...)`）は所有で、§5.4 の表に行を足した（`match f(...)` と対称）。全ての末尾が発散する初期化式は §7 の E0503 だけ。`match` の対象が静的な値は借用の行。
  W4-07 は、末尾を集める走査を構文の木の一つの補助にして名前の段と modes が同じものを使い、束縛の状態に派生元の並びを持たせる。静的な値だけの集成体のリテラルは S-610、今の実装の誤り（場所でない対象の腕、一時の値の破棄）は R-251。仕様 §5.4
