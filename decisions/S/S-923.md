# S-923 具体化で関数型になるフィールドの `t.f(1)`

- 空白: `pub struct T2[T] { f: T }` の `t: T2[fn(I32) -> I32]` の `t.f(1)` は、宣言の型は `T`、受け手での型は関数型である。§6.2 の「関数型のフィールド」がどちらを指すかを書いていない。今は E0413。
  読み (1) 受け手で具体化した型で決める（E0020、候補 `t.f.(1)`）。読み (2) 宣言の型で決める（E0413）。総称の本体の `t: T2[T]` の `t.f(1)` はどちらの読みでも E0413。
- 決定: (1)。関数型かは受け手で具体化した型で決める。`t: T2[fn(I32) -> I32]` の `t.f(1)` は E0020 で、候補は `t.f.(1)`。総称の本体の `t: T2[T]` の `t.f(1)` は E0413 のまま。仕様 §6.2（2026-11-06 決定）。
