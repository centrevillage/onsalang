# S-417 Rust の範囲を限る可視性

- 空白: Rust の他の制限付きの可視性（`pub(super)`、`pub(self)`、`pub(in a.b)`）。
  今は E0002「expected `pkg`, found …」で、候補も note も無い（`pub_crate` の行は `crate` だけを見る）。`pub(self)` は `priv` に当たり、`pub(super)` と `pub(in …)` は Onsa に同じ範囲が無い。
  note で可視性の 3 段階を示す E0002 か、`pub(self)` だけ候補を出す E0020 かを決める。第 22 組の下書きの付録で見つけた（2026-10-10）
- 提案: 決定（2026-10-10、利用者が ID を挙げて推奨の (a) を了承し、細部は Fable の案。下書きと Fable が一致、第 23 組）: `pub(super)`・`pub(self)`・`pub(in …)` と、`pub(` の後が `crate`・`pkg` でない他の形（`pub()`、`pub(module)`、`pub(package)` など）は、一つの E0002 の行（候補なし、note で可視性の 3 段階）。
  主の範囲は `pub` から `)`。空白を挟んでも一つの誤り、`pub` 改行 `(…)` は今の E0002（S-412）。可視性は増やさない。仕様 §15.1。実装は W3-08（`pub_pkg` と同じ回）
