# S-627 std 以外の依存の診断: 文字列でない値（`fx = { path = "../fx" }`）、E0200 の位置、使った所の E0302 との併発

- 空白: §15.3 は `[dependencies]` の値を版の文字列とし、std 以外の依存は E0200 で「全てのコマンドに効くので、マニフェストの検査で出す」「使った位置で E0200」とするが、次を書いていない: (1) 値が文字列でない形（`fx = { path = "../fx" }`。§19.1 は取得元を第 2 期とする）のコード（E1103 / E0200 / E1101）。
  (2) マニフェストの E0200 の位置（キー、値、行）。(3) ソースの `use fx.{…}` が同時に E0302 になるか、マニフェストで止まるか。
  今の実装は、`fx = "1.0.0"` で診断 0 件・終了コード 0、`use fx.{thing}` で E0302 だけ、表の値では toml の読み誤りの文面で終了コード 2。
- 決定: 決定（2026-11-01、利用者が ID を挙げて了承。95 回目、第 77 組）: S-827 の (d′) から。(1) `fx = { path = "../fx" }`・`fx = 1`・`My-Fx = "1.0.0"` は、キーに E0200 だけ（全てのコマンドのマニフェストの検査、終了コード 2、値を読まない）。(2) 位置はキー。
  (3) マニフェストの誤りなのでソースを読まずに止まり、`use fx.{…}` の E0302 は同時に出ない（行を消した後の検査で出る。§18.1 の 82 行）。仕様 §15.3
- 経緯: 59 回目（2026-10-24）、W4-01 U1 のテストの担当が見つけた（二つの空白を一つにまとめた）。E0200 の Rust のテスト 3 件は `#[ignore = "W4-02"]` で、行と `onsa.toml` を指すことだけを確かめる。
