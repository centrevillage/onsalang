# S-219 `for` の始点が終点より大きい範囲

- 空白: `for i in a..b` で `a > b` のとき（空の範囲か panic か）。§7 は半開区間とだけ書き、`par` は `a < b` を要する（E0808）。W2-11/t で見つけた（2026-10-08）
- 提案: (a)。始点が終点以上（`a..<b`）か終点より大きい（`a..=b`）範囲は空で、`for` は本体を一度も実行しない（端は §3.5 の順に両方を評価する）。
  端が定数で分かっても誤りにしない（利用者: 定数で誤りにできれば良いが、例外的な扱いが要るのでしない）。`par` の E0808 は複製の数が決まらないための規則で `for` には当てない（仕様 §7。2026-10-09 決定、第 12 組。`..<` は実装済みで、事例は W3-18 の `tests/spec/control/range_half_open.onsa` に足した。`..=` は W8-03 の降下の最初の比較で 0 回になり、W8-03 が事例を足す）
