# S-1273 添字の中の変更がその基を書く形（`xs[reset(inout xs)]`）で、基の要素をいつ読むか

- 空白: §3.5 は「添字 `xs[i]` は、`xs` の後に `i` を評価する」とするが、基が場所（局所変数やフィールドの経路）のとき、基の「評価」が場所を決めるだけか、基の値を読むことかを書いていない。添字の式が基を書く形（`reset(inout xs)` が `xs = [7, 8, 9]` にして 1 を返し、`xs` の初めは `[1, 2, 3]`。`let v = xs[reset(inout xs)]`）で、(1) 場所を決め、添字を評価してから要素を読む（書いた後の値で 8）か、(2) 基の値を先に読む（書く前の値で 2。基が配列なら写しが要る）かで値が割れる。sema は誤りにしない（E0702 の窓は呼び出しの引数）。同じ族に入りうる形: 代入先の場所（`xs[reset(inout xs)] = v`）、入れ子の添字、フィールドの基（`s.xs[f(inout s)]`）、flow の本体の位置。W8-03 の設計メモ（194 回目）の 5 章で見つけた。再現の入力 `target/notes/194/w803/memo/probe/pl/`。
- 決定: 決定（2026-11-28、利用者。194 回目、第 123 組）: S-1275 の決定から。添字の式の中で基と重なる場所を変更すると E0702（`xs[reset(inout xs)]`、`s.xs[f(inout s)]`、`xs.slice(0, 2)[f(inout xs)]`、`(if t { xs } else { ys })[reset(inout xs)]`）。右辺が代入先の基を変更する `xs[0] = reset(inout xs)` は当たらない（S-1264 の順のまま）。E0704 にも当たる形のコードは細部 S-1276。
- 経緯: 194 回目（2026-11-28）、W8-03 の設計メモが見つけた。S-1275 の経緯。
