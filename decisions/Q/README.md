# 再発防止の決定（Q）

第 1 期のレビューを受けた、同じ誤りを繰り返さないための方法（実装から独立した期待値、安全網、仕様に無い前提を表に出す、作業の分け方、判断の重複を防ぐ）と、その決定。
原因の分析と推奨の組み合わせは、元の文書 `process-improvement-phase1.md` に残る。

## 本文のラベル

`docs.py new Q` は、この節のラベルを新しい Q の雛形にする。

- `案`: やり方。
- `費用`: 入れる費用。
- `推奨`: 推奨と理由。
- `決定`: 決めたこと。

## 再発防止の文書から移した Q

Q-01〜Q-15 は、`process-improvement-phase1.md` §2 の見出しの節から本文を一字も変えずに移し、§4 の決定の表の行を本文の末尾の `決定` の箇条にした（日付は `decided`）。
Q-09 には、§4 の「Q-09（API への適用）」の行を `決定（API への適用、2026-10-03）` の箇条として足した。
