# Q-08 一つの検査コマンド（CI の代わり）

- 案: CI を用意しないので、`tools/gate.sh`（仮）で次をまとめて回す。親は作業を受け入れるたびに実行する。
  - fmt、clippy、test
  - 仕様の例の検査
  - Q-07 の C の検査
  - Q-06 の短いファズ
  - Q-10 の印の照合
  - Q-14 の直書きの検査
  - 診断コードの網羅性の照合（2026-10-06、点検 C-26 で追加）: 登録簿の全てのコードが仕様の本文に現れ、仕様の本文の全てのコードが登録簿にある（欠番を除く）
- 費用: 低。
- 推奨: 採る。
- 決定: 採る。`tools/gate.sh` に、fmt / clippy / test、仕様の例の検査、Q-07、Q-06 の短いファズ、否定例が各コード 3 件以上かの数え上げ、golden の更新の一覧、Q-10 の印の照合、Q-14 の直書きの検査をまとめる。仕様の例の検査は、実装待ちのブロックを S 番号を添えた明示の一覧に置き、一覧に無い食い違いと、照合が通るのに一覧に残っているものを失敗にする。診断コードの網羅性の照合を足した（点検 C-26、S-109）
