# Q-07 生成した C を、複数のコンパイラと sanitizer で検査する

- 案:
  - テストで生成した C を、clang と gcc の両方でコンパイルする。`-Wall -Wextra -Werror` を付け、UBSan / ASan 付きでも実行する。
  - 公開ヘッダを C++ でもコンパイルする。
  - `cc` が無いときは、テストを失敗にする。
  - 飛ばした flow の数を表示する。
- 費用: 低。
- 推奨: 採る。R-10、R-65、R-67 は、これで見つかった。
- 決定: 採る。生成した C を Clang と gcc-15 で `-std=c11 -Wall -Wextra -Werror -pedantic`、UBSan / ASan 付きで実行し、公開ヘッダを C99 と C++11（g++-15、clang++）でコンパイルする（S-53、S-95）。`cc` が無ければ失敗、飛ばした flow の数を表示する。
  S-105 の x86 と ARM の比較は `-arch x86_64` と Rosetta で取り、境界の結論は実機の x86 で確かめる
