# D-09 依存クレートは最小にする

| 用途 | クレート | `wasm32` |
|---|---|---|
| CLI | `clap`（derive） | 不要 |
| JSON / TOML | `serde`, `serde_json`, `toml` | 可 |
| WASM の出力 | `wasm-encoder` | 可 |
| LSP | `lsp-server`, `lsp-types`（rust-analyzer と同じ） | 不要 |
| 音声出力（`play`） | `cpal` | 不要 |
| 動的ロード（`play`） | `libloading` | 不要 |
| wasm-bindgen | `wasm-bindgen` | `onsa_web` のみ |

字句・構文・型・Core・インタプリタ・C 出力には外部クレートを使わない。
