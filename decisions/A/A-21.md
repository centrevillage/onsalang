# A-21 無名関数に `rt` の印を書ける形（`rt fn(x: U32) -> U32 { x }`。期待する型の無い位置や捕捉する無名関数を `rt` にする道）と、A-16 の `auto` の印との関係

- 候補: 無名関数の頭に `rt` を書ける形（`rt fn(x: U32) -> U32 { x }`）。今は構文の E0002（「an anonymous function cannot be `rt`; its `rt` comes from the expected type」）で、`rt` の無名関数は期待する型からだけ作れる（S-1032）。期待する型の無い位置（その場で呼ぶ対象、合流の枝）と、`let` に置けない捕捉する無名関数を `rt` にする道になる。
  A-16 の `auto` の印との関係を、開くときに一緒に決める（利用者、146 回目）: A-16 は多相にしたい印の位置に `auto` を書き（`f: auto fn(move E) -> F`）、渡した関数が `rt fn` なら呼び出しを `rt` と数える案で、開くときの細部 (b) に「`auto` の位置に渡す無名関数を `rt` と見るか（本体から推論か、`rt` の関数の中なら `rt` の規則か）」がある。無名関数の `rt` の印があれば、その位置に `rt` の無名関数を書く形で (b) が決まりうる。逆に `auto` で本体から推論する形を採るなら、無名関数の `rt` の印は要らないかもしれない。印を書く位置と意味（効果行の `uses {…}` と同じく型の注釈として読むか）、fmt の正規形、E0002 の候補の書き換えも決める。
- 決定: 将来の実装の候補として登録（2026-11-13、利用者が S-1032 の決定と一緒に了承し、A-16 の `auto` の印に関係するので論点に含めるよう指示した。146 回目）。時期は決めていない。A-16 と一緒に開く。
- 理由: S-1032 で期待する型の無い無名関数は `rt` でないと決めた。無い場合に困る形は、`rt` の関数の中でその場で呼ぶ捕捉する無名関数（`(fn(x: U32) -> U32 { x + k }).(1)`、`?` を閉じ込める形）で、今も E0901、`let` に置けない（E0710）ので型の注釈を書く道が無い。直し方は補助の `rt fn` へ渡すかブロックの式にする（第 99 組の段 1 の `target/notes/146/g99/advisor/probe/a1.txt` の `rt_iife_capture`・`rt_iife_try`、`a4.txt` の `rt_helper_route`）。必要は確かめられていない。第 99 組（S-1032）の独立のレビューの段 1 が挙げた。関係: S-1032、A-16、S-1041
