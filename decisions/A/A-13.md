# A-13

- 候補: `@param` に数値の ID を直接指定するキー
- 決定: 保留（2026-10-06。プラグインの出力を作るとき、第 2 期）
- 理由: 数値の ID は文字列の ID から決まる（S-104、§11.7）。既存のプラグインを Onsa に移すとき、保存済みのプロジェクトとプリセットとの互換のために、元の製品の数値の ID に合わせたいことがある。ハッシュでは任意の数値を選べない。無い場合は、移す前の製品の数値と一致する文字列を探すことになり、現実的でない。
  足すなら、`@param` の閉じたキーの一覧（§11.7）と凍結（§15.4）の扱い、文字列の ID との関係（両方を書くか、数値が優先か）を一緒に決める。足しても既存のコードは壊れない
