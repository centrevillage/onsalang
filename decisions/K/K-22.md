# K-22 呼び出しの型引数 `::[…]` を新しい作業にする

- 論点: S-239 の決定（式の中の型引数 `::[…]` を第 1 期に入れる、[`spec-gaps-w2-w3.md`](spec-gaps-w2-w3.md) の第 9 組）を既存の作業に足すと、W3-07（K-21 の後も M）と W4-12（S）が過大になる（K-15 の教訓）。
- 決定（2026-10-08、親）: 新しい作業を二つ足す。W3-19「型引数の構文 `::[…]`」（字句と構文、fmt の正規形、構文の段の他言語の形の候補を `::[…]` への編集に。W3-15 の後。W3-07 は W3-19 の後で、`.(` と S-256 の構文の段の形が同じ所を触るため）。
  W4-13「型引数の具体化」（名前の段と型の段、値として取り出す `id::[U8]`。W4-12 と W3-19 の後）。メソッドの `v.m[…](x)` の型の段の候補は W5-02 のまま。
  候補が `::[…]` になったので、S-256 の構文の段の形は W3-07 から W3-19 へ、名前の段の `P[…](…)` と `Buf[F32].zeroed(4)` の E0020 は W4-12 から W4-13 へ移す（値の `P[…].(…)` は W4-12 のまま）。作業は 100 個になる。
  あわせて、第 6〜9 組の他の決定の割り当て: S-264 は W4-05（別名と書いた型、型の共有）と推論の作業（推論した型。W5 のどの作業かは W4-05 の作業票で決める）。
  S-267 は、段の順を W4-06、`~` の有無の E0811 / E0812 と E0821 を W4-12、E0801・E0806・見えている名前への `^` の E0020 を W7-04（名前の段で実装する）。S-268 は W5-08。S-281 は W3-15。S-287・S-288・S-289 は W2-09。
