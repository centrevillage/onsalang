# K-06 作業の単位と役割の組

- 論点: 作業ごとに、テスト・実装・壊す側の票をどう組むか。
- 案: 一つの作業 ID に三つの票を組み、表には実装の票の骨格を書く。テストの票は、その作業の決定と仕様の節から期待値を書く。基盤の作業（gate、テストの形）にはテストの役割を置かない。
- 推奨: 上のとおり。作業 ID は 85 個になる（K-13 で W1-10 を足し、86 個）。票ごとに別の ID にすると約 240 になり、依存の欄が票の順の写しで埋まって追いにくい。
- 決定: 推奨のとおり（2026-10-07）。票は作業 ID に `/t`（テスト）、`/i`（実装）、`/b`（壊す側）を付けて呼ぶ（`rules/process.md` 8.6）。
