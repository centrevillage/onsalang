## 性能の要件

コンパイラの検査の時間の目安（X-20、2026-11-02 に利用者が決めた）。測り方は `issues/X/X-20/measure_stages.py`（`onsa_cases --phases`）。

- 5000 行までのパッケージの `check`（std を含み、プロセスの起動を除く）は、release で 50 ms 以内。IDE の書くたびの再検査も同じ目安（書くたびに std を解析し直さない前提）。
- 各段の時間は、入力の大きさにおよそ比例する（n log n まで）。二乗以上で伸びる形を見つけたら R に登録し、担う作業を決める。
- 確かめは段の終わりに `measure_stages.py` を回し、前の段との比と、大きさを変えた族の増え方を記録する（gate には入れない）。単位ごとは、報告の `compare.py speed` の前後で見る（リファクタリングの単位は `rules/refactoring.md` 8.2、他の単位は作業票の受け入れ条件に書く）。
