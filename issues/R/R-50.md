# R-50 flow の生成項目を `use` で取り込めない。`use` の解決が書く位置に依存する

- 高・直す + 要判断・観点 1 / 2｜`crates/onsa_sema/src/sig.rs:38-49`、`:1415`、`resolve.rs:228`｜§11.6「`use dsp.synth.voice.{State, Params}` で取り込める」、§15.1「`use` はどの位置にも書ける」｜再現（親）
- 原因: 名前空間の中身（列挙子、flow の生成項目、関連項目）を、`use` の解決より後の段で作っている。
- 再現:
  - `use dsp.synth.voice.{State, Params}` が E0302 になる。
  - `use Shape.{Circle}` は、§4.1 の規則による拒否ではなく、「見つからない」で落ちる。
  - `use math.{sin}` を `use std.math` より前に書くと E0302 になる。
  - `pub(pkg) use` は何も言われず、非公開として扱われる。
- 直し方:
  - 名前空間の表を収集の段で作る。
  - モジュールの中の import を不動点まで解決する。
  - 列挙子の `use` は専用の文面で拒否する。
- 判断（R-106）: `pub(pkg) use`。S-36 で書き方ごと無くなった。
