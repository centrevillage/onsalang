# R-09 C: 結果の出力先（sret / NRVO）が引数と重なると壊れる

- 高・直す + 仕様へ・観点 1｜`crates/onsa_backend_c/src/emit.rs:1090-1096`、`:752-760`｜§12.7、§5.2｜再現（親）
- 原因: `x = swap2(x)` が `al__swap2(&x, &x)` になる。呼ばれた側は `*out` に書いてから引数を読む。
- 再現:
  - `swap2` は `var r = q; r.b = p.a; r` を返す。インタプリタは 21、C は 22。
  - 配列の回転では、C が 0 を返す。
  - `o.i = mix(o)` でも起きる。
- 直し方: 出力先の場所が、どれかの引数の場所と重なりうるなら、一時変数に構築してからコピーする。
- 仕様へ: §12.7 の「直接構築を保証できない場所」に「構築先が引数から読まれる場合」を足す。
- 構造上の原因: R-81。
