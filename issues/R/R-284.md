# R-284 選択のパターンの同じ枝の中で同じ名前を二度束縛しても E0304 にならない（`(x, x) | (x, x) => x`）

- 場所: 型付けの選択のパターンの束縛（`onsa_sema/src/body/patterns.rs` の `or_bindings`）。同じ枝の中の名前も「前の枝の名前」として使い直す。
- 内容: `match p { (x, x) | (x, x) => x }` は終了コード 0（dev `65a1073` のバイナリ）。選択の無い `let (x, x) = p` は E0304（§5.1 のシャドーイングは無い）。
  再現は 75 回目の scratchpad の `w404/u2a/i/probe/`の `or/dup_in_branch.onsa`・`dup_let.onsa`。W4-04 の名前の段の記録は同じ枝の二つ目を別の束縛にするので、E0304 を記録から出すと直る。
- 経緯: 75 回目（2026-10-27）、W4-04 U2a/i（onsa-impl）が見つけ、親が再現した。直すのは W4-04 の U3b（ローカルの E0304 を名前の段へ移す単位）。
- 判断:
- 補い（2026-10-27、親）: 76 回目（2026-10-27）、W4-04 U3a/t の後の U3b/t（onsa-test）: U3a（`7f32e49`）の後、`match p { (x, x) | (x, x) => x }` は内部エラー「index out of bounds: the len is 2 but the index is 3」（`onsa_sema/src/body.rs:617`、終了コード 101）になった（U3a の前は終了コード 0）。
  U3a の壊す側の掃引に選択のパターンの二度の束縛が無かった。事例 `tests/spec/negative/pattern_choice_dup_binding.onsa` は実装待ちの一覧に載せず（内部エラーは黙らせない）、U3b で E0304 にして通す
- 反映（2026-10-27、親）: W4-04 U3b（`1595183`）で直した。局所を記録の束縛から一括に作り、選択の同じ枝の二度の束縛は名前の段の E0304（事例 `tests/spec/negative/pattern_choice_dup_binding.onsa`）。U3a で入った内部エラーも消えた
