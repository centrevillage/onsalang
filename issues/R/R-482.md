# R-482 部分ビューの部分ビュー（`f(a.slice(0, 2).slice(0, 1), inout a[0].0)`）が、同じ呼び出しの `inout` と重なっても E0702 にならない（一段なら E0702。実際の別名）

- 場所: `crates/onsa_sema/src/modes/exclusive.rs::view_place`（部分ビューごとに `Proj::Index` を一つ足す）と、同じ関数を読む `modes/write.rs` の書き込み。E0715 の枠も同じ。
- 内容: `a.slice(0, 2).slice(0, 1)` の場所は `a[_][_]` になり、`inout a[0].0`（`a[_].0`）と二歩目で食い違って重ならないと判定される。一段の `a.slice(0, 2)`（`a[_]`）なら E0702。インタプリタで借用の側の読みが `inout` の書き込みで変わり、C も同じ要素を指す二つのポインタを渡す（実際の別名）。二つの `inout` の形と E0715 の形も同じ。
  再現は `target/notes/161/w712/u2c/audit/advisor/`（`in/p1.txt` の `slice_of_slice_tuple_elem`、`in/p7.txt` の `write_write_slice_of_slice`、`for_frame_field_vs_slice_of_slice`、インタプリタは `in/t1/`、C は `c/c2/onsa_cprobe.c` の `main__slice_slice`）。W4-08 の S-805 の実装から。
- 経緯: 161 回目（2026-11-17）、W7-12 U2c の想定漏れの監査（onsa-advisor、段 1）が見つけた。親が `f(a.slice(0, 2).slice(0, 1), inout a[0].0)` の通過を再現した。
- 判断: 直す（高、実際の別名）。W7-12 U2c1 の共通の構造で、部分ビューの場所を添字を足さずに基の場所にする（束縛の見出しと同じ答え。基は列の型で、重なりの答えは一段では変わらない）。
- 反映（2026-11-17、親）: W7-12 U2c1a（8449d850）: sources::leaves は部分ビューを外しても場所に添字を足さない（基の場所。見出しと同じ答え）。事例 overlap_views_nested_args・overlap_views_nested_frame
