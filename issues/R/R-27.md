# R-27 クロージャの効果を照合しない。効果行変数は宣言できるが使えない

- 高・直す + 仕様へ + 要判断・観点 1 / 2｜`crates/onsa_sema/src/body.rs:1758-1776`、`effects.rs:44-119`、`infer.rs:199`、`ty.rs:206`｜§8.1、S-23
- クロージャの効果:
  - 純粋な引数 `f: fn(U32) -> U32` に、`Alloc` を使う無名関数を渡せる。外側の関数に `uses {Alloc}` があれば通る。
  - 名前付きの関数で同じことをすると E0401 になり、扱いが一貫していない。
- 効果行変数:
  - `apply[e](f: fn() uses {e}) uses {e}` は宣言できる。しかし `subst` が効果を置換せず、単一化が効果の完全一致を要求するので、使う側が必ず失敗する。
  - そのときのメッセージに `uses {<0>}` という内部の添字が出る。
  - `uses {A, B}` と `uses {B, A}` は別の型になる。
- 直し方: 効果の集計をクロージャの単位にする（R-83）。
- 仕様へ: 関数型の効果の部分型。純粋な関数を `uses {Alloc}` の位置に渡せるか、を決める。
- 判断（R-27）: 第 1 期は、利用者の効果行変数を E0200 にする（推奨）。第 2 期の効果の作り直しで入れる。
- 決定（2026-10-03）: (1) 無名関数の効果を、期待する型の効果行で照合する（今直す）。(2) 関数型どうしの互換を (a) で定める: 引数と返り値は等しく、効果行は含まれる関係、`rt` は同じ向き。効果行は集合。(3) 効果行の変数は第 1 期では宣言の時点で E0200 にし、第 2 期に handler と一緒に入れる。
- 判断: (1) 無名関数の効果を、期待する型の効果行で照合する（今直す）。(2) 関数型どうしの互換を (a) で定める: 引数と返り値は等しく、効果行は含まれる関係、`rt` は同じ向き。効果行は集合。(3) 効果行の変数は第 1 期では宣言の時点で E0200 にし、第 2 期に handler と一緒に入れる
- 反映: 仕様 §8.1 / §10 に反映済み（2026-10-03）。計画 D-08 に追記。実装は W6-01
