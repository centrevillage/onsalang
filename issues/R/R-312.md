# R-312 境界に書いた prelude の演算子 trait（`T: Add`）の E0200 の文面が「user-defined traits as bounds」で、利用者の trait と呼ぶ（`Add` は prelude の trait、S-107）

- 場所: `crates/onsa_diag/src/unsupported.rs` の `TraitBounds`（「user-defined traits as bounds」）と、境界の名前を引く `sig.rs::lower_generics`。
- 内容: `pub fn k[T: Add](x: T) -> T { x }` は E0200「this version does not support user-defined traits as bounds」@1:13。`Add` は prelude の演算子 trait（S-107）で、利用者の trait ではない。`T: Num` は通る。
  コードと止まることは正しく、文面だけが違う。
- 経緯: 79 回目（2026-10-28）、第 71 組の下書き（onsa-gap）が範囲の外で見つけ、親が再現した。前からある。
- 判断（2026-10-28、親）: 直す（文面だけ）。演算子 trait を境界に入れる W5-05 で、境界にできない trait の文面を「この版では演算子 trait を境界にできない」の形に分けるか、境界にできるようにする。
