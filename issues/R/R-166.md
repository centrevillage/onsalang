# R-166 マニフェストの `main_frame` を読んで捨てる

- 低・直す・観点 1｜マニフェスト｜§15.3
- 内容: `main_frame = "static"` を書いたターゲットで `onsa build --target c` が何も言わずに通る（終了コード 0）。`main_frame` は `crates/onsa_driver/src/lib.rs` で読むだけで、どこでも使わない。仕様 §15.3 は、この版のコンパイラが未対応のもの（`main_frame` など）は使った位置で E0200 になり、黙って無視されないとする。
- 経緯: W2-07/b が E0200 の一覧（`onsa_diag::unsupported`）と仕様の E0200 の例を突き合わせて見つけた（2026-10-08）。再現は `main_frame = "static"` の `[target.*]` を持つパッケージ。
- 決定（2026-10-08、親）: 直す。W4-02（マニフェストの閉じた表）で、`main_frame` を実装するか、E0200 の一覧の項目にして使った位置で E0200 にする。
- 判断: 直す（親、仕様が明確）。マニフェストの `main_frame` を黙って捨てず、実装するか E0200 にする。W2-07/b で見つけた
- 反映: 実装は W4-02
