# R-501 `F64` の `vdelay~(x, d, 4294967295)` が `check` を通り、降下が環の長さ `MAX + 1` の溢れで内部エラーになる

- 場所: `crates/onsa_core/src/lower/flow/generated.rs` の `ring_len`（`PlanKind::Vdelay` の `max + 1`）。
- 内容: `F64` の `vdelay~(x, 2.0, 4294967295)` は `MAX <= 2^24` の上限（`F32` だけ、§11.4）に当たらず `check` を通るが、環の長さ `MAX + 1` が `U32` を溢れ、`dump --core`・`build`・`test` の降下が内部エラー（「attempt to add with overflow」、終了コード 101）になる。
  `F32` の同じ形は W7-14 U3 から E0808 になったので当たらない。`delay~(x, 4294967295)` は環の長さが `N` で溢れず、状態の大きさの E0409（S-88 の (3)、W9-04）の分。再現は横の `R-501/f64_max.onsa`。
- 経緯: 167 回目、2026-11-18、W7-14 U3 の実装の担当が前からの内部エラーとして報告し（U3 の前のバイナリでは `F32` の形も同じ内部エラーだった）、親が再現して登録した。
- 判断: 内部エラーなので見つけた W7-14 で直す（`rules/leader.md` 7.4）。降下は環の長さを溢れない幅で数え、`U32` に収まらなければ E0200（この版では `U32` を超える要素の状態を持てない。W9-04 の E0409 の大きさの検査が入るまで）にする。
