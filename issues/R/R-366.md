# R-366 `panic` のメッセージの `??` が C の文字列で三文字表記に読まれる

- 場所:
- 内容: `panic("a ??/ b")` の文字列が `c_string`（`onsa_backend_c/src/emit.rs`）でそのまま C に出る。`-std=c11` は三文字表記を読むので、メッセージが変わる（`??/` は `\`）。gate の旗では `-Wtrigraphs` で C がコンパイルできない。`c_string` は前からあるが、`panic(msg)` で利用者が任意の文字列を書けるようになったので届く。
  直し方の案: 連続する `??` の二つ目を `\?` にする（他の文字列の出力は変えない）。`c-clang` の事例を一件足す
