# R-53 引数がリテラルだけの総称関数の呼び出しで、E0406 が早すぎる

- 中・直す・観点 1｜`crates/onsa_sema/src/body.rs:875-899`｜§4.5（E0406 は「引数から決まらない型パラメータ」）、§4.7、S-22
- 再現: `let a = id(3)` と `let m = max(1, 2)` が E0406 になる。整数リテラルは、関数の終わりで `I32` に決まるはずである。
- 資料の誤り: `impl-review` T-3 の記述は総称関数の本体の中の話に読めるが、実装は呼び出し側にも及んでいる（§4）。

- 範囲（2026-10-04、R-79 の議論で確かめた）: 利用者の総称の enum の列挙子も、後の使用で型が決まるのに E0406 になる（`let m = Maybe.Just(1.5)`、`let m = Maybe.Nothing`）。組込みの `Some` / `None` は別の経路で通る。S-71 で Option / Result をこの一般の経路に載せるので、その前に直す。再現は `tests/review-phase1/parent/r79_enum.onsa`。
