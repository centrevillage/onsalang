# R-110 `match` のガードで対象を変更できる

- 低・要判断・観点 3｜`crates/onsa_core/src/lower/body.rs:641`｜§7「match x の束縛は借用束縛で、x は変わらない」
- 現状: ガードの中の `clear(inout x)` が検査を通り、後の腕は変更後の値で判定される。一般の経路では、腕ごとに `tag(x)` を読み直している。
- 判断（R-110）:
  - (a) 検査器で、ガードの中での対象の変更を禁止する（Rust と同じ）。
  - (b) Core で対象を一時変数に取る。
  - 推奨は (a)。
- 決定（2026-10-03）: (a)。ガードの中の対象の変更は E0715（S-42、R-118 と一緒に決めた）。
- 判断: (a) ガードの中では対象とその一部を変更できない（E0715）。S-42
- 反映: 仕様 §7 に反映済み（2026-10-03）。実装は W4-10
