# R-207 fuzz の修正候補の網に、仕様が約束の外とした類を既知として示す形が無い

- 低・直す・観点 2｜道具（`tools/fuzz.py` の fix の網）｜§18.1、S-236、S-384、S-386、S-389、S-413
- 内容: `tools/fuzz.py` の fix-same-place は、候補を一つ当てた後に同じ段以前の診断が残る変異体を、新しい類として gate を落とす。既知になるのは `tests/pending.toml` に載った保存の入力が示す類だけで、一覧の項目は外す予定の作業 ID を要る。
  仕様が約束の外とした形（S-386 の `|` と S-389 の読み始めの `||` の二段の直し、S-384 の誤りが二つある入力、S-413 の `two(N` 改行 `{ 1 })`）は直す作業が無いので載せられず、事例を足すたびに変異体の選び方がずれて新しい類として出る。
  W3-06 の単位 2 の gate では 4 類（`0562ac9f`、`1cf48968`、`3516409a`、`10f0bfcf`）。
- 経緯: W3-06/i の単位 2 の gate のファズが見つけ、親が入力を確かめた（2026-10-10）。4 つとも閉じていないファイルに縮められた入力で、二つは決定の二段の直し、二つは誤りが二つある入力（`10f0bfcf` は dev の `ade4450` でも同じく破れる、W3-06/i の報告）。
- 決定（2026-10-10、親）: 直す。`tests/fuzz/allowed.toml` に、仕様が約束の外とした類を、類の文字列・それを示す保存の入力・根拠の S・注記で並べ、fuzz はそれを既知とする。並べた入力がその類を示さなくなったら gate を落とす（古い項目を残さない）。網が粗くなる（同じ類の本当の誤りも既知になる）代償は、事例の器（`onsa_tests::fix_contract`）が約束を確かめることで補う。W3-06 の単位 2 で行う。
- 判断: 直す（親）。fuzz の修正候補の網に、仕様が約束の外とした類（二段の直し、誤りが二つある入力）を既知として示す形が無く、事例を足すたびに新しい類として gate を落とす。W3-06/i の単位 2 の gate が見つけた
- 反映: 実装は W3-06 の単位 2（`tests/fuzz/allowed.toml` と `tools/fuzz.py`）
