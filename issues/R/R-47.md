# R-47 マニフェストと依存の誤りを黙って無視する。`platform` が必須

- 中・直す・観点 1 / 3｜`crates/onsa_driver/src/lib.rs:41-108`、`:239`、`:276`｜§15.3、S-11
- 黙って無視するもの:
  - 依存の `foo = "1.0.0"` と `std = "9.9.9"`、未知の表 `[bogus]`、綴り違いのキー（`bulk_treshold`）
  - パッケージ名 `My-Pkg` と `std`
- `platform` が必須の項目になっている。仕様 §15.3 の `[targets.web] kind = "source" lang = "js"` を含めると、`check` / `test` / `build` の全てが `missing field platform` で失敗する。
- パッケージの中のファイルを `onsa check main.onsa` と指定すると、マニフェストを探さない。単一ファイルとして扱い、`use` が全て E0302 になる。
- 直し方:
  - 未知のキーと未対応の依存をエラーにし、std の版を照合し、パッケージ名を検査する。
  - `platform` を任意にし、ターゲットの検査は `build` 時に行う。
  - マニフェストを上の階層へ探す。LSP にも要る。
- 決定（2026-10-03）: 直す（未知のキーと未対応の依存はエラー、std の版の照合、パッケージ名の検査、`platform` は任意にして `build` 時に検査、マニフェストを上の階層へ探す）。
- 判断: 直す（未知のキーと未対応の依存はエラー、std の版の照合、パッケージ名の検査、`platform` は任意にして `build` 時に検査、マニフェストを上の階層へ探す）
- 反映: 実装（W4-02）
