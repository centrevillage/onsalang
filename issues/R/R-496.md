# R-496 `^名前` の先の `let` が誤りの部分（式のクロックが誤り）のとき、`^名前` は段 1 のクロックで読まれ、使う側に診断が出る

- 内容: `let a = prev~(^b)` の後に `let b = slow(p)`（非 `rt`、`p` は `block`）は E0813@`^b`（`b` を段 1 のクロック `block` で読む）。`b` を上に書くと `slow(p)` の E0815 だけ。`let a = prev~(slow(^b))` の後に `let b = prev~(p)` は `slow(^b)` の E0815。§18.1 と S-1133 の線では、誤りの部分を `^` で読む側も診断を出さない（助言の担当、確信は高）。書く順で報告が変わる。通るプログラムは変わらない。前からの挙動。再現は `target/notes/165/w702/u3/b/repro/`（`f1a`・`f1b`）、事例 `tests/spec/flow_clock/feedback_to_a_let_in_error_until_w7_09.onsa`（実装待ち）。
