# R-283 入れ子の無名関数の捕捉が外の無名関数に入らず、外の無名関数を `let` に束縛しても E0710 にならない（`let h = fn(i: U32) -> U32 { apply(fn(j) { j + k }) }`）

- 場所: 型付けの局所の引き（`onsa_sema/src/body.rs` の `lookup_local`）。いちばん内側の無名関数の frame にだけ捕捉を記す。
- 内容: `pub fn g(k: U32) -> U32 { let h = fn(i: U32) -> U32 { apply(fn(j) { j + k }) }  h(1) }` は終了コード 0（dev `65a1073` のバイナリ）。`k` を直に読む `let h = fn(i: U32) -> U32 { i + k }` は E0710。
  外の無名関数も内側を作るのに `k` を要るので、捕捉する無名関数で第二級（§5.3、`let` に束縛すると E0710）と読める。再現は 75 回目の scratchpad の `w404/u2a/i/probe/`の `nested/nested.onsa`・`flat.onsa`（区切りで `target/notes/75/w404/u2a/i/probe/` へ写す）。
  W4-04 の名前の段の記録（`captures`）は捕捉を内側から開いている全ての無名関数に記すので、modes が記録を読むと直る。そのとき `tests/spec/negative/modes_second_class.onsa` の `captures_inout_in_a_nested_closure` の E0712 の位置が、内側から外側の無名関数に移る（同じ行）。
- 経緯: 75 回目（2026-10-27）、W4-04 U2a/i（onsa-impl）が記録と型付けの突き合わせ（`tests/spec` の 7719 本体で捕捉の差が 1 件）で見つけ、親が再現した。直すのは W4-04 の型付けの切り替えの単位（U3a・U3b の「変わる形の一覧」に入れる）。
