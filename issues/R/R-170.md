# R-170 `Option[Str]` の `match` が内部エラーになる

- 中・直す・観点 1｜降下（パターン）｜§7、§18.1
- 内容: `Option[Str]` の値を `Some("a") => …` のような文字列のパターンで `match` すると、降下が内部エラー「constructor pattern on a non-enum」（終了コード 101）になる。
  文字列のパターンが無くても、`Option[Str]` の `Some(_)` / `None` や `Result[U8, Str]` の `Err(_)` の `match` で同じ内部エラーになる（W2-06/b、HEAD から）。§18.1 では、この版で扱えない形は E0200 で知らせる（S-224）。
- 経緯: W2-06/t2 が見つけた（2026-10-08）。
- 決定（2026-10-08、親）: 直す。パターンの降下を作り直す W8-06 で行う。
- 判断: 直す（親、仕様が明確）。`Option[Str]` の文字列のパターンの `match` の内部エラーを無くす。W2-06/t2 で見つけた
- 反映: 実装は W8-06
- 反映（2026-11-27、親）: W8-16 B1（192 回目）で構造で閉じた（S-67 の判断が名指す族）: `Option[Str]`・`Result[U8, Str]` の引数や局所の束縛を持つ単位は束縛の段の一つの E0200 で止まり、`match` の降下に届かない。親が再現（193 回目、文書の点検の担当が気付いた）: `Some("a")`・`Some(_)`・`None` の `match`（引数 `o: Option[Str]`）と `Err(_)` の `match`（引数 `r: Result[U8, Str]`）と局所 `let o: Option[Str] = None` の `match` は、`3424a80` で束縛の位置の E0200 だけ、終了コード 1、内部エラー 0。内部エラーは `aa164f2`（11-21）の基で既に `Str` の E0200 に替わっていた（どの作業で替わったかは確かめていない）。止まる形の事例は `tests/spec/negative/lower_unfit_params.onsa`・`lower_unfit_return_local.onsa`。
