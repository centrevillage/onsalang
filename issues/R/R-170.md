# R-170 `Option[Str]` の `match` が内部エラーになる

- 中・直す・観点 1｜降下（パターン）｜§7、§18.1
- 内容: `Option[Str]` の値を `Some("a") => …` のような文字列のパターンで `match` すると、降下が内部エラー「constructor pattern on a non-enum」（終了コード 101）になる。
  文字列のパターンが無くても、`Option[Str]` の `Some(_)` / `None` や `Result[U8, Str]` の `Err(_)` の `match` で同じ内部エラーになる（W2-06/b、HEAD から）。§18.1 では、この版で扱えない形は E0200 で知らせる（S-224）。
- 経緯: W2-06/t2 が見つけた（2026-10-08）。
- 決定（2026-10-08、親）: 直す。パターンの降下を作り直す W8-06 で行う。
- 判断: 直す（親、仕様が明確）。`Option[Str]` の文字列のパターンの `match` の内部エラーを無くす。W2-06/t2 で見つけた
- 反映: 実装は W8-06
