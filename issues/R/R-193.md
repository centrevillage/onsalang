# R-193 `<…>` の候補が、中身が並びとして読めない形にも出る

- 低・直す・観点 1｜構文｜§4.5、§18.1
- 内容: 型パラメータと型引数の `<…>` を `[…]` にする E0020（W3-15 の `angle_brackets` の行）は、括弧の後ろのトークンだけを見て候補を作り、中身を見ない。`fn b<T q>` に候補 `fn b[T q]` が出て、当てると同じ箇所に E0002（`expected ']'`）が残り、§18.1 の約束（S-236）を破る。中身が型パラメータ・型引数の並びとして読めるときだけ候補を作り、読めなければ候補なしの E0002 と note にする。
- 経緯: W3-18 の gate のファズが見つけた（2026-10-09、`fix-same-place: fix|E0020|write the brackets ...|E0002`。保存した入力 `tests/fuzz/b330941f.onsa`、種 `tests/review-phase1/parent/r70/07_array_table.onsa`）。
