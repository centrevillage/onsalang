# R-135 構造体のフィールドの第二級の型が E0710 にならない

- 中・直す・観点 1｜型の整形性の検査｜§5.3
- 内容: 仕様 §5.3 は、借用・`Span`・捕捉するクロージャを「引数の位置にだけ」とし、構造体のフィールドにはできない（E0710）とする。今の実装は、`struct Viewer { window: Span[F32] }`、`[Span[F32]; 2]` のフィールド、総称の `Span[T]` のフィールドを通す。
- 経緯: W1-10 のテストの票が仕様から書いた否定例で見つけた（2026-10-07）。再現は `tests/spec/negative/modes_second_class_fields.onsa` と `modes_flow_span_fields.onsa`（実装待ち）。
- 決定（2026-10-07、親）: 直す。仕様は明確で、判断は要らない。型の整形性を位置と型構成子の組で判定する W4-05 で扱う。
- 判断: 直す（親、仕様が明確）。構造体のフィールドの第二級の型（`Span`、`[Span; N]`、総称の `Span[T]`）は E0710（仕様 §5.3）。W1-10 で見つけた。再現は `tests/spec/negative/modes_second_class_fields.onsa`、`modes_flow_span_fields.onsa`
- 反映: 実装は W4-05
- 反映（2026-10-29、親）: W4-05 U4a（`6bd892a`）: 構造体と列挙子のフィールドの第二級の型は署名の E0710（型の段）。`tests/spec/negative/modes_second_class_fields.onsa` を実装待ちから外した。
