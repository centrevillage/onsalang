# R-258 型の位置の型引数の数の誤り（総称でない型の `P[I32]`、`Option[I32, F32]`）が E0412 でなく E0302 になる

- 場所: `crates/onsa_sema/src/sig/types.rs` の `arity_err`（型の位置の型引数の数の検査）
- 内容: 型の位置で、総称でない型に型引数を書く形（`fn f(p: P[I32])`）と、数の違う形（`Option[I32, F32]`）が、E0302「`P` takes 0 type argument(s), 1 given」になる。
  S-103 は型引数の数を E0412 とした（§4.5 の「型引数と const 引数の数が宣言と合わなければ E0412」は式の中の型引数の文で、型の位置の文は無い）。再現は `issues/R/R-258/arity.onsa`。
  この文面を期待する事例は `tests/` に無い。`tests/review-phase1/parent/t8.onsa` の `type_arity`（`fn type_arity(x: F32[I32])`、コメントの期待は E0412、S-103 の再現）も同じ形で、期待値付きのテストと実装待ちの項目は無い。
- 経緯: 58 回目（2026-10-24）、X-8 の第二弾の見積もり（組 B1、onsa-impl）が R-248 の見積もりで見つけ、親が dev `4965cf0` の release で再現した。担当は仕様の空白として報告したが、S-103 で決まっているので R にした。
- 判断: 直す（親、S-103 の決定のとおり）。型の位置の型引数の数の誤りと、総称でない型への型引数を E0412 にする。R-248 と同じ所なので W4-05 で一緒に直す。
