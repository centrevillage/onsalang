# R-367 本体の全体が発散する、構造体・配列・タプルを返す関数の C が `-Wunused-parameter` で落ちる

- 場所:
- 内容: `struct S { a: I32, b: F32 }` を返す `fn p1(x: I32) -> S { panic("p") }`、`{ while true {} }`、全ての枝が `panic` の形、`[I32; 2]`、`(I32, I32)` は、生成した C の本体が `*out` に書かないので `-Wall -Wextra -Werror` の `unused parameter out` で落ちる（clang と gcc）。`panic` の呼び出しで書けるようになった形（`ebc860ad` から）。`(void)out;` を出す。`tests/spec/c_runtime` に事例が無かった
- 経緯:
- 判断:
- 反映（2026-11-04、親）: W5-08 の U3 の直し。`out` を読まない sret の本体に `(void)out;` を出す。事例は `tests/spec/c_runtime/c_diverging_aggregates.onsa`。
