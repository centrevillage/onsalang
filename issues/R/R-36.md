# R-36 属性を検査するのは、struct / enum の `@derive` だけ

- 高・直す・観点 1 / 3｜`crates/onsa_sema/src/sig.rs:737`｜§6.5「これ以外の属性は無い」
- 再現: 次のどれもエラーにならない。
  - `@foo fn`、`@derive(PartialEq) fn`
  - `@deprecated struct`、`@relaxed @repr(rust) @param(min: 0.0) struct`
  - `@bogus const`、`@nope impl`、メソッドに付けた `@what`

- 直し方: 項目の種類ごとに許す属性の表を一か所に置き、位置違いと引数違いも拒否する。

- 判断: 直す（属性の位置と引数を、項目の種類ごとの表で検査する。`@bulk` も同じ表で検査する）。あわせて S-34 で derive を属性から型の宣言へ移したので、表に残る属性は `@repr`、`@relaxed`、`@param`、`@bulk` だけ（S-43 で `@mem(bulk)`、S-57 で `@fp(relaxed)` に改めた）
