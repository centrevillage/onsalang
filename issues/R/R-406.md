# R-406 効果行変数の後の `.`（`fn b[e](x: F32) -> e.K`、本体の `e.x`、`uses {e.x}`）が「cannot find `e`」の E0302 になる（§15.1 では効果行変数は名前空間でない名前で、その後の `.` は E0308）

- 場所: 未確認（名前の段の経路の頭の引き方。型の位置は `onsa_sema/src/sig/`、本体は `names/body/paths.rs`）。
- 内容: `fn a[e](x: F32) -> F32 uses {e} { e.x }`、`fn b[e](x: F32) -> e.K`、`fn c[e, U: e.x]`、`uses {e.x}` は、どれも E0302「cannot find `e`」。
  §15.1 は効果行変数を名前空間でない名前とし、名前空間でない名前の後に `.` を書くのを E0308 とする（`Show.show(1)` と同じ）。`F32.PI.x` は E0308「`PI` is a constant, which has no members」。
  誤りのあるファイルのコードだけで、実害は低い（名前は見つかっているのに「見つからない」と言う）。入力は `target/notes/125/w511u10e/probe/effvar.onsa`。
