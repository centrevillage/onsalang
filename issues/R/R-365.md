# R-365 値を返す関数の本体の末尾の入れ子のブロックが `return` で終わる形（`{ { return e } }`）の C がコンパイルできない

- 場所:
- 内容: `fn f(x: I32, c: Bool) -> I32 { { return (0 + 5) } }` に `@export` を付けて `onsa build` すると、生成した C が `return …; return ((onsa_unit){0});` になり、`-Wall -Wextra -Werror` の有無によらず「incompatible result type」で落ちる。interp は通る。`{ panic("a") }`、`{ while true {} }`、`{ if c { return 1 } else { return 2 } }` は通る。
  原因: Core の `Block::diverges`（最後の文が `Return`・`Break`・`Continue`）が入れ子のブロックを見ない。前からある（`36773a20` でも同じ）が、S-891 が再帰の形を仕様にしたので通るはずの形である。壊す側の生成の台本（`target/notes/113/` に控え）が見つけ、gate を通っていた形なので `rules/leader.md` 4.9 で事例を足す
