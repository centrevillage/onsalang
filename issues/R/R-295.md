# R-295 組込みの型の関連関数を値として取り出す形（`let f = Buf.zeroed`、`let g = F32.from_bits`）が、§6.1 で書けるのに E0302「cannot find」になる

- 場所: 名前の段の組込みの型の後の名前（`names/body/paths.rs::builtin_assoc`）。呼び出しの名前のときだけ関連関数の表を引き、値の位置では関連定数だけを引く。
- 内容: §6.1 は関連関数を項目の関数と同じく値として使えるとする（`let mk = Point.new`）。利用者の型の関連関数はそうなるが、組込みの型の `let f = Buf.zeroed`・`let g = F32.from_bits` は E0302「cannot find `zeroed`」になる。
  書けるプログラムが通らない。前からの形（W4-04 U5 の前の dev `e741747` も同じ）。再現は横のディレクトリの `values.onsa`。
- 経緯: 77 回目（2026-10-27）、W4-04 U5/b（onsa-break）の指摘 4。
- 判断: 直す。組込みの関連関数を std の宣言にする W5-02 で、値の位置でも同じ表から引く（型付けが関数値の型を作れなければ、それまでは §18.1 の E0200）。
