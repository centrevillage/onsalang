# R-404 境界が与える型パラメータのメンバ（`T: Float` の `-> T.PI`）と const パラメータの後の `.`（`-> N.K`）を型・境界・効果行に書くと、E0308 でなく「cannot find `T`」の E0302 になる

- 場所: `crates/onsa_sema/src/sig/heading.rs` の `missing_member`（W5-11 U10a で足した。境界がメンバを与えないときだけメンバを名指す）と、`sig/types.rs` の経路の型の枝。
- 内容: `fn a[T: Float](x: T) -> T.PI`、`U: T.PI`、`uses {T.PI}`、`let y: T.PI` は E0302「cannot find `T`」。§15.1 の「名前は見つかったが、その位置に要る種類でなければ、位置によらず E0308」によれば E0308 である（`F32.PI` を型の位置に書くと今も E0308）。
  const パラメータの後の `.`（`fn h[const N: U32](x: F32) -> N.K`、`U: N.x`、`uses {N.x}`）も「cannot find `N`」（本体の `N.x` は E0413）。W5-11 U10a（R-370）の前から。入力は `target/notes/124/w511u10a/probe/` の `r370b`・`r370c`。
- 経緯: 124 回目（2026-11-08）、W5-11 U10a/i（onsa-impl）が R-370 を直すときに見つけ、親が U10a のビルドで再現した。
- 判断: 直す（親）。W5-11 の U10 の残り（名前の段。`missing_member` が見つけたメンバの種類を返し、見出しでは `kind_error`、型では `not_a_type` に渡す見込み）。
- 補い（2026-11-08、親）: W5-11 U10a の壊す側（124 回目）が同じ族の形を足した（どれも前から）。(1) 未知の境界（`fn b[T: Copy + ?Dup](x: T) -> T.K`、矛盾のある並び）の後の `.` も「cannot find `T`」で、本物の E0416 を隠す。
  §18.1 の未知の境界と S-747 の A5 では黙る（本体の `T.K` は `Fail::Held` で黙る）。中。(2) 後ろのパラメータの境界（`fn b[U: T.x, T: Show]`、`struct S[U: T.zzz, T: Show]`）、自分の境界（`fn b[T: T.x]`）、const パラメータの型（`fn a[T, const N: T.K]`）も同じ文面。
  (3) R-370 の見出しと型の位置の事例が `tests/` に無く、`type_param_members.rs` は境界が読める形だけを見る。直すときに未知の境界の形を足す。(4) `use_form` の字と fmt の書き換え（`fmt/rewrites.rs`）を結ぶ確かめが無い。作った字を `fmt` に通して変わらないことを見るテストを一つ置く案。
  入力は `target/notes/124/w511u10a/probe/unknown_bound.onsa`
