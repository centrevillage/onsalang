# R-405 `Show` にメソッド `show` が無い（本体の `x.show()` は `I32` でも E0413）。§15.1 の `Show.show(1)` の note は `x.show()` の形を示す

- 場所: 未確認（組込みの trait のメンバの表 `crates/onsa_sema/src/traits.rs` か、仕様の §6.3 の標準 trait の一覧）。
- 内容: `fn f[T: Show](x: T) -> Str uses {Alloc} { x.show() }` は E0413「`T` has no method `show`」、`fn g(x: I32) -> Str uses {Alloc} { x.show() }` も E0413「`I32` has no method `show`」。
  §15.1 は `Show.show(1)` を E0308 とし、note でメソッドの形 `x.show()` を示す（事例 `tests/spec/module/dot_after_trait_name.onsa`）。
  仕様が `Show` のメンバ（`show` の署名）を定めているかは確かめていない（§6.3 の標準 trait の一覧と §6.6 の `Show` の文字列の項は文字列の形だけを書く）。定めていなければ、§15.1 の note の例が無いメソッドを示すことになる。入力は `target/notes/125/w511u10e/probe/show_body.onsa`。
