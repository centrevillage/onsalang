# R-96 組込みのメソッドの範囲が、仕様と合わない

- 中・要判断・観点 1 / 3｜`crates/onsa_sema/src/builtin.rs:74-101`、`body.rs:670`、`:1411`｜§4.2（`Str` の API は `len` / `is_empty` / `as_bytes` / `from_utf8`）、§19.2、§6.2（同じ関数に二つの呼び方は無い）、S-09、S-12
- 仕様で削除済みなのに通る: `s.find(t)`、`s.substr(0, 1)`、`get_substr`、`is_char_boundary`
- 仕様にあるのに無い: `s.as_bytes()`
- 二通りの呼び方: `x.sqrt()`、`floor`、`ceil`、`trunc`、`round`、`abs`、`min`、`max`、`is_nan` のメソッドが、`std.math` の関数と並存している。
- 仕様に無い追加: `Option.is_some` / `is_none` / `unwrap_or`、`Result.is_ok` / `is_err`、列の `is_empty`
- trait の実装: `Bool` は `PartialOrd` / `Ord` を満たさない（Rust とは違う）。`Char` は `Default` を満たさない。
- 古い文面: E0413 の文面が、削除済みの `.bytes()` / `.chars()` / `.substr` を勧める。
- 判断（R-96）:
  - **`Str`**: 仕様に合わせる（削除と追加）。
  - **浮動小数のメソッド**:
    - (a) `std.math` の関数に一本化する（§6.2 どおり）。
    - (b) メソッドの形も仕様に入れる。
    - 推奨は (a)。
  - **`Option` / `Result` の補助メソッド**: Rust と同じ名前と意味なので、仕様に一覧を足して残すことを推奨する（S-12 の形）。
  - **`Bool` / `Char`**: Rust に合わせる（`Bool: Ord`、`Char: Default`）。
- 決定（2026-10-03）: `Option` / `Result` のメソッドは `unwrap` と `map_err` だけ（`unwrap` は無いと煩雑なので残す）。`is_some` / `is_none` / `unwrap_or` / `is_ok` / `is_err` は外し、書いたら E0413 で `match` の形を示す。
  `Str` の検索と切り出しは、無いと煩雑な用途があるので候補として残し、第 2 期に実例で判断する。方針: 組込みの API は仕様の閉じた一覧だけを実装するが、必要と分かったものは拒否で終わらせず、[`api-candidates.md`](api-candidates.md) で議論する。コーパスの重力に引かれただけのものは省く。
  浮動小数のメソッド形（`x.sqrt()` など）も、`std.math` の関数と二重になり一意性の原則（P2）に反するので不採用（A-04）。`Bool: Ord`、`Char: Default` は、必要な実例が無いので入れない（A-05、A-06）。
  組込み型の trait の表を §6.3 に閉じた一覧として書き、`Option` / `Result` の `PartialOrd` / `Ord` は外す（A-07）。浮動小数の `Show` の書式を定めた。
- 判断（一部）: `Option` / `Result` のメソッドは `unwrap` と `map_err` だけ（`unwrap` は無いと煩雑なので残す）。`is_some` / `is_none` / `unwrap_or` / `is_ok` / `is_err` は外し、書いたら E0413 で `match` の形を示す。`Str` の検索と切り出しは、無いと煩雑な用途があるので候補として残し、第 2 期に実例で判断する。
  方針: 組込みの API は仕様の閉じた一覧だけを実装するが、必要と分かったものは拒否で終わらせず、[`api-candidates.md`](api-candidates.md) で議論する。コーパスの重力に引かれただけのものは省く。
  浮動小数のメソッド形（`x.sqrt()` など）も、`std.math` の関数と二重になり一意性の原則（P2）に反するので不採用（A-04）。`Bool: Ord`、`Char: Default` は、必要な実例が無いので入れない（A-05、A-06）。
  組込み型の trait の表を §6.3 に閉じた一覧として書き、`Option` / `Result` の `PartialOrd` / `Ord` は外す（A-07）。浮動小数の `Show` の書式を定めた。これで R-96 は全て決定
