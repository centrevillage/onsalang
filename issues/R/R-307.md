# R-307 同じ型のメンバの関連定数と関連関数の名前が重なると、E0304 が書いた順によらず定数に付き、定数が前にあると note「first defined here」が後ろの関数を指す

- 場所: `crates/onsa_sema/src/sig.rs` の 349 行（`impl` のメンバの名前を `fns.iter().chain(&consts)` の順で `assoc` の表に入れる）。
- 内容: 同じ型の関連定数と関連関数の名前が重なると、E0304 は書いた順によらず定数に付く。定数が前にあると（`pub const a: I32 = 2` の後の `pub fn a() -> I32 { 1 }`）、E0304 は 3 行の定数に付き、note「first defined here」が 4 行の後ろの関数を指す。
  S-737 は、同じ型のメンバどうしの E0304 をソースの順で後の宣言に付け、前を note で示すと決めた（§6.2）。再現は横の `const_then_fn.onsa`（定数が前）と `fn_then_const.onsa`（関数が前）。

- 判断（2026-10-28、親）: 直す（低）。W4-05 のメンバの同名の所（S-737 の実装と同じ所）で、メンバをソースの順に表へ入れる。
