# R-513 `sample` の値を `sample * N` の入力に渡した E0815 の文が「a value is never made slower」と逆の向きを言う

- 場所: `crates/onsa_sema/src/flow/clocks/checks.rs` の E0815 の文（「a value is never made slower」の二か所）。
- 内容: `fold2~(x)`（`x` は `sample`、`fold2` の入力は `at (sample * 2)`）と `fold2~(id~(x).up~(2))` は E0815「this argument is at the clock `sample` but the input `x` of `fold2` is at `sample * 2`; a value is never made slower (§11.3)」になる。引数の方が遅く、足りないのは速くする向き（§11.3「`sample * N` へは、変換の flow で書く」）なので、文の後半が逆を言う。診断のコードと位置は正しい。
- 経緯: 174 回目（2026-11-21）、W7-09 U2b の参照評価器の設計の審査（onsa-advisor）が実験（`target/debug/onsa check`）で見つけ、親が今のバイナリで確かめて登録した。
- 判断: 直す（低、文だけ）。引数の方が遅く入力が `sample * N` のときは、変換の flow か `.up~(N)` で書く旨の文にする。W7 の区切りの作業 W7-17 で。
