# R-55 合成型のリテラルどうしの比較を拒否し、メッセージに内部の型変数が出る

- 中・直す・観点 1｜`crates/onsa_sema/src/body.rs:670-789`、`:1817-1824`｜§4.7
- 再現: `Some(1) == Some(2)` と `[1, 2] == [1, 2]` が E0401「`==` is not defined for `Option[?0]`」になる。
- 範囲（2026-10-03 に追加で確かめた）: 推論で型が決まったローカルでも落ちる。`let a: [I32; 2] = [1, 2]` の後の `a == [1, 2]`、リテラルが左辺の `[1, 2] == a`（`a` は引数）が E0401「`==` is not defined for `[I32; 2]`」になる。引数どうし（`a: [I32; 2]`）は通る。
  演算子の trait の検査が、型変数を解決しきる前に行われている。テストでよく書く `assert a == [1, 2]` が通らないので、重さを低から中に上げた。浮動小数のリテラルだけの `[1.0, 2.0] == [1.0, 2.0]` は、`1.0 == 1.0` と同じく E0405 になるべきである。
- 決定（2026-10-03）: 直す。判定は R-53 と同じく、整数リテラルの既定化と単一化の後に行う。議論の中で R-119 と R-120 を見つけた。
- 判断: 直す（重さを中に。推論で型が決まったローカルと、リテラルが左辺の比較も含む。判定は R-53 と同じく既定化と単一化の後。浮動小数のリテラルだけなら E0405）
- 反映: 実装（W5-01）
