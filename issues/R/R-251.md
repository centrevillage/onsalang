# R-251 場所でない対象の `match` の腕を借用にし、`for s in id(xs)`・`match id(x)` の一時の値の破棄を rt の関数で数えない

- 場所: `crates/onsa_sema/src/modes.rs` の束縛の種類（`for` と `match` の見出しは、場所でない対象も借用にする）と、rt の関数の破棄の検査（一時の値の破棄を数えない）
- 内容: 再現は横のディレクトリ。`match_call_affine.onsa`: `match mko()`（`mko` は `Option[Buf[F32]]` を返す）の腕の `Some(z) => take(move z)` が E0711「`z` is borrowed here and Affine」になる。§5.4 の表は場所でない対象（`match f(...)`）の腕の束縛を所有とする。
  `rt_for_call.onsa`・`rt_match_call.onsa`: `rt fn` の中の `for s in id(xs)` と `match id(x)`（`id` は `Str` か `[Str; 2]` を返す）が通る。一時の値（所有）は反復や `match` の後で破棄され、破棄に `Alloc` が要るので、rt の関数では誤り（§10、§12.2。`let t = id(x)` は今も E0901）。
  S-604 で、場所でない `for` の反復元も所有と決めた（§5.4 の表に行を足す）。
- 経緯: 第 42 組の下書き（onsa-gap、2026-10-23、57 回目）の付録が S-604 の確かめで見つけ、助言の担当の二段が R にすると決め、利用者が了承した（B18）。親が dev `2ebd664` の release の `check` で再現した。直しは束縛の状態を作り直す W4-07。
