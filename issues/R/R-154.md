# R-154 `Ring[F32, NEG]`（`NEG` は `I32` の定数）が E0408 になる

- 内容: const 引数に `I32` の定数を書くと E0408「a const argument must fit in `U32`」になる。§4.5 は `U32` でない定数を E0401（修正候補は定数の型を `U32` にする）とする。S-228 で、前置の `-` の付いた const 引数も E0401 と決めた。
- 経緯: S-228 の仕様の空白 S-207〜S-228 の下書き（[`spec-gaps-w2-w3.md`](spec-gaps-w2-w3.md) の付録 A）で見つけた（2026-10-08）。
- 決定（2026-10-08、親）: 直す。仕様は明確。W2-06 で S-228 と同じ回に直す。
- 判断: 直す（親、仕様が明確）。`I32` の定数の const 引数を E0401 にする。S-228 の下書きで見つけた
- 反映: 実装は W2-06
