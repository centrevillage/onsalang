# R-249 列挙子の綴りの誤り（`Shape.Circel(1.0)`）が E0302 でなく E0401「`Shape` is not a value」になる

- 場所: `crates/onsa_sema/src/body/names.rs` の経路の頭の解決（102・160 行の「is not a value」）
- 内容: `pub enum Shape { Circle(F32), Rect(F32, F32) }` と `Shape.Circel(1.0)` は E0401「`Shape` is not a value」になる。§15.1 は名前が見つからなければ E0302 とし、型の名前の後の `.` の名前（列挙子、関連の名前）が無いのは名前の誤りである。
  文面も、型を値と取り違えたように読める（R-38 の `Point.private_assoc()`、R-179 と同じ類）。綴りの近い名前は候補にしない（S-258）。
- 経緯: 第 40 組の下書き（onsa-gap、2026-10-23、55 回目）が S-258 の確かめで見つけた（族の外、`target/notes/55/gap40/probe/` の n11）。親が dev `8427cf2` の release の `check --json` で再現した。直しは `body/names.rs` を作り直す W4-04。
- 判断:
- 補い（2026-10-27、親）: 75 回目（2026-10-27）: 組込みの型でも、無い関連の名前の `F32.y` は E0302「cannot find `y`」、`F32.y()` は E0413「`F32.y` does not exist」で、書き方でコードが割れる。W4-04 の U5 で、型の名前の後の名前の解決（この R の道）として S-707 の E0302 に揃える。第 65 組の助言の段 1・段 2 が見つけ、親が再現した。
