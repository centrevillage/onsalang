# R-481 引数の位置の生成型のリテラルを `if`・`match`・ブロックの末尾に置き、フィールドが場所でない値のとき、降下が腕の中の一時の `span` を腕の外で読む C を作る（`take(if c { pair.In { l: mk(v), r: y } } else { … })`）

- 場所: Core の降下の生成型のリテラル（`crates/onsa_core/src/lower/body/expr.rs` の `AK::Struct` が、フィールドをその場で `coerce` で view にする）。
- 内容: 引数の位置の生成型 `In`・`Out` の struct リテラルを `if`・`match`・ブロックの末尾に置き、フィールドが場所でない値（呼び出しの結果など）のとき、降下は腕のブロックの中に一時 `__arr` を作ってその `span` をリテラルに入れ、腕の外の呼び出しで読む。
  生成した C では一時の配列が `if (c) { … }` の中の変数で、呼び出しはその寿命の後に読む（C の未定義の動作。`check` も `build` も通る）。
  再現は `target/notes/161/w712/u2c/review/c1/`（`take(if c { pair.In { l: mk(v), r: y } } else { pair.In { l: y, r: y } })`、`rt fn`）、出力は同じ所の `c1out/onsa_cprobe.c` の `main__pick`。
  W7-12 U2b（`b61bc866`）で引数の位置の生成型のリテラルが通るようになってから（U2b の前は E0711）。
  同じ根の形は生成型に限らない: `take(if c { mk(v).slice(0, 2) } else { y.slice(0, 2) })`（素の `Span` の腕の中の一時）も同じ C になる（`target/notes/161/w712/u2c/audit/advisor/` の `in/p1.txt` の `temp_view_tail_if`、`c/c2/onsa_cprobe.c` の `main__temp_view_if` の形。161 回目の監査）。直に書いた `take(mk(v).slice(0, 2))` は関数の高さに一時を置いて正しい。S-1113 の (A)（末尾の平面の配列リテラルを平面のリテラルとして降ろす）も、そのままでは同じ形を作る。
  同じ仕組みが受ける形（S-1118 の (2)）: 腕・ブロックの中で作った破棄の要らない束縛の部分ビューを末尾に置く形（`take(if c { let t = [1.0, 2.0, 3.0, 4.0] … t.slice(0, 2) } else { … })`。降下は `t` を腕の中のローカルな配列にする）。
  161 回目の決定の文の監査（`target/notes/161/w712/u2c/audit2/`）が足した同じ根の形: 末尾の生成型のリテラルの要素に置いた腕の Copy の束縛（`take(if c { var t: [F32; 2] = [v; 2] … pair.In { l: t, r: y } } else { … })`、要素は腕の中でビューになる。`main__gen_lit_copy`）、見出しの形（`let s = if c { [1.0, 2.0, 3.0, 4.0].slice(0, 2) } else { … }` の後の `s[0]`、`for w in if c { let t = […] … t.slice(0, 2) } else { … }`）、派生の鎖（腕の中の `let s = if d { [1.0, 2.0].slice(0, 1) } else { … }` を外の末尾に置く形）。値で写した借用束縛の形は R-484。
  記憶域は、ビューが届きうる最も外の読み手まで生きる所に置く（呼び出しの文の高さでは見出しと鎖に足りない。最も簡単なのは関数の高さで、静的な値は静的領域でもよい、S-610）。
- 経緯: 161 回目（2026-11-17）、W7-12 U2c の設計メモ（onsa-impl）が「腕のスコープを抜けた後の寿命は未確認」と挙げ、メモの審査（onsa-advisor）が `build --target host` の C で確かめた。親が C の出力を読んで登録した。
- 判断: 直す（高。生成した C の未定義の動作。生成型の形は W7-12 U2b が入れた後退、素の `Span` の形は前から）。W7-12 U2c2 の降下で、腕・ブロックの外へ出うるビューが、その中で宣言した記憶域（一時、破棄の要らない束縛の値、値で写した借用束縛 R-484、開いたリテラルの要素の Copy の束縛）を指す形を一つの判定にし、その記憶域をビューが届きうる最も外の読み手まで生きる所（まずは関数の高さ）に置く（入るまでは E0200）。
