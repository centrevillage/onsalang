# R-524 改行の後の行頭の `/`（導くクロックの続き）の扱いが、struct のフィールドの括弧の中（続けて読み候補一つで通る）・flow の入力（候補の無い E0002）・top level の `const`（E0020 の後に E0002）・本体の `let`（改行の E0002）で揃っていない（誤りのプログラムだけ）

- 場所: 構文の段（`crates/onsa_syntax/src/parser/` の型の後のクロックの読みと E0020 の表）。
- 内容: クロックの次の行が行頭の `/ 4` のとき、struct のフィールドの括弧の中は改行を越えて読み候補一つで通り、flow の入力は候補の無い E0002、top level の `const C: U32 at sample` は E0020「remove the clock」の後に E0002、本体の `let c: U32 at sample` は改行の E0002 になる。
  §2.5 では行頭の `/` は前の行に続かない。どれも誤りのプログラムで、当て続ければ止まる。再現は `target/notes/188/w717/l2/d/in/` の k2〜k4 と R-509 の (2)。
- 経緯: 188 回目（2026-11-26）、W7-17 L2（R-509）の読むだけの設計（onsa-impl）が範囲の外で見つけ、親が登録した。後の作業に構文の段の作業が無いので、W7-17 の L2 で、揃える直しが小さければ一緒に行う（大きければ送り先を決め直す）。
- 判断: 2026-11-26、親（188 回目）: L2/i の一行の直し（struct の括弧の中でも続けて読まない）は、struct の形の候補を一段で通らなくし、四つの形も揃わないので採らない。揃え方は細部 S-1255（W7 の区切りで確認だけ）。決まった直しは、その後に行う。
