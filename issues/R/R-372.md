# R-372 誤りの型の呼び先の引数の配列リテラルが値として検査され、偽の E0710・E0711 が出る

- 場所: `crates/onsa_sema/src/body/calls.rs` の `args_of_unknown_callee`。§18.1
- 内容: 受け手が誤りの型のメソッドの呼び出しで、配列リテラルの引数が値として検査され、偽の診断が出る。`m.total([a, b])`（`a`・`b` は `Span[F32]`）が E0710、`Buf[F32]` なら E0711 になる。見出しを直した形では診断が出ない書き方で、§18.1 の「引数のモードと移動を検査せず」と合わない。失敗した `use` の名前の受け手でも前から同じ。W5-04 U2 で、この道に届く入力が増えた（前は偽の E0413 だった）。再現は `target/notes/115/w504/u2b/b9.onsa`。
- 経緯: 115 回目（2026-11-05）、W5-04 U2 の壊す側（onsa-break）が見つけ、親が記録した。受け手が誤りの型の呼び出しの形なので、呼び出しの形の型の段の W5-15 で直す。
