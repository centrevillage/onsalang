# R-253 借用の `T: ?Dup` の値を `move` の引数に渡す `put(move v)` が通る

- 場所: modes の `move` の引数の検査（総称の本体。位置は W4-07 の作り直しで確かめる）
- 内容: 再現は横の `borrowed_maybe_affine.onsa`。`fn g2[T: ?Dup](v: T) { put(move v) }`（`put` は `[T: ?Dup](move x: T)`）が通る。`v` は借用の引数で、`T: ?Dup` は Affine でありうるので、§4.5「`T` の値は複製できない」と §5.2「Affine 値は所有していなければ `move` で渡せない」から、印の有無によらず候補なしの E0711（S-609）。
  総称の本体の modes が、種の分からない `T` を Dup と見ているのか、インスタンスごとにしか検査していない（D-15 の「一度だけ」にも関わる）のかは未確認。
- 経緯: 第 44 組の一回目（S-609）の独立のレビューの段 1（onsa-advisor、2026-10-23、58 回目）が見つけ、親が dev `2ebd664` の release の `check` で再現した（`target/notes/58/gap44/check/c2.onsa`）。直しは W4-09（`move` の検査）で、総称の本体の扱いは W4-07 の設計メモで確かめる。利用者が R にすると了承した（A6）。
