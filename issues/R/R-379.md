# R-379 綴りの誤りの `impl Defualt for P` の後に、`P.default()` の E0302 と `T: Default` の E0416 が連なる（§18.1）

- 場所: 型の段の見出しの読み（`impl Tr for Ty` の `Tr` が見つからないとき、`Ty` のメンバと trait が読めたことになる）。
- 内容: `impl Defualt for P { rt fn default() -> P { … } }` の後の `P.default()` が E0302、`P` を `T: Default` へ渡す形が E0416 になる。見出しの名前を直すと消える誤りで、§18.1 の連鎖を出さない見方に反する。W5-06 の前からの形である。入力は `target/notes/117/w506/u4/ty1.onsa`。
- 経緯: 117 回目（2026-11-06）、W5-06 U4/b（onsa-break）が前からの形として挙げた。関係: S-850、S-895。
- 反映（2026-11-12、親）: W5-13 U1（`953df495`）で仮の形を入れた: 見出しの trait（かその型引数）が読めない `impl` の対象の型を `Modules::unknown_impls` に入れ、その型の `.` の後の見つからない名前と trait を満たすかの判断を黙らせる。仕様 §18.1（104〜105 行）は見出しが誤りの trait の `impl` のメンバを型の `.` の空間に「数える」とするので、今の形は広すぎる（`P.nope()`、enum の見つからない列挙子 `E.Z`、署名の位置の `[F32; P.NOPE]` も黙る）。別名を対象にした `type Al = P; impl Defualt for Al` は連鎖が残る（`unknown_impls` に別名の def が入る）。本直しは W5-13 U11（設計メモから。案 A: 名前の段の終わりで trait の名前を判定し、読めなければメンバの def を作り、`sig/decls.rs` の `impl_target`・`member_cx` の門を通す。105 行の範囲（trait の名前だけか、対象の型引数・孤児規則の見出しの誤りも含むか）を決める）。材料 `target/notes/141/w513u1/`（`r379_fix1.md`、壊す側の報告と `mut379.py`）。形の E0200 の `impl Hash for Q` の後の使う所の連鎖は §18.1 が書かない（U1 の担当の範囲の外の 2）。
