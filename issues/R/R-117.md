# R-117 `inout` 引数から `move` で取り出せる

- 中・直す・観点 1｜`crates/onsa_sema/src/modes.rs`（`let` の初期化と `move` の判定）｜§5.2「Affine 値は所有していなければ `move` で渡せない（E0711）」
- 再現: `fn g2(inout b: Buf[F32]) -> U32 uses {Alloc} { let c = move b; c.len() }` が通る。`c` は関数の終わりで破棄され、呼び出し側の `b` は破棄済みの記憶域を指す。第 1 期は `Buf` がインタプリタ限定なので表に出にくい。
- 直し方: `inout` 引数は所有していないものとして扱い、`move` を E0711 にする（R-85 の所有の状態に含める）。
