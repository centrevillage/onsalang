# R-24 `for x in xs` が、反復元の複製ではなく元の場所を毎回読む

- 中・要判断・観点 1 / 3｜`crates/onsa_core/src/lower/body.rs:389-410`｜§5.4「反復子が集合の複製を保持し、本体で xs を変えても…」
- 再現: `var xs = [1, 2, 3]; for x in xs { xs[2] = 100; sum = sum + x }`。仕様の読みでは 6、実際は 103。
- 判断（R-24）:
  - (a) 仕様どおり複製する。大きな値型の配列ではコピーが高くつく。
  - (b) 反復中に反復元へ書き込むことを、排他性の違反（E07xx）にする。Rust と同じ結果になる。
  - (c) 値型の配列と `Span` は元の場所を読む、と仕様に書く。
  - 推奨は (b)。
- 決定（2026-10-03）: (b) 反復中の反復元への書き込みを禁止する（E0715）。§5.4 の「反復子が複製を持つ」という説明を改める。
- 判断: (b) 反復中の反復元への書き込みを禁止する（E0715）。§5.4 の「反復子が複製を持つ」という説明を改める
- 反映: 仕様 §5.4 に反映済み（2026-10-03）。実装は W4-09
- 反映（2026-10-31、親）: W4-09 U1（91 回目、`dc733b6c`）: 借用の `for` の本体で反復元とその一部（派生した束縛は派生元、見出しの末尾の各々、部分ビューは元の全体）を変更すると E0715（`modes/frozen.rs`）。事例は `tests/spec/negative/for_borrowed_change*.onsa` と `values/borrow_for_change_ok.onsa`
