# R-159 `x as T`（`x: T`）の E0411 の文面が「needs a conversion method」で、そのメソッドは無い

- 低・直す・観点 1｜型の段（`as`）｜§3.3
- 内容: 型パラメータには変換のメソッドが無いのに、文面がそれを求める。S-210 で、文面は「型パラメータに `as` は無い」とし、`x: T` の `x as T` には `as T` を外す候補を、`x: F32` の `x as T` には候補を出さないと決めた。
- 経緯: S-210 の仕様の空白 S-207〜S-228 の下書き（[`spec-gaps-w2-w3.md`](spec-gaps-w2-w3.md) の付録 A）で見つけた（2026-10-08）。
- 決定（2026-10-08、親）: 直す。W5-02 で直す。
- 判断: 直す（親、S-210 で決めた）。型パラメータの `as` の E0411 の文面と候補を直す。S-210 の下書きで見つけた
- 反映: 実装は W5-02
