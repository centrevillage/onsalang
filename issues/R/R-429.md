# R-429 構造体のパターンの最後でない `_` を最後へ移す候補が、最後の要素の後ろの行末コメントを `_` の行へ付け替える

- 場所: `crates/onsa_syntax/src/foreign/rests.rs::underscore_last`（S-512 の、最後でない `_` を並びの最後へ移す候補。ブロック形で `}` が行頭にあり、最後の要素の後ろに `,` があるとき、挿す位置をその `,` の直後に置く枝）。
- 内容: ブロック形の構造体のパターンで、最後の要素の後ろに行末コメントがあると（`y: b, // last`）、候補は `,` の直後に改行と字下げを付けた `_` を挿すので、コメントが `y: b,` の行から `_` の行へ移る（当てた形は `y: b,` 改行 `_ // last`）。後ろに `,` の無い `y: b // last` は `y: b, _ // last` で、コメントは行末のまま。当てた後の検査は通り（残るのは型の段の誤りだけ）、§18.1 は付け替えを禁じていない。見た目の細部で、候補の有無と通るプログラムは変わらない。再現: `match i { Item {` 改行 `_,` 改行 `x: a,` 改行 `y: b, // last` 改行 `} => 1 }`（W5-24 U4 の主のツリー、`check --json` の候補の挿入は `y: b,` の直後）。
- 経緯: 137 回目（2026-11-11）、W5-24 U4 の壊す側（onsa-break）が低として報告し、親が再現した。関係: S-512。
