# R-276 `onsa fmt` が名前が一つだけの並び（`use std.{math}`）を並びの無い形（`use std.math`）に揃えない

- 場所: `onsa fmt`（`crates/onsa_syntax` の整形）。
- 内容: §15.1 は「fmt は名前が一つだけの並びを並び無しの形に揃える（`use std.{math}` は `use std.math`。並びの中にコメントがあれば残す、`spec/tools.md` §3.3）」とするが、`use std.{math}` のファイルの `onsa fmt --check` は終了コード 0 で、書き換えない（dev `49c469b` で親が再現）。
- 経緯: 69 回目（2026-10-25）、W4-03 U3d/t（onsa-test）が範囲の外で見つけた（前からの挙動）。
- 判断:
- 反映（2026-11-07、親）: W5-11 U6・U7（2026-11-07、123 回目）: `fmt/rewrites.rs` の `use_names` が素の名前一つの並びの括弧を外し（中か `}` の後ろの同じ行にコメントがあれば外さない）、`use_names_ast` が §3.5 の比べで全ての名前一つの並びを `use a.b` と読む。事例と `std` と仕様の例は U7 で正規形に直した。事例は `tests/spec/fmt/use_one_name_*.onsa`、Rust のテストは `crates/onsa_cli/tests/cli/use_list_forms.rs`。
