# R-517 参照評価器が、`sample_tick()` と刻みの `at` を付けたパラメータの種類を混ぜた普通の式を、使う所の時間で読む（字は `at` の刻みの時間を保つ）

- 場所: `crates/onsa_tests/src/flow_ref/hoist.rs` の `stage_of`（参照評価器）。
- 内容: `sample_tick()` と、`at` を付けたパラメータの種類（`p at (sample / 4)`、`p` は `block`）を混ぜた普通の式（修飾子の条件でない）を、評価器が `AMBIENT` の段とし、使う所の時間を読む。
  §11.3「刻みの値（…`sample_tick()`）を一つでも読む式は、その式のクロックの段の式である」から、式のクロックは `at` の側の `sample / 4` で、その刻みの時間を保つ。インタプリタ（sema と Core）は字のとおり。
  再現: `issues/R/R-517/e4.onsa`（`let t = sample_tick() % 8 == 4 && (p at (sample / 4))` を `t at sample` で読む形と、`((sample_tick() + (p at (sample / 4))) % 8 == 4) at sample`。インタプリタは 2 件とも通り、評価器は位置 4・12 だけ真にする）。
  生成の双子はこの形を作らない。修飾子の条件に書いた形は S-1230 の単位で字のとおりになった。
- 経緯: 183 回目（2026-11-24）、W7-10 の S-1230 の評価器の担当（onsa-impl）が範囲の外の気付きに挙げた（前からある割れ）。評価器に掛けた再現は担当の確かめで、親はインタプリタの側だけ再現した。
- 判断: 直す（低、評価器だけ）。W7-17 で、生成の双子にこの形を足すかも決める。
