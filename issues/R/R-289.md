# R-289 同じ単位の名前の段の誤りが位置の順でない（fn の本体の `let x = nope` の右辺や型注釈の E0302 が、前の位置のパターンの E0304 より先。flow の本体の先歩きの E0302・型注釈の誤りが前の文の誤りより先）

- 場所: W4-04 の名前の段の歩き手（`names/body/exprs.rs` の `let`・`var`・`for` と無名関数の引数、`names/body/mod.rs::walk_flow` の先歩き）。式を先に歩き、パターンの束縛を後に宣言する。flow の本体は `let` のパターンと型注釈を先に歩く。
- 内容: §18.1 では同じ段の中は開始の位置の順で最初の誤りを報告する。fn の本体の `let x = nope`（`x` が見えている）は、2:7 の E0304 でなく 2:11 の E0302 を報告する（`issues/R/R-289/let_init_first.onsa`）。
  同じ形: `let x: Nope = 1`、`var x = nope`、`for x in nope {}`、`let (y, x) = (nope, 1)`、`let P { x: x } = nope`、無名関数の引数 `fn(x: Nope)`。
  flow の本体では、後ろの `let` のパターンの経路の E0302（`let Nope { a: q } = x`）や型注釈の E0302 が、前の文の名前の誤りや E0304 より先になる（`issues/R/R-289/pf.onsa`）。
  前（dev `7f32e49`、U3a の後）も同じ出力で、通るプログラムは変わらない。一つの単位に誤りが二つ以上あるときに、どちらを報告するかだけが仕様と違う。U3b は flow の本体の `let` の E0304 だけを、その文に着くまで後送りにした。
- 経緯: 76 回目（2026-10-27）、W4-04 U3b/i（onsa-impl）の「範囲の外」と U3b/b（onsa-break）の指摘 2・3 で、親がまとめた。
- 判断: 直す（低）。W4-04 の U7a（隠蔽の E0304、`scope.rs` を触る単位）で、パターンの重なりを右辺より先に確かめるか、歩き手の誤りを単位の中で位置の順に並べて最初を報告する形にする。flow の先歩きの誤り（E0304 以外）の後送りも同じ所で扱う。
