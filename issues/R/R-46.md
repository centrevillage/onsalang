# R-46 命名・ファイルとモジュールの対応の検査が漏れ、衝突したファイルを黙って捨てる

- 中・直す + 仕様へ・観点 1 / 3｜`crates/onsa_syntax/src/naming.rs:116`、`crates/onsa_driver/src/lib.rs:100`、`:129`、`:198`、`crates/onsa_sema/src/sig.rs:57`、`resolve.rs:212`｜§2.3、§15.1
- 命名の検査の漏れ:
  - 型パラメータの「1 語」を検査しない（`[ItemKey]` が通る）。
  - ファイル名 `MyMod.onsa` と `my-mod.onsa` が E0320 にならない。後者は `use` で参照できない。
- 衝突したファイルを捨てる:
  - `a.b.onsa` と `a/b.onsa` がどちらもモジュール `a.b` になる。後に読んだ方が勝ち、片方は検査もされずに消える。
  - `a.onsa` の項目 `b` が、子モジュール `a/b.onsa` を黙って隠す。
- std の隠蔽: 利用者のファイル `std.onsa` が std パッケージを隠す。
- 仕様へ: パッケージ名と、ルート直下のモジュール名のどちらを優先するか（R-106）。
- 決定（2026-10-03）: 直す（型パラメータの 1 語、ファイル名の `snake_case`、衝突したファイル、項目と子モジュールの衝突を検査する）。std と同名のモジュールは E0304（R-106 / S-37）。
- 判断: 直す（型パラメータの 1 語、ファイル名の `snake_case`、衝突したファイル、項目と子モジュールの衝突を検査する）。std と同名のモジュールは E0304（R-106 / S-37）
- 反映: 仕様 §2.3 / §15.1 に反映済み（2026-10-03）。実装は W4-02
- 反映（2026-10-23、親）: X-8: W4-02 を分け、実装は W4-14（型パラメータの名前の検査を含む）。
- 反映（2026-10-24、親）: W4-14 U2（2026-10-24、61 回目）で、型パラメータの 1 語（仮の扱い S-642）とファイル名・ディレクトリの名前の E0320（S-300・S-313・S-325）を直した。衝突したファイルと、項目と子モジュールの衝突は W4-03（`sig/collect.rs` の作り直し）に残る。
- 反映（2026-10-24、親）: S-642（2026-10-24、62 回目、族 S-650）で、型パラメータの「1 語」の規則を外した。型パラメータは `UpperCamel` で、2 語の名前（`ItemKey`）は通る（U2 の否定の事例は W4-14 U3 で入れ替える）。
