# R-194 modes の段が範囲の端を読まない

- 高・直す・観点 1｜modes｜§5.2、§7
- 内容: `modes.rs` の `ExprKind::Range { .. } => {}` が範囲の端に入らないので、`for i in 0..<b.len()` の端での移動後の使用と、端の中の二重の移動（`for i in 0..<take(move b)` を二つ）が E0704 にならない（`while s < b.len()` は E0704）。Affine の値が二重に解放されうる。`par` の端は読んでいる。W3-18 の前から（`0..b` でも同じ）。
- 経緯: W3-18/b が見つけた（2026-10-09）。
- 決定（2026-10-09、親）: 直す。範囲の端を扱う W3-18 で行う。
- 判断: 直す（親、仕様が明確）。modes の段で範囲の端を値の位置として読み、端での移動後の使用と二重の移動を E0704 にする。W3-18/b で見つけた
- 反映: W3-18 で直した
