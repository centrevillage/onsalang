# R-306 `::` の前後の空白（`F32:: PI`）で、経路の区切りの E0020 の候補を当てると、同じ位置にメンバの空白の E0020 が残る

- 場所: `crates/onsa_syntax/src/foreign/rows.rs` の表の行 `path_separator`（候補は `::` だけを `.` に置き換える）。
- 内容: 経路の区切りに `::` を書き、同じ行でその前か後に空白があると（`F32:: PI`、`F32 ::PI`、`F32 :: PI`）、`::` の E0020 の候補は `::` だけを `.` にする。当てた後の `F32. PI` は、同じ位置にメンバの `.` の前後の空白の E0020（候補は空白を除く）が残る。その候補を当てた `F32.PI` は誤りが無く、二回で直る。
  ファズの入力 `tests/fuzz/ce515053.onsa`（`e:: F` で、`{` が閉じない）。
- 経緯: `4f28a1a` と `d8e0472` の網羅の検査（シャード 0/2）の fuzz が見つけた（ファズ `ce515053`、2026-10-28）。前からある（`7584dc6` のコードも同じ）。
- 判断（2026-10-28、親）: 直さない（実害が低い）。`::` の前後の空白は書き手がまず書かない形で、候補は新しい誤りを作らず、残る E0020 には空白を除く候補があり、二回で直る（R-231・R-244 と同じ形）。入力を `tests/fuzz/allowed.toml` に載せる。
