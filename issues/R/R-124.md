# R-124 先頭が 0 の整数（`017`）が、10 進として通る

- 中・要判断・観点 1 / 3｜`crates/onsa_syntax/src/lexer.rs`（`number`）｜§2.4、§0.3 の規則 4
- 内容: `017` は 10 進の 17 として通る。C・Go・Java は 8 進の 15 と読み、検査を通るのに意味が違う偽の友人になる。Rust は 17 と読み、Python 3 はエラーにする。仕様は先頭の 0 について何も書いていない。
- 判断（R-124）: 推奨は E0020 にし、読みが分かれるので候補に `17` と `15` を並べる。
- 経緯: R-73 の議論で見つけた（2026-10-04）。
- 決定（2026-10-04）: E0020。読みが分かれる書き方はコンパイルエラーにする（利用者の方針）。S-63。
- 判断: E0020。S-63: 0 以外の 10 進の整数は 0 で始めない。`017` の候補は `17` と `15`（`00` は `0`）。読みが分かれる書き方はコンパイルエラーにする
- 反映: 仕様 §2.4 に反映済み（2026-10-04）。実装は W3-05
