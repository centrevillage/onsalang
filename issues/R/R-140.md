- 経緯: W1-06 の実装の担当が見つけた（2026-10-07）。

- 判断: 直す（親、仕様が明確）。C API の `init` を仕様 §14.2 の形（`init(s, bulk, const cfg*, sample_rate)`）にする。W1-06 で見つけた
