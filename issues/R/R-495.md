# R-495 flow の段の診断のうち型検査の歩き（`flow/check.rs`）が出すもの（E0807・E0808、`NestedDelays`・`SampleTick` の E0200）は本体を未完にしてクロックの歩きを止めるので、前の位置のクロックの誤りに勝つ

- 場所: `crates/onsa_sema/src/flow/check.rs`（型検査の中の flow の段の検査。`Stage::Flow` の E0807・E0808、`NestedDelays`・`SampleTick` などの E0200）と `flow/clocks.rs` の `finish_flow`（本体が未完ならクロックの歩きを回さない）。

- 経緯: 165 回目（2026-11-18）、W7-02 U3 の読みの助言の段 1（onsa-advisor）が範囲の外の気付きに挙げ、親が登録した。
