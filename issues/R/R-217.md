# R-217 腕の本体の隣り合う文字列の `,` の候補が、同じ段の誤りを残す

- 低・直す・観点 1｜syntax（`foreign/lists.rs` の `,` の抜けの候補）｜§18.1（候補を当てた後に、同じ段か前の段の誤りを残さない）
- 内容: `match x { 1 => "a" "{x}", _ => 2 }` の E0002 の候補「write the `,` between the elements」を当てると、`"{x}"` が次の腕のパターンになり、「a string with an interpolation cannot be a pattern」の E0002 が残る。
  腕の本体は並びの要素でないので、`,` を足すと別の腕の頭になる。まとめる候補（S-438）は残らない。
  親が dev の `f4b9a8b` と W3-05 の版で再現した（同じ）。
- 経緯: W3-05 の直しの往復 1 の再確認の壊す側が、`fix-same-place` の掃引で見つけた（2026-10-13）。W3-05 の変更の前からある。
- 決定（2026-10-13、親）: 直す。`,` の候補を出すのは、腕の本体の後ろで `,` が腕を区切っても後ろが腕として読める形だけにするか、腕の本体では出さない。時期は W3 の終わりの候補の約束の論点と同じ回。
- 判断: 直す（親）。腕の本体の隣り合う文字列の `,` の候補が、次の腕のパターンの E0002 を残す（`1 => "a" "{x}"`）。W3-05 の再確認の壊す側が見つけた。前からある
- 反映: 実装は W3 の終わりの候補の約束の論点と同じ回
