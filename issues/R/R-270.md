# R-270 文字列の補間 `"{MAXV}"` がモジュールの定数と `use` の束縛を引かず、E0302「cannot find for the interpolation」になる

- 場所: 本体の文字列の補間の名前の解決（W4-04 の `body/names.rs` の作り直しの範囲）
