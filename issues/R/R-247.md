# R-247 名前の無い `lpp~(x)` が E0302 でなく E0812 になり、`~` を外す候補を当てると E0302 が出る

- 場所: `crates/onsa_sema/src/flow/check.rs` の `~` の有無の判定（E0812、416・437 行の文面）。呼び先の名前が見つからないときも flow でないとして E0812 にし、`~` を外す候補を付ける
- 内容: `pub flow lp(…)` のあるモジュールで `lpp~(x)` と書くと、名前が見つからないのに E0812「`lpp` is not a flow; `~` creates a flow instance…」になり、`~` を外す候補が付く。候補を当てた `lpp(x)` は E0302「cannot find `lpp` in this scope」になる。
  名前が見つからない形は E0302 である（§15.1）。§18.1 は、候補を一つ当てて検査し直したとき、触れた単位に同じ段かそれより前の段の診断を残さないとする（E0812 と E0302 はどちらも名前の段）。修復のループが一周増え、文面も誤りを取り違えさせる。
- 経緯: 第 40 組の下書き（onsa-gap、2026-10-23、55 回目）が S-258 の確かめで見つけた（族の外、`target/notes/55/gap40/probe/` の n23・m03）。親が dev `8427cf2` の release の `check --json` で再現した。直しは E0812 の候補の族（S-590）を受け持つ W4-12。
