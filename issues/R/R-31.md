# R-31 `.slice()` を経由すると排他性の検査をすり抜ける。部分ビューの `inout` は未実装

- 高・直す・観点 1｜`crates/onsa_sema/src/modes.rs:790`、`:799-874`、`:462`｜§5.2（E0702）、§5.3｜再現（親）
- 排他性のすり抜け: `add(inout a, a)` は E0702 になるが、`add(inout a, a.slice(0, 8))` と `a.copy_from!(a.slice(0, 8))` は通る。
- 未実装: 仕様の次の形が E0701 になる。`impl-review` §3 にも載っていない。
  - `fill(inout a.slice(0, 4))`
  - `fill2(inout [a, b])`
  - `a.slice(0, 4).fill!(2.0)`
- 未実装: `inout [a, a]` の重複を検出しない。
- 直し方: 組込みの `slice` と、平面の要素を、元の場所の射影として扱う。
- 延期するなら: E0200 で明示し、未実装の一覧に載せる。
- 決定（2026-10-03）: 直す（組込みの `slice` と平面の要素を元の場所の射影として扱い、排他性を検査する。`inout xs.slice(a, b)` と `inout [a, b]` を実装する）。
- 判断: 直す（組込みの `slice` と平面の要素を元の場所の射影として扱い、排他性を検査する。`inout xs.slice(a, b)` と `inout [a, b]` を実装する）
- 反映: 実装（W4-08）
- 反映（2026-10-31、親）: 直した（W4-08 U2 `67a4eb65`、90 回目）。
