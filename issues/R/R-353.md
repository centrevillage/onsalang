# R-353 診断の文面に内部の型変数 `?0` が出る（`Option[?0]` has no field、a float literal cannot have type `?0`、`[?0; 2]` is not a function）

- 場所: 型の表示（`crates/onsa_sema/src/ty.rs` の 527・581 行の辺り）が型変数を `?{番号}` と書き、型の段の診断の文面がそれをそのまま使う
- 内容: `let o = Some(1)` の後の `o.x` は「`Option[?0]` has no field `x`」、`let n = 1 + 2.0` は「a float literal cannot have type `?0`」、`[1, 2].(x)` は「`[?0; 2]` is not a function and cannot be called」（`1bb94a0`）。
  演算子の文面の分は W5-01 U1（R-55）が直した。再現は 105 回目の scratchpad の `s854-advisor/probe/a_mixed.onsa`・`b_some_fld.onsa` と `probe/lits/arr.onsa`
- 経緯: 105 回目（2026-11-03）、S-854 の独立のレビュー（助言の担当）が見つけ、親が再現した。前からある。利用者は「手戻りがないタイミングならすぐ直して良い」とした
- 判断: 直す（文面）。S-854 の文面（「整数」「浮動小数」）と同じ所で、型の中のリテラルの型変数の表示を決めて直す（W5-01 の U2）
