# R-26 非 rt の関数やクロージャを `rt fn` の型として渡せる

- 高・直す・観点 1｜`crates/onsa_sema/src/infer.rs:198`、`body.rs:1777`、`rt.rs:170`｜§10「`rt` は関数型の一部で、高階関数でも保持される」｜再現（親）
- 再現: 次のどれも通る。
  - `apply(heavy, 1.0)`（`apply` の引数の型は `rt fn(F32) -> F32`、`heavy` は非 rt）
  - `let g: rt fn(F32) -> F32 = heavy`
  - `apply(fn(x: F32) -> F32 { heavy(x) }, 1.0)`
  - rt の関数の中から呼んでも通る。
- 原因:
  - 単一化は `rt` を無視している。rt 検査は、rt 関数の本体の中の呼び出しだけを見る。
  - クロージャは期待型から `rt` を写すだけで、本体を rt の規則で検査しない。
- 直し方:
  - `rt` を部分型として扱う。`rt` を期待する位置に、非 rt を置けないようにする。
  - `rt` の型を得たクロージャの本体には、rt の規則を適用する。
- 決定（2026-10-03）: 直す（§8.1 / §10 の関数型の互換の規則で、`rt` の位置に rt でない関数を置けない）。
- 判断: 直す（§8.1 / §10 の関数型の互換の規則で、`rt` の位置に rt でない関数を置けない）
- 反映: 仕様 §10 に反映済み（2026-10-03）。実装は W6-01
