# R-309 型引数の位置の `self`（`let a: Option[self]`）の E0308 の文面が、`self` を「a constant expression」と呼ぶ

- 場所: `crates/onsa_sema/src/sig/types.rs::lower_type_arg`（`ConstArg` の分岐を、頭がローカルかの判定より先に通る）。
- 内容: メソッドの本体の `let a: Option[self] = None` は E0308「`self` is a constant expression, not a type (§4.5)」になる。`self` はローカル（引数）なので、期待は「`self` is a local, not a type (§15.1)」の形。通るプログラムは変わらない。再現は横の `opt_self.onsa`。
  S-741 で署名の型も引数を見るので、署名の `Option[self]` も同じ文面になる。
- 経緯: 79 回目（2026-10-28）、第 69 組の独立のレビュー（onsa-advisor）が見つけ、親が再現した。
- 判断（2026-10-28、親）: 直す（低）。W4-19 で、`ConstArg` の分岐の前にローカルの判定を置くか文面を改める（約 +2〜5 行）。
- 反映（2026-10-28、親）: W4-19 U1 で直した（`88f730f`）。
