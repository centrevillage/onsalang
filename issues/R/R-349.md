# R-349 要素が Affine の `[T; N]` の `fill!(v)` が誤りなく通り、借用で受けた一つの値を全ての要素へ複製する

- 場所: 組込みの表（`crates/onsa_sema/src/builtin.rs` の `Recv::Seq`）が列のメソッドを全ての列の受け手に置き、要素の種を見ない。
- 内容: `fn g(inout xs: [Buf[F32]; 2], b: Buf[F32]) -> U32 uses {Alloc} { xs.fill!(b) … }` が `85400d9b` で誤りなく通り、借用で受けた一つの `Buf[F32]` を二つの要素へ複製する（Affine の値の複製、§5.2）。
  §4.5 は `Buf[T]`・`Span[T]` の要素を `T: Copy` に限るが、`[T; N]` の受け手は `Span[T]` のメソッドを引くので当たらない。再現は `issues/R/R-349/fill_affine.onsa`。
- 経緯: 104 回目（2026-11-02）、X-23 の見積もりの組 A（onsa-impl）が見つけ、助言の担当（段 1）が `fill_affine.onsa` で終了コード 0 を確かめた。親が再現した。前からある。
- 判断: 直す（今通る誤り）。どの形を誤りにするかは S-847（S-794 と同じ族）で決め、W5-02 で列のメソッドを std に宣言するときに直す。
