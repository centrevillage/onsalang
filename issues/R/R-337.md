# R-337 第二級の値（捕捉する無名関数）に付けた `inout` の E0703 の「`inout` を消す」候補を当てると、同じ段の E0710 が残る（`keep(inout fn(x: I32) -> I32 { x + k })`）

- 場所: `crates/onsa_sema/src/modes/calls.rs::by_value`（値で受ける位置の `inout` の印の E0703 と「`inout` を消す」候補）。
- 内容: `move` の関数型の引数 `keep(move f: fn(I32) -> I32)` に捕捉する無名関数を `inout` の印付きで渡す `keep(inout fn(x: I32) -> I32 { x + k })` は E0703「this parameter is `move`: it takes the value, not `inout`」で、候補「remove `inout`」が付く。
  当てた `keep(fn(x: I32) -> I32 { x + k })` は捕捉する無名関数を `move` の引数へ渡す E0710 で、同じ段の誤りが残る（§18.1 の 27 行の約束に反する）。構築子の要素 `Some(inout …)` も同じ形。W4-11 で既定のモードの関数型の引数を第二級にすると、`keep(inout f)`・`Some(inout f)` も同じになる。
  再現は横の `inout_closure.onsa`（`onsa_cases --fix-loop --pick first` で「no-candidate after 1 step」、dev `6de1620d`）。
- 経緯: 92 回目（2026-10-31）、W4-11 の設計メモの審査（onsa-advisor）が指摘した。親が dev のバイナリで再現した。
- 判断: 直す（低。誤りのあるプログラムの候補の有無だけ）。W4-11 U1 で、被演算子が第二級の値のとき `by_value` の候補を出さない（E0703 は残す。§18.1 の「候補を作れなければ出さない」）。
- 反映（2026-10-31、親）: W4-11 U1（`c644644c`）で、`by_value` の候補を、被演算子の末尾に第二級の値があるときは出さない形にした（E0703 は残る）。`negative/fn_param_second_class_inout_mark.onsa`・`fn_param_second_class_marked_tails.onsa`
