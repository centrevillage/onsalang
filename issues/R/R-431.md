# R-431 C の後端が、借用の引数の struct の配列のフィールドを `Span[U8]` の引数に渡す形（`view_len(s.a)`、`s.a.slice(0, s.n)`）で `const` を捨てる C を出し、`-Werror` の C コンパイラが通らない

- 場所: `crates/onsa_backend_c/src/emit/fns.rs` の `span_arg`（と、同じ形を作る `Span` の部分のビューの所）。`export.rs` の境界の写しは要素の型への cast を書いている。
- 内容: 借用の引数で受けた struct の配列のフィールドを `Span[U8]` の引数に渡す形（`struct S { a: [U8; 4], n: U32 }` の `fn of_param(s: S) -> U32 { view_len(s.a) }` と `view_len(s.a.slice(0, s.n))`）で、C の出力が `const uint8_t[4]` を `uint8_t *` の引数に渡し、`clang -std=c11 -Wall -Wextra -Werror -pedantic -fsyntax-only` が「discards qualifiers」の誤りを 2 件出す（dev `69326f64`。`-Werror` が無ければ警告）。値は正しい。再現の入力は横のディレクトリ。
- 経緯: 139 回目（2026-11-11）、W5-12 の設計メモ（onsa-impl）が範囲の外で見つけ、親が再現した。`FixedStr` を借用の引数で受けて `Span[U8]` に渡す形は全てこれに当たる。
- 判断: 中（正しいプログラムの C が `-Werror` で通らない）。`FixedStr` の `Span[U8]` の出口を入れる W5-12 の単位（U3a）で直す（`rules/leader.md` 7.4: その形を担う作業で、C の手順の事例がこの形を要る）。
- 反映（2026-11-12、親）: W5-12 U3a `499d8d22` で直した（`emit/fns.rs::array_span` が配列の `Span` を一か所で作り、要素の型へ cast する）。R-109 の `const` の外れと同じ不具合で、`tests/pipeline/span_const.onsa` の C も通るようになった。S-94 の (2) の `const T*` の型は R-109 の W10-04 で見る。
