# R-341 定数を `!(` で呼ぶ `K!(x)` の E0020 の候補が `K.!(x)` を作り、構文の段の E0002 が残る

- 場所: sema の名前の段（`names/body/kinds.rs::value_called`。値の `x(...)` の E0020 を `!(` の呼び出しにも当て、候補は呼び先の後への `.` の挿入）。
- 内容: fn の本体の `K!(x)`（`K` は定数）は名前の段の E0020「a value is called as `f.(x)`」と、呼び先の後に `.` を挿入する候補で、当てた `K.!(x)` は構文の段の E0002「expected a field name or tuple index after `.`, found `!`」になる。
  §18.1 の約束（前の段の誤りを残さない）に反する。flow の本体も同じ。組込み型の定数の `F32.PI!()` も `F32.PI.!()` を作る（`issues/R/R-341/pi_bang.onsa`、第 76 組の段 1 が見つけた）。
  入力は `issues/R/R-341/k_bang_fn.onsa` と候補を当てた後の `k_bang_after.onsa`（dev `cf526898`）。
- 経緯: 93 回目（2026-10-31）、第 76 組の下書き（onsa-gap）が見つけ、親が再現した。前からある。
- 判断: 直す（低。誤りのあるプログラムの候補だけ）。値を `!(` で呼ぶ形のコードと候補は第 76 組（S-812）で決まり、どの読みでも W4-12 の U1 で直る。
- 補い（2026-10-31、親）: 署名と本体の定数式（`[F32; K!(1)]`、`[0; K!(1)]`）は `constarg.rs` が別に読み、W4-12 U1 の後も E0020 と候補 `K.!(1)` のまま（U1 の壊す側が見つけた）。`constarg.rs` を触る W4-12 の U3 で揃える。
- 反映（2026-10-31、親）: W4-12 U1（`65d5aaae`）。本体の呼び出しの `K!(x)`・`F32.PI!()` は E0401 で候補なし。定数式の形（`[F32; K!(1)]`、`[0; K!(1)]`）は U3 で揃えるまで OPEN のまま。
- 反映（2026-10-31、親）: W4-12 U3（`ebe6fe13`）。署名と本体の定数式の `[F32; K!(1)]`・`[0; K!(1)]` は本体の `K!(x)` と同じ E0401 で候補なし、`[F32; N(1)]` は E0020（`resolve.rs::at_callee` の `Callee::NoFunction`）。本体の `K!(x)` は U1 で直っていた。
