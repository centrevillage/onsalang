# R-303 互いを指す型別名の循環（`type C0 = C1`、…、`type C(N-1) = C0`）の検査が指数時間になる（N=20 で約 34 秒、N=300 は 60 秒で終わらない）

- 場所: 型別名の展開（`crates/onsa_sema/src/sig.rs::alias_ty` の `expanding`、`sig/types.rs::lower_alias_before`）が、循環に入った別名を使う所ごとに鎖の全体を辿り直す（推測。W4-04 U8b/b の報告）。
- 内容: `type C0 = C1` から `type C(N-1) = C0` までの循環を宣言するだけで、`onsa check` の時間が N に対して指数で伸びる（N=12 で 0.08 秒、16 で 1.5 秒、18 で 6.6 秒、20 で約 34 秒、300 は 60 秒で打ち切り）。
  前からある（W4-04 U8b の前の `95cd275` でも N=18 で 6.5 秒）。誤りのある入力で検査が終わらないことは、修復のループと LSP を止めるので重大度は高（壊す側の見立て）。再現は `python3 issues/R/R-303/scale.py <onsa> none 12 16 18`。
- 経緯: 78 回目（2026-10-28）、W4-04 U8b/b（onsa-break）の指摘 6。関係: R-182、R-298、S-730。
- 判断: 直す（高）。別名の循環の E0311（R-182）を入れる W4-05 で、展開の結果か循環の判定を別名ごとに一度だけ求める形にする。W4 の段の終わりの前に直す（`rules/process.md` の Q-12）。
