# R-05 インタプリタの再帰が深さ約 200 でプロセスごと落ちる

- 中・直す + 仕様へ・観点 1 / 3｜`crates/onsa_interp/src/lib.rs:112`｜§12.5
- 再現: `fn depth(n: U32) -> U32 { if n == 0 { 0 } else { depth(n - 1) + 1 } }` の `depth(200)` で、debug ビルドの `onsa test` が abort する。上限の 4096 は効いていない。他のテストの結果も出ない。
- 直し方: 大きなスタックのスレッドで実行し、上限は実測で決める。
- 仕様へ: スタックが尽きたときの挙動（R-112）。
