# R-99 `@param` の値の型を検査しない。NaN の扱いが書かれていない

- 低・要判断・観点 3｜`crates/onsa_core/src/lower/flow.rs:571`、`:1382`、`runtime/c/onsa.h:385`｜§11.7
- 再現:
  - `@param(default: 2.7) n: Ctl[I32]` で、既定値が黙って 2 に切り捨てられる。
  - `Ctl[Bool]` の `@param` は内部エラーになる。
- 未報告の方針: 飽和で NaN を素通しする方針は、`onsa.h` のコメントにしか無い。
- 判断（R-99）: 整数と `Bool` の `Ctl` 入力に `@param` を認めるか。
  - 推奨は、整数は認めて値の型を検査し、`Bool` は `min` / `max` 無しで認めること。
  - NaN の扱い（素通しか、既定値に置き換えるか）も仕様に書く。
- 範囲（2026-10-05 に追加で確かめた）:
  - NaN の扱いは、R-21 で `@param` を純粋なメタデータにした（境界の飽和をやめた）ときに論点ごと無くなった。値の条件は呼び出し側の責任。
  - 値の検査が無い: `I32` の `default: 2.7`（2 に切り捨て）、`U32` の `min: -1`、`min > max`、範囲の外の `default`、`step: 0.0`、`scale: "log"` で `min: 0.0`、同じキーの二度書き（後が勝つ）、補間の `unit: "d{x}B"`（`"dB"` になる）が全て通る。
  - `Bool` と enum の入力は `check` を通り、`onsa test` で `params_default` の降下が内部エラー（numeric literal of a non-numeric type）。`Bool` に `default: true` と書くと E0809（数値のリテラルでない）。
  - 仕様は値を「コンパイル時定数」とするが、実装はリテラル（と符号の反転）だけ。`max: TOP` は E0809。
  - `default` は省略でき、export では `@param` が必須でも `default` は不要なので、C の `params_default` を作れない場合がある。
  - C の `onsa_param_info` は仕様に形が無く、`onsa.h` は `float` と NAN（未指定）で、型の情報が無い。
  - 再現は `tests/review-phase1/parent/r99.onsa`（期待値と今の出力は各 flow の上のコメント）。既存の `flow/e16/pd.onsa` も同じ。
- 決定（2026-10-05）: S-87。
  - (1) 入力の値型は `F32` `F64` `I8`〜`I32` `U8`〜`U32` `Bool`。`I64` / `U64` は `double` の受け渡しで全ての値を表せないので外す。enum は §19.1（表示名、値の番号、C の表現を決める必要があり、後から足しても壊れない）。
  - (2) 値は `const` の初期化式と同じ規則（型は入力の値型、文字列のキーは `Str`）。本体で範囲を守るとき（R-21）と同じ定数を共有でき、`@param` 専用の文法を持たない（利用者: 統一感がある）。
  - (3) 制約: 有限、`min < max`、`default` は範囲の中、`step > 0`、log は `min > 0`、`Bool` には `default` `unit` `label` `id` だけ、同じキーは一度だけ（E0809。型の不一致は E0401）。
  - (4) `default` は必須。CLAP / VST3 / AU は既定値を要し、`params_default` の規則も単純になる。
  - (5) C の `onsa_param_info`（§14.2）: `kind`（入力の型）と `scale` の列挙、値の欄は型で形が変わる共用体。元の案（全て `double`）は、真偽を数で表すことになるので利用者の指摘で改めた。制約が無ければソースでキーを書かず、C の表では制約の無い値（浮動小数は `-INFINITY` / `INFINITY` / `0`、整数は型の範囲の両端と `1`）で埋める（有無の印の案は採らなかった）。
- 判断: S-87: 入力の値型は `F32` `F64` `I8`〜`I32` `U8`〜`U32` `Bool`（`I64` / `U64` と enum は E0809、enum は §19.1）。値は `const` の初期化式と同じ規則（型は入力の値型）。`default` は必須。
  制約（有限、`min < max`、範囲の中の `default`、`step > 0`、log は `min > 0`、`Bool` のキー、重複なし）は E0809、型の不一致は E0401。C の `onsa_param_info` は `kind` で値の欄の形が変わる共用体で、書かれていない範囲は制約の無い値。NaN は R-21 で論点ごと無くなった。
  再現は `tests/review-phase1/parent/r99.onsa`
