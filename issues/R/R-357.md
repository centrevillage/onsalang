# R-357 一般の E0406 の文面が、組込み型の `impl` の型パラメータで推論の変数を出す（`the impl of Buf[<0>]`）

- 場所: `crates/onsa_sema/src/body/generics.rs` の 63 行（`the `impl` of `{head}`` の `head`）と、文面を出す `deferred.rs`。再現は `target/notes/106/w502u1/probe/impls.onsa` の 14 行と `e0406.onsa`
- 内容: 組込み型の `impl` の関連関数の呼び出しで型パラメータが決まらないとき、一般の E0406 の文面が対象の型を推論の変数ごと出す（`the type parameter `T` of the `impl` of `Buf[<0>]` cannot be determined`）。利用者の型（`W`）では `of `W`` と出る。§18.1 は文面に推論の変数を出さない。
  今は利用者が組込み型に `impl` を書く形（孤児規則の前）でだけ出るが、W5-02 の U6 で `Buf.zeroed` が std の `impl[T: Copy] Buf[T]` になると一般の道を通るので、その単位で型の名前だけを出すように直す
- 経緯: 106 回目（2026-11-03）、W5-02 U1 の設計メモ（onsa-impl）が範囲の外で気付き、独立の審査が R の候補に挙げた。親が固定のバイナリ（`dc6570a1`）で再現した。前からある
