# R-531 場所でない添字の基（`if`・ブロックの末尾、部分ビュー `slice`）を持つ添字の中で、基の `Buf` を移す・付け替える形を `check` が通し、移した・破棄した `Buf` を読む（`(if t { b } else { c })[take(move b)]`、`b.slice(0, 2)[take(move b)]`）

- 場所: sema の値の段（`crates/onsa_sema/src/modes/walk.rs` の `ExprKind::Index` の枝と `path()`）。基が場所の経路なら `b[take(move b)]` は E0704 になるが、基が場所でない式（`if`・`match`・ブロックの末尾、`slice` の部分ビュー）だと、添字の中の `move`・`inout` の付け替えを基の使用と重ねて数えない。
- 内容: `(if t { b } else { c })[take(move b)]` と `b.slice(0, 2)[take(move b)]`（`b: Buf[F32]`）は `check` を通り、解釈器は移した `Buf` を読んで 0.0 を返す。`(if t { bs } else { cs })[rbs(inout bs)].len()`・`({ bs })[…]`（`rbs` が `bs` を長さの違う `Buf` に付け替える）と `b.slice(0, 2)[rb(inout b)]` も通り、破棄した前の `Buf` を読む。§5.2・§5.4 の移動と借用の規則に反する（移した値の使用、借用の間の変更）。第 1 期は `Buf` が C に届かない（E0200）ので、観測は解釈器だけ。再現の入力はこの R の横の `q.onsa`（`q02`・`q03`）と `n.onsa`（`n01`・`n02`・`n20`）。
- 経緯: 194 回目（2026-11-28）、第 123 組（S-1273）の独立のレビューの段 1（onsa-advisor）が想定漏れを探して見つけた。親が `target/base/0049175/onsa` で再現した。
- 判断: 直す。S-1273 の決定と一緒に W8-03 で直す（通るプログラムを誤りにする直しなので、見つけた作業で直す。`rules/leader.md` 7.4）。S-1273 で添字の中の基の変更を誤りにするなら、同じ判定で塞がる。
- 補い（2026-11-28、親）: S-1275 の決定（F4、利用者）で、添字の中で基と重なる場所を変更する形は E0702 になり、この形は通るプログラムから無くなる。W8-03 の U3b（sema の窓）で閉じる。
