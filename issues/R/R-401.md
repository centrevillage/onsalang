# R-401 閉じない `[` の並びの次の行頭に語の並びの項目（`export fn z`）が続く形を並べると、検査の時間が二乗に近く増える（4000 個で 0.38 秒、8000 個で 1.41 秒）

- 場所: 未確認（括弧の中の並びの要素の読みと回復。`fn z` なら線形なので、語の並び（`export`）を要素の名前として読む経路の見込み）。
- 内容: `fn f<i>() -> I32 {` / `  let y = [1,` / `export fn z<i>() -> I32 { 1 }` を N 個並べると、`onsa check` が N=2000 で 0.12 秒、4000 で 0.38 秒、8000 で 1.41 秒（debug）。`export` を `fn` に替えると 0.02・0.05・0.09 秒、`[1,` を `1 +` に替えると 0.05・0.09 秒、`export fn` だけを並べると 0.02・0.04 秒で線形。
  dev（`7324d34`）でも同じ（4000 で 0.36 秒、8000 で 1.38 秒）。X-20 の性能の要件の二乗の形に当たる。台本は `target/notes/124/w511u9/probe/quad.py`。
- 経緯: 124 回目（2026-11-08）、W5-11 U9 の直しの往復の実装の担当（onsa-impl）が見つけ、親が U9 の後と dev の固定のバイナリで再現した。
- 判断: 直す（親）。W5-11 の U10（R-398 と同じく性能の形）。
