# R-328 derive の一覧が E0200 の型（`struct P1: Show { … }`）を境界の型引数に使うと、使う側（`fn k(x: S2[P1])`、本体の `need_show(p1)`）に偽の E0416 が出る（宣言の誤りの連鎖。derive を空として扱う）

- 場所: derive の一覧の読み（E0200 の derive を落として空とする所）と `Bounds::satisfies` の利用者の型の trait の腕。
- 内容: `struct P1: Show { … }`（この版の derive の `Show` が E0200）の後の `fn k1(x: S2[P1])`（`S2[T: Show]`）に E0416「`P1` does not satisfy the bound `T: Show`」が出る（再現は横の `d2.onsa`）。
  宣言の誤りを直すと消える連鎖で、§18.1 の誤りのある宣言（読めなかった部分を使う側に診断を出さない）に反する。本体の `need_show(p1)` には前から出る。
- 経緯: 82 回目（2026-10-29）、W4-05 U4a/b（onsa-break）が低の指摘 7 として挙げた。
- 判断: 直す（低。誤りのあるプログラムの報告だけ）。W4-05 U4b のついでに、derive の一覧に誤りのある型の trait を未知として扱う。
- 反映（2026-10-29、親）: W4-05 U4b（`f9ef2c6`）: `DERIVABLE` にこの版で扱えるかの欄を足し、E0200 の derive も書いた trait として満たす。事例 `tests/spec/types/wellformed_derive_error_uses.onsa`。誤りの名前の扱いは S-774（W5-06）。
- 判断（2026-10-29、親）: W4-05 U4b では、derive の一覧に誤りのある型の trait を未知とする形でなく、この版の E0200 の derive を書いた trait として満たす形にした（反映）。見つからない名前と derive できない名前の扱いは S-774（W5-06）。
