# R-01 字句解析器が非 ASCII の文字でパニックする

- 高・直す・観点 1｜`crates/onsa_syntax/src/lexer.rs:283`、`:291-293`、`:355-357`｜§2.4｜再現（親）
- 原因: 不正なバイトを 1 バイトずつ読み飛ばすので、スパンが UTF-8 の文字の途中を指す。
- 再現:
  - `let s = "{音}"` で `onsa check` がパニックする（`byte index 26 is not a char boundary`）。
  - `"\音"` は、`onsa_driver/src/lib.rs:289` の `fill_found` でパニックする。
- 影響: LSP（M7）では、入力の途中で常駐プロセスが落ちる。
- 直し方:
  - 読み飛ばしを文字単位にする。
  - 全てのスパンが文字境界にあることを `debug_assert` で検査する。
  - 非 ASCII を含む否定例を足す。
