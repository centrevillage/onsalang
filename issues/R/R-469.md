# R-469 比べの連鎖の読み（`foreign/lines.rs::read_chain`）が、外に対の無い深さ 0 の閉じ括弧を連鎖の終わりとして受け、`a === _ )` のような誤りが二つの入力にも `==` の候補を出す

- 場所: `crates/onsa_syntax/src/foreign/lines.rs::read_chain`（深さ 0 の閉じ括弧で連鎖を終える所。`from` の外の開き括弧を閉じるかを見ない）。
- 内容: `a === _ )`・`a === _ ]`・`h(a === _ ()` は、閉じ括弧に対が無い（誤りが二つ）のに連鎖が読めたとして `strict_equality` の候補「compare with `==`」が出る。U10 の前の `compares` も `a === b )` に候補を出していた（前から）。U10c が `_` を被演算子に受けたので、`_` の形にも広がった（壊す側の格子 gen_d で U10 に比べて 46 件）。誤りが二つの入力だけで、当てると閉じ括弧の誤りが残る。
- 経緯: 154 回目、2026-11-15、W6-04 U10c の直し（交互の確かめを `read_chain` に入れた）の実装の担当が「範囲の外」に挙げた（報告 `target/notes/154/w604/onsa-impl-a8b2756539c2a8b03-001.md`）。止まる線に当たるので入れなかった。
- 判断: （2026-11-15、親）低。直すなら深さ 0 の閉じ括弧が `from` の外の開き括弧を閉じるかを確かめる。W6-04 の区切りで、残りの単位に入れるか第 2 期へ送るかを決める。
