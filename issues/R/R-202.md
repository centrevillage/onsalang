# R-202 括弧に接する前置の `~`（`let y = ~(a)`）が `faust_bit_not` にならず候補の無い E0002

- 低・直す・観点 1｜syntax（`foreign.rs` の `faust_bit_not`）｜§2.6、§18.1、`spec/foreign-forms.toml` の `faust_bit_not`
- 内容: `let y = ~a` は `faust_bit_not` の E0020（候補 `!a`）だが、`let y = ~(a)` は「expected an expression, found `~`」の E0002 で候補が無い。
  S-363 で `faust_bit_not` の範囲を「直前が名前でも `if` / `match` でもない、被演算子に接する前置の `~`」と決め、データのファイルの注記にも書いたが、括弧に接する形が外れている（`~(` を名前の無い flow の呼び出しの印として読んでいるとみられる）。W3-09 の前の dev でも同じ。
- 経緯: 第 17 組の下書きが見つけ、親が dev と W3-09 の途中のバイナリで確かめた（2026-10-09）。
- 決定（2026-10-09、親）: 直す。FAUST の形の照合を作る W3-08 で行う。
- 判断: 直す（親）。括弧に接する前置の `~`（`let y = ~(a)`）が `faust_bit_not` の E0020 にならず、候補の無い E0002（S-363 の範囲から外れる）。第 17 組の下書きで見つけた
