# R-339 名前でない値（タプルの添字でないもの）に接した `!(` が、並びの外では note の無い E0002 になる（同じ位置の `~(` は印の note を出す）

- 場所: syntax（`crates/onsa_syntax/src/parser/expressions.rs` の後置の印の枝。`SPEC-GAP(S-631)` の近く）。
- 内容: 名前でない値に接した `!(`（`inc(1)!(x)`、`t.0[1]!(x)`、`t.0.(x)!(x)`）は、並びの外では E0002「expected newline or `}`」だけで、印の書き方の note が無い。同じ位置の `~(`（`inc(1)~(x)`）とタプルの添字に接した `!(`（`t.0!(x)`）は、印は項目・メソッド・flow の名前の直後に書くという note を出す。
  入力は `issues/R/R-339/bang_after_call.onsa`（note なし）と `tilde_after_call.onsa`（note あり）。並びの中の `two(inc(1)!(x), 1)` は `,` の挿入の候補が出る（S-631）。
- 経緯: 93 回目（2026-10-31）、S-630・S-631 の独立のレビューの段 1（onsa-advisor）が見つけ、親が dev `cf526898` で再現した。
- 判断: 直す（低。報告の文だけで、候補と通るプログラムは変わらない）。印の note を `~(` と同じ条件で付ける。S-631 の注記を直す W4-12 の呼び出しの形の単位で一緒に行う。
