# R-152 `main` より後ろに並ぶモジュールで宣言した総称の型を、別のモジュールで型引数つきで使うと E0302 になる

- 中・直す・観点 1｜名前の段（モジュールの処理順）｜§15.1、§4.5
- 内容: パッケージの中で、ファイル名が `main` より後ろに並ぶモジュールで宣言した総称の struct / enum を、別のモジュールのシグネチャで型引数つきで使うと `Wrap takes 0 type argument(s), 1 given`（E0302）になる。ファイル名を `main` より前にすると消える。宣言の処理がモジュールの並びの順に依っている。
- 経緯: W2-06/t で見つけた（2026-10-08）。再現は `tests/spec/semantics/imported_generic_pkg`（W2-06 で入る）。
- 決定（2026-10-08、親）: 直す。仕様は明確で、判断は要らない。署名の段を作り直す W4-05（宣言どうしを順によらず扱う）で直す。
- 判断: 直す（親、仕様が明確）。総称の型の宣言を、モジュールの並びの順によらず扱う。W2-06/t で見つけた
- 反映: 実装は W4-05
