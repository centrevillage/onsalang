# R-11 C: 符号無しから符号付きへの `narrow_*` が常に `None` を返す

- 高・直す・観点 1｜`crates/onsa_backend_c/src/emit.rs:1584-1600`｜§3.3
- 原因: `uint32_t` と `INT32_MIN` を比べるので、`INT32_MIN` が `0x80000000` に変換される。
- 再現: `5u32.narrow_i32()` が `None` を返す。U64 → I64、U32 → I8 も同じ。
- 直し方: 符号無しから符号付きへの変換では、上限だけを比べる。
