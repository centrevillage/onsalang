# R-533 要素の長さが 0 の配列の添字を `for` の反復元に置くと（`g: [[U32; 0]; 2]` の `for x in g[i]`、`i = 5`）、解釈器も C も範囲外を報告せずに通る

- 場所: 解釈器の `for` の反復元の評価（`crates/onsa_interp/src/exec.rs`）と C の後端の `for` の降下（`emit/fns/`）。反復元が添字の場所で、要素の長さが 0 のとき、添字の範囲の検査を飛ばす。
- 内容: `let g: [[U32; 0]; 2] = [[], []]` の `for x in g[i] { … }` は、`i = 5` でも解釈器も C も範囲外を報告せず、0 回回って通る（再現の入力はこの R の横の `f.onsa` の `f02`）。同じ `g[i]` を `let`、`.len()`、`Span` の引数に置くと、両方とも範囲外を報告する（`f03`〜`f05`）。§9.2 の添字の検査は要素の長さによらない。あわせて、C は反復元の純な添字の式（`1 / z`、`onsa_idx(i, …)`）をループの中で反復ごとに評価し直す（効果のある式は一度だけ。`f01`）。
- 経緯: 194 回目（2026-11-28）、第 123 組の下書き（onsa-gap）が族の形を調べて見つけた。親が `target/base/0049175/onsa` で再現した。
