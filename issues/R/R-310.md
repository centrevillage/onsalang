# R-310 同じ総称の型を入れ子にした型（`Pair[Pair[I32]]`）の種が計算できない（`kind.rs` の訪問中の def の集合が内の `Pair` で `None` を返す）。今は分からない種を Affine でないとみなすので偶然通るが、W4-16 で Affine にすると Copy の値が二度使えなくなる

- 場所: `crates/onsa_sema/src/kind.rs` の 50 行の周り（`visiting: HashSet<DefId>` の守り）。
- 内容: `pub struct Pair[T] { a: T }` の `Pair[Pair[I32]]` で、外の `Pair` を訪問中に内の `Pair` に当たり `None` を返す。`onsa interface` は `Inner`（`p: Pair[I32]`）に `Copy` を出し、`Outer`（`p: Pair[Pair[I32]]`）に種を出さない。再現は横の `nested_generic.onsa`（循環が無いので `interface` も回せる）。
  今は分からない種を「Affine でない」とみなす（R-30）ので値は複製でき、偶然通る。W4-16 が分からない種を Affine にすると、Copy の値が二度使えなくなる退行になる。
