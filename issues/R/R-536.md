# R-536 遅延の書き位置 `w` の添字を検査しない C（W8-03 U5c の `below`）のメモリの安全が、関数をまたぐ状態の不変条件 `w < N` に頼る。状態を Core の外から書く者（ホットリロードの状態の引き継ぎ、§18.3）が破ると範囲外を書く

- 場所: `crates/onsa_core/src/bounds.rs`（`Below` の表と `Env::below`: 書き位置の欄の読みを `[0, N−1]` とみなす）、`crates/onsa_core/src/verify/scope.rs`（V-26）、`crates/onsa_core/src/lower/flow/state.rs`（`StateField::below`）。
- 内容: W8-03 U5c から、flow の降下が遅延と `vdelay` の書き位置の欄に `below: N` を記録し、区間の段がその欄の読みを `[0, N−1]` として `buf[w]` の検査を外す。健全さは V-26 の帰納（Core の中の全ての書き込みが N 未満）だけで、Core の外の書き込みは見ない。§18.3 の照合は型が同じノードの間でだけ状態を引き継ぎ、`[T; N]` の N が同じときだけ `w` が引き継がれるので、今の字では不変条件は保たれる。状態の引き継ぎ・移し替え・外からの状態の書き込みを足す作業は、`w < N` を保つ義務を負う（`below` の欄を引き継ぐときに確かめるか、`init` に戻す）。
- 経緯: W8-01 の設計メモ部 4 の 3.3 の L1（191 回目）。W8-03 の決まったことの一枚（194 回目）で「U5 で R に記録」と決め、U5c（195 回目）で `below` を入れたときに親が登録した。
