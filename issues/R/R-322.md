# R-322 種の制約の判定（`body/bounds.rs::satisfies`）に `Ptr` の腕が無く、種が Copy の `Ptr[F32]` を `U: Copy` の型パラメータ（暗黙の `Dup` も）に渡すと、偽の E0416「`Ptr[F32]` is not Copy or Shared」が出る（§4.1 の表は `Ptr[T]` を Copy とする）

- 場所: `crates/onsa_sema/src/body/bounds.rs::satisfies`（`Checker` の種の制約と trait の境界の判定）。組込み型の腕は `Str`・`Bytes`・`Array`・`Map`・`Set`・`Option`・`Result` だけで、`Ptr` は最後の `_ => false` に落ちる。
- 内容: §4.1 の表は `Ptr[T]` の種を Copy とする。`pub fn need[U: Copy](x: U) -> U { x }` の `need(p)`（`p: Ptr[F32]`）に E0416「`Ptr[F32]` is not Copy or Shared, so it does not satisfy `U: Dup` of `need`」が出る（`target/notes/81/u4/g_body_sat.onsa` の 4 行）。
  暗黙の `Dup` の型パラメータに渡しても同じ。
  W4-05 U4（今の名では U4a）で `satisfies` を署名の段と共有すると、署名の `Buf[Ptr[F32]]`・`W[Ptr[F32]]` にも偽の E0416 が出る。
- 経緯: 81 回目（2026-10-29）、W4-05 U4/i の見積もり直し（onsa-impl）が範囲の外の気付きとして挙げ、親が dev `5aa4557` の `target/debug/onsa` で再現した。前からある。
- 判断: 直す（中。正しいプログラムを拒む）。W4-05 U4a の `satisfies` の共有と同じ単位で、`Ptr` の腕（`Copy`・`Dup`）を足す（約 1 行）。
- 反映（2026-10-29、親）: W4-05 U4a（`6bd892a`）: `Bounds::satisfies` に `Ptr` の腕（`Copy`・`Dup`）。事例 `tests/spec/types/wellformed_ptr_kind.onsa`。
