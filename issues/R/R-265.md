# R-265 `onsa interface` が、出さない型（無指定と `priv`）の固有の `impl` を `pub` のメンバ付きで出す

- 場所: `crates/onsa_driver/src/interface.rs` の `DefKind::Impl` の腕（メンバの `vis` だけを見て、持ち主の型が出るかを見ない）
- 内容: 横のディレクトリの `pk2` で、無指定の `struct Inner` の `impl Inner`（`pub fn new`・`pub fn get`）と `priv struct Hidden` の `impl Hidden`（`pub fn make`）が、型の宣言を出さないのに `impl` の節として出る（dev `3895f4d` の `onsa interface`）。
