# R-411 本体の値と呼び出しの位置の効果行変数（`let a = e`、`e(x)`）が「cannot find `e`」の E0302 になる（型と境界の位置は E0308、§15.1 では名前空間でも値でもない名前）

- 場所: `names/body/paths.rs` の経路の頭の引き方（本体は見出しの効果行変数を値の名前として引かない見込み）。
- 内容: `fn v[e](f: fn(F32) -> F32 uses {e}, x: F32) -> F32 uses {e} { let a = e … }` の `e` と、`e(x)` の `e` は E0302「cannot find `e`」。
  同じ関数の `-> e`・`U: e` は E0308（「`e` is an effect row variable, not a type」など）。§15.1 は効果行変数を名前空間でも値でもない名前とし、名前が見つかって種類が違えば位置によらず E0308 とする。誤りのあるファイルのコードだけ。前から。入力は `target/notes/125/w511u10f/a.onsa`。
- 経緯: 125 回目（2026-11-08）、W5-11 U10f/i（onsa-impl）が範囲の外で気付き、親が前のバイナリ（`88cd71ae`）と U10f の途中のバイナリで再現した。
- 判断: 直す（親）。W5-11 U10f に含める（足す行が 15 以内なら。超えるなら U10f の後に回す）。
- 反映（2026-11-08、親）: W5-11 U10f（`d476c183`）: `names/body/paths.rs::effect_var` が `kind_fail` の E0308 にする（値の位置は「not a value」、呼び出しの頭は「not a function」）。`e~(x)` と `TypeOrValue` の位置（`s.gm[e](x)`）は前のまま E0302。
