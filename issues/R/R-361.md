# R-361 構築子の関数値（`let f = Hold.B`）が Affine の要素の引数を借用で受けるので、`f.(b)` で借用の Affine の値を値に入れて返せ、同じ値を二度包める（直接の `Hold.B(b)` は E0711）

- 場所: 構築子の関数値の型を作る所（`crates/onsa_sema/src/` の型の段。タプル形の列挙子を値として書いた形の関数型の引数のモードが `Mode::Borrow`）。
- 内容: §4.4 はタプル形の列挙子を捕捉の無い関数値とし（`Circle` は `fn(F32) -> Shape`）、§5.2・§5.4 は借用の Affine の値を値に入れられない（E0711）とする。
  今の実装は構築子の関数値の引数を借用で作るので、`let f = Hold.B` の後の `f.(b)` が、借用の `b: Buf[F32]` を `Hold` の値に入れて返せる。`move` で受けた `b` でも `(f.(b), f.(b))` で同じ値を二度包み、`f.(b)` の後に `b.len()` を読める。直接の `Hold.B(b)` は E0711 になる。
  再現は `issues/R/R-361/ctor_affine_alloc.onsa`（`1a848838` で `x_value_twice`・`x_value_then_use`・`x_borrowed_twice` が通り、`x_lambda_like`・`x_direct_borrowed` は E0711）。直し方は S-872（構築子の関数値の引数のモード）の決定で決まる。
