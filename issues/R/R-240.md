# R-240 `_` で始まる名前の let の束縛が、E0302 になる

- 場所: 名前の段（`let` の束縛の名前の解決。場所は未確認）。
- 内容: `let _z = 5` が、束縛の名前の位置で E0302 `cannot find \`_z\`` になる。型を書いた `let _z: I64 = 5` も同じ。引数の `_x` と、`_` で終わる `z_` は通る。
  仕様 §2.3 は、識別子を「ASCII の英字・数字・`_` からなり、数字では始まらない」とし、`_` で始まる名前を特別に扱う文は無い。正しいプログラムを拒んでいる疑いがある。再現は `R-240/let_underscore.onsa`。
- 経緯: X-3/U1c の壊す側の再確認が、範囲の外で見つけた（2026-10-18）。前からある（dev `d0ff722` も同じ）。
- 判断（2026-10-18、親）: 直す。直す作業は、X-8 で W4 の範囲を決めるときに決める。
- 判断（2026-10-23、親、X-8）: R-168 と同じ誤り（`let _x = 1` が束縛の位置で E0302）。W4-04 で R-168 と一緒に直す。
- 判断（2026-10-24、親）: 改めた（2026-10-24、63 回目、S-648・S-650 の決定）: R-168 と同じく、`_z` は頭の `_` を飛ばして束縛と読み、名前の規則（頭の `_` は書けない）で E0320、候補は `z`。引数の `_x` も E0320。直すのは W4-14 U3（R-168 と一緒に、文書の点検の指摘）。
