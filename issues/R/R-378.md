# R-378 長さ 0 の `[x; 0]` の C が `{ { } }` になり、`-Werror,-Wc23-extensions` の検査で落ちる

- 内容: 横の `zero_repeat.onsa` を前のバイナリで回して再現する。`struct Z: Default { a: [I32; 0] }` の `default()`（W5-06 U3）も同じ所に当たる。W5-06 の前からの形である。
- 経緯: 117 回目（2026-11-06）、W5-06 U3/i（onsa-impl）が範囲の外で見つけた。
