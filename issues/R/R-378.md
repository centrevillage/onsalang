# R-378 長さ 0 の `[x; 0]` の C が `{ { } }` になり、`-Werror,-Wc23-extensions` の検査で落ちる

- 場所: C の生成の配列の初期化子。`[1; 0]` の C が `{ { } }` になり、`-Werror,-Wc23-extensions` で落ちる。
- 内容: 横の `zero_repeat.onsa` を前のバイナリで回して再現する。`struct Z: Default { a: [I32; 0] }` の `default()`（W5-06 U3）も同じ所に当たる。W5-06 の前からの形である。
- 経緯: 117 回目（2026-11-06）、W5-06 U3/i（onsa-impl）が範囲の外で見つけた。
- 判断（2026-11-27、親）: 191 回目、W8-01 の設計メモ部 2（2.7）が、R-432（`499d8d22`）の直しで既に直っていると見つけた。`issues/R/R-378/zero_repeat.onsa` の生成した C は `onsa_arr_i32_0` が `int32_t a[1]`、値が `((onsa_arr_i32_0){ { 0 } })` で、`clang -std=c11 -Wall -Wextra -Werror -Wc23-extensions` が警告なしに通る（親が確かめた）。`Z: Default { a: [I32; 0] }`、`[(1, 2); 0]`、`[None; 0]`、長さ 0 の `from_fn` も部 2 の担当が clang と gcc-15 の `-pedantic -Werror` で確かめた。DONE にした。
