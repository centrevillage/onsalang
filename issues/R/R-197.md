# R-197 別のモジュールから取り込んだ総称の struct の型引数の数を誤る

- 中・直す・観点 1｜名前｜§4.5、§15.1
- 内容: `shapes.onsa` の `pub struct Pair[T] { first: T, second: T }` を `main.onsa` で `use shapes.{Pair}` と取り込み、`fn g(p: Pair[I32])` と書くと、E0302「`Pair` takes 0 type argument(s), 1 given」になる。同じモジュールの総称の struct は通る。取り込んだ型の型パラメータの数を、定義でなく取り込みの記録から読んでいると見える。
- 経緯: W3-21/t が見つけた（2026-10-09、別モジュールの struct への `..` の候補の事例を書く途中）。
- 決定（2026-10-09、親）: 直す。`use` の解決を作り直す W4-03 で行う。
- 判断: 直す（親、仕様が明確）。別のモジュールから取り込んだ総称の struct（`use shapes.{Pair}` の `Pair[I32]`）の型引数の数を、定義の型パラメータから数える（今は E0302「takes 0 type argument(s)」）。W3-21/t で見つけた
- 反映: 実装は W4-03
