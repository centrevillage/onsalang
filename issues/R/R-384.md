# R-384 境界の並びの E0020 の候補が、`:` や `?` と名前の間のコメントで崩れる

- 場所: `crates/onsa_sema/src/sig/bound_list.rs` の `element_span`、`sig/derives.rs` の `drop_element`。
- 内容: `pub fn f[T: Dup + ? // c` 改行 `Escape](x: T)` の候補が `?` とコメントごと消し、`?Escape` が `Escape` に変わる（AST の `Bound` に `?` の位置が無い）。`[T: // c` 改行 `Dup]` の候補は `Dup` だけを消して構文の誤りを残す。どちらも `--fix-loop` は止まる。
- 経緯: 119 回目（2026-11-06）、W5-17 U1/b（onsa-break）が見つけた。
- 判断: 直す。実害は低い（`:`・`?` の直後にコメントを書く形はまず無い）。字句の候補の残りと一緒に W5-11 で見る。
