# R-461 破棄の要らない束縛（静的な値と数の組 `let p = ("g", v)`）を早い出口の前に待たせると、その破棄を E0601 に数える

- 場所: `crates/onsa_sema/src/modes/flow.rs` の `Walker::owned`（Shared の種の場所を、`lits` に無ければ所有と数える見込み。レビューの見当で、確かめていない）。
- 内容: `pub rt fn x(v: F32, r: Result[U32, U32]) -> Result[((Str, F32), U32), U32] { let p = ("g", v)` の後の `Ok((p, r?))` は、E0601「`p` is dropped by an exit before it is used」になる。`p` は破棄の要らないリテラルの束縛で、§5.4 は「静的な値と同じく、複製も破棄も何もしない」、§12.2 はその破棄を「要らない」とするので、誤検出である（通るはずのプログラムが誤りになる）。要素が静的な値だけの `Ok(("a", r?))` と、`let k = r?` と分けた `Ok((p, k))` は誤りなし。
  再現: `target/notes/152/s1045adv/nodrop.onsa`（`x` が E0601、`y`・`z` は誤りなし）、レビューの `target/notes/152/s1045adv/advisor/cases4.txt` の `h_nodrop_wait_exit`・`h_static_wait_exit`。
- 経緯: 152 回目、2026-11-15、S-1045 の独立のレビューの段 1（onsa-advisor、報告 `target/notes/152/s1045adv/report.md` の 5 節の (a)）が見つけ、親が `onsa-u7b`（dev `4a8f58b0` のコード）で再現した。W6-04 の破棄の点の見直しで直す。
- 判断:
- 補い（2026-11-15、親）: 153 回目、W6-04 の前の洗い出しの領域 O（onsa-advisor、報告 `target/notes/153/w604_survey/O_report.md` の O1）が場所を確かめた。`modes/flow.rs` の `Walker::owned` は `lits.get(&x)` を式そのものの鍵で引くだけで、束縛の段が決める「場所の根が破棄の要らない束縛か、経路を下って静的な値・破棄の要らないリテラルに届くか」（`binding/mod.rs::borrowed`、`binding/literal.rs::no_drop_path`）を見ない。
  範囲は題より広い: 静的な値だけの束縛（`let s = "g"` の後の `Ok((s, r?))`）、経路（`Ok((p.0, r?))`）、束縛を経ない式（`Ok((("g", v).0, r?))`、`Ok((["a", "bc"][i], r?))`）、`move` の引数（`Ok(eat(p, r?))`）も同じ E0601 になる（親が固定のバイナリ `onsa-e0b47f0` で再現。入力 `target/notes/153/w604_survey/O/r461.onsa`・`r461b.onsa`）。借用の引数の `Str` の複製（`b(s: Str, …)` の `Ok((s, r?))`）は Shared の値の複製なので正しい E0601 で、この R ではない。
  S-1045 (1) の `Repeat` の腕も同じ `owned` を読むので、この R を先に直す（直さずに足すと `[p; 0]` の `p` を誤って数える）。
- 反映（2026-11-16、親）: W6-04 U2（`eed963f9`）で直した。束縛の段に「式の値が破棄不要か」の判定 `binding::no_drop` を一つ置き、`borrowed`・リテラルの束縛と modes の `owned` が読む。経路・静的な値だけの束縛・束縛を経ない式・`move` の引数も同じ。事例 `tests/spec/negative/drop_nodrop_wait_*.onsa`、模型 `crates/onsa_cli/tests/cli/repeat_zero_model.rs`。置く位置によらない拡張は S-1065（U13 `db1eb234`）。
