# R-292 補間の値が `Show` を満たすかを確かめない（§2.4 の E0416）。struct の値・関数値・列挙子の構築子を穴に書いても通る

- 場所: 型付けの補間の穴（`crates/onsa_sema/src/body/named.rs` の `check_hole`）。穴の値の型を作るが、`Show` を満たすかは見ない。
- 内容: §2.4 は補間される値が `Show` を実装していなければならない（E0416）とするが、`"{p}"`（struct `P` の値）・`"{KP}"`（struct の定数）・`"{g}"`（関数値）・`"{Shape.Circle}"`（列挙子の構築子）が `onsa check` を通る。
  この版では利用者の型は `Show` を実装できない（`impl Tr for P` の形は E0200、`Show` の derive は E0200）ので、組込みの型（§6.3 の表）と `Show` の境界のある型パラメータの他は E0416 になるはずである。
  ローカルの穴は前から確かめていない。W4-04 U4 で頭が定数・関数・構築子の穴が解決されるようになり、通る形が広がった。この版では `Str` の降下が E0200 なので、誤った値が生成されることは無い。
  再現は横のディレクトリの `show.onsa`（U4 の後は診断なし。前の dev `42e2f5c` はローカルの穴だけが通り、他は偽の E0302）。
- 経緯: 77 回目（2026-10-27）、W4-04 U4/b（onsa-break）の指摘 1。W4-04 の設計メモ 2.5 が U4 で `Show` の E0416 を足さないとし、担う作業が無かった。
- 判断: 直す。宣言の `: trait` の意味と前提の検査、derive を扱う W5-06 で、穴の値の型が `Show` を満たすかを確かめる（§6.3 の組込みの表、境界、derive）。
