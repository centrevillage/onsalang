# R-239 前置の - を被演算子に持つ as の E0411 の候補が、意味を変える

- 場所: `crates/onsa_sema/src/body/expressions.rs` の E0411 の候補（` as T` を変換のメソッドに置き換える）。
- 内容: `-a as I32` の候補は ` as I32` を `.narrow_i32()` に置き換え、`-a.narrow_i32()` になる。`-a` を狭めるのではなく、`a` を狭めてから符号を反転するので、意味が変わる（X-3 の X3-1e の e3 で約束に残した意味の性質）。
  `(a + b) as I32` は括弧が残るので正しい。当てた後に E0401 も出るので、安全の器（L1）には別の理由で当たる。再現は `R-239/e0411.onsa` の `neg`。前からある（dev と全文が同じ）。
- 経緯: X-3/U1 の壊す側が見つけた（2026-10-17）。
- 判断（2026-10-17、親）: 直す。被演算子が前置の式なら括弧で囲む形にする。直す作業は、X-8 で W4 の範囲を決めるときに、E0411 の既にある `fix-contract` の 2 項目と一緒に決める。
- 判断（2026-10-23、親、X-8）: W5-02 で直す。W5-02 が整数の縮小の候補を §3.3 に合わせて出さなくすると、この形は消える。残る E0411 の候補で被演算子が前置の式なら括弧で囲む。
