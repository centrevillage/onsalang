# R-176 `?Dup` の型パラメータを含む利用者の型が `Dup` の要求を通る

- 中・直す・観点 1｜型（種の制約）｜§4.5、§4.6
- 内容: `pub struct Wrap[T: ?Dup] { x: T }` の `Wrap[U]`（`U: ?Dup`）は `U` が Affine でありうるので Dup でないが、`need_dup(w)` や `[w; 2]` が通る。種を求める処理が型パラメータを含む利用者の型で種を返さず、要求の検査がそれを「満たす」と扱う。HEAD の modes の E0711 も同じ穴を持っていた。再帰する型も同じく通る。
- 経緯: W2-06/b が見つけた（2026-10-08）。
- 決定（2026-10-08、親）: 直す。型パラメータを含む型の種を、各引数の境界（`?Dup` かどうか）から求める。種の制約を扱う W5-08 で、R-172 と同じ回に行う。それまでの事例は実装待ちの一覧に載せる。
- 判断: 直す（親、仕様が明確）。`?Dup` の型パラメータを含む利用者の型の種を、引数の境界から求める。W2-06/b で見つけた
- 反映: 実装は W5-08
