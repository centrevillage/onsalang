# R-201 fmt が括弧の中の要素の中の改行を除くとき、行末のコメントを遠くへ移す

- 低・直す・観点 1｜fmt｜§2.5、`spec/tools.md` §3.2（コメントの置き場所、S-58）
- 内容: `match n {` の腕の `0 => // c` 改行 `1,` を `onsa fmt` が `0 => 1,` にし、コメントを `match` の閉じ括弧の後ろ（`} // c`）へ移す。`S { f: // c` 改行 `a, g: 1 }` も `S { f: a, g: 1 } // c`。コメントは書かれた行に残す（S-58）。
  R-199（継続の前の行のコメント）と同じ種類で、括弧の中の要素の中の改行の場合。`spec/tools.md` §3.2 は「書き手の改行は保つ」とするが、要素の中の改行（`f:` の後、`=>` の後）を保つかを書かない。
- 経緯: 第 16 組の下書きが見つけ、親が W3-20 の後の dev のバイナリで確かめた（2026-10-09）。
- 決定（2026-10-09、親）: 直す。fmt を CST に移す W3-11 で R-199 と同じ回に行う。要素の中の改行を保つかは、そのときに `spec/tools.md` に書く。
- 判断: 直す（親）。fmt が括弧の中の要素の中の改行を除くとき、行末のコメントを遠くへ移す（腕の `0 => // c` 改行 `1,` が `} // c`）。コメントは書かれた行に残す（S-58）。第 16 組の下書きで見つけた
- 反映: 実装は W3-11
