# R-293 `onsa test` で、`Str` を型引数に含む `Option`・`Result`（`Option[Str]`、`Result[I32, Str]`）の値への `match` が、Shared の型の E0200 でなく内部エラー「constructor pattern on a non-enum」（終了コード 101）になる

- 場所: Core への降下のパターン（`crates/onsa_core/src/lower/body/pat.rs` の構築子のパターン。対象の型を `Ty::Enum` と決めてかかる）。型の降下（`lower/mod.rs::core_ty`）は `Str` を `Feature::SharedTypes` の E0200 にするが、パターンの降下がその前に別の型を受ける。
- 内容: `Result[I32, Str]` か `Option[Str]` の値に `match` で `Ok(v)`・`Err(_)`・`Some(_)`・`None` を当てる関数を `test` から呼ぶと、`onsa test` が内部エラー「internal lowering error: constructor pattern on a non-enum」で止まる（終了コード 101）。`onsa check` は通る。
  §18.1 は、この版で扱えない形（Shared の型の `Str`）を E0200 にし、内部エラーにしないとする。`Result[I32, I32]` は通る。再現は横のディレクトリの `result_str.onsa`・`option_str.onsa`（dev `e741747` と `42e2f5c`）。
- 経緯: 77 回目（2026-10-27）、W4-04 U5/t（onsa-test）が正例の事例を走らせるときに範囲の外で見つけ、親が再現した。前からの形。
- 判断: 直す（内部エラーは残さない）。値の `match` の降下の一般経路を扱う W8-06 で、構築子のパターンの対象の型の降下の誤り（E0200）を先に返す。
- 補い（2026-10-28、親）: 79 回目（W4-05 U1/b の壊す側）: `onsa test` だけでなく `onsa interface` と `onsa dump --core` も同じ内部エラーになる（`tests/spec/module/prelude_variants_bare.onsa` の 41 行、`Option[Str]` の `Some(_)`・`None`）。前からある。
- 経緯（2026-10-30、親）: 85 回目（W4-16 U2/b）: U2 で静的な値の `Option[Str]`（`let o = Some("a")`）を `match` する形も rt の関数と `uses {Alloc}` の無い関数で check を通るようになり、同じ内部エラーが `onsa test`・`dump --core` で出る（借用の引数の `match op` は前から check を通る）。
