# R-134 `main` の効果行を、ターゲットの `provides` と照合しない

- 中・直す・観点 1｜`crates/onsa_driver/src/build.rs`（`check_exports`）｜§8.5、§15.3
- 内容: 仕様 §15.3 は「`main` または export される関数の効果行に、`provides` に無い効果が含まれていれば E0610」とする。今の実装は export される関数だけを照合し、`main` は照合しない。`provides = []` のターゲットで `pub fn main() uses {Alloc} {}` がビルドの段を通る。
- 経緯: W1-10 のテストの票が仕様から書いた否定例で見つけた（2026-10-07）。再現は `tests/spec/negative/build_provides_main.onsa`（実装待ち）。
- 決定（2026-10-07、親）: 直す。仕様は明確で、判断は要らない。効果の段の W6-03 で、`main` と export される関数を同じ規則で照合する。
- 判断: 直す（親、仕様が明確）。`main` の効果行も export と同じく `provides` と照合し、無ければ E0610（仕様 §15.3）。W1-10 で見つけた。再現は `tests/spec/negative/build_provides_main.onsa`
- 反映: 実装は W6-03
