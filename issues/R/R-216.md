# R-216 `@param` の値の検査が無い

- 中・直す・観点 1｜sema と flow（`@param` の値の検査、`flow.rs` の整数の入力の値）｜§11.7（値は入力の値型の値で、型の合わない値は E0401。値の制約の違反は E0809）
- 内容: `@param` の値の型と制約を検査しない。整数の入力に浮動小数の値（`min: 2.5`）、`F32` の入力に整数の値（`min: 0`）、`min < max` の違反が通る。
  逆に、§11.7 が書けるとする `const` の名前の値（`min: LO`）は「must be a numeric literal」の E0809 で拒まれる。
  親が dev の `f4b9a8b` で再現した（2026-10-13）。
  整数の入力の巨大な浮動小数の値は、`flow.rs` の `v as i128` で黙って飽和する。
- 経緯: W3-05/b の単位 1 が範囲の外として報告した（2026-10-13）。W3-05 の前からある。
- 決定（2026-10-13、親）: 直す。時期は W7 か W10 の `@param` の作業を見て決める。
- 判断: 直す（親）。`@param` の値の型と制約を検査せず、`const` の名前の値を拒む（§11.7）。整数の入力の巨大な浮動小数の値が飽和する。W3-05/b の単位 1 が見つけた。前からある
- 反映: 実装は W7 か W10 の `@param` の作業を見て決める
