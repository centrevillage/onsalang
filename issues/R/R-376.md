# R-376 `array.from_fn` に `target` の宣言の関連関数を渡すと降下の後に内部エラーになる
- 場所: `crates/onsa_core/src/lower/body/call.rs` の `lower_from_fn`。§3.3、§6.1
- 内容: `array.from_fn(F32.round_from)` のように `target` の宣言の関連関数を渡すと、`lower_from_fn` が本体の無い宣言に `fn_id` を使い、`onsa test` が exit 101「a call of `…round_from__U32`, which has no body」で落ちる。通るはずのプログラムである。W5-05 U3 で `T.round_from` も同じ所に届くようになった。
- 経緯: 117 回目（2026-11-05）、W5-05 U3 の実装の担当（onsa-impl）が見つけた（`1ee7270f` のバイナリでも同じ）。
- 判断: 直す。内部エラーで、U3 が届かせる形なので U3 の中で直す。
- 反映: 親が `row_prim` を分け、`lower_from_fn` が `target` の宣言を `Prim` で呼ぶ形にした。事例 `tests/spec/num_traits/tp_conv_value_form_from_fn.onsa`。
