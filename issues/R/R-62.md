# R-62 括弧・角括弧・`match` の腕の中では E0003 を検査しない

- 低・直す・観点 1｜`crates/onsa_syntax/src/parser.rs:1669-1690`｜§2.5
- 再現: `id(if c { 1 }\n     else { 2 })` が通る。
- 範囲（2026-10-04 に追加で確かめた）: `match` の腕の中の同じ形と、S-47 の `{` の位置（括弧の中の `if c` の次の行の `{`、クロージャ `fn(i)` の次の行の `{`）も検査されない。`onsa fmt` は `else` を前の行へ移す。

- 反映: 仕様 §2.5 に反映済み（2026-10-04）。実装は W3-06
