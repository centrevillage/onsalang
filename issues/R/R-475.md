# R-475 `inout` の `Span`・`Out` を `if` で選んで `match` の見出しや `for` の反復元に置く形が、借用束縛の E0710 を通る（`match if c { xs } else { ys } { k => … }`）

- 場所: modes の `view_of_inout`（見出しの値の場所を見て、`if`・`match`・ブロックの末尾の行の派生元を見ない）。
- 内容: §5.4（S-217）は `inout` の引数からの `Span` を束縛できない（E0710）とする。`inout xs`・`inout ys` の `match if c { xs } else { ys } { k => k.len() }` と `for ch in if c { xs } else { ys }` が通る（`match (xs)` は E0710）。生成型の `Out` の同じ形も通る。後の書き込みは E0701、変更後の使用は E0704 で止まるので、記憶域の害は無い。再現は `target/notes/159/g106/advisor2/sp3.txt`（`sp_match_inout_if`・`sp_for_inout_if`・`out_match_inout_if`。親が `onsa-9bb710c` で再現した）。
- 経緯: 159 回目（2026-11-16）、S-218 の案 (b) の想定漏れの確かめ（onsa-advisor）が見つけた。前から。
- 判断: 直す（中）。W7-12 U2 で modes の第二級の述語に生成型を入れるときに、`view_of_inout` が行の派生元（`head_places`）を見る形にする（約 +5）。`Span` にも当たる。
