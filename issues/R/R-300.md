# R-300 std の効果の後の `.` を呼ぶ形（`Alloc.x()`）が、型付けの E0401「`Alloc` is not a value」になる（値として書いた `Alloc.y` は名前の段の E0302「has no members」）

- 場所: 名前の段の歩き手の呼び出しの頭（`names/body/paths.rs` の `Place::Callee`）が効果の名前の後の `.` を名前の段で扱わず、型付けの callee の枝に回る（推測。W4-04 U8a/i の報告）。
- 内容: §15.1 は効果を名前空間とし、名前空間に無いメンバは E0302 とする。`Alloc.y`（値）は名前の段の E0302「`Alloc` has no members」だが、`Alloc.x()`（呼び出し）は型付けの E0401「`Alloc` is not a value」になり、コードと文面が名前の段の規則に合わない。
  前からある（`P78/bin/onsa-u7b2`、dev `727ad03` のコードでも同じ）。誤りのあるプログラムが通ることは無いので重大度は低。再現は `issues/R/R-300/alloc_dot.onsa`。
- 経緯: 78 回目（2026-10-28）、W4-04 U8a/i（onsa-impl）が範囲の外として報告し、親が前と後のバイナリで再現した。関係: S-713、R-84。
- 判断: 直す（低）。名前空間の後の見つからないメンバの E0302 に揃える。W4-04 の U8b（効果行と効果の名前を扱う単位）で直す。
