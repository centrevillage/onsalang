# R-436 定数式の中の無名関数とブロックの型の場所と型引数を、別名の循環と順のグラフが辿らず、内部エラー（`type A = [F32; (fn() { Rg::[A, 4].CAP })]`）と宣言の順で変わる診断が出る

- 場所: `crates/onsa_sema/src/sig/decls.rs` の `Graph::expr`（別名と定数の循環と順のグラフ。定数式の葉の鎖だけを `constarg::operands` で辿る）と、`crates/onsa_sema/src/names/body/consts.rs::const_names`（定数式の中の無名関数の型引数の並びも下ろす）の食い違い。内部エラーは `crates/onsa_sema/src/sig.rs` の 407 行の辺り（`internal error: an alias read as it is lowered: a cycle not in the order`）。
- 内容: (a) `type A = [F32; (fn() { Rg::[A, 4].CAP })]`（`Rg[T, const N: U32]` に関連定数 `CAP`）で `onsa check` が内部エラー（終了コード 101）。閉包の外の `type A = [F32; Rg::[A, 4].CAP]` は E0311。(b) `type A = (F32, F32)` と `type B = [F32; (fn() { A.N })]` は、この順なら E0302、逆の順なら E0417 で、§4.5 の「書いた順によらずに引く」に反する（fn の署名と本体は順によらず E0302）。どちらもグラフが定数式でない形（無名関数・ブロック）の中の型の場所と型引数の並びと値の鎖を辿らないためと読む。再現は `target/notes/140/b3-advisor/advisor/in/q3c.txt`・`last2.txt`（`P/bin/onsa-a732713`、親が再現した）。
- 経緯: 140 回目（2026-11-12）、S-908・S-912・S-989 の独立のレビューの段 1（onsa-advisor）が、S-989 の想定漏れを調べて見つけた。関係: S-989、R-426。
- 判断: 中（内部エラー）。S-989 の決定で定数式の中の型の場所を名前の段で読む形にするなら、`Graph::expr` を葉の中の型の場所・型引数の並び・値の鎖まで辿るように広げる直しで (a)(b) が消える見込み（advisor の見当 20〜35 行）。W5-13 で S-989 と R-426 と同じ単位にする。見当を大きく超えるか形ごとの手当てが続くなら、定数式でない形の中を読まない案（S-989 の advisor の案 (3)）に戻して比べる。
