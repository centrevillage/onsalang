# R-450 総称の関数を関数型で具体化して値に置くと、捕捉する無名関数が第一級の値として関数の外へ出る（`let r = keep_t::[fn(U32) -> U32]` の後の `r.(fn(x: U32) -> U32 { x + k })` を返す形が通る）

- 場所: 型の段の、総称の関数を値に置く所と関数値の呼び出し（`crates/onsa_sema/src/body/`）。S-809 の E0710 は、渡す先の宣言の型の頭を呼び出しの所で見る。
- 内容: 再現は横の `escape.onsa`（dev `ea8d73f6` の `onsa check` で誤りなし）。`pub fn keep_t[T](x: T) -> T { x }` を関数型で具体化して値に置き（`let r = keep_t::[fn(U32) -> U32]`、注釈の `let r: fn(fn(U32) -> U32) -> fn(U32) -> U32 = keep_t`、高階関数への `run(keep_t, k)`）、捕捉する無名関数 `fn(x: U32) -> U32 { x + k }` を渡すと、それが返り値として第一級の値で関数の外へ出る。
  S-809 は、第二級の関数値を渡せるのは宣言の型の頭が関数型の既定のモードの引数だけとし、型パラメータの引数へ渡すと E0710 とする（直接の `keep_t(fn(x: U32) -> U32 { x + k })` と `Some::[fn(U32) -> U32]` の値を通す形は E0710）。関数値を通すと、呼ぶ所に見えるのは具体化した型 `fn(fn(U32) -> U32) -> fn(U32) -> U32` だけで、宣言の頭が `T` だったことが消える。
  関数値の降下は今 E0200（W8-09）なので、まだ実行まで届かない。降下が入ると、捕捉した環境が呼び出しの後に残る誤り（解放した領域の参照）になる。
- 経緯: 144 回目（2026-11-13）、第 96 組（S-874）の独立のレビューの段 1（onsa-advisor）が見つけ、親が固定のバイナリ `onsa-ea8d73f` で再現した。塞ぎ方（具体化した値の型、E0710 を出す位置、今通る `ap(hof, inc)` の扱い）は S-1029 で決める。関係: S-809、S-862、S-874
