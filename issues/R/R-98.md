# R-98 名前の無いノードの番号とフィールドの順が後順

- 低・仕様へ・観点 3｜`crates/onsa_sema/src/flow.rs:1250-1350`｜S-06
- 再現: `let a = prev(lp~(x), 0.0) + prev(x, 1.0); let b = lp~(prev(a, 0.0))` の State は `{lp_0, prev_0, prev_1, prev_2, b, ...}` になる。
- 影響: 番号と順は、プローブとホットリロードが依存する。
- 推奨: S-06 に「式の後順で番号を振る」と書く。
- 範囲（2026-10-05 に追加で確かめた）:
  - 番号は種類（組込みの遅延の名前と、修飾を除いた flow の名前）ごとに flow 全体の通し番号で、`par` の本体の中も同じ列を使う。修飾の違う同名の flow（`fa.lp~`、`fb.lp~`）は列を共有する。分解する `let` の flow の呼び出しは名前の無いノードになる。`onsa graph` と `onsa interface` の名前は一致している。
  - 仕様は「番号で呼ぶ」とだけ書き、順も範囲も無い。§12.4 の配置にも名前の無いノードの位置が無い。
  - §18.3 のホットリロードは名前と型で照合するので、先頭の `let` に `prev~` を足すと後ろの全ての `prev_k` がずれ、型の同じ別のノードの状態を引き継ぐ。
  - 他の環境（利用者の問いを受けて調べた）: 名前で照合するのは人が名前を付けたフィールドの保存（Unity）。木の中の位置と型とキー（React、Flutter の `Widget.canUpdate`）。構造の同値とキー（Elementary）。差分（Glicol の LCS）。引き継がずにクロスフェード（FaustLive、SuperCollider の JITLib）。音のデータフローで名前で照合する例は見当たらない。
  - 再現は `tests/review-phase1/parent/r98.onsa`（今の実装の構文。期待値と今の出力は先頭のコメント）。
- 決定（2026-10-05）: 名前で状態を照合する前提を改めた（S-86）。
  - (1) 利用者の指摘: 各フィールドには呼び出しの依存の木があり、識別子はそれを表せない。ホットリロードは、コンパイラが出す flow の計画（状態の各フィールドの構造上の位置、種類、型、オフセット）を旧新で照合し、型が同じノードの間でだけ状態を引き継ぐ。サブインスタンスは中まで照合する。プローブの付け替えも同じ。
    照合の方法（`let` の名前を鍵とした木の中の位置、差分、照合できない部分のクロスフェード）は `spec/tools.md` §2（S-66）。構造の同値でノードを見分ける方式は、上流の定数の変更で下流の状態を全て失うので採らない。ホットリロードは M7（T7-5）で未着手なので、作り直しは無い。
  - (2) 生成する名前は表示用になる（`onsa interface`、生成コード、デバッガ、プローブの宛先）。利用者の判断「表示用なので直感的な方」により、含む `let` の名前で修飾し（`a.prev_0`）、`let` ごと・種類ごとに字面の順で番号を振る。出力の式の中は修飾なし、分解する `let` は最初に束縛する名前、`par` の本体は `par` の名前で修飾（`saws.saw_0`、`m.par_0.acc_0`）、巻き上げは `a.hoist_0`。
  - (3) 配置（§12.4）: 各 `let` の位置に自身のフィールドと式の中のノード（字面の順）、次に出力の式の中のノード、次に巻き上げの値（`let` の順）。
  - (4) 計画（R-91）に各ノードの構造上の位置を加え、LSP の拡張と `onsa interface` に出す。`onsa graph` のノード名も同じ名前（`parent/r76.onsa` の期待値を直した）。
- 判断: 名前で状態を照合する前提を改めた（S-86）。ホットリロードとプローブの付け替えは、コンパイラが出す flow の計画（構造上の位置、種類、型、オフセット）を旧新で照合し、型が同じノードの間でだけ状態を引き継ぐ（方法は `spec/tools.md` §2）。
  生成する名前は表示用で、含む `let` で修飾し、`let` ごと・種類ごとに字面の順（`a.prev_0`、出力の中は `lp_0`、`par` の本体は `saws.saw_0`）。配置は `let` の位置に式の中のノード、次に出力の中、次に巻き上げ。元の推奨（後順を書く）を、利用者の指摘で改めた。再現は `tests/review-phase1/parent/r98.onsa`
