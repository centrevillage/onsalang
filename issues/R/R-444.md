# R-444 `a` 改行 `- /* c */ b` の E0020 の候補 `write a line comment` が、ブロックコメントを外して `- b` にし、`-` の後の空白の E0020 を残す（§18.1、S-247）

- 場所: `crates/onsa_syntax/src/foreign/` のブロックコメントを行コメントにする候補（題 `write a line comment`）。
- 内容: `a` 改行 `- /* c */ b` の E0020 の候補 `write a line comment` は、§2.1・S-247 の「空白を一つ残してトークンを離す」規則でブロックコメントを外して `- b` にするので、`-` の後の空白の E0020（§2.5）が残る（`onsa_cases --fix-contract` の違反）。前からの形。再現は `issues/R/R-444/cm_cmt_in_neg.onsa`。
- 経緯: 142 回目（2026-11-12）、W5-13 U8b/b（onsa-break）が R-443 と一緒に挙げ、U7b の担当が別の原因と確かめた。
- 判断（2026-11-12、親）: W5-13 U7c で見る。候補を当てると誤りが残る形では候補を出さない（§18.1）のが S-247 の規則を変えない直し方。S-247 の規則に触れる直し方しか無ければ報告させる。
