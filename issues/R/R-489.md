# R-489 E0809（`@export` の flow の `block` の入力に `@param` が無い）が、値型の E0810（Copy でない）より先に出て、`@param` を足すと E0810 に変わる

- 場所: flow の検査の段の `@export` の入力の検査（`crates/onsa_sema/src/sig/generated.rs` の `check_generated` の `@param` の必須）と、値型の Copy の E0810（`check_rate_value_type`）の順。
- 内容: `@export pub flow g(p: Str at block, x: F32 at sample) -> F32 at sample { x }` の `onsa check` は「the `block` input `p` of the exported flow `g` has no `@param`」（E0809、2:12）だけを出す。書き手が `@param(default: 0.0)` を足すと、次に E0810（`Str` は Copy でない）が出て、型を直すまで `@param` は使えない（一往復のむだ）。S-372 は関数型の入力でこの順を E0810 が先と決めた（細部 5）。再現は `target/notes/163/s372reg/order.onsa`、段 1 の `target/notes/163/g109/advisor/probe/` の `a20`・`q05`。
- 経緯: 163 回目（2026-11-17）、S-372 の段 1（onsa-advisor）が R の候補に挙げ、親が dev のバイナリで再現した。
- 判断: 直す（低）。値型の E0810 がある入力には、その入力の `@param` の必須の E0809 を出さない（S-372 の細部と同じ形、S-1123）。W7-13 U3 で入れる。
