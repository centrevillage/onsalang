# R-486 腕で宣言して変更した Copy の束縛を、引数の位置で開いたリテラルの要素に置くと E0702 になる（`take_in(if c { var t … t[0] = 2.0 … pair.In { l: t, r: y } } else { … })`）

- 場所: modes の引数の中の変更（`crates/onsa_sema/src/modes/exclusive.rs::changed_in_args` の `holds`）。
- 内容: 腕・ブロックの中で宣言して変更した Copy の束縛を、引数の位置で開いたリテラル（生成型の struct リテラルのフィールド、平面の配列リテラルの要素）の要素に置くと、E0702「`t[0]` is changed in another argument while `t` is passed borrowed in the same call」になる。
  §5.2「引数の中のブロックで宣言した変数への代入は、どの引数とも重ならない」に反する（`t` は同じ引数の `if` の腕で宣言した）。
  `holds` が変更を開いた要素（`Passed::arg`）の範囲で見るので、要素の外で同じ引数の中の変更が「他の引数の中」になる。W7-12 U2c1a（`8449d850`）が要素を新しい `arg` にしてからの後退（U2c1a の前の `2da3b3f` は通る）。
  対照の素の `Span` の末尾、変更の無い形、直に書いたフィールドのブロック、平面の要素のブロックは通る。U2c2 で末尾の平面の配列リテラルを開くと、同じ形がそこにも広がる。
  再現は `target/notes/162/w712/u2c2/memo/in/p4.txt` の `gen_lit_changed_local`（対照は同じファイル）。
  同じ根の後退がほかに二形ある（どれも `2da3b3f` は通る）: 外の `var x` を腕の文で変更してから要素に置く形（`take_in(if c { x[0] = 1.0 … pair.In { l: x, r: y } } else { … })`）と、別の腕の文で変更する形。素の `Span` の同じ形は今も通る。
  再現は `target/notes/162/w712/u2c2/review/in/r1.txt` の `gen_spine_outer_changed`・`gen_other_arm_changed`（対照は `span_*`、E0702 のままの形は `planar_other_elem_changed`・`direct_gen_other_field_block_changed`・`gen_arm_local_changed_in_other_elem`）。
- 経緯: 162 回目（2026-11-17）、W7-12 U2c2 の設計メモ（onsa-impl）が範囲の外で見つけた。親が固定のバイナリと `2da3b3f` で再現した。
- 判断: 直す（中、正しいプログラムを誤りにする後退）。W7-12 の小さな単位 U2c1c（U2c2 の型の段の前）で、`holds` を「変更が、その場所の単位（`sources.rs` の `arg`）の中にあるか、外の引数の中でどの開いた要素の中にも無い」にする（U2c2 の設計メモの審査の推奨）。
  「根が外の引数の中で宣言した局所変数なら比べない」は外の変数の二形を直さず、要素をまたぐ変更（`gen_arm_local_changed_in_other_elem`）を通す。「`holds` を外の引数の範囲で見る」は要素ごとの重なり（`planar_other_elem_changed`、S-196）を壊す。どちらも採らない。
