# R-59 FAUST の `+ ~ _` に E0020 の修正候補が無い

- 中・直す・観点 1｜`crates/onsa_syntax/src/parser.rs:1368-1374`、`:1621`｜§18.1、T1-8
- 再現: `x + ~ _` は修正候補の無い E0002 になる。否定例のテストも E0002 を期待値にしている。
- 直し方:
  - `<二項演算子> ~ _` の形を E0020 にし、`prev` を使う書き方を示す。
  - flow の本体の代入（E0806）には、`let` への置換を修正候補に入れる。
- 決定（2026-10-04）: 直す。修正候補は S-44 の後の書き方（`prev~(^y)`）にする。E0020 は修正候補を作れるときだけで、一意でなければ全て並べ、作れなければ E0002（note で書き方を示す）。`~` は形で決める（被演算子が `_` なら FAUST の帰還、それ以外は C 系のビット反転 `!x`）。FAUST の `x'` と `x@N` も E0020 にする。E0806 の `let` の候補は未定義のときだけ。S-48。
- 判断: 直す。S-48: E0020 は修正候補を作れるときだけで、一意でなければ全て並べ、作れなければ E0002 と note。`~ _` は `prev~(^y)`、前置の `~x` は `!x`、`x'` は `prev~(x)`（S-466 で外した）、`x@N` は `prev~` / `delay~`。FAUST の合成の演算子は E0002。E0806 の `let` の候補は未定義のときだけ。`pub(crate)` の修正候補は S-36 に合わせて「外す」に改める
- 反映: 仕様 §2.6 / §18.1 に反映済み（2026-10-04）。FAUST の形は W3-23 で直した。E0806 の `let` の候補は W7-04（`tests/spec/fixes/e0806_assign.onsa` の実装待ち）
