# R-169 符号なしの整数に `std.math.abs` を呼べる

- 低・直す・観点 1｜型（境界）｜§6.3、§3.4
- 内容: `abs(200u8)` が検査を通り、値をそのまま返す（インタプリタも C も）。`std.math.abs` は `T: Num` を要求し（`std/math.onsa`）、§6.3 は符号なし整数が `Num` を満たさないと定めるので、境界を満たさない E0416 になるはず。
- 経緯: W2-05/b が見つけた（2026-10-08）。
- 決定（2026-10-08、親）: 直す。組込みの数の型に対する std の総称の関数の境界の検査（W5-05、`T: Int` などの境界の実装と同じ回）で行う。
- 判断: 直す（親、仕様が明確）。符号なしの整数への `std.math.abs`（`T: Num`）を E0416 にする。W2-05/b で見つけた
- 反映: 実装は W5-05
- 補い（2026-10-29、親）: 82 回目の W4-05 U4a/i2（onsa-impl）: 出所は `body/bounds.rs::satisfies` が `Ty::Int(_)` の全てに `Num` を与えること（§6.3 は符号なしの整数は `Num` を満たさないとする）。
  外すと `std/math.onsa` の `min`・`max`（`T: Num`。仕様では `AnyNum`）が `U32` で E0416 になり正しいプログラムを広く拒むので、U4a では直していない。数の trait の境界（W5-05）と並べて直す。
