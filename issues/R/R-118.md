# R-118 `match` の腕の中で、対象を書き換えられる

- 中・要判断・観点 1 / 3｜`crates/onsa_sema/src/modes.rs:489`｜§7「`match x` の束縛は借用束縛（§5.4）で、`x` は変わらない」
- 再現: `match x { Some(v) => { x = None; v.len() }, None => 0 }`（`x: Option[Buf[F32]]` は `var`）が通る。`x = None` で古い `Buf` が破棄され、借用束縛 `v` は破棄済みの記憶域を読む。
- 現状: 対象は `match` の位置で読まれるだけで、腕の中では普通の `var` のまま書き換えも `inout` への受け渡しもできる。腕の束縛が対象の中を指していることを、どの検査器も追っていない。借用の `for` の E0715 に当たる規則が `match` に無い。R-110 はガードの中の変更だけを扱う。
- 判断（R-118）:
  - (a) 対象を書き換えた後に、Copy でない借用束縛を使えない。束縛が無いか Copy なら、腕の中で対象を書き換えられる（エンベロープの段の遷移 `match self.stage { Stage.Attack => { self.stage = Stage.Decay } }` はそのまま書ける）。
  - (b) `match` の間は対象を変更できない（借用の `for` の E0715 と同じ）。段の遷移は `self.stage = match self.stage { ... }` と書き直す。
  - 推奨は (a)。R-110 と一緒に決める。
- 決定（2026-10-03）: (a)。変更した場所と重なる Copy でない束縛は、move と同じく以後使えない（E0704）。Copy の束縛は束縛した時点の値（S-42）。
- 経緯: R-54 の議論で見つけた（2026-10-03）。
- 判断: (a) 腕の本体では対象を変更できる。変更した場所と重なる Copy でない束縛は move と同じく以後使えない（E0704）。Copy の束縛は束縛した時点の値。対象を一時変数に取る案は Affine で効かないので採らない。腕の束縛も借用の起点にし（S-41 で保留していた）、派生した束縛も一緒に無効になる。S-42
- 反映: 仕様 §5.4 / §7 に反映済み（2026-10-03）。実装は W4-10
- 判断（2026-10-30、親）: W4-07 で直す。利用者が了承した（86 回目、W4-07 の設計メモの審査の A1）。腕の中で対象を変更すると、重なる Copy でない借用束縛と派生した束縛を以後 E0704 にする（新しい modes の §7 の無効化、U3）。ガードの中の変更の E0715（R-110）は W4-10 のまま。
