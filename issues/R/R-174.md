# R-174 ブロックコメントの候補が後ろのコードをコメントに入れる

- 中・直す・観点 1｜字句（E0020 の候補）｜§2.1、§18.1
- 内容: `let a = 1 /* one */ + 2` の候補は `/* one */` を `// one` に置き換え、`+ 2` がコメントに入る。当てると検査を通り、`a` が 3 から 1 になる。字句解析器は `*/` を行をまたいで探さないので、複数行のコメントは一行目だけが候補で変わり、E0002 が残る。
- 経緯: W3-15/t が見つけ、第 4 組（S-247）の下書きと Fable が再現した（2026-10-08）。
- 決定（2026-10-08、親）: 直す。S-247 の決定に従って候補を作り、`*/` を行をまたいで探す。W3-15 で行う。
- 判断: 直す（親、S-247）。ブロックコメントの候補が後ろのコードを巻き込まないようにし、`*/` を行をまたいで探す。W3-15/t で見つけた
- 反映: W3-15 で直した
