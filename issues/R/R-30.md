# R-30 種の分からない型を「Affine でない」とみなし、Affine の値を複製できる

- 高・直す・観点 1 / 2｜`crates/onsa_sema/src/kind.rs:58`、`layout.rs:65`（`subst`）、`modes.rs:615`、`rt.rs:286`、`body.rs:795`、`:831`｜§4.5、§4.6、§5.2｜再現（親）
- 原因: `kind_of` が `None` のとき、modes は「Affine でない」、境界の検査は「検査しない」として扱う。`None` になるのは、次の 2 つの場合である。
  - **`?Dup` の型パラメータ**: `fn dup2[T: ?Dup](move x: T) -> (T, T) { (move x, move x) }` に `Buf` を渡すと、`onsa test` まで通る。`fn dup3[T: ?Dup](x: T) -> T { x }` も通る。
  - **総称の型の実体化**: `layout::subst` は、置換後の型が intern 済みでなければ、置換前の型を返す近似になっている。
    - `struct Holder[T: ?Dup] { items: (T, U32) }` で、`Holder[Buf[F32]]` を 2 回 `move` できる。
    - 結果は、プログラムの別の場所で `(Buf[F32], U32)` が使われたかどうかで変わる。
- 直し方:
  - `subst` を、intern する版の一つにまとめる。
  - 種が分からないときは、保守的に Affine として扱う。`?Dup` のパラメータは Affine とする。
- 決定（2026-10-03）: 直す（`subst` を intern する版に一本化し、種が分からないときは Affine として扱う。`?Dup` のパラメータは Affine）。
- 判断: 直す（`subst` を intern する版に一本化し、種が分からないときは Affine として扱う。`?Dup` のパラメータは Affine）
- 反映: 実装（W4-07）
- 判断（2026-10-23、親、X-8）: `subst` の一本化は W4-05（型の表現と intern の形を変える作業）、種の分からない型を Affine にするのは W4-07。
