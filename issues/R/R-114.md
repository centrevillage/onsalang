# R-114 仕様の本文の例が、存在しない API を使っている

- 低・仕様へ・観点 3｜`spec/` §4.7、§5.3、§6.1｜P9
- 内容: 無名関数の説明の例が、延期した `Array.map`（§19.1）と、どこにも定義の無い `xs.for_each!` を使っていた。`map_err`（§4.4）は §9.1 で意図された `Result` のメソッドなので、そのままにした。
- 影響: P9（仕様の例は全て検査を通る）の検査は、コードブロックだけを見るので漏れていた。仕様はプライマーとして LLM に渡す前提なので、存在しない API を書かせることになる。
- 経緯: レビューの後、利用者との議論で見つけた（R-08 で、無名関数を使う場所を洗い出したとき）。

- 判断: 仕様の本文の例を、実在する API（`array.from_fn`）と無名関数の型の例に差し替える（きっかけは R-08 の議論）
