# R-259 事例の器が修正候補の無いことを約束できない: `fixes = 0` か書かない事例で、候補のある診断が咎められない

- 場所: テストの器（`crates/onsa_tests/src/fixes.rs` の `compare`、`onsa_cases --run`）｜§18.1（修正候補の数の約束）
- 内容: `fixes = N` の事例は、K = 1..N の候補があることと N を超える候補が無いことを確かめるが、`fixes = 0` と書いた事例も `fixes` を書かない事例も候補を見ない。
  候補のある診断（`"a"(x)` の E0020、候補 `.(`）を `fixes = 0` の事例に置いても通る（`issues/R/R-259/fixes_zero.onsa` を `tests/spec/fixes/` に置いた ROOT で `onsa_cases --run`、dev `3e14d7d`）。
  そのため、仕様が「候補なし」と決めた診断（S-591・S-606 の印と `::[` の E0002 など）を事例で約束できない。今は事例の説明と報告で示すだけ。
- 経緯: 59 回目（2026-10-24）、W4-17 U1 のテストの担当が見つけ、親が再現した。
- 判断:
- 判断（2026-10-25、親）: X-15（69 回目、利用者が了承）で、書いた `fixes = 0` は「候補を持つ診断が無い」を確かめるようになった。書かない事例は今のまま候補を数えない（候補が主題でない事例が多いため）。この R はそれで閉じる。
