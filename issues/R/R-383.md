# R-383 インタプリタが配列の引数を呼び出しごとに写すので、配列の `len()` と `get()` が 1 回 O(N) になる

- 場所: `crates/onsa_interp/src/calls.rs` の呼び出しの引数の束ね方。
- 内容: `len` を std の `rt fn len(self)` へ移したので、`onsa test` と `const` の評価で配列の `xs.len()` が 1 回ごとに配列を写す。
  N=100000 で 200000 回の `len` は 0.027 秒から 1.06 秒になった（`target/notes/119/` の壊す側の報告、再現は `t/p2.onsa`・`p3.onsa` の形）。`get` は前から同じ。生成した C は `const` のポインタ渡しで O(1) のまま。
- 経緯: 119 回目（2026-11-06）、W5-17 U1/b（onsa-break）が見つけた。
- 判断: 直す。借用の引数を写さない形か、`len` の呼び出しを降下で畳む形を W5-13 で見る。仕様は `len` の費用を約束していない。
- 判断（2026-11-12、利用者）: 送り先を W8-04 へ移した（140 回目、W5-13 の前の洗い出しの判断の 5）。場所は `onsa_interp/src/calls.rs` と `place.rs` の `ArgVal` の一か所だが、直しは値の表し方（借用の集約を写さない）に触り、移動・コピー・破棄を扱う W8-04 が作り直すため。
