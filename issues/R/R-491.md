# R-491 総称の struct（`Pair[F32, I32]`）を `sample` の出力にすると、フィールドがスカラでも境界の形の E0810 になる（§11.6 は「スカラ・`[スカラ; N]` をフィールドに持つ struct」を出力に認める）

- 場所: `crates/onsa_sema/src/sig/generated.rs` の `boundary_outputs`（境界の形の判定）。
- 内容: `pub struct Pair[A, B] { a: A, b: B }` と `pub flow g(a: F32 at sample, b: I32 at sample) -> Pair[F32, I32] at sample { Pair { a: a, b: b } }` の `onsa check` が「`sample` inputs and outputs are scalars, `[scalar; N]`, or structs of those; nested arrays cannot cross the boundary」の E0810（dev `a69d68b7`）。型引数を当てた後のフィールドは `F32`・`I32` で、§11.6 の出力の形に入る。総称でない同じ形の struct は通る。再現は横の `gen.onsa`。前からの挙動（W7-13 U3 の前も後も。U3 の後は文面が変わる）。
- 経緯: 163 回目（2026-11-17）、W7-13 U3 の実装の担当が範囲の外の気付きに挙げ、親が dev のバイナリで再現した。
- 判断: 直すか、この版の制限（E0200）にするかを、降下と C の境界（`Out` のフィールドの平面の型）が型引数を当てた struct を扱えるかを確かめてから決める。W7-13 を閉じる前に見る（直すなら小さな単位）。
