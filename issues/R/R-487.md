# R-487 `onsa interface` が `@param` の文字列のキーの値をエスケープせずに出す（`label: "a\"b"` が `label: "a"b"` と出る）

- 場所: `crates/onsa_driver/src/interface.rs` の `@param` の文字列のキー（`unit`・`label`・`id`）の表示。
- 内容: `label: "a\"b\\c\n"` を `onsa interface` が `label: "a"b\c` と改行で出す（エスケープしない）。読み直すと別の字になる。`Char` の表示が使う Rust の `escape_default` をそのまま文字列に当てると、`{`・`}` を `{{`・`}}` にせず（読み直すと補間の穴になる）、ASCII の外を全て `\u{…}` にする（日本語の `label` が読めなくなる）。Onsa の文字列リテラルに戻す関数は木に無い（`onsa_syntax/src/literal.rs` は読む側だけ）。JSON の出力は serde が処理するので当たらない。再現は `target/notes/163/w713/u4memo/` のメモの probe `more/str_escape`。
- 経緯: 163 回目（2026-11-17）、W7-13 U4 の設計メモ（onsa-impl）が範囲の外で見つけ、メモの独立の審査（onsa-advisor）が費用を見積もった（新しい関数 10〜15 行とテスト）。前から。
- 判断: 直す（低）。W7-13 U4b で `interface` の `@param` の行を書き直すときに、Onsa の文字列リテラルに戻す関数を一つ足す。U4b の行数に余裕が無ければ小さな単位に切る。
- 反映（2026-11-17、親）: W7-13 U4b（163 回目）で、`interface` の `@param` の文字列を `onsa_syntax::quote_str`（`\`・`"`・`{`・`}` と書けない字のエスケープ、`test_name::quote` と一つ）で出すようにした。事例は `crates/onsa_cli/tests/cli/interface_param_values.rs` の読み直しのテスト。
