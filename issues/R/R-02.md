# R-02 再帰する型と循環する `const` が検査を通り、後段でスタックが溢れる

- 高・直す + 仕様へ・観点 1 / 3｜`crates/onsa_sema/src/kind.rs:50`、`layout.rs:126`、`consteval.rs:73`、`crates/onsa_core/src/lower/mod.rs:432`｜§4.1、§12.1、§6.6｜再現（親）
- 再現:
  - `struct Node { v: I32, next: Node }` と `enum List { Cons(I32, List), Nil }` は `check` を通る。その後 `interface` と `dump --core` で stack overflow になる。
  - `const A: U32 = B` と `const B: U32 = A` も `check` を通る。`test` で stack overflow になる。
- 直し方: シグネチャの段で、型定義の閉路と `const` の依存の閉路を検出する。
- 仕様へ: どちらも誤りであると書き、診断コード（E03xx）を足す。
