# R-17 flow: 部分式に書いた非 rt 関数が `tick` から呼ばれる

- 高・直す・観点 1 / 3｜`crates/onsa_sema/src/flow.rs:1176-1211`、`crates/onsa_core/src/lower/flow.rs:758`｜§11.5 の表「効果行が空の非 rt fn … 引数のレートが Init 以下のときだけ呼べる。init で評価される」
- 原因: どの段で評価するかを、`let` 単位でしか選んでいない。
- 再現: `flow g(x: Sig[F32], level: Init[F32]) { x * make_gain(level) }` は検査を通る。tick に `make_gain(s.0)` が出る。
  - debug では、検証器が `rt function calls non-rt` で落ちる。
  - release では、rt の保証が破れる。
  - `par` の `i` を引数にした場合も同じ。
- 直し方: 部分式を巻き上げる（R-97 の判断による）。それができないなら、sema で E0805 にする。
- 決定（2026-10-02）: R-97 の (b)（部分式の単位の巻き上げ）で直す。rt でない関数の呼び出しは、式のどこに書いても `init` で評価される。S-33。
- 判断: R-97 の (b)（部分式の単位の巻き上げ）で直す。rt でない関数の呼び出しは、式のどこに書いても `init` で評価される
- 反映: S-33。実装は W7-05
- 補い（2026-11-03、親）: 第 80 組の下書き（110 回目、2026-11-03）で、効果行が空の非 rt の関数を flow の本体で `sample` の引数で呼ぶ形（`nr(x)`、`P { v: x }.get()`）が、§11.5 の表（効果行が空の非 rt fn の行）の E0815 でなく E0805（「is not `rt` and takes arguments at the clock `init` or constants only」、`flow/rate.rs`）になることが分かった（`db9f2125`）。
  この作業で直すときにコードも表に合わせる。再現は `target/notes/110/g80/flow_nonrt.onsa`。
- 反映（2026-11-19、親）: （2026-11-19、169 回目）W7-05 で直した。条件の位置の外は U1 `fe664a0b`（rt でない関数の呼び出しは `init` の欄、`tests/spec/flow_semantics/hoist_non_rt_calls.onsa`）、条件の位置の中は U2 `2dcd3bfb`（その位置を選ぶ条件が `init` より速い段で決まれば E0815、`tests/spec/flow_clock/e0815_non_rt_call_in_a_condition.onsa`）、`par~` の本体は U3 `f571fd9f`（`hoist_par_non_rt_calls.onsa`、`hoist_par_e0815_non_rt_call.onsa`）。定数だけの引数と結果が Copy でない呼び出しは E0200 のまま（W9-03、S-1160）。
