# R-17 flow: 部分式に書いた非 rt 関数が `tick` から呼ばれる

- 高・直す・観点 1 / 3｜`crates/onsa_sema/src/flow.rs:1176-1211`、`crates/onsa_core/src/lower/flow.rs:758`｜§11.5 の表「効果行が空の非 rt fn … 引数のレートが Init 以下のときだけ呼べる。init で評価される」
- 原因: どの段で評価するかを、`let` 単位でしか選んでいない。
- 再現: `flow g(x: Sig[F32], level: Init[F32]) { x * make_gain(level) }` は検査を通る。tick に `make_gain(s.0)` が出る。
  - debug では、検証器が `rt function calls non-rt` で落ちる。
  - release では、rt の保証が破れる。
  - `par` の `i` を引数にした場合も同じ。
- 直し方: 部分式を巻き上げる（R-97 の判断による）。それができないなら、sema で E0805 にする。
- 決定（2026-10-02）: R-97 の (b)（部分式の単位の巻き上げ）で直す。rt でない関数の呼び出しは、式のどこに書いても `init` で評価される。S-33。
- 判断: R-97 の (b)（部分式の単位の巻き上げ）で直す。rt でない関数の呼び出しは、式のどこに書いても `init` で評価される
- 反映: S-33。実装は W7-05
