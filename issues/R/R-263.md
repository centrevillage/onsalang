# R-263 export する頭が `_` の関数の C の名前が `t_onsa_g` になり、§14.2 の「`prefix` と名前の最後の要素をつなげたもの」（`t__g`）と違う

- 内容: `[export] prefix = "t_"` のパッケージで頭が `_` の関数 `pub fn _g` を出すと、C の名前は `t_onsa_g` になる（dev `fdc4fa5`、`onsa build --target host`。再現は `issues/R/R-263/`）。§14.2 の「C の名前は `prefix` と名前の最後の要素をつなげたもの」なら `t__g`。
