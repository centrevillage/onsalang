# R-347 `@export` の項目の名前が規則に揃えると予約語になるとき（`@export pub flow Match`）、E0320 の修正候補 `match_` を出し、当てると `@export` の名前の末尾の `_` の E0320 が残る

- 場所: `onsa check` などの E0320 の修正候補（`onsa_sema` の改名の候補）。
- 内容: §2.3 の 75 行は「規則に揃えた名前が予約語になるときは、末尾に `_` を足した名前を候補にする」とし、63 行は「末尾の `_` は予約語を避ける綴りで、`@export` の項目の名前（§14.2）を除き、どの形にも書ける」とする（S-653）。`@export pub flow Match(x: F32 at sample) -> F32 at sample { x }` の E0320 は候補 `match_` を出し、当てると `the name of an item with @export does not end with _ (§14.2)` の E0320（候補なし）が残る。
  §18.1 の候補の安全の約束（当てた後に同じ段の誤りを残さない）に反する。他の候補は仕様に無いので、`@export` の項目では予約語の候補を出さない（note は残す）。前からの形（W4-02 U1 の S-653 と、前からある予約語の候補の組み合わせ）。
- 経緯: 99 回目（2026-11-01）、W4-02 U4 のテストの担当（NEW-B、`P99/w402u4/t/probe/b/`）が見つけた。親が仕様の 63・75 行で確かめた。
