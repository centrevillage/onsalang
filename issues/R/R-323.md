# R-323 循環した struct・enum（値の循環の E0311）に数の合わない型引数を書いた型（`fn f(x: C[I32])`、`impl C[I32]`）に E0412 が出ない（`type_of_entity` が数を見ずに誤りの型を返す。循環を直しても残る誤り）

- 場所: `crates/onsa_sema/src/sig/types.rs::type_of_entity` の struct・enum の枝（循環した宣言は数を比べる前に誤りの型を返す）。
- 内容: `struct C { d: D }`・`struct D { c: C }` の後の `fn f(x: C[I32])` と `impl C[I32] { … }` に、E0311 だけが出て、数の E0412 が出ない（W4-05 U4c の前も後も同じ。再現は横の `cyc_sig.onsa`）。
  循環を直しても型引数の数の誤りは残るので、S-753・S-754 の見方（直しても残る誤りは連鎖でない）では報告する形。`impl` の見出しは S-759 の (2') で数が合わないので並びの規則も判定せず、何も出ない。
- 経緯: 81 回目（2026-10-29）、W4-05 U4c/i2（onsa-impl）が報告し、親が `P80/bin/onsa-w405u3b2` と U4c の後のバイナリで前からあることを確かめた。
- 判断: 直す（低。誤りのあるプログラムの報告だけ）。W4-05 U4a のついでに、循環した宣言でも数を比べる（約 2〜4 行。82 回目に U4a に入れた）。
