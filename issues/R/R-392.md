# R-392 `/=` の候補が、直後の `//` とつながって `///` を作る（`x/=//` 改行 `r`）

- 場所: `crates/onsa_syntax/src/foreign/assign.rs` の複合代入の候補（`=` の直後に ` x /` を入れる枝）と、`edits::joining` が隣のコメントを字句のつながりに数えないこと。
- 内容: 入力 `tests/fuzz/dffd5993.onsa`（`fn g()->U{x/=//` 改行 `r`）。候補を当てると `x= x ///` になり、`//` のコメントが `///` に変わる。前の版（`d7c35101`、`655a5faf`）でも同じ候補が出る。事例を足して変異が変わり、見えるようになった。
  実害は低い。`/=` の直後に空白なしで `//` が来る形だけで、ファイルの意味を黙って変えない（残るのは書き手が読める誤りである）。入力は `tests/fuzz/allowed.toml` に載せた。
