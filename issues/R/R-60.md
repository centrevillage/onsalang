# R-60 derive した `Default` の値を作る手段が無い

- 低・直す・観点 1｜`crates/onsa_sema/src/sig.rs:716`｜§6.4、S-13
- 再現: `P.default()` が E0401 になる。S-13 の「Default は実装済み」は、境界が成り立つかの判定だけである。
- 直し方: `default()` を降下する。または、第 1 期は E0200 にする。
- 表記: レビューの時点の `@derive(Default)` は、S-34 で宣言の `: Default`（`pub struct P: Default { ... }`）に移った。
- 範囲（2026-10-04 に追加で確かめた）: `F32.default()` は E0413、総称の `T.default()` は E0302。enum の `Default` の derive は、どの列挙子を既定にするかが決まらないまま通る。
- 決定（2026-10-04）: 直す（降下する）。呼び方は `P.default()` と `T.default()`。enum の `Default` の derive は E0416 で、手で `impl Default` を書く。S-49。
- 判断: 直す。S-49: `default()` を降下し、`P.default()` と総称の `T.default()` で呼ぶ（S-46 の境界からの解決と同じ道）。struct は各フィールドの既定値。enum の `Default` の derive は E0416
- 反映: 仕様 §6.3 / §6.4 に反映済み（2026-10-04）。実装は W5-06
