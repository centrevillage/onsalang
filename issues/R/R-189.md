# R-189 複数の単一ファイルのテストが黙って消える

- 中・直す・観点 1｜テストの実行｜§11.8、§15.1
- 内容: `onsa test x/a.onsa y/a.onsa` で、どちらのモジュールも `a` になり、`test "t"` が同じ完全な名前になる。結果は `y/a.onsa` の一件だけで、`x/a.onsa` のテストは黙って消える。`onsa check` も重なりを報告しない。
- 経緯: S-286 の確かめで親が再現した（2026-10-08）。
- 決定（2026-10-08、親）: 直す。S-286 で、マニフェストの無いファイルを複数渡す形は使い方の誤り（終了コード 2）とした。W4-02 で実装する。
- 判断: 直す（親）。マニフェストの無いファイルを複数渡すと、同じファイル名のモジュール（`x/a.onsa` と `y/a.onsa`）のテストが同じ完全な名前になり、一つが黙って結果から消える。S-286 で複数のファイルを渡す形を使い方の誤りにする。会話で利用者が見た再現（2026-10-08）
- 反映: 実装は W4-02
