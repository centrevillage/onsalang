# R-478 `[]` を `[Span[T]; 0]` の引数に渡すと E0401 になる（§5.3 は `[a, b]` の配列リテラルを引数の位置に書けるとし、要素の無いものを除かない）

- 場所: 型の段の引数の位置の配列リテラル（`[Span[T]; N]` への変換）。
- 内容: `fn f(inout xs: [Span[F32]; 0])` の `f(inout [])` と、生成する API の `a.process(inout s, xs, inout [])`（出力が `[F32; 0]`）が E0401「expected `[Span[F32]; 0]` (or an array / `Buf` of the same element), found `[]`」になる。
  通すには `var e: [Buf[F32]; 0] = []` と書いて `inout e` を渡す。S-1110（第 107 組）の後は境界の配列が N ≥ 1 なので生成する API には出ず、利用者の関数の引数に残る。再現は `target/notes/160/g107/probe/zero_array_process/`。
- 経緯: 160 回目（2026-11-16）、S-1110 の段 1（onsa-advisor）が範囲の外で見つけた。前から。
- 判断: 直す（低）。W7-12 U2b で引数の位置のリテラル（struct リテラルの planar）を触るときに、要素の無い配列リテラルも見る。
- 反映（2026-11-17、親）: W7-12 U2b（`b61bc866`）で引数の位置のリテラルと一緒に直した。W7-12 を閉じる（163 回目）。
