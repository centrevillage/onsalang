# R-187 型引数の決まらない総称の関連定数が検査を通り、`onsa test` で内部エラーになる

- 中・直す・観点 1｜型の段｜§4.7、§18.1
- 内容: 総称の `impl` の関連定数（`impl[T, const N: U32] Rg[T, N] { pub const CAP: U32 = N }` の `Rg.CAP`）を型引数を決めずに参照すると、型パラメータの決まらないまま `onsa check` を通り、`onsa test` で内部エラー（終了コード 101、「unbound const parameter」）になる。
  同じ形の列挙子 `E2.B`（`enum E2[T] { A(T), B }`）は E0406。内部エラーは検査の誤りの見逃しである（§18.2 の 101 は降下の予期しない失敗）。
- 経緯: 第 9 組の下書き（S-239）で見つけた（2026-10-08。親と Fable が再現）。
- 決定（2026-10-08、親）: 直す。どのコードにするか（E0406 か、値が型パラメータに依らなければ通すか）は S-304 で決め、数の trait と関連定数を扱う W5-05 で行う（S-239 の後は `Rg::[F32, 4].CAP` と書ける）。
- 判断: 直す（親）。型引数の決まらない総称の関連定数（`Rg.CAP`）が検査を通り `onsa test` で内部エラーになる見逃しを無くす（コードは S-304）。第 9 組の下書き（S-239）で見つけた
- 反映: 実装は W5-05
