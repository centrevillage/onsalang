# R-512 参照評価器が修飾子の見分けと連鎖の頭を sema の名前の段の記録（`ModifierCall`）と別に導く（`flow_ref/sema_view.rs` の `Body::modifier`、`rate.rs` の `chain_of`）

- 場所: `crates/onsa_tests/src/flow_ref/sema_view.rs` の `Body::modifier`（一覧の名前で、組込みもインスタンスも記録の無い呼び出しを修飾子とする否定の引き）と `rate.rs` の `chain_of`（受け手を辿って頭を作る）。sema には名前の段の記録 `ModifierCall`（`names/body/mod.rs` の `modifiers`、「the one place that decides one」、`pub(crate)`）がある。
- 内容: どの呼び出しが修飾子で連鎖の頭はどれかは名前の解決の判断（評価器が読む名前の表 `instance_of`・`flow_builtin` と同じ類）で、二か所にあると片方だけが変わりうる（D-15）。比の和は評価器が仕様から独立に求める（参照の役目）ので、ここに含めない。誤りを再現する入力は無い（構造）。
- 経緯: 173 回目（2026-11-21）、W7-09 U2a/b（onsa-break）が中（構造）として挙げ、親が登録した（報告の控えは `target/notes/173/w709/u2a/b_report.md`）。
- 判断: 直す（低）。sema が `Analysis` の関数で名前の段の修飾子の記録を公開し、評価器はそれを引く。評価器に `.when~`・`.reset_if~` を足して修飾子の見分けを広げる W7-10 で行う。
- 反映（2026-11-23、親）: 180 回目、W7-10 U1e で直した: sema が `Analysis::modifier_of` で名前の段の `ModifierCall`（修飾子、受け手、頭）を公開し、評価器の `sema_view.rs` の `Body::modifier` と `rate.rs` の `chain_of` の受け手の辿りがそれを引く。比の和・W・段は評価器が独立に求める（判断のとおり）。
