# R-456 後で宣言した別名のメンバを指す別名（`type B = A.N` の後に `type A = U32`）が、名前の段の内部エラー「an alias read before the order lowered it」になる（前に書けば E0302）

- 場所: 署名の段の別名と定数の順のグラフ（`crates/onsa_sema/src/sig/decls.rs` の `named`）。型の経路は、経路の全体が解けたとき（`resolve`）だけ別名へ辺を引くので、`A.N` のように途中の別名 `A` までしか解けない経路では `A` へ辺を引かない。名前の段が `A.N` を読むとき、まだ降ろしていない `A` を読み（`names/typed.rs::alias_type` の 131 行）、内部エラーになる。定数の式の側（`read`）は最後に届いた別名へ辺を引いている（R-440）。
- 内容: `type B = A.N` の次の行に `type A = U32` と書くと、`onsa check` が「internal error: an alias read before the order lowered it」で 101 になる。順を逆にすると `A.N` の E0302（`N` が無い）になる。W5-13 U2b（`47a5a0b8`、S-1016）が「順の外で別名を読むのは内部エラー」とした後からで、W6-02 の前のバイナリ（`onsa-918b709`）でも同じ。
- 経緯: 148 回目（2026-11-14）、W6-02 U5b のコミット（`9cd3c9d3`）の網羅の検査の fuzz（種 `tests/spec/types/const_forms_not_read_order.onsa` の変異 3）が見つけた。事例を足して変異が変わり、前からの不具合を新しく引いた。入力は `tests/fuzz/96131508.onsa`（`type B=A10.N` と `type A10`）、最小の形は上の二行。
- 判断: 直す（内部エラー。`rules/leader.md` 7.4 で見つけた作業の W6-02 の小さな単位で直す）。期待は順を逆にしたときと同じ E0302。
