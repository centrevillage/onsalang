# R-68 `onsa test` が、モジュール `test` の関数をテストとして実行する

- 中・直す・観点 2 / 3｜`crates/onsa_driver/src/lib.rs:456`、`crates/onsa_core/src/lower/mod.rs:204`｜§11.8、S-16
- 原因: テストを、名前の接頭辞 `test.` で見分けている。
- 再現: パッケージに `test.onsa` を置くと、その中の関数がテストとして実行され、失敗として数えられる。
- テスト名: モジュールの経路を落とすので、別のモジュールの同名のテストが同じ名前になる。
- 直し方: Core の関数に、テストであることを示す印を持たせる。
- 決定（2026-10-04）: 直す。S-55: テストはモジュールの経路と名前で識別し（`dsp.voice "decays"`）、報告と `--json` に含める。`--filter` と `--json` を仕様に載せる。`tests/` の役割は R-122 に分けた。
- 判断: 直す。S-55: Core の関数にテストの印を持たせる。テストはモジュールの経路と名前で識別し（`dsp.voice "decays"`）、報告と `--json` の `"module"` に出す。`onsa test` の `--filter`（完全な名前の部分一致）と `--json` を仕様に載せる。`tests/` の役割は R-122
- 反映: 仕様 §11.8 / §18.2 に反映済み（2026-10-04）。実装は W2-10
