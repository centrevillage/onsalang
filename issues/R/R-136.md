# R-136 `BITS` が 32 ビット以外の整数型で誤る

- 中・直す・観点 1｜関連定数の評価｜§6.6
- 内容: `I32.BITS` だけが正しく、`I64.BITS == 64`、`U64.BITS == 64`、`U8.BITS == 8` が偽になる。`let b: U32 = I64.BITS; assert b > 32` も偽。
- 経緯: W1-08 のテストの票が仕様から書いた test で見つけた（2026-10-07）。再現は `tests/spec/semantics/bounds64.onsa` の「BITS of the 64-bit types」（実装待ち）。
- 決定（2026-10-07、親）: 直す。仕様は明確で、判断は要らない。関連定数を扱う W5-05 で直す。
- 判断: 直す（親、仕様が明確）。`I8`〜`U64` の `BITS` を型の幅にする（仕様 §6.6）。W1-08 で見つけた。再現は `tests/spec/semantics/bounds64.onsa` の「BITS of the 64-bit types」
- 反映: 実装は W5-05
