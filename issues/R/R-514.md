# R-514 `onsa interface` が状態のフィールドを `名前: 型` でなく大きさと配置（`8 bytes, align 4, fast`）で出し、サブインスタンスの `State`・組込みの flow の疑似型・`let` の値の型を出さない（§11.6）

- 場所: `crates/onsa_driver/src/interface.rs` の状態のフィールドの行（`fast_fields` を並べる所）。
- 内容: §11.6「`onsa interface` は、状態のフィールドを `名前: 型` で表示する。サブインスタンスの型はその flow の `State`（`src: saw.State`）、組込みの flow の状態は呼び出しに合わせた疑似型（`prev[F32]`、`delay[F32, N]`、`vdelay[F32, N]`）、`let` 由来の値は値の型である」に対し、今は全てのフィールドを `_out.ch_0: 8 bytes, align 4, fast  // offset 0` の形で出し、型を出さない。前から（W7-16 U5b2 より前の `target/base/8e67089/onsa` で同じ）。再現は `target/notes/176/w716/u5b2/iface.onsa`（`onsa interface`）。
- 経緯: 176 回目（2026-11-22）、W7-16 U5b2 のテストの担当（onsa-test）が範囲の外で見つけ（interface のテストは型の字に頼らず欄の大きさで子の欄を確かめた）、親が今のバイナリで再現した。直すのは interface の大きさを改める W9-07。
