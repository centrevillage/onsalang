# R-451 `rt` の関数の中で、`rt` でない関数型の位置に置く無名関数の本体を `rt` の規則で検査する（`rt fn mk() -> fn(U32) -> U32 { fn(y: U32) -> U32 { heavy(y) } }` が E0901）

- 場所: `crates/onsa_sema/src/rt.rs` の `body_rules`（`rt` の関数の本体の呼び出しを、無名関数の中のものも含めて項目ごとに数える）。効果の側の `effects.rs::first_use` も項目ごとで、無名関数ごとに仕分けない（R-359、R-27 (1)）。
- 内容: 再現は横の `rt_closure.onsa`（dev `ea8d73f6` の `onsa check` で E0901 が二つ）。`rt` の関数の中で、`rt` でない関数型の位置（返り値、struct のフィールド）に置く無名関数の本体の、`rt` でない関数の呼び出しが、外側の `rt` の関数の呼び出しとして E0901 になる。
  §8.1 は「期待する型が `rt` なら、本体を `rt fn` の規則で検査する」とし、`rt` でない位置の無名関数の本体は `rt` の規則で見ない。通るはずのプログラムを誤りにする。期待する型の無い無名関数（`let l = fn(y: U32) -> U32 { heavy(y) }`）も同じく E0901 で、その扱いは S-1032 の決定に従う。
- 経緯: 145 回目（2026-11-13）、W6-01 の設計メモ（onsa-impl）が範囲の外で気付いた点として挙げ、親が固定のバイナリ `onsa-ea8d73f` で再現した。R-27 (1)・R-26 の後半と同じ「本体の使用を無名関数ごとに仕分ける」仕組みで直るので、W6-03 に置く（同回、利用者が W6-01 の案 (a) を了承）。関係: R-26、R-27、R-359、S-1032
