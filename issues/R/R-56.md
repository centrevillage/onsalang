# R-56 `T.ZERO` と `F32.ZERO` が無い

- 中・直す・観点 1｜`crates/onsa_sema/src/body.rs:923`、`builtin.rs:140`｜§6.6「型パラメータでは `T.ZERO`」
- 再現: `x + T.ZERO` が E0302 になる。
- 影響: T-3（リテラルは `T` に束縛しない）と合わせると、総称の数値関数で 0 を作る手段が無い。
- 経緯: 計画の T2-5 では完了扱いになっている。
- 決定（2026-10-03）: 直す。`Num` / `Float` の中身と組込み型の関連定数を S-46 で定めた。`ONE` は `Float` に置く（Q15 / Q31 が 1 を表せないため）。浮動小数の `MIN` は設けない。`std.math.sum` は `[T: Num]` と `T.ZERO` に改めた（R-23）。
- 判断: 直す（trait の関連定数を実装し、`T.ZERO` と `F32.ZERO` を引けるようにする）。
  S-46: `Num` は `Add` `Sub` `Mul` `Div` `Rem` `PartialEq` `PartialOrd` と `ZERO`、`Float` は `Num` と `ONE` `PI` `MAX` `EPSILON` `INFINITY` `NAN`。`ONE` を `Num` に置かないのは Q15 / Q31 のため。
  組込み型の関連定数は閉じた表で、浮動小数の `MIN` は偽の友人なので設けない。`std.math.sum` は `[T: Num]` と `T.ZERO`（R-23 を改めた）
- 反映: 仕様 §6.3 / §6.6 / §13.4 に反映済み（2026-10-03）。実装は W5-05
- 補い（2026-10-27、親）: 75 回目（2026-10-27）: 本体の経路の頭の型パラメータ（`T.ZERO`、無い名前の `T.nosuch`）は、今はどちらも E0302「cannot find `T`」で、`T` が見つかる名前なのに見つからないと言う。
  W4-04 の名前の段の歩き手が頭を型パラメータに解決し（U2b）、無い関連の名前は R-147・S-707 の E0302 の文面に揃える。`T.ZERO` そのものの値はこの R（W5-05）。第 65 組の助言の段 1 が見つけた。
