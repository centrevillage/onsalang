# R-267 補間のある test の名前の E0002 の後に、別の test に偽の E0306 が付く（`test "x{1}y"` と `test "xy"`）

- 場所: 構文の段の誤りの回復（補間のある test の名前を読んだ後の名前の値）と、`crates/onsa_sema/src/names/collect.rs` の `collect_test`（E0306 の重なりの表）
- 内容: 横のディレクトリの `q_test_interp1`（`test "x{1}y"` と `test "xy"`）で、前者の E0002「the name of a test cannot hold an interpolation」に続いて、後者に E0306「test "xy" is defined twice in this module」が付く（dev `3895f4d` も同じ）。
  補間のある名前は test でない（S-244、`onsa_syntax::test_name::value` の文書）ので E0306 の相手にしない（§18.1 の偽の連鎖の誤り）。誤りの回復で補間を落とした名前 `xy` が残っているとみられる。
- 経緯: 64 回目（2026-10-25）、W4-03 U2a の壊す側（onsa-break）が見つけた（前からの挙動）。直しは読み続けた宣言と失敗した名前を扱う W4-03 の U3b。
