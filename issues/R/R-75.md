# R-75 `onsa interface` に、flow の状態を含む型の大きさが出ない

- 中・直す・観点 1｜`crates/onsa_driver/src/interface.rs:29`、`:531`｜§17.6「Poly … その大きさは onsa interface に出る」、§12.1
- 再現:
  - `Poly` は `// Affine` とだけ出て、大きさが無い。
  - State のフィールドは「8 bytes, align 4」と出て、型が失われる。
  - Core の降下が一か所でも失敗すると、全ての flow の大きさが消える。
- 範囲（2026-10-04 に追加で確かめた）: `voice.SIZE` / `BULK_SIZE` を、S-32 で名前空間から外した後も `pub const` として出す。`vdelay_0.buf` / `vdelay_0.w` と、`poisoned` / `initialized` / `sample_rate` が、`let` 由来のフィールドと同じ形で並ぶ。
  §11.6 / §12.4 は `onsa interface --target <名前>` に大きさを出すとするが、§18.2 の表にも CLI にも `--target` が無い。
- 決定（2026-10-04）: 直す。S-65: `--target` で、そのターゲットでの大きさと各 flow の `SIZE` / `ALIGN` / `BULK_SIZE` / `BULK_ALIGN`。
  付けなければ bulk 無効での大きさを出し（ポインタの幅にも依存しない）、`@mem(bulk)` を持つ状態とハンドルを含む値に条件を添える（利用者の質問を受けて、依存する型を全て「ターゲットによる」とする案から改めた）。
  状態のフィールドは `名前: 型`（サブインスタンスは `saw.State`、組込みの flow は疑似型 `prev[F32]` / `delay[F32, N]` / `vdelay[F32, N]`、`.buf` / `.w` は内訳、`let` に由来しないフィールドに印）。ホットリロードはこの表記で型を比べる。
  §12.4 の配置の段の上で作るので、第 2 段から第 4 段（T4-10 の後）へ移した。再現は `tests/review-phase1/parent/r75/`。
- 判断: 直す。S-65: `onsa interface --target <名前>` で、そのターゲットでの大きさと各 flow の `SIZE` / `ALIGN` / `BULK_SIZE` / `BULK_ALIGN`。
  付けなければ bulk 無効での大きさを出し、`@mem(bulk)` を持つ状態には「bulk が有効なターゲットでは変わる」、ハンドルを含む値には「ポインタの幅による」と添える。
  状態のフィールドは `名前: 型`（`saw.State`、疑似型 `prev[F32]` / `delay[F32, N]` / `vdelay[F32, N]`、`.buf` / `.w` は内訳、`let` に由来しないフィールドに印）で、ホットリロードもこの表記で比べる。`voice.SIZE` を `pub const` として出さない。
  再現は `tests/review-phase1/parent/r75/`
