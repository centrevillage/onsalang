# R-457 flow の本体で、補間の穴の値のクロックを、それを含む呼び出しのクロックに数えない（`let n = len_of("{x}")` が通る）

- 場所: flow の本体のクロックの解析（呼び出しの引数のクロック。補間の穴）。
- 内容: 横の `hole_clock.onsa`。`pub fn len_of(s: Str) -> F32`（`rt` でない）を flow の本体で `let n = len_of("{x}")`（`x` は `sample`）と呼ぶと通る。同じ関数に `x` を直に渡す `x + lf(x)` は E0805「`lf` is not `rt` and takes arguments at the clock `init` or constants only」、`x + len_of("{x}")` は E0200（「a call of a function that is not `rt` in an expression at the clock `sample`」、note は「bind the call with a `let` of its own, which is computed at `init`」）。穴の `x` の `sample` が呼び出しのクロックに入らず、`let` の値が `init` で一度だけ計算されうる（推測）。
  正例 `tests/spec/lex/interp_paths_locals.onsa` の `in_a_flow` などがこの形に頼って通る（S-1043 の決定で補間の扱いも変わる）。
