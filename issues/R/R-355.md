# R-355 総称の型の derive が型引数を見ず、満たさない型引数でも trait を満たすとする（`struct Pair[T]: PartialEq` の `Pair[Plain]` の `==` が通る）

- 内容: `pub struct Pair[T]: PartialEq { a: T, b: T }` と `PartialEq` を持たない `struct Plain { x: F32 }` で、`let p: Pair[Plain] = …` の `p == p` が `check`・`dump --core`・`onsa test` とも通る（`__eq.p1_Pair__p1_Plain` を作って走る）。
