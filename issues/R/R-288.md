# R-288 `sample_tick()` を flow の本体で呼ぶと E0302「cannot find」になる（§11.4 の組込み名で、まだ扱えない形は §18.1 の E0200）

- 場所: `onsa_sema/src/flow/check.rs` の組込みの呼び出しの判定（約 343 行）が `prev`・`delay`・`vdelay`・`sample_rate` だけを見て、`sample_tick` を見ない。名前の段の記録（`FlowBuiltin`）は `sample_tick` を持つ。
- 内容: `pub flow f(x: F32 at sample) -> F32 at sample { let t = sample_tick()  x }` は E0302「cannot find `sample_tick` in this scope」（dev `07f71e4`）。§11.4 は `sample_tick()` を flow の組込みとし、§18.1 は仕様にあってこの版が扱えない形を E0200 にする。
  E0302 は「名前を足すか綴りを直す」の直し方を示すので、書き手が `fn sample_tick()` を足すと E0304（組込みの名前）になり、二つの診断が逆のことを言う（S-720 と同じ形）。事例は `tests/spec/flow/builtin_sample_tick_call.onsa`（`until = "W7-09"`）。
- 経緯: 76 回目（2026-10-27）、W4-04 U3b/t（onsa-test）が見つけ、親が確かめた。W7-09 が `sample_tick()` を実装するまでの間の形。
- 判断: 直す（低）。W4-04 の U3b で、組込みの呼び先の口（`paths.rs::flow_builtin` と flow の検査の呼び出しの判定）が `sample_tick()` を E0200（この版が扱えない組込み）にする。実装は W7-09。
