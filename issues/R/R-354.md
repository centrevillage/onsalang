# R-354 std の `min`・`max` の宣言が `T: Num` で、§6.3 の 124 行（`min` / `max` は `AnyNum`）と食い違う

- 場所: `std/math.onsa` の 23・24 行（`pub target rt fn min[T: Num](x: T, y: T) -> T`、`max` も同じ）
- 内容: §6.3 の 124 行は `std.math` の `min` / `max` を `AnyNum`（符号なしを含む全ての数）とするが、std の宣言は `T: Num`（符号なし整数を満たさない）である。
  この版は `T: AnyNum`・`T: Int`・`T: Unsigned` の境界を E0200 にする（「this version does not support user-defined traits as bounds」）ので、宣言だけを `AnyNum` に替えることは今できない
- 経緯: 105 回目（2026-11-03）、第 78 組の独立のレビュー（onsa-advisor の段 1）が見つけ、親が確かめた
- 判断: 直す（宣言を仕様に合わせる）。`AnyNum` の境界の対応（W5-05 の数の trait、R-94）の後、`std.math` の Onsa の本体を書く W5-07 で直す。S-855（`add_from!` の要素の `AnyNum`）も同じ境界を使う
