# R-506 flow の E0309 が、誤りの単位を読む式と同じ遅延（またはその隣）で読まれる `let` を「出力と `let _` の届かない所でだけ読まれる」と誤って報告する

- 場所: flow の E0309 の到達の材料（`crates/onsa_sema/src/flow/reads.rs` の印付けが集めていた `Marked::deps`）。
- 内容: 誤りの単位を読む式（署名の読めない `id2` の呼び出し、§18.1 で誤りの値）と同じ `let` の中の遅延（`let c = prev~(id2(p) + b)`、`id2(p) + prev~(b)`、`prev~(b) + id2(p)`）は、クロックが誤りのクロックになり、印付けは段の無い節点の引数を歩かないので、その第 1 引数の読み（`b`）が到達の材料から落ちた。出力が `c` を読み `c` が `b` を読むのに、`b` に E0309「read only where the output and no `let _` reach」が出た（§5.1 では誤った報告。誤りのあるプログラムでだけ起き、通るプログラムは変わらない）。再現は事例 `tests/spec/negative/flow_unused_reads_in_a_failed_delay.onsa`（固定のバイナリ `target/base/364bacf/onsa` で E0309 が 3 件）。
- 経緯: 170 回目、2026-11-19、W7-15 U2 の実装（onsa-impl）が、E0309 の材料を計画の辺から作る直しの一時の比べ（辺から作った `deps` と `Marked::deps` の突き合わせ）で見つけた（`tests/spec/negative/flow_reads_failed_units.onsa` の `call_read_on` の一件。出力は同じ）。W7-14 U5 の形から前からある。
- 判断: 直す（低）。計画の辺は全ての読みを持つので、W7-15 U2 が到達の材料を辺から作る形にして直した（設計メモ 3 章の一本化そのもの）。
- 反映: W7-15 U2 `a2fddcc9` で直した（到達の材料を計画の辺から作る）。回帰の事例 `tests/spec/negative/flow_unused_reads_in_a_failed_delay.onsa`。
