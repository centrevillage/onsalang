# R-146 `onsa fmt` が、構文解析が失敗させた項目をファイルから消す

- 高・直す・観点 1｜`crates/onsa_syntax/src/fmt.rs:16`、`crates/onsa_driver/src/lib.rs`（`diff_ast`）｜§18.2
- 内容: 構文解析器が E00xx でない診断（タプルの添字の溢れの E0408）で項目を失敗させると、fmt は番号の範囲（`1..=20`）で構文の診断かを判定しているので止まらず、AST に無いその項目を出さずにファイルを書き換える。終了コードは 0。S-56 の書き換えの前後の AST の比較は、両方にその項目が無いので通る。`diff --ast` も同じ。
  再現: `fn f(t: (I32, I32)) -> I32 { t.99999999999 }` と `fn g` のファイルに `onsa fmt` をかけると、`fn f` が消える。
- 経緯: W3-02 の設計メモで見つけた（2026-10-08）。
- 決定（2026-10-08、親）: 直す。fmt と `diff --ast` は、診断の段で判定する（W3-02）。どの段の診断で止めるかの文は S-214（利用者が決める）。決まるまでは、字句解析と構文解析の段の全ての診断で止める（保守的）。CLI のテストに再現を入れる。
- 判断: 直す（親）。fmt と `diff --ast` は、構文解析が項目を失敗させた診断があれば書き換えない（段で判定。条件の文は S-214）。W3-02 の設計メモで見つけた
- 反映: 実装は W3-02
