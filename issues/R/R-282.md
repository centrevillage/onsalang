# R-282 const パラメータを型の位置に書いた形（`fn f[const N: U32](x: N)`、`Option[N]`、struct のフィールドの `a: N`）が、診断なしで通る

- 場所: 署名の型の位置の名前の解決（`onsa_sema/src/sig/types.rs`。総称パラメータの並びの const パラメータを型の名前として引いている見込み、未確認）。
- 内容: `pub fn f[const N: U32](x: N) -> I32 { 0 }`、`pub fn g[const N: U32](x: Option[N]) -> I32 { 0 }`、`pub struct S[const N: U32] { a: N }` は、診断が無く終了コード 0（dev `65a1073` のバイナリ、コードは `381bb7e` と同じ）。
  本体の注釈の `let a: N = 0` は E0401「an integer literal cannot have type `N`」で、`N` を型と読んでいる。§15.1 の「値やモジュールを型の位置に書く」E0308（const パラメータは定数、§4.5）に当たり、仕様に無い形を黙って受理している（`rules/process.md` 8.2 の 2）。
  再現は 75 回目の scratchpad の `g65/probe/n/n1.onsa`（区切りで `target/notes/75/g65/probe/n/` へ写す）。
- 経緯: 75 回目（2026-10-27）、第 65 組（S-713）の下書き（onsa-gap）が見つけ、親が再現した。直すのは W4-04 のコードの割り当ての単位（U8、S-103）。
- 判断:
- 補い（2026-10-28、親）: W4-04 U8a/b（78 回目）: 本体の注釈の型の位置も同じ（`let _: M = 1` は E0401「an integer literal cannot have type `M`」、`t as M` は E0411、無名関数の引数の `fn(x: M)` は通る。再現 `issues/R/R-282/body_annotations.onsa`）。署名と一緒に W4-04 U8b で直す。
