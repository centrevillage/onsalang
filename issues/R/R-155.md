# R-155 `const N: U32 = 0 - 1` が `check` を通り、`const` の初期化式の panic がビルドで E0200 になる

- 中・直す・観点 1｜定数の評価（`check` とビルド）｜§6.6、§18.1
- 内容: §6.6 はコンパイル時の評価の panic を E0419 とする。今は `onsa check` が初期化式を評価せずに通し、`onsa build` で「the C backend does not support this `const` initializer」の E0200 になる。プログラムの誤りが未対応の機能として出て、S-224 の E0200 の定めにも合わない。
- 経緯: S-227 と S-224 の仕様の空白 S-207〜S-228 の下書き（[`spec-gaps-w2-w3.md`](spec-gaps-w2-w3.md) の付録 A）で見つけた（2026-10-08）。
- 決定（2026-10-08、親）: 直す。仕様は明確。W9-03 で E0419 にし、`onsa check` でも出す。
- 判断: 直す（親、仕様が明確）。`const` の初期化式の panic を E0200 でなく E0419 にし、`onsa check` でも出す。S-227 と S-224 の下書きで見つけた
- 反映: 実装は W9-03
