# R-471 クロックの読めない入力を持つ flow の生成する関数を呼ぶと、引数の数の E0412 が連鎖する（`flow g(x: F32 at sample, c: F32 at foo)` の `g.init(8.0)`）

- 場所: `crates/onsa_sema/src/sig/flow_sig.rs`（読めないクロックの入力を誤りの型の `Sig` の入力として残す、S-692）と、生成する関数の引数の数の検査。
- 内容: クロックの読めない入力（`at foo`、クロックの無い入力の E0810）を持つ flow の `init`・`process` を呼ぶと、入力が `Sig` の誤りの入力として数えられ、`g.init(8.0)` が「takes 2 argument(s) but 1 were given」、古い形の `g.process(inout s, g.Params{}, xs, inout ys)` が「takes 5 but 4」の E0412 になる。§18.1 の「誤りの単位で連鎖を出さない」から、読めない flow への呼び出しは黙る方が一貫する。前からの挙動（W7-12 U1 の前も後も同じ）。W7-12 U1 は、同じ flow の `Config`・`Params` を両方作って型の名前の E0302 を避けたが、呼び出しの数は黙らない。再現 `target/notes/157/w712/u1/b/c9.txt` の `fooclock`・`noclock_run`・`fooclock_old`・`noclock_old`。
- 経緯: 157 回目、2026-11-16、W7-12 U1/b（onsa-break）が低として挙げた。直し方の見当: 見出しのクロックが読めない flow（`members_unknown` の形）では、生成する関数の引数の数の検査を黙らせる。
- 判断: 直す（低、§18.1 の「誤りの単位で連鎖を出さない」）。W7-12 U3a で、見出しのクロックが読めない flow と、入力か出力が E0810 の flow（`members_unknown`）の生成する関数（`process`・`process_inplace`・`render`、`init`）の呼び出しに失敗の印を付けて黙らせる。出力が E0810 の `process` の呼び出しの E0412・E0401 と、入力が E0810 の呼び出しの E0401 も同じ族（162 回目の U3 の設計メモの審査、`target/notes/162/w712/u3/review/` の `in/b.txt`・`in/c.txt`）。
