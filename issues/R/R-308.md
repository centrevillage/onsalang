# R-308 無名関数の効果行の名前を型付けが引くので、そこで見つからない名前（E0302）が、同じ単位の後ろの名前の段の誤りに隠れる

- 場所: `crates/onsa_sema/src/body/expressions.rs` の 617 行（無名関数の効果行を型付けが `read_effects` で読む）。本体の注釈の関数型の効果行は名前の段が読む。
- 内容: `let g = fn(x: I32) -> I32 uses {Nope} { x }` の次の行に `let _: Nope2 = 1` があると、名前の段の後ろの E0302（3 行）だけが出て、前の行の `Nope` は報告されない（名前の段の誤りで単位が型付けへ進まないため）。§8.1 は効果行の名前を他の名前と同じく解決するとし、§18.1 は同じ段の中で位置の順の最初の誤りを報告する。
  再現は横の `closure_row_then_name.onsa`（隠れる形）と `fn_type_row_then_name.onsa`（本体の注釈の関数型の効果行は名前の段で、正しく 2 行の E0302）。W4-04 の持ち越しの「無名関数の効果行の E0200 は型の段のまま」と同じ根。
- 経緯: 79 回目（2026-10-28）、第 69 組の下書き（onsa-gap）が見つけ、親が再現した。前からある。
- 判断（2026-10-28、親）: 直す（低）。S-738 の決定のとおり、無名関数の効果行を名前の段の歩き手が読む形にすると直る（W4-19）。
