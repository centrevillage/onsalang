# R-493 `vdelay~` の要素の型が浮動小数でない形のコードが仕様（§11.4 の E0416）と違い、実装は E0401

- 場所: `crates/onsa_sema/src/flow/rate.rs` の `pass_inner`（W7-02 U2b-2 の後は `flow/clocks` の段 2 の検査、全ての `let` の後の `float_checks`）。
- 内容: §11.4 の `vdelay~` の行は「`T: Float`（でなければ E0416）」で、`tasks/diag-codes.md` の E0410〜E0416 の行も E0416 の境界に「`vdelay` の `Float`」を挙げる。実装は E0401「`` `vdelay~` interpolates and needs a float signal (`F32` / `F64`, §11.4) ``」を出す（`pub flow f(x: I32 at sample) -> I32 at sample { vdelay~(x, 2, 4) }` で E0401@2:3）。既にある事例 `tests/spec/flow_semantics/rules_negative.onsa` の `vdelay_on_i32` などは E0416 を期待し、他の形と一緒に実装待ち（until W7-06）。通るプログラムは変わらない。前からの挙動。
- 経緯: 165 回目（2026-11-18）、W7-02 U2b-2/t（onsa-test）が仕様とのずれとして報告し、親が登録した。W7-02 の設計メモ（H3 の表の 2）と R-473 は E0401 のまま書いていた。
- 判断: 直す（低）。W7-02 U3 で、同じ検査を遅延の呼び出しの位置へ移す R-473 と一緒にコードを E0416 にし、文面を他の E0416 の境界の文と揃える。U2b-2 は今の E0401 を写す（出力を変えない単位）。`rules_negative.onsa` の実装待ちは他の形が W7-06 を待つので残る。
