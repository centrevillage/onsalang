# R-511 輪の中で、まだ決まらない値（`^名前`）を読む被演算子が誤りのとき、上に書いた読み手が先に診断を出す（`let c = prev~(slow(^a))`・`let a = slow(prev~(^a) + p)`）

- 場所: `crates/onsa_sema/src/flow/clocks.rs` の `Walk::bottoms`・`call`、`flow/clocks/checks.rs` の `check_fn_call`（段 1 は、解いている輪の `^名前`（⊥）を読んだ呼び出しの E0815 を決めない）。
- 内容: `let c = prev~(slow(^a))` の後に `let a = slow(prev~(^a) + p)`（`slow` は非 `rt`、`p` は `block`）は、前も後も `c` の側の E0815 が出る。R-496 と S-1133 (1) の線では `a` の E0815 だけになる。段 1 は ⊥ を読む被演算子から誤りを作らない（作ると段 2 で輪が自分の `Error` に黙り、誤りが消える。W7-09 U4b/b の #1）ので、輪は `sample` で解け、`^a` の読み手は黙らない。誤りは消えず、報告の位置だけが変わる。通るプログラムは変わらない。前からの形。再現は `target/notes/173/w709/u4b/i2/res.txt` の `partial_reader_above`。
- 経緯: 173 回目（2026-11-21）、W7-09 U4b/i2（onsa-impl）が R の候補として挙げ、親が登録した。
- 判断: 直す（低）。段 2 の `^名前` が段 1 の値を読む今の形と両立しないので、輪の誤りの報告の形を見直すときに。段の終わり（W7-17）で見る。
