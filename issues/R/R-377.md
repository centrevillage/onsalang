# R-377 空の struct をフィールドに持つ値が flow の状態に入ると、生成した C がコンパイルできない（状態の大きさの静的アサート）

- 場所: C の生成と状態の大きさの計算。C の構造体は `struct Empty { uint8_t onsa_empty; }` だが、状態の大きさの計算は空の struct を 0 と数えるので、`ONSA_STATIC_ASSERT` が失敗する。
- 内容: 横の `e.onsa` を `onsa_cases --c c-clang <root>` に渡すと、`sizeof(struct e_f) == 8` の静的アサートで止まる。derive を使わない `P { x: 0.0, e: Empty {} }` でも同じで、W5-06 の前からの形である。W5-06 U3 の `default()` は同じ形に届く。
- 経緯: 117 回目（2026-11-06）、W5-06 U3/i（onsa-impl）が範囲の外で見つけた。
