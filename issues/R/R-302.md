# R-302 見つかった名前を struct リテラルの頭（型パラメータ `T { x: 1 }`、const パラメータ `M { x: 1 }`、組込みの型の関連定数 `F32.PI { x: 1 }`）と本体の注釈の型の位置（`let _: F32.PI = 1`、`let _: Str.len = 1`、`let _: F32.from_bits = 1`）に書くと、E0308 でなく E0302「cannot find」になる

- 場所: 名前の段の struct リテラルの頭の引き（`names/body/paths.rs` の `item`）と、型の位置の組込みの型の関連の名前の引き（`sig/types.rs::type_of_entity`）が、見つかった名前を「無い」と扱う（推測。W4-04 U8a/b の報告）。
- 内容: §15.1 は「名前は見つかったが、その位置に要る種類でなければ E0308」とする。次の形は名前が見つかるのに E0302「cannot find」になり、文面が偽である。
  struct リテラルの頭の型パラメータ `T { x: 1 }` と const パラメータ `M { x: 1 }`（パターンの `M =>` は E0308）、組込みの型の関連定数 `F32.PI { x: 1 }`。本体の注釈の型の位置の組込みの型の関連の名前 `let _: F32.PI = 1`・`let _: Str.len = 1`・`let _: F32.from_bits = 1`（利用者の型の `let _: P.N = 1` は E0308）。
  前からある（W4-04 U8a の前の `onsa-u7b2` でも同じ）。誤りのあるプログラムが通ることは無いので重大度は低。再現は `issues/R/R-302/found_names.onsa`（const パラメータの注釈の形は R-282）。
- 経緯: 78 回目（2026-10-28）、W4-04 U8a/b（onsa-break）の指摘 6・7。関係: S-103、S-713、R-282。
- 判断: 直す（低）。見つかった名前の E0308 に揃える。W4-04 の U8b（型の位置の残りを扱う単位）で、struct リテラルの頭も一緒に直す。
