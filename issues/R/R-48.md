# R-48 生成する名前が単射でなく、衝突を検査しない

- 高・直す + 仕様へ・観点 1 / 3｜`crates/onsa_sema/src/flow.rs:1224-1243`、`:616`、`crates/onsa_core/src/lower/flow.rs:277`、`lower/mod.rs:225`、`:228`、`:371`、`crates/onsa_backend_c/src/emit.rs:226`、`:552`、`:805`、`export.rs:184`、`:236`、`names.rs:15-29`、`:160-164`｜§2.2、§11.6、S-06、§14.2、§15.3
- 層ごとに、次の衝突がある。
- **状態のフィールド**:
  - 利用者の `let prev_0` と、無名の `prev` が両方 `prev_0` になる。
  - `let poisoned` は検証器で落ちる。
  - `let d_buf` は、C で `delay` のバッファと同じ名前になる。`let bulk` も同じ種類の衝突である。
  - 予約された組込み名（`sample_rate`、`delay` など）を、ローカルで隠せる。
- **Core の型名**:
  - `Option[fn(F32) -> F32]` と `Option[fn(I32) -> I32]` が、同じ `Option__Fn` になる。
  - モジュール `a_b` と `a.b` の同名の struct が衝突する。
- **C の名前**:
  - 既定の `prefix = "onsa_"` で、export の関数 `shr_i8` が、ランタイムの `onsa_shr_i8` と衝突する。
  - 別のモジュールの同名の flow と、flow と関数（`gain` と `gain_init`）が衝突する。
  - タプルの型名が `((I32,I32),I32,I32)` と `((I32,I32,I32),I32)` で同じになる。
  - `let floor` が C の `floor` を隠す。
  - `onsa_` で始まる名前に `_` を足すので、`onsa_version` の export が `onsa_onsa_version_` になる（§14.2 の例と合わない）。
- 直し方:
  - 衝突を sema か build の段で診断する。
  - ランタイムは、利用者が使えない接頭辞（`onsa__`）へ移す。
  - 局所変数は衛生的に改名する。
  - 型名は単射にし、一意であることを検証器で検査する。
- 仕様へ: 予約名の一覧。
- 決定（2026-10-03）: 直す。入出力の名前の衝突は S-30 で解消済み。状態の生成する名前と固定のフィールド名を予約し、`let` の名前に使えないことを仕様に書く。Core の型名は単射にし、C の名前は衛生的に改名する（ランタイムは利用者が使えない接頭辞へ）。
- 判断: 直す。入出力の名前の衝突は S-30 で解消済み。状態の生成する名前と固定のフィールド名を予約し、`let` の名前に使えないことを仕様に書く。Core の型名は単射にし、C の名前は衛生的に改名する（ランタイムは利用者が使えない接頭辞へ）
- 反映: 仕様 §11.6 に反映済み（2026-10-03）。実装は W7-03（予約の名前）、W8-11（Core の型名）、W10-02（C の名前）
