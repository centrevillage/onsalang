# R-241 属性の行の次の、`-` か `^` で始まる行の E0020 の候補が、E0002 を残す

- 場所: `crates/onsa_syntax/src/foreign/lines.rs` の `leading_minus` の行（行頭の前置にもなる記号の E0020）。
- 内容: 属性だけの行の次の行が `-` か `^` で始まると（`@fp(relaxed)` 改行 `-x`）、E0020 を出し、候補は記号を前の行の末尾へ移すか、前の行につなぐ。当てた後も、宣言の位置に `-` があるので、同じ位置に E0002（expected a declaration）が残る。
  前の行が宣言の終わり（`fn g() {}` 改行 `-x`）なら、初めから E0002 になる。属性の行の終わりは、前の行に続く式の終わりではない。再現は `R-241/attr_minus.onsa`、ファズの入力 `tests/fuzz/e6aa2d76.onsa`（`@f` 改行 `^ `）。
- 経緯: X-3/U1c の gate の fuzz が見つけた（ファズ `e6aa2d76`、2026-10-18）。足した事例で変異の組が変わって出た。前からある（U1 の前のバイナリ `0020fe6` も同じ）。
- 判断（2026-10-18、親）: 直さない（実害が低い）。もとの入力も当てた後の入力も宣言の位置の誤りで、当てた後は E0002 が正しい誤りを示す。入力を `tests/fuzz/allowed.toml` に載せる。
