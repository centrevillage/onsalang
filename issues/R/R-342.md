# R-342 flow の本体の関数の呼び出しの `inout`・`move` の引数（`h(inout x)`、`m(move x)`）が誤りなしで通る（§11.2 は E0806）

- 場所: sema（`flow/check.rs` の flow の本体の検査。`plain_args` の E0806 はインスタンスと遅延の引数だけに当たり、普通の関数の呼び出しの引数には当たらない）。
- 内容: §11.2 は flow の本体に書けない形に「`inout` / `move` の引数」を挙げる（E0806）。flow の本体の `let a = h(inout x)`（`h` は `inout` の引数を取る `rt fn`）と `let a = m(move x)` は、誤りなしで通る（入力は `issues/R/R-342/fn_inout_flow.onsa`。dev `96f96382` と W4-12 U2 の後で終了コード 0）。
  インスタンスと遅延の引数の `lp~(inout x)`・`prev~(move x)` は今も E0806。同じ根の R-340（flow の本体の `!` の呼び出しが通る）と同じく、flow の本体の閉じた一覧の判定の抜け。
- 経緯: 94 回目（2026-10-31）、W4-12 U2 の直し（onsa-impl、U2/i2）が、インスタンスの引数の E0806 の後退を調べたときに範囲の外として見つけ、親が再現して登録した。関係: R-340、S-267。
- 判断: 直す（中。誤りのあるプログラムが通る）。E0806 を名前の段で出す W7-04 で、全ての呼び出しの `inout`・`move` の引数を閉じた一覧の外として報告する。W4-12 U2 の名前の段の歩き手は、今の flow の段が E0806 にする所（インスタンスと遅延の引数）でだけ止まる（止めると後の段で何も出ない）。
