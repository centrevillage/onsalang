# R-87 診断の基盤: E0020 の検出が散在し、修正候補に範囲が無い

- 中・直す・観点 2｜`crates/onsa_syntax/src/lexer.rs`（3 か所）、`parser.rs`（約 17 か所）、`fmt.rs:16`、`onsa_cli/src/main.rs:195`、`onsa_tests/src/lib.rs:233`、`crates/onsa_diag/src/lib.rs:47-54`、`token.rs:139-141`｜§18.1、§18.3
- E0020 の検出: 本体の解析経路に混ざっている。第 2 期で外来の書き方を足すたびに、構文解析器を触ることになる。
- 魔法の定数: 「構文エラーか」を番号の範囲（`1..=20`）で判定している。「修正候補が必須か」はテストの文字列の一覧で判定している。どちらも本来、登録簿（`codes.rs`）が持つべき属性である。
- 修正候補の形: 範囲を持たず、診断の表示範囲を置き換えるだけである。
  - E0320 の修正候補は、宣言の名前だけを直す。使用箇所が E0302 になり、修復ループが 1 周増える。
  - LSP の code action は、（範囲、置換文字列）の組の列を要する。
- キーワードの判定: enum の宣言順に依存している。
- 直し方:
  - E0020 の検出を一つのモジュールに集める。
  - `Code` に `is_syntax_fatal` と `requires_fix` を持たせる。
  - `Fix { edits: Vec<(Span, String)> }` にする。§18.1 に JSON の形を書き足す。
- 関連: R-74 の議論で、E0601 の主の位置を最初に `Alloc` を使った箇所に移し、修正候補をシグネチャへの挿入にする案が出た（今はシグネチャが主の位置で、使った箇所は note）。修正候補が範囲を持てるようになるので、この項目と一緒に検討する（2026-10-04）。
- 範囲（2026-10-05 に追加で確かめた）: 修正候補は `replace`・`insert_before`・`insert_after` の 3 種類で、どれも診断の範囲への編集である。仕様の例は `replace` だけで、`insert_*` は計画 §3.1 にだけあった。
  JSON の `span` は複数行のときだけ `end_line` を足し（仕様に無い）、列は文字で数える（単位は仕様に無い）。E0020 は字句解析器に 6 か所、構文解析器に 6 か所で作られている。
  再現は `tests/review-phase1/parent/r87.onsa`（E0320 の候補が宣言だけを直し、E0601 が署名に置かれ、候補が `insert_after` になる）。
- 決定（2026-10-05）:
  - (1) 修正候補は `title` と `edits`（範囲と置き換える文字列の組の並び）を持ち、挿入は空の範囲の置き換え。一つの候補の編集はまとめて当て、ファイルをまたいでもよい（S-81、§18.1）。
  - (2) `span` は `end_line` を常に出し、列は文字（Unicode のスカラー値）で数える。LSP のサーバが LSP の単位に変換する（S-81）。
  - (3) 登録簿に、段と「修正候補が必須か」を持たせ、CLI・fmt・テストはそれを読む（計画 D-04 の追記）。
  - (4) E0020 の検出を一つのモジュールの規則の表に集め、構文解析器は解析に失敗した点で問い合わせる（CST の上で作る）。
  - (5) 複数の箇所を直す修正候補: E0320 は宣言と全ての使用箇所を直し、E0302 は `use` の並びへの挿入（S-74 の候補を実現する）（S-82）。
  - (6) E0601 は、`rt` かどうかによらず最初の使用の位置に置き、`rt` でない関数の修正候補は署名への挿入（S-77 を改めた。R-74 から持ち越した論点の決着）（S-82）。
  - キーワードの判定は、明示の一覧にする（判断は要らない）。
- 判断: 直す。(1) 修正候補は `title` と `edits`（範囲と置き換える文字列）、挿入は空の範囲。(2) `span` は `end_line` を常に、列は文字（S-81）。(3) 登録簿に段と「修正候補が必須か」。(4) E0020 は一つのモジュールの規則の表。(5) E0320 は全ての使用箇所を直し、E0302 は `use` の挿入。
  (6) E0601 は最初の使用の位置に置く（S-77 を改めた、S-82）。再現は `tests/review-phase1/parent/r87.onsa`
- 反映: 仕様 §2.3 / §8.1 / §18.1 に反映済み、計画 D-04 / §3.1 に追記（2026-10-05）。実装は (1)〜(4) W3-02、(5) W4-04、(6) W6-03
