# R-449 署名の段の整形性の検査（`sig::wellformed`）が入れ子の各段で型の要約（`summary::Read::of`）を読み直し、総称の型を深く入れ子にしたフィールドの型で深さの二乗（深さ 240 で 1.4 秒）
