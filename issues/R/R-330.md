# R-330 初期化式に名前の誤りのある `const M: U32 = zz` を配列の長さに使う他の単位に、偽の計算した長さの E0200 が出る

- 場所: 配列の長さの定数を計算する所（計算した長さの E0200、`crates/onsa_diag/src/unsupported.rs` の `ComputedArrayLengths`）。
- 内容: 初期化式に名前の誤りのある `const M: U32 = zz`（E0302）を、他の単位で配列の長さに使う（`let a = [0; M]`、`fn h() -> [I32; M]`）と、使う側に偽の E0200「constants computed by expressions as array lengths」が出る（11:15・15:17）。§18.1 は誤りのある宣言を使う側に診断を出さない。
  型に名前の誤りのある `const N: Nope = 3` を使う側は今も黙る。再現は横の `const_users.onsa`。
- 経緯: 83 回目（2026-10-29）、W4-06 U1/i（onsa-impl）の設計メモが範囲の外として報告した（F1）。前からある。W4-06 は判定を「前の段」にするので、これを増やさない。
- 判断: 直す（低）。W9-03 で長さを計算するときに、循環の定数を読む長さを黙らせる（S-734、W9-03 の `持ち越し`）のと同じく、誤りのある定数を読む長さを黙らせる。
- 補い（2026-11-10、親）: 型の誤りのある初期化式 `const K: U32 = 1.5`（E0401）の定数を長さに使う `[F32; K]` にも、同じ偽の E0200（計算した長さ）が出る（dev `cdc74d99`、131 回目に W5-16 U1c の票を作るときに確かめた）。同じ族で、W9-03 で同じく黙らせる。
