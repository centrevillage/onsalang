# R-273 出力の struct より前に宣言した flow の生成する API が誤る（`g.process` に出力の引数が無く、`g.Out` の大きさが 0）のに `onsa check` が通る

- 場所: `crates/onsa_sema/src/sig.rs` の `lower_all`（def の順に下ろす）と `sig/flow_sig.rs::flow_members`（`boundary_outputs`）。
- 内容: `pub flow g(x: F32 at sample) -> St at sample { … }` の後に `pub struct St { a: F32, b: F32 }` を書くと、`onsa check` は通るが、`onsa interface` では `g.Out` の大きさが 0 で、`g.process` に出力の引数が無い（生成する API が誤る）。
  struct を先に書けば正しい。flow の生成項目を作る時点で出力の struct のフィールドがまだ下りていないと見える（直しの担当の見当）。再現は横の `flow_before_struct.onsa`（dev `49c469b` で親が再現）。
- 経緯: 69 回目（2026-10-25）、W4-03 U3b2 の直しの担当（onsa-impl）が範囲の外で見つけた（前からの挙動）。
- 判断（2026-10-25、親）: 直す（69 回目、利用者が了承）。W4-03 の U5（`sig.rs` を段に分け、flow の生成項目を署名の型の全体の後に作る）で構造として直す。今だけの直しと、U5 までの E0200 は入れない（C-01）。
