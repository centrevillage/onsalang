# R-266 取り込む名前がキーワードや予約語でも、`use std.test`・`use match`・`use kp.clock`・`use clock` が E0002・E0200 にならない

- 場所: `crates/onsa_sema/src/names/imports.rs`（`use` の解決。取り込む名前に宣言の名前の規則を当てる所の候補は `bind`）
- 内容: §15.1 は「並びの各要素と、並びの無い経路の最後の要素は…宣言の名前と同じ規則で読む（キーワードは E0002、予約語は E0200）。`use std.test` と `use match` は E0002、`use kp.clock` と `use clock` は E0200」とする。
  横のディレクトリの `k_use_std_test`（`use std.test`）、`k_use_match`（`match.onsa` と `use match`）、`k_use_clock_last`（`use kp.clock`）、`k_use_clock_head`（`use clock`）は診断なしで終了コード 0（dev `3895f4d` も W4-03 U2a の後も同じ）。
  並びの形の `k_use_clock_list`（`use kp.{clock}`）だけは E0200 になる。
- 経緯: 64 回目（2026-10-25）、W4-03 U2a の壊す側（onsa-break）が見つけた（前からの挙動）。直しは失敗した名前と E0200 を扱う W4-03 の U3b。
