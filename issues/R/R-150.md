# R-150 const パラメータの配列の引数を、const パラメータを持つ関数へ渡すと E0401 になる

- 中・直す・観点 1｜`crates/onsa_sema`（const パラメータの推論）｜§4.5、§6.1
- 内容: `fn f[const N: U32](xs: [U32; N])` の中で `xs` を、const パラメータを持つ別の関数（自分自身を含む）へ渡すと、`expected [U32; ?0], found [U32; N]` の E0401 になる。§6.1 の `mean[const N: U32]` の形から、通るべき。再帰に限らない。
- 経緯: W2-04/t で見つけた（2026-10-08）。再現は `tests/spec/semantics/recursion_generic_const.onsa`（W2-04 で入る）。
- 決定（2026-10-08、親）: 直す。仕様は明確で、判断は要らない。総称の推論を直す W2-06（S-174、R-148）と同じ回に、const パラメータを型の位置の定数として推論する。
- 判断: 直す（親、仕様が明確）。const パラメータの配列の引数を、const パラメータを持つ関数へ渡せるようにする。W2-04/t で見つけた
- 反映: 実装は W2-06
