# R-248 型パラメータに型引数を書く形（`fn f[T](x: T[I32])`）が E0412 でなく E0302 になる

- 場所: `crates/onsa_sema/src/sig/types.rs` の型の位置の型引数の検査（65 行の文面）
- 内容: `pub fn f[T](x: T[I32]) -> I32 { 1 }` は E0302「a type parameter takes no arguments」になる。§4.5 は、型パラメータを持たない項目（総称でない関数、flow、型パラメータ、列挙子の名前）に型引数を書くと E0412 とする。
  S-595 で決めた `Self[…]` の E0412（今は型引数を黙って捨てる）と同じ所で直せる。
- 経緯: 第 40 組の下書き（onsa-gap、2026-10-23、55 回目）が S-595 の確かめで見つけた（族の外、`target/notes/55/gap40/probe/` の m01）。親が dev `8427cf2` の release の `check --json` で再現した。直しは署名の型の W4-05（`Self[…]` の E0412 を担う W4-04 と揃える）。
