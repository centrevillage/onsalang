# R-286 W4-04 U3a の後、同じ単位で後ろの位置の名前の誤り（E0302）が、前の位置の E0806・E0811・E0812・E0821 に勝つ（仕様ではどれも名前の段で、開始の位置の順。実装は後の四つをまだ flow の段で出す）

- 場所: W4-04 U3a で、名前の誤り（E0302）は歩き手が名前の段で出すようになった。flow の本体の制限（E0806）と `~` の有無（E0811・E0812）、flow の外の flow だけの構文（E0821。今の実装は E0812 か E0200）は、まだ型付けと flow の検査が flow の段で出す（`flow/check.rs`）。
- 内容: §18.1（S-267）ではどれも名前の段で、同じ段の中は開始の位置の順で最初のものを報告する。U3a の後は段の順で E0302 が先になり、後ろの位置の E0302 が前の位置の誤りに勝つ。
  例: fn の本体の `let y = g~(1)` の次の行の `let z = nope` は、前は 4 行目の E0812、今は 5 行目の E0302。flow の本体の `let c = fn(q: I32) { nope }` は、前は無名関数の E0806、今は中の `nope` の E0302。
  通るプログラムは変わらず、一つの単位に誤りが二つ以上あるときに、どちらを報告するかだけが仕様と違う。再現は `issues/R/R-286/`（前は dev `7cd8d17`、後は U3a の主のツリーのビルド）。
  壊す側の掃引では、flow の本体の `for`・`while`・`return`・`assert`・式文・`?`・無名関数の中に名前の誤りがある形の約 148 件が当たった（`target/notes/76/w404/u3a/b/`）。代入文だけは歩き手が `Fail::Later` で止めるので前のまま。
- 経緯: 76 回目（2026-10-27）、W4-04 U3a/b（onsa-break）の指摘 2 で、親が再現した。今それだけを守る手当て（歩き手が E0806・E0811・E0812 の形で止まる）は、これらを名前の段へ移す作業で捨てることになるので、足さない（親の判断、利用者に報告した）。
