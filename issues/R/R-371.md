# R-371 閉じていない `[` の `impl` がファイルの最後の項目のとき、E0002 が `[` を指さない

- 場所: 構文の段の回復。§18.1 の括弧の回復
- 内容: `impl S[ {` の後に項目があれば E0002 は「this `[` is never closed」で `[` を指す。`impl` がファイルの最後の項目だと、本体の最初のメンバのトークンを指す「expected an expression, found `pub`」になる。同じ誤りの位置と文面が、後ろの項目の有無で変わる。誤りの数は変わらない。再現は `target/notes/115/w504/u2/probe/last_item.onsa`（`d4fb06d1`）。
