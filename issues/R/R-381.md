# R-381 C の予約語の写し（`default` → `default_`）が単射でなく、フィールド `default` と `default_` の struct の C がコンパイルできない

- 場所: `crates/onsa_backend_c/src/names.rs` の `c_ident`（`C_KEYWORDS` に当たる名前の後ろに `_` を足す）。
- 内容: `pub struct Named { default: U32, default_: U32 }` の `onsa build --target host` は `struct main__Named { uint32_t default_; uint32_t default_; };` を出し、C がコンパイルできない（clang の `duplicate member`）。
  C の予約語を写す `_` の足しが単射でない。他の予約語の名前と、関数と型の名前の写しも同じ形である。入力は `target/notes/118/w522/u3b/c2_main.onsa`。
- 経緯: 118 回目（2026-11-06）、W5-22 U3 の壊す側が見つけた。前からの形で、既定値は関係しない。
- 判断: （2026-11-06、親）中。誤りのない入力で C がコンパイルできない。名前の写しの単射を担う W8-11 で直す。
