# R-173 引数でない位置の `&mut T` の候補を当てると値が変わる

- 中・直す・観点 1｜構文（E0020 の候補）｜§5.2、§18.1
- 内容: `var x: &mut I32 = a` の E0020 の候補は `&mut` を除くだけで、当てると `var x: I32 = a` になり検査を通る。`x = 5` の後も `a` は 1 のまま（書き手の意図では 5）。`var r = &mut a` の候補 `inout a` は当てると E0002。候補が誤りを隠し、S-236 の約束にも反する。
- 経緯: 第 4 組（S-250）の下書きが見つけ、Fable が再現した（2026-10-08）。
- 決定（2026-10-08、親）: 直す。S-250 の決定に従い、引数でない位置の `&mut T` と引数でない式の `&mut x` は候補なしの E0002 と note にする。W3-15 で行う。
- 判断: 直す（親、S-250）。引数でない位置の `&mut T` の候補を、当てると値が変わる形から候補なしの E0002 にする。第 4 組の下書きで見つけた
- 反映: W3-15 で直した
