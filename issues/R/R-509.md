# R-509 候補の約束（§18.1）に触れる前からの構文の段の形 4 件: ブロックコメントの E0020 が後の比の E0002 を隠す、`const` の行頭の比が E0020 の候補の後に残る、型引数の「remove the space」が E0011 を隠す、`p as F32 at sample / 2` の E0011 の候補が E0011 を残す

- 場所: 構文の段の候補（`crates/onsa_syntax/src/parser/failure.rs` の E0020 の表、`groups.rs` の E0011 の候補）。どれも W7-09 U1 の前のバイナリ（`target/base/8cd542a/onsa`）でも同じ。
- 内容: (1) `F32 at sample /* c */ / 4` は E0020「write a line comment」の後に比の E0002 が残る（ブロックコメントが同じ単位の別の誤りを隠す一般の形）。(2) `const C: U32 at sample` 改行 `  / 4 = 4` は E0020「remove the clock」の後に行頭の `/` の E0002 が残る。
  (3) `Option[F32 at sample / a .b]`・`Option[F32 as U32 / a .b]` は E0020「remove the space」が E0011 を隠す（クロックと関わらない）。(4) `p as F32 at sample / 2` は E0011「parenthesize the inner one」の後に E0011 が残る。
  どれも誤りのプログラムで、当て続ければ止まる（候補の後に残る誤りがもう一つ出るだけ）。再現の入力は `target/notes/172/w709/u1/r509/`。
- 経緯: 172 回目（2026-11-21）、W7-09 U1/b（onsa-break）と U1/i2（onsa-impl）が導くクロックの候補を確かめる中で見つけた。親が登録した（利用者の離席中。直す作業は利用者が決める）。
- 判断: 2026-11-21、利用者（172 回目）: W7-17 で直す（W7 の低の持ち越しを集める作業。誤りのプログラムにしか出ず、いつ直しても手戻りが無い）。
- 反映: 2026-11-26、W7-17 L2（188 回目）: (4) を直した（`crates/onsa_syntax/src/groups.rs` の `unchained`・`operand_casts`。二項の被演算子と範囲の端の連鎖は一つの E0011 で、内側の括弧も入れた一つの候補。S-1078 の二つ目の候補にも内側の括弧。事例 `tests/spec/fixes/e0011_chain_*`）。
  (1)・(2) は元の単位に誤りが二つの形で候補の約束（S-236）の外なので今のまま、(3) と変種は報告の順の細部 S-1253、行頭の `/` の揃えは R-524（細部 S-1255）。連鎖の二つ目の候補は細部 S-1254、壊す側の見つけた範囲の端の和と根でない `/` は細部 S-1257・S-1258。
