# R-122 パッケージの `tests/` の役割が仕様に無い

- 低・要判断・観点 3｜`crates/onsa_driver/src/lib.rs`（モジュールの収集）｜§15.1「`tests/` と `target/` を除く」
- 内容: §15.1 はモジュールを集めるときに `tests/` を除くとだけ書き、何のための場所かを決めていない。`onsa test` が読むのかも決まっていない。
- 判断（R-122）:
  - (a) 結合テスト・機能テストの場所。パッケージの外から `pub` の項目だけを使う別のパッケージとして、`onsa test` が実行する（S-37 の後は `use <パッケージ名>.<モジュール>` で参照する）。
  - (b) テスト用のデータ（WAV など）の置き場として予約するだけで、Onsa のファイルは読まない。
  - 利用者の見立ては (a)。設計（依存の解決、`onsa test` の実行の単位、テスト用のデータとの関係）を詰めてから決める。
- 経緯: R-68 の議論で見つけた（2026-10-04）。
- 経過（2026-10-05）: R-88 の決定で、役割は std 以外の依存と一緒に第 2 期で決めることになった（結合テストのパッケージは親へのパスの依存を前提にする。仕様 §19.1）。ここでは第 1 期の扱いと文言を決めた。
- 範囲（2026-10-05 に追加で確かめた）:
  - パッケージルート直下の `tests/` の `.onsa` は、モジュールの収集から黙って除かれる。失敗するテストと構文の誤りを含む `tests/api.onsa` を置いても、`onsa check` は何も出さずに成功し、`onsa test` はそのテストを実行せずに「1 passed, 0 failed」で終了コード 0。
  - 除くのはルート直下だけで、`dsp/tests/n.onsa` は普通のモジュール `dsp.tests.n` として集められ、テストも実行される。§15.1 の「`tests/` を除く」は範囲が曖昧だった。
  - 再現は `tests/review-phase1/parent/r122/`。
- 決定（2026-10-05）: S-96。
  - (1) 第 1 期は、ルート直下の `tests/` に置いた `.onsa` を、モジュールを集めるコマンド（`check`、`test`、`build` など）と LSP で E0200 にする（(a)）。`.onsa` でないファイルは読まない。黙って除くと、Rust の習慣で書いた結合テストが一度も実行されないまま `onsa test` が成功する。第 2 期で役割を決めても、E0200 だったものが動くようになるだけで、既存のコードの意味は変わらない。
  - (2) §15.1 に「パッケージルート直下の `tests/` と `target/`」と明記した。それより深い `tests/` は普通のモジュールのディレクトリ。
  - (3) 第 2 期に役割を決めるときの問い:
    - 実行の単位: `tests/` 全体で一つのパッケージか、ファイルごとか。ファイルごとなら、共通の補助をどこに置くか。
    - 依存: 親のパッケージへの暗黙のパスの依存。テストだけが使う依存を設けるか。
    - 見える名前: 親の `pub` だけ。S-36 で無指定はパッケージ内なので、外から使えるかの確認になる。
    - `onsa test`: 既定で中のテストと `tests/` の両方を実行するか。テストの名前の形（S-55 の `dsp.voice "decays"` に対応するもの）。
    - テスト用のデータ: 置き場と読み方（`Fs` の効果をテストで許すか、`const` に埋め込むか）。参照の WAV と比べる補助（`std.dsp.test`）。
    - 前提の確認: 外からのテストが Onsa で要る用途（`pub` の API の確認、長い機能テストの分離）を実例で確かめる。S-36 で可視性の既定がパッケージ内なので、Rust とは中のテストから見える範囲が違う。
- 判断: S-96: 役割は R-88 の決定どおり第 2 期に std 以外の依存と一緒に決める。それまで、パッケージルート直下の `tests/` の `.onsa` はモジュールを集めるコマンドと LSP で E0200（黙って除くと、Rust の習慣で書いた結合テストが実行されないまま `onsa test` が成功する）。
  除く範囲はルート直下の `tests/` と `target/` と明記。第 2 期に決めるときの問いを本文に集めた。再現は `tests/review-phase1/parent/r122/`
