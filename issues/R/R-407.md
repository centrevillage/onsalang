# R-407 定数式の位置（配列の長さ、型引数の const 引数、繰り返しの数）の、見えている const パラメータの後の `.`（`[F32; N.K]`、`Ring[F32, N.K]`、`[x; N.K]`）が「cannot find `N`」の E0302 になる

- 場所: 未確認（定数式の名前の引き方。`constarg`・`sig/` の定数式の枝の見込み）。
- 内容: `fn l2[const N: U32](x: [F32; N.K])`、`Ring[F32, N.K]`、`[x; N.K]` は E0302「cannot find `N`」。§5.1 では `N` は見出しの全体と本体で見えるので、「見つからない」は合わない。同じ位置の `T.BITS`（`T: Int`）は E0417。定数式の `N.K` がどの誤り（E0308・E0417 など）かは §4.5 が決めていない。
  型・境界・効果行の位置の `N.K` は W5-11 U10e（R-404）で E0308 になった。誤りのあるファイルの文面とコードだけ。前から（dev `55162a4e` も同じ）。入力は `target/notes/125/w511u10e/break/`（`b11`・`b30`・`b37`）。
- 経緯: 125 回目（2026-11-08）、W5-11 U10e/b（onsa-break）の F2。親が U10e のバイナリで再現した。
- 判断:
- 判断（2026-11-08、親）: W5-13 へ送る（利用者が了承、125 回目）。定数式の位置の `N.K` のコード（E0308・E0417 など）を S で決めてから直す
- 補い（2026-11-08、親）: W5-11 U10f の実装の担当が、効果行変数の後の `.` の定数式の位置（`[F32; e.K]`）も同じく「cannot find `e`」の E0302 になることを見つけた（`constarg` の経路、同じ族）。入力は `target/notes/125/w511u10f/c.onsa`
- 反映（2026-11-10、親）: S-967（値の項目の後の名前は位置によらず E0417）で決まり、W5-16 U1b2（`0fde81c6`）で `[F32; N.K]`・`Ring[F32, N.K]`・`[x; N.K]` が E0417 になった（131 回目の文書の点検が見つけ、親が dev `dec4cd5a` で再現した）。事例は `tests/spec/types/const_after_value_generic.onsa` の const パラメータの `M.x`。
