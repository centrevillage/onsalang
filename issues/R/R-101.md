# R-101 字句・fmt の、報告されていない細則

- 低・要判断・観点 3｜`crates/onsa_syntax/src/lexer.rs:81`、`:429-435`、`parser.rs:314-328`、`:1192`、`:1406`、`:1621`、`fmt.rs:820-848`｜§2、§18.2
- 識別子: ASCII だけ。`let 音 = 1` は E0001 になる。
- doc コメント:
  - `////` は普通のコメントになる。
  - `///` は、空行や普通のコメントを挟んでも次の項目に付く。
- `=` の整列: `var` も含む。型注釈の付いた `let` で列が切れる（S-07 は「連続する 1 行の `let`」としか書いていない）。
- 空白: `xs [0]` は E0002 だが、`f (x)` は呼び出しとして通る。
- `return` / `break` / `continue`: 文としてだけ書ける。`None => return 0,` は、修正候補の無い E0002 になる。Rust から来た書き手がよく書く形である。
- 推奨: いずれも仕様に書く。
  - 識別子は ASCII だけとする。
  - doc は、空行を挟んだら付かないことにする。
  - `f (x)` は E0002 にする。
  - `=> return 0` は E0020 にし、`=> { return 0 }` を示す。
- 範囲（2026-10-05 に追加で確かめた）:
  - doc コメントが空行や `//` を挟んでも付くことは、R-63（S-51）で §2.1 に書かれている（元の推奨の「空行を挟んだら付かない」は、その決定より前のもの）。
  - 後置の括弧の前の空白: `xs [0]`、`Option [I32]`、パターンの `Some (x)` は修正候補の無い E0002。`f (x)`、宣言の `fn f (x: I32)`、`fn f[T] (x: T)` は通る。括弧の中では改行も空白なので、`h(h⏎(x))` は `h(h(x))` と読む。属性と `pub(...)`、ハンドラの引数は前から空白を許さない。
  - 整列: `let a = 1`、`var bb = 2`、`let ccc: I32 = 3` と並べると、型注釈の行で列が切れる。
  - 再現は `tests/review-phase1/parent/r101/`（形ごとのファイル。期待値と今の出力は各ファイルの先頭のコメント）。既存の `syntax/ret_arm.onsa`、`syntax/space_idx.onsa` も同じ。
- 決定（2026-10-05）: S-89。
  - (1) 識別子は ASCII の英字・数字・`_` だけ（E0001）。命名規則が大文字と小文字で種別を決めるので、大文字・小文字の無い文字では決まらない。
  - (2) doc の付き方は S-51 のまま。`/` が 4 つ以上続く行は普通のコメント。
  - (3) fmt は連続する 1 行の `let` と `var` の `=` を全て揃える（型注釈の付いたもの、分解するものも含む）。
  - (4) 並びを開く後置の `(` と `[` は前のトークンの直後に書き、空白は E0020（修正候補は空白の除去。`xs [0]` には `xs([0])` も）。
    元の推奨は `f (x)` を受理して fmt で揃える案だったが、利用者の判断で誤りにした: 配列と規則が揃い、そう書く書き手は引数の括弧を省ける言語（Ruby など）のつもりで `f` と `(x)` を別々に並べた可能性があるので、構文の誤りにする方が親切。
    括弧の中でも、改行の後の `(` と `[` は前に付かない（`,` の無い二つの要素として E0002。修正候補は `,` の挿入と改行の除去）。
  - (5) 腕の `return` / `break` / `continue` は E0020（修正候補はブロックで囲む形）。これらは文のままにする（式にすると腕の書き方が二つになる）。
- 判断: S-89: 識別子は ASCII だけ（E0001）。`////` は普通のコメント（doc の付き方は S-51 のまま）。fmt は 1 行の `let` と `var` の `=` を全て揃える。並びを開く後置の `(` と `[` は前のトークンの直後に書き、空白は E0020（`f (x)` も誤り。利用者の判断）、括弧の中の改行の後は `,` の無い要素として E0002。
  腕の `return` は E0020（修正候補はブロック）。再現は `tests/review-phase1/parent/r101/`
- 反映: 仕様 §2.1 / §2.3 / §2.5 / §7 / §18.1 / §18.2 に反映済み（2026-10-05）。実装は W3-04、W3-06、W3-11
