# R-317 型パラメータが入れ子の奥にある引数（`G_{k-1}[Option[T]]`、`[T; 1]`、`(T, T)`）は、環境で閉じても宣言の答えを覚える鍵にならず、一段ごとに前の段を二度持つ総称の鎖（18 段）で種・配置・破棄の要否が予算に当たって答えなしになる

- 場所: `crates/onsa_sema/src/walk.rs` の `Walk::remember`（鍵は、引数を環境で最上位だけ解いた型が全て閉じたときに作る）と `ty.rs` の `Types::open`（intern したときの形で決まる）。
- 内容: `struct G_k[T] { x: G_{k-1}[Option[T]], y: G_{k-1}[Option[T]] }` の 18 段と `struct H { g: G18[F32] }`（横の `nested_open.onsa`）は、`interface` が `H` に種も配置も出さない（W4-05 U2b の前も後も同じ）。
  引数 `Option[T]` は、環境で `T` が `F32` に決まっても intern の形では開いているので鍵にならず、宣言を問うたびに辿って歩数の予算 `STEPS` に当たる。引数が `T` のままなら、U2b の後は 24 段まで答えが出る。開いた引数だけの入れ子（U1/b の F4 の形の総称だけの鎖）は、深さの上限も効く。
  今は分からない種を Affine でないとみなす（R-30）ので実害は無いが、W4-16 で Affine にすると正しいプログラムが誤りになる。直すには、引数を環境の下で置き換えた閉じた型を鍵にする（歩きの中で intern する手立てが要る）。
- 経緯: 80 回目（2026-10-28）、W4-05 U2b の壊す側（指摘 2）。前からある。親が `onsa-728ebb7` と U2b の後のビルドで再現した。
- 判断: （2026-10-28、親）W4-16 で分からない種を Affine にする前に直す。
- 反映（2026-10-30、親）: W4-16 U3（`0fec18fd`、85 回目）: 覚える鍵に環境に対する鍵と本体の型パラメータの種の並びに対する鍵を足し、項目を求め終えたらその下の鍵を捨てる。`nested_open.onsa` の `H` は `interface` で Copy と大きさが出る。事例 `tests/spec/types/kind_nested_generic_deep.onsa`。
