# R-196 型の位置の中の `[…, …]` に式の型引数の候補を出す

- 低・直す・観点 1｜構文｜§4.5、§18.1
- 内容: W3-19 の `,` を含む `[…]` の行（式の中の型引数を `name::[…]` にする E0020）が、型の位置の中（`type R = e[t[[], l]` の `t[…]`）でも当たり、`::` を挿入する候補を出す。型の位置に `::[` は書けないので、当てると同じ箇所に E0020 が残り、§18.1 の約束（S-236）を破る。行の文脈の判定で、型の位置を除く。
- 経緯: W3-18 の gate のファズが見つけた（2026-10-09、`fix-same-place: fix|E0020|write the type arguments as ...|E0020`。保存した入力 `tests/fuzz/82d90c5e.onsa`、種 `tests/spec/nesting/types.onsa`）。
- 決定（2026-10-09、親）: 直す。W3-20（K-23）で行う。
- 判断: 直す（親、S-236）。W3-19 の `,` を含む `[…]` の行の候補を、型の位置の中では出さない（`type R = e[t[[], l]` に `::` の挿入の候補が出て、当てた後に E0020 が残る）。W3-18 の gate のファズが見つけた。保存した入力 `tests/fuzz/82d90c5e.onsa`
