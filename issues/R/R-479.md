# R-479 出力の型が「分からない」flow（出力が誤りの型か E0810）の `process`・`render` の呼び出しに、出力の引数の無い形の引数の数の E0412 が続く（`-> [F32; 0] at sample` の `m.process(inout s, a, inout o)`）

  誤りの型と空の struct の出力は前から同じで、長さ 0 は W7-12 U2a の E0810（S-1110）で同じ形になった。再現は `target/notes/160/w712/u2a/b/c35.txt`。

- 判断: 直す（低）。W7-12 U3 で `process`・`render` の引数の形を作り直すときに、出力が分からない flow の呼び出しを黙らせる。
