# R-54 借用引数からの `let y = x`（Affine）が E0711 になる

- 中・直す・観点 1 / 2｜`crates/onsa_sema/src/modes.rs:330`、`body.rs:2453`｜§5.4 の表（借用引数からは借用束縛）
- 再現: `fn f(b: Buf[F32]) -> U32 { let c = b; c.len() }` と `let b = h.buf` が E0711 になる。
- 原因: 本体の検査器は借用束縛と判定するのに、modes は消費位置として扱う。所有の判定の重複（R-85）が根である。
- 決定（2026-10-03）: 直す。仕様の空白（§5.2 と §5.4 の文言、分解する `let`、派生の起点、`inout` 引数）は S-41 で埋めた。議論の中で R-117 と R-118 を見つけた。
- 判断: 直す（R-85 と一緒に、所有の状態を一つにして全ての段が参照する）。S-41: §5.2 に借用束縛は消費しないと書き足す。借用の起点は借用引数（既定のモードと `self`）と借用の `for` の束縛で、派生した借用束縛も起点になる。`inout` 引数は起点にならない。分解する `let` は元が起点なら借用束縛
- 反映: 仕様 §5.2 / §5.4 に反映済み（2026-10-03）。実装は W4-16（X-8 の第二弾で W4-07 から分けた）
