# R-128 `Num` / `Float` が `Copy` を含むことが、仕様に無い

- 中・要判断・観点 3｜`crates/onsa_sema/src/body.rs:2772-2773`（`implies`）｜§6.3（S-46）、`impl-review` T-2
- 内容: 実装は `T: Num` と `T: Float` が `Copy` の境界を満たすとする。`need_copy[U: Copy]` に対して `fn via_num[T: Num](x: T) -> T { need_copy(x) }` が通り、同じ形の `T: PartialEq` は E0416 になる（2026-10-04 に確かめた）。
  §6.3 の `Num` の中身（S-46）に `Copy` は無い。`impl-review` T-2 はこの含意を「仕様へ」としたが、反映されていなかった。
- 判断（R-128）: (a) `Num` は `Copy` を要する（仕様に書く）。(b) 要さない（実装を直す）。推奨は (a)。
- 決定（2026-10-04）: (a)。S-73。理由: 数の型は値として扱う（Q15 / Q31 も Copy の struct）。(b) では、総称の数値のコードを rt で書くたびに `T: Num + Copy` と重ねることになる（P10）。Copy でない数（任意精度など）は用途が見えない。実装は今のまま。再現は `tests/review-phase1/parent/r128.onsa`。
- 判断: (a) `Num` は `Copy` を要する。S-73（`Float` は `Num` を通じて含む。実装は今のまま。`impl-review` T-2 の未反映を解消）。再現は `tests/review-phase1/parent/r128.onsa`
