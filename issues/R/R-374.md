# R-374 パターンの頭の型パラメータ（`T.ZERO =>`）の E0302 が「cannot find `T`」で、見つかる名前を見つからないと言う

- 場所: 名前の段のパターンの経路（`crates/onsa_sema/src/names/`）。§7、§15.1
- 内容: `T: AnyNum` の `match x { T.ZERO => … }` は E0302「cannot find `T`」である。`T` は見つかる名前で、W5-05 U3 の後も式の経路だけが `T` を引くならこの文面のまま残る。`I32.MAX =>` の「is not a variant」と揃えるのが §7 の読みである。コードは変わらず、通るプログラムも変わらない。
- 経緯: 116 回目（2026-11-05）、W5-05 の設計メモの独立の審査（onsa-advisor）が見つけた。文面だけなので W5-13 の見直しで扱う。
- 判断: 直す。文面だけで優先は低い。
