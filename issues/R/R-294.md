# R-294 仕様にある組込みの型の関連の名前のうち、この版が扱わないもの（`I32.default()`・`Str.from_utf8(b)`・`F32.ZERO`）が、§18.1 の E0200 でなく E0302「cannot find」になる

- 場所: 名前の段の組込みの型の後の名前（`names/body/paths.rs::builtin_assoc`）。関連関数の有無は `builtin::has_assoc_fn`（中身は `assoc_fn_row`）、関連定数は `has_assoc_const` で引き、どちらの表もこの版が実装した名前だけを持つ。
- 内容: 仕様は `Default` の `I32.default()`（§6.3）、`Str.from_utf8(b)`（§4.2 の表）、数の関連定数 `F32.ZERO`・`I32.ONE`（§6.6 の表）を定めるが、この版はまだ扱わない。
  §18.1 は、仕様にあってコンパイラがまだ扱えない形を E0200 にするとするが、今は E0302「cannot find `default`」になり、名前が無いと言う。W4-04 U5 の前は E0413「`I32.default` does not exist」で、どちらも E0200 でない（定数の形は前から E0302）。
  通るプログラムは変わらない（どの形も落ちる）。再現は横のディレクトリの `default.onsa`・`from_utf8.onsa`（U5 の後と、前の dev `e741747`）。
- 経緯: 77 回目（2026-10-27）、W4-04 U5/b（onsa-break）の指摘 2。U5 で名前の段が関連関数の表を見るようになり、コードが E0413 から E0302 に変わって目立った。
- 判断: 直す。組込み型のメソッド・関連関数・関連定数を std の宣言にする W5-02 で、仕様の名前を全て表に載せ、この版が扱わないものを E0200 にする（扱う作業は W5-03・W5-05・W5-06）。
