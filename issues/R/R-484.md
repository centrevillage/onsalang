# R-484 借用の `match` の腕などで作った Copy でない借用束縛（派生元の場所を指す、S-796）を、降下が腕の中へ値で写すので、インラインの配列のビュー（`take(match o { Some(h) => h.xs.slice(0, 2), None => … })`、`o: Option[G[T]]`）が腕の中の写しを指して腕の外で読まれる

- 場所: Core の降下の借用束縛（腕の束縛と `let` の借用束縛を値で写す。`main__G__F32 h = (*o).u.v_Some.f0;`）。
- 内容: 言語の意味では、Copy でない借用束縛は派生元の場所を指す（S-796、§5.4）ので、そのビューを腕の外で読む形は正しい。降下は束縛を腕の中のローカルへ値で写し、ビューはその写しを指すので、生成した C は腕を出た後に読む（未定義の動作）。
  形: `take(match o { Some(h) => h.xs.slice(0, 2), None => y.slice(0, 2) })`、`take(if c { let h2 = x … h2.xs.slice(0, 2) } else { … })`、`let s = match o { Some(h) => h.xs.slice(0, 2), … }`、`take_in(match o { Some(h) => pair.In { l: h.xs, r: y }, … })`（`struct G[T] { xs: [F32; 4], t: T }`、境界の無い `T`）。今は全て通る。
  今 C に届くのは総称だけ（`Buf`・`Str` はこの版の C の後端が E0200）。それらが C に入ると、Shared のフィールドとインラインの配列を持つ struct・タプルに広がる。
  再現は `target/notes/161/w712/u2c/audit2/`（`in/c2/main.onsa`、C は `out/c2/onsa_cprobe.c` の `main__arm_inline_derived__F32` ほか）。
- 経緯: 161 回目（2026-11-17）、W7-12 U2c の決定の文の見落としの監査（onsa-advisor）が見つけた。親が C を読んで再現した。
- 判断: 直す（高、生成した C の未定義の動作）。今は W7-12 U2c2 で、R-481 の「入るまでは E0200」を、腕の外へ出るビューが腕の中で宣言した記憶域（値で写した借用束縛を含む）を指す形の一つの判定に広げる。降下で Copy でない借用束縛を派生元の場所の参照にする直し（写しも減る）は W8 の降下の作業で行う。
