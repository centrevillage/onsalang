# R-262 E0320 の候補が識別子でない（`struct _0`・`enum C { _0 }`・`const _0` の候補が `0`）

- 場所: `crates/onsa_syntax/src/naming.rs` の候補の作り方（`convert`・`split_words`）｜§2.3（E0320 の候補）、§18.1（候補を当てた後の約束）
- 内容: `_` の後が数字の名前（`_0`）の型・列挙子・定数の E0320 の候補が `0` で、識別子でない（当てると E0002 などの字句か構文の誤りになる）。値の `_0` は通る。
  `struct _0 { x: I32 }` は「replace `_0` with `0`」（dev `fdc4fa5`、`P62/pcheck52/z.onsa`。62 回目の scratchpad）。§18.1 は約束を満たす候補を作れなければ出さないとするので、候補を出さないのが仕様の形である。
- 経緯: 62 回目（2026-10-24）、族「§2.3 の名前の形」（S-650、第 52 組）の下書き（onsa-gap）が見つけ、親が再現した。`_0` を名前と認めるかは S-650（S-651）の決め方による。直すのは W4-14 U3（R-260 と同じ所）。
- 判断:
- 反映（2026-10-24、親）: W4-14 U3（63 回目）で直した: 規則に揃えた名前が識別子にならない名前（`_0`・`_1`・`__`）は候補なし。事例 `tests/spec/negative/naming_no_candidate.onsa`
