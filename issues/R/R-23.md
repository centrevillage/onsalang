# R-23 `std.dsp.sum` が 0.0 から畳む

- 低・直す・観点 1｜`std/dsp.onsa:7-12`｜§11.8「`xs[0]` から順に左へ畳む」
- 影響: `-0.0` だけを足すと `+0.0` になり、仕様どおりに書いた変換先とビットが一致しない。
- 直し方: `xs[0]` から始める。`N = 0` の場合を仕様に足す。
- 決定（2026-10-03）: `sum` を `std.math.sum[T: Num + Default, const N: U32](xs: [T; N]) -> T` にする（境界と `N = 0` の値は R-56 / S-46 で `[T: Num]` と `T.ZERO` に改めた）。
  `N = 0` なら `T.default()`、それ以外は `xs[0]` から順に左へ畳む（仕様の順を保ち、全て `-0.0` なら `-0.0`）。整数にも使え、`Default` の無い型には使えない。数の計算なので `std.dsp` から `std.math` へ移す（境界も `abs` / `min` / `max` と同じ `Num`）。
- 判断: `sum` を `std.math.sum[T: Num + Default, const N: U32](xs: [T; N]) -> T` にする（境界と `N = 0` の値は R-56 / S-46 で `[T: Num]` と `T.ZERO` に改めた）。`N = 0` なら `T.default()`、それ以外は `xs[0]` から順に左へ畳む（仕様の順を保ち、全て `-0.0` なら `-0.0`）。
  整数にも使え、`Default` の無い型には使えない。数の計算なので `std.dsp` から `std.math` へ移す（境界も `abs` / `min` / `max` と同じ `Num`）
- 反映: 仕様 §11.5 / §11.8 / §13.4 に反映済み（2026-10-03）。実装は W5-07（総称の中で `T.default()` を呼ぶ R-60 の後）
