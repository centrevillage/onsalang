# R-147 flow の名前空間に無い項目の参照が E0302 にならない

- 低・直す・観点 1｜名前の段（flow の名前空間の経路）｜§15.1、§11.6
- 内容: `process_inplace` を生成しない flow に `voice.process_inplace(...)` と書くなど、flow の名前空間に無い項目を指すと、今の実装は E0401（「`more_fields` is a flow; outside a flow body use its namespace」）を出す。§15.1 の一般則では、見つからない名前は E0302。
- 経緯: W2-11/t で見つけた（2026-10-08）。再現は `tests/spec/negative/flow_inplace_absent.onsa`（W2-11 で入る）。
- 決定（2026-10-08、親）: 直す。仕様は明確で、判断は要らない。flow の名前空間の経路を解決する名前の段（W4-04）で、無い項目を E0302 にする。生成する項目の一覧（`process_inplace` の有無）は W7-03。
- 判断: 直す（親、仕様が明確）。flow の名前空間に無い項目の参照を E0302 にする。W2-11/t で見つけた
- 反映: 実装は W4-04（生成する項目の一覧は W7-03）
- 補い（2026-10-24、親）: 61 回目（2026-10-24）、S-625 で Onsa の生成する API から `params_default` を外したので、W7-03 の後の `g.params_default()` も名前空間に無い項目の参照（E0302）になる。第 50 組の試した入力 `p/d2`（`@param` の無い `block` の入力がある flow の `g.params_default()` が E0401）と同じ所。
- 補い（2026-10-25、親）: 69 回目: `process_inplace` の有無（型で決まる）は W4-03 U3b2 で入った（S-694）。残るのは `Out`・`Config`・`Params` の有無（R-264）と、名前空間に無い項目の文面（`g.SIZE` の E0401 など）。
- 補い（2026-10-26、親）: 74 回目: 型で無いと決まった生成項目を本体の経路で引く形（`one.process_inplace(…)`）の S-707 は、この判断と同じ E0302 に決めた（確認だけ）。
- 反映（2026-10-27、親）: W4-04 の分は済んだ。
  flow の名前空間に無い名前（`g.nosuch(1)`、型で無いと決まった `one.process_inplace`）は名前の段の E0302（U3a から。U5 `446bc1e` で事例 `tests/spec/negative/flow_namespace_absent_names.onsa`）。`flow_inplace_absent.onsa` の E0302 の 5 か所も合い、残る落ちは 64 行の生成の条件で W7-03
