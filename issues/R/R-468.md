# R-468 効果行に、取り込んでいない既にある module の経路で効果を書いた（`uses {m.Random}`、E0302「named only through a `use`」）とき、行が開かず、失敗した名前だけが原因の E0601 が残る

- 内容: §18.1 は効果行に見つからない名前（E0302）も失敗した名前と同じに扱い、行を開き、指しえた効果（経路の最後の名前と同じ名前の効果）を足りない効果に数えないとする（S-691、S-1062）。存在しない module の経路 `uses {kp.Random}` はそうなるが、存在する module `m` を `use` せずに書いた `uses {m.Random}` は、E0302（cannot find `m`: named only through a `use`）の後に行が開かず、その関数型を受ける呼び手に E0601 が残る。std の `Random` でも利用者の `effect` でも同じ。通るプログラムは変わらない（E0302 が別にある）。
