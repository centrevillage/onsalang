# R-335 `Str` のフィールドを持つ struct の値の `inout` 引数のフィールドへの代入と読みが、降下で内部エラー「no field」になる（E0200 でない）

- 場所: `crates/onsa_core/src/lower/mod.rs` の型の写し（493〜510 行の近く。`type_ids` に `Opaque` の仮の型を先に入れ、フィールドの型の降下が `Str` の E0200 で失敗すると仮の型が残る）と、`lower/build.rs::field_by_name`（63 行の内部エラー）。
- 内容: 第 1 期は `Str` を持つ関数の `test` と `build` が E0200 である（`tasks/phase2.md`）。`pub struct P { a: Buf[F32], n: U32, s: Str }` の `inout p: P` を受ける関数の本体の `p.n = 3` と `p.n` を降下すると、E0200 でなく「internal lowering error: no field `n`」になる（`onsa test` と `onsa dump --core`）。`Str` のフィールドを外すと通る。
  再現は横の `str_field_inout.onsa`（dev `98ffc611`）。壊す側は、借用の配列の `for p in ps { t = t + p.n }` も同じ内部エラーになると報告した。異常終了ではない。
- 経緯: 91 回目（2026-10-31）、W4-09 U2 の壊す側（onsa-break）が範囲の外の前からの挙動として報告した。親が dev のバイナリで再現した。
- 判断: 直す（中。正しいプログラムが内部エラーになる。`rules/leader.md` 4.5 で内部エラーは許可の一覧に載せない）。W8-01 の「変換先によらない未対応の検出を降下の前の一つの段に寄せる」で、`Str` を含む型の E0200 を降下の前に出す形にする（仮の型が残る道を無くす）。
- 経緯（2026-10-31、親）: 関係: R-332（同じ「no field」の内部エラー、`Str` のフィールドを持つ struct。同じ W8-01）
