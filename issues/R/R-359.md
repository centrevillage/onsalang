# R-359 期待する関数型が純粋な無名関数の本体の `Alloc` が、外側の関数の効果行に `Alloc` があると黙って通る（§8.1 の「外側の関数の効果行には数えない」）

- 場所: 効果の集計（`crates/onsa_sema/src/effects.rs`。無名関数の本体の `Alloc` の使用を、外側の関数の効果行で判定している見当。W6-03 が作り直す、R-83 の (2)）。
- 内容: §8.1 は「無名関数は、期待する関数型の効果行と `rt` に照らして本体を検査する。期待する型が純粋なら、本体で `Alloc` を使えない（外側の関数の効果行には数えない）」とする。`bff9c843` では、外側の関数が `uses {Alloc}` のとき、純粋な関数型の引数（`f: fn(move E) -> F`）に渡した無名関数の本体の `Samples.zeroed(1).len()` と `uses {Alloc}` の関数の呼び出しが、E0601 にならず通る（終了コード 0）。
  外側に `uses {Alloc}` が無ければ E0601 になる。
  再現は `issues/R/R-359/outer_row.onsa`（`map_err` と同じ型の利用者の関数で書いたもの。印の行が期待の E0601）。W5-02 U6 の事例 `tests/spec/negative/map_err_effects_outer_row.onsa` が同じ形を持ち、W6-03 まで実装待ちに置く。
- 経緯: 109 回目（2026-11-03）、W5-02 U6/t（onsa-test）が見つけ、親が `bff9c843` のバイナリで再現した。前からある。関係: R-83、S-77
- 判断:
- 補い（2026-11-13、親）: 第 99 組（S-1032）の独立のレビューの段 1（146 回目）が、効果行を持たない本体を経る形を挙げた（親が再現）: `const F: fn(I32) -> I32 = { let l = fn(y: I32) -> I32 { bump(y) }` 改行 `l }` とフィールドの既定値の同じ形が今通り、純粋な関数が `F.(1)` で確保する（初期化式は `Alloc` を与えられる、§6.6）。入力は `target/notes/146/g99/advisor/probe/a1.txt` の `const_block_closure`、`a4.txt` の `field_default_block_closure`。直接書いた形（期待型あり）も通る。W6-03 のテストに `const` と既定値の形を入れる材料。期待型の無い無名関数の扱いは S-1032。
