# R-359 期待する関数型が純粋な無名関数の本体の `Alloc` が、外側の関数の効果行に `Alloc` があると黙って通る（§8.1 の「外側の関数の効果行には数えない」）

- 場所: 効果の集計（`crates/onsa_sema/src/effects.rs`。無名関数の本体の `Alloc` の使用を、外側の関数の効果行で判定している見当。W6-03 が作り直す、R-83 の (2)）。
- 内容: §8.1 の 35 行は「無名関数は、期待する関数型の効果行と `rt` に照らして本体を検査する。期待する型が純粋なら、本体で `Alloc` を使えない（外側の関数の効果行には数えない）」とする。`bff9c843` では、外側の関数が `uses {Alloc}` のとき、純粋な関数型の引数（`f: fn(move E) -> F`）に渡した無名関数の本体の `Samples.zeroed(1).len()` と `uses {Alloc}` の関数の呼び出しが、E0601 にならず通る（終了コード 0）。
  外側に `uses {Alloc}` が無ければ E0601 になる。
  再現は `issues/R/R-359/outer_row.onsa`（`map_err` と同じ型の利用者の関数で書いたもの。印の行が期待の E0601）。W5-02 U6 の事例 `tests/spec/negative/map_err_effects_outer_row.onsa` が同じ形を持ち、W6-03 まで実装待ちに置く。
