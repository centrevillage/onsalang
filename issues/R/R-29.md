# R-29 `for … in move xs` が、正しい例を拒否し、誤った例を通す

- 高・直す・観点 1｜`crates/onsa_sema/src/modes.rs:350-353`、`:662-665`｜§5.4
- 正しい例を拒否する: `for b in move xs { take(move b) }` が E0704 になる。ループ変数を、外側の変数と誤って判定している。
- 誤った例を通す: `xs` が移動済みにならないので、ループの後の `xs[0].len()` が通る。
- 決定（2026-10-03）: 直す（`for … in move xs` の反復元を移動済みにし、ループ変数を反復ごとの内側の変数として扱う）。
- 判断: 直す（`for … in move xs` の反復元を移動済みにし、ループ変数を反復ごとの内側の変数として扱う）
