# R-416 `,` の抜けた `use` の並び（`use kp.{g h}`）を、全部は読めなかった並びとして扱い、そのモジュールの見つからない名前（`zzz()` の E0302）を黙らせる（§2.5 では二つの要素として全部読める）

- 場所: `crates/onsa_syntax` の `use` の並びの読み（`,` の抜けの E0002 の後の扱い）と、名前の段の「全部は読めなかった `use`」の判定。
- 内容: `use kp.{g h}` は §2.5 の「`,` の無い二つの要素」の E0002（候補は `,` の挿入）で、要素の名前は全て読めている。§18.1 によれば、取り込む名前まで読めた構文の段の誤りの `use` は、その名前（`g`・`h`）を誤りとして黙らせるだけで、そのモジュールの見つからない名前は黙らせない。今は（dev `5d5cd987`）並びを切った形として扱い、同じファイルの `zzz()` の E0302 も出ない（`{g, h}` なら出る）。再現は `issues/R/R-416/`（`onsa check` をこのディレクトリで）。
