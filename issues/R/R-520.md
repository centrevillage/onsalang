# R-520 遅延の第 1 引数の中の、`^名前` を含む巻き上げた部分式（`prev~(x * (^k * 2.0))`、`k` は下の `block` の `let`）で、`check` は通り降下が内部エラー（`local k read before definition`）

- 場所: `crates/onsa_core/src/lower/flow/hoist.rs`（巻き上げた部分式を、それを含む `let` の位置で書く）。
- 内容: 遅延の第 1 引数の中の `^名前` を含む部分式が、読む段より遅い段（`block`・`init`・`sample / N`）の式なら、巻き上げの欄（刻みの計算した部分式の欄）になる。欄は、それを含む `let` の位置で書くので、下に書いた `let` をまだ計算していない時点で読み、Core の検証器が `local k read before definition` で拒む（`test`・`build`・`dump --core` の内部エラー。`check` は通る）。
  ```
  let q = prev~(x * (^k * 2.0))            // k は block の let
  let k = b + 1.0
  ```
  ```
  let q = prev~((^k * 2.0) at sample)      // k は sample / 4 の let
  let k = prev~(^k at (sample / 4)) + 1.0
  ```
- 再現: `target/notes/185/three/adv/p1only/main.onsa`（`sample / 4`）、185 回目の `probe/p3`（`block`）。固定のバイナリ `510f04e` で exit 101。W7-05 の巻き上げ（`block`）と W7-09 の刻みの部分式（`sample / N`）からの形で、前からある。
- 経緯: 185 回目（2026-11-25）、第 119 組の後の段 1 の助言の担当（onsa-advisor、S-1240 の論点を見ていて）が `sample / 4` の形を挙げ、親が `block` の形も再現した。
- 判断: W7-11 U2b で直す（段の中の順の作り直しが同じ所を触る。置き場所は S-1244）。
