# R-452 型の位置の `rt fn(…) uses {Alloc}` を書ける（`pub fn w(g: rt fn(U32) -> U32 uses {Alloc})` が通る。§8.2 の「`rt fn` の効果行には rt 効果しか書けない」の E0902 は宣言だけを見る）

- 場所: `crates/onsa_sema/src/sig.rs` の E0902（513 行あたり）は `rt` の関数の宣言の効果行だけを見る。関数型の下ろし（`sig/types.rs`）は `rt` と効果行の組を見ない。
- 内容: `pub fn w(g: rt fn(U32) -> U32 uses {Alloc}) -> U32 { 0 }` が dev `ea8d73f6` の `onsa check` で誤りなし（親が再現、`target/notes/145/g97/` の `parent/rtalloc.onsa`）。§8.2 は「`rt fn` の効果行には rt 効果しか書けない（§10）」とし、§10 の規則 1 は効果行に `Alloc` を含まないことを E0902 とする。型の位置の `rt fn` の効果行も同じ字に当たる。
  この型に置けるのは規則 2 で収まる純粋な `rt` の関数だけで、`rt` の関数の中から呼ぶと効果行の `Alloc` が数えられるので、健全さの穴ではない。S-1031 の合流の合わせは `rt` と `Alloc` を同時に作らない（全ての腕が `rt` なら和も rt 効果だけ）。
- 経緯: 145 回目（2026-11-13）、第 97 組（S-1031）の独立のレビューの段 1（onsa-advisor）が新しい S の候補として挙げ、親が §8.2 の字から実装の誤りと読んで登録した。関係: S-1031、R-26
- 判断:
- 反映（2026-11-13、親）: W6-01 U2a（`daa8ace6`）: `lower_effects` が `rt` を受け、宣言と型の位置の両方で `rt` で `Alloc` を含む行を E0902 にする（一か所）。事例 `tests/spec/effects/fn_compat_rt_fn_type_alloc.onsa`。
