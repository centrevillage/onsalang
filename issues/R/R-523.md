# R-523 C の後端が、終わりが `U32` の端の `par~` の複製（`0 ..< N` の数える輪）を二つ以上持つ関数で、添字を読まない輪の `uint32_t i` を使わず、`-Wunused-variable` の警告になる（`-Werror` で落ちる。§13.4 の「警告を出さない」）

- 場所: C の後端（`crates/onsa_backend_c/src/`）の使わない局所の `(void)`。輪ごとでなく局所ごとに見るので、同じ局所を束縛する輪が二つあり、一つだけが添字を読むと、読まない側の宣言が残る。輪は `crates/onsa_core/src/lower/flow/generated.rs` の `Replicas`（終わりが `U32` に収まらないとき `k` で数え、`i = from + k` を束縛する、S-257）。
- 内容: `par~ i in 4294967294 ..= 4294967295 { prev~(x) + ((y * (i - 4294967294)) at sample) }` を `@export` した flow の C の `init` が、`clang -Werror` の `-Wunused-variable` で落ちる。`1d2fbbe9`（W7-17 の前）でも同じ（前から。イベントには関わらない）。値は変わらない。
- 再現: `issues/R/R-523/i.onsa`（188 回目に親が `1d2fbbe9` のバイナリで確かめた）。
- 経緯: 188 回目（2026-11-25）、W7-17 U6a の実装（onsa-impl）が見つけた（範囲の外）。
- 判断: 直す（低。値は変わらない）。R-522 と同じ W8-03 で、輪ごとに使うかを見るか、束縛を作らないかを決める。
- 補い（2026-11-26、親）: 190 回目、W7-17 L5/i2 の実装（onsa-impl）から: 同じ根（C の後端の `unread_use` が読みを局所の `LocalId` ごとに見るので、一つの局所を幾つかのブロックで束縛して一部だけが読むと、読まないブロックの宣言に `(void)` が付かない）の後退が S-1247 の腕の欄で出て、L5/i2 は `match~` の `choose` と同じ `bind_read`（束縛の後に何もしない読みを置く、S-288）を段の作業のブロックにも使って直した。後端を宣言（`let` の文）ごとに見る形（`onsa_core::walk` に `let` を知らせる歩きを足し、`FnEmitter` の読みを文ごとの集まりに、約 45〜60 行）にすると、この R と `bind_read` の二つの使い方が一つの判断になる。W8-03 で比べる。
