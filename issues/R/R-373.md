# R-373 `trait Tr: Show {` の上位の trait の並びが E0002 になる（§6.3 が書く形で、読みは E0200）

- 場所: `crates/onsa_syntax/src/parser/` の `trait` の宣言の見出し。§6.3、§4.6
- 内容: `pub trait Tr: Show { … }` と `trait Tr: Dup {}` は E0002「expected `{`, found `:`」で、§6.3 が書く上位の trait の形が構文の段で落ちる。`trait Tr { … }` は E0200 で、閉世界の規則（この版で未実装の機能は E0200）からは上位の trait の形も E0200 が読みである。再現は横のディレクトリ。
- 経緯: 116 回目（2026-11-05）、第 87 組の下書き（onsa-gap、S-751 の調べ）が NEW-3 として挙げ、親が再現した。伏せた独立のレビューも R とした。構文の段の小さな直しなので W5-11 で行う。
- 判断: 直す。構文の段で上位の trait の並びを読み、`trait` の E0200 に落とす。
