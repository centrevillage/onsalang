# R-497 `onsa graph` が出力の頂点と、`out` という名前の入力か `let` の頂点を同じ DOT の名前 `"out"` で出し、一つに潰れて実線の閉路ができる

- 場所: `crates/onsa_driver/src/graph.rs` の出力の頂点（`g.visit(o, "out", …)`）。
- 内容: `onsa graph` は出力の頂点の DOT の名前を `"out"` にし、入力と `let` の頂点はその名前で出す。`let out = lp~(x) + 1.0` の後の出力 `lp~(out)`（入力 `out` も同じ）は、二つの頂点が同じ DOT の名前になって一つに潰れ、実線の辺 `lp_1 -> out`・`out -> lp_1` ができる（`spec/tools.md` §1.2 の、実線だけで閉路を作らない絵に反する）。終了コード 0。再現は 165 回目の scratchpad の `g1081/advisor/probe/a1/let_out`・`a2/input_out_graph`（`onsa graph f .`）。通るプログラムの検査は変わらない（表示だけ）。
- 経緯: 165 回目、2026-11-18、第 110 組（族: flow の状態の名前）の段 1（onsa-advisor）が見つけ、親が再現して登録した。
- 判断: 直す（低）。出力の頂点の名前を利用者の名前と重ならない形にする（族の S-1138 の決定に合わせる）。W7-03 の名前の単位（U1c）で graph の頂点の名前を計画から引くときに直す。
- 反映（2026-11-18、親）: 165 回目、W7-03 U1c（`47adf20a`）: graph の出力の頂点の名前を `_out` にし、ノードの頂点を計画の path にした（事例 `tests/spec/flow/state_names_graph_out.onsa`）。
