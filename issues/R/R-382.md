# R-382 `onsa interface` が `impl` のメソッド自身の型パラメータを誤って出す（`pub fn peek[U](self, y: U)` が `peek[T, U](self, y: T)`）

- 場所: `crates/onsa_driver/src/interface.rs` のメソッドの見出しの表示（型パラメータの番号の読み）。
- 内容: `impl[T] Rack[T] { pub fn peek[U](self, y: U) -> U32 }` の `onsa interface` が `pub fn peek[T, U](self, y: T) -> U32` を出す。`impl` の型パラメータが見出しの `[ ]` に並び、`y: U` が `y: T` になる。
- 経緯: 119 回目（2026-11-06）、W5-17 U1/t（onsa-test）が見つけ、親が固定のバイナリで再現した。
- 判断: 直す。W5-17 が `onsa interface` に `?Escape` を出すので、同じ単位で直す。
- 反映（2026-11-06、親）: W5-17 で直した（119 回目）。`impl` の型パラメータは `impl` の見出しに出す。事例は `tests/spec/types/interface_impl_method_params.onsa`。
