# R-299 署名の配列長に、ソースで後ろに書いた最上位の `const K: I32` を書くと、§4.5 の E0401（定数式の型は `U32`）にならず黙って通る（先に書けば E0401）

- 場所: 署名の段（`crates/onsa_sema/src/sig.rs::lower_signatures`）が def をソースの順に下ろし、配列長の定数式の型を、その時点で下ろされた定数からだけ確かめる（推測。S-725 の下書きのコードの読み）。
- 内容: §4.5 は配列の長さの定数式の型を `U32` とし、違えば E0401 とする。`pub type A = [F32; K]` と `pub fn f(a: [F32; K])` の後ろに `pub const K: I32 = 2` を書くと、診断なしで通る（終了コード 0）。同じ `const` を先に書けば、二か所に E0401「a constant expression has the type `U32`; `K` is `I32`」が出る。
  W4-04 U6 の前の dev `5fc054e` と U7b1 の後の `4fb3fda` も同じで、前からある。§4.5 に反するプログラムが黙って通るので重大度は中。再現は `issues/R/R-299/late.onsa`（通る）と `early.onsa`（E0401）。
- 経緯: 78 回目（2026-10-28）、第 67 組の S-725 の下書き（onsa-gap）が同じ根の誤りとして見つけ、親が `P78/bin/onsa-u7b2`（dev `727ad03`）で再現した。関係: S-725。
- 判断: 直す（中）。署名の段の順に頼る S-725 と同じ根なので、S-725 の決定と一緒に W4-05 で直す（定数の型を引いた時点で下ろす）。
- 補い（2026-10-28、親）: S-725 は (1) に決まった（2026-10-28、第 67 組）。定数の型を引いた時点で下ろす遅延の中で直す（W4-05 の「第 67 組から」）。
- 補い（2026-10-29、親）: 別名を頭にした経路の形が残る: `type Al = S` の後の `type Row = [F32; Al.N]` と `const K: [F32; Al.N]` は、後ろに書いた `impl S { pub const N: I32 = 2 }` を読むと E0401 が出ずに黙って通る（`issues/R/R-299/alias_late.onsa`、前に書けば E0401 の `alias_early.onsa`）。
  最上位の定数の形（`late.onsa`）は W4-05 U2 で直った（二か所に E0401）。型の宣言のグラフ（`sig/decls.rs::Graph::read`）が `Al.N` で別名への辺だけを足し、`N` への辺が無いため。W4-05 U3a で直す（80 回目の U3/i の見積もり直しが見つけた）。
