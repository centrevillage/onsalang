# R-438 C の後端が一時変数を名前の頭 `onsa_t` で判定し、`onsa_trunc_*` の呼び出しと利用者のローカル `onsa_t` も一時と読んで、`inout` の後に読み直す（`I32.trunc_from(x) + bump(inout x)` がインタプリタ 2、C 10。黙った誤コンパイル）

- 場所: `crates/onsa_backend_c/src/emit/fns.rs` の `is_stable`（出力した C の字の頭 `onsa_t` を一時変数と読み、後の被演算子の副作用の後でも同じ値とみなす）と `operands`・`temp`。
- 内容: 一時変数の名前（`onsa_t` と数字）の判定が頭の字だけなので、ランタイムの `onsa_trunc_*`・`onsa_trunc_sat_*` の呼び出しと、利用者のローカル `onsa_t`（`names::ident` が `onsa_t_` にする）も一時と読む。そのため `I32.trunc_from(x) + bump(inout x)`（`bump` が `x` を 9.5 にして 1 を返す）は、C が `bump(&x)` の後に `onsa_trunc_i32_f32(x)` を読み、インタプリタの 2 に対して C は 10。`var onsa_t: I32 = 1` の `onsa_t + bump_i(inout onsa_t)` もインタプリタ 11、C 15。§3.5 の評価順に反する黙った誤コンパイルで、gate の事例にこの形は無い。再現は `target/notes/140/w513_survey/K/stable/`（`P/bin/onsa-a732713` の `test` と `build --target host`、親が生成された C を読んで確かめた）。
- 経緯: 140 回目（2026-11-12）、W5-13 の前の洗い出しの領域 3（onsa-advisor）が見つけた。根は R-93・R-81 の `is_stable`（出力の字から値の不変を推す）と同じで、R-93 の再現の `((int` のキャストとは別の形。`onsa_trunc_` は M4 からあり、W5 の後退ではない。
- 判断: 高（黙った誤コンパイル）。根の直し（`is_stable` を除く正規形）は R-93 の W8-03。W5-13 では、一時変数の判定を `onsa_t` の後が数字だけの名前に限る狭い直し（`fns.rs` +4 −1 の見当）と、`[[test.host]]` の事例を入れる。`((int` のキャストの形は R-93 に残る。
- 反映（2026-11-12、親）: W5-13 U3（`cd9d7ef0`）で直した。一時変数の名前は `emit/fns.rs` の `TEMP` と `is_temp`（`onsa_t` の後が数字だけ）の一か所で、作る所と判定が同じ定数を引く。事例 `tests/spec/c_runtime/c_temp_names.onsa`（`trunc`・`trunc_sat`・ローカル `onsa_t`・範囲の終わり、`[[test.host]]`）。壊す側が 40 余りの形でインタプリタと C を突き合わせ、全て合った。`((int` の形（`(c as I64) + bump8(inout c)` が C で 101、期待 2）は R-93 に残る。
