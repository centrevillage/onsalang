# R-318 自分を `Ptr` で指す struct（`struct K { p: Ptr[K] }`）の値を二度 `move` する関数が `check` を通り、`onsa interface` が Core の検証器の内部エラー（「local: type mismatch」、終了コード 101）になる

- 場所: Core への降下（`move` の降下）と Core の検証器。どの段が誤るかは未確認。
- 内容: `pub struct K { p: Ptr[K] }`、`fn take(move k: K) {}`、`pub fn two(move k: K) { take(move k)  take(move k) }`（横の `ptr_self_moved_twice.onsa`）は、`check` が終了コード 0 で、`interface` が「the Core verifier rejected the output of lowering: in `two`: local: type mismatch `()` vs `K`」の内部エラー（101）になる。
  `K` は `Ptr` だけを持つので種は Copy で、二度目の `move` は誤りでない（§5.2）。`Ptr` を通らない Copy の struct（`struct K { v: F32 }`）では起きない。二つの宣言の輪（`K { p: Ptr[E] }`、`E { p: Ptr[K] }`）でも同じ。
- 経緯: 80 回目（2026-10-28）、W4-05 U2b の壊す側の再確認が `Ptr` の輪の掃引で見つけ、親が小さな形で再現した。W4-05 U2b の前（`728ebb7`）も同じ。
- 判断: （2026-10-28、親）直す（`check` を通るプログラムの内部エラー）。移動・コピー・破棄の降下の作業（W8-04）で直す。
