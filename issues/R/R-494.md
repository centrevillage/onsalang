# R-494 後ろの `let` が flow の段の誤りで歩きを止めると、前の遅延の `^名前` の第 1 引数を読めないまま偽の E0813 を出す

- 場所: 消した `crates/onsa_sema/src/flow/rate.rs` の rate pass（`finish_flow` の不動点の反復）。
- 内容: 遅延の第 1 引数に後ろの `let` を読む `^名前` があり、その `let` か間の `let` が flow の段の誤り（`if~`・`match~` の E0200 など）を持つと、反復の各回がその誤りで止まり、`^名前` の `let` のクロックが初めの値（定数）のまま残る。最後の回は前の遅延で「this one is a constant」の E0813 を出していた（`^b` の `let b = x` は `sample` なので偽の診断）。§11.3 では `^名前` は `let` のクロックを読み、§18.1 では最初の誤りは後ろの E0200。W7-02 U2b-2/b（onsa-break）の乱択の 30,000 件の 97 件（`^` を含む生成だけ。文面が `init`・`block` に変わる形と、後ろの E0815・E0805 が現れる形を含む）。通るプログラムは変わらない。前からの挙動。
- 経緯: 165 回目（2026-11-18）、W7-02 U2b-2 の壊す側が「M-5 の外の違い」として見つけた。新しい歩き（段 1 で `let` のクロックを解いてから段 2 で検査し、最初の診断で止まる）では出ない。
- 判断: 直す（中）。W7-02 U2b-2 で直った（新しい側が仕様に合う。前に合わせる直しは仕様に反する）。事例 `tests/spec/flow_clock/order_feedback_then_later_error.onsa`（親が壊す側の再現 `fama1`・`fama2`・`fama3`・`fama5` から書いた）。
- 反映（2026-11-18、親）: W7-02 U2b-2（`dd05492a`）で直った（新しい歩きが段 1 で `let` のクロックを解いてから段 2 で検査する）。事例 `tests/spec/flow_clock/order_feedback_then_later_error.onsa`。
