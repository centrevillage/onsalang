# R-95 部分移動の禁止が、報告されていない規則になっている

- 中・仕様へ・観点 3｜`crates/onsa_sema/src/modes.rs:640`｜§5.2（部分移動について記述なし）
- 現状: `fn take_field(move s: Holder) -> Buf[F32] { s.buf }` が、E0711「partial moves are not allowed」になる。回避策は `let Holder { buf: b, gain: _ } = move s`。Rust は部分移動を許す。
- 推奨: 禁止を仕様に書く。分解の `let` を修正候補に出す。
- 範囲（2026-10-05 に追加で確かめた）:
  - E0711 になる形: 末尾の `s.buf`、`let b = move s.buf`、タプルの `t.0`、入れ子の `o.inner.buf`、`move self` の `self.buf`、配列の `let b = move xs[0]`。修正候補は無い。`uses {Alloc}` が無いと、先に E0601（`s` 全体を破棄すると見ている）が出る。残りが Copy なら `Alloc` は要らないはずである。
  - 通る形: 分解の `let Holder { buf: b, gain: _ } = move s`、`match move s { Holder { buf: b, gain: _ } => b }`、タプルの `let (b, _) = move t`。
  - 問題になるのは Affine のフィールドだけ（Copy と Shared のフィールドは複製）。struct のパターンは全てのフィールドを書き（`..` は無い、§7）、省略形も無い（§4.2）ので、分解は残りを全て `_` で並べる。
  - `Drop`（第 2 期。`impl Drop` は E0200）を実装する型の分解と、`drop(move self)` の本体の終わりの `self` の扱いが仕様に無い。
  - 再現は `tests/review-phase1/parent/r95.onsa`（期待値と今の出力は各項目の上のコメント）。既存の `body/pm1_partial.onsa` も同じ。
- 決定（2026-10-05）: 元の推奨（禁止）ではなく、取り出しで全体を消費する形にした（S-85）。
  - (1) 所有する値の Affine のフィールドを消費する位置に置くと、元の値全体を消費する。残りのフィールドはその場で破棄し、以後は使えない（E0704）。意味は分解の `let` と同じ。対象は struct とタプルのフィールドの静的な経路で、配列の要素は E0711 のまま（動的な添字では分解に書き換えられない）。
    理由: §5.4 の `let a = p.0` と `let (a, _) = p` の同値を種によらず保ち、Affine だけの例外を無くす。禁止すると取り出しの度に全てのフィールドを書き、フィールドの追加で全て直す（P10）。Rust と同じ部分移動は、フィールドごとの移動の状態と破棄が要る。残りを使おうとすると E0704 になるので、Rust の読み方とのずれは黙って誤らない。
  - (2) `Drop` を実装する型は、分解も取り出しもできない（E0711）。`drop(move self)` の本体の終わりでは、`self` を `drop` を呼び直さずにフィールドごとに破棄し、本体の中では `self` を分解できる。仕様には今書き、実装は第 2 期（計画 §5）。
  - (3) 診断: 取り出した後の使用は E0704 で、取り出した位置と、先に読むか分解する書き方を note で示す（修正候補は意図が一つに決まらないので出さない）。配列の要素の E0711 は `for x in move xs` を note で示す。
  - 参考: 配列のパターンが無いので、Affine の要素の配列を要素ごとに分けるには `for ... in move` を使うしかない。必要になったら別の項目にする。
- 判断: 取り出しで全体を消費する（S-85）。所有する値の Affine のフィールドを消費する位置に置くと元の値全体を消費し、残りはその場で破棄、以後は E0704。
  意味は分解の `let` と同じで、struct とタプルの静的な経路だけ（配列の要素は E0711、`for x in move xs`）。`Drop` の型は分解も取り出しもできない（E0711）。`drop(move self)` の本体の終わりは `self` をフィールドごとに破棄（`drop` を呼び直さない）。元の推奨（禁止）を利用者と比べ直して改めた。
  再現は `tests/review-phase1/parent/r95.onsa`
