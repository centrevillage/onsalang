# R-275 並びの無い `use` の最後の取り込む名前の予約語・キーワード（`use kp.clock`、`use std.test`）の E0200・E0002 を名前の段で出し、`onsa fmt` が止まらない（§18.1 は構文の段）

- 場所: `crates/onsa_sema/src/names/collect.rs::not_a_declared_name`（W4-03 U3b2、R-266 の直し）。並びの要素の形は構文の段（`onsa_syntax/src/parser/items.rs::parse_use`）。
- 内容: §18.1 は、取り込む名前まで読めた `use kp.clock` の E0200 と `use std.test` の E0002 を構文の段の誤りとし、`onsa fmt` は構文の段の診断（予約語の E0200 を含む）のあるファイルを書き換えず終了コード 2 とする。
  U3b2 の実装は、並びの無い最後の要素の予約語・キーワードを名前の段で出すので、`use kp.clock` のファイルの `onsa fmt --check` は終了コード 0（並びの形 `use kp.{clock}` は 2）。
- 経緯: 69 回目（2026-10-25）、二度目の文書の点検（onsa-docs）の F5 で見つけた（`docs69b/t1/` で再現）。U3b2 で入った。
- 判断: 直す（親、仕様が明確）。W4-03 の U3d で、並びの要素と並びの無い最後の要素のキーワード・予約語を構文の段で出す（R-272 と同じ `parse_use` の所）。表は `onsa_syntax` の一か所に置き、名前の段の `unbindable` はそれを引いて組込みの flow の名前だけを足す。
- 反映（2026-10-25、親）: W4-03 U3d（69 回目）: 宣言の名前になれない語の表を `onsa_syntax/src/token.rs::not_a_name` の一か所に置き、`parse_use::check_taken` が並びの要素と並びの無い最後の語に当てて構文の段で出す。
  名前の段の `names/clash.rs::unbindable` はその表を引き、組込みの flow の名前だけを足す。`not_a_declared_name` は消した。fmt の終了コードは `crates/onsa_cli/tests/use_name_rules.rs`。
