# R-51 newtype（`struct Hz(F32)`）の値を作れない

- 中・直す + 仕様へ・観点 1 / 3｜`crates/onsa_sema/src/body.rs:2054-2058`、`:1088`、`:1385`｜§4.4
- 再現: `Hz(440.0)` は「not a function」、`Hz { 0: 1.0 }` は E0002、パターン `Hz(v)` は E0302 になる。宣言はできても、値を作れない。
- 仕様へ: Rust と同じく、構築子 `fn(F32) -> Hz` とパターン `Hz(v)` を入れる。
- 決定（2026-10-03）: newtype を仕様から外した（S-39）。論点ごと無くなる。別の型として区別したい値は、名前付きのフィールドが 1 つの struct で書く。
- 判断: S-39: newtype を仕様から外すので、論点ごと無くなる。タプル形の struct は E0020（修正候補は名前付きのフィールドの struct）。newtype と単位の型は、取り違えの検査が要る実例が出てから §19.1 で決める
- 反映: 仕様 §4.1 / §4.4 / §6.4 / §15.1 / §19.1 に反映済み（2026-10-03）。実装は W3-08
