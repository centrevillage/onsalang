# R-363 `array.from_fn` に本体で書いた無名関数の中の panic は `onsa test --json` の `calls` が空で、名前付きの関数を渡すと `from_fn` の呼び出しが入る（S-554 の 4 の決定では、どちらも `from_fn` の呼び出しが入る）

- 場所: `crates/onsa_core/src/lower/body/call.rs` の `lower_from_fn`（無名関数を呼び出しの位置で展開するので、中の panic に `from_fn` の呼び出しの枠が無い）と、`onsa test --json` の `calls` を作る所。
- 内容: `array.from_fn(fn(i) { 10 / (i - i) })` を test の本体に書くと、`division by zero` の `calls` が空になる。名前付きの関数 `array.from_fn(bad)` を渡すと `calls` に本体の `array.from_fn(bad)` が入る。無名関数の中の `assert` も `calls` が空。
  S-554 の 4 の決定（§18.1）は、関数値を呼ぶ std の関数の呼び出しを、関数値の中の panic の `calls` に入れる（本体に書いた無名関数でも同じ）とする。再現は `issues/R/R-363/fromfn.onsa`・`fromfn3.onsa`（`dd4e4e97` のバイナリ）。通るプログラムは変わらず、`calls` の中身だけが違う。
- 経緯: 110 回目（2026-11-04）、第 81 組の下書き（onsa-gap）が S-554 を書く途中で見つけ、独立のレビューの段 1・段 2 が S-554 の 4 の下で R にすると勧めた。
- 判断: 直す（低）。`std.test.check` の関数値の呼び出しの枠を作る作業（W8-09）で、`from_fn` も同じ仕組みに乗せる。
