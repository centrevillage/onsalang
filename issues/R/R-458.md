# R-458 flow の遅延（`prev~`・`delay~`）の値型が Copy でなくても、`let` に置かなければ受け付け、状態に `Str` などが入る

- 場所: flow の本体の遅延（§11.4）の値型の検査。
- 内容: 横の `prev_value_type.onsa`。`prev~(if x > 0.0 { "a" } else { "bb" }, "z").len()` と `prev~(mk(x), "z").len()`（`mk` は `Str` を返す `rt fn`）は通り、同じ遅延を `let s = prev~(…)` に置くと E0810「the value type of a signal must be Copy; `Str` is Shared」。
  §12.4 は「flow の状態の大きさは、コンパイル時に決まる（遅延線の長さはコンパイル時定数、値型は Copy、ヒープを使わない）」とするので、名前を付けない遅延の値型も Copy でなければならない。`delay~(…, 4, None)`（`Option[Str]`）も同じ（段 1 の `a1.txt`）。
- 経緯: 第 104 組（S-1043）の独立のレビューの段 1（onsa-advisor）が挙げ、親が固定のバイナリ `onsa-bf474a4` で再現した（149 回目、2026-11-14）。
  材料は `target/notes/149/gap/g104/advisor/` と段 1 の報告 `target/notes/149/gap/g104/onsa-advisor-aa36969ddf6da6add-001.md`。 関係: S-1043、S-1046（巻き上げで状態に Copy でない値）、E0810、S-616。
- 判断:
- 補い（2026-11-18、親）: 166 回目（2026-11-18）、S-1047 の決定 (d) で、状態を持つもの（インスタンス、組込みの遅延、`par~`）が作る値の型は名前を付けない位置でも Copy（E0810）と §11.3 に一文を足した。この R の遅延の値も同じ文に入る（W7-07 の直しは §11.3 のこの文を指す。`par~` の分は W7-14 U7、同じ判定の関数）。
- 反映（2026-11-19、親）: W7-07 U2（168 回目、`d4f44c1c`）で直した: 名前を付けない遅延の値型も `flow/clocks/checks.rs` の `check_delay_value`（`check_par`・`check_let` と同じ `not_copy_signal`）で E0810。事例 `tests/spec/negative/flow_delay_value_copy_e0810.onsa`・`_order_e0810.onsa`・`_let_e0810.onsa`・`_default_s1155.onsa`。横の再現の `prev_str`・`prev_owned`・`prev_let` はこれらの事例が持ち、`lit_affine` は S-1043 の形で `tests/spec/negative/flow_alloc_owned_values.onsa` が持つので、再現は消した。
