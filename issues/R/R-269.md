# R-269 fn の本体で flow を関数の形で呼ぶ `lp()` が、名前の段の E0308 でなく型の段の E0401「`lp` is not a function」になる

- 場所: 本体の名前の解決（呼び出しの位置の名前の種類。W4-04 の `body/names.rs` の作り直しの範囲）
- 内容: 再現は横の `fn_calls_flow/`（`pub flow lp` と、fn の本体の `lp()`）。型の段の E0401「`lp` is not a function」になる（dev `aa8a918` と U3a2 の `c335496` で同じ）。§15.1 の「名前は見つかったが、その位置に要る種類（…関数、flow…）でなければ E0308」と §18.1 の段の順では、名前の段の誤り。
  §15.1 の E0308 の例の並び（「E0308 になるのは…場合である」）は、関数の位置の flow を名指していない。コードを E0308 と読むかは W4-04 で確かめ、割れるなら S にする。flow の本体の `lp(x)` は E0811 と候補「`~` を足す」で正しく出る（§2.6）。
- 経緯: 第 59 組の独立のレビュー（onsa-advisor、2026-10-25、67 回目）の段 1 が範囲の外で見つけ、段 2 が既にある R（R-254・R-249・R-179・R-147）と別の形として新しい R にするとした。直しは W4-04。
