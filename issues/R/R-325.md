# R-325 modes が flow の生成型 `Out` の値を第二級に数えず、`let k = o`・`let k = Some(o)`（`o: swap.Out` の `inout` 引数）が E0710 でなく E0711「Affine value `o` is consumed here」になる（§5.3 は `In`・`Out` を第二級とする。同じ形の `Span` は E0710）

- 場所: `crates/onsa_sema/src/modes.rs::is_second_class`（値の位置の第二級の判定。`Span`・`[Span; N]` だけで、生成型の `Out` を数えない）。
- 内容: `pub flow swap(…) -> Stereo at sample` の後の `fn keep_in_let(inout o: swap.Out) -> U32 { let k = o … }` と `let k = Some(o)` が、E0710 でなく E0711「Affine value `o` is consumed here」になる。
  同じ形の `Span`（`let k = Some(xs)`）は E0710（再現は横の `modes_out_value.onsa`）。
  W4-05 U4a で署名の第二級の頭の判定（`sig/wellformed.rs::second_class`、`Span` と生成型の `Out`）を一か所にしたが、modes はそれを呼ばない（U4a は modes を変えない）。判定の重複（D-15）も残る。
- 経緯: 82 回目（2026-10-29）、W4-05 U4a/i（onsa-impl）が親の求めで確かめ、再現を作った。前からある。
- 判断: 直す（低。誤りのあるプログラムの診断のコードだけ）。W4-07 の modes の作り直しで、第二級の判定を整形性の段の頭の述語に揃える（`In` は W7-03 の生成項目の後）。
- 判断（2026-10-30、親）: 同じ族の形: `inout o: swap.Out` の `let l = o.l` が E0710 でなく部分移動の E0711 になる（86 回目、第 75 組の段 1、`target/notes/86/g75/parent/out_field_let.onsa`）。W4-07 の第二級を種より先に見る順で直る（S-788）。
- 判断（2026-10-30、親）: U2b で、`inout o: swap.Out` の `let l = o.l` は第二級を先に見る順では直らないと分かった。生成型 `Out` のフィールドの型が `Buf[T]` のため（R-334、W7-03）。`let k = Some(o)` は、構築子の要素を `Consume` に置く U3a で直る。
- 判断（2026-10-30、親）: U2b の壊す側で、型の段が `render` の結果を `Out` と同じ型で作るため（`Rendered` が無い、R-264・R-334）、modes が生成型 `Out` を第二級に数えると `let o = g.render(...)` が E0710 になると分かった（つなぐと `tests/` の 43 ファイルで 153 件）。
  利用者が (B) を了承: W7-03 で `Out` と `Rendered` を分けるまで modes は生成型を第二級に数えず、この R の生成型の形（`let k = o`）は W7-03 で直す。`Span` の形は W4-07 のまま。
