# R-274 型パラメータを書いた型の別名（`type Al[T] = (T, T)`、E0002）の後の `Al[I32]` に E0302「`Al` takes 0 type argument(s)」が出る

- 場所: 型の別名の宣言の読み続け（構文の段の E0002 の後の別名の def）と、型の位置の型引数の数の検査。
- 内容: §4 は型の別名が型パラメータを持たないとし、`pub type Al[T] = (T, T)` は E0002。その後の `fn f(a: Al[I32])` に E0302「`Al` takes 0 type argument(s), 1 given」が出る（構文の誤りの宣言からの連鎖）。型の位置の型引数の数の誤りは E0412（R-258）。再現は横の `alias_params.onsa`（dev `49c469b`）。
- 経緯: 69 回目（2026-10-25）、W4-03 U3b2 の実装の担当（onsa-impl）が範囲の外で見つけた（前からの挙動）。直すのは R-258 と同じ W4-05 の見込み。

- 判断（2026-10-25、親）: 直すのは W4-05（R-258 と同じ型の位置の型引数の数の所）。期待の診断は W4-05 の設計で決める（§18.1 の読み続けた宣言の読めなかった部分として黙るか、E0412 か）。
