# R-432 長さ 0 の配列のフィールドを持つ struct の `const` の C の初期化子が `{ {  } }`（空の初期化子）になり、`-std=c11 -pedantic` で C23 の拡張の警告、`-Werror` で通らない（`FixedStr[0]` の `const` も当たる）

- 場所: `crates/onsa_backend_c/` の `static const` の初期化子を書く所（長さ 0 の配列の値）。C の配列の型は `typedef struct onsa_arr_u8_0 { uint8_t a[1]; }` で長さ 0 の配列ではないが、初期化子が空になる。
- 内容: `struct Z { a: [U8; 0], n: U32 }` の `const` を `onsa build --target host` で C にすると、`static const … = { .a = { {  } }, … }` を出し、`clang -std=c11 -Wall -Wextra -pedantic -fsyntax-only` が「use of an empty initializer is a C23 extension [-Wc23-extensions]」の警告を出す（dev `69326f64` の前のバイナリでも同じ）。W5-12 U2 の後は `const E: FixedStr[0] = ""` も当たる。値は正しい。
- 経緯: 139 回目（2026-11-11）、W5-12 U2 の実装の担当（onsa-impl）が範囲の外で見つけた（入力は `P/w512/u2/i/p/z0.txt`・`cap0.txt`）。
- 判断: 低（警告で、値は正しい。`-Werror` の C コンパイラでは通らない）。C の後端を触る W5-12 U3a（R-431）で一緒に直す（`rules/leader.md` 7.4: `FixedStr[0]` の形を入れた作業）。
