# R-352 `Array[T]` の受け手が列のメソッドの表から `len`・`fill!` を引いて通る（§4.2 では `Array` の `len` は第 2 期）

- 内容: `fn f(a: Array[F32]) -> U32 { a.len() }` と `fn f(inout a: Array[F32]) { a.fill!(1.0) }` が `check` を通る。§4.2 は `Array` の `len()` を第 2 期とし、組込みのメソッドは閉じた一覧（S-98）。
