# R-191 `move` の引数と `move self` への代入が E0701 になる

- 中・直す・観点 1｜引数のモードと移動｜§5.1、§5.2、§5.4
- 内容: §5.1 は「`let` の束縛と借用の引数は変更できない（E0701）」とし、`move` の引数（`move self` を含む）は借用でなく所有である（§5.4 の表）。
  今の実装は `move v: [I32; 2]` の `v[0] = 3` と `move self` の `self.n = …` を E0701（「`v` is a borrowed parameter」「`self` is borrowed」）にする。
  S-250 で `mut self` の候補を `move self` にした根拠（`move self` の本体で `self` を変えられる）とも食い違う。
- 経緯: W3-15/t2 がデータのファイルの `mut_self` の例で見つけ、親が再現した（2026-10-09）。
- 決定（2026-10-09、親）: 直す。束縛の状態を一つの列挙にする W4-07 で、`move` の引数を所有・可変にする。
- 判断: 直す（親、仕様が明確）。`move` の引数と `move self` への代入を E0701 にしない（§5.1 の E0701 は `let` と借用の引数だけ。S-250 の `move self` の候補の根拠）。W3-15/t2 で見つけた
- 反映: 実装は W4-07
- 判断（2026-10-29、親）: 84 回目、W4-16 の設計メモから（利用者が了承、A3）: 束縛の状態を一つの列挙にする W4-16 の表の関数が `move` の引数の行を決めるので、所有・可変（`OwnedMut`）にするのは W4-16 の U1a に移した（W4-07 から）。`tests/spec/values/move_assign.onsa` の項目は U1a で外す。
- 判断（2026-10-29、親）: 84 回目（親）: `move` の引数は所有・可変なので、`inout` に渡せ、`inout self` のメソッドの受け手にもなれる（§5.1 の E0701 は `let` と借用の引数だけ）。§5.2 の `inout` の行と受け手の文が「`var` か `inout` 引数」だけを挙げていた写し漏れを、決定に合わせて直した（W4-16 U1a の実装とテストの担当の報告から）。
