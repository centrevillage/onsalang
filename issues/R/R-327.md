# R-327 循環した型（E0311）を使う所に書いた型引数（`struct Cy2[T] { a: Cy2[T] }` の後の `fn y(x: Cy2[N[Bool]])`・`Cy2[Span[F32]]`）の要求と位置を判定しない（下ろした型が誤りの型なので、書いた型の引数を歩かない）

- 場所: `crates/onsa_sema/src/sig/wellformed.rs`（書いた型と下ろした型を並べて歩く所。下ろした型が誤りの型なら中を歩かない）。
- 内容: 値の循環で E0311 になった `struct Cy2[T] { a: Cy2[T] }` の後の `fn y11(x: Cy2[N[Bool]])` と `fn y05(x: Cy2[Span[F32]])` に診断が出ない（再現は横の `y1.onsa`）。書いた型引数は署名の型の位置なので、§4.5 の E0416 と §5.3 の E0710 に当たる。
  使う単位には E0311 が無いので、その単位は診断なしで、循環を直した後に二回目の修復になる。型引数の数（`Cy2[F32, F32]`）は R-323 で E0412 になった。
- 経緯: 82 回目（2026-10-29）、W4-05 U4a/b（onsa-break）が低の指摘 6 として挙げた。
- 判断: 直す（低。誤りのあるプログラムの報告だけ）。W4-05 U4b のついでに、下ろした型が循環の誤りの型でも、書いた型引数を型の宣言の型パラメータと並べて判定する。
