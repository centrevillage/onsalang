# R-277 配列の長さ（型の位置の定数式）に書いた利用者の型の関連定数（`[F32; Point.N]`）が E0302 になる

- 場所: 型の位置の定数式の名前の解決（`crates/onsa_sema` の型の下ろし）。
- 内容: §4.5 は、配列の長さと const 引数の定数式に「`I32.BITS` のような具体的な型の関連定数」を含める。利用者の型の `pub const N: U32 = 4` を `pub fn b() -> [F32; Point.N]` に書くと、E0302「cannot find `Point.N`」になる。
  再現は `issues/R/R-277/`（`main.onsa` の 2 行と、`util.onsa` の `Point` と関連定数 `N`）。dev のバイナリ（2026-10-25 のビルド）と基 `100e8a0` で同じ。可視性とは別の件。
- 経緯: 70 回目（2026-10-26）、W4-03 U4a/i（onsa-impl）が範囲の外で見つけた（前からの挙動）。親が dev のバイナリで再現した。直す作業は、定数式の文法と型を受け持つ W5-08 とした。
