# RF-24 経路の頭の引き方（ローカル → self → 見出しのパラメータ → モジュール）が四か所にある（W5-13 の洗い出しの M7）

- 場所: `crates/onsa_sema/src/` の `names/body/paths.rs` の `Walker::resolve`（本体と定数式）、`sig/types.rs` の型の経路、`sig/heading.rs::heading_name`（境界と効果行）、`sig/decls.rs` のグラフ。型パラメータの後のメンバは `sig/heading.rs::param_member` と `paths.rs::type_param`、種の対応は `resolve.rs::of_generic`・`sig/heading.rs::param_kind`・`names/collect.rs`。
- 内容: 経路の頭の引き方（ローカル → `self` → 見出しのパラメータ → モジュール）が四か所にあり、見出しが束縛する名前の種類を足すと四か所を直す。網羅の `match` は種の対応だけを拾い、引く順は拾わない。`member_note` は本体の側だけ。`type_args.rs` の `const_form` は「関連の型がこの版に無い」ことに頼る。全体を一つにするのは +80 −60 の見当で、位置ごとに文面が違い出力の確かめが重い。
- 経緯: 140 回目（2026-11-12）、W5-13 の前の洗い出しの領域 2（onsa-advisor、M7）。利用者が W5-13 で触らず RF に置くことを了承した。関連の型（trait の中の型）を入れる作業の前に見る。関係: R-427、`target/notes/140/w513_survey/survey.md`。
