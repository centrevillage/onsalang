# RF-14 fmt の速さ

- 内容:
  - 新しい印字器は長い入力で古い印字器の 1.3〜1.6 倍（release。10 万要素の 1 行で 0.032 s → 0.050 s）。計画の分は約 1 割で、残りは歩きの印字器。隙間ごとに `space::space` が表の約 40 行を照らす所が重い見立て（測っていない）。表を記号の種類で引く形にする案。
  - 書き込む前の確かめ（U5）で、長い入力の `fmt --check` がさらに 1.7〜1.84 倍（二度目の解析、比べの側の AST の複製二つ、項目のダンプ）。`tools/speed.py all` の 1467 ファイルでは 3.05 s → 3.18 s（プロセスの起動が大半）。増え方は線形（W3-11/b が 40 万行まで確かめた）。出力の側を複製せずに書き換える案（U5/i）。
- 経緯: 27 回目、W3-11 の U3b/i と U5/i の測り
  - 長い入力は 27 回目の scratchpad の `w311u5i/long/`（作り方 `long.py`）と `w311u5b/scale.py`・`scale2.py`。12 回目の `w306b2/speed/` は空だった。
