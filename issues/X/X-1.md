# X-1 gate / fuzz の改善

## 問題点

現状、gate / fuzz の実行時間が長いために開発スピードの低下要因になっている。
また、待ち時間が長くなるため、エージェントのセッションキャッシュが切れやすく、トークン効率が悪い。
これらを改善するための方策を考える。

## 改善の手順

1. W3 で gate / fuzz を実行した時の有用性を実績ベースで評価する
  - 実行したが有用な結果が得られなかったケース、有用な結果が得られたケースをそれぞれ分析

2. gate / fuzz の基準を決める
  - 実行時間の基準
  - 実行タイミングの基準
  - 網羅性の基準

3. 具体的な改善策を考える

以下の観点で改善策を考える:
- 網羅性の空間を疎にする
  - 網羅的に実行するのでなく、抜取り検査的に各ケースの代表値をサンプリングして検証
- 実行タイミングを疎にする
  - 一度の実行で全て検証するのではなく、監視バッチなどで定期的にコードの変更を検出し、分割実行
- 検証の範囲を修正内容に応じて絞る
  - 全てを実行するのではなく、修正内容ごとに範囲を分割して実行
- 実行回数を制限する
  - 常に実行するのではなく、必要に応じて実行するための基準を決める
