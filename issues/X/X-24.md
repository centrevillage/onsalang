# X-24 遅いテストを常に回さない

- 決めたこと（2026-11-07、122 回目、利用者）: テスト実行を遅くするテストは、常に実行される形にしない。
  - きっかけ: E0423 は事例が 3 件要り（`diag-negatives`）、1 件が具体化を約 65536 個作る。事例は `cargo test` の `cases` のほか、static の `diag-negatives`（`onsa_cases --run`）、`fix-loop`、C の検査、`compare.py core` が読むので、1 件の重さが何度も掛かる。
  - 手順:
    1. 仕組み: 重い事例を `tests/heavy/` に置く。`onsa_tests::case::EXCLUDED` に足して既定の走査から外し、`crates/onsa_tests/tests/cases.rs` の `#[ignore = "heavy"]` のテストがそのディレクトリを回す。
       gate の項目 `heavy` は `--quick` で飛び、全体の gate と段の終わりで回り、作業の検査と網羅の検査では `crates/onsa_core/` か `tests/heavy/` が変わったときだけ回る。
       `diag-negatives` は `tests/heavy/` の印を走らせずに数える（照らすのは項目 `heavy`）。`compare.py core` も外す。
    2. 既にあるテストの洗い出し: `cargo test --workspace` と事例で 1 件約 1 秒を超えるものを測り、移すものを利用者と決める。
