# 改善の項目（X）

進め方の改善の項目（gate とファズ、文書の構造など）。利用者が問題点と改善の手順を書き、親が手順ごとに案を出し、利用者が決める。
手順で作った評価・案・道具・独立のレビューは、横のディレクトリ `issues/X/X-<番号>/` に置く（scratchpad の経路は書かない）。決めた後の実行の単位は `tasks/` に作り、項目のファイルから ID で指す。

- 一覧は `python3 -B tools/docs.py list X`。

## 頭の欄

| キー | 形 | 値 | 要る | 意味 |
|---|---|---|---|---|
| `status` | 閉じた値 | `OPEN` / `DOING` / `DONE` | はい | 状態 |

## 本文のラベル

`docs.py new X` は、この節のラベルを新しい X の雛形にする。

- `決めたこと`: `決めたこと（手順 <n>、<日付>）` の形で、手順ごとに決めたことと材料のファイル。
- `持ち越し`: 後の手順や作業に入れること（出所の票と日付と一緒に）。済んでも消さない。

X の本文の初めは利用者の文（`## 問題点`、`## 改善の手順`）で、見出しを保つ（本文に見出しを使わない約束の例外）。ラベルの箇条はその後に置く。
